Favicon Sizes Explained: 16×16 to 512×512

Every favicon size and what it is for: 16×16 tab icons, 32×32 retina, 180×180 Apple Touch, 192×192 and 512×512 Android, and how the ICO container ties them together.

A favicon is not one image. It is a family of images at different sizes, each serving a different place in the browser or on a device. The smallest is 16 by 16 pixels for the tab, and the largest is 512 by 512 pixels for Android install screens.

Understanding which size goes where saves you from the two classic failures: a blurry tab icon and a pixelated home screen icon. This guide walks through every size in a complete pack, from 16 pixels to 512 pixels, and explains what each one does.

All of these sizes come from a single upload in the favicon generator. You never need to export each size by hand. Knowing what the pack contains, though, helps you check that nothing is missing and design a mark that works at every scale.

The 16 Pixel Tab Icon

Sixteen by sixteen pixels is the size a favicon was born at, and it is still the size most people see most often. It sits in the browser tab next to the page title, a square about the width of a capital letter.

At this size, only the boldest shapes survive. A single letter, a solid symbol, or a high-contrast shape reads clearly. Thin lines disappear, gradients flatten into a single tone, and small text becomes noise. Design for this size first and everything else follows.

Every browser uses the 16 pixel icon in the tab bar, and most also use it in bookmark menus and history lists. It is the hardest working size in the pack, seen hundreds of times a day by a regular visitor.

When you check your icon, look at the 16 pixel preview before anything else. If the mark is recognizable there, it will be recognizable everywhere. If it is a blur there, no larger size can save it.

The 32 Pixel Retina Tab Icon

Thirty-two by thirty-two pixels is the retina version of the tab icon. High-density screens pack twice as many physical pixels into the same space, so browsers request the 32 pixel icon to keep the tab mark sharp on modern laptops and desktops.

On a standard screen, the 32 pixel icon is downscaled to 16 and looks the same as the smaller file. On a retina screen, it renders at full sharpness, with edges that look crisp instead of soft. The difference is subtle but visible side by side.

The ICO container holds both the 16 and 32 pixel versions, so the browser picks the right one for the screen it is running on. You do not need to choose between them or serve them separately.

A mark designed for 16 pixels works fine at 32, because the larger size only adds sharpness. The reverse is not true: a mark that needs 32 pixels of detail to be understood will fall apart when it is squeezed to 16.

The 48 Pixel Shortcut Icon

Forty-eight by forty-eight pixels is the size Windows uses for desktop shortcuts and taskbar pins. When someone drags your site to the desktop or pins it to the taskbar, the 48 pixel icon is the one that appears.

It also appears in some browser bookmark managers and in the address bar on older browsers. It is a middle size: large enough to show a little more detail than the tab icon, but still small enough that simplicity wins.

The ICO file includes the 48 pixel size alongside the smaller ones, so desktop shortcuts get a proper icon instead of a stretched 16 pixel file. A stretched icon at this size looks soft and unprofessional, which is why the dedicated size exists.

Most sites never think about this size, and most visitors never notice it consciously. It matters on the day someone pins your site to their taskbar and sees it every morning beside their other apps.

The 64 and 96 Pixel Sizes

Sixty-four and 96 pixel icons serve the in-between contexts: larger bookmark tiles, browser new-tab pages, and some extension interfaces. They are the sizes that appear when the browser has more room than a tab but less than a home screen.

At 64 pixels, a logo can carry a little more character than at 16. A two-tone mark or a simple symbol with a background shape reads well. At 96 pixels, the icon starts to look like a small app tile rather than a tab mark.

These sizes live inside the ICO container too, so they cost nothing extra to ship. The browser selects the closest size to what it needs and scales the rest of the way, which keeps edges clean.

You rarely need to think about these sizes when designing, because anything that works at 16 and at 180 will work at 64 and 96. They exist to fill the gaps so no context ever gets a badly scaled icon.

The 180 Pixel Apple Touch Icon

One hundred eighty by 180 pixels is the Apple Touch Icon, used when an iPhone or iPad user adds your site to the home screen. It is the first size where your icon is displayed large enough to be judged as a design rather than a tab marker.

Apple ignores transparency in this icon and fills transparent areas with black. A logo with a transparent background gets black corners that look like a mistake, so a solid background fill is the standard choice here. A brand-colored square behind the mark is the safe and attractive option.

Apple also adds its own rounded-corner mask to home screen icons, so the corners of your 180 pixel image are hidden behind the system shape. Design with that in mind: keep important detail away from the corners, since the mask will clip them.

The Apple Touch Icon is a PNG file, separate from the ICO container. It is linked from the HTML snippet with a dedicated link tag, and the browser fetches it only when the user adds the site to the home screen.

The 192 Pixel Android Icon

One hundred ninety-two by 192 pixels is the Android home screen icon, listed in the web manifest. When an Android user adds your site to the home screen, this is the icon that appears beside their apps.

Android applies a mask to the icon depending on the device and launcher, so the safe area matters. Keep the mark centered with padding around it, because a launcher may crop the edges into a circle, a squircle, or a rounded square.

The 192 pixel icon is also used for the install prompt and for the site in the app drawer on some devices. It needs to look like an app icon, not a shrunken logo: bold, centered, and readable at a glance.

Unlike the Apple icon, the Android icon can use transparency, but a solid background is still the safer choice. A solid fill guarantees the icon looks the same on every launcher and wallpaper, while a transparent mark can clash with a busy background.

The 512 Pixel Android Icon

Five hundred twelve by 512 pixels is the largest size in the pack, used for the Android splash screen and the install prompt. When a user opens your installed web app, this icon appears on the splash screen while the page loads.

At this size, every flaw in the source image is visible. A low-resolution logo stretched to 512 pixels looks soft, and a JPEG with compression artifacts shows them plainly. This is the size that punishes a small source file most severely.

Start from a source of at least 512 pixels, or an SVG, so the largest icon renders as sharply as the smallest. A vector source is ideal here because it scales to 512 without any loss at all.

The 512 pixel icon is also the file many site builders ask for when you set a site icon in a dashboard. Uploading this PNG gives the builder a large, clean source to resize for its own needs.

How the ICO Container Works

The ICO format is a container that holds several images of different sizes in a single file. A typical favicon.ico contains the 16, 32, 48, and sometimes 64 pixel versions, each stored as its own image inside the container.

When a browser needs an icon, it opens the ICO file, looks at the sizes available, and picks the one closest to what it needs. This is why one file can serve the tab, the bookmark menu, and the desktop shortcut without separate downloads.

The ICO file the generator produces is a genuine multi-frame ICO binary. That distinction matters because a renamed PNG with an ICO extension fools some browsers but fails in others, and fails entirely in tools that validate the format.

Modern browsers can also use a PNG favicon directly, which is why the pack includes PNG files too. The ICO file remains the default because of its long history: browsers request favicon.ico at the site root even when no snippet is present.

Which Size Does What: A Quick Map

The tab icon is 16 pixels, with 32 pixels for retina screens. Desktop shortcuts and taskbar pins use 48 pixels. Larger bookmark tiles and new-tab pages use 64 and 96 pixels. The Apple home screen uses 180 pixels, Android uses 192 for the home screen and 512 for the splash screen and install prompt.

Each size is a different viewing distance. The tab icon is seen at a glance among many tabs, the home screen icon is seen deliberately among apps, and the splash screen icon is seen alone while a page loads. The design must work at all three distances.

The pack covers every context with five files: the ICO container, the Apple Touch PNG, the two Android PNGs, and the manifest that points to them. Nothing else is needed for a complete setup.

If you ever find a size missing from a pack, regenerate rather than patching it in by hand. A hand-added file can carry the wrong dimensions or the wrong format, while a regenerated pack keeps every size consistent with the same source.

Designing for Every Size

Design for the smallest size first. If the mark reads at 16 pixels, it will read at every larger size, because larger sizes only add room and sharpness. If the mark needs 180 pixels to be understood, it will fail in the tab where it is seen most.

Use one bold shape, one or two colors, and strong contrast. A single initial in a brand color on a solid background is the most reliable favicon design there is. A detailed illustration with five colors is the least reliable.

Test the mark at 16, 180, and 512 pixels before you ship it. Those three sizes represent the tab, the home screen, and the splash screen. If the design survives all three, the sizes in between will take care of themselves.

When a logo cannot be simplified enough, use a detail of it rather than the whole thing. A symbol from the logo, a single letter, or the most recognizable shape often makes a better favicon than the full wordmark squeezed into a square.

Checking Your Pack

After generating, open the ZIP and confirm the ICO file, the Apple Touch PNG, the 192 and 512 pixel Android PNGs, and the manifest are all present. A missing file usually means an interrupted download, so regenerate if anything is absent.

Install the pack on your site, then check the tab icon, the bookmark icon, and the home screen icon on a real phone. Each check tests a different size, and together they cover the whole range from 16 to 512 pixels.

Clear the browser cache if the old icon lingers, and test in a private window to see what a new visitor sees. A private window has an empty cache, so it shows the current files rather than a stored copy.

If one size looks wrong while the others look right, the source image is usually the cause. A low-resolution source fails at 512 pixels, and a detailed source fails at 16. Regenerate from a better source rather than editing a single output file.

Quick Reference: Favicon Sizes at a Glance

Tab: 16 pixels, retina 32. Desktop shortcut: 48. Bookmark tiles: 64 and 96. Apple home screen: 180. Android home screen: 192. Android splash and install: 512. The ICO file holds the small sizes, PNG files hold the large ones, and the manifest lists the Android icons.

Design for 16 pixels first, start from a source of at least 512 pixels or an SVG, and give the Apple icon a solid background. Test the tab, the bookmark, and the home screen before you call the job done.

Frequently asked questions

What is the smallest favicon size I need?

Sixteen by sixteen pixels is the smallest size, used for the browser tab. It is also the hardest to design for, because only the boldest shapes survive at that size. Always check the 16 pixel preview before downloading a pack.

Why do I need a 512 by 512 icon for a tiny tab favicon?

The 512 pixel icon is not for the tab. Android uses it for the splash screen and the install prompt, where the icon is displayed large. A pack without it shows a stretched or missing icon on Android, even though the tab icon works fine.

Is a PNG favicon enough, or do I need an ICO file?

A PNG works in modern browsers, but the ICO file is still the default: browsers request favicon.ico at the site root even without a snippet, and the ICO container holds several sizes in one file. A complete pack includes both, so every browser and context is covered.

What size should my source logo be for a favicon?

At least 512 by 512 pixels, or an SVG with no fixed resolution. The largest icon in the pack is 512 pixels, so a smaller source gets stretched and looks soft. A large source or a vector file keeps every size sharp.

Why does the Apple Touch Icon need a solid background?

Apple fills transparent areas of the home screen icon with black, which looks like a rendering error. A solid brand-colored background avoids the black corners entirely and makes the icon look like a deliberate app icon.

Do all browsers use the same favicon sizes?

Mostly, but not exactly. All browsers use 16 and 32 pixels for tabs, while Apple and Android each have their own home screen sizes. A complete pack covers the shared sizes plus the platform-specific ones, so you do not need to track each browser separately.
