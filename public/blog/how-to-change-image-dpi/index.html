How to Change Image DPI

Change an image DPI to 72, 150, 300, or 600 in four steps — or any custom value up to 2400. Batch support, ZIP download, and a Verified DPI badge included.

Your image is ready, but the platform wants 300 DPI and your file says 72, or says nothing at all. The fix takes less than a minute once you know the steps.

This guide walks you through changing image DPI in four practical steps: upload, choose the value, verify the badge, and download. It also covers batches, screenshots, and the common problems that trip people up.

No software to install, no account to create, and no pixels harmed. The change is a metadata edit, so your image looks exactly the same when you finish.

What You Need Before You Start

You need the image files in JPEG or PNG format. Those are the only formats that store a DPI tag in a standard way, so the tool accepts only those two.

Know the DPI value your destination wants. Book printers and journals usually ask for 300, draft prints accept 150, and screens are happy with 72 or 96.

Check the pixel dimensions before you start. DPI cannot rescue an image with too few pixels, so confirm the dimensions are large enough for the print size you need.

A browser is all the software you need. The tool runs on Chrome, Safari, Firefox, and Edge, on desktop and on mobile, with no extension.

Step 1: Upload Your JPEG or PNG Files

Open the image DPI changer and drag your files into the upload area. You can drop one image or a whole batch at once.

You can also click the upload area to browse for files, or paste a clipboard screenshot with Ctrl+V to stamp it immediately without saving it first.

Each file appears in a list with its current DPI shown beside it. Many photos will read Before: Not set, which simply means the file has no DPI tag yet.

If a file is rejected, check its format. WebP, HEIC, BMP, GIF, and SVG files are not supported here, and the tool will tell you so rather than failing silently.

Step 2: Choose a Preset or a Custom DPI

Pick one of the five presets: 72 for screen, 96 for Windows, 150 for draft print, 300 for high print, or 600 for archival work. For most publishing jobs, 300 is the right choice.

If your destination asks for a different number, type it into the custom DPI field. Any whole number from 1 to 2400 is accepted, so values such as 200 or 350 work fine.

The same value applies to every file in the batch. If different images need different DPI values, process them in separate batches, one value at a time.

Double-check the number before you process. A typo that turns 300 into 3000 is easy to make and will be written faithfully, so read the field once more.

Step 3: Process and Look for the Verified Badge

Click to process the files. The tool rewrites the DPI tag in each file header and then reads the file back to confirm the new value is stored correctly.

Each successful file shows a Verified DPI badge. That badge is your confirmation that the file will report the same DPI in any standards-compliant reader, including your publishing platform.

If a file shows an error instead, read the message. A corrupted JPEG or an unsupported format will be flagged clearly, and the rest of the batch will still process normally.

Do not skip the verification step. A file that was processed but not verified is a guess, and a failed submission costs far more time than a second glance at the badge.

Step 4: Download the Stamped Files

Download each file individually, or click the ZIP download to get the whole batch in one archive. The ZIP keeps the original file names, so the images drop straight back into your project.

Output files are named clearly so you can tell them apart from the originals. Keep the originals as well, so you always have an untouched copy to return to.

Open one downloaded file in your platform or in an image viewer and confirm the DPI reads correctly. That final check takes seconds and catches any misunderstanding before submission.

Submit the stamped files to your platform. If the platform still complains, the problem is usually the pixel dimensions, not the DPI, so check those next.

Changing DPI for a Whole Batch

Books, catalogs, and journal articles need dozens of images at the same DPI. The batch workflow handles them all in one pass with one preset.

Drop the entire folder into the tool and choose the value once. Every file gets stamped, verified, and listed with its badge, so you can see at a glance if any file failed.

Download the batch as a single ZIP. The archive preserves the file names, which matters when the images are referenced by name in a document or a layout file.

If a few files in the batch are WebP or HEIC, convert them first. The image converter turns them into JPG or PNG, and then they can join the next batch.

DPI for Print Publishing and Journals

Book platforms such as Amazon KDP check DPI on every image in the manuscript. A cover or an interior image tagged below their minimum is rejected, and the whole submission stalls.

Academic journals are stricter still. Many demand 300 DPI for photographs and 600 DPI for line art, and they check the tag before they check the content.

The workflow is the same in both cases: confirm the pixel dimensions first, stamp the DPI second, verify the badge third, and submit fourth. Skipping the first step is the most common cause of a second rejection.

For line art, use the 600 DPI preset. Thin lines and small text need the extra density, and a 300 DPI line drawing can look ragged when printed at full size.

Fixing a 72 DPI File That Got Rejected

A 72 DPI rejection is the most common DPI problem, and it is also the easiest to fix. The pixels are usually fine; only the metadata tag is wrong.

Upload the file, choose the 300 DPI preset, and process it. The tool rewrites the tag, verifies it, and the downloaded file passes the platform check.

Before you resubmit, confirm the dimensions. A 72 DPI file that is also small in pixels will fail again, this time on dimensions, and no DPI value can fix that.

If the file is a screenshot, the same fix applies. Screenshots usually carry a 72 or 96 DPI tag, and stamping them at 300 DPI makes them acceptable to print workflows, provided the pixels are enough.

DPI for Screenshots

Screenshots are the quickest DPI fix of all, because you can paste them straight from the clipboard. Copy the screen, press Ctrl+V in the tool, and the screenshot is ready to stamp.

Choose 300 DPI for a screenshot that will appear in a printed manual or a book. The pixels are whatever the screen captured, but the tag will satisfy the print workflow.

Be honest about the limits. A screenshot of a small dialog box has few pixels, and stamping it at 300 DPI makes it a very small print, not a sharp large one.

For screenshots that must print large, capture them at a higher display scaling first. A screenshot taken on a retina display carries twice the pixels and prints twice as large.

Removing or Stripping a DPI Tag

Sometimes you want no DPI tag at all, rather than a different one. The tool can strip the DPI metadata from a file, leaving the pixels untouched.

Stripping is useful when a file carries a wrong tag that confuses your software. A photo tagged at an odd value can make a layout program scale it unexpectedly, and removing the tag resets the behavior.

To strip the tag, use the remove option in the tool and process the file. The downloaded file has no DPI metadata, and software that opens it will fall back to its own default.

Only strip a tag when you have a reason. Most publishing workflows want a tag present, and a file with no tag can be rejected just as easily as a file with the wrong one.

Troubleshooting Unsupported Formats

If the tool rejects your file, the first thing to check is the format. WebP, HEIC, BMP, GIF, and SVG files are not supported, and the tool will say so clearly.

Convert the file to JPG or PNG and try again. The image converter handles WebP and HEIC, and the conversion preserves the pixels while giving the file a format that can carry a DPI tag.

Watch out for misnamed files. A WebP file saved with a .jpg extension will be rejected even though its name looks right, because the tool reads the actual file contents.

When in doubt, open the file in an image viewer and re-save it as JPG or PNG. A clean re-save guarantees the format matches the extension.

Troubleshooting Corrupt Files

A corrupted JPEG will fail with an error message, and the rest of the batch will keep processing. The error is specific to that file, not to the tool.

Try opening the file in an image viewer. If the viewer also fails, the file is damaged and needs to be re-downloaded or re-exported from its source.

A file that opens in the viewer but fails in the tool may have a damaged header. Re-saving it from the viewer writes a fresh header, and the new file usually processes fine.

Never submit a file that failed processing. A corrupt file that slips into a print job can stall the whole submission, so fix or replace it before you go further.

Checking the Result After Download

After downloading, open one file and confirm its DPI. On Windows, right-click the file, choose Properties, and look at the details tab. On Mac, open it in Preview and check the inspector.

The number should match what you chose. A JPEG stamped at 300 DPI reads back as 300, while a PNG can read back as 299 because of how PNG stores resolution in pixels per meter.

If the number is wrong, re-process the original rather than the downloaded file. Re-stamping a stamped file works, but starting from the original keeps the chain of changes clean.

Keep a note of the value you used for each project. When the same images go to a second platform with different rules, the note tells you what to change without re-checking every file.

DPI for E-commerce and Marketplace Images

Marketplace images live on screens, so DPI seems irrelevant to them, but sellers still get tripped up by it. The confusion usually starts when a marketplace help page mentions DPI alongside pixel dimensions.

For product listings, the pixel dimensions are the rule that matters. A marketplace that wants 1000 pixels on the longest side checks the pixel count, not the DPI tag, and a file stamped at 300 DPI with only 600 pixels still fails.

That said, stamping marketplace images at 300 DPI does no harm and occasionally helps. Some seller tools and print-on-demand services read the tag, and a correct value keeps those workflows smooth.

The practical approach is to fix the pixels first and the DPI second. Confirm the dimensions with the dimensions checker, resize if needed, and then stamp 300 DPI as a final step before uploading the listing images.

For print-on-demand products such as mugs, shirts, and posters, DPI matters a great deal. The product is printed, so the same 300 DPI standard applies, and the pixel math decides how large the design can be printed.

Check the print-on-demand requirements for each product before you upload. A design that works on a mug may be too small for a poster, and the DPI tag alone will not bridge that gap.

Re-applying a Different DPI Value

Projects change, and a file stamped at 300 DPI may later need 600 DPI for an archive or a fine-art print. The tool lets you re-apply a new value to the same files.

Upload the files again, choose the new preset or custom value, and process them. Each pass is lossless, so the pixels are never degraded by repeated stamping.

You can also go the other way, from 600 back down to 300, with the same safety. The header is rewritten each time and the pixel data is never touched.

Frequently asked questions

How long does it take to change the DPI of an image?

Seconds. The tool rewrites a few bytes in the file header and does not re-encode any pixels, so even a large batch finishes quickly. The time you spend is mostly uploading and downloading, not processing.

Can I change the DPI of many images at once?

Yes. Drop the whole batch into the tool, choose one DPI value, and every JPEG and PNG in the batch gets stamped in a single pass. Download the results as one ZIP file with the original file names preserved.

What happens if I enter a custom DPI by mistake?

The tool writes whatever number you enter, from 1 to 2400, and verifies it with the badge. If you notice the mistake, just re-process the original files with the correct value. Each pass is lossless, so the error costs you a minute, not the image.

Does changing DPI affect the image quality or colors?

No. Only the resolution metadata in the header changes. The pixels, the compression, the EXIF data, and the ICC color profile all stay exactly as they were. The image looks identical on screen before and after.

Can I paste a screenshot and change its DPI right away?

Yes. Copy the screenshot, press Ctrl+V in the tool, and it appears ready to stamp. Choose 300 DPI for print use, process it, and download the result. This is the fastest route from screen capture to print-ready file.

Why was my file rejected by the DPI changer?

The usual reasons are an unsupported format such as WebP or HEIC, a file over the size limit, or a corrupted JPEG. Convert unsupported formats to JPG or PNG first, and re-export any file that will not open in an image viewer.
