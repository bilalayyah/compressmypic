How to Check Image Dimensions

Check the width, height, aspect ratio, and print size of any image — one file or a whole batch. Five steps, with CSV and JSON export at the end.

You need to know how big an image really is, in pixels, before you upload it, print it, or hand it to a client. The file name will not tell you, and the thumbnail lies.

This guide shows you how to check image dimensions in five steps, for one image or for a whole batch. It takes about a minute, and you will end with a report you can share.

No software to install, no account to create, and nothing uploaded anywhere. Your images are read locally in your browser from start to finish.

What You Need Before You Start

You need the image files themselves, on your computer or phone. JPG, PNG, WebP, GIF, BMP, HEIC, and SVG files all work, up to 20 MB each.

If you have a platform requirement, note it down first. A minimum width, a required ratio, or a target print size gives the check a pass-or-fail standard instead of a vague feeling.

A browser is all the software you need. Chrome, Safari, Firefox, and Edge all run the tool, on desktop and on mobile, with no extension.

For a batch check, gather the files into one folder before you start. Dropping a folder is faster than hunting for files one by one while the table is half built.

Step 1: Upload One Image or a Whole Batch

Open the image dimensions checker and drag your files into the upload area. You can drop a single image or a whole folder at once.

You can also click the upload area to browse for files, or paste a clipboard image with Ctrl+V to check a screenshot you just took.

The table starts filling in as each file is read. Each row shows the file name, pixel dimensions, aspect ratio, megapixels, file size, and transparency status.

If you have more files to add later, drop them in and they join the existing table. The tool appends new rows instead of clearing the ones you already have.

Step 2: Read the Dimensions Table

Start with the dimensions column. It shows width by height in pixels, such as 1920 by 1080, and that pair is the single most important number in the whole report.

Compare the width and height against your requirement. If your platform wants at least 1000 pixels wide and the image is 800, it fails, no matter how good it looks.

Next, glance at the megapixels column. It tells you the total pixel count at a glance, which helps when you compare two images that have different shapes but similar size.

Finally, check the file size column. A very small file with large dimensions may be heavily compressed, which is a warning sign for print work even if the pixels check out.

Step 3: Check the Aspect Ratio

The ratio column shows the shape of each image, such as 16:9, 4:3, or 1:1. It also shows the exact ratio when an image does not match a standard shape.

Match the ratio to your destination. A 4:5 portrait fills a phone feed better than a square, while a 16:9 landscape suits a video thumbnail or a website hero image.

Watch for near misses. An image at 1.48:1 looks square-ish but is not 3:2, and a platform that crops to 3:2 will trim its edges in ways you did not plan.

If the ratio is wrong, crop the image before you do anything else. The image cropper cuts to the exact ratio you need, and the checker confirms the result afterwards.

Step 4: Validate Against Minimum Width and Height

Enter your platform minimums in the Min Width Check and Min Height Check fields. The tool flags every image that falls below either number.

Flagged rows are your to-do list. Each one needs either a larger source file, a resize, or a decision to accept the lower quality.

Do not upscale a flagged image and assume the problem is solved. Upscaling invents pixels, so the file passes the number check while looking softer than a true high-resolution image.

When a source file cannot be made larger, talk to the person who supplied it. A photographer or designer with the original can usually export a bigger version in seconds.

Step 5: Export the Report as CSV or JSON

When the table is complete, click Export CSV for a spreadsheet or Export JSON for a structured data file. Both contain the same columns as the on-screen table.

The CSV opens in Excel or Google Sheets, where you can sort by width, filter by ratio, or highlight the flagged rows for a teammate to fix.

The JSON is for developers and automated pipelines. It carries the same data in a format a script can read, which suits content systems and quality dashboards.

Export before you close the tab, because the table lives only in your browser. A refresh clears it, and re-checking a large batch is a waste of time.

Checking a Single Image Quickly

For one image, the process is the same but faster. Drop the file in, read the dimensions row, and you are done in under ten seconds.

Paste is the fastest route of all for screenshots. Copy a screenshot, press Ctrl+V in the tool, and the dimensions appear without saving any file.

On a phone, upload the image from your gallery. The table works on small screens, and the key numbers are visible without scrolling sideways.

A single-image check is also the fastest way to settle an argument. When two people disagree about whether an image is big enough, the checker gives a number neither side can dispute.

Reading the Print Size Column

The Print at 300 DPI column converts pixels into inches at print quality. A 3000-pixel-wide image shows as 10 inches, which is its safe printed width.

Compare that number with the size you actually need. If you need an 8-inch print and the column says 4 inches, the image will look soft when stretched to fit.

Remember that 300 DPI is a quality standard, not a law. A poster viewed from across a room can print fine at 150 DPI, while a brochure held in the hand needs the full 300.

For print questions in general, the image DPI changer can set the DPI metadata on your files once you know the pixels are sufficient.

Spotting Misleading File Extensions

A file named .jpg is not always a JPEG. People rename files, and some systems save a WebP with a .jpg extension by mistake.

The checker reads the actual image data, not the extension. If a supposed JPG turns out to be a WebP, the tool reports what the file really is.

This matters because some platforms reject files whose contents do not match their extension. Catching the mismatch in the checker saves a failed upload later.

If you find a misnamed file, convert it properly instead of renaming it again. The image converter writes a correct file with the right format and extension.

Checking SVG Files

SVG files are vectors, so the checker reads their intrinsic dimensions from the width, height, and viewBox attributes instead of counting pixels.

The intrinsic size is the size the designer intended. An SVG can scale far beyond it without losing sharpness, but the intended size tells you the proportions to preserve.

If an SVG has a viewBox but no width or height, the checker shows the ratio without absolute dimensions. That is normal for responsive icons designed to scale.

For icons, compare the SVG ratio with your layout. A viewBox of 0 0 24 24 is square, and placing it in a wide slot will either stretch it or leave empty space.

Troubleshooting Unreadable Files

Sometimes a file will not read at all, and the tool marks it as an error. The usual cause is a corrupted download or a file that is not really an image.

Try opening the file in an image viewer first. If the viewer also fails, the file is damaged and needs to be re-downloaded or re-exported from its source.

A file over 20 MB will also be rejected. Compress it or resize it first, then check the smaller version, since the dimensions of the resized file are what you will actually use.

One bad file never blocks the rest of the batch. The checker reports the error row and keeps reading the remaining files, so you can fix the broken one afterwards.

Fixing an Image That Failed the Check

Start with the source. Ask for the original export at a larger size before you try any software fix, because a true high-resolution file beats any upscaled copy.

If the ratio is wrong, crop it. The image cropper cuts to the exact ratio your platform wants, and a fresh check confirms the new dimensions.

If the file is too small and no larger source exists, resize it with the image resizer and accept the softness. It is better than failing the upload, but be honest with the client about the quality.

Re-check after every fix. A second pass through the checker confirms the new dimensions and gives you a clean report to file with the finished work.

Sharing the Report with Your Team

A CSV report is the easiest thing to share. Send it to the designer, the developer, or the client, and everyone sees the same numbers instead of arguing from memory.

Highlight the flagged rows before you send it. A report with the failures marked clearly gets fixed faster than a raw table that makes the reader hunt for problems.

For recurring work, agree on a minimum size once and write it down. Every future batch gets checked against the same standard, and the reports become comparable over time.

Keep old reports in the project folder. When a platform changes its requirements, the old report shows which images were compliant before and which ones need re-checking now.

Checking Dimensions Before a Print Order

Print orders are the most expensive place to discover a dimensions problem, because the mistake is only visible after the job is printed and paid for. A two-minute check beforehand is the cheapest insurance in the whole workflow.

Start by asking the printer for the finished size in inches and the DPI they want, which is usually 300. Multiply the inches by the DPI to get the pixel dimensions you need, and write that number down.

Run your images through the checker and compare each one against that target. Any image that falls short will print soft, and the shortfall tells you exactly how much smaller the print must be to stay sharp.

Pay attention to the ratio as well as the size. A print shop that trims to a fixed ratio will crop your image, so confirm that the important details sit safely inside the crop area.

Check the file format at the same time. Printers prefer JPG or TIFF for photos and PDF or PNG for graphics, and a file in the wrong format can cause delays even when the dimensions are right.

Finally, export the report and send it to the printer with the files. A printer who can see the dimensions table will spot a problem before the press runs, which is far better than spotting it on the finished sheets.

Making Dimension Checks a Habit

One-off checks catch one-off problems, but most dimension failures repeat. The same supplier sends small images every month, or the same template exports at the wrong ratio again and again.

Build the check into your workflow instead of treating it as an emergency step. Run every new batch of images through the checker the moment it arrives, before anyone starts designing with it.

Keep a simple log of what failed and why. After a few weeks the pattern becomes obvious, and you can fix the source — a wrong export preset, a careless supplier, or a template that needs updating — instead of fixing each image by hand.

Share the habit with the team. When everyone checks dimensions before handing files over, the failures stop arriving at the last minute, and the checker becomes a quiet background step rather than a rescue tool.

Quick Reference Checklist

Drop the files in, read the dimensions column first, then the ratio, then the megapixels and file size for context.

Enter your minimum width and height, flag the failures, and fix them from the source file whenever possible rather than upscaling.

Check the print size column before sending anything to print, and export the CSV or JSON report before closing the tab.

Frequently asked questions

How do I check the dimensions of an image on my phone?

Open the dimensions checker in your mobile browser and upload the image from your gallery. The table shows width, height, ratio, and megapixels. You can also paste a screenshot directly to check its pixel size without saving a file.

Can I check dimensions without downloading any software?

Yes. The checker runs entirely in your browser on desktop and mobile. There is nothing to install, no account to create, and your files are never uploaded to a server.

Why does Windows say my image is one size and the checker says another?

Windows Explorer sometimes shows dimensions rounded or scaled for display, and some apps show the size after applying DPI settings. The checker reads the true pixel width and height stored inside the file, which is the number platforms actually check.

What is a good minimum width for product photos?

It depends on the platform, but most marketplaces want at least 1000 pixels on the longest side so shoppers can zoom in. Always check the current rules for the specific marketplace, then enter that number in the Min Width Check field.

Can the checker read dimensions from a screenshot I paste?

Yes. Copy the screenshot and press Ctrl+V in the tool, and it will read the pixel dimensions immediately. This is the fastest way to verify the size of a screen capture before sending it to someone.

What should I do if my image is smaller than the required size?

First ask for the original file at a larger size, since upscaling invents pixels and softens the image. If no larger source exists, resize it with the image resizer and accept the quality trade-off, then re-check to confirm the new dimensions.
