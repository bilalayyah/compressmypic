How to Convert Multiple Images at Once

Convert a whole folder of images to JPG, PNG or WebP in one pass. Upload, pick a format, set quality, and download one ZIP.

Converting images one at a time is fine for a single photo. For a folder of fifty, it is a chore that eats an afternoon. Batch conversion does the whole folder in one pass.

The process is simple: upload the folder, pick one output format, set the quality once, and download a single ZIP with everything inside.

This guide walks through each step, with the settings that matter for a clean, consistent batch.

Step 0: Prepare Your Folder First

Put every image you want to convert in one folder before you start. A tidy folder means you upload once, instead of hunting through your drive for stragglers.

Remove files that do not belong. Old screenshots, duplicates, and unrelated photos only slow the batch down and clutter the ZIP.

Check for problem files. A file named .jpg that is really a WebP, or a half-downloaded image, will fail during conversion. Fix or remove those first.

Keep the originals safe. The converter never modifies them, but a backup copy in a separate folder is good practice before any batch job.

Step 1: Upload the Whole Batch

Open the Bulk Image Converter in your browser. The page works on desktop and mobile, with nothing to install.

Drag the folder onto the upload area, or click it to select multiple files. You can pick dozens of files at once in the file picker.

Each file appears as a card with its name, dimensions, and size. Scan the list quickly to confirm nothing is missing and nothing extra slipped in.

Files up to 25MB each are accepted. That covers phone photos, camera shots, and large screenshots, so most folders upload without any preparation.

Step 2: Pick the Target Format

Choose JPG when the batch is mostly photographs and the destination is general. Every system accepts JPG, and the files stay small and portable.

Choose WebP when the batch is for a website. It is smaller than JPG at the same quality and keeps transparency, which suits mixed photo and logo batches.

Choose PNG when the batch is graphics, icons, or screenshots with text. PNG keeps edges sharp and transparency intact, though the files are larger.

Remember that one format applies to the whole batch. If you need two formats, run the batch twice rather than splitting it by hand.

Step 3: Set the Quality Once

The quality slider applies to every file in the batch. For JPG or WebP output, 80 to 85 percent is a safe default for mixed photo batches.

For batches with text-heavy screenshots, prefer WebP at 85 percent. It keeps small letters readable, while JPG tends to smear them.

For batches you plan to print, push the quality to 90 percent or higher. Print reveals flaws that screens hide, and the extra size is worth it.

If you picked PNG, the slider disappears. PNG is lossless, so there is no quality level to choose, and every file stores its pixels exactly.

Step 4: Decide About Transparency

If your target is JPG, pick a matte fill colour for transparent areas. White suits most uses, while a brand colour matches a specific website background.

Check a logo card after the first conversion to see how the fill looks. A black box behind a logo means the fill colour was wrong, and you can change it.

If your target is PNG or WebP, skip this step. Both formats preserve transparency, so logos and stickers stay see-through without any fill.

Mixed batches need a moment of thought here. A logo and a photo in the same JPG batch share the fill colour, but the fill only affects transparent parts, so photos are untouched.

Step 5: Convert and Watch the Progress

Click the Convert button and watch the cards change. Each file converts independently, so you can see progress file by file rather than waiting blindly.

Large batches take a little while, since every file is decoded and re-encoded on your device. A batch of fifty photos usually finishes in a minute or two.

Watch for error badges as the batch runs. A single corrupted file shows a warning without stopping the rest, so the good files still finish.

You can add more files while a batch is running. New files join the queue and convert with the same settings as the rest.

Step 6: Review the Results Card by Card

Each converted card shows the new file size next to the old one. A quick scan tells you whether the batch actually saved space.

Click Compare on a card to inspect the before and after side by side. Check faces, text, and edges, which are the first places where low quality shows.

Pay attention to the batch summary at the end. It totals the original and converted sizes, so you can see the overall savings in one number.

If the total grew instead of shrinking, the format was wrong for that batch. Switch from PNG to WebP or JPG and convert again.

Step 7: Download Everything as One ZIP

Click Download All to bundle the whole batch into a single ZIP archive. The ZIP name identifies the target format, so you know what is inside.

Unzip into a fresh folder, not on top of your originals. A separate folder keeps the converted files organised and prevents accidental overwrites.

If you set a filename suffix, every output carries it. A suffix such as -webp makes the converted files easy to tell apart from the originals.

Check a few files from the ZIP before you use them. Open one photo and one logo, confirm they look right, and check the format is the one you wanted.

Fixing Files That Failed

A failed file shows an error badge on its card. Read the message, since it usually names the problem, such as an unsupported or corrupted file.

Remove the failed file from the list and convert the rest. You can deal with the problem file separately, instead of letting it hold up the batch.

For a file that fails repeatedly, check its real format. Open it in a photo viewer or check its properties, since the extension may be wrong.

Convert stubborn files one at a time in the general Image Converter. A single file is easier to troubleshoot than a batch of fifty.

Converting the Same Batch to Another Format

You do not need to re-upload to make a second version. After the first conversion, change the output format and convert again.

The originals stay in the queue between runs, so a JPG batch and a WebP batch come from one upload. Download each ZIP before switching formats.

Use the filename suffix to tell the two batches apart. A suffix of -jpg for the first run and -webp for the second keeps the outputs organised.

This two-format workflow is common for websites. JPGs serve older systems, while WebPs serve modern browsers, and both come from the same source folder.

Batch Tips for Phones

Batch conversion works on a phone browser, but it is slower and the screen is small. Keep phone batches to a dozen files or fewer.

Select multiple photos at once from your gallery. The upload area accepts multi-select, so you do not need to add photos one by one.

Downloads land in your phone's Downloads folder as a ZIP. You may need a file manager app to unzip it, depending on your phone.

For a large folder, use a desktop. The bigger screen and faster processor make a hundred-file batch far more comfortable.

Keeping Your Originals Safe

The converter never modifies your originals. It reads them, creates new files, and leaves the sources exactly as they were.

Even so, keep a backup of the source folder before a big batch. A single mistake in a later step, such as unzipping over the originals, can still cause trouble.

Use the filename suffix to prevent collisions. When converted files carry a tag like -converted, they cannot overwrite the originals by accident.

Store the originals and the converted copies in separate folders. Clear separation is the simplest way to avoid confusion later.

Sorting Files Before Upload

A quick sort before uploading saves time later. Group the files by type, so photos, logos, and screenshots each get their own batch with the right settings.

Photos want JPG or WebP at 80 to 85 percent quality. Logos want PNG or WebP with transparency preserved. Screenshots with text want WebP at 85 percent.

Sorting takes minutes and prevents rework. A mixed batch forces a compromise setting that suits nobody perfectly, while sorted batches each get their best setting.

Remove duplicates and rejects during the sort. Every extra file costs conversion time and clutters the ZIP, so a quick cull before uploading is worth the effort.

Put the sorted groups in separate folders with clear names, such as photos-to-webp and logos-to-webp. The folders keep the batches organised from start to finish.

Converting Photos from a Trip

Trip photos are the classic bulk job. Hundreds of HEIC files from an iPhone need to become JPGs before they can be shared with family or uploaded anywhere.

Sort the photos first, removing blurry shots and duplicates. A trip album of three hundred photos often has fifty worth keeping, and converting only those saves real time.

Convert the keepers to JPG at 90 percent quality. The photos look their best, the files open everywhere, and the album is ready to share with anyone.

For photos going to a website or blog, convert to WebP instead. The files are a third smaller, the pages load faster, and the images look identical.

Keep the HEIC originals in an archive folder after converting. They are the best-quality copies, and you can convert them again if you need a different format later.

Converting Work Documents in Bulk

Work documents often arrive as a folder of scans in mixed formats. Converting them all to one format makes the set consistent and easier to file.

For scans that must stay readable, convert to PNG. The text stays sharp through editing and re-saving, which matters for contracts and forms.

For scans that must stay small, convert to JPG at 85 percent quality. The files shrink dramatically, and the text stays readable at that setting.

Name the converted files by document and date, such as contract-2026-11.jpg. A clear name helps colleagues find the right file without opening ten candidates.

Store the converted documents in the shared drive with the same folder structure as the originals. A mirrored structure keeps the archive navigable for everyone.

Reusing Settings for Repeat Batches

Repeat batches are common: the same product photos every week, the same screenshots every month. Writing down the settings once makes every repeat batch identical.

Keep a one-line note per job, such as WebP 85 percent, white matte. That line is the whole recipe, and anyone can follow it without guessing.

Store the note in the job folder, next to the source files. A future batch starts by reading the note, not by remembering what worked last time.

When the settings change, update the note immediately. A stale note is worse than no note, since it produces a batch that looks different from the last one.

Review the notes every few months. A setting that made sense for fifty images may not suit five hundred, and a small adjustment can save a large amount of time.

Converting Images for a Client Handover

A client handover needs images in a format the client can open, and JPG is the safest choice. A folder of WebP files may fail on the client's old computer, while JPGs open everywhere.

Convert the images in one batch, using the same quality for all of them. Consistency matters when the client reviews the set, since mixed quality looks careless.

Name the converted files clearly, with the project and the date. A file called website-hero-nov-2026.jpg tells the client what it is, while IMG_4821.jpg tells them nothing.

Include a short readme with the delivery, listing the formats and the settings used. A one-line note prevents the client from asking why there are two copies of every image.

Keep the originals in your own archive after the handover. If the client asks for a different format later, the originals let you convert again without asking for the files back.

Frequently asked questions

Can I drag a whole folder into the bulk converter?

Yes, you can drag a folder onto the upload area, and the tool picks up the image files inside it. You can also click the area and select many files at once in the file picker. Either way, every valid image joins the same conversion queue.

What file types can I mix in one bulk batch?

JPG, PNG, WebP, HEIC, SVG, BMP, GIF, and AVIF can all sit in the same queue. Every valid file converts to the output format you selected. The only exception is animated GIFs, which become still images because only the first frame is converted.

How do I stop converted files overwriting my originals?

Use the optional filename suffix, such as -webp or -converted, so every output has a different name from its original. Also unzip the ZIP into a fresh folder instead of on top of the originals. Together, those two habits make overwrites impossible.

Why is one file in my batch much bigger after converting?

That file probably went from a lossy format to PNG, which stores every pixel exactly and can be several times larger. Or the quality slider was set very high for a simple image. Check that file card, and consider converting it separately with different settings.

Can I pause a bulk conversion halfway through?

There is no pause button, but each file converts independently, so you can simply wait for the current file and then stop adding new ones. Files that already finished stay converted and downloadable. To restart, just upload the remaining files as a new batch.

Does the bulk converter work without an internet connection?

Once the page has loaded, conversion runs locally in your browser and does not need the internet. You need a connection only to open the page the first time. After that, you can convert batches offline until you close the tab.
