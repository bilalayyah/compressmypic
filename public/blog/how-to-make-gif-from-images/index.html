How to Make a GIF from Images

Turn your photos into an animated GIF in minutes: gather frames, upload, order and time them, set the loop, preview, and download a share-ready GIF.

Making a GIF from images is a short job: gather a few photos, upload them as frames, set the timing, and download the animation. This guide walks through each step in order, from choosing frames to sharing the finished GIF.

You need just one thing before you start: two or more images to animate. They can be photos, screenshots, product shots, or illustrations. Similar sizes and shapes give the smoothest result, but the tool handles mixed sizes too.

The GIF maker does the work in your browser. Nothing uploads to a server, there is no account, and the finished GIF downloads free. Follow the steps below and you will have an animation in a few minutes.

Step 1: Gather Your Frames

Collect the images that will become the frames of your GIF. A reaction GIF needs a few photos that show a change of expression. A product demo needs shots from different angles. A tutorial needs one image per step.

Five to fifteen frames is the right range for most GIFs. Fewer frames make a short, punchy animation, while more frames make a longer, smoother one. More than twenty frames usually means the GIF is trying to be a video.

Use images with similar dimensions where you can. Frames of the same size and shape animate smoothly, while wildly different sizes cause jumps and black bars. Crop or resize the frames first if they differ a lot.

Order the frames in your head before you upload. A product rotation reads clockwise, a tutorial reads in step order, and a reaction reads as a build and a payoff. A clear order before you start saves rearranging later.

Step 2: Upload the Frames

Open the GIF maker and drop your frame images onto the dropzone, or click to choose them from your device. You can upload everything at once, or add frames later with the Add Frames control if you find more images mid-way.

The tool accepts JPG, PNG, WebP, HEIC, GIF, BMP, and SVG files up to 20 MB each. Phone photos, screenshots, and graphics all work. An iPhone HEIC photo uploads and converts without any extra step.

The frames appear in the order you uploaded them, as a list you can rearrange. Check that all the images you need are there before moving on. A missing frame is easier to add now than after the timing is set.

If you upload an existing GIF as a frame, the tool can extract a single frame from it. That is useful when you want to reuse one moment from an old animation as part of a new one.

Step 3: Reorder the Frames

Drag the frames into the order that tells the story. The first frame is what viewers see before the animation starts, and the last frame is what they see before the loop restarts, so both ends deserve attention.

Put the strongest frame first. In a chat or a feed, the first frame is the thumbnail, and it decides whether anyone watches the animation at all. A dull first frame means the GIF gets skipped.

Check the sequence for jumps. A frame that belongs later in the motion but sits early in the list creates a visible jump in the animation. Read the frame list like a storyboard and move any frame that breaks the flow.

Remove any frame that does not earn its place. A blurry shot, a duplicate angle, or a frame that adds nothing to the story only makes the GIF longer and heavier. Fewer, better frames beat many mediocre ones.

Step 4: Duplicate or Remove Frames

Duplicate a frame when you want to hold it longer without changing the timing settings. A duplicated title slide shows for twice as long, and a duplicated final frame lets the message land before the loop restarts. Duplicating is the simplest way to emphasize a moment.

Duplicating is also the way to repeat a moment inside the animation. A product angle shown twice reads as a pause, and a reaction frame shown twice reads as emphasis. Use it sparingly, or the animation feels like it stutters.

Remove frames that slow the GIF down without adding meaning. A near-duplicate of the previous frame, a blurry shot, or a frame that only repeats the last one can go. Each removed frame makes the file smaller and the animation tighter.

You do not need to upload the same file twice to repeat a frame. The duplicate control copies the frame inside the tool, so the repeated moment costs no extra upload and no extra file management.

Step 5: Set Frame Delays

Frame delay is how long each frame stays on screen, and it decides how the animation feels. Start with one of the quick presets: 1, 2, 5, or 10 frames per second. Five frames per second is the usual starting point for a demo or a reaction.

Set a single delay for all frames first, then adjust the individual frames that need more time. A title slide needs a longer hold so viewers can read it, and the final frame needs a longer hold so the message lands before the loop restarts.

A uniform delay for every frame is the most common mistake in GIF timing. The important frames rush past unread, while the motion frames drag. Give the important frames more time and the motion frames less, and the GIF feels considered rather than mechanical.

Watch the Live Timing Preview as you adjust. A delay that looks right as a number can feel wrong in motion, and the preview shows the real feel. If the animation rushes past the key frame, lengthen that frame rather than slowing the whole GIF.

Step 6: Set the Loop Count

Choose how many times the GIF plays. An infinite loop plays forever, which suits reactions, decorations, and anything meant to catch the eye repeatedly. It is the classic GIF behavior and the default choice.

A finite loop plays a set number of times and then stops on the final frame. That suits a tutorial or a demo where the viewer should end on the finished state. A loop count of two or three gives a second look without looping forever.

A single play shows the animation once and stops. That suits a reveal, such as a before-and-after that should end on the after. The viewer sees the change, then the result stays on screen.

Match the loop to the destination. A chat reaction wants an infinite loop, a product demo wants a few loops, and a tutorial step wants to end on the result. The wrong loop makes a good GIF feel broken.

Step 7: Choose Frame Fit

Frame Fit decides what happens when your frames have different aspect ratios. Contain fits each frame inside the output size without cropping, so the whole frame stays visible and any empty space becomes a border.

Cover fills the output size completely by cropping the frame, so there are no empty bands but the edges of some frames may be cut off. It gives a clean, full-bleed animation at the cost of losing edge detail.

Choose Contain when every part of every frame matters, such as a tutorial where a cropped button would hide the step. Choose Cover when the animation must fill the frame cleanly, such as a social post where empty bands would look unfinished.

If your frames all share the same dimensions, the fit setting does not matter, because there is nothing to crop or pad. The setting only matters for mixed-size frame sets, so check it when your frames come from different sources.

Step 8: Set the Output Size

Set the output width for the place the GIF will be shared. A width of around 480 pixels suits chat and social feeds, where the GIF is viewed on a phone. A larger width suits a website or a presentation, where the GIF is displayed bigger.

The aspect ratio stays fixed when you edit the output width, so changing the width scales the whole GIF rather than stretching it. Set the width once and the height follows from the frames.

Smaller is usually better for GIFs. A GIF at 480 pixels wide is small enough to share quickly and large enough to see clearly. A GIF at 1000 pixels wide is several times the file size, for a difference most viewers will not notice.

Check the destination limits before you generate. Some chat apps and platforms downscale large GIFs or reject files over a size limit, so a huge GIF wastes bandwidth for no visible gain. Match the size to the place.

Step 9: Check the Live Preview

Open the Live Timing Preview and watch the animation play with your current settings. This is the honest test: the preview shows the finished timing, the loop, and the frame order exactly as the downloaded file will play them.

Watch for three problems: a frame that flashes past too fast, a jump where the order breaks, and a loop restart that feels abrupt. The first frame and the last frame decide how smooth the loop feels, so watch the restart point closely.

Fix problems in the preview rather than after downloading. Adjust a delay, reorder a frame, or change the loop count, then watch the preview again. Each fix takes seconds here and a full regeneration later.

Check the preview on your phone if the GIF is destined for a chat or a feed. A GIF that looks smooth on a desktop monitor can feel fast on a phone, and the phone is where the audience will see it.

Step 10: Generate and Download

When the preview looks right, generate the GIF. The tool encodes the frames into a standard GIF89a file in your browser, which takes a few seconds for a short GIF and longer for one with many frames or a high palette quality.

Watch for the Large GIF Warning. If the estimated file passes 5 MB or 15 MB, the tool will tell you. Reduce the output width first, since halving the width cuts the pixels to a quarter, then reduce the frame count or the frame rate.

Download the finished file, which saves as animated_compressmypic.gif. Rename it to something meaningful before you share it, such as product-demo.gif or birthday-reaction.gif, so it is easy to find later.

Open the downloaded GIF and play it once to confirm it works. Check the timing, the loop, and the size. If anything is wrong, change the setting in the tool and generate again rather than trying to fix the finished file.

Fixing a GIF That Is Too Large

A GIF that is too large usually has one of three causes: too many frames, too large dimensions, or too high a frame rate. Fix them in that order of impact, starting with the dimensions, which give the biggest saving.

Halve the output width and the file shrinks dramatically, because the pixel count falls to a quarter. A GIF at 480 pixels wide is a quarter of the size of the same GIF at 960 pixels, and the visible difference on a phone is small.

Next, cut the frame count. Remove frames that repeat the previous one or add little to the story. Each frame removed is a direct saving in file size, and a shorter GIF is usually a better GIF as well.

Finally, lower the frame rate. Dropping from ten frames per second to five halves the frames per second of animation. If the GIF still needs to be smaller after all three cuts, the GIF compressor can shrink the finished file further.

Sharing Your GIF

Share the GIF file directly in chat apps such as WhatsApp, Telegram, Slack, and Discord, which all play GIFs inline. Upload the file as an attachment or paste it into the message, and it animates for the recipient without any extra step.

On social platforms, upload the GIF as a media file. Most feeds accept GIF uploads and play them automatically, though some convert the GIF to a video behind the scenes. The animation still plays, so the result is the same for the viewer.

On a website, embed the GIF with a normal image tag. It plays automatically when the page loads, so place it where the motion adds value rather than distraction. A GIF in a tutorial draws the eye to the step it demonstrates.

Keep a copy of the frame images as well as the finished GIF. If you need a different size, a different loop, or a corrected frame later, the frames let you regenerate in minutes. A GIF alone cannot be edited back into its frames easily.

Quick Reference: GIF Checklist

Gather five to fifteen frames with matching dimensions, upload them, arrange them in story order, and duplicate the frames that need emphasis. Set a base delay near five frames per second, lengthen the title and final frames, and pick a loop for the context.

Set the output width for the destination, choose Contain or Cover for mixed-size frames, and check the Live Timing Preview before generating. Heed the Large GIF Warning and shrink the width first.

Frequently asked questions

How many images do I need to make a GIF?

You need at least two images, since a GIF is a series of frames played in sequence. Five to fifteen frames is the right range for most GIFs. Fewer frames make a short, punchy animation, while more frames make a longer and heavier one.

Can I add more frames after I start?

Yes. The Add Frames control lets you append more images at any point, even after you have set the timing. The new frames join the end of the list, and you can drag them into the right position.

How do I make one frame stay on screen longer?

Give that frame a longer delay, or duplicate it so it appears twice in a row. Both methods work; a longer delay is cleaner for a title slide, while duplicating is quicker for a short emphasis. Check the result in the Live Timing Preview.

What image formats can I use as GIF frames?

The tool accepts JPG, PNG, WebP, HEIC, GIF, BMP, and SVG files up to 20 MB each. Photos, screenshots, and graphics all work as frames. If you upload an existing GIF, the tool can extract a single frame from it.

Why is my GIF file so big?

GIFs store every frame as a full image, so many frames, large dimensions, and a high frame rate all add size. Reduce the output width first, since halving it cuts the pixels to a quarter, then cut the frame count or the frame rate.

Can I use the GIF I made on WhatsApp and Instagram?

Yes. WhatsApp, Telegram, Slack, Discord, and Instagram all play GIFs. Upload the file as a media attachment and it animates inline. Some platforms convert the GIF to video behind the scenes, but the animation still plays for the viewer.
