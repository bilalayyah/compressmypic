How to View Image Metadata

Step-by-step guide to viewing image metadata: open a photo in the viewer, read EXIF and GPS fields, export a JSON report, and verify a cleaned file.

Viewing image metadata sounds technical, but it takes less than a minute. You open a photo in a viewer, read the report, and decide whether anything in it should stay private.

This guide walks through each step with the free Image Metadata Viewer. It works in your browser, needs no account, and never uploads your photos.

By the end you will know how to find GPS coordinates, read camera settings, export a JSON report, and check that a cleaned file is truly clean.

What You Need Before You Start

You need the image file itself, saved on your device. The original file from your camera roll or camera card carries the most metadata.

A photo downloaded from WhatsApp, Instagram, or Facebook is a poor test subject. Those services strip EXIF and GPS headers on upload, so the viewer will find little or nothing.

Screenshots are also poor test subjects. Your operating system clipboard passes raw pixels, not the original camera file, so pasted screenshots show dimensions and format only.

Use a JPG, PNG, WebP, HEIC, GIF, BMP, or SVG file up to 20 MB. That covers full-resolution phone photos, DSLR JPEGs, and detailed PNG exports.

Open the viewer in any modern browser. Chrome, Firefox, Safari, and Edge all work, on desktop and on mobile.

Step 1: Open the Viewer

Go to the Image Metadata Viewer page. You will see an upload zone and a short explanation of what the tool does.

There is no sign-in screen and no paywall. The tool is free, and you can inspect as many photos as you like, one at a time.

If you are on a phone, open the page in mobile Safari or Chrome. The layout adapts, and you can pick a photo straight from your camera roll.

Bookmark the page if you check photos often. Photographers, sellers, and parents tend to use it before every public post, so quick access helps.

Step 2: Upload Your Image

Drag your image onto the upload zone, or click it to pick a file from your device. The file parses immediately, right in your browser.

You can also paste an image with Ctrl+V on Windows or Cmd+V on Mac. Pasting is handy for a photo already on your clipboard, but remember that clipboard images carry no camera headers.

Parsing happens locally using File ArrayBuffer byte parsing. Zero bytes leave your computer or phone, which is the whole point of a privacy tool.

If the file is larger than 20 MB, the upload will not work. Compress it first with the image compressor, then inspect the smaller copy.

Within a moment the summary bar appears. That is your first result, and it already answers the most important question: does this file carry sensitive data?

Step 3: Read the Summary and Privacy Banner

The summary bar shows the detected container format, the pixel dimensions, and the file size. It also states whether sensitive embedded metadata tag types were found.

Read the format first. The viewer inspects actual binary magic bytes rather than trusting the filename, so a PNG renamed with a .jpg extension is still reported as a PNG.

Next, read the privacy risk banner. If sensitive tags were found, the banner says so plainly. If nothing sensitive was found, the banner says that too.

A clean summary does not always mean the file is original. A stripped photo from a messaging app also shows a clean summary, because its metadata was already removed upstream.

Compare the summary with what you expect. A DSLR JPEG should show camera data. A screenshot should show almost nothing. A mismatch tells you the file was processed somewhere along the way.

Step 4: Check for a GPS Location Alert

GPS coordinates are the first thing to check, because they are the most sensitive field a photo can carry. Scroll to the warning area just above the properties table.

If GPSIFD tags exist, an amber banner reads GPS Location Coordinates Detected. It shows the exact decoded latitude and longitude in decimal form.

Those two numbers can point to a home, a school, a workplace, or the precise spot where the photo was taken. Treat them as private until you decide otherwise.

The warning box also offers a one-click jump to Remove Image Metadata. If you plan to share the photo, follow that link and strip the tags first.

If no GPS alert appears, the photo carries no location data. That is the result you want before posting anything taken at home or near your children.

Step 5: Read the Metadata Table

Below the banner sits the extracted metadata table. Entries are grouped so you can scan them without reading every line.

The Camera group holds make, model, lens, and software. The EXIF group holds shutter speed, aperture, ISO, focal length, flash, and metering mode.

The GPS group holds latitude, longitude, and altitude when present. The PNG or WebP chunks group holds IHDR, pHYs, text chunks, and VP8X flags.

The File info group holds the container format, dimensions, and size. These are facts about the file itself, not about the camera.

Sensitive entries carry an amber Privacy Tag label. Look for GPS coordinates, exact capture timestamps, photographer or artist names, camera serial numbers, and device model strings.

Take your time with the timestamp. The exact date and time a photo was taken can reveal routines, such as when a house is empty or when a child leaves school.

Step 6: Copy or Export the JSON Report

If you need a record of what the file contained, export it. Click Copy JSON in the summary bar to place the full structured report on your clipboard.

Click Export JSON to download a file named after your image with a _metadata suffix. The file is a clean JSON report you can keep, attach to a ticket, or compare later.

Developers use these reports to debug image pipelines. If a field disappears between two processing steps, the JSON reports show exactly where it went.

Photographers use them to keep exposure recipes. The JSON preserves ISO, aperture, and shutter speed from a shot worth repeating.

For a deeper explanation of what each field means, read EXIF Data Explained: What Your Photos Reveal. For the full tool overview, read Image Metadata Viewer: Complete Guide.

Step 7: Verify a Cleaned File

After stripping metadata from a photo, drop the cleaned output back into the viewer. This second inspection proves the cleaning worked.

If scrubbing succeeded, a green banner confirms that no EXIF, GPS, or hidden camera tags were detected. No GPS alert appears.

If tags remain, the table shows exactly which ones survived. Common survivors are PNG text chunks and JPEG comments, which some cleaners miss.

When leftovers appear, clean the file again with Full Canvas Re-encode in the Remove Image Metadata tool. It rebuilds the pixels from scratch and drops every inherited segment.

Make this a two-pass habit for sensitive photos. Inspect, strip, inspect again. The second pass takes seconds and removes all doubt.

Viewing Metadata on a Phone

Most photos live on phones, and the check matters most right before posting. Open the viewer in mobile Safari or Chrome and pick a photo from your camera roll.

The summary, GPS alert, and grouped table all appear the same way as on desktop. Copy JSON and Strip Metadata work the same way too.

Check the photo before you open the social app, not after. Once a photo is posted, anyone can download it and read whatever it still carries.

If you find GPS data, strip it on the phone before sharing. The Remove Image Metadata tool runs in the mobile browser, so the whole workflow fits in your pocket.

How to Read Camera Settings in the Report

Camera settings tell the story of how a photo was made. Each field has a plain meaning once you know what to look for.

ISO is the sensor sensitivity. Low ISO means a bright scene or a tripod; high ISO means a dark scene and usually more grain.

Aperture, shown as an F-number, is how wide the lens opened. A small F-number means a wide opening and a blurred background; a large one means a deep, sharp scene.

Shutter speed is how long the sensor was exposed. Fast speeds freeze motion, slow speeds blur it. The viewer shows it as a fraction of a second or as whole seconds.

Focal length is the lens zoom at the moment of capture. Short lengths mean a wide view; long lengths mean a zoomed-in view.

Flash state tells you whether the flash fired. Metering mode tells you how the camera measured the light. Together these fields let another photographer recreate the shot.

Troubleshooting: When the Report Looks Empty

An empty report usually has a simple cause. Work through the list below before assuming the viewer is broken.

  • The photo came from WhatsApp, Instagram, or Facebook. These services strip EXIF and GPS on upload, so the file arrives clean.
  • You pasted a screenshot. Clipboards pass raw pixels, so pasted images carry no camera headers at all.
  • The file is a HEIC, GIF, BMP, or SVG. The viewer reports container info and dimensions for these, but full binary EXIF chunks are only extracted for JPEG, PNG, and WebP.
  • The photo was edited and re-exported. Many editors drop EXIF on export unless you ask them to keep it.
  • The file was already cleaned. A photo stripped by the Remove Image Metadata tool will show the green no-tags banner, which is the correct result.

If you expected camera data and got none, test with a fresh original straight from the camera roll. That tells you whether the file or the viewer is the cause.

If the original also shows nothing, check your camera app settings. Some phones let you turn off location recording, which removes GPS tags at the source.

Common Mistakes to Avoid

The most common mistake is checking the wrong file. People inspect a copy they already posted, see nothing, and assume the original is clean too. Always inspect the file you are about to share.

Another mistake is trusting the filename. A .jpg file can really be a PNG, and the viewer reports the true format from magic bytes. Read the summary, not the extension.

A third mistake is skipping the second inspection. Stripping feels complete when the download appears, but only a re-inspection proves the tags are gone.

A fourth mistake is forgetting the timestamp. People look for GPS and ignore the capture time, yet an exact timestamp can reveal routines just as clearly as a location.

Finally, do not assume a clean report means a safe photo. The image itself can still show a street number, a school uniform, or a car plate. Metadata is only half the privacy check.

Comparing Two Photos Side by Side

Sometimes one report is not enough. Comparing two photos shows what changed between them, which is useful when a file passes through several apps.

Open the first photo, export its JSON report, and save the file. Then clear the viewer with the red trash icon and open the second photo the same way.

Put the two JSON reports side by side. Any field present in one and missing in the other was added or removed by whatever processed the file in between.

This comparison is how developers find which step in a pipeline drops a field. It is also how photographers learn which editor keeps their camera data and which one discards it.

A common test is the original against the social media copy. The original shows full EXIF and GPS, while the downloaded social copy shows almost nothing. The gap proves the platform stripped the data.

Another useful test is the original against the cleaned copy. The cleaned copy should show the green no-tags banner, while the original shows the full table. That contrast is your proof that stripping worked.

Saving Reports for Later

Exported JSON reports are worth keeping when the photo matters. A report is a small text file, easy to store alongside the image or in a project folder.

Keep reports for client work, where a client may ask when and where a photo was taken. The JSON answers that question without sharing the original file.

Keep them for debugging too. When an image behaves oddly months later, the saved report shows what the file contained before any further processing.

Name the report clearly, such as wedding-photo-metadata.json, so you can find it later. The default name already includes the image file name with a _metadata suffix, which is a good start.

Quick Recap

Open the Image Metadata Viewer, drop in the original file, and read the summary banner first. Then check the GPS alert, scan the grouped table, and note any amber Privacy Tag labels.

Export JSON if you need a record. Strip the file with Remove Image Metadata if anything sensitive appears, then inspect the cleaned copy again to confirm.

The whole routine takes under a minute. Make it a habit before every public post, and your photos will show only what you chose to share.

Frequently asked questions

How do I view metadata on a photo I already posted online?

Download the posted photo first, then drop the downloaded file into the viewer. Most social platforms strip metadata on upload, so the downloaded copy usually shows nothing — but if the platform kept the tags, the viewer will find them. Note that downloading from the platform may itself strip data, so this checks the public copy, not your original.

Can I view metadata without installing any software?

Yes. The Image Metadata Viewer runs entirely in your browser — no install, no account, and no upload. Drop the file in, read the report, and close the tab. Your photos never leave your device.

What should I do if the viewer finds GPS coordinates in my photo?

Do not share that file as it is. Open the Remove Image Metadata tool, drop the photo in, and download the cleaned copy. Then drop the cleaned copy back into the viewer to confirm the GPS alert is gone before you post it.

Why does the viewer show different fields for the same photo in different formats?

Each format stores metadata differently. A JPEG holds EXIF directories, a PNG holds text and eXIf chunks, and a WebP holds EXIF chunks plus VP8X flags. Converting a photo between formats can drop fields, so the same picture as a JPG and as a PNG will show different tables.

Can I view metadata for many photos at once?

The viewer inspects one file at a time. To check a batch, inspect each file in turn — click the red trash icon in the summary bar to reset, then drop the next photo. Each inspection takes seconds, so a small batch goes quickly.

Does viewing metadata change my photo in any way?

No. The viewer is strictly read-only. It reads headers from browser memory and displays them, without modifying, compressing, or deleting anything in your original file. Your file on disk stays exactly as it was.
