An image can look perfect on your screen and still fail the moment you upload it. A marketplace rejects it for being too small, a printer crops it unexpectedly, or a website stretches it into a blur.

The cause is almost always the dimensions: the width and height in pixels. Most people never check them until something breaks, and by then the deadline is already tight.

This guide explains how the CompressMyPic image dimensions checker works, what every number in its report means, and how to use it to catch size problems before they reach your customers.

What Is an Image Dimensions Checker?

An image dimensions checker reads the pixel width and height of your images and shows them in a clear table. It works on single files and on whole batches dropped in at once.

The tool accepts JPG, PNG, WebP, GIF, BMP, HEIC, and SVG files, up to 20 MB each. It reads the real dimensions stored inside each file, not the size your operating system guesses from the file name.

Beyond width and height, the report includes aspect ratio, megapixels, file size, and whether the image has transparency. It also calculates the print size at 300 DPI for every image.

Everything runs locally in your browser. Your images are never uploaded to a server, so unreleased product shots and confidential ad creatives stay private while you check them.

Pixels, Width, and Height Explained

An image is a grid of pixels, and its dimensions are simply the count of columns and rows in that grid. An image described as 1920 by 1080 has 1,920 pixels across and 1,080 pixels down.

Width always comes first in the pair. A 1200 by 800 image is landscape, while an 800 by 1200 image is portrait, even though both contain the same number of pixels.

Pixels are the only size that matters on screen. A screen displays one image pixel per screen pixel at full zoom, so a 400-pixel-wide image can never fill a 1200-pixel-wide space without stretching.

That stretching is what people mean by a blurry image. The browser invents the missing pixels, and the invention always looks softer than the real thing.

Aspect Ratio Explained

Aspect ratio is the relationship between width and height, written as two numbers with a colon between them, such as 16:9 or 4:3. It describes the shape of the image, not its size.

A 1920 by 1080 image and a 1280 by 720 image share the 16:9 ratio, because both divide down to the same proportions. They are different sizes but the same shape.

The checker matches each image against common ratios such as 16:9, 4:3, 1:1, 3:2, and 4:5. It also shows the exact ratio when an image falls between the standard shapes.

Ratio matters because platforms crop to it. An Instagram portrait slot expects 4:5, so a 16:9 photo uploaded there loses its sides. Checking the ratio first tells you what will survive the crop.

Megapixels Explained

Megapixels count the total number of pixels in an image, expressed in millions. You get the number by multiplying width by height and dividing by one million.

A 4000 by 3000 photo is 12 megapixels, because 4,000 times 3,000 equals 12,000,000 pixels. A 1920 by 1080 image is about 2.1 megapixels.

Camera makers use megapixels as a headline number, but it hides the shape. A 12-megapixel panorama and a 12-megapixel square have the same pixel count and very different dimensions.

For print, megapixels are a rough guide to how large you can print. A 12-megapixel file prints well at A4 size, while a 2-megapixel file starts to soften beyond a postcard.

Batch Checking: Many Images at Once

Checking images one at a time is slow when you have a product catalog or a photo shoot to verify. The dimensions checker accepts whole batches in a single drop.

Drag a folder or a group of files into the tool and it builds one table with every image. Each row shows the file name, dimensions, ratio, megapixels, file size, and transparency status.

You can append more batches to the same table later. If a second folder arrives after the first, drop it in and the new rows join the existing report instead of replacing it.

If one file in a large batch cannot be read, the tool reports that file as an error and keeps going. The rest of the batch still gets checked, so one bad file never blocks the whole job.

The Min Width and Min Height Validator

Many platforms publish minimum pixel sizes. Amazon, Etsy, and Shopify all reject product images below a certain width, and the exact number differs by platform.

The checker includes a Min Width Check and a Min Height Check. You enter the numbers your platform demands, and the tool flags every image that falls short.

A flagged image is not necessarily unusable, but it needs attention. You can resize it larger, though that will soften it, or you can go back to the original and export it at a bigger size.

The validator is also useful inside a team. Agree on a minimum once, enter it in the tool, and every batch gets judged against the same standard instead of by eye.

Print Size at 300 DPI

The report includes a Print at 300 DPI column, which converts pixel dimensions into physical inches at print quality. It answers the question of how large an image can be printed without losing sharpness.

The math is simple: divide the pixel width by 300 to get the printable width in inches. A 3000-pixel-wide image prints at 10 inches wide at 300 DPI.

At 150 DPI the same image prints twice as large, but with visibly softer detail. The 300 DPI figure is the safe number for brochures, books, and product packaging.

This column prevents a common mistake: sending a web-sized image to print. A 1200-pixel image that looks fine on screen only prints at 4 inches wide at 300 DPI, far too small for a poster.

Transparency Detection: Alpha Channels

Some images carry a transparency channel, called alpha, that lets parts of the image show whatever sits behind it. Logos and icons usually need it, while photos almost never do.

The checker detects whether a PNG or WebP actually has an alpha channel. That matters because a file can be saved as PNG and still be fully opaque, with no transparency at all.

Knowing this saves embarrassment. A logo that looks transparent in your editor but is actually opaque will show a white box when placed on a colored background.

If you need to change transparency, convert the file properly. Saving a JPG as PNG does not add transparency, and the checker will tell you so before you discover it on the live site.

Exporting the Report: CSV and JSON

Checking is only half the job; the other half is sharing the results. The tool exports the full table as CSV or JSON with one click.

The CSV export includes columns for file name, dimensions, aspect ratio, megapixels, file size, transparency, and print size. It opens directly in a spreadsheet for sorting and filtering.

The JSON export carries the same data in a structured format for developers. It is the right choice when the report feeds into a script, a content pipeline, or a quality dashboard.

Export before you close the tab. The table lives only in your browser, and a refresh wipes it. A saved CSV is the record your team can refer back to.

SVG Files and Intrinsic Dimensions

SVG graphics are vectors, not pixels, so their size works differently. An SVG has intrinsic dimensions defined by its width, height, and viewBox attributes, and the checker reads those.

This is useful because an SVG can be scaled to any size without losing sharpness. Its intrinsic dimensions tell you the size the designer intended, not a limit on how large it can go.

Be careful with SVGs that have a viewBox but no width or height. They have a ratio but no fixed size, and the checker will show the ratio while noting that no absolute dimensions exist.

For logos and icons, the SVG reading confirms the intended proportions. If the viewBox ratio does not match the ratio your layout expects, the icon will distort or leave gaps.

Common Platform Requirements

Every platform has its own dimension rules, and they change often. The table below is a starting point, but always confirm the current numbers on the platform itself before a big upload.

Marketplaces such as Amazon and Etsy want large square or near-square product images, often at least 1000 pixels on the longest side. Smaller images fail their minimum checks and look poor when shoppers zoom in.

Social platforms each want their own shape. A square works for a feed post, a 4:5 portrait fills a phone screen better, and a 16:9 landscape suits a video thumbnail or a cover image.

Print services want the most pixels you can give them. A 300 DPI target means a full-page print needs roughly 2500 by 3300 pixels, far more than any web image.

Fixing Images That Fail the Check

A failed image usually has one of three problems: it is too small, its ratio is wrong, or its format does not fit the job. Each has a different fix.

Too small is the hardest to fix. Upscaling adds pixels that were never there, so the result is softer than a true high-resolution original. Go back to the source file whenever you can.

A wrong ratio is fixed by cropping. Use the image cropper to cut the image to the ratio your platform wants, keeping the subject centered and important details inside the frame.

A wrong format is fixed by converting. A photo saved as PNG can become a JPG for the web, and a logo saved as JPG should become a PNG so its edges stay sharp and its background stays transparent.

Dimensions Checker vs Image Resizer

The checker and the resizer are companion tools, not competitors. The checker tells you what size an image is, and the resizer changes it when the answer is wrong.

Use the checker first, as a diagnostic step. It tells you which images in a batch fail, and by how much, so you only resize the ones that need it.

Use the image resizer next, on the flagged files only. Resizing the whole batch wastes time and can damage images that were already correct.

Then run the checker again on the resized files. The second pass confirms the fix worked and gives you a final report to file with the project.

Privacy: Batch Processing in Your Browser

A batch of product photos can include unreleased items, and an ad creative can include pricing that is not yet public. Uploading such files to a server is a risk.

The checker reads every file locally. The browser opens each image, measures it, and builds the table without sending a single byte anywhere.

That also means there is no daily limit and no fee. You can check a thousand images in a session, and the only cost is the time your own computer takes to read them.

For teams handling confidential material, local processing is the feature that makes the tool usable at all. No upload means no copy of the files exists outside your own machine.

How to Use the Image Dimensions Checker

Open the image dimensions checker and drop your images into the upload area. You can also paste a clipboard image directly to verify its pixel resolution in seconds.

The table fills in as each file is read. Check the dimensions, ratio, and megapixel columns first, then look at the print size and transparency columns for the details that matter to your job.

Set the Min Width and Min Height values if your platform demands them. Flagged rows show up clearly, so you can see exactly which files need work.

Export the report as CSV or JSON when you are done, and read the practical steps in How to Check Image Dimensions or the comparison in Dimensions vs Resolution vs File Size Explained. If a file needs changing, the image DPI changer can fix its print metadata next.

Frequently asked questions

What is the difference between image dimensions and image resolution?

Dimensions are the pixel width and height, such as 1920 by 1080. Resolution is the density, usually DPI or PPI, which says how many of those pixels fit into an inch. An image can have large dimensions and low resolution, or small dimensions and high resolution. The full comparison is in our article on dimensions vs resolution vs file size.

How many images can I check in one batch?

There is no fixed limit in the tool. You can drop in a whole folder of images and the table builds row by row. Very large batches take longer because the browser reads each file, but there is no daily cap and no fee for large checks.

Why does my image show different dimensions in different apps?

Some apps show the pixel dimensions while others show the dimensions after applying a DPI value or a display scaling factor. The checker reads the true pixel dimensions stored in the file, which is the number that matters for uploads and print.

Can the checker tell me if an image will print well?

Yes, through the Print at 300 DPI column. It converts the pixel dimensions into physical inches at print quality. If the printed size is smaller than what you need, the image will look soft when printed larger.

Do I need to install anything to check dimensions in bulk?

No. The checker runs in your browser on desktop and mobile, with no install and no account. Drop your files in, read the table, and export the report as CSV or JSON.

What happens to my images after I check them?

Nothing. The files are read locally in your browser and never uploaded anywhere. Closing the tab removes the table from memory, so export the CSV or JSON report first if you need to keep the results.
