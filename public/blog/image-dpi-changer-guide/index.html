Your photo has the right pixels, the right size, and the right look, but the printer or the publishing platform rejects it. The reason is often a single number buried in the file: the DPI value.

DPI tells software how densely to pack the pixels when the image is printed. A file tagged at 72 DPI looks like a poster to a print system, while the same pixels tagged at 300 DPI look like a proper page.

This guide explains how the CompressMyPic image DPI changer works, what each preset means, and how to fix DPI problems without touching a single pixel of your image.

What Is DPI?

DPI stands for dots per inch, and it describes how many printed dots fit into one inch of paper. In image files it is usually called the resolution tag, and it sits in the file header as a small piece of metadata.

A 3000-pixel-wide image tagged at 300 DPI prints 10 inches wide, because 3000 divided by 300 equals 10. The same pixels tagged at 150 DPI print 20 inches wide, with each dot spread further apart.

DPI does not describe the image itself. It describes the intended physical size of the image when it leaves the screen and meets paper, ink, or a printing press.

Most cameras and screenshots save a DPI tag, but many save none at all. A file with no DPI tag is not broken; it simply leaves the print size up to whatever software opens it next.

DPI Is Metadata, Not Pixels

The most important fact about DPI is that changing it does not change the image. The pixel grid stays exactly the same, and the visible picture does not gain or lose any detail.

The DPI changer rewrites a few bytes in the file header and leaves the pixel data untouched. That is why the change is lossless: there is nothing to lose, because nothing is re-encoded.

This also means changing DPI cannot make a blurry image sharp. A 400 by 400 thumbnail set to 300 DPI is still a 400 by 400 thumbnail, and it will still look soft when printed large.

What the change does is tell the next program the correct print size. A print shop, a book platform, or a journal submission system reads the tag and lays the image out at the size you intended.

DPI Presets Explained: 72 to 600

The tool offers five presets, each matched to a real use case. Choosing the right one is mostly a matter of knowing where the image is going.

72 DPI is the screen preset. It comes from the early days of monitors, and it marks a file as intended for display rather than print. Many web images carry this tag by default.

96 DPI is the Windows preset, the standard density of Windows displays. It is the tag most screenshots carry, and it means the same thing as 72 DPI in practice: this image is for screens.

150 DPI is the draft print preset. It suits internal proofs, large posters viewed from a distance, and any print where speed matters more than fine detail.

300 DPI is the high print preset and the one you will use most. It is the standard for books, brochures, magazines, and packaging, and it is the value most platforms demand. 600 DPI is the archival preset, used for fine-art reproduction and documents that must survive close inspection under magnification.

Custom DPI: Any Value from 1 to 2400

Sometimes no preset fits. A specific printer, a journal, or a book platform may demand an unusual value, and the tool accepts any custom DPI from 1 to 2400.

Type the number you need and the tool applies it exactly. The range is wide on purpose, because real publishing workflows occasionally ask for values such as 200, 350, or 1200 DPI.

Values below 72 are rarely useful for print, but they are valid metadata. The tool does not judge your number; it writes it faithfully and verifies the result.

If you change your mind after processing, you can re-apply a different DPI to the same files. The tool lets you run the processed images again at 600 DPI after a 300 DPI pass, with no quality loss at either step.

Which Formats Work: JPEG and PNG

The DPI changer works with JPEG and PNG files, because those formats store a DPI tag in a standard place. Both are handled losslessly, with no re-encoding of the pixel data.

Other formats are rejected with a clear message. WebP, HEIC, BMP, GIF, and SVG files do not carry a DPI tag in the same way, so stamping one onto them would be misleading.

If your file is a WebP, convert it to JPG or PNG first, then set the DPI. The image converter handles that step, and the DPI changer takes it from there.

This limit is a feature, not a gap. A tool that pretends to set DPI on a format that cannot store it would silently produce files that still fail the platform check.

Why Photos Show Before: Not Set

Many uploaded photos show Before: Not set in the tool, which surprises people. The photo is fine; it simply has no DPI tag stored in its header.

Phone cameras often skip the DPI tag entirely, because the phone does not know whether the photo will be printed or shared on screen. Screenshots behave the same way.

A missing tag is not an error, but it is a problem for platforms that demand one. Amazon KDP, academic journals, and print shops all check the DPI value, and a missing value counts as a failure.

Setting the DPI on such a file fills in the missing metadata. The pixels do not change, but the file now answers the platform question instead of leaving it blank.

The Verified DPI Badge

After processing, each file gets a Verified DPI badge. The badge is not decoration; it means the tool read the file back and confirmed the new DPI value is actually stored in it.

Verification matters because DPI tags can be tricky. Some formats store the value in dots per centimeter instead of dots per inch, and a careless tool can write one while the reader expects the other.

The changer handles that conversion correctly and then proves it by reading the result. If the badge appears, the file will report the same DPI in any standards-compliant reader.

Check for the badge before you submit a file. A processed file without verification is a guess, and publishing platforms do not accept guesses.

EXIF Tags and ICC Profiles Are Preserved

Changing DPI rewrites only the resolution bytes in the header. Your camera EXIF data, including the date, camera model, and exposure settings, stays exactly as it was.

The ICC color profile is preserved too. That profile tells printers and screens how to interpret the colors, and losing it would shift every color in the image.

This is why the tool is safe for professional work. A photographer can set the DPI on a client file without worrying that the metadata the client needs has been stripped away.

If you do want metadata removed, that is a separate job. The remove image metadata tool strips EXIF and location data, while the DPI changer deliberately keeps everything intact.

Why PNG Sometimes Reads Back as 299 DPI

Some users set 300 DPI on a PNG and read it back as 299 DPI in another program. This looks like an error, but it is a rounding artifact of how PNG stores resolution.

PNG files store resolution in pixels per meter, not per inch. Converting 300 DPI to pixels per meter gives a number that does not divide evenly, so the stored value rounds slightly.

When a reader converts it back to DPI, the result can be 299 instead of 300. The difference is one dot per inch out of three hundred, which has no visible effect on any print.

Most platforms accept 299 DPI as equivalent to 300, but if yours is strict, use JPEG for that file. JPEG stores DPI directly in dots per inch, so it reads back as exactly 300.

Batch Processing and ZIP Export

Print projects rarely involve one image. A book chapter, a product catalog, or a journal article can need dozens of images stamped at 300 DPI, and doing them one by one is tedious.

The DPI changer processes files in batches. Drop in the whole set, choose the preset once, and every file gets the same DPI value in a single pass.

When the batch finishes, download all the results as one ZIP file. The ZIP keeps the individual file names, so the images slot straight back into the project folder they came from.

You can also download files one at a time if you only need a few. The batch workflow is for volume; the single download is for the quick fix on one image.

Does Changing DPI Change File Size?

No, or almost no. The DPI tag is a few bytes in the header, so changing it adds or removes nothing measurable from the file size.

A JPEG that weighs 2.4 MB before the change weighs 2.4 MB after it. The pixels are untouched, the compression is untouched, and only the metadata differs.

This surprises people who expect a 300 DPI file to be bigger than a 72 DPI file. File size comes from pixels and compression, not from the DPI tag, and the tag is nearly free.

If a file does need to be smaller, compress it separately. The image compressor reduces the weight without changing the dimensions, and then the DPI changer can set the print tag on the smaller file.

Why Platforms Reject 72 DPI Files

Publishing platforms reject 72 DPI files because the tag tells them the image is meant for screens. A book printer that sees 72 DPI assumes the image will print far too large and too soft.

Amazon KDP, academic journals, and stock photo sites all enforce minimum DPI rules for this reason. They are not being picky; they are protecting the printed result.

The fix is quick once you understand it. Stamp the file at 300 DPI, verify the badge, and resubmit. The pixels were always good enough; only the metadata was wrong.

Remember the limit, though. If the pixels are genuinely too few for the print size, no DPI value will save the file. Check the dimensions first with the image dimensions checker.

Re-applying a Different DPI Later

Workflows change, and a file stamped at 300 DPI may later need 600 DPI for an archival print. The tool lets you re-process files as often as you like.

Each pass is lossless, so re-stamping costs nothing in quality. The header is rewritten, the pixels stay untouched, and the new value is verified with a fresh badge.

This is useful for teams that serve both print and archive from the same source files. One set of pixels can carry 300 DPI for the book and 600 DPI for the archive, with no duplication.

Keep the original files safe regardless. A DPI change is reversible, but having the untouched original means you never have to wonder what was changed and when.

How to Use the Image DPI Changer

Open the image DPI changer and drop your JPEG or PNG files into the upload area. You can also paste a clipboard screenshot directly to stamp it at 300 DPI in seconds.

Pick a preset or type a custom value between 1 and 2400. The tool shows the current DPI for each file, or Not set when the file has no tag at all.

Process the files and look for the Verified DPI badge on each result. Download them individually or as one ZIP, then confirm the value in your publishing platform.

Frequently asked questions

Will changing DPI make my image look sharper on screen?

No. DPI is print metadata and browsers ignore it, so the image looks exactly the same on screen before and after the change. Sharpness on screen comes from pixel dimensions, not from the DPI tag. If the image looks soft on screen, it needs more pixels, not a higher DPI.

Can I set DPI on a WebP or HEIC file with this tool?

No. The tool works with JPEG and PNG only, because those formats store a DPI tag in a standard way. Convert a WebP or HEIC file to JPG or PNG first with the image converter, then set the DPI on the converted file.

What DPI should I use for a book cover or magazine page?

300 DPI is the standard for books, magazines, brochures, and packaging. Use the 300 DPI preset and confirm the pixel dimensions are large enough for the physical size. For fine-art or archival reproduction, step up to the 600 DPI preset.

Does the DPI changer work on my phone?

Yes. The tool runs in mobile browsers on iOS and Android. Upload JPEG or PNG files from your gallery, pick a preset, and download the stamped files. Batch ZIP downloads work on mobile too.

Why does my PNG read 299 DPI after I set 300 DPI?

PNG stores resolution in pixels per meter, and converting 300 DPI to that unit rounds slightly. When another program converts it back, it can read 299 DPI. The difference is invisible in print, and most platforms accept it. For an exact 300 reading, use JPEG instead.

Can I change DPI without an account or payment?

Yes. The tool is free, needs no account, and processes everything locally in your browser. There is no limit on how many files you stamp, and your images are never uploaded to a server.
