SVG to PNG: Complete Guide

Convert SVG logos and icons to PNG at any size. Scale, transparency, fonts, gradients, and the limits — everything explained.

An SVG logo can scale to any size without ever going blurry, yet half the places you need it do not accept SVG. A form, an email, or an old program wants a PNG, and the SVG must become pixels.

Converting SVG to PNG, called rasterizing, turns the vector shapes into a fixed grid of pixels at the size you choose. The result is an ordinary image that opens everywhere.

This guide explains how rasterizing works, which scale to pick, and the traps that catch people with fonts, linked images, and transparency.

What Is an SVG File?

SVG stands for Scalable Vector Graphics. Unlike a photo, which stores pixels, an SVG stores instructions: draw a circle here, a line there, fill this shape with blue.

Because the file describes shapes rather than pixels, it can scale to any size without losing sharpness. A 24-pixel icon and a billboard from the same SVG both look perfect.

SVG files are text, which means you can open one in a text editor and read the code. That also makes them tiny for simple graphics, often just a few kilobytes.

The format is ideal for logos, icons, and illustrations. It is less suited to photographs, which are better stored as pixels.

What Does Rasterizing Mean?

Rasterizing turns vector shapes into a pixel grid. The converter reads the SVG instructions, draws the shapes onto a canvas, and saves the result as a PNG.

The key choice is the output size. A 24-pixel icon rasterized at 1x becomes a 24-pixel PNG, while the same icon at 4x becomes a 96-pixel PNG, sharp enough for high-resolution screens.

Once rasterized, the image is fixed. A 96-pixel PNG cannot scale up to 500 pixels without going blurry, unlike the SVG it came from.

Always keep the SVG original. It is the master copy, and you can rasterize it again at any size whenever you need a different PNG.

Choosing the Right Scale

For a website icon, 2x or 3x the display size is usually enough. A 24-pixel icon displayed on a retina screen wants a 48-pixel or 72-pixel PNG to look sharp.

For a logo on a presentation slide, 4x gives a comfortable margin. A small logo scaled up in PowerPoint stays sharp when the PNG has enough pixels behind it.

For print, go larger still. A logo printed at 2 inches wide needs at least 600 pixels at 300 DPI, so pick a scale that reaches that size.

The export scale is capped at 8000 pixels on the longest side. For most icons and logos the cap never matters, since a 100-pixel logo at 4x is only 400 pixels.

Transparency Is Preserved

SVG files often have transparent backgrounds, and the PNG keeps that transparency. A logo rasterized to PNG sits cleanly on any background colour.

Check the result with the Compare viewer before downloading. Zoom into the logo edges and confirm the transparency looks clean, with no white fringe.

If the SVG has a background rectangle, that rectangle becomes part of the PNG. Remove the background shape in your design tool if you want a transparent result.

For a logo that must work on many backgrounds, transparency is essential. Keep the SVG master, and rasterize a transparent PNG whenever you need one.

Fonts and Text Inside SVG

Text inside an SVG depends on fonts, and the converter may not have the font your SVG uses. When the font is missing, the text falls back to a default font, which changes the look.

Web fonts referenced inside an SVG are not loaded during conversion. The browser cannot fetch them in the rasterizing context, so the text renders in a fallback font.

The fix is to convert text to outlines in your design tool before converting. Outlined text becomes shapes, not letters, so it renders exactly regardless of fonts.

For a logo, outlined text is the professional standard anyway. It guarantees the lettering looks identical everywhere, on every machine.

Linked Photos and External Files

An SVG can reference an external image file, such as a photo linked by URL. That linked image will be missing from the PNG, since the converter cannot fetch it.

The same applies to external CSS files. Styles defined in a separate file are not loaded during conversion, so the shapes may render without their colours.

The fix is to embed everything inside the SVG before converting. Images should be data URIs, and styles should be inline, so the file is fully self-contained.

Most design tools have an option to embed images when exporting SVG. Use it, and the converted PNG will match the original exactly.

Gradients, Opacity, and Effects

Gradients inside an SVG render correctly during conversion. A smooth blend from one colour to another becomes a smooth blend in the PNG.

Opacity works too. A shape set to 50 percent opacity appears semi-transparent in the PNG, blending with whatever sits behind it.

Complex filters, such as blurs and drop shadows defined in SVG, usually render as well. The browser's SVG engine handles most standard filters correctly.

Very exotic effects may not survive. If a filter looks wrong in the PNG, simplify it in the design tool, or accept the small difference.

Batch Converting an Icon Pack

You can convert a whole icon pack of SVGs at once. Each file converts independently, and the ZIP holds them all ready to use.

Use the same scale for the whole pack. Consistency matters when icons appear together, since mixed sizes look uneven.

Files up to 25MB each are accepted, which covers even huge illustrated files with thousands of paths. Very complex SVGs simply take a second or two longer to rasterize.

Check two or three icons after converting, rather than all fifty. If those look good, the rest will too, since the settings are the same.

When to Use PNG Instead of SVG

Use PNG when the destination does not accept SVG. Forms, emails, old programs, and many social platforms want raster images, not vector files.

Use PNG when the image must look identical everywhere. An SVG can render differently in different browsers, while a PNG looks the same in every app.

Use PNG for social media profile pictures and avatars. Most platforms convert uploads to raster formats anyway, so providing a PNG gives you control over the result.

Keep the SVG for the web and for future edits. The vector master is the file you return to whenever you need a different size or a different format.

Does Converting Change the Colours?

Converting SVG to PNG does not change the colours. The shapes are drawn with the same colour values, and the PNG stores them exactly.

Colour profiles are the one subtlety. An SVG with an embedded profile may render slightly differently in the PNG, though the difference is usually invisible.

For brand colours, check the PNG against the original. Open both side by side and confirm the colours match, especially for saturated brand hues.

If a colour looks wrong, the problem is usually a missing font or a linked image, not the colour itself. Check those first before blaming the conversion.

File Sizes After Conversion

A small SVG icon of 5KB can become a PNG of 20KB or more, depending on the scale. Pixels cost more bytes than vector instructions, especially at large sizes.

The PNG size grows with the square of the scale. Doubling the scale quadruples the pixel count, so a 4x PNG is sixteen times larger than a 1x PNG.

Choose the smallest scale that meets the need. A 2x PNG for a website icon is plenty, and a 4x PNG for the same icon wastes bytes for no visible benefit.

For a large print PNG, the size is unavoidable. A 300 DPI print file needs many pixels, and the PNG will be large, which is correct for print.

Common Problems and Fixes

If an SVG fails to rasterize with an error, the file may contain unsupported features or malformed code. Open it in a browser first to confirm it renders there.

If the text looks wrong, the font is missing. Convert the text to outlines in your design tool and convert again.

If a linked photo is missing, embed it as a data URI inside the SVG. The converter cannot fetch external files, so the image must travel inside the SVG itself.

If the PNG looks blurry, the scale was too low. Rasterize again at a higher scale, since a low-resolution PNG cannot be sharpened afterwards.

SVG Logos for Social Media

Social media platforms do not accept SVG uploads, so a logo must become a PNG before it can be a profile picture or a cover image. Rasterizing at the right size gives a sharp result.

For a profile picture, rasterize at 400 by 400 pixels. The image looks sharp on desktop and mobile, and the file stays small enough to upload quickly.

For a cover image, rasterize at the platform's recommended size. Facebook, X, and LinkedIn each have different cover dimensions, and the right size matters more than the format.

Check the logo after converting, since social platforms crop profile pictures into circles. A logo with important details near the edges may lose them to the circular crop.

Keep the SVG original for the next platform. A new social network with different sizes needs only a fresh rasterization, not a redesign.

SVG Icons for Apps

App icons start as SVG files in the design tool, and they become PNGs for the app stores. Each store has its own size requirements, so one SVG produces many PNGs.

Rasterize the icon at 1024 by 1024 pixels for the App Store, then scale down for smaller sizes. A large master produces sharp results at every smaller size.

For Android, rasterize at the sizes the Play Store lists, usually 512 by 512 for the store icon and smaller sizes for the launcher. The same SVG serves them all.

Test the icons on light and dark backgrounds before submitting them. An icon that relies on a white background will vanish on a dark theme, and the fix is a transparent version.

Keep the SVG masters in the project repository. They are the source assets, and every platform build comes from them, so they deserve version control.

SVG for Print Materials

Print materials such as business cards, flyers, and posters need high-resolution images, and SVG is the ideal source. Rasterize at 300 DPI for a crisp print.

For a business card logo, rasterize at 4x the SVG size. A small logo scaled up in print stays sharp when the PNG has enough pixels behind it.

For a poster, rasterize at the largest scale the tool allows, up to the 8000-pixel cap. A large print needs many pixels, and the cap rarely limits real poster work.

Check the colours after converting, since print colours differ from screen colours. A quick test print confirms the brand colours look right on paper.

Send the PNG to the print shop with the SVG as a backup. The shop can rasterize the SVG itself if the PNG has a problem, so providing both covers every case.

SVG for Email Signatures

Email signatures need a small logo, and SVG is not supported in most email clients. Rasterize the logo to PNG at a small size, usually 100 to 200 pixels wide.

Keep the PNG file small, under 50KB if possible. A large logo in every email wastes bandwidth and annoys recipients, while a small one loads instantly.

Host the logo on your website and link it in the signature, rather than attaching it. A linked image loads from your server, keeping the email itself small.

Test the signature in several email clients before rolling it out. A quick test in Gmail, Outlook, and Apple Mail catches the broken images before your contacts do.

For a logo with transparency, the PNG keeps it. The signature logo sits cleanly on any email background, while a JPG version would show a white box.

SVG for Favicons

A favicon is the tiny icon in the browser tab, and it usually starts as an SVG logo. Rasterize it at 16, 32, and 48 pixels for the standard favicon sizes.

Modern browsers also accept SVG favicons directly, so you may not need to convert at all. Check the browser support for your audience before deciding.

For older browsers, the PNG favicon is the safe choice. A 32-pixel PNG works in every browser, while an SVG favicon may fail on an old one.

Design the favicon simply, since tiny sizes hide detail. A complex logo at 16 pixels becomes a blur, while a simple shape stays recognisable.

Test the favicon in several browsers after adding it. A quick check confirms it displays correctly, so the site looks polished in every tab.

Frequently asked questions

What scale should I pick to turn a 24px icon into a sharp PNG?

Use 4x for a 96px PNG, which looks sharp on retina screens and in presentations. For a website icon, 2x or 3x is usually enough. For print, pick a scale that reaches at least 300 DPI at the printed size. The export caps at 8000px on the longest side, which rarely matters.

Does SVG to PNG keep the transparent background?

Yes. SVG files with transparent backgrounds produce transparent PNGs, so a logo sits cleanly on any background colour. If the SVG has a background rectangle, that rectangle becomes part of the PNG, so remove it in your design tool first if you want transparency.

Why is a linked photo missing from my converted PNG?

The converter cannot fetch external files during conversion, so any image linked by URL is left out. Embed the image as a data URI inside the SVG before converting, so the file is fully self-contained. Most design tools have an option to embed images when exporting SVG.

Can I use a webfont inside an SVG for PNG export?

Not reliably. Web fonts referenced inside an SVG are not loaded during conversion, so the text falls back to a default font. Convert text to outlines in your design tool before converting, so the lettering becomes shapes and renders exactly regardless of fonts.

What is the largest PNG an SVG can produce?

The export scale is capped at 8000px on the longest side, so a very large SVG at 4x stops at that ceiling. For most icons and logos the cap never matters, since a 100px logo at 4x is only 400px. For print work, check that the capped size still meets your DPI needs.

Is the PNG output lossless?

Yes. PNG is a lossless format, so the rasterized pixels are stored exactly as drawn. The PNG cannot be sharper than the rasterization, though, since the vector shapes are fixed into pixels at the chosen scale. For a sharper result, rasterize again at a higher scale from the SVG original.
