Image Dimensions Checker ব্যবহার করবেন কীভাবে

সরাসরি আপনার ব্রাউজারে কাজটি শেষ করতে এই সহজ ধাপগুলো অনুসরণ করুন।

1

একটি বা একাধিক ছবি ছাড়ুন বা বেছে নিন

২০ MB পর্যন্ত JPG, PNG, WebP, HEIC, SVG, BMP, GIF বা AVIF ফাইল ড্রপজোনে আপলোড করুন, অথবা Ctrl+V দিয়ে পেস্ট করুন।

2

পিক্সেল মাপ ও অ্যাসপেক্ট রেশিও দেখুন

টেবিলে নির্দিষ্ট Width × Height (px), Megapixels, Orientation (Landscape, Portrait, Square) ও সরলীকৃত/দশমিক Aspect Ratio দেখুন।

3

ফাইলের ওজন, ফরম্যাট ও Alpha চ্যানেল যাচাই করুন

Size / Format কলামে আসল শনাক্ত করা কনটেইনার টাইপ, বাইট সংখ্যা ও ট্রান্সপারেন্ট Alpha পিক্সেল আছে কি না তা দেখুন।

4

আনুমানিক ৩০০ DPI প্রিন্ট সাইজ দেখুন

Print @300 DPI কলামে প্রিন্ট ল্যাবে আপলোড করার আগে ইঞ্চিতে সর্বোচ্চ ধারালো ফিজিক্যাল প্রিন্ট মাপ (প্রস্থ" × উচ্চতা") দেখুন।

5

ন্যূনতম স্পেক যাচাই চালান ও CSV বা JSON এক্সপোর্ট করুন

ইচ্ছেমতো Min Width Check (px) ও Min Height Check (px) নিয়ম লিখে Pass বা Below Min চিহ্নিত করুন, তারপর Export CSV বা Export JSON ক্লিক করুন।

ব্যাচ ডাইমেনশন পরীক্ষা

একসাথে কয়েক ডজন অ্যাসেট দেখুন — স্টোরের প্রোডাক্ট ছবি, অ্যাড ক্রিয়েটিভ বা অ্যাপ স্ক্রিনশট যাচাইয়ের জন্য আদর্শ।

নির্দিষ্ট ও সাধারণ অ্যাসপেক্ট রেশিও

গাণিতিকভাবে সরলীকৃত রেশিও হিসাব করে, আর ১৬:৯, ৪:৩, ১:১ ও ৪:৫-এর মতো সাধারণ স্ট্যান্ডার্ডের সাথে মেলায়।

কাস্টম Min/Max ভ্যালিডেটর

ইচ্ছেমতো ন্যূনতম বা সর্বোচ্চ প্রস্থ/উচ্চতা নিয়ম ঠিক করে কোন ছবি স্পেক মানে আর কোনটি মানে না, তা সাথে সাথে হাইলাইট করুন।

CSV ও JSON এক্সপোর্ট

পরীক্ষা করা সব ছবির মাপের পরিষ্কার CSV স্প্রেডশিট বা JSON সারাংশ ডাউনলোড করুন।

Image Metadata Viewer

Image DPI Changer

Image to Base64

Base64 থেকে ছবি
