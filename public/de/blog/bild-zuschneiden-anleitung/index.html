Bild zuschneiden: Anleitung

Schneiden Sie jedes Bild online in Sekunden zu: hochladen, Auswahlrechteck ziehen, Seitenverhältnis wählen, Maße prüfen und einen sauberen Zuschnitt herunterladen.

Ein Bild zuzuschneiden dauert weniger als eine Minute, sobald man die Schritte kennt. Sie laden das Foto hoch, ziehen ein Rechteck um den Teil, den Sie behalten möchten, und laden das Ergebnis herunter.

Diese Anleitung führt Sie durch den gesamten Ablauf. Sie behandelt die Wahl des Seitenverhältnisses, das Raster für einen besseren Bildausschnitt, die Prüfung der Ausgabegröße und die Wahl des richtigen Exportformats.

Am Ende können Sie auf jedem Gerät ein Profilbild, ein Banner, einen Screenshot oder ein Dokument sauber zuschneiden. Bewahren Sie die Originaldatei auf, bis Sie den Download geprüft haben.

Vorbereitung: Entscheiden Sie zuerst den Verwendungszweck

Entscheiden Sie, wo das zugeschnittene Bild leben wird, bevor Sie das Tool öffnen. Ein Profilbild braucht ein Quadrat, ein Banner ein breites Rechteck und ein Druck ein bestimmtes Verhältnis.

Der Verwendungszweck bestimmt das Seitenverhältnis, und das Verhältnis bestimmt die Form Ihres Auswahlrechtecks. Wer mit der falschen Form beginnt, muss den Zuschnitt später wiederholen.

Nutzen Sie das Originalfoto, keine komprimierte oder bearbeitete Kopie. Zuschneiden aus der bestmöglichen Quelle hält die behaltenen Pixel so scharf wie möglich.

Öffnen Sie das Tool „Bild zuschneiden“ in Ihrem Browser. Alles läuft lokal, Ihr Foto wird also nie auf einen Server hochgeladen.

Bild in fünf Schritten zuschneiden

Der Ablauf ist für ein Foto, einen Screenshot oder ein eingescanntes Dokument derselbe. Hochladen, einrahmen, prüfen, exportieren und den Download kontrollieren.

Nehmen Sie sich Zeit für den Schritt mit dem Bildausschnitt. Ein sorgfältiger Zuschnitt jetzt erspart Ihnen die Wiederholung, wenn das Bild an seinem Verwendungszweck falsch aussieht.

  1. Laden Sie Ihr Bild hoch, indem Sie es in die Ablagefläche ziehen, auf Ihrem Gerät auswählen oder einen Screenshot mit Strg+V einfügen.
  2. Ziehen Sie das Auswahlrechteck über den Teil, den Sie behalten möchten, und nutzen Sie die acht Griffe, um es von jeder Seite oder Ecke aus zu skalieren.
  3. Wählen Sie eine Seitenverhältnis-Voreinstellung wie 1:1, 4:3 oder 16:9 – oder lassen Sie sie frei für eine eigene Form.
  4. Prüfen Sie die Ausgabemaße in Pixeln, die das Tool anzeigt, und bestätigen Sie, dass sie groß genug für den Verwendungszweck sind.
  5. Wählen Sie Exportformat und Qualität und klicken Sie dann auf „Herunterladen“, um das zugeschnittene Bild zu speichern.

Öffnen Sie die heruntergeladene Datei einmal, bevor Sie sie verwenden. Bestätigen Sie, dass der Bildausschnitt stimmt und nichts Wichtiges an den Rändern abgeschnitten wurde.

Das Auswahlrechteck ziehen

Das Auswahlrechteck ist das Rechteck, das Ihren Zuschnitt definiert. Ziehen Sie innerhalb des Rechtecks, um es zu verschieben, oder ziehen Sie an einem der acht Griffe, um seine Größe zu ändern.

Die Eckgriffe skalieren von zwei Seiten gleichzeitig – der schnellste Weg, ein Motiv einzurahmen. Die Kantengriffe passen nur eine Seite an, was für Feinabstimmungen praktisch ist.

Wenn eine Seitenverhältnis-Voreinstellung aktiv ist, halten die Griffe das Rechteck in Proportion. Die Form bleibt beim Ändern der Größe fest – ein Quadrat bleibt also ein Quadrat.

Alles außerhalb des Rechtecks verdunkelt sich auf der Arbeitsfläche. Diese Abdunklung hilft Ihnen genau zu sehen, was behalten und was weggeschnitten wird.

Eine Seitenverhältnis-Voreinstellung wählen

Wählen Sie 1:1 für ein quadratisches Profilbild oder einen Instagram-Beitrag. Das Rechteck bleibt beim Ziehen perfekt quadratisch, sodass der Bildausschnitt konsistent bleibt.

Wählen Sie 4:3 für eine traditionelle Fotoform oder einen Dokumentenzuschnitt. Es ist etwas breiter als hoch und eignet sich für die meisten gedruckten Fotos und eingescannten Seiten.

Wählen Sie 16:9 für ein breites Banner, ein Video-Thumbnail oder eine Präsentationsfolie. Die breite Form erstreckt sich über Bildschirme, ohne leeren Raum zu lassen.

Nutzen Sie den freien Modus, wenn keine Voreinstellung passt. Sie können das Rechteck in jede Form ziehen – praktisch, um einen einzelnen Absatz aus einer Seite oder ein Detail aus einem Produktfoto herauszuschneiden.

Das Drittelraster nutzen

Das Raster teilt das Auswahlrechteck in neun gleiche Teile. Platzieren Sie das Motiv auf einer der Linien oder an einem Kreuzungspunkt für eine natürlichere Komposition.

Setzen Sie bei einem Porträt die Augen auf die obere waagerechte Linie. Bei einer Landschaft gehört der Horizont auf die obere oder untere Linie statt in die Mitte.

Das Raster hilft Ihnen auch, ein gekipptes Motiv zu erkennen. Verläuft ein Horizont diagonal über das Raster, braucht das Foto womöglich ein Geraderücken vor oder nach dem Zuschnitt.

Ignorieren Sie das Raster, wenn das Motiv in der Mitte besser wirkt. Ein symmetrisches Gebäude, ein Logo oder ein Frontalporträt sieht in der Mitte oft am besten aus.

Für einen präzisen Bildausschnitt heranzoomen

Zoomen Sie heran, wenn das Detail, das Sie haben möchten, klein ist. Ein Produktmerkmal, ein Gesicht in einer Menschenmenge oder eine einzelne Textzeile profitieren alle von einem genaueren Blick, bevor Sie das Rechteck platzieren.

Zoomen verändert die Ausgabequalität nicht. Es vergrößert nur die Vorschau, damit Sie die Auswahl genau positionieren können, und der Export nutzt weiterhin die Originalpixel.

Ziehen Sie das Bild nach dem Zoomen so, dass das Detail zentriert ist, und passen Sie dann das Rechteck darum an. Prüfen Sie die Maßanzeige, um zu bestätigen, dass der Zuschnitt noch groß genug ist.

Ist der herangezoomte Zuschnitt zu klein für seinen Verwendungszweck, verbreitern Sie das Rechteck oder nutzen Sie ein Quellbild mit höherer Auflösung. Ein winziger Zuschnitt, der auf Bannergröße gestreckt wird, wirkt weich.

Ausgabemaße vor dem Herunterladen prüfen

Das Tool zeigt die genauen Ausgabemaße in Pixeln vor dem Herunterladen an. Das ist die wichtigste Prüfung im gesamten Ablauf – und sie dauert zwei Sekunden.

Vergleichen Sie die Zahl mit dem, was Ihr Verwendungszweck verlangt. Ein Profilbild braucht nur wenige hundert Pixel, ein Website-Banner dagegen womöglich über tausend.

Ist der Zuschnitt zu klein, verbreitern Sie das Auswahlrechteck. Ein breiteres Rechteck erfasst mehr Pixel und gibt dem Verwendungszweck mehr Material zum Arbeiten.

Die Schaltfläche „Gesamt auswählen“ setzt das Rechteck auf das ganze Bild zurück. Nutzen Sie sie, wenn Sie zu weit zugeschnitten haben und den Bildausschnitt von vorn beginnen möchten.

Exportformat und Qualität wählen

Wählen Sie JPG für Fotos. Der Qualitätsregler lässt Sie Dateigröße gegen Details abwägen, und eine Einstellung um 85 bis 90 hält die meisten Fotos sauber aussehend.

Wählen Sie PNG für Screenshots, Logos und Grafiken mit Text. PNG ist verlustfrei, sodass die Kanten von Buchstaben scharf bleiben, und es erhält Transparenz, wenn Sie sie brauchen.

Wählen Sie WebP, wenn Sie kleine Dateien mit guter Qualität möchten. Es eignet sich gut für Webbilder, auch wenn einige ältere Systeme das Format noch ablehnen.

Beachten Sie, dass der Qualitätsregler bei PNG verschwindet, weil PNG keine verlustbehaftete Kompression hat, die man anpassen könnte. Das ist normal und kein Fehler im Tool.

Einen Screenshot zuschneiden

Fügen Sie einen Screenshot direkt mit Strg+V ein, um den Speicherschritt zu überspringen. Das Bild erscheint sofort im Tool und ist bereit zum Beschneiden.

Ziehen Sie das Rechteck um den Teil, der zählt: die Fehlermeldung, die Einstellung oder die Schaltfläche. Schneiden Sie Browser-Symbolleiste, Taskleiste und jeden leeren Raum weg.

Exportieren Sie Screenshots als PNG. Das verlustfreie Format hält kleinen Text lesbar, während JPG-Kompression die Kanten von Buchstaben verwischt und sie schwerer lesbar macht.

Benennen Sie die Datei klar, etwa fehlermeldung.png. Ein klarer Name macht den Screenshot leicht auffindbar, wenn Sie ihn an eine Nachricht oder eine Fehlermeldung hängen.

Auf Handy oder Tablet zuschneiden

Das Tool arbeitet auf Touchscreens mit Fingergesten. Ziehen Sie das Rechteck mit einem Finger und zoomen Sie mit zwei Fingern heran, wenn Sie den Bildausschnitt genauer betrachten möchten.

Laden Sie aus Ihrer Galerie hoch oder fotografieren Sie direkt. Das Tool behandelt die Datei genauso wie auf einem Computer, und die Exportoptionen sind identisch.

Kleine Bildschirme erschweren präzises Einrahmen – zoomen Sie also heran, bevor Sie das Rechteck platzieren. Ein sorgfältiger Zuschnitt auf dem Handy ist immer noch besser als ein hastiger auf dem Desktop.

Heruntergeladene Zuschnitte landen in Ihrem üblichen Download-Ordner. Von dort aus können Sie sie ohne weitere Schritte in eine Chat-App, eine E-Mail oder einen Social-Media-Beitrag teilen.

Häufige Zuschnittprobleme lösen

Wenn sich das Auswahlrechteck nicht in der Form ändern lässt, prüfen Sie, ob eine Seitenverhältnis-Voreinstellung gesperrt ist. Wechseln Sie in den freien Modus, um das Rechteck in jede beliebige Form zu ziehen.

Wenn der heruntergeladene Zuschnitt unscharf aussieht, war die Auswahl wahrscheinlich zu klein. Kehren Sie zur Originaldatei zurück und verbreitern Sie das Rechteck, oder beginnen Sie mit einer Quelle in höherer Auflösung.

Wenn der Zuschnitt die falsche Form für seinen Verwendungszweck hat, prüfen Sie die Verhältnis-Voreinstellung. Ein Zuschnitt im Format 1:1 passt nicht in ein breites Banner, und ein Zuschnitt im Format 16:9 passt nicht in einen quadratischen Profilplatz.

Wenn das Bild außerhalb des Rechtecks dunkel aussieht, ist das die Abdunklung der Arbeitsfläche für den Bereich, der entfernt wird. Es ist ein Vorschaueffekt, keine Änderung an Ihrer Datei.

Kurztipps für bessere Zuschnitte

Schneiden Sie jedes Mal von der Originaldatei aus zu. Ein JPG, das schon zugeschnitten und gespeichert wurde, erneut zuzuschneiden, fügt mit jeder Runde Schaden hinzu.

Lassen Sie etwas Luft um das Motiv. Ein Gesicht ohne Luft über dem Kopf wirkt beengt, und ein Produkt, das den Rand berührt, sieht wie ein Fehler aus.

Prüfen Sie den Zuschnitt vor dem Herunterladen in voller Größe. Zoomen Sie in das Gesicht oder den Text hinein und bestätigen Sie, dass nichts Wichtiges weich oder abgeschnitten ist.

Speichern Sie die zugeschnittene Datei unter einem klaren Namen. Ein Name wie banner-16x9.png ist Monate später nützlich, ein Name wie IMG_4821.png dagegen nicht.

Produktfotos zuschneiden

Produktfotos brauchen einen konsistenten Bildausschnitt, denn eine Shopseite mit uneinheitlichen Zuschnitten wirkt nachlässig. Schneiden Sie jedes Produktbild im selben Verhältnis zu, damit das Raster sauber ausgerichtet ist.

Lassen Sie etwas Platz um das Produkt. Ein enger Zuschnitt, der die Ränder berührt, lässt den Artikel beengt wirken, während ein kleiner Rand ihm Luft zum Atmen gibt.

Nutzen Sie einen schlichten Hintergrund und schneiden Sie Unordnung an den Rändern weg. Eine saubere Produktaufnahme mit weißem oder hellem Hintergrund verkauft sich besser als eine überladene mit Ablenkungen.

Schneiden Sie bei einem Shop mit vielen Produkten alle Bilder im gleichen Stil zu: gleiches Verhältnis, gleiche Ränder, gleicher Hintergrund. Konsistenz im gesamten Katalog zählt mehr als ein einzelner perfekter Zuschnitt.

Bilder für E-Mails zuschneiden

Bilder in E-Mails müssen klein und korrekt geformt sein, denn ein großes Foto kann den Text vom Bildschirm schieben oder die Nachricht langsam laden lassen.

Schneiden Sie das Bild vor dem Anhängen auf den Teil zu, der zählt. Ein vollständiger Screenshot mit winzigem Detail ist in einer E-Mail nutzlos, während ein enger Zuschnitt des Details sofort klar ist.

Exportieren Sie E-Mail-Bilder als JPG für Fotos und PNG für Screenshots. Die kleinere Dateigröße hält die E-Mail leicht, und das richtige Format hält den Inhalt lesbar.

Prüfen Sie das zugeschnittene Bild vor dem Versenden auf einem Handy. Die meisten E-Mails werden mobil gelesen, und ein Zuschnitt, der auf dem Desktop gut aussieht, kann auf einem Handybildschirm zu klein oder zu breit sein.

Zuschneiden und Barrierefreiheit

Ein guter Zuschnitt hilft allen, doch er zählt am meisten für Menschen, die Bilder in großer Größe oder mit Bildschirmvergrößerung betrachten. Ein enger Zuschnitt der wichtigen Inhalte ist leichter zu verfolgen als eine weite Aufnahme voller Ablenkungen.

Wenn Sie ein Diagramm oder eine Grafik zuschneiden, halten Sie Beschriftungen und Legende innerhalb des Rahmens. Eine Grafik ohne ihre Beschriftungen ist bedeutungslos, egal wie scharf der Zuschnitt ist.

Schneiden Sie bei Anleitungsbildern immer nur einen Schritt auf einmal zu. Ein einzelner klarer Zuschnitt pro Schritt ist leichter zu verfolgen als ein großes Bild, das den gesamten Ablauf auf einmal zeigt.

Fügen Sie eine kurze Bildunterschrift oder einen Alternativtext hinzu, wenn Sie ein zugeschnittenes Bild teilen. Die Unterschrift erklärt, was der Zuschnitt zeigt – das hilft Menschen, die das Bild nicht klar sehen können.

Mit wiederholbaren Zuschnitten Zeit sparen

Wenn Sie dieselbe Art von Bild oft zuschneiden, bauen Sie sich eine Gewohnheit darum auf. Nutzen Sie jedes Mal dieselbe Verhältnis-Voreinstellung, dasselbe Exportformat und dasselbe Namensmuster.

Eine konsistente Routine spart bei jedem Zuschnitt Minuten. Sie hören auf, Verhältnis und Format jedes Mal von vorn zu entscheiden, und beginnen, saubere Zuschnitte zu produzieren, ohne darüber nachzudenken.

Notieren Sie sich die Verhältnisse, die Ihre Plattformen brauchen. Eine kurze Liste auf Ihrem Schreibtisch – etwa Profil 1:1 und Banner 16:9 – nimmt jeder Zuschnittsitzung das Rätselraten.

Prüfen Sie Ihre Zuschnitte gelegentlich. Plattformen ändern ihre Größenregeln, und ein Verhältnis, das letztes Jahr funktioniert hat, passt womöglich nicht mehr in den Platz, den Sie ansteuern.

Häufige Fragen

Wie schneide ich ein Bild für Instagram quadratisch zu?

Laden Sie das Foto hoch, wählen Sie die Voreinstellung 1:1 und ziehen Sie das quadratische Rechteck über den Teil, den Sie haben möchten. Halten Sie das Motiv zentriert, mit etwas Luft ringsum, prüfen Sie die Ausgabemaße und laden Sie es dann als JPG für ein Foto oder PNG für eine Grafik herunter.

Kann ich ein Foto zuschneiden, ohne eine App zu installieren?

Ja. Das Tool läuft vollständig in Ihrem Browser auf jedem Gerät – ohne Installation und ohne Konto. Laden Sie das Bild hoch, ziehen Sie das Auswahlrechteck, wählen Sie ein Verhältnis und laden Sie das Ergebnis herunter. Ihr Foto wird nie auf einen Server hochgeladen.

Welches Format ist das beste für den Download eines zugeschnittenen Screenshots?

PNG, weil es verlustfrei ist und kleinen Text scharf hält. JPG-Kompression verwischt die Kanten von Buchstaben, was Screenshots schwerer lesbar macht. Nutzen Sie JPG nur für zugeschnittene Fotos, bei denen die kleinere Dateigröße wichtiger ist als pixelgenaue Kanten.

Wie schneide ich eine Person oder ein Objekt am Rand eines Fotos heraus?

Ziehen Sie das Auswahlrechteck so, dass die unerwünschte Person oder das unerwünschte Objekt außerhalb liegt, und laden Sie dann den Zuschnitt herunter. Der abgedunkelte Bereich auf der Arbeitsfläche zeigt genau, was entfernt wird. Sitzt das Objekt in der Mitte des Bildes, kann Zuschneiden es nicht entfernen – weichzeichnen Sie es stattdessen.

Warum ist mein zugeschnittenes Bild nach dem Hochladen unscharf?

Das Auswahlrechteck war wahrscheinlich zu klein, sodass der Zuschnitt weniger Pixel hat, als der Verwendungszweck braucht. Kehren Sie zur Originaldatei zurück, verbreitern Sie das Rechteck und prüfen Sie die Ausgabemaße vor dem Herunterladen. Ein Original in höherer Auflösung hilft ebenfalls.

Kann ich einen Zuschnitt nach dem Herunterladen rückgängig machen?

Nicht aus der heruntergeladenen Datei, denn Zuschneiden entfernt die weggeschnittenen Pixel dauerhaft. Bewahren Sie das Originalfoto auf, damit Sie es anders zuschneiden können. Nutzen Sie im Tool die Schaltfläche „Gesamt auswählen“, um das Rechteck vor dem Herunterladen zurückzusetzen.
