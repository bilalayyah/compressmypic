Die Bildgröße online zu ändern dauert etwa eine Minute, wenn man die Schritte kennt. Foto hochladen, Größe wählen, Vorschau prüfen und Ergebnis herunterladen. Keine Software zu installieren, kein Konto anzulegen und kein Warten auf einen Upload zu einem Server.

Diese Anleitung führt durch den Ablauf im Tool Bildgröße ändern, vom ersten Upload bis zum finalen Download. Sie deckt beide Größenmodi, die Seitenverhältnis-Sperre, die Vorlagen und die Qualitätseinstellungen ab, damit Sie ein Foto oder einen ganzen Stapel sicher verkleinern können.

Am Ende wissen Sie, wie Sie eine Zielgröße für eine Website, einen Social-Media-Beitrag oder einen Druck wählen und wie Sie das Ergebnis prüfen, bevor Sie es verwenden. Wenn Sie zuerst die Hintergründe wollen, lesen Sie Bildgröße ändern: Die komplette Anleitung.

Größenänderung in sechs Schritten

Der gesamte Ablauf folgt jedes Mal denselben sechs Schritten. Lernen Sie sie einmal, und jede Größenänderung danach ist Routine, ob das Bild ein Handyfoto, ein Produktfoto oder ein Screenshot ist.

  1. Bild hochladen: Ziehen Sie eine JPG-, PNG-, WebP-, HEIC-, GIF-, BMP- oder SVG-Datei bis 20 MB per Drag-and-drop herein, wählen Sie sie vom Gerät aus oder fügen Sie einen Screenshot mit Strg+V ein.
  2. Pixel- oder Prozentmodus wählen: Nutzen Sie „In Pixeln“ für eine exakte Größe bis 12.000 px oder „In Prozent“ zum Skalieren zwischen 10 und 200 Prozent.
  3. Größe festlegen: Tippen Sie Breite und Höhe ein, ziehen Sie den Prozent-Schieberegler, tippen Sie einen Schnellbutton oder klicken Sie eine Vorlage wie Instagram-Beitrag oder Full HD.
  4. Seitenverhältnis-Sperre und Anpassung prüfen: Halten Sie „Seitenverhältnis gesperrt“ für proportionale Skalierung eingeschaltet, oder lösen Sie sie und wählen Sie „Enthalten“, „Ausfüllen“ oder „Exakt strecken“.
  5. Format und Qualität wählen: Behalten Sie „Original“ oder wechseln Sie zu JPG, PNG oder WebP, stellen Sie die Qualität von 10 bis 100 Prozent ein und wählen Sie eine Mattierungsfarbe für JPG.
  6. Größe ändern und herunterladen: Klicken Sie auf „Alle verkleinern“, prüfen Sie das Ergebnis in der Vergleichsansicht und laden Sie dann die Datei oder die ZIP für einen Stapel herunter.

Wählen Sie zuerst Ihre Zielgröße

Entscheiden Sie die Größe, bevor Sie das Tool öffnen, nicht während Sie auf das Breitenfeld starren. Das Ziel bestimmt die Zahl: Ein Blogbild, ein Social-Media-Beitrag und ein Druck wollen unterschiedliche Maße. Raten im Tool verschwendet eine Größenänderung und führt oft zu einer zweiten, korrigierten.

Fragen Sie, wo das Bild zu sehen sein wird und wie groß es dort erscheint. Ein Bild, das 800 Pixel breit angezeigt wird, braucht etwa 800 Pixel in der Datei, mit etwas Extra für scharfe Bildschirme. Ein Bild, das einen breiten Hero füllen soll, braucht eher 1920 Pixel Breite.

Wenn keine exakte Größe vorgegeben ist, nutzen Sie die gängigen Größen als Richtlinie. Blogbilder funktionieren gut mit 1200 Pixeln Breite, Thumbnails mit 600 und Fullscreen-Heros mit 1920. Diese drei Zahlen decken die meiste Größenänderung im Web ab, die Sie je machen werden.

Schreiben Sie das Ziel vor dem Hochladen auf. Eine Notiz wie „1080 mal 1080 für den Beitrag und 1200 breit für den Blog“ hält die Arbeit schnell und verhindert, dass Sie dasselbe Foto zweimal verkleinern. Das Tool merkt sich zwischen Besuchen nichts, Ihre Notiz ist also der Plan.

Pixel oder Prozent: Welcher Modus?

Nutzen Sie „In Pixeln“, wenn das Ziel Ihnen eine exakte Zahl vorgibt. Social-Media-Plattformen, Marktplätze und Design-Tools veröffentlichen alle exakte Größen, und wer sie eintippt, garantiert, dass das Bild genau in dieser Größe ankommt. Das ist der Modus für Vorgaben.

Nutzen Sie „In Prozent“, wenn das Ziel einfach kleiner ist. Ein Ordner mit Kamerafotos bei 4000 Pixeln Breite braucht kein exaktes Ziel, er muss nur halb so groß werden. 50 Prozent einzustellen skaliert jedes Foto in einem Durchgang proportional, ohne Zahlen nachzuschlagen.

Der Prozentmodus hält gemischte Stapel außerdem konsistent. Jedes Bild schrumpft um denselben Anteil, die relativen Größen im Satz bleiben also gleich. Das zählt für eine Galerie, in der ein Foto klar größer bleiben soll als ein anderes.

Halten Sie das Seitenverhältnis gesperrt

Die Seitenverhältnis-Sperre ist die wichtigste Steuerung im ganzen Tool. Ist sie eingeschaltet, aktualisiert eine geänderte Breite die Höhe im exakten Verhältnis, das Bild behält also seine natürliche Form. Gesichter bleiben natürlich, Kreise bleiben rund und Produkte behalten ihre wahren Proportionen.

Wenn Sie Ihr erstes Foto in eine leere Warteschlange legen, setzt das Tool die Breite zunächst auf bis zu 1200 Pixel und berechnet die passende Höhe für Sie. Dieser Startwert ist ein sinnvoller Ausgangspunkt fürs Web, und Sie können ihn sofort mit eigenen Zahlen überschreiben.

Lösen Sie die Sperre nur, wenn ein Ziel einen exakten Rahmen mit einer anderen Form verlangt. Beim Lösen erscheinen „Enthalten“, „Ausfüllen“ und „Exakt strecken“, und Sie müssen bewusst eines wählen. „Enthalten“ behält das ganze Motiv mit Auffüllung, „Ausfüllen“ füllt den Rahmen durch Beschnitt der Ränder und „Strecken“ verzerrt zur Anpassung.

Nutzen Sie eine Vorlage, wenn eine passt

Vorlagen sind der schnellste Weg zu einer korrekten Größe. Ein Klick trägt die exakten Maße für ein gängiges Ziel ein, Sie tippen also nie eine Zahl ein und schlagen keine nach. Sie sind ideal, wenn Sie oft für Social Media verkleinern und die Größen immer wieder vergessen.

  • Instagram-Beitrag: 1080 mal 1080, die quadratische Feed-Größe.
  • Instagram-Story: 1080 mal 1920, die hohe Fullscreen-Größe.
  • YouTube-Thumbnail: 1280 mal 720, die breite Thumbnail-Größe.
  • Facebook-Titelbild: 851 mal 315, die breite und kurze Header-Größe.
  • X-Header: 1500 mal 500, die sehr breite Banner-Größe.
  • Full HD: 1920 mal 1080, die Standard-Breitbildgröße.

Ein Klick auf eine Vorlage schaltet das Tool in den Pixelmodus und trägt diese Maße ein. Sie können sie danach immer noch anpassen, eine Vorlage ist also ein Ausgangspunkt und keine festgelegte Wahl. Wenn eine Plattform ihre Größe ändert, passen Sie die Zahlen an und machen weiter.

Vorlagen ändern die Form Ihres Fotos allein nicht. Ein breites Foto, das mit gesperrtem Verhältnis auf eine quadratische Vorlage verkleinert wird, behält seine breite Form in der Vorlagenbreite und wird nicht quadratisch. Um den quadratischen Rahmen zu erzwingen, lösen Sie das Verhältnis und wählen „Ausfüllen“ oder schneiden Sie das Foto zuerst mit Bild zuschneiden quadratisch zu.

Format und Qualität einstellen

Format und Qualität entscheiden, wie die verkleinerte Datei gespeichert wird, und sie zählen genauso viel wie die Maße. Das Originalformat zu behalten ist die vorsichtige Wahl: Das verkleinerte Bild behält das Format, mit dem es ankam, und bei Transparenz oder Farbe passiert nichts Unerwartetes.

Ein Formatwechsel im selben Durchgang spart eine zweite Arbeit. Ein PNG-Screenshot kann für einen Blog zu einem JPG mit 85 Prozent Qualität werden, oder ein JPG-Foto kann für eine schnellere Seite zu einem WebP werden. Das Tool wandelt beim Skalieren um, ein Klick erledigt also beide Schritte.

Qualität nahe 85 Prozent ist der ideale Wert für die meisten Webbilder. Sie hält Kanten scharf und Verläufe sauber und schneidet die Dateigröße deutlich. Senken Sie die Qualität nur Richtung 65 bis 75 Prozent, wenn die Datei sehr klein sein muss, und heben Sie sie Richtung 95 bis 100 Prozent für die Druckvorbereitung an.

Wenn Sie JPG als Ausgabe für ein transparentes PNG wählen, legen Sie zuerst die Mattierungsfarbe fest. Transparente Bereiche füllen sich mit dieser Farbe, standardmäßig Weiß, weil JPG keine Transparenz speichern kann. Für ein Logo, das transparent bleiben muss, behalten Sie stattdessen PNG- oder WebP-Ausgabe.

Ergebnis vor dem Herunterladen prüfen

Schauen Sie sich das verkleinerte Bild immer an, bevor Sie es verwenden. Klicken Sie bei einer fertigen Ergebniskarte auf „Vergleichen“ oder auf ihr Thumbnail, um den Vorher-nachher-Vergleich zu öffnen. Er zeigt Original- und Zielmaße, die Byte-Ersparnis und einen geteilten Schieberegler für feine Details.

Schauen Sie zuerst auf Text, weil Text Weichheit vor allem anderen zeigt. Schauen Sie dann auf Gesichter und Kanten, wo Dehnung oder zu starkes Verkleinern am leichtesten auffallen. Wenn das Bild weich aussieht, liegt die Ursache meist in einer Vergrößerung oder einer sehr niedrigen Qualitätseinstellung, und beides lässt sich durch einen neuen Durchgang mit anderen Zahlen beheben.

Prüfen Sie auch die Maße in der Ergebniskarte, nicht nur das Bild selbst. Ein Tippfehler im Breitenfeld passiert leicht und fällt leicht übersehen, und die Karte zeigt die exakte Ausgabegröße. Die Zahlen zu bestätigen dauert zwei Sekunden und erspart, das Bild erneut auf eine Plattform hochzuladen, die die falsche Größe ablehnt.

Einen Stapel in einem Durchgang verkleinern

Ein Foto geht schnell, aber ein Ordner voller Fotos ist der Moment, in dem sich das Online-Tool wirklich auszahlt. Legen Sie mehrere Bilder in die Warteschlange, stellen Sie eine Größe ein, klicken Sie auf „Alle verkleinern“, und jedes Bild wird mit denselben Einstellungen verarbeitet. Die Schritte müssen nicht pro Foto wiederholt werden.

Bei gesperrtem Seitenverhältnis behält jedes Foto seine eigenen Proportionen und teilt sich die Breitenbegrenzung. Hochformate bleiben Hochformate und Querformate bleiben Querformate, genau das, was Sie für einen Blogordner oder ein Produktshooting mit gemischter Ausrichtung wollen.

Wenn zwei oder mehr Bilder fertig sind, erscheint eine „Stapel fertig“-Leiste mit einem Button „Alle herunterladen (ZIP)“. Ein Klick packt jede verkleinerte Datei in resized_images_compressmypic.zip, was weit schneller ist, als jede Datei einzeln herunterzuladen. Für größere Ordner sind die Anleitung zum Verkleinern im Stapel und das Tool Bilder stapelweise verkleinern genau für diese Arbeit gebaut.

Größe auf dem Handy ändern

Das Tool funktioniert auf Handys genauso wie auf dem Desktop, mit berührungsfreundlichen Schiebereglern und Vorlagen. Laden Sie aus Ihrer Fotobibliothek hoch, tippen Sie eine Vorlage an und laden Sie das verkleinerte Bild zurück aufs Handy. Das ist praktisch, um ein Foto direkt vor dem Posten zu korrigieren.

Handy-Browser kommen mit mittleren Größen gut zurecht, sehr große Canvas-Flächen können auf einem Mobilgerät aber viel Speicher brauchen. Wer innerhalb von 4000 bis 6000 Pixeln bleibt, hält die Verarbeitung auf dem Handy schnell, und dieser Bereich deckt jede Social-Media- und Webgröße ab, die Sie wahrscheinlich brauchen.

Einfügen funktioniert auf dem Desktop mit Strg+V, auf dem Handy können Sie einen Screenshot in den Browser teilen oder aus der Bibliothek wählen. In beiden Fällen wird das Bild lokal auf dem Handy verarbeitet, eine langsame Verbindung bremst die Größenänderung also nicht aus.

Größe für Social Media ändern

Social-Media-Plattformen schneiden unvorhersehbar zu, wenn ein Bild in der falschen Größe ankommt, die Größenänderung vor dem Posten ist die Minute also wert. Ein quadratischer Beitrag, der auf 1080 mal 1080 verkleinert wurde, füllt den Feed sauber, während eine Story mit 1080 mal 1920 den Bildschirm ohne schwarze Balken füllt.

Halten Sie das Motiv zentriert und weg von den Rändern. Plattformen legen Buttons, Bildunterschriften und Profilbilder über Ihr Bild, und alles nahe an einem Rand kann verdeckt enden. Eine Vorlage gibt Ihnen den Rahmen, aber Ihre Bildgestaltung entscheidet, was darin überlebt.

Verkleinern Sie für jede Plattform eine eigene Kopie, statt eine Größe überall wiederzuverwenden. Ein YouTube-Thumbnail mit 1280 mal 720 und ein X-Header mit 1500 mal 500 sind unterschiedliche Formen, und ein Bild kann nicht beiden dienen, ohne zu beschneiden oder zu verzerren. Zwei schnelle Größenänderungen schlagen einen unbeholfenen Kompromiss.

Wenn dasselbe Bild auf mehrere Plattformen muss, verkleinern Sie jedes Mal vom Original aus. Eine bereits verkleinerte Kopie erneut zu verkleinern verstärkt die Weichheit, während ein frischer Start vom Original jede Version so scharf hält, wie die Quelle es erlaubt.

Größe für eine Website ändern

Webbilder sollten zu ihrer Anzeigegröße passen. Ein Foto, das 800 Pixel breit gezeigt wird, braucht keine 4000 Pixel in der Datei, und die überzähligen Pixel verlangsamen nur die Seite. Die Größenänderung auf die Anzeigebreite, mit etwas Extra für scharfe Bildschirme, ist die einfachste Geschwindigkeitsverbesserung, die eine Website machen kann.

Blogbilder mit 1200 Pixeln Breite sind eine gute Standardeinstellung, weil sie auf dem Desktop scharf aussehen und für mobile Leser leicht genug bleiben. Hero-Bilder können auf 1920 Breite gehen, während Thumbnails und Avatare auf 600 oder weniger sinken können. Passen Sie jedes Bild an seinen Platz auf der Seite an.

Kombinieren Sie die Größenänderung für das beste Ergebnis mit einem Formatwechsel. WebP mit 80 bis 85 Prozent Qualität ist meist die kleinste Datei, die noch sauber aussieht, und das Tool kann beim Skalieren umwandeln. Für das ganze Bild zur Bildgeschwindigkeit lesen Sie Bildgröße ändern oder komprimieren: Was ist der Unterschied?.

Prüfen Sie nach dem Verkleinern auch die Dateigröße, nicht nur die Maße. Ein JPG mit 1200 Pixeln bei 85 Prozent Qualität ist typischerweise ein vernünftiges Gewicht für eine Website, während dasselbe Bild als PNG um ein Vielfaches schwerer sein kann. Wenn die Datei immer noch schwer wirkt, senken Sie die Qualität etwas oder wechseln Sie zu WebP.

Größe für den Druck ändern

Der Druck braucht mehr Pixel als ein Bildschirm, weil ein Drucker sie dicht packt. Ein Druck von 6 mal 4 Zoll bei 300 Punkten pro Zoll braucht 1800 mal 1200 Pixel, und ein größerer Druck braucht proportional mehr. Ändern Sie die Größe auf die Pixelzahl, die die Druckgröße verlangt, nicht auf eine Bildschirmgröße.

Halten Sie die Qualität für den Druck bei 95 bis 100 Prozent und bevorzugen Sie PNG oder hochwertiges JPG als Ausgabe. Die Datei wird größer sein als eine Webversion, aber das ist richtig: Der Druck zeigt jedes Pixel, und die zusätzlichen Daten halten den Druck scharf.

Vergrößern Sie niemals ein kleines Bild auf eine Druckgröße und erwarten Sie, dass es scharf aussieht. Ein Foto mit 800 Pixeln, das für den Druck auf 1800 Pixel gestreckt wird, sieht auf Papier weich aus, weil die Details nie da waren. Für den Druck beginnen Sie mit dem höchstaufgelösten Original, das Sie finden können.

Häufige Probleme lösen

Wenn das verkleinerte Bild gestreckt aussieht, war das Seitenverhältnis mit „Exakt strecken“ gelöst oder Breite und Höhe wurden unabhängig voneinander eingegeben. Führen Sie die Größenänderung mit eingeschalteter Sperre erneut aus, oder lösen Sie sie und wählen Sie stattdessen „Enthalten“ oder „Ausfüllen“. Die Vergleichsansicht zeigt die Verzerrung deutlich.

Wenn das verkleinerte Bild unscharf aussieht, ist die übliche Ursache die Vergrößerung eines kleinen Originals oder eine zu niedrige Qualitätseinstellung. Prüfen Sie zuerst die Originalmaße: Wenn die Quelle kleiner ist als das Ziel, verkleinern Sie das Ziel oder akzeptieren Sie ein weicheres Ergebnis. Auch die Qualität zurück Richtung 85 Prozent zu heben hilft.

Wenn die Datei größer statt kleiner geworden ist, liegt die Ursache wahrscheinlich im Format. Die Umwandlung eines JPG in PNG beim Verkleinern erzeugt eine verlustfreie Datei, die das JPEG-Original überwiegen kann. Stellen Sie die Ausgabe auf WebP oder JPG mit 80 bis 85 Prozent Qualität um und verkleinern Sie erneut.

Wenn ein GIF seine Animation verloren hat, ist das zu erwarten. Das Canvas rendert beim Verkleinern den ersten Frame eines GIFs und exportiert ein einzelnes Standbild. Um eine Animation zu behalten und gleichzeitig ihr Gewicht zu senken, nutzen Sie statt dieses Tools das GIF-Komprimierungs-Tool.

Häufige Fragen

Wie verkleinere ich ein Bild auf eine exakte Größe, etwa 800 mal 600?

Öffnen Sie das Tool zum Ändern der Bildgröße, laden Sie Ihr Foto hoch und wählen Sie den Modus „In Pixeln“. Tippen Sie 800 in das Breitenfeld und 600 in das Höhenfeld ein, halten Sie das Seitenverhältnis gesperrt, wenn das Foto diese Form schon hat, oder lösen Sie es und wählen Sie „Enthalten“ oder „Ausfüllen“, wenn es das nicht tut. Klicken Sie auf „Alle verkleinern“ und laden Sie das Ergebnis herunter.

Wie mache ich ein Bild kleiner, ohne etwas wegzuschneiden?

Nutzen Sie den Prozentmodus und wählen Sie einen Wert unter 100 Prozent, etwa 50 Prozent, bei gesperrtem Seitenverhältnis. Das ganze Bild schrumpft proportional und nichts wird weggeschnitten. Alternativ nutzen Sie „In Pixeln“ mit einer kleineren Breite und eingeschalteter Sperre, was die Höhe automatisch herunterskaliert.

Kann ich einen Screenshot verkleinern, den ich gerade gemacht habe?

Ja. Kopieren Sie den Screenshot in die Zwischenablage und drücken Sie dann Strg+V auf der Seite des Tools, um ihn direkt in die Warteschlange zu legen. Er lädt seine Maße sofort und wird mit Ihren aktuellen Breiten-, Höhen- oder Prozenteinstellungen verkleinert. Laden Sie den Screenshot auf dem Handy stattdessen aus Ihrer Fotobibliothek hoch.

Was ist die beste Größe für einen Instagram-Beitrag?

Ein quadratischer Instagram-Beitrag ist 1080 mal 1080 Pixel groß. Klicken Sie im Tool auf die Vorlage „Instagram-Beitrag“, und sie trägt diese Maße für Sie ein. Wenn Ihr Foto nicht quadratisch ist, schneiden Sie es zuerst mit dem Tool zum Zuschneiden quadratisch zu, oder lösen Sie das Verhältnis und wählen Sie „Ausfüllen“, um den quadratischen Rahmen zu füllen.

Warum sieht mein verkleinertes Bild unscharf aus?

Unschärfe entsteht meist durch das Vergrößern eines kleinen Originals, weil das Tool vorhandene Pixel strecken muss, um die größere Größe zu füllen. Sie kann auch von einer sehr niedrigen Qualitätseinstellung kommen. Prüfen Sie die Originalmaße, verkleinern Sie nach Möglichkeit lieber als zu vergrößern und halten Sie die Qualität für Webbilder nahe 85 Prozent.

Kann ich dasselbe Bild auf mehrere verschiedene Größen verkleinern?

Ja. Verkleinern Sie jedes Mal vom Original aus, statt eine bereits verkleinerte Kopie erneut zu verkleinern, damit jede Version so scharf bleibt, wie die Quelle es erlaubt. Laden Sie das Original hoch, stellen Sie die erste Größe ein, laden Sie sie herunter, ändern Sie dann die Größe und klicken Sie erneut auf „Alle verkleinern“, um die nächste Version zu erzeugen.
