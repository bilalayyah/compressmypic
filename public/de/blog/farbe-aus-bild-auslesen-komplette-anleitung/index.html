Farbe aus Bild auslesen: Anleitung

Jeder Designer kennt das: Man sieht eine Farbe auf dem Bildschirm und will ihren exakten Code wissen. Ein Screenshot, ein Foto, ein Logo oder ein Website-Mockup kann den perfekten Farbton enthalten – doch Raten führt nie zum Ziel.

Mit einem Farbwähler lösen Sie das in Sekunden. Sie öffnen ein Bild, zeigen auf ein beliebiges Pixel und lesen den exakten Farbcode in HEX, RGB, HSL und CMYK ab.

Diese Anleitung erklärt, wie Sie mit dem Farbwähler von CompressMyPic Farben auslesen, was die einzelnen Farbcodes bedeuten und wie Sie ausgewählte Farben in echten Design- und Entwicklungsprojekten einsetzen.

Was ist ein Farbwähler?

Ein Farbwähler ist ein Browser-Tool, das die Farbe eines beliebigen Pixels aus einem hochgeladenen Bild ausliest. Er funktioniert wie die Pipette in einem Designprogramm – nur ohne Installation.

Sie ziehen ein Foto oder einen Screenshot in das Tool, bewegen den Cursor über das Bild, und das Tool zeigt die Farbe genau an diesem Punkt an. Der Wert aktualisiert sich live, während Sie den Cursor bewegen.

Das Tool akzeptiert gängige Bildformate wie JPG, PNG, WebP und GIF. Dateien bis zu 20 MB werden unterstützt – das deckt fast jedes Foto, Logo und jeden Screenshot ab, aus dem Sie je eine Farbe entnehmen müssen.

Alles läuft lokal in Ihrem Browser. Ihr Bild wird nie auf einen Server hochgeladen, also bleiben Kunden-Mockups und unveröffentlichte Markenarbeiten privat, während Sie Farben daraus entnehmen.

Wie die Pipette ein Pixel ausliest

Jedes digitale Bild ist ein Raster aus winzigen Quadraten, den Pixeln. Jedes Pixel speichert eine Farbe, beschrieben durch drei Zahlen für rotes, grünes und blaues Licht.

Wenn Sie auf einen Punkt im Bild klicken, liest das Tool die Rot-, Grün- und Blauwerte dieses einen Pixels aus. Dann wandelt es diese drei Zahlen in jedes Farbformat um, das Sie brauchen könnten.

Die Messung ist exakt, keine Schätzung. Das Pixel hat wirklich diese Farbe, und der Code, den Sie kopieren, gibt sie in einer Designdatei, einem Stylesheet oder einem Druckdokument originalgetreu wieder.

Trotzdem kann ein einzelnes Pixel überraschen. In einem Foto unterscheiden sich benachbarte Pixel oft leicht, sodass ein Schritt zur Seite schon die letzte Ziffer eines HEX-Codes verändern kann.

Die Farbcodes: HEX, RGB, HSL, CMYK

Jedes ausgewählte Pixel liefert gleich mehrere Farbcodes. HEX ist der sechsstellige Code, den Webentwickler in CSS verwenden, zum Beispiel #2563EB für ein kräftiges Blau.

RGB beschreibt dieselbe Farbe als drei Zahlen von 0 bis 255, je eine für Rot, Grün und Blau. Es ist das Format, das die meisten Design-Tools und Bildbearbeitungsprogramme von Haus aus verstehen.

HSL beschreibt eine Farbe über Farbton, Sättigung und Helligkeit. Designer mögen es, weil es der menschlichen Farbwahrnehmung entspricht: Man wählt einen Farbton und macht ihn dann satter oder heller.

CMYK beschreibt die Farbe als Farbanteile in Prozent für den Druck. Auf dem Bildschirm ist das nur eine Annäherung, denn Bildschirme arbeiten mit Licht und Drucker mit Farbe – doch als Ausgangspunkt für Druckarbeiten ist es nützlich.

Die 11×11-Lupe: Warum Vergrößerung so wichtig ist

Das richtige Pixel zu treffen, ist bei normalem Zoom schwer. Eine dünne Linie, ein kleines Icon oder ein ein Pixel breiter Rahmen ist leicht um Haaresbreite zu verfehlen – und ein Fehlgriff liefert die falsche Farbe.

Das Tool löst das mit einer 11×11-vergrößerten Lupe. Sie zeigt eine vergrößerte Ansicht der Pixel rund um Ihren Cursor, sodass Sie genau sehen, welches Pixel Sie gleich entnehmen.

Die Lupe ist besonders nützlich bei UI-Screenshots. Buttons, Trennlinien und Texte sitzen oft auf weichgezeichneten Kanten, an denen die Farbe über zwei oder drei Pixel verläuft.

Mit der Vergrößerung können Sie auf die feste Mitte einer Form zielen statt auf ihre verlaufende Kante. Genau diese Entscheidung macht oft den Unterschied zwischen der echten Markenfarbe und einem trüben Zwischenton aus.

Ausgewählte Farbfelder: Eine Sammlung aufbauen

Eine Farbe reicht selten aus. Eine Markenpalette, ein Website-Theme oder eine Präsentation braucht mehrere Farben, die zusammenpassen – und das Tool lässt Sie sie eine nach der anderen sammeln.

Jeder Klick fügt die entnommene Farbe Ihrer Ablage „Ausgewählte Farbfelder“ hinzu. So können Sie die Hauptfarbe, den Akzent, die Hintergrundfarbe und die Textfarbe aus demselben Bild sammeln.

Die Farbfelder bleiben während der Arbeit sichtbar, sodass Sie sie nebeneinander vergleichen können. Wenn zwei Entnahmen fast identisch aussehen, können Sie eine davon entfernen und die sauberere Version behalten.

Wenn Sie zweimal auf denselben HEX-Wert klicken, entsteht kein Duplikat. Das Tool hält Ihre Sammlung übersichtlich – wichtig, wenn Sie ein Foto mit vielen fast identischen Farbtönen abtasten.

CSS-Export: Vom Bild ins Stylesheet

Gesammelte Farbfelder nützen nur etwas, wenn Sie sie in Ihr Projekt übernehmen können. Die Schaltfläche „CSS exportieren“ lädt Ihre ausgewählten Farben als sofort einsetzbare CSS-Variablen herunter.

Der Download liefert Ihnen Variablen wie --color-1, --color-2 und so weiter, jede mit einem HEX-Wert. Sie können sie in ein Stylesheet einfügen und überall in Ihrem Design verwenden.

Das ist besser, als Codes einzeln in eine Textdatei zu kopieren. Der Export hält alle Farben an einem Ort, in der richtigen Reihenfolge und ohne Tippfehler.

Für einen umfassenderen Palette-Workflow baut das Farbpaletten-Tool automatisch eine sortierte Palette. Nutzen Sie den Farbwähler, wenn Sie exakte Pixel wollen, und den Extraktor, wenn Sie die dominanten Farben eines ganzen Fotos suchen.

Farben aus Fotos entnehmen

Fotos sind die häufigste Quelle für entnommene Farben. Ein Sonnenuntergang, ein Produktfoto oder ein Reisefoto kann eine ganze Palette liefern, deren Farben von Natur aus zusammenpassen.

Beginnen Sie mit den größten ebenen Flächen des Fotos. Ein klarer Himmel, eine gestrichene Wand oder ein Kleidungsstück liefert eine stabile Farbe, die sich besser abtasten lässt als eine unruhige Textur.

Meiden Sie die hellsten Glanzlichter und die tiefsten Schatten. Diese Bereiche sind oft übersteuert – die eigentliche Farbinformation ist verloren, und der Code, den Sie erhalten, ist einfach Weiß oder Schwarz.

Tasten Sie denselben Bereich ein paar Mal ab und vergleichen Sie die Ergebnisse. Wenn sich die Codes um einen Wert herum gruppieren, ist dieser Wert die echte Farbe der Oberfläche. Wenn sie stark streuen, nehmen Sie die Mitte der Gruppe.

Farben aus Logos und Screenshots entnehmen

Logos und Screenshots von Benutzeroberflächen sind der Präzisionsfall. Eine Markenfarbe muss exakt stimmen, denn ein fast richtiger Farbton sieht neben dem echten Logo falsch aus.

Bei Logos tasten Sie die Mitte einer großen, ebenen Form ab. Die Mitte eines Buchstabens oder eines Blocks ist einfarbig, während die Kanten in den Hintergrund übergehen und Mischwerte liefern.

Bei Screenshots fügen Sie sie nach Möglichkeit direkt mit Strg+V ein. Das Tool akzeptiert Bilder aus der Zwischenablage, sodass Sie einen Bildschirm aufnehmen und abtasten können, ohne vorher eine Datei zu speichern.

Wenn Sie einen Screenshot abtasten, achten Sie auf die Pixelkoordinaten im Pixel-Inspektor. Die Koordinaten helfen Ihnen, exakt an dieselbe Stelle zurückzukehren, falls Sie einen Wert später noch einmal prüfen müssen.

Farbgenauigkeit: JPEG-Rauschen und Transparenz

Die JPEG-Komprimierung verändert Pixelfarben leicht. Das Format speichert Farben in kleinen Blöcken, sodass zwei benachbarte Pixel in einem gleichmäßigen Himmel sich um eine Ziffer oder zwei unterscheiden können.

Diese Schwankung ist normal und für die meisten Arbeiten harmlos. Nehmen Sie den Wert, der in dem Bereich am häufigsten vorkommt – dann sieht Ihr Ergebnis mit bloßem Auge richtig aus.

PNG-Dateien verhalten sich anders. Ein PNG speichert exakte Farben, der ausgelesene Code ist also genau der Code, den die Datei enthält – ganz ohne Komprimierungsrauschen.

Transparente Bereiche brauchen Sorgfalt. Wenn Sie einen transparenten Teil eines PNG-Logos abtasten, lesen Sie die Farbe unter der Transparenz aus – das kann Weiß oder Schwarz sein statt der Farbe, die Sie erwarten.

Farben auf dem Handy und Touchscreens entnehmen

Der Farbwähler funktioniert auf Handys und Tablets genauso wie auf dem Desktop. Sie tippen statt zu klicken, und dieselben Lupen- und Farbfeldfunktionen stehen zur Verfügung.

Tippen ist ungenauer als eine Maus, weil eine Fingerspitze viele Pixel auf einmal abdeckt. Die vergrößerte Lupe ist hier noch wichtiger, denn sie zeigt, was unter Ihrem Finger liegt.

Vergrößern Sie das Bild im Browser, bevor Sie tippen, wenn das Ziel klein ist. Ein größeres Bild gibt Ihrem Finger ein größeres Ziel und verringert die Chance, ein benachbartes Pixel zu erwischen.

Für kritische Markenfarben prüfen Sie die Entnahme später auf dem Desktop. Ein Fingertipp auf dem Handy kommt nah heran, doch ein Mausklick auf das exakte Pixel ist die verlässliche Endkontrolle.

Häufige Fehler beim Entnehmen von Farben

Der häufigste Fehler ist, eine Kante statt einer ebenen Fläche abzutasten. Weichgezeichnete Kanten vermischen zwei Farben, und der Mischwert gehört zu keiner von beiden.

Ein weiterer Fehler ist, einem einzigen Klick auf ein verrauschtes Foto zu vertrauen. Ein Pixel in einem körnigen Bild kann ein Ausreißer sein – tasten Sie dieselbe Stelle also immer zwei- oder dreimal ab.

Manche vergessen auch, dass Bildschirme unterschiedlich sind. Derselbe HEX-Code kann auf zwei Monitoren leicht anders aussehen – beurteilen Sie eine Farbe also nach ihrem Code, nicht nur nach dem Eindruck auf Ihrem Display.

Und tasten Sie niemals einen Screenshot von einem Screenshot ab. Jede Aufnahme und jedes erneute Speichern kann Farben leicht verschieben – arbeiten Sie also immer mit der saubersten Originaldatei, die Sie haben.

Farbwähler oder Paletten-Extraktor?

Der Farbwähler und der Paletten-Extraktor beantworten unterschiedliche Fragen. Der Farbwähler nennt Ihnen die exakte Farbe eines Pixels, das Sie selbst wählen, während der Extraktor die dominanten Farben des ganzen Bildes findet.

Nutzen Sie den Farbwähler, wenn Sie wissen, was Sie wollen: das exakte Blau eines Logos, den exakten Farbton eines Buttons oder den exakten Ton einer Wand auf einem Foto.

Nutzen Sie den Extraktor, wenn Sie Ideen suchen: die fünf oder sechs Farben, die ein Foto prägen, sortiert danach, wie viel vom Bild sie bedecken. Er ist der schnellere Weg zu einer vollständigen Palette.

Viele Designer nutzen beides. Sie extrahieren eine Palette für das Gesamtkonzept und greifen dann mit dem Farbwähler eine präzise Akzentfarbe heraus, die der Extraktor zu niedrig eingestuft hat.

Wer nutzt einen Farbwähler?

Webentwickler nutzen ihn, um ein Design-Mockup exakt zu treffen. Wenn ein Kunde einen Screenshot statt einer Designdatei schickt, stellt der Farbwähler die echten HEX-Codes wieder her.

Grafikdesigner nutzen ihn, um Paletten aus Referenzfotos aufzubauen. Ein Foto auf einem Moodboard kann die gesamte Farbwelt für ein Poster oder eine Markenidentität liefern.

Printdesigner nutzen den CMYK-Wert als Ausgangspunkt. Er ist keine perfekte Druckübereinstimmung, sagt ihnen aber, ob eine leuchtende Bildschirmfarbe auf Papier überlebt.

Content-Creator nutzen ihn für Thumbnails und Social-Media-Grafiken. Wenn ein Thumbnail-Akzent zur Markenfarbe passt, wirkt ein Kanal über Dutzende Videos hinweg konsistent.

Datenschutz: Ihre Bilder bleiben in Ihrem Browser

Datenschutz zählt, wenn das Bild ein Kunden-Mockup, ein unveröffentlichtes Produktfoto oder ein privates Foto ist. Solche Dateien auf einen beliebigen Server hochzuladen, ist ein Risiko, das Sie nicht eingehen müssen.

Dieses Tool verarbeitet alles lokal. Das Bild wird von Ihrem Browser gelesen, die Pixel werden auf Ihrem Gerät abgetastet, und nichts verlässt Ihren Computer.

Das heißt auch: Das Tool funktioniert offline, sobald die Seite geladen ist. Sie können Farben in einem Flugzeug, in einem Besprechungsraum oder überall ohne Verbindung entnehmen.

Wenn Sie mit sensiblen Markenassets arbeiten, ist die lokale Verarbeitung das entscheidende Merkmal. Kein Upload bedeutet: Es liegt keine Kopie der Datei auf einem Server, den Sie nicht kontrollieren.

Farben aus Verläufen und Mustern entnehmen

Verläufe sind ein Sonderfall, weil sich die Farbe von einem Ende zum anderen stufenlos ändert. In einem Verlauf gibt es keine einzelne richtige Farbe – nur die Farbe genau an der Stelle, die Sie abtasten.

Um einen Verlauf zu erfassen, tasten Sie mehrere Punkte entlang seiner Länge ab. Nehmen Sie die Startfarbe, die Mittelfarbe und die Endfarbe, und Sie können den Verlauf in CSS mit diesen drei Stops nachbauen.

Muster brauchen dieselbe Sorgfalt. Eine gestreifte oder karierte Fläche enthält mindestens zwei Farben, und der Farbwähler liest nur das Pixel unter Ihrem Cursor – nicht das Muster als Ganzes.

Bei einem Muster tasten Sie jeden einzelnen Streifen separat ab und speichern alle als Farbfelder. Die Farbfeldsammlung beschreibt dann das Muster, auch wenn kein einzelner Klick das könnte.

Texturierte Oberflächen wie Holz, Stoff oder Stein sind der schwierigste Fall überhaupt. Ihre Farbe variiert von Pixel zu Pixel, sodass eine einzelne Messung fast bedeutungslos ist.

Bei Texturen tasten Sie fünf oder sechs benachbarte Pixel ab und suchen den Durchschnitt. Der häufigste Wert in der Gruppe ist die beste einzelne Repräsentation dieser Oberfläche – und er wird in Ihrem Design richtig aussehen.

So nutzen Sie den Farbwähler

Öffnen Sie den Farbwähler in Ihrem Browser. Ziehen Sie Ihr Bild in den Upload-Bereich oder fügen Sie einen Screenshot direkt aus der Zwischenablage ein.

Eine Standardfarbe erscheint, sobald das Bild geladen ist – entnommen aus der Mitte des Bildes. Bewegen Sie den Cursor, um das Bild zu erkunden, und beobachten Sie, wie die Lupe die Pixel unter Ihrem Zeiger vergrößert.

Klicken Sie auf ein beliebiges Pixel, um es zu Ihren ausgewählten Farbfeldern hinzuzufügen. Klicken Sie weiter, um alle Farben zu sammeln, die Sie für Ihr Design brauchen.

Wenn Ihre Sammlung vollständig ist, klicken Sie auf „CSS exportieren“, um die Farben als Stylesheet-Variablen herunterzuladen. Die Schritt-für-Schritt-Version finden Sie in Farbe aus einem Bild auswählen: So geht es, und die Codeformate erklärt HEX vs. RGB vs. HSL: Farbcodes erklärt.

Häufige Fragen

Was ist der Unterschied zwischen dem Entnehmen einer Farbe und dem Extrahieren einer Palette?

Beim Entnehmen lesen Sie ein exaktes Pixel aus, das Sie selbst wählen – Sie bestimmen also genau, welche Farbe Sie bekommen. Beim Extrahieren scannt das Tool das ganze Bild und sortiert automatisch die häufigsten Farben. Nutzen Sie den Farbwähler für exakte Markenfarben und den Extraktor, wenn Sie eine fertige Palette aus einem Foto wollen.

Warum liefern zwei Klicks auf dieselbe Stelle leicht unterschiedliche HEX-Codes?

In Fotos sind benachbarte Pixel wegen Kamerarauschen und JPEG-Komprimierung selten identisch. Jedes Pixel hat seine eigene Farbe, sodass ein Pixel weiter zur Seite schon die letzte Ziffer ändern kann. Tasten Sie die Mitte einer ebenen Fläche ab und nehmen Sie den Wert, der am häufigsten vorkommt.

Kann ich ausgewählte Farben direkt in einem Website-Stylesheet verwenden?

Ja. Die Schaltfläche „CSS exportieren“ lädt Ihre Farbfelder als CSS-Variablen mit HEX-Werten herunter. Fügen Sie sie in Ihr Stylesheet ein und verwenden Sie die Variablen überall dort, wo Sie diese Farbe brauchen. Die HEX-Codes funktionieren auch in jedem Design-Tool, das eingefügte Farbwerte akzeptiert.

Verändert oder komprimiert der Farbwähler mein Bild?

Nein. Das Tool liest nur Pixelwerte und verändert, speichert oder komprimiert Ihre Datei nie. Ihr Originalbild bleibt unberührt, und Sie können die Seite schließen und wissen, dass die Datei auf Ihrem Gerät genau so ist wie vorher.

Wie entnehme ich eine Farbe von einer Website, von der ich kein Bild herunterladen kann?

Machen Sie einen Screenshot der Seite und fügen Sie ihn dann mit Strg+V in das Tool ein – oder laden Sie die Screenshot-Datei hoch. Der Farbwähler liest die Screenshot-Pixel wie jedes andere Bild, sodass Sie Buttons, Hintergründe und Textfarben von jeder Website abtasten können.

Was soll ich tun, wenn die entnommene Farbe in meinem Design-Tool anders aussieht?

Prüfen Sie zuerst, ob Sie den vollständigen HEX-Code kopiert haben, ohne eine Ziffer zu vergessen. Denken Sie dann daran, dass Monitore und Farbprofile variieren – derselbe Code kann auf zwei Bildschirmen leicht anders aussehen. Vertrauen Sie dem Code selbst und vergleichen Sie ihn auf demselben Bildschirm mit dem Originalbild.
