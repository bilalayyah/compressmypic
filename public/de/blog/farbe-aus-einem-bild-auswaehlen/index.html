Farbe aus einem Bild auswählen: So geht es

Entnehmen Sie in vier Schritten eine exakte Farbe aus jedem Foto, Logo oder Screenshot: Lupe nutzen, Farbfelder aufbauen und CSS exportieren.

Sie haben in einem Foto oder einem Screenshot die perfekte Farbe gefunden und brauchen jetzt ihren Code. Raten kostet Zeit, und ein fast richtiger Farbton sieht neben dem Original falsch aus.

Diese Anleitung führt Sie in vier praktischen Schritten durch das Entnehmen einer Farbe aus einem Bild. Sie laden das Bild hoch, zielen mit der Lupe, speichern die Farbe und exportieren sie für Ihr Projekt.

Der ganze Vorgang dauert unter einer Minute, wenn man ihn einmal kennt. Keine Software zu installieren, kein Konto anzulegen und keine Datei, die auf einen Server hochgeladen wird.

Was Sie brauchen, bevor Sie starten

Sie brauchen das Bild, das die Farbe enthält. Ein Foto, eine Logodatei, ein Screenshot oder ein Design-Mockup funktionieren alle – in JPG, PNG, WebP oder GIF.

Die Datei kann bis zu 20 MB groß sein – das deckt Handyfotos und hochauflösende Screenshots problemlos ab. Wenn Ihre Datei größer ist, komprimieren Sie sie zuerst oder machen Sie einen frischen Screenshot.

Sie brauchen außerdem einen Browser. Das Tool läuft in Chrome, Safari, Firefox und Edge, auf dem Desktop und auf dem Handy – ohne Erweiterung oder Plugin.

Und wissen Sie ungefähr, wo die Farbe im Bild liegt. Eine grobe Vorstellung vom Ort spart Zeit, besonders in einem vollen Foto mit vielen ähnlichen Farbtönen.

Schritt 1: Bild hochladen oder Screenshot einfügen

Öffnen Sie den Farbwähler und ziehen Sie Ihr Bild in den Upload-Bereich. Sie können auch auf den Bereich klicken, um eine Datei auf Ihrem Gerät auszuwählen.

Wenn die Farbe gerade auf Ihrem Bildschirm zu sehen ist, machen Sie einen Screenshot und fügen Sie ihn mit Strg+V unter Windows oder Cmd+V auf dem Mac ein. Das Tool akzeptiert Bilder direkt aus der Zwischenablage.

Das Bild erscheint im Farbwähler, sobald es geladen ist. Eine Farbe wird sofort angezeigt – entnommen aus der Mitte des Bildes –, sodass Sie wissen, dass das Tool bereit ist.

Wenn Sie die falsche Datei hochgeladen haben, wechseln Sie im Tool einfach zu einem anderen Foto. Ihre bisherigen Farbfelder bleiben erhalten, sodass Sie bei Bedarf auch über mehrere Bilder hinweg sammeln können.

Schritt 2: Mit der Vergrößerungslupe zielen

Bewegen Sie den Cursor über das Bild und beobachten Sie die 11×11-vergrößerte Lupe. Sie zeigt ein vergrößertes Raster der Pixel rund um Ihren Zeiger, mit dem Zielpixel in der Mitte.

Werden Sie langsamer, wenn Sie sich der gewünschten Farbe nähern. Die Lupe lässt Sie den Unterschied zwischen der festen Mitte einer Form und ihrer verlaufenden Kante erkennen.

Zielen Sie auf die Mitte einer ebenen Fläche. Ein Button, eine Wand oder ein Farbblock ist in der Mitte einfarbig und an den Rändern vermischt – die Mitte liefert also den wahren Wert.

Behalten Sie den Pixel-Inspektor im Blick, während Sie sich bewegen. Er zeigt die exakten Koordinaten sowie die aktuellen HEX-, RGB-, HSL- und CMYK-Werte für das Pixel unter Ihrem Cursor.

Schritt 3: Klicken, um das Farbfeld zu speichern

Wenn die Lupe das richtige Pixel zeigt, klicken Sie darauf. Die Farbe landet in Ihrer Ablage „Ausgewählte Farbfelder“, und ihre Codes werden zum Kopieren angezeigt.

Klicken Sie auf den HEX-Code, um ihn zu kopieren. HEX ist das Format, das die meisten brauchen, da es direkt in CSS, Figma, Canva und die meisten Design-Tools passt.

Sammeln Sie alle Farben, die Sie brauchen, bevor Sie die Seite verlassen. Ein vollständiges Set kann die Hauptfarbe, einen Akzent, eine Hintergrundfarbe und eine Textfarbe aus demselben Bild umfassen.

Wenn zwei Farbfelder identisch aussehen, speichert das Tool kein Duplikat. Wenn Sie zweimal auf denselben HEX-Wert klicken, erhalten Sie einen sauberen Eintrag statt zwei.

Schritt 4: CSS exportieren oder Codes kopieren

Wenn Ihre Farbfelder vollständig sind, klicken Sie auf „CSS exportieren“. Das Tool lädt eine Datei mit Ihren Farben als CSS-Variablen herunter – fertig zum Einfügen in ein Stylesheet.

Wenn Sie nur eine Farbe brauchen, kopieren Sie stattdessen ihren HEX-Code direkt aus dem Inspektor. Das geht schneller, als für einen einzelnen Wert eine Datei herunterzuladen.

Für Druckarbeiten notieren Sie die CMYK-Werte, die für jede Entnahme angezeigt werden. Sie sind eine erste Annäherung – nützlich, um einen Printdesigner vor einer echten Umwandlung zu informieren.

Testen Sie die Farbe sofort in Ihrem Projekt. Fügen Sie den Code ein, betrachten Sie ihn neben dem Originalbild und vergewissern Sie sich, dass er passt, bevor Sie etwas darauf aufbauen.

Eine Farbe aus einem Foto entnehmen

Fotos brauchen eine etwas andere Herangehensweise als flache Grafiken. Kamerarauschen und JPEG-Komprimierung bedeuten, dass benachbarte Pixel variieren – ein Klick erzählt also selten die ganze Geschichte.

Tasten Sie denselben Bereich drei- oder viermal ab und bewegen Sie sich dabei jedes Mal um ein oder zwei Pixel. Wenn die Codes in den ersten fünf Ziffern übereinstimmen, haben Sie die echte Farbe gefunden.

Wählen Sie die größte ebene Fläche, die Sie finden können. Ein klarer Himmel, eine gestrichene Tür oder ein einfarbiges Hemd liefert eine deutlich stabilere Messung als eine texturierte Oberfläche.

Halten Sie sich von hellen Glanzlichtern und tiefen Schatten fern. Diese Zonen verlieren Farbinformation, und der Code, den Sie dort ablesen, ist oft einfach Weiß, Schwarz oder Grau.

Eine Farbe aus einem Logo entnehmen

Logos verlangen Präzision, denn eine Markenfarbe, die um eine Ziffer danebenliegt, sieht trotzdem falsch aus. Beginnen Sie mit der hochwertigsten Logodatei, die Sie haben – idealerweise einem PNG.

PNG-Dateien speichern exakte Farben, also ist die Messung vertrauenswürdig. JPEG-Logos tragen Komprimierungsrauschen, das die letzte Ziffer des HEX-Codes verschieben kann.

Tasten Sie die Mitte der größten ebenen Form im Logo ab. Die Mitte eines Buchstabens oder eines Blocks ist einfarbig, während die Kanten in den Hintergrund übergehen.

Prüfen Sie das Ergebnis, indem Sie die entnommene Farbe auf demselben Bildschirm neben das Logo legen. Wenn sie übereinstimmen, haben Sie die Markenfarbe. Wenn nicht, versuchen Sie es ein oder zwei Pixel weiter innen.

Eine Farbe aus einem Screenshot entnehmen

Screenshots sind die schnellste Quelle für UI-Farben. Nehmen Sie den Bildschirm auf, fügen Sie ihn mit Strg+V ein und tasten Sie den Button, die Kopfzeile oder den Hintergrund direkt ab.

Nutzen Sie die Lupe bei Screenshots sorgfältig. Elemente der Benutzeroberfläche haben weichgezeichnete Kanten, also sind die Randpixel eine Mischung aus Element und Hintergrund.

Für Textfarben tasten Sie den dicksten Teil eines Buchstabens ab, etwa die Mitte eines fetten Strichs. Dünner Text besteht größtenteils aus Randpixeln, die als Mischwerte gelesen werden.

Notieren Sie sich die Pixelkoordinaten, während Sie arbeiten. Wenn ein Teammitglied einen Wert anzweifelt, können Sie beide an exakt dieselbe Stelle zurückkehren und ihn bestätigen.

Eine Farbe auf dem Handy oder Tablet entnehmen

Auf einem Touchscreen tippen Sie statt zu klicken, und dieselben Lupen- und Farbfeld-Tools stehen zur Verfügung. Laden Sie das Bild aus Ihrer Galerie hoch oder fügen Sie einen Screenshot ein.

Ihre Fingerspitze bedeckt viele Pixel – vergrößern Sie also zuerst das Bild. Ein größeres Bild gibt Ihnen ein größeres Ziel und eine bessere Chance, das richtige Pixel zu treffen.

Nutzen Sie die Lupe zur Bestätigung, bevor Sie tippen. Sie zeigt, was unter Ihrem Finger liegt – etwas, das Sie nicht sehen können, solange Ihr Finger auf dem Bildschirm ist.

Für eine Farbe, die exakt sein muss, etwa eine Markenfarbe, machen Sie die Endkontrolle auf einem Desktop. Ein Mausklick auf ein Pixel ist verlässlicher als ein Fingertipp.

Fehlersuche: Wenn die Farbe falsch aussieht

Wenn die entnommene Farbe zu hell oder zu dunkel aussieht, haben Sie wahrscheinlich ein Glanzlicht oder einen Schatten erwischt. Bewegen Sie sich zur Mitte der Form und versuchen Sie es erneut.

Wenn die Farbe trüb aussieht, haben Sie vermutlich eine weichgezeichnete Kante erwischt. Bewegen Sie sich ein oder zwei Pixel nach innen, wo die Farbe fest und unvermischt ist.

Wenn sich der HEX-Code bei jedem Klick ändert, ist der Bereich verrauscht. Tasten Sie mehrere benachbarte Pixel ab und nehmen Sie den Wert, der am häufigsten vorkommt.

Wenn die Farbe im Farbwähler richtig, in Ihrem Design-Tool aber falsch aussieht, prüfen Sie den eingefügten Code. Eine fehlende Ziffer oder ein vertauschtes Zeichen ist die übliche Ursache – nicht der Farbwähler.

Die entnommene Farbe in Ihrem Projekt verwenden

Auf einer Website fügen Sie den HEX-Code in Ihr CSS ein oder nutzen die exportierten Variablen. Der Variablen-Ansatz hält Ihre Farben auf der ganzen Website konsistent.

In Figma, Canva oder Photoshop fügen Sie den HEX-Code in das Farbfeld ein. Jedes große Design-Tool akzeptiert HEX, sodass der Wert ohne Umwandlung übertragen wird.

Für eine Präsentation oder ein Dokument nutzen Sie die RGB-Werte. Office-Tools zeigen Farben oft als drei Zahlen an, und die RGB-Ausgabe passt genau zu diesem Format.

Für den Druck gehen Sie von der CMYK-Annäherung aus und stimmen sich mit Ihrer Druckerei ab. Bildschirme und Drucker geben Farben unterschiedlich wieder – ein Probedruck lohnt sich also.

Eine vollständige Palette aus einem Bild aufbauen

Ein Bild kann eine ganze Palette liefern. Nehmen Sie die dominante Hintergrundfarbe, die Hauptfarbe des Motivs, einen Akzent und einen dunklen Ton für Text.

Halten Sie die Anzahl klein. Vier bis sechs Farben reichen für die meisten Designs, und mehr als das lässt ein Layout meist unruhig wirken.

Prüfen Sie die Farbfelder vor dem Export gemeinsam. Wenn zwei Farben fast identisch sind, entfernen Sie eine. Wenn das Set unausgewogen wirkt, tauschen Sie eine Entnahme gegen einen helleren oder dunkleren Ton.

Wenn Sie stattdessen die Gesamtansicht des Bildes wollen, versuchen Sie das Farbpaletten-Tool. Es sortiert die dominanten Farben automatisch – ein schneller Weg, um Ihre handverlesene Auswahl zu vergleichen.

Farben aus Diagrammen und Datenvisualisierungen entnehmen

Diagramme und Grafiken nutzen Farbe, um Datenreihen zu trennen, und es ist wichtig, diese Farben zu treffen, wenn Sie einen Bericht oder ein Dashboard auf denselben Daten aufbauen. Der Farbwähler kann jede Reihenfarbe aus einem Diagrammbild wiederherstellen.

Tasten Sie die Mitte jedes Balkens, jeder Linie oder jedes Tortensegments ab – weit weg von den Kanten, wo Farben in den Hintergrund übergehen. Ein dicker Balken lässt sich leicht abtasten, während eine dünne Linie die Lupe braucht, um ihre Mitte zu treffen.

Arbeiten Sie zuerst die Legende ab, denn sie zeigt jede Reihenfarbe meist als festen Block. Diese Blöcke sind die saubersten Entnahmen im ganzen Diagramm.

Wenn zwei Reihenfarben fast identisch aussehen, prüfen Sie ihre HEX-Codes, bevor Sie sich entscheiden. Farben, die auf dem Bildschirm gleich aussehen, können sich genug unterscheiden, um etwas auszumachen, wenn sie in Ihrem eigenen Diagramm nebeneinander sitzen.

Speichern Sie die Reihenfarben in der Reihenfolge der Legende. So behält Ihr neues Diagramm dieselbe Farb-zu-Reihen-Zuordnung, und Leser, die das Original gesehen haben, werden nicht verwirrt.

Für Dashboards entnehmen Sie auch die Hintergrund- und Gitterlinienfarben. Ein Dashboard, das den originalen Hintergrund und die originalen Gittertöne wiederverwendet, wirkt durchdacht – eines, das sie errät, wirkt leicht daneben.

Entnommene Farben speichern und organisieren

Entnommene Farben nützen nur etwas, wenn Sie sie später wiederfinden. Der CSS-Export per Download ist die einfachste Art, ein Set zu speichern, denn er legt jedes Farbfeld in einer Datei mit klaren Variablennamen ab.

Benennen Sie Ihre Exportdatei nach dem Projekt, nicht nach dem Datum. Eine Datei namens homepage-refresh-colors.css ist Monate später nützlich, während colors-2026-11-17.css nichts darüber sagt, wohin die Farben gehören.

Wenn Sie ein Design-Tool nutzen, fügen Sie die HEX-Codes auch in dessen Farbstile oder Variablen ein. Wenn dieselben Werte sowohl im Stylesheet als auch in der Designdatei stehen, driften die beiden nicht auseinander.

Für Markenfarben notieren Sie die RGB- und CMYK-Werte neben dem HEX-Code in Ihrem Brand-Guide. Verschiedene Teams brauchen verschiedene Formate, und ein Guide, der alle aufführt, verhindert, dass Leute Werte nebenbei umrechnen und dabei Fehler machen.

Notieren Sie kurz bei jeder Palette, woher die Farben stammen. Ein Satz wie „entnommen aus dem Herbstkampagnen-Foto“ sagt einem künftigen Designer, warum diese Farben zusammengehören.

Sichern Sie Ihre exportierte CSS-Datei schließlich mit dem Rest des Projekts. Eine Palette, die nur in einem Browser-Tab lebt, verschwindet in dem Moment, in dem der Tab geschlossen wird – und dieselben Pixel ein zweites Mal zu entnehmen, ist Zeitverschwendung.

Kurzanleitung als Checkliste

Laden Sie die sauberste Originaldatei hoch, die Sie haben – keinen Screenshot von einem Screenshot. Jede zusätzliche Speicherung kann Farben leicht verschieben.

Zielen Sie mit der Lupe, tasten Sie die Mitte ebener Flächen ab und klicken Sie zwei oder drei benachbarte Pixel an, um den Wert zu bestätigen.

Kopieren Sie den HEX-Code für Web- und Designarbeiten, die RGB-Werte für Dokumente und die CMYK-Annäherung für Druckbriefings.

Exportieren Sie CSS, wenn Sie mehr als ein Farbfeld haben, und prüfen Sie die Farbe in Ihrem Projekt, bevor Sie darauf aufbauen. Den vollständigen Hintergrund finden Sie in Farbe aus einem Bild auslesen: Die komplette Anleitung und den Formatvergleich in HEX vs. RGB vs. HSL: Farbcodes erklärt.

Häufige Fragen

Wie viele Farben kann ich aus einem Bild entnehmen?

Es gibt praktisch keine Grenze dafür, wie viele Farbfelder Sie in einer Sitzung sammeln können. Nehmen Sie so viele, wie Ihr Design braucht – vier bis sechs Farben reichen aber meist für eine stimmige Palette. Wenn Sie zweimal auf denselben HEX-Wert klicken, entsteht kein doppelter Eintrag.

Muss ich etwas installieren, um eine Farbe aus einem Bild zu entnehmen?

Nein. Der Farbwähler läuft vollständig in Ihrem Browser – in Chrome, Safari, Firefox und Edge. Es gibt keine Erweiterung, kein Plugin und kein Konto. Öffnen Sie die Tool-Seite, laden Sie Ihr Bild hoch und fangen Sie an zu klicken.

Kann ich eine Farbe aus einem Videobild oder einem pausierten Video entnehmen?

Ja, indirekt. Pausieren Sie das Video, machen Sie einen Screenshot des Bildes und fügen Sie den Screenshot mit Strg+V in den Farbwähler ein. Das Tool liest Screenshot-Pixel wie jedes andere Bild, sodass Sie Farben aus jedem Einzelbild entnehmen können.

Warum zeigt die Lupe ein Raster statt des normalen Bildes?

Die Lupe vergrößert die Pixel rund um Ihren Cursor, damit Sie jedes einzelne sehen können. Das Raster macht deutlich, welches Pixel in der Mitte liegt und welche daneben sitzen. Genau diese Präzision lässt Sie vermischte Randpixel vermeiden.

Welche Bildformate funktionieren mit dem Farbwähler?

JPG-, PNG-, WebP- und GIF-Dateien funktionieren, jeweils bis zu 20 MB. PNG ist die beste Wahl, wenn Exaktheit zählt, denn es speichert Farben ohne Komprimierungsrauschen. Sie können auch Screenshots direkt aus der Zwischenablage einfügen.

Kann ich auf meinem Handy Farben aus einem Bild entnehmen?

Ja. Laden Sie das Bild aus Ihrer Galerie hoch und tippen Sie auf die gewünschte Farbe. Die Lupe hilft Ihnen trotz der Größe einer Fingerspitze beim Zielen. Für markenkritische Farben prüfen Sie den endgültigen Wert mit einem Mausklick auf einem Desktop.
