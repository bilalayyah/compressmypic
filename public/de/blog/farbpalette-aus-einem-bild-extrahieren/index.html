Farbpalette aus Foto extrahieren

Extrahieren Sie in fünf Schritten eine Farbpalette aus jedem Foto: hochladen, 3–12 Farbfelder wählen, Prozente lesen und CSS oder JSON kopieren.

Sie haben ein Foto mit Farben, die Sie lieben, und brauchen diese Farben als Palette für eine Website, ein Poster oder eine Marke. Sie mit dem Auge zu kopieren, ist langsam und ungenau.

Diese Anleitung führt Sie in fünf Schritten durch das Extrahieren einer Farbpalette aus einem Bild: hochladen, die Farbfeldanzahl wählen, die Prozente lesen und das Ergebnis kopieren oder herunterladen.

Der ganze Vorgang dauert unter einer Minute, wenn man ihn einmal kennt. Keine Software zu installieren, kein Konto anzulegen und keine Datei, die auf einen Server hochgeladen wird.

Was Sie brauchen, bevor Sie starten

Sie brauchen das Bild, das die Farben enthält, im JPG-, PNG- oder WebP-Format, bis zu 20 MB. Ein Foto, eine Produktaufnahme, ein Screenshot oder ein Kunstwerk funktionieren alle.

Wissen Sie, wofür die Palette gedacht ist. Ein Website-Theme braucht vier bis sechs Farben, eine Markenidentität ein paar mehr, und ein Moodboard kann die vollen zwölf nutzen.

Ein Browser ist die einzige Software, die Sie brauchen. Das Tool läuft in Chrome, Safari, Firefox und Edge, auf Desktop und Handy, ohne Erweiterung.

Und nutzen Sie die sauberste Originaldatei, die Sie haben. Eine erneut komprimierte Kopie oder ein Screenshot des Fotos kann Pixelwerte leicht verschieben und die resultierende Palette verändern.

Schritt 1: Bild hochladen oder Screenshot einfügen

Öffnen Sie das Farbpaletten-Tool und ziehen Sie Ihr Bild in den Upload-Bereich. Sie können auch auf den Bereich klicken, um eine Datei auf Ihrem Gerät auszuwählen.

Wenn die Farben gerade auf Ihrem Bildschirm zu sehen sind, machen Sie einen Screenshot und fügen Sie ihn mit Strg+V ein. Das Tool akzeptiert Bilder direkt aus der Zwischenablage, sodass Sie eine Palette aus jeder Website oder App extrahieren können, die Sie gerade ansehen.

Die Palette erscheint, sobald das Bild geladen ist – beginnend mit dem Standard von 6 Farbfeldern. Jedes Farbfeld zeigt seine Farbe, seine Codes und den Prozentsatz des Bildes, den es abdeckt.

Wenn Sie die falsche Datei hochgeladen haben, wechseln Sie im Tool zu einem anderen Foto. Die alte Palette wird ersetzt, und Sie können weiterarbeiten, ohne die Seite neu zu laden.

Schritt 2: Wählen, wie viele Farbfelder Sie wollen

Bewegen Sie den Schieberegler, um die Farbfeldanzahl zwischen 3 und 12 einzustellen. Die Palette baut sich bei jeder Bewegung sofort neu auf, sodass Sie Anzahlen in Sekunden vergleichen können.

Beginnen Sie mit 6 und schauen Sie sich das Ergebnis an. Wenn zwei Farbfelder fast identisch aussehen, senken Sie die Anzahl auf 4 oder 5 und beobachten Sie, wie die Duplikate zu einer saubereren Farbe verschmelzen.

Wenn eine Akzentfarbe fehlt, die Ihnen wichtig ist, erhöhen Sie die Anzahl Richtung 12. Mehr Farbfelder geben kleinen Details ihre eigenen Kästen, sodass ein winziges Neonschild oder eine kleine Blume erscheinen kann.

Es gibt keine einzelne richtige Anzahl. Eine minimale Website will 3 oder 4, ein reichhaltiges Markenboard will 8 oder 10, und der Schieberegler existiert, damit Sie die Zahl finden, die zu Ihrem Projekt passt.

Schritt 3: Die Prozente und den Streifen lesen

Jedes Farbfeld trägt ein Prozent-Abzeichen, das zeigt, wie viel des Bildes diese Farbe abdeckt. Der größte Prozentsatz ist die dominante Farbe, und die kleinsten sind die Akzente.

Lesen Sie die Prozente als Hierarchie für Ihr Design. Die dominante Farbe sollte den meisten Raum einnehmen, die sekundäre Farbe eine unterstützende Rolle und die kleinsten Farben nur die Highlights.

Schauen Sie sich den proportionalen Farbstreifen unter den Farbfeldern an. Er zeigt dieselbe Hierarchie als Balken, wobei die Segmentbreiten den Prozenten entsprechen – was die Balance leicht beurteilbar macht.

Wenn der Streifen größtenteils eine Farbe ist, hat das Foto einen starken dominanten Ton, und Ihr Design wird ruhig wirken. Wenn der Streifen gleichmäßig unterteilt ist, ist das Foto lebhaft, und Ihr Design braucht anderswo Zurückhaltung.

Schritt 4: Die Palette als CSS oder JSON kopieren

Klicken Sie auf „CSS kopieren“, um alle Farbfelder als CSS-Variablen zu kopieren. Die Variablen sind der Reihe nach benannt, jede mit einem HEX-Wert, und sie fügen sich direkt in ein Stylesheet ein.

Klicken Sie auf „JSON kopieren“, wenn die Palette in Code statt in ein Stylesheet einfließt. Das JSON enthält die HEX-, RGB- und HSL-Werte jeder Farbe plus ihren Prozentanteil, in einer Form, die ein Skript parsen kann.

Ändern Sie die Farbfeldanzahl, und die Exporte aktualisieren sich. Sie können von 6 Farben auf 4 wechseln, ohne erneut hochzuladen, und das kopierte CSS oder JSON spiegelt den neuen Satz sofort wider.

Speichern Sie den Export beim Projekt. Eine Palette, die nur in einem Browser-Tab lebt, verschwindet, wenn der Tab geschlossen wird, während eine gespeicherte Datei da ist, wenn das Projekt wieder aufgenommen wird.

Schritt 5: Die Palettenkarte herunterladen

Klicken Sie auf „Paletten-PNG herunterladen“, um eine Palettenkarte zu erzeugen: das Originalfoto mit dem Farbfeldstreifen und den Farben darunter. Es ist die visuelle Zusammenfassung der Extraktion.

Teilen Sie die Karte mit einem Kunden oder einem Team. Ein Bild der Palette kommuniziert schneller als eine Liste von HEX-Codes – besonders gegenüber Leuten, die keinen Code lesen.

Nutzen Sie die Karte in Moodboards, Markendokumenten und Präsentationen. Sie zeigt, woher die Farben kamen, was Vertrauen schafft, denn der Kunde kann das Quellfoto sehen.

Bewahren Sie die Karte bei den Projektdateien auf. Wenn die Palette Monate später infrage gestellt wird, zeigt die Karte Quelle und Begründung in einem Bild.

Eine Palette aus einem Foto extrahieren

Fotos sind die beste Quelle für Paletten, denn ihre Farben passen in der realen Welt bereits zusammen. Ein Sonnenuntergang, eine Straßenszene oder eine Produktaufnahme kann ein ganzes Schema liefern.

Beginnen Sie mit den größten ebenen Flächen des Fotos. Ein klarer Himmel, eine gestrichene Wand oder ein Kleidungsstück gibt eine stabile Farbe, die der Extraktor hoch und zuverlässig einstuft.

Passen Sie auf gemischtes Licht auf. Ein Foto mit warmem Sonnenlicht auf einer Seite und kühlem Schatten auf der anderen kann zwei Versionen derselben Farbe erzeugen, die in der Palette wie Duplikate aussehen.

Wenn das passiert, wählen Sie die Version, die zu der Stimmung passt, die Sie wollen. Die warme eignet sich für ein gemütliches Design, die kühle für ein frisches Design, und beide zu behalten, verwässert die Palette meist.

Eine Palette aus einem Logo extrahieren

Logos sind ein Präzisionsfall, denn eine Markenpalette muss exakt stimmen. Beginnen Sie mit der hochwertigsten Logodatei, die Sie haben – idealerweise einem PNG auf festem Hintergrund.

Transparente Hintergründe werden vom Extraktor gehandhabt, der vollständig transparente Pixel ignoriert. Doch ein Logo auf transparentem Hintergrund kann trotzdem seltsame Ergebnisse liefern, wenn die Kanten halbtransparent sind.

Für das sauberste Ergebnis legen Sie das Logo zuerst auf einen weißen oder markenfarbigen Hintergrund und extrahieren Sie aus dieser Version. Die Palette spiegelt dann die Logofarben wider, nicht die Transparenzbehandlung.

Verifizieren Sie die Schlüsselfarben anschließend mit dem Farbwähler. Der Farbwähler liest das exakte Pixel, was die Markenfarbe bestätigt, wenn der Extraktionswert leicht daneben aussieht.

Eine Palette aus einem Screenshot extrahieren

Screenshots sind der schnellste Weg, die Palette einer Website oder App zu erfassen, die Sie bewundern. Nehmen Sie den Bildschirm auf, fügen Sie ihn mit Strg+V ein, und die Palette erscheint.

Der Extraktor sortiert die Farben der Benutzeroberfläche nach Abdeckung, sodass der Hintergrund und die Hauptflächen dominieren, während Button- und Linkfarben als kleine Akzente erscheinen.

Seien Sie vorsichtig mit Text. Ein Screenshot voller Text erzeugt graue und schwarze Farbfelder aus den Buchstaben, die nicht Teil der Designpalette sind und ignoriert werden sollten.

Denken Sie an die Originalitätsfrage. Eine Palette, die von einer anderen Website inspiriert ist, ist in Ordnung, doch eine Konkurrenz-Markenpalette komplett zu kopieren, ist eine schlechte Wahl für Kundenarbeiten.

Wenn ein kleiner Akzent fehlt

Ein winziger Akzent kann aus einer Palette verschwinden, weil der Extraktor Farben nach Abdeckung sortiert. Ein Neonschild, das 1 Prozent eines Fotos abdeckt, kann in eine benachbarte Farbe gefaltet werden.

Erhöhen Sie zuerst die Farbfeldanzahl Richtung 12. Mehr Farbfelder geben kleinen Details ihre eigenen Kästen, sodass der Akzent eine bessere Chance hat, zu erscheinen.

Wenn er trotzdem nicht erscheint, greifen Sie ihn mit der Pipette. Der Farbwähler liest das exakte Pixel, und Sie können diese Farbe von Hand zur extrahierten Palette hinzufügen.

Notieren Sie den Akzentprozentsatz, wenn Sie ihn manuell hinzufügen. Ein 1-Prozent-Akzent ist eine Highlight-Farbe, keine Hauptfarbe, und ihn für große Flächen zu nutzen, wird das Design überwältigen.

Doppelte Farbtöne in der Palette reparieren

Zwei Farbfelder, die fast identisch aussehen, stammen meist aus einem Verlauf – etwa einem Himmel, der allmählich von Hellblau zu dunklerem Blau wechselt. Der Algorithmus teilt den Verlauf in zwei Kästen auf.

Behalten Sie den Farbton, der besser zu Ihrem Design passt, und entfernen Sie den anderen. Eine Palette mit einem Blau ist sauberer als eine Palette mit zwei Blau, die niemand unterscheiden kann.

Alternativ senken Sie die Farbfeldanzahl. Bei 6 Farben fällt der Verlauf meist in einen einzigen Kasten, und das Duplikat verschwindet ohne manuelle Bearbeitung.

Wenn Sie ein Duplikat entfernen, prüfen Sie die Prozente. Die behaltene Farbe sollte in Ihrem Design den kombinierten Anteil tragen, denn die beiden Farbtöne zusammen deckten so viel vom Foto ab.

Die Palette in Figma, Canva und CSS nutzen

In Figma fügen Sie jeden HEX-Code in einen Farbstil ein. Erstellen Sie einen Stil pro Farbfeld, benannt nach seiner Rolle – etwa Hintergrund, Primärfarbe und Akzent –, damit das Team sie konsistent nutzt.

In Canva fügen Sie die HEX-Codes in das Brand-Kit oder in den Farbwähler für jedes Element ein. Die Palette bleibt dann über jedes Design im Konto hinweg verfügbar.

In CSS fügen Sie die kopierten Variablen in Ihr Stylesheet ein und verweisen überall auf die Variablen. Eine variablenbasierte Palette ist leicht zu aktualisieren, denn das Ändern eines Werts aktualisiert die ganze Website.

Für ein Designsystem speichern Sie den JSON-Export als Quelle der Wahrheit. Eine Token-Pipeline kann ihn lesen und daraus CSS, Figma-Variablen und Dokumentation aus derselben Datei erzeugen.

Die Anzahl wechseln, ohne erneut hochzuladen

Sie können die Farbfeldanzahl jederzeit ändern, ohne das Bild erneut hochzuladen. Bewegen Sie den Schieberegler, und die Palette baut sich aus denselben Bilddaten sofort neu auf.

Das ist nützlich, um Anzahlen zu vergleichen. Versuchen Sie 4, dann 6, dann 8 und beobachten Sie, wie die Palette Details gewinnt und dann anfängt, Farbtöne zu duplizieren. Die richtige Anzahl liegt meist direkt bevor die Duplikate erscheinen.

Kopieren Sie das CSS oder JSON nach jeder Änderung, wenn Sie mehrere Versionen behalten wollen. Der Export spiegelt immer die aktuelle Anzahl wider, sodass eine Version, die Ihnen gefallen hat, verloren gehen kann, wenn Sie den Schieberegler erneut bewegen.

Das Hochladen eines neuen Bildes löscht die alte Palette automatisch. Das hält das Tool ordentlich, bedeutet aber, dass Sie jede Palette, die Sie behalten wollen, speichern sollten, bevor Sie Bilder wechseln.

Eine Palette aus Produktfotos extrahieren

Produktfotos sind ein Sonderfall, denn die Palette muss dem Produkt dienen, nicht nur dem Foto. Eine Produktaufnahme auf weißem Hintergrund gibt eine Palette, die von Weiß dominiert wird – was wenig über das Produkt selbst sagt.

Für Produktarbeiten extrahieren Sie stattdessen aus einer Lifestyle-Aufnahme statt aus einer Studioaufnahme. Ein Produkt, das in Gebrauch fotografiert wurde – in einem Raum oder draußen –, trägt die Farben seines Kontexts, und diese Farben ergeben eine bessere Palette.

Wenn nur eine Studioaufnahme existiert, schneiden Sie das Produkt vor dem Extrahieren eng zu. Das Entfernen des weißen Hintergrunds zwingt den Extraktor, die Produktfarben statt des leeren Raums darum herum zu sortieren.

Prüfen Sie die Palette gegen die Produktfarben, die Sie kennen. Wenn die Markenfarbe des Produkts fehlt oder verschoben ist, verifizieren Sie sie mit der Pipette und fügen Sie sie von Hand zur Palette hinzu.

Produktpaletten fließen in Listings, Verpackungen und Werbung ein, sodass Konsistenz wichtiger ist als sonst. Speichern Sie den CSS- oder JSON-Export bei den Produktdateien und nutzen Sie dieselbe Palette über jeden Kanal hinweg, in dem das Produkt erscheint.

Für eine Produktreihe extrahieren Sie eine Palette aus jedem Produkt und vergleichen Sie sie. Produkte, die eine Palettenfamilie teilen, sehen aus wie eine Reihe, während Produkte mit unzusammenhängenden Paletten wie eine zufällige Ansammlung aussehen.

Saisonale Produkte verdienen saisonale Paletten. Eine Sommer-Produktaufnahme gibt helle, warme Farben, während die Winterversion desselben Produkts tiefere Töne gibt – und die Palette sollte sich mit der Saison ändern.

Testen Sie die Palette schließlich auf dem Marktplatz-Listing selbst. Eine Palette, die in einem Design-Tool gut aussieht, kann gegen den weißen Hintergrund und die Interface-Farben des Marktplatzes scheitern – prüfen Sie sie also vor dem Launch an Ort und Stelle.

Kurzanleitung als Checkliste

Laden Sie das sauberste Original hoch, stellen Sie die Farbfeldanzahl ein, lesen Sie die Prozente und den Streifen, kopieren Sie dann CSS oder JSON und laden Sie die Palettenkarte herunter.

Bereinigen Sie Fast-Duplikate, retten Sie fehlende Akzente mit der Pipette und speichern Sie den Export beim Projekt, bevor Sie den Tab schließen.

Häufige Fragen

Wie wähle ich aus, welche extrahierten Farben ich tatsächlich nutze?

Beginnen Sie mit der größten Prozentfarbe als Ihrer dominanten, nehmen Sie die zweitgrößte als Ihre sekundäre und nutzen Sie die kleinsten als Akzente. Vier bis sechs Farben reichen für die meisten Designs. Entfernen Sie Fast-Duplikate und jede Farbe, die nicht zur Stimmung passt – auch wenn sie hoch eingestuft ist.

Kann ich eine Palette aus einem Videostandbild oder einem Filmbild extrahieren?

Ja. Machen Sie einen Screenshot des Bildes, fügen Sie ihn in den Extraktor ein, und die Palette erscheint. Filmstills sind ausgezeichnete Quellen, weil Kameraleute ihre Farbschemata sorgfältig gestalten. Nutzen Sie die Palette als Inspiration, statt einen Filmlook komplett für Kundenarbeiten zu kopieren.

Warum summieren sich die Prozente nicht auf 100 Prozent?

Meistens tun sie das, innerhalb der Rundung. Jeder Farbfeldprozentsatz wird auf eine ganze Zahl gerundet, sodass die angezeigten Werte insgesamt 99 oder 101 Prozent ergeben können. Die zugrunde liegenden Anteile sind exakt, und die Rundung betrifft nur die Anzeige.

Was ist der Unterschied zwischen der Palettenkarte und dem CSS-Export?

Die Palettenkarte ist ein PNG-Bild, das das Foto mit seinen Farbfeldern zeigt – gemacht zum Teilen mit Menschen. Der CSS-Export ist Text mit den Farbvariablen – gemacht zum Einfügen in Code. Nutzen Sie die Karte für Kunden und Präsentationen und das CSS für Entwickler.

Kann ich eine Palette aus einem Schwarz-Weiß-Bild extrahieren?

Ja, doch das Ergebnis werden Graustufen sein. Die Prozente zeigen trotzdem die Tonstruktur des Fotos, was nützlich ist, wenn Sie in Monochrom designen. Eine Graupalette aus einem starken Foto kann eine elegante Basis für ein minimalistisches Design sein.

Wie teile ich eine extrahierte Palette mit einem Kunden, der keine Design-Tools nutzt?

Laden Sie die Palettenkarten-PNG herunter und schicken Sie sie. Die Karte zeigt das Quellfoto mit den Farbfeldern darunter, sodass jeder die Farben sehen kann und woher sie kamen. Fügen Sie auch die HEX-Codes in der Nachricht hinzu, damit der Kunde sie später referenzieren kann.
