Favicon erstellen: Anleitung

Erstellen Sie in wenigen Minuten ein Favicon aus Ihrem Logo: Quellbild vorbereiten, Abstand und Hintergrund festlegen, helle und dunkle Tabs prüfen und das Paket auf Ihrer Website installieren.

Ein Favicon zu erstellen klingt technisch, dauert mit dem richtigen Tool aber nur wenige Minuten. Sie laden ein Logo hoch, stellen ein paar Einstellungen ein, laden ein Paket mit Dateien herunter und fügen ein kurzes Snippet in Ihre Website ein. Diese Anleitung führt Sie Schritt für Schritt durch den Ablauf.

Vor dem Start brauchen Sie nur zwei Dinge: eine Logo-Datei und Zugriff auf Ihre Website-Dateien. Ein quadratisches PNG- oder SVG-Logo eignet sich am besten, und die größte Version, die Sie haben, liefert das schärfste Ergebnis. Haben Sie nur ein JPG, funktioniert das ebenfalls.

Der Favicon-Generator erledigt die ganze Arbeit in Ihrem Browser. Ihr Logo verlässt Ihr Gerät nie, es gibt kein Konto zu erstellen, und das fertige Paket lädt als ZIP herunter. Folgen Sie den Schritten unten – schon hat Ihre Website einen kompletten Icon-Satz.

Schritt 1: Logo vorbereiten

Öffnen Sie Ihre Logo-Datei und prüfen Sie, ob sie quadratisch ist oder dem nahekommt. Eine quadratische Fläche nutzt den winzigen Favicon-Platz am besten, während ein breites, rechteckiges Logo leere Streifen über und unter der Marke hinterlässt. Ist Ihr Logo breit, schneiden Sie einen quadratischen Ausschnitt zu oder nutzen Sie eine Ein-Buchstaben-Version.

Prüfen Sie die Auflösung. Eine Quelle mit 512 mal 512 Pixeln oder mehr schrumpft sauber auf jede Favicon-Größe. Eine 64-Pixel-Quelle, auf 512 Pixel für Android gestreckt, wirkt weich – nutzen Sie also immer die größte Datei, die Sie haben. Eine SVG-Datei ist ideal, weil sie gar keine feste Auflösung hat.

Vereinfachen Sie das Motiv, falls es kleinen Text oder feine Details enthält. Ein Slogan unter einer Wortmarke überlebt 16 Pixel nicht – entfernen Sie ihn für die Favicon-Version. Behalten Sie das mutigste Element: das Symbol, den Anfangsbuchstaben oder die stärkste Form.

Hat Ihr Logo einen transparenten Hintergrund, lassen Sie ihn vorerst so. Transparenz gibt Ihnen im Generator die meisten Optionen, weil Sie eine Hintergrundfüllung später immer noch ergänzen können, falls die Vorschau zeigt, dass Sie eine brauchen. Ein JPG hat keine Transparenz – PNG oder SVG sind hier der bessere Startpunkt.

Schritt 2: In den Generator hochladen

Öffnen Sie den Favicon-Generator und ziehen Sie Ihr Logo in den Upload-Bereich oder klicken Sie, um die Datei auf Ihrem Gerät auszuwählen. Sie können ein kopiertes Bild auch direkt aus der Zwischenablage mit Strg und V einfügen – praktisch, wenn das Logo in einer anderen App geöffnet ist.

Das Tool akzeptiert PNG, SVG, JPG, WebP und HEIC bis 20 MB. Die meisten Logos sind deutlich kleiner als dieses Limit, die Größe ist also selten ein Problem. Stammt Ihre Datei von einem Smartphone-Foto im HEIC-Format, wird sie ohne zusätzlichen Schritt hochgeladen und umgewandelt.

Sobald die Datei geladen ist, erstellt der Generator eine Vorschau des Icon-Pakets. Sie sehen die Marke in mehreren Größen gerendert und können beurteilen, wie sie klein und groß wirkt. Sieht das Logo bei 16 Pixeln falsch aus, korrigieren Sie jetzt das Quellbild statt später.

Haben Sie ein rechteckiges Logo hochgeladen, passt das Tool es ohne Verzerrung in die quadratische Fläche ein. Prüfen Sie, ob das Ergebnis zu klein wirkt. Falls ja, bereiten Sie eine quadratischere Version der Marke vor, bevor Sie weitermachen.

Schritt 3: Abstand und Form festlegen

Der Abstand ist der Freiraum zwischen Ihrem Logo und dem Rand des Icons. Beginnen Sie mit einem kleinen Wert – genug, damit die Marke den Rand der Fläche nicht berührt. Ein Logo, das an den Rahmen gedrückt ist, wirkt beengt, gerade in Tab-Größe, wo jedes Pixel zählt.

Vergrößern Sie den Abstand, wenn das Logo feine Kanten oder dünne Striche hat. Dünne Details brauchen Luft, sonst verschmelzen sie bei kleinen Größen mit dem Rand. Verkleinern Sie ihn, wenn die Marke mutig und einfach ist – eine kräftige Form kann die Fläche gefahrlos stärker ausfüllen.

Der Eckenradius rundet die Ecken des Icon-Hintergrunds ab. Eine leichte Rundung weicht den Look auf, ohne den Charakter der Marke zu verändern. Eine volle Rundung macht aus dem Icon einen Kreis – passend für Avatare und App-Icons, kann aber ein quadratisches Logo unglücklich beschneiden.

Beobachten Sie die Vorschau, während Sie diese Einstellungen ändern. Die Änderungen gelten für alle Größen im Paket auf einmal: Eine Anpassung aktualisiert das Tab-Icon, das Apple-Icon und die Android-Icons gemeinsam. Hören Sie auf, sobald die kleinste Vorschau noch klar lesbar ist.

Schritt 4: Hintergrundfüllung wählen

Die Hintergrundfüllung ist die Farbe hinter einem transparenten Logo. Ohne Füllung bleibt das Icon leicht, und die Tab-Farbe des Browsers scheint durch. Das funktioniert gut bei dunklen, kräftigen Logos auf hellen Tabs.

Fügen Sie eine deckende Füllung hinzu, wenn das Logo blass, dünn oder hell ist. Ein weißes oder markenfarbenes Quadrat hinter der Marke gibt ihr auf jedem Tab Kontrast. Wählen Sie eine Füllung, die zu Ihrer Marke passt – diese Farbe wird Teil der Icon-Identität.

Apple-Touch-Icons ignorieren Transparenz und füllen leere Bereiche mit Schwarz – eine deckende Füllung ist für das Startbildschirm-Icon also die sichere Wahl. Bleibt Ihr Tab-Favicon transparent, das Apple-Icon braucht aber eine Füllung, handhabt der Generator beides mit denselben Einstellungen.

Prüfen Sie die Füllung gegen die helle und die dunkle Tab-Vorschau. Eine Füllung, die auf einem hellen Tab toll aussieht, kann auf einem dunklen Tab schwer wirken – und umgekehrt. Die richtige Füllung hält die Marke in beiden Themes sichtbar, ohne sie zu überlagern.

Schritt 5: Vorschauen prüfen

Der Generator zeigt Ihr Icon auf hellen und dunklen Browser-Tabs. Schauen Sie zuerst auf die dunkle Vorschau, wenn Ihr Logo dunkel ist, und zuerst auf die helle, wenn Ihr Logo hell ist. Genau dort, wo Logo-Farbe und Tab-Farbe übereinstimmen, tauchen Probleme auf.

Richten Sie Ihre Aufmerksamkeit auf die kleinste Vorschau – das 16-Pixel-Tab-Icon. Das ist die Größe, die Besucher am häufigsten sehen, und dort stirbt Detailreichtum. Erkennen Sie die Marke in dieser Größe noch, funktioniert das Favicon. Wird sie zu einem Fleck, vereinfachen Sie die Quelle oder vergrößern Sie den Abstand.

Werfen Sie auch einen Blick auf die größte Vorschau, das 512-Pixel-Android-Icon. Eine Marke, die klein gut lesbar ist, kann groß leer oder verloren wirken – vor allem, wenn es sich um einen einzelnen dünnen Buchstaben handelt. Die große Vorschau zeigt, ob das Design auf einem Startbildschirm trägt.

Überspringen Sie diesen Schritt nicht. Die Vorschau fängt die zwei häufigsten Fehler ab: ein Icon, das im Dark Mode verschwindet, und eine Marke, die in Tab-Größe zu Brei wird. Beides lässt sich jetzt in Sekunden beheben – nach dem Upload kostet es eine volle Runde Cache-Leeren.

Schritt 6: Paket herunterladen

Wenn die Vorschauen stimmen, laden Sie die ZIP-Datei herunter. Darin finden Sie favicon.ico, das Apple Touch Icon, die Android-Icons mit 192 und 512 Pixeln, die Datei site.webmanifest und das HTML-Snippet. Alles ist benannt und bereit zum Hochladen.

Sie können auch einzelne Dateien herunterladen, wenn Sie nur eine davon brauchen. Allein favicon.ico reicht für eine schnelle Korrektur auf einer alten Website, während die vollständige ZIP-Datei die richtige Wahl für eine neue Website ist, die den kompletten Satz braucht.

Entpacken Sie das Paket auf Ihrem Computer und sehen Sie sich die Dateien vor dem Hochladen an. Prüfen Sie, ob die Icon-Größen vorhanden sind und ob die Manifest-Datei dabei ist. Ein kurzer Blick jetzt verhindert eine Überraschung durch eine fehlende Datei, nachdem Sie Ihre Website schon bearbeitet haben.

Bewahren Sie eine Kopie der ZIP-Datei an einem sicheren Ort auf. Wenn Sie später ein Rebranding machen oder die Website-Dateien verlieren, ist die ZIP-Datei der schnellste Weg, den Icon-Satz wiederherzustellen. Sie ist auch die Grundlage, um das Paket mit einer kleinen Änderung neu zu erzeugen, statt von vorn zu beginnen.

Schritt 7: Dateien hochladen

Laden Sie die Icon-Dateien in das Stammverzeichnis Ihrer Website hoch – denselben Ordner, in dem Ihre Startseite liegt. Browser suchen favicon.ico standardmäßig im Stammverzeichnis, sodass es dort auch Seiten abdeckt, die das Snippet nicht enthalten.

Nutzen Sie den Datei-Manager Ihres Hostings, einen FTP-Client oder Ihr Deployment-Tool, um die Dateien zu kopieren. Die Dateien sind klein, der Upload dauert Sekunden. Vergewissern Sie sich, dass jede Datei im Stammverzeichnis gelandet ist und nicht versehentlich in einem Unterordner.

Gibt Ihr Website-Baukasten das Stammverzeichnis nicht frei, suchen Sie in seinem Dashboard nach einer Favicon- oder Website-Icon-Einstellung. Viele Baukästen nehmen ein hochgeladenes Icon entgegen und übernehmen die Dateiablage selbst. Laden Sie in dem Fall das 512-Pixel-PNG hoch, da Baukästen meist von einer großen Quelle aus skalieren.

Benennen Sie die Dateien nicht um, es sei denn, Sie aktualisieren auch das HTML-Snippet. Eine umbenannte Datei mit altem Snippet-Pfad ist dasselbe wie eine fehlende Datei – und der Browser zeigt stattdessen das Standard-Icon.

Schritt 8: HTML-Snippet einfügen

Öffnen Sie das HTML-Snippet, das mit dem Paket kam. Es enthält Link-Tags für das Favicon, das Apple Touch Icon und das Web-Manifest. Kopieren Sie den gesamten Block exakt so, wie er geliefert wurde, ohne die Pfade zu bearbeiten.

Fügen Sie das Snippet im Head-Bereich Ihrer Seiten ein, in der Nähe der anderen Meta- und Link-Tags. Auf einer einfachen HTML-Website fügen Sie es auf jeder Seite oder in einer gemeinsamen Header-Vorlage ein. In React oder Next.js gehört es einmal in die Layout- oder Dokument-Datei, die alle Seiten teilen.

Speichern Sie die Datei und laden Sie Ihre Website im Browser neu. Das Tab-Icon sollte sich in Ihr neues Favicon ändern. Falls nicht, ist das alte Icon möglicherweise zwischengespeichert – das ist normal und wird im nächsten Schritt behandelt.

Prüfen Sie die Snippet-Pfade, wenn das Icon auch nach dem Cache-Leeren nicht erscheint. Ein Pfad, der auf einen nicht existierenden Unterordner zeigt, ist die übliche Ursache. Das Snippet geht davon aus, dass die Dateien im Stammverzeichnis liegen – ein anderer Ort braucht angepasste Pfade.

Schritt 9: Cache leeren und testen

Browser speichern Favicons lange zwischen, sodass Ihr eigener Browser nach dem Upload weiterhin das alte Icon zeigen kann. Machen Sie einen harten Reload mit Strg, Umschalt und R oder öffnen Sie die Favicon-URL direkt und laden Sie diese Seite neu, um einen frischen Abruf zu erzwingen.

Testen Sie das Icon in einem zweiten Browser oder in einem privaten Fenster, wo der Cache leer ist. Ein privates Fenster zeigt, was neue Besucher sehen – das ist der ehrliche Test. Erscheint das Icon dort, hat der Upload funktioniert und nur der Cache Ihres Hauptbrowsers ist veraltet.

Fügen Sie die Website zum Startbildschirm Ihres Smartphones hinzu und prüfen Sie das Apple- oder Android-Icon. Das Startbildschirm-Icon ist die größte Version und zeigt Fehler, die die Tab-Vorschau verbirgt. Sieht es auf dem Smartphone richtig aus, ist das Paket vollständig.

Speichern Sie die Seite als Lesezeichen und schauen Sie sich die Lesezeichenliste an. Das Favicon sollte neben dem gespeicherten Titel erscheinen. Ein fehlendes Icon in den Lesezeichen bedeutet meist, dass der Snippet-Pfad falsch ist oder die Datei nicht hochgeladen wurde.

Schritt 10: Wann neu erzeugen?

Erzeugen Sie das Paket neu, sobald sich Ihr Logo ändert – auch nur leicht. Eine neue Wortmarke, eine neue Markenfarbe oder ein verfeinertes Symbol verdienen ein frisches Paket, denn ein veraltetes Favicon widerspricht dem neuen Branding überall dort, wo es erscheint.

Erzeugen Sie das ganze Paket neu, statt eine einzelne Datei zu ersetzen. Wer nur favicon.ico austauscht, lässt die alte Marke auf Startbildschirmen und im Manifest zurück – eine verwirrende Mischung aus alten und neuen Icons auf verschiedenen Geräten.

Ändern Sie Ihren Website-Namen oder Ihre Theme-Farbe, aktualisieren Sie auch das Manifest. Der Generator schreibt mit jedem Paket ein frisches Manifest, sodass Neuerzeugen Name, Farben und Icons synchron hält – ohne JSON von Hand zu bearbeiten.

Behalten Sie die alte ZIP-Datei, bis das neue Paket live verifiziert ist. Hat der neue Upload ein Problem, stellen die alten Dateien das bisherige Icon in Sekunden wieder her. Sobald das neue Icon im Tab, auf dem Smartphone und in den Lesezeichen bestätigt ist, kann das alte Paket weg.

Kurzübersicht: Checkliste für die Favicon-Erstellung

Bereiten Sie ein quadratisches PNG- oder SVG-Logo mit mindestens 512 Pixeln vor und entfernen Sie kleinen Text. Laden Sie es in den Generator, stellen Sie Abstand und Eckenradius ein, wählen Sie eine Hintergrundfüllung und prüfen Sie die helle und die dunkle Vorschau in der kleinsten Größe.

Laden Sie die ZIP-Datei herunter, laden Sie die Dateien in Ihr Stammverzeichnis hoch, fügen Sie das Snippet in die gemeinsame Head-Vorlage ein und testen Sie in einem privaten Fenster und auf Ihrem Smartphone. Leeren Sie den Cache, wenn das alte Icon noch nachhängt.

Den vollständigen Hintergrund zu jeder Datei im Paket lesen Sie im Favicon-Generator: Die komplette Anleitung, und die Größen im Detail unter Favicon-Größen erklärt: von 16×16 bis 512×512. Starten Sie jetzt mit dem Favicon-Generator.

Häufige Fragen

Welche Logo-Datei sollte ich für ein Favicon verwenden?

Ein quadratisches PNG- oder SVG-Logo mit mindestens 512 Pixeln eignet sich am besten. SVG ist ideal, weil es ohne Qualitätsverlust auf jede Größe skaliert. Ein JPG funktioniert auch, hat aber keine Transparenz – mit PNG oder SVG haben Sie mehr Kontrolle über den Hintergrund.

Warum erscheint mein neues Favicon nicht sofort?

Browser speichern Favicons aggressiv zwischen – manchmal wochenlang. Machen Sie einen harten Reload, öffnen Sie die Favicon-URL direkt und laden Sie sie neu, oder testen Sie in einem privaten Fenster. Bei anderen Besuchern erscheint das neue Icon, wenn ihr Cache abläuft – oder sofort, wenn Sie eine Versionsnummer an die Icon-Links hängen.

Wohin gehören die Favicon-Dateien auf meiner Website?

Laden Sie sie in das Stammverzeichnis Ihrer Website hoch – denselben Ordner wie Ihre Startseite. Browser suchen favicon.ico standardmäßig im Stammverzeichnis. Fügen Sie dann das HTML-Snippet in den Head-Bereich Ihrer Seiten ein, damit der Browser auch das Apple-Icon und das Manifest findet.

Muss ich das HTML-Snippet auf jeder Seite einfügen?

Fügen Sie es einmal in die gemeinsame Head-Vorlage oder Layout-Datei ein, die alle Seiten nutzen. Auf einer einfachen HTML-Website ist das der Header-Include; in React oder Next.js die Layout- oder Dokument-Datei. Sie müssen es nicht von Hand auf jede Seite kopieren.

Kann ich ein Favicon aus einem Foto auf meinem Smartphone erstellen?

Ja, der Generator akzeptiert HEIC-Fotos von iPhones ebenso wie JPG- und PNG-Dateien. Ein Foto ergibt bei 16 Pixeln allerdings selten ein gutes Favicon – schneiden Sie also zuerst einen markanten Ausschnitt oder eine einzelne starke Form zu, um das beste Ergebnis zu bekommen.

Was, wenn mein Logo nicht quadratisch ist?

Der Generator passt ein rechteckiges Logo ohne Verzerrung in die quadratische Fläche ein – das Ergebnis kann aber klein wirken und an den Seiten Leerraum haben. Für das beste Ergebnis bereiten Sie eine quadratische Version Ihrer Marke vor oder schneiden Sie vor dem Hochladen den wiedererkennbarsten Ausschnitt zu.
