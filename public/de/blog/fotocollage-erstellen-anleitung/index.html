Fotocollage erstellen: Anleitung

Erstellen Sie in wenigen Minuten eine Fotocollage: Fotos auswählen, Raster- oder Streifen-Layout wählen, anordnen, Abstände und Hintergrund festlegen und ein teilbereites Bild exportieren.

Eine Fotocollage zu erstellen ist eine kurze Aufgabe: ein paar Fotos auswählen, ein Layout wählen, sie anordnen und ein Bild exportieren. Diese Anleitung führt Sie Schritt für Schritt durch den Ablauf – von der Wahl der Fotos bis zum Teilen der fertigen Collage.

Vor dem Start brauchen Sie nur eines: die Fotos, die Sie kombinieren möchten. Vier bis neun starke Fotos mit ähnlichem Licht ergeben die beste Collage. Eine Reihe von Fotos von einer Reise, einem Ereignis oder einer Produktrange funktioniert besser als eine zufällige Mischung.

Mit Bildcollage erstellen erledigen Sie die Arbeit in Ihrem Browser. Nichts wird auf einen Server hochgeladen, es gibt kein Konto, und der Export ist kostenlos. Folgen Sie den Schritten unten – in wenigen Minuten haben Sie eine fertige Collage.

Schritt 1: Fotos auswählen

Wählen Sie die Fotos aus, die zusammengehören. Eine Collage erzählt eine kleine Geschichte – die Fotos sollten also ein Motiv teilen: eine Reise, einen Geburtstag, eine Produktrange oder ein Familientreffen. Fotos von einem Ereignis wirken wie eine Sammlung; Fotos von fünf Ereignissen wie ein zufälliger Haufen.

Wählen Sie vier bis neun Fotos. Vier füllen ein 2-mal-2-Raster sauber, neun ein 3-mal-3-Raster. Weniger als vier lassen leere Zellen zurück, mehr als neun machen jedes Foto zu klein, um es zu genießen. Qualität schlägt Quantität in einer Collage.

Wählen Sie Fotos mit ähnlichem Licht und ähnlicher Farbe. Eine Reihe, in der ein Foto dunkel und unscharf ist, lenkt das Auge auf das schwache Foto, während eine Reihe mit konsistentem Licht wie eine bewusste Sammlung aussieht. Ist ein Foto deutlich dunkler als der Rest, hellen Sie es vor dem Start auf oder lassen Sie es weg.

Wählen Sie ein Hero-Foto. Ein starkes Bild wird zum Hauptfoto, vergrößert über den Rest – wählen Sie also die Aufnahme, die die Reihe am besten repräsentiert. Das Hero ist meist das klarste, hellste oder emotionalste Foto der Gruppe.

Schritt 2: Fotos hochladen

Öffnen Sie das Tool und ziehen Sie Ihre Fotos in den Upload-Bereich oder klicken Sie, um sie auf Ihrem Gerät auszuwählen. Sie können sie alle auf einmal hochladen, und das Tool platziert sie in der Reihenfolge, in der Sie sie gewählt haben, in das Raster.

Das Tool akzeptiert JPG, PNG, WebP, HEIC, GIF, BMP und SVG bis 20 MB pro Datei. Smartphone-Fotos, Screenshots und Grafiken funktionieren alle, und eine Mischung von Formaten in einer Collage ist in Ordnung. Ein iPhone-HEIC-Foto wird hochgeladen wie jede andere Datei.

Fünf oder mehr Fotos wählen automatisch das 3-mal-3-Raster, vier oder weniger automatisch das 2-mal-2-Raster. Laden Sie weniger Fotos hoch, als das Raster Zellen hat, warten die leeren Zellen auf weitere Fotos, und Sie können sie später hinzufügen.

Haben Sie das falsche Foto hochgeladen, entfernen Sie es, ohne von vorn zu beginnen. Das Tool lässt Sie ein einzelnes Foto aus einer Zelle entfernen und ersetzen – ein Fehler kostet so Sekunden statt eines Neuaufbaus der gesamten Collage.

Schritt 3: Layout wählen

Wählen Sie ein Raster- oder ein Streifen-Layout. Das 2-mal-2-Raster passt zu vier Fotos, das 3-mal-3-Raster zu neun, der vertikale Streifen zu einer Sequenz, die von oben nach unten gelesen wird, und der horizontale Streifen zu einer Sequenz, die von links nach rechts gelesen wird.

Raster passen zu Reihen, in denen jedes Foto gleich wichtig ist: eine Reise, ein Ereignis oder eine Produktrange. Die quadratische Form passt zu Feeds und Anzeigen, und die gleichen Zellen geben jedem Foto dasselbe Gewicht.

Streifen passen zu Sequenzen und Vergleichen. Ein vertikaler Streifen liest sich wie eine Geschichte – passend für einen Tag in Reihenfolge. Ein horizontaler Streifen liest sich wie eine Zeitachse – passend für ein Vorher-und-Nachher oder ein Panorama aus Momenten.

Ändern Sie das Layout nach dem Hochladen frei. Die Fotos bleiben an Ort und Stelle, und die Zellen ordnen sich neu – so können Sie ein Raster und einen Streifen in Sekunden vergleichen. Das Layout, das auf einen Blick am besten lesbar ist, ist meist das richtige.

Schritt 4: Fotos anordnen

Ziehen Sie ein Foto auf eine andere Zelle, um sie auf dem Desktop zu tauschen, oder tippen Sie zum Auswählen und tippen Sie erneut zum Tauschen auf einem Smartphone. Der Tausch geschieht sofort, und Sie können vor dem Export so oft neu anordnen, wie Sie möchten.

Setzen Sie das Hero-Foto in die prominenteste Zelle. In einem 2-mal-2-Raster ist das die Zelle oben links, die das Auge zuerst sieht. In einem 3-mal-3-Raster zieht die mittlere Zelle das Auge an – das Hero gehört also dorthin oder oben links.

Balancieren Sie Hell und Dunkel über das Raster aus. Ein dunkles Foto neben einem weiteren dunklen Foto erzeugt eine schwere Ecke, während ein dunkles Foto neben einem hellen die Collage ausbalanciert. Verteilen Sie die hellen und dunklen Fotos gleichmäßig, statt sie zu bündeln.

Probieren Sie mehrere Anordnungen aus, bevor Sie sich festlegen. Ein Foto, das in einer Zelle verloren wirkt, kann in einer anderen die Collage verankern, und ein Tausch, der eine Sekunde dauert, kann die gesamte Balance verändern. Vertrauen Sie der Anordnung, die auf einen Blick am besten lesbar ist.

Schritt 5: Ein Foto hervorheben

Machen Sie das Hero-Foto größer als den Rest, indem Sie die Teilungen anpassen. Ziehen Sie eine Teilungslinie, um die Hero-Zelle zu vergrößern und ihre Nachbarn zu verkleinern – das gibt der Collage einen Blickpunkt und eine Hierarchie statt eines flachen Rasters.

Wählen Sie das Hauptfoto nach Qualität ebenso wie nach Motiv. Das Hero sollte das schärfste, hellste Foto der Reihe sein, weil das Vergrößern eines schwachen Fotos nur die Aufmerksamkeit auf seine Fehler lenkt. Ein starkes Foto vergrößert wirkt bewusst; ein schwaches vergrößert wirkt wie ein Fehler.

Beschränken Sie das Hauptfoto auf ein Foto. Zwei große Zellen konkurrieren miteinander, und die Hierarchie bricht zusammen – vergrößern Sie also eine Zelle deutlich über den Rest und lassen Sie die anderen gleich. Ein Hauptfoto ist die Regel, die die Collage auf einen Blick lesbar macht.

Werden die Teilungen ungleichmäßig und Sie möchten von vorn beginnen, setzen Sie sie auf ein einheitliches Raster zurück. Das Tool setzt die Teilungen auf gleiche Zellen zurück – so können Sie eine andere Hauptfoto-Anordnung ausprobieren, ohne die Collage neu zu erstellen.

Schritt 6: Abstände und Ecken anpassen

Stellen Sie den Abstand zwischen Zellen ein. Ein Abstand von null ergibt eine nahtlose, rahmenlose Collage, bei der die Fotos sich berühren und ein durchgehendes Bild bilden. Ein sichtbarer Abstand trennt die Fotos in einzelne Rahmen – passend für einen Scrapbook- oder Galerie-Look.

Stellen Sie den Eckenradius für die Zellen ein. Ein kleiner Radius weicht die Collage auf und passt zu Social-Media-Posts, während quadratische Ecken formell wirken und zu Drucken und Anzeigen passen. Ein großer Radius verwandelt jede Zelle in eine abgerundete Kachel – passend für verspielte Designs.

Abstand und Eckenradius sind unabhängig – Sie können sie also frei kombinieren. Ein breiter Abstand mit quadratischen Ecken wirkt wie eine Galeriewand, während ein schmaler Abstand mit abgerundeten Ecken wie eine App wirkt. Die Kombination bestimmt die Stimmung der Collage.

Die Hintergrundfarbe scheint durch die Abstände hindurch – wählen Sie also Abstand und Hintergrund als Paar. Ein weißer Abstand auf weißem Hintergrund wirkt wie ein sauberer Rahmen, während eine Markenfarbe in den Abständen die Collage an eine Kampagne bindet.

Schritt 7: Hintergrund festlegen

Wählen Sie die Hintergrundfarbe aus den schnellen Voreinstellungen. Weiß ist die Standard- und sicherste Wahl: Es hält die Collage sauber, passt zu jedem Feed oder jeder Seite und macht die Fotos zur einzigen Farbe im Bild.

Eine Markenfarbe verwandelt die Collage in eine gestaltete Grafik. Die Farbe in den Abständen bindet die Collage an eine Kampagne, und eine Reihe von Collagen in derselben Farbe bildet eine wiedererkennbare Serie. Nutzen Sie sie, wenn die Collage ebenso Werbung wie Sammlung ist.

Transparente PNG-Sticker, die in Zellen platziert werden, zeigen die Hintergrundfarbe hinter sich. Ein Sticker auf weißem Hintergrund liest sich als sauberer Ausschnitt, während ein Sticker auf farbigem Hintergrund einen Farbton von der Farbe dahinter annimmt. Prüfen Sie Sticker vor dem Export gegen den Hintergrund.

Halten Sie den Hintergrund einfach. Ein Hintergrund, der gegen die Fotos kämpft, lenkt das Auge auf die Abstände statt auf die Bilder, und eine helle Abstandsfarbe zwischen gedämpften Fotos lässt die Collage belebt wirken. Weiß oder ein weiches Neutral ist die sichere Wahl.

Schritt 8: Flächengröße wählen

Wählen Sie eine Flächengröße und ein Verhältnis für das Ziel. Quadrat passt zu Feeds, Anzeigen und Thumbnails. Hochformat passt zu Stories und Smartphone-Hintergründen. Breit passt zu Bannern und Headern. Das Tool bietet schnelle Voreinstellungen für jede Form.

Die Exportauflösung geht bis zu 4000 Pixel – groß genug zum Drucken. Wählen Sie einen großen Export, wenn die Collage gedruckt werden könnte, und einen moderaten, wenn sie nur online gepostet wird. Sie können später immer herunterskalieren, aber keine Pixel hinzufügen.

Prüfen Sie die Vorschau im gewählten Verhältnis. Eine Collage, die als Quadrat ausgewogen aussieht, kann als Hochformat gestreckt wirken, weil die Zellen ihre Form ändern. Passen Sie die Anordnung nach dem Ändern des Verhältnisses an – das beste Layout für eine Form muss nicht zu einer anderen passen.

Wenn Sie nicht sicher sind, wo die Collage verwendet wird, wählen Sie Quadrat. Es ist die nachsichtigste Form, lässt sich überall vorhersehbar zuschneiden und funktioniert als Thumbnail, Anzeige und Feed-Post ohne weitere Bearbeitung.

Schritt 9: Collage in der Vorschau prüfen

Sehen Sie sich die vollständige Vorschau an, bevor Sie exportieren. Prüfen Sie, ob jedes Foto in der richtigen Zelle ist, das Hero-Foto prominent ist, die Abstände gleichmäßig sind und die Hintergrundfarbe so aussieht, wie Sie es beabsichtigt haben. Eine Vorschau in voller Größe zeigt Details, die ein Thumbnail verbirgt.

Prüfen Sie jede Zelle auf schlechte Beschnitte. Die Anpassung „Ausfüllen“ kann ein Gesicht, ein Produktetikett oder eine Textzeile am Rand eines Fotos abschneiden. Wechseln Sie die Anpassung für jede Zelle, bei der der Beschnitt schadet, zu „Enthalten“ und akzeptieren Sie den Rand, der damit einhergeht.

Schauen Sie sich die Collage auf Ihrem Smartphone an, wenn sie für Social Media bestimmt ist. Eine Abstandsfarbe, die auf einem Desktop-Monitor dezent wirkt, kann auf einem Handybildschirm laut wirken, und eine Collage, die groß ausgewogen aussieht, kann klein belebt wirken. Das Smartphone ist der Ort, an dem das Publikum sie sieht.

Vergleichen Sie die Collage auch in kleiner Größe. Verkleinern Sie Ihre Ansicht auf Thumbnail-Größe und prüfen Sie, ob die Collage noch lesbar ist. Eine Collage, die nur in voller Größe funktioniert, scheitert als Feed-Post, wo sie klein unter vielen anderen gesehen wird.

Schritt 10: Exportieren und teilen

Wählen Sie das Exportformat. JPG passt zu Fotografien und zu jeder Collage, bei der eine kleine Datei zählt – etwa einem Social-Media-Post. PNG passt zu Collagen mit scharfem Text, flachen Farben oder Transparenz, die den Export überleben muss.

Klicken Sie auf Herunterladen – die fertige Collage wird auf Ihrem Gerät gespeichert. Der Dateiname spiegelt die Collagen-Einstellungen wider, sodass Sie Versionen auseinanderhalten können, wenn Sie mehrere exportieren. Öffnen Sie die Datei und schauen Sie sie vor dem Teilen noch einmal an.

Teilen Sie die Collage als ein einziges Bild: Laden Sie sie in einen Social-Media-Feed hoch, hängen Sie sie an eine Nachricht an oder fügen Sie sie einer Anzeige hinzu. Die Collage ist eine Datei – sie postet sich wie jedes andere Bild, und die Fotos darin reisen gemeinsam, wohin die Datei auch geht.

Behalten Sie die Quellfotos ebenso wie die fertige Collage. Brauchen Sie später ein anderes Verhältnis, ein anderes Layout oder ein korrigiertes Foto, lassen die Quellen Sie in Minuten neu erstellen. Eine flache exportierte Collage lässt sich nicht leicht zurück in ihre Teile bearbeiten.

Collagen für den Druck

Eine Collage für den Druck braucht einen großen Export. Wählen Sie die maximale Auflösung – bis zu 4000 Pixel –, damit der Druck in der gewünschten Größe scharf bleibt. Eine Collage, die für Social Media exportiert wurde, druckt in großer Größe schlecht, weil die Pixel nicht vorhanden sind.

Wählen Sie PNG für den schärfsten Druck oder ein hochwertiges JPG für einen fotografischen Druck. PNG hält Ränder und Text knackig, während JPG Fotos effizient komprimiert. Beides funktioniert bei einer großen Exportgröße; die Wahl hängt davon ab, ob die Collage grafisch oder fotografisch ist.

Prüfen Sie das Seitenverhältnis gegen das Papier- oder Rahmenformat. Eine quadratische Collage passt in einen quadratischen Rahmen, eine Hochformat-Collage in einen Standard-Fotodruck. Eine Nichtübereinstimmung bedeutet, den Druck zu beschneiden oder mit weißen Rändern zu leben – passen Sie also das Verhältnis vor dem Export an.

Drucken Sie zuerst einen kleinen Test, wenn die Collage wichtig ist – etwa ein Geschenk oder ein gerahmter Druck. Ein Testdruck zeigt Farbverschiebungen und Schärfeprobleme, die der Bildschirm verbirgt, und kostet weit weniger als das Neudrucken eines großen Rahmens.

Eine Collage reparieren, die nicht stimmt

Eine Collage, die nicht stimmt, hat meist eines von vier Problemen: ein schwaches Foto, einen schlechten Beschnitt, eine unausgewogene Anordnung oder eine Abstandsfarbe, die gegen die Fotos kämpft. Beheben Sie sie in dieser Reihenfolge – beginnend mit den Fotos selbst.

Ersetzen Sie zuerst das schwächste Foto. Ein dunkles, unscharfes oder themenfremdes Foto zieht das Auge an, egal wo es sitzt, und keine Anordnung kann es verbergen. Tauschen Sie es gegen ein stärkeres Foto aus derselben Reihe aus oder wechseln Sie zu einem kleineren Raster ohne es.

Prüfen Sie als Nächstes die Beschnitte. Ein Gesicht, das am Rand einer Zelle abgeschnitten ist, oder ein Motiv, das durch die Anpassung gequetscht wird, ruiniert die Zelle. Wechseln Sie die Anpassung für diese Zelle zu „Enthalten“ oder wählen Sie ein anderes Foto dafür – die Collage verbessert sich sofort.

Balancieren Sie dann die Anordnung neu aus. Bewegen Sie die hellen Fotos auseinander, setzen Sie das Hero in die prominente Zelle und verteilen Sie die dunklen Fotos gleichmäßig. Ein einziger Tausch repariert oft eine Collage, die sich falsch anfühlte, ohne offensichtliche Ursache.

Vereinfachen Sie schließlich Abstände und Hintergrund. Eine helle Abstandsfarbe oder ein belebter Hintergrund kann eine gute Collage laut wirken lassen. Setzen Sie die Abstände auf Weiß und die Ecken auf einen kleinen Radius – die Fotos tragen die Collage dann allein.

Kurzübersicht: Collagen-Checkliste

Wählen Sie vier bis neun starke Fotos mit ähnlichem Licht, laden Sie sie hoch und wählen Sie ein Raster oder einen Streifen. Ordnen Sie per Ziehen oder Tippen zum Tauschen an, vergrößern Sie das Hero-Foto und stellen Sie Abstände, Ecken und Hintergrund ein.

Wählen Sie ein Flächenverhältnis für das Ziel, exportieren Sie JPG für Fotos und PNG für Grafiken und prüfen Sie jede Zelle in voller Größe und in Thumbnail-Größe auf schlechte Beschnitte. Bewahren Sie die Quellfotos für einen späteren Neuaufbau auf.

Häufige Fragen

Wie wähle ich aus, welche Fotos in eine Collage gehören?

Wählen Sie Fotos, die ein Motiv teilen – etwa eine Reise, ein Ereignis oder eine Produktrange – und wählen Sie vier bis neun der stärksten aus. Fotos mit ähnlichem Licht und ähnlicher Farbe wirken wie eine Sammlung, während eine zufällige Mischung wie ein Haufen aussieht. Lassen Sie jedes Foto weg, das dunkel, unscharf oder themenfremd ist.

Was, wenn ich weniger Fotos hochlade, als das Layout Zellen hat?

Die leeren Zellen warten auf weitere Fotos, und Sie können sie später hinzufügen. Sie können auch zu einem kleineren Layout wechseln – etwa einem 2-mal-2-Raster für vier Fotos –, sodass es keine leeren Zellen gibt. Exportieren Sie nicht mit leeren Zellen, es sei denn, der Leerraum ist bewusst gewählt.

Kann ich ein Foto in eine andere Zelle verschieben?

Ja. Ziehen Sie ein Foto auf eine andere Zelle, um sie auf dem Desktop zu tauschen, oder tippen Sie zum Auswählen und tippen Sie erneut zum Tauschen auf einem Smartphone oder Tablet. Sie können vor dem Export so oft neu anordnen, wie Sie möchten, und die Vorschau aktualisiert sich sofort.

Sollte ich meine Collage als JPG oder PNG speichern?

Nutzen Sie JPG für Fotocollagen und für jedes Bild, bei dem eine kleine Datei zählt – etwa einen Social-Media-Post. Nutzen Sie PNG für Collagen mit scharfem Text, flachen Farben oder Transparenz, weil PNG jede Kante knackig hält und transparente Bereiche bewahrt.

Wie drucke ich meine Collage?

Exportieren Sie mit der größten Auflösung – bis zu 4000 Pixel – und passen Sie das Flächenverhältnis an das Papier- oder Rahmenformat an. Wählen Sie PNG für den schärfsten Druck oder ein hochwertiges JPG für einen fotografischen Druck und drucken Sie zuerst einen kleinen Test für ein wichtiges Stück.

Kann ich eine Collage auf meinem Smartphone erstellen?

Ja, das Tool läuft im Browser auf Smartphones und Tablets. Laden Sie aus Ihrer Fotobibliothek hoch, tippen Sie zum Tauschen von Fotos zwischen Zellen und laden Sie die fertige Collage herunter. Tippen-zum-Tauschen ersetzt das Ziehen auf Touchscreens, sodass das Anordnen auf Mobilgeräten zuverlässig funktioniert.
