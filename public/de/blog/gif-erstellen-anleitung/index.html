GIF erstellen: Die komplette Anleitung

Erstellen Sie animierte GIFs aus Ihren Fotos: Frames auswählen, Timing, Loop-Optionen, Frame-Anpassung und die Dateigröße im Griff behalten.

Ein GIF ist eine kurze, sich wiederholende Animation aus einer Reihe von Standbildern. Es spielt ohne Ton, wiederholt sich endlos oder eine festgelegte Anzahl von Loops und funktioniert in fast jeder Chat-App, jedem Social-Media-Feed und jeder Website. Ein gut gemachtes GIF sagt in zwei Sekunden, was ein Absatz nicht kann.

Mit GIF erstellen verwandeln Sie Ihre Fotos im Browser in ein animiertes GIF. Laden Sie zwei oder mehr Frame-Bilder hoch, legen Sie das Timing für jeden Frame fest, wählen Sie die Loop-Anzahl und laden Sie eine GIF89a-Datei ohne Wasserzeichen herunter. Nichts wird auf einen Server hochgeladen.

Diese Anleitung erklärt, wie GIFs funktionieren, wie Sie Frames auswählen und timen und wie Sie die Dateigröße klein genug halten, um sie zu teilen. Ob Sie ein Reaktions-GIF, eine Produkt-Demo oder einen Tutorial-Clip erstellen – dieselben Prinzipien gelten.

Was ist ein GIF?

GIF steht für Graphics Interchange Format und existiert seit den späten 1980er-Jahren. Es ist eines der ältesten Bildformate, die bis heute täglich genutzt werden – und seine Langlebigkeit kommt von einem Merkmal: Animation ohne Video.

Ein GIF speichert eine Reihe von Frames, die jeweils für kurze Zeit nacheinander gezeigt werden. Der Player läuft durch die Frames, und das Ergebnis sieht wie ein kurzer Video-Clip aus. Es gibt keinen Ton, keine Player-Steuerung und keinen Bedarf an einem Video-Codec.

GIFs sind auf 256 Farben pro Frame begrenzt – deshalb eignen sie sich besser für Illustrationen, Screenshots und einfache Animationen als für vollfarbige Fotografien. Ein Foto-GIF funktioniert, aber die begrenzte Palette kann Verläufe streifig und Hauttöne flach wirken lassen.

Das Format ist universell. Chat-Apps, Social-Media-Feeds, Foren, E-Mails und Websites zeigen GIFs ohne speziellen Player an. Diese Universalität ist der Grund, warum ein GIF bis heute der einfachste Weg ist, eine kurze Animation mit jedem zu teilen.

Wie das Tool funktioniert

Das Tool codiert Ihre Fotos vollständig in Ihrem Browser in ein animiertes GIF. Ihre Frames verlassen Ihr Gerät nie – wichtig, wenn es sich um unveröffentlichte Produktaufnahmen oder persönliche Fotos handelt. Es gibt keinen Upload, keine Warteschlange und kein Warten auf einen Server.

Sie laden zwei oder mehr Frame-Bilder hoch, und das Tool ordnet sie der Reihe nach an. Sie können Frames per Ziehen neu ordnen, einen Frame duplizieren, um ihn länger zu halten, und einen Frame entfernen, der nicht dazugehört. Die Frame-Liste ist die Timeline Ihrer Animation.

Jeder Frame bekommt seine eigene Verzögerung, gemessen in Bruchteilen einer Sekunde. Eine kurze Verzögerung macht die Animation schnell, eine lange langsam. Sie können auch eine einzige Verzögerung für alle Frames festlegen und dann einzelne Frames anpassen, die länger verweilen müssen.

Die Live-Timing-Vorschau zeigt die Animation mit Ihren aktuellen Einstellungen, bevor Sie die Datei erzeugen. Was Sie in der Vorschau sehen, ist das, was das fertige GIF aussehen wird – prüfen Sie es also vor dem Download. Die erzeugte Datei ist ein Standard-GIF89a, das überall dort abspielt, wo GIFs unterstützt werden.

Frames auswählen

Frames sind die Standbilder, aus denen die Animation besteht, und die Wahl der Frames entscheidet, ob das GIF funktioniert. Ein gutes GIF erzählt eine kleine Geschichte: ein Vorher und Nachher, ein sich drehendes Produkt, eine Schritt-für-Schritt-Aktion oder eine Reaktion, die sich aufbaut und entlädt.

Nutzen Sie Frames, die in Größe und Form ähnlich sind. Das Tool verarbeitet Bilder mit unterschiedlichen Seitenverhältnissen, aber ein Satz von Frames mit passenden Abmessungen ergibt eine geschmeidige Animation ohne Sprünge oder schwarze Balken. Skalieren oder schneiden Sie die Frames zuerst zu, wenn sie stark voneinander abweichen.

Halten Sie die Frame-Anzahl moderat. Ein GIF mit fünf bis fünfzehn Frames reicht meist für eine Reaktion, eine Demo oder einen kurzen Tutorial-Schritt. Mehr Frames bedeuten eine längere Animation und eine größere Datei – und ein sehr langes GIF verliert die Wirkung, die das Format ausmacht.

Die Reihenfolge ist wichtiger als die Anzahl. Eine Produktrotation liest sich im oder gegen den Uhrzeigersinn, ein Tutorial in Schritt-Reihenfolge und eine Reaktion als Aufbau und Auflösung. Ordnen Sie die Frames so an, dass sich die Bewegung natürlich anfühlt, und prüfen Sie dann die Vorschau.

Frame-Verzögerungen und Timing

Die Frame-Verzögerung ist, wie lange jeder Frame auf dem Bildschirm bleibt, und sie ist die Hauptkontrolle darüber, wie sich die Animation anfühlt. Eine Verzögerung von 0,1 Sekunden pro Frame ergibt eine schnelle, energische Bewegung, während 0,5 Sekunden eine langsame, bewusste ergeben.

Nutzen Sie eine konsistente Verzögerung für den Hauptteil der Animation und eine längere für die Frames, die Betonung brauchen. Eine Titelfolie am Anfang verdient eine längere Haltezeit, damit Betrachter sie lesen können, und der letzte Frame verdient eine längere Haltezeit, damit die Botschaft landet, bevor der Loop neu startet.

Die Schnell-Voreinstellungen von 1, 2, 5 und 10 Bildern pro Sekunde geben Ihnen Startpunkte. Ein Bild pro Sekunde ist eine langsame Diashow, fünf Bilder pro Sekunde eine zügige Demo und zehn Bilder pro Sekunde glatt genug für einfache Bewegung. Starten Sie mit einer Voreinstellung und feinjustieren Sie dann einzelne Frames.

Testen Sie das Timing in der Live-Timing-Vorschau. Eine Verzögerung, die als Zahl richtig aussieht, kann sich in Bewegung falsch anfühlen – die Vorschau zeigt das echte Gefühl. Wenn die Animation am wichtigen Frame vorbeirast, verlängern Sie diesen Frame, statt das ganze GIF zu verlangsamen.

Bildraten-Voreinstellungen

Die Voreinstellungen übersetzen Bilder pro Sekunde in Verzögerungen. Ein FPS bedeutet, dass jeder Frame eine Sekunde lang gezeigt wird – passend für eine Diashow aus Standbildern, bei der jedes Bild einen vollen Blick verdient. Zwei FPS bedeuten eine halbe Sekunde pro Frame – passend für eine langsame Demo.

Fünf FPS bedeuten ein Fünftel einer Sekunde pro Frame – der ideale Wert für die meisten GIFs. Es ist schnell genug, um sich wie Bewegung anzufühlen, und langsam genug, dass jeder Frame registriert wird. Produkt-Demos, Tutorials und einfache Animationen leben meist bei dieser Rate.

Zehn FPS bedeuten ein Zehntel einer Sekunde pro Frame – die geschmeidigste Einstellung, die das Tool bietet. Sie passt zu Bewegung, die flüssig aussehen muss, etwa einer Rotation oder einem Geh-Zyklus, bedeutet aber auch mehr Frames pro Sekunde Animation und eine größere Datei.

Höher ist nicht immer besser. Ein GIF mit zehn Bildern pro Sekunde und dreißig Frames ist drei Sekunden lang und schwer, während dieselbe Idee mit fünf Bildern pro Sekunde und fünfzehn Frames drei Sekunden lang und halb so groß ist. Passen Sie die Rate an die Bewegung an, nicht an das Maximum.

Loop-Optionen

Looping entscheidet, wie oft das GIF abspielt. Ein Endlos-Loop spielt für immer – das klassische GIF-Verhalten und die richtige Wahl für Reaktionen, Dekorationen und alles, was wiederholt das Auge fangen soll.

Ein begrenzter Loop spielt eine festgelegte Anzahl von Malen und stoppt dann auf dem letzten Frame. Das passt zu einem Tutorial oder einer Demo, bei der der Betrachter auf dem fertigen Zustand enden soll, nicht auf einem Frame mitten in der Animation. Eine Loop-Anzahl von zwei oder drei gibt dem Betrachter einen zweiten Blick, ohne endlos zu loopen.

Ein einmaliges Abspielen – Loop-Anzahl eins – zeigt die Animation einmal und stoppt. Das passt zu einer Botschaft, bei der die Animation eine einmalige Enthüllung ist, etwa ein Vorher-und-Nachher, das auf dem Nachher enden soll. Der Betrachter sieht die Veränderung, dann bleibt das Ergebnis stehen.

Wählen Sie den Loop passend zum Kontext. Eine Chat-Reaktion will einen Endlos-Loop, eine Produkt-Demo ein paar Loops, und ein Tutorial-Schritt will auf dem Ergebnis enden. Der falsche Loop lässt ein gutes GIF kaputt wirken.

Frame-Anpassung: Enthalten vs. Ausfüllen

Die Frame-Anpassung entscheidet, was passiert, wenn die Frames unterschiedliche Seitenverhältnisse haben. „Enthalten“ passt jeden Frame ohne Beschnitt in die Ausgabegröße ein – der ganze Frame bleibt sichtbar, und leerer Raum wird zu einem Rand. Das bewahrt das vollständige Bild auf Kosten leerer Streifen.

„Ausfüllen“ füllt die Ausgabegröße vollständig, indem der Frame beschnitten wird – es gibt keine leeren Streifen, aber die Ränder des Frames können abgeschnitten werden. Das ergibt eine saubere Animation ohne Ränder auf Kosten verlorener Frame-Ränder.

Wählen Sie „Enthalten“, wenn jeder Teil jedes Frames zählt – etwa bei einem Tutorial, wo ein beschnittener Button den Schritt verbergen würde. Wählen Sie „Ausfüllen“, wenn die Animation den Rahmen sauber füllen muss – etwa bei einem Social-Media-Post, wo leere Streifen unfertig wirken würden.

Das Seitenverhältnis bleibt fest, wenn Sie die Ausgabebreite bearbeiten – eine Änderung der Breite skaliert also das ganze GIF, statt es zu verzerren. Legen Sie die Ausgabemaße einmal fest, wählen Sie die Anpassung, und die Frames folgen konsistent.

Ausgabegröße und Abmessungen

Die Ausgabebreite legt die Pixelbreite des fertigen GIF fest, und die Höhe folgt aus dem Seitenverhältnis der Frames. Eine Breite von 480 Pixeln ist eine gängige Wahl für Chat und Social-Media-Sharing, während eine größere Breite zu einer Website oder einer Präsentation passt.

Kleiner ist bei GIFs meist besser. Ein GIF mit 480 Pixeln Breite ist klein genug, um schnell geteilt zu werden, und groß genug, um auf einem Smartphone klar gesehen zu werden. Ein GIF mit 1000 Pixeln Breite hat viermal so viele Pixel und eine mehrfach so große Datei – für einen Unterschied, den die meisten Betrachter nicht bemerken.

Das Tool setzt ein Minimum und ein Maximum für die Ausgabemaße, sodass extreme Größen nicht möglich sind. Sehr kleine Ausgaben verlieren Details, sehr große Ausgaben erzeugen Dateien, die zu groß zum Teilen sind. Bleiben Sie für die beste Balance in der Mitte des Bereichs.

Prüfen Sie die Abmessungen gegen das Ziel. Eine Chat-App skaliert ein großes GIF ohnehin herunter – eine riesige Datei zu senden verschwendet also Bandbreite ohne sichtbaren Gewinn. Ein Website-Banner braucht eine größere Breite als ein Chat-Sticker – passen Sie die Größe an den Ort an.

Farbpaletten-Qualität

GIFs speichern höchstens 256 Farben pro Frame – der Encoder muss also wählen, welche Farben er behält. Der Schieberegler „Farbpaletten-Qualität“ steuert, wie sorgfältig diese Wahl getroffen wird. Eine höhere Einstellung analysiert die Frames gründlicher und behält die Farben, die am wichtigsten sind.

Höhere Qualität ergibt glattere Verläufe und genauere Hauttöne, dauert aber länger beim Codieren und kann eine etwas größere Datei erzeugen. Niedrigere Qualität codiert schneller und macht kleinere Dateien, aber Verläufe können streifig werden und dezente Farben sich verschieben.

Nutzen Sie für Fotografien eine höhere Palettenqualität. Fotos haben Tausende von Farben, und eine sorgfältige Palette hält das Bild wiedererkennbar. Für Illustrationen und Screenshots mit wenigen Farben reicht eine niedrigere Einstellung, weil die Palette ohnehin alle Farben aufnehmen kann.

Testen Sie die Palette an einem Frame mit Verlauf oder Gesicht. Dort zeigt sich eine schlechte Palette zuerst – als Streifenbildung im Himmel oder als Flecken in der Haut. Sieht der Test-Frame sauber aus, wird auch der Rest des GIF sauber sein.

Warnung bei großem GIF

Das Tool zeigt eine Warnung bei großem GIF, wenn die geschätzte Datei 5 MB oder 15 MB überschreitet. Diese Schwellen existieren, weil große GIFs schwer zu teilen sind: Sie laden in Chats langsam, können an Upload-Limits scheitern und verbrauchen mobile Daten.

Ein GIF wird aus drei Gründen groß: viele Frames, große Abmessungen oder eine hohe Bildrate. Das Kürzen eines dieser drei Faktoren verkleinert die Datei. Weniger Frames ist meist der beste Schnitt, weil ein kürzeres GIF auch ein besseres GIF ist.

Wenn die Warnung erscheint, reduzieren Sie zuerst die Ausgabebreite. Die Halbierung der Breite schneidet die Pixelzahl auf ein Viertel – die größte einzelne Einsparung, die es gibt. Reduzieren Sie dann die Frame-Anzahl oder die Bildrate, bis die Warnung verschwindet.

Muss das GIF groß bleiben, überlegen Sie, ob ein GIF das richtige Format ist. Ein kurzes Video im MP4-Format ist weit kleiner als dieselbe Animation als GIF, und die meisten Plattformen akzeptieren Video. Der GIF-Kompressor kann ein fertiges GIF verkleinern – ein Video ist aber die bessere Wahl, wenn die Größe das Hauptproblem ist.

Transparenz in GIFs

GIFs unterstützen Transparenz, aber nur als eine einzige transparente Farbe, nicht als glatten Alphakanal. Ein Pixel ist entweder vollständig transparent oder vollständig deckend – weiche Ränder und Schatten werden also gegen einen transparenten Hintergrund hartkantig.

Das Tool bewahrt transparente Hintergründe aus PNG-Frames, wenn die Ausgabe dafür eingerichtet ist. Ein Logo oder ein Sticker mit Transparenz behält seine durchsichtigen Bereiche – passend für Overlays und Chat-Sticker, die auf jedem Hintergrund sitzen müssen.

Weiche Ränder brauchen Sorgfalt. Ein Logo mit Schlagschatten oder ausgefranstem Rand zeigt einen Heiligenschein, wenn die Transparenz auf eine einzige Farbe reduziert wird, weil die halbtransparenten Pixel entweder deckend oder klar werden müssen. Eine Grafik mit harten Kanten funktioniert besser als eine weiche.

Testen Sie ein transparentes GIF auf hellem und dunklem Hintergrund. Ein Heiligenschein, der auf Weiß unsichtbar ist, kann auf Schwarz offensichtlich sein – und umgekehrt. Zeigt sich der Heiligenschein, flachen Sie die Grafik stattdessen auf eine Volltonfarbe ab.

Häufige Fehler

Der häufigste Fehler ist zu viele Frames. Ein GIF mit fünfzig Frames ist ein Video in Verkleidung – es wird schwer, langsam und langweilig. Kürzen Sie die Frame-Liste auf die wesentlichen Momente, und das GIF wird schärfer und kleiner zugleich.

Ein weiterer Fehler ist eine einheitliche Verzögerung für jeden Frame. Eine Titelfolie, die ein Zehntel einer Sekunde gezeigt wird, kann nicht gelesen werden, und ein letzter Frame, der ein Zehntel einer Sekunde gezeigt wird, kann nicht landen. Geben Sie den wichtigen Frames längere Verzögerungen und den Bewegungs-Frames kürzere.

Ein dritter Fehler ist eine riesige Ausgabegröße. Ein GIF, das mit 1000 Pixeln Breite für eine Chat-Nachricht exportiert wird, hat viermal so viele Pixel wie eine 500-Pixel-Version, und die Chat-App skaliert es ohnehin herunter. Passen Sie die Größe an das Ziel an.

Und schließlich ignorieren viele Menschen die Palettenqualität bei Foto-GIFs. Eine niedrige Paletten-Einstellung verwandelt ein Foto in ein posterisiertes Durcheinander mit gestreiftem Himmel und fleckiger Haut. Erhöhen Sie die Palettenqualität für Fotografien und halten Sie sie nur bei einfachen Grafiken niedrig.

Kurzübersicht: GIF-Checkliste

Wählen Sie fünf bis fünfzehn Frames mit passenden Abmessungen, ordnen Sie sie in Erzähl-Reihenfolge an und stellen Sie eine Basis-Verzögerung von etwa fünf Bildern pro Sekunde ein. Geben Sie Titel- und Schluss-Frames längere Haltezeiten und wählen Sie eine Loop-Anzahl passend zum Kontext.

Stellen Sie die Ausgabebreite für das Ziel ein, nutzen Sie „Enthalten“, wenn jedes Detail zählt, und „Ausfüllen“, wenn der Rahmen sauber gefüllt werden muss, und erhöhen Sie die Palettenqualität für Fotografien. Beachten Sie die Warnung bei großem GIF und verkleinern Sie zuerst die Breite.

Häufige Fragen

Was ist ein GIF und wie unterscheidet es sich von einem Video?

Ein GIF ist eine Reihe von Standbildern, die in einer Schleife abspielen – ohne Ton und ohne Player-Steuerung. Ein Video nutzt einen Codec, um Bewegung und Ton in eine viel kleinere Datei zu komprimieren. GIFs sind größer, spielen aber überall ohne Player ab – darum dominieren sie Chats und Social-Media-Feeds.

Wie viele Frames sollte ein GIF haben?

Fünf bis fünfzehn Frames reichen für die meisten GIFs: eine Reaktion, eine Produkt-Demo oder ein kurzer Tutorial-Schritt. Mehr Frames bedeuten eine längere Animation und eine größere Datei. Braucht Ihr GIF fünfzig Frames, ist es wahrscheinlich ein Video – und ein Videoformat dient ihm besser.

Warum sind GIF-Dateien so groß?

GIFs speichern jeden Frame als vollständiges Bild mit einer 256-Farben-Palette und komprimieren im Vergleich zu Video schlecht. Viele Frames, große Abmessungen und eine hohe Bildrate vergrößern die Datei. Reduzieren Sie zuerst die Breite, dann die Frame-Anzahl, um ein GIF schnell zu verkleinern.

Kann ich ein GIF aus einem Video erstellen?

Das Tool erstellt GIFs aus Standbildern, nicht aus Videodateien. Um ein Video in ein GIF zu verwandeln, extrahieren Sie zuerst eine Reihe von Standbildern aus dem Video und laden dann diese Frames als GIF-Frames hoch. Wählen Sie die Frames aus, die die Bewegung tragen, die Sie möchten.

Funktionieren GIFs auf allen Social-Media-Plattformen?

Auf fast allen. Chat-Apps, Social-Media-Feeds, Foren und E-Mails zeigen GIFs ohne speziellen Player an. Einige Plattformen wandeln hochgeladene GIFs automatisch in Video um – die Animation spielt aber trotzdem, das Ergebnis ist für den Betrachter also dasselbe.

Was ist die beste Größe für ein GIF?

Etwa 480 Pixel Breite ist ein guter Standard für Chat und Social-Media-Sharing: klein genug, um schnell gesendet zu werden, und groß genug, um auf einem Smartphone klar gesehen zu werden. Nutzen Sie eine größere Breite nur für eine Website oder eine Präsentation, wo das GIF größer dargestellt wird.
