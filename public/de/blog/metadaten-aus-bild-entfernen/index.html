Metadaten aus Bild entfernen: Anleitung

Metadaten aus einem Bild entfernen: Foto hochladen, EXIF und GPS löschen, die passende Methode wählen, saubere Dateien herunterladen – und das Ergebnis prüfen.

Metadaten aus einem Bild zu entfernen, dauert weniger als eine Minute. Sie laden das Foto hoch, das Tool entfernt die versteckten Daten, und Sie laden eine saubere Kopie herunter.

Diese Anleitung führt Sie Schritt für Schritt durch das kostenlose Tool Bild-Metadaten entfernen. Es läuft in Ihrem Browser, braucht kein Konto und lädt Ihre Fotos nirgendwo hoch.

Am Ende wissen Sie, wie Sie ein Foto bereinigen, einen ganzen Stapel bereinigen, die richtige Bereinigungsmethode wählen und beweisen, dass das Ergebnis sauber ist.

Was Sie vor dem Start brauchen

Sie brauchen die Bilddatei, die Sie teilen möchten, auf Ihrem Gerät gespeichert. Arbeiten Sie mit der Originaldatei, nicht mit einer Kopie, die Sie bereits irgendwo gepostet haben.

Das Tool akzeptiert JPG-, PNG-, WebP- und HEIC-Dateien bis zu 20 MB pro Datei. Das deckt Smartphone-Fotos, Spiegelreflex-JPEGs, PNG-Exporte und iPhone-HEIC-Dateien ab.

Behalten Sie eine private Kopie des Originals, wenn Ihnen die Metadaten wichtig sind. Die Bereinigung ist für die bereinigte Kopie endgültig, und Kameraeinstellungen oder GPS-Daten lassen sich daraus später nicht wiederherstellen.

Öffnen Sie das Tool in einem modernen Browser. Chrome, Firefox, Safari und Edge funktionieren alle – auf dem Desktop und auf dem Smartphone.

Wenn Sie unsicher sind, was Ihr Foto enthält, prüfen Sie es zuerst im Bild-Metadaten-Viewer. Er zeigt jeden Tag, bevor Sie entscheiden, was entfernt wird.

Schritt 1: Öffnen Sie das Tool

Gehen Sie auf die Seite Bild-Metadaten entfernen. Sie sehen eine Upload-Box und eine kurze Erklärung, was das Tool macht.

Es gibt keine Anmeldemaske und keine Bezahlschranke. Das Tool ist kostenlos, und Sie können unbegrenzt viele Fotos bereinigen – ohne Wasserzeichen oder Gebühren.

Öffnen Sie die Seite auf dem Smartphone in mobilem Safari oder Chrome. Das Layout passt sich an, und Sie können Fotos direkt aus Ihrer Galerie wählen.

Setzen Sie ein Lesezeichen, wenn Sie Fotos oft bereinigen. Verkäufer, Journalisten und Eltern nutzen es vor jedem öffentlichen Beitrag, da hilft ein schneller Zugriff.

Schritt 2: Laden Sie Ihre Fotos hoch

Ziehen Sie Fotos in die Upload-Box oder klicken Sie darauf, um Dateien von Ihrem Gerät zu wählen. Sie können ein Foto oder einen ganzen Stapel auf einmal ablegen.

Sie können auch mit Strg+V unter Windows oder Cmd+V auf dem Mac einfügen. Ein kopiertes Bild oder ein Screenshot landet direkt in der Upload-Warteschlange und wird automatisch bereinigt.

Die Bereinigung startet sofort beim Hochladen. Es gibt keinen Startknopf zu drücken und kein Warten auf einen Server, weil die ganze Arbeit im Speicher Ihres Browsers passiert.

Jede Datei darf bis zu 20 MB groß sein. Wenn eine Datei größer ist, komprimieren Sie sie zuerst mit dem Bildkomprimierer und bereinigen Sie dann die kleinere Kopie.

Wenige Sekunden später erscheint für jedes Foto eine Karte. Diese Karte zeigt Dateiname, Bereinigungsergebnis und Verifizierungs-Abzeichen.

Schritt 3: Prüfen Sie die Verifizierungs-Abzeichen

Nach dem Upload wird jede Karte automatisch erneut gescannt und zeigt, wie viele Metadaten-Tags entfernt wurden, zum Beispiel „X Metadaten-Tags entfernt, 0 verbleibend“.

Ein grünes oder smaragdgrünes Abzeichen bedeutet, dass die Ausgabe als sauber verifiziert wurde. Das Tool führt seinen Metadaten-Parser ein zweites Mal auf der Ausgabedatei aus, sodass das Abzeichen eine echte Prüfung ist, keine Vermutung.

Wenn ein Foto direkt nach dem Upload „Verifiziert sauber“ zeigt, enthielt die Quelle bereits gar keine EXIF-, GPS- oder Textblöcke. Screenshots und Fotos aus Messenger-Apps kommen häufig so an.

Warten Sie, bis die Abzeichen auf allen Karten grün werden, bevor Sie herunterladen. Ein Stapel ist erst fertig, wenn jede Karte verifiziert ist.

Wenn eine Karte verbleibende Tags zeigt, braucht die Datei einen weiteren Durchlauf. Ändern Sie die Bereinigungsmethode und klicken Sie auf „Alle erneut bereinigen“, wie in Schritt 5 erklärt.

Schritt 4: Wählen Sie die Bereinigungsmethode

Die Standardmethode ist die verlustfreie binäre Entfernung, und sie ist für die meisten JPG- und PNG-Fotos die richtige Wahl. Sie entfernt Metadatensegmente, ohne einen einzigen Pixel zu decodieren oder neu zu komprimieren.

Behalten Sie diese Methode, wenn Sie keine Qualitätsveränderung wollen. Ihr JPG bleibt ein JPG, Ihr PNG bleibt ein PNG, und transparente PNG-Hintergründe überleben bytegenau.

Wählen Sie die vollständige Canvas-Neucodierung, wenn Sie eine brandneue Bitmap ohne vererbte Segmente wollen. Sie wird außerdem automatisch für WebP- und HEIC-Eingaben genutzt und immer dann, wenn Sie das Ausgabeformat ändern.

Die Neucodierung behebt auch die Ausrichtung. Wenn ein Hochformat-JPEG nach einer verlustfreien Bereinigung seitlich aussieht, wurde das Ausrichtungs-Flag gelöscht, ohne die Pixel zu drehen. Die Canvas-Neucodierung brennt die aufrechte Ausrichtung in das exportierte Bild ein.

Sie können die Methode vor dem Download jederzeit ändern. Stellen Sie sie um, klicken Sie auf „Alle erneut bereinigen“, und der Stapel wird mit der neuen Einstellung erneut verarbeitet.

Schritt 5: Stellen Sie Ausgabeformat und Qualität ein

Standardmäßig behält das Tool das Originalformat, sodass ein JPG ein JPG bleibt und ein PNG ein PNG. Das ist die sicherste Wahl, wenn nur die Metadaten weg sollen.

Um beim Bereinigen umzuwandeln, wählen Sie JPG, PNG oder WebP unter „Ausgabeformat“. Jede Datei wird über Canvas sauber neu codiert – mit allen Metadaten entfernt und dem gewählten Format angewendet.

Stellen Sie den Schieberegler „Neucodierungs-Qualität“ beim Neucodieren zwischen 50 und 100 Prozent ein. Eine Qualität um 85 Prozent ist ein guter Standard für WebP- und JPG-Exporte und balanciert Größe und Detailtreue.

Der Schieberegler bewirkt bei Dateien mit verlustfreier binärer Entfernung nichts, weil keine Pixel neu codiert werden. Er gilt nur für WebP- und HEIC-Eingaben oder für Exporte per vollständiger Canvas-Neucodierung.

Klicken Sie nach jeder Einstellungsänderung auf „Alle erneut bereinigen“. Dateien werden beim Hochladen sofort mit Ihren aktuellen Einstellungen bereinigt – der Knopf wendet Ihre neuen Einstellungen also auf den ganzen Stapel an.

Den vollständigen Vergleich der beiden Methoden finden Sie unter Metadaten aus Bildern entfernen: Anleitung für EXIF und GPS.

Schritt 6: Laden Sie die sauberen Dateien herunter

Wenn die Abzeichen grün sind, laden Sie Ihre Dateien herunter. Klicken Sie auf „Sauber herunterladen“ bei einer einzelnen Karte, um dieses Foto zu speichern, oder auf „Alle sauber herunterladen (ZIP)“ für den ganzen Stapel.

Die ZIP-Datei heißt clean_images_no_metadata.zip. Sie enthält jedes bereinigte Foto aus dem Stapel – bereit für den Upload auf einen Marktplatz, in ein Forum oder in eine Anzeige.

Downloads sind separate Dateien. Ihre Originale auf der Festplatte bleiben unberührt, weil Browser Dateien in Ihren lokalen Ordnern nicht überschreiben können.

Speichern Sie die sauberen Dateien dort, wo Sie sie von den Originalen unterscheiden können, zum Beispiel in einem Ordner namens „sauber“ oder „bereit-zum-posten“. Sie zu verwechseln, macht den Zweck zunichte.

Teilen Sie die bereinigten Kopien, nicht die Originale. Wenn Sie versehentlich das Original hochladen, gehen die Metadaten gleich mit.

Schritt 7: Prüfen Sie die bereinigte Datei

Die Prüfung ist der Schritt, den die meisten Menschen überspringen – und sie ist der Schritt, der beweist, dass die Arbeit erledigt ist. Ziehen Sie eine heruntergeladene saubere Datei in den Bild-Metadaten-Viewer.

Wenn die Bereinigung erfolgreich war, bestätigt das grüne Banner, dass keine EXIF-, GPS- oder versteckten Kamera-Tags erkannt wurden, und es erscheint keine GPS-Warnung. Das ist eine unabhängige Prüfung der Dateibytes.

Wenn Tags übrig bleiben, zeigt die Viewer-Tabelle genau, welche überlebt haben. Häufige Überlebende sind PNG-Textblöcke und JPEG-Kommentare, die manche Bereinigungstools übersehen.

Wenn Reste auftauchen, kehren Sie zum Entfernungstool zurück, wechseln Sie zur vollständigen Canvas-Neucodierung, klicken Sie auf „Alle erneut bereinigen“ und laden Sie erneut herunter. Prüfen Sie dann die neue Datei auf dieselbe Weise.

Machen Sie daraus eine Zwei-Durchläufe-Gewohnheit bei sensiblen Fotos: prüfen, bereinigen, erneut prüfen. Die zweite Prüfung dauert Sekunden und beseitigt jeden Zweifel.

Metadaten auf dem Smartphone entfernen

Die meisten Fotos werden vom Smartphone aus geteilt, also funktioniert der Ablauf in mobilen Browsern. Öffnen Sie das Tool in iOS Safari oder Android Chrome und wählen Sie Fotos aus Ihrer Galerie.

Die Dateien werden beim Hochladen bereinigt, die Abzeichen werden grün, und Sie laden saubere Kopien direkt auf Ihr Gerät herunter. Teilen Sie dann die bereinigten Dateien aus Ihrer Galerie.

Bereinigen Sie, bevor Sie die Social-Media- oder Marktplatz-App öffnen, nicht erst danach. Sobald ein Foto gepostet ist, hat vielleicht schon jemand das Original mit seinen Metadaten heruntergeladen.

Wenn Ihre Smartphone-Kamera standardmäßig den Standort aufzeichnet, überlegen Sie, die Standortfunktion für die Kamera-App auszuschalten. So entstehen gar keine GPS-Tags an der Quelle, und künftige Fotos brauchen keine Bereinigung für den Standort.

Stapel für Marktplätze bereinigen

Verkäufer fotografieren Produkte zu Hause, und diese Fotos können GPS-Koordinaten tragen, die direkt auf die Adresse des Verkäufers zeigen. Die Stapelbereinigung beseitigt dieses Risiko für eine ganze Fotoserie auf einmal.

Ziehen Sie die vollständige Reihe von Anzeigenfotos zusammen hinein und warten Sie, bis die Abzeichen auf allen Karten grün werden. Klicken Sie dann auf „Alle sauber herunterladen (ZIP)“ und laden Sie die bereinigten Dateien in die Anzeige hoch.

Nutzen Sie dieselbe Routine für Forenbeiträge, Mietanzeigen und Kleinanzeigen. Überall dort, wo Fremde Bilder in voller Auflösung herunterladen, sind Metadaten ein Risiko, das es wert ist, entfernt zu werden.

Es gibt kein Limit für die Dateianzahl über die Grenze von 20 MB pro Datei hinaus. Hundert Anzeigenfotos lassen sich genauso leicht bereinigen wie eines – ohne Wasserzeichen, Anmeldungen oder Gebühren.

Die Datenschutzrisiken hinter dieser Routine finden Sie unter Foto-Datenschutz: Was GPS- und EXIF-Daten über Sie verraten.

Fehlersuche: Wenn die Bereinigung nicht wie erwartet funktioniert

Die meisten Probleme haben eine einfache Ursache. Gehen Sie die Liste unten durch, bevor Sie annehmen, dass das Tool kaputt ist.

  • Ein Foto sieht nach der Bereinigung seitlich aus. Die verlustfreie Bereinigung hat das EXIF-Ausrichtungs-Flag gelöscht. Wechseln Sie zur vollständigen Canvas-Neucodierung und klicken Sie auf „Alle erneut bereinigen“, um die aufrechte Ausrichtung in die Pixel einzubrennen.
  • Eine Datei zeigt nach der Bereinigung weiterhin Tags. Manche PNG-Textblöcke oder JPEG-Kommentare können einen ersten Durchlauf überleben. Probieren Sie die vollständige Canvas-Neucodierung, die das Bild von Grund auf neu aufbaut.
  • Der Qualitätsregler scheint nichts zu bewirken. Er gilt nur für WebP- und HEIC-Eingaben oder für Exporte per vollständiger Canvas-Neucodierung. Die verlustfreie binäre Entfernung codiert Pixel nie neu, sodass der Regler dort keine Wirkung hat.
  • Eine Datei lässt sich nicht hochladen. Prüfen Sie die Größe: Die Grenze liegt bei 20 MB pro Datei. Komprimieren Sie das Bild zuerst und bereinigen Sie dann die kleinere Kopie.
  • Die heruntergeladene Datei sieht genauso aus wie das Original. Das ist korrekt. Die Bereinigung entfernt versteckte Daten, keine Pixel, sodass eine erfolgreiche Bereinigung exakt so aussieht wie das Original.
  • Das Abzeichen meldet sofort „Verifiziert sauber“. Die Quelle hatte bereits keine Metadaten, was bei Screenshots und Fotos aus Messenger-Apps üblich ist. Es war nichts falsch.

Wenn ein Problem bestehen bleibt, testen Sie es mit einem frischen Original direkt aus der Galerie. So erfahren Sie, ob die Datei oder die Einstellungen die Ursache sind.

Metadaten aus HEIC-Fotos entfernen

iPhone-Fotos kommen oft als HEIC-Dateien an und brauchen eine etwas andere Behandlung. Das Tool akzeptiert HEIC-Uploads bis zu 20 MB, genau wie JPG und PNG.

HEIC-Dateien werden nicht mit der verlustfreien binären Entfernung bereinigt. Stattdessen zeichnet das Tool die Pixel auf eine frische Leinwand, was garantiert, dass alle Metadaten-Header verworfen werden.

Das bedeutet, dass eine HEIC-Bereinigung immer eine Neucodierung ist. Stellen Sie den Schieberegler „Neucodierungs-Qualität“ ein, bevor Sie herunterladen: Um 85 Prozent ist ein guter Standard, und 90 bis 100 Prozent behalten die meisten Details.

Sie können ein HEIC-Foto beim Bereinigen auch umwandeln. Wählen Sie JPG, PNG oder WebP unter „Ausgabeformat“, und das Tool exportiert eine saubere Kopie im gewählten Format.

HEIC in JPG umzuwandeln, ist ein gängiger Schritt vor dem Teilen, weil JPG überall geöffnet wird. Umwandlung und Bereinigung passieren in einem Schritt, sodass kein zweiter Durchlauf nötig ist.

Prüfen Sie nach dem Download das Ergebnis wie bei jeder anderen Datei. Ziehen Sie die bereinigte Kopie in den Bild-Metadaten-Viewer und bestätigen Sie das grüne Banner.

Was nach dem Download zu tun ist

Das Herunterladen der sauberen Datei ist nicht der letzte Schritt. Ein paar kleine Gewohnheiten nach dem Download stellen sicher, dass die saubere Kopie diejenige ist, die tatsächlich geteilt wird.

Prüfen Sie zuerst den Dateinamen. Der bereinigte Download kann denselben Namen tragen wie das Original, also bewahren Sie ihn in einem separaten Ordner auf, um die beiden nicht zu verwechseln.

Prüfen Sie zweitens mindestens eine Datei aus jedem Stapel. Öffnen Sie die bereinigte Kopie im Viewer und bestätigen Sie das grüne Banner „Keine Tags“, bevor Sie sie irgendwo hochladen.

Löschen Sie drittens die sauberen Kopien aus Ihrem Downloads-Ordner, sobald sie gepostet sind, wenn die Originale anderswo liegen. Alte saubere Kopien, die mit Originalen vermischt sind, sorgen später für Verwirrung.

Wenn Sie viertens vom Smartphone aus teilen, vergewissern Sie sich, dass das Teilen-Menü die bereinigte Datei ausgewählt hat. Galerie-Apps können für Originale und bereinigte Kopien identisch aussehen, also prüfen Sie Dateiname oder Ordner.

Kurze Zusammenfassung

Öffnen Sie das Tool Bild-Metadaten entfernen, ziehen Sie Ihre Fotos hinein und warten Sie auf die grünen Verifizierungs-Abzeichen. Wählen Sie die verlustfreie binäre Entfernung für JPG und PNG oder die vollständige Canvas-Neucodierung für WebP, HEIC, Formatwechsel oder seitliche Fotos.

Laden Sie die sauberen Dateien oder die ZIP-Datei herunter und prüfen Sie eine davon im Bild-Metadaten-Viewer. Wenn das grüne Banner erscheint, ist das Foto sicher zu teilen.

Die ganze Routine dauert unter einer Minute. Machen Sie sie zur Gewohnheit vor jedem öffentlichen Beitrag, und Ihre Fotos tragen nur das, was Sie teilen wollten.

Häufige Fragen

Wie entferne ich Metadaten aus einem Foto auf meinem iPhone?

Öffnen Sie das Tool „Bild-Metadaten entfernen“ in mobilem Safari, wählen Sie das Foto aus Ihrer Galerie und warten Sie auf das grüne Verifizierungs-Abzeichen. Tippen Sie dann auf „Sauber herunterladen“, um die bereinigte Kopie auf Ihrem Gerät zu speichern. Teilen Sie die bereinigte Kopie, nicht das Original aus Ihrer Galerie.

Kann ich Metadaten aus einem Screenshot entfernen?

Screenshots tragen meist von vornherein keine Kamera-Metadaten, weil die Zwischenablage rohe Pixel statt der originalen Kameradatei übergibt. Wenn Sie einen Screenshot in das Tool ziehen, zeigt es typischerweise sofort „Verifiziert sauber“. Das Tool prüft ihn trotzdem, sodass Sie nichts verlieren, wenn Sie ihn durchlaufen lassen.

Was ist der schnellste Weg, viele Fotos zu bereinigen, bevor eine Anzeige online geht?

Ziehen Sie die gesamte Reihe auf einmal in das Tool, warten Sie auf die grünen Abzeichen auf allen Karten und klicken Sie auf „Alle sauber herunterladen (ZIP)“. Die ZIP-Datei enthält jedes bereinigte Foto in einer Datei. Laden Sie die bereinigten Dateien in Ihre Anzeige hoch – niemals die Originale.

Muss ich ein Foto bereinigen, wenn ich es nur an einen Freund schicke?

Das hängt vom Kanal ab. Messenger-Apps wie WhatsApp entfernen Metadaten automatisch, sodass ein Foto, das auf diesem Weg geschickt wird, meist sauber ankommt. E-Mail-Anhänge und direkte Dateiübertragungen behalten oft das Original intakt – bereinigen Sie das Foto also zuerst, wenn Sie es als Datei schicken.

Warum ist mein bereinigtes Foto kleiner als das Original?

Kamerafotos tragen oft eingebettete EXIF-Vorschaubilder, XMP-Blöcke und Kommentarsegmente. Sie in der verlustfreien binären Entfernung zu löschen, spart häufig mehrere zehn Kilobyte – ohne jede Veränderung der Bildschärfe. Die kleinere Größe ist ein Bonus, kein Zeichen von Qualitätsverlust.

Kann ich das Entfernen von Metadaten nach dem Download der sauberen Datei rückgängig machen?

Nein. Die bereinigte Kopie hat keine Metadaten mehr, die sich wiederherstellen ließen. Darum sollten Sie Ihre Originaldatei in einem privaten Ordner behalten, bevor Sie bereinigen. Das Original behält seine Kameraeinstellungen und GPS-Daten für Ihre eigenen Unterlagen, während die bereinigte Kopie diejenige ist, die Sie teilen.
