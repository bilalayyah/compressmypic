SVG in PNG konvertieren

SVG-Logos und -Icons in PNG umwandeln, in der Größe, die Sie brauchen: hochladen, Skalierung wählen, Ergebnis prüfen und herunterladen.

Ein SVG-Logo ist unendlich skalierbar, doch viele Orte wollen noch immer ein PNG. Die Umwandlung dauert Sekunden, und die einzige Entscheidung, die zählt, ist die Ausgabegröße.

Wählen Sie die richtige Skalierung, und das PNG sieht perfekt aus. Wählen Sie die falsche, kommt es unscharf oder unnötig riesig heraus.

Diese Anleitung führt Schritt für Schritt durch den Ablauf, vom Hochladen des SVG bis zum Herunterladen eines scharfen PNG.

Vor dem Start: Das SVG vorbereiten

Öffnen Sie das SVG zuerst in einem Browser und bestätigen Sie, dass es korrekt rendert. Sieht es dort falsch aus, sieht es als PNG ebenfalls falsch aus.

Wandeln Sie Text in Ihrem Design-Tool in Pfade um, wenn das SVG Schrift enthält. Umgewandelter Text wird zu Formen und rendert deshalb exakt, unabhängig von Schriften.

Betten Sie verlinkte Bilder als Data-URIs in das SVG ein. Der Konverter kann keine externen Dateien abrufen, ein verlinktes Foto fehlt also im PNG.

Entfernen Sie jedes Hintergrundrechteck, wenn Sie ein transparentes PNG wollen. Eine Hintergrundform wird Teil des Bildes, während ein transparentes SVG transparent bleibt.

Schritt 1: Das SVG-zu-PNG-Tool öffnen

Öffnen Sie das SVG-zu-PNG-Tool in Ihrem Browser. Die Seite läuft auf Windows, Mac, Linux, ChromeOS, Android und iOS.

Sie sehen einen Upload-Bereich und eine Skalierungsauswahl. Diese zwei Bedienelemente sind der ganze Ablauf.

Es ist kein Konto nötig, und nichts wird hochgeladen. Die Umwandlung passiert auf Ihrem Gerät – das zählt bei Kundenlogos und Marken-Assets.

Auf dem Handy funktioniert die Seite im mobilen Browser. Tippen Sie auf den Upload-Bereich, um SVG-Dateien von Ihrem Gerät zu wählen.

Schritt 2: Ihre SVG-Dateien hochladen

Ziehen Sie Ihre SVG-Dateien auf den Upload-Bereich, oder klicken Sie ihn an, um die Dateiauswahl zu öffnen. Für einen Stapel können Sie viele Dateien auf einmal auswählen.

Jede Datei erscheint als Karte mit Vorschaubild, sodass Sie bestätigen können, dass die richtigen Dateien geladen sind. Eine falsche Datei ist leicht zu erkennen und zu entfernen.

Dateien bis zu 25 MB pro Stück werden akzeptiert – das deckt selbst riesige illustrierte Dateien mit Tausenden von Pfaden ab. Sehr komplexe SVGs brauchen einfach eine Sekunde oder zwei länger.

Sie können ein kopiertes SVG auch mit Strg+V auf dem Computer einfügen. Das ist praktisch, wenn der SVG-Code aus einer anderen App in Ihrer Zwischenablage liegt.

Schritt 3: Die Ausgabeskalierung wählen

Die Skalierungsauswahl bietet 1x, 2x, 3x und 4x. Die Skalierung vervielfacht die natürliche Größe des SVG, ein 24-Pixel-Icon mit 4x wird also ein 96-Pixel-PNG.

Für ein Website-Icon reichen meist 2x oder 3x. Das PNG sieht auf Retina-Bildschirmen scharf aus, ohne Bytes zu verschwenden.

Für ein Logo auf einer Präsentationsfolie gibt 4x eine bequeme Reserve. Ein kleines Logo, das man in PowerPoint hochskaliert, bleibt scharf, wenn das PNG genug Pixel dahinter hat.

Für den Druck wählen Sie die Skalierung, die bei der Druckgröße 300 DPI erreicht. Ein Logo, das man mit 5 Zentimetern Breite druckt, braucht mindestens 600 Pixel, rechnen Sie also von der Druckgröße rückwärts.

Schritt 4: Die Dateien umwandeln

Klicken Sie auf den Button „Umwandeln“. Das Tool zeichnet jedes SVG in der gewählten Skalierung auf eine Leinwand und kodiert das Ergebnis als PNG.

Die Umwandlung ist schnell, meist ein bis zwei Sekunden pro Datei. Sehr komplexe SVGs mit Tausenden von Pfaden brauchen etwas länger zum Zeichnen.

Jede Karte aktualisiert sich mit der neuen PNG-Größe und den Maßen. Prüfen Sie die Maße, um zu bestätigen, dass die Skalierung die erwartete Größe erzeugt hat.

Schlägt eine Datei mit einem Fehler fehl, enthält das SVG vielleicht nicht unterstützte Funktionen oder fehlerhaften Code. Öffnen Sie es in einem Browser, um zuerst zu bestätigen, dass es dort rendert.

Schritt 5: Das Ergebnis prüfen

Klicken Sie auf einer Karte auf „Vergleichen“, um SVG und PNG nebeneinander zu sehen. Zoomen Sie in die Logokanten hinein und bestätigen Sie, dass sie scharf und sauber sind.

Prüfen Sie zuerst den Text, falls das SVG welchen enthält. Falsch aussehender Text bedeutet eine fehlende Schrift, und die Lösung ist, den Text in Pfade umzuwandeln und erneut umzuwandeln.

Prüfen Sie auf fehlende Bilder. Ein leerer Raum dort, wo ein Foto sein sollte, bedeutet, dass das Bild extern verlinkt war, und Sie müssen es als Data-URI einbetten.

Prüfen Sie die Transparenz. Ein Logo, das transparent sein sollte, darf keinen weißen Kasten um sich herum zeigen, sonst hatte das SVG ein Hintergrundrechteck, das Sie entfernen müssen.

Schritt 6: Die PNG-Dateien herunterladen

Klicken Sie auf einer einzelnen Karte auf „Herunterladen“, um ein PNG zu speichern. Der Dateiname behält Ihren ursprünglichen Namen mit der Endung .png.

Für einen Stapel klicken Sie auf „Alle herunterladen“, um eine einzige ZIP-Datei mit allen umgewandelten PNGs darin zu erhalten. Das geht weit schneller, als sie einzeln herunterzuladen.

Prüfen Sie die heruntergeladenen Dateien einmal, bevor Sie sie verwenden. Öffnen Sie ein PNG in Ihrem Foto-Viewer und bestätigen Sie, dass es in der Größe, die Sie brauchen, scharf aussieht.

Behalten Sie auch die ursprünglichen SVG-Dateien. Sie sind die Originale, und Sie können sie jederzeit erneut in jeder Größe rastern, wenn Sie ein anderes PNG brauchen.

  1. Öffnen Sie das SVG-zu-PNG-Tool und laden Sie Ihre SVG-Dateien hoch.
  2. Wählen Sie eine Skalierung: 2x fürs Web, 4x für Präsentationen und Druck.
  3. Wandeln Sie um und prüfen Sie Kanten, Text und Transparenz.
  4. Laden Sie einzelne PNGs oder den ganzen Stapel als ZIP herunter.

Ein ganzes Icon-Pack umwandeln

Wählen Sie in der Dateiauswahl alle SVG-Icons auf einmal aus. Sie laden in die Warteschlange, und ein Klick wandelt sie alle mit derselben Skalierung um.

Verwenden Sie für den ganzen Pack dieselbe Skalierung. Einheitlichkeit zählt, wenn Icons gemeinsam auftreten, weil gemischte Größen ungleichmäßig aussehen.

Prüfen Sie nach der Umwandlung zwei oder drei Icons, statt alle fünfzig. Sehen diese gut aus, tun es die übrigen auch, weil die Einstellungen dieselben sind.

Laden Sie die PNG-Icons dort hoch, wo sie gebraucht werden. Ein Favicon, ein App-Icon oder ein Foliendeck akzeptiert PNG-Dateien ohne weitere Umwandlung.

Größe für jeden Zweck wählen

Für ein Favicon rastern Sie in den exakten Größen, die die Seite braucht – meist 16, 32 und 48 Pixel. Der Favicon-Generator kann diese Größen auch aus einem PNG erzeugen.

Für einen Social-Media-Avatar ist 400 mal 400 Pixel eine gute Größe. Er sieht auf Desktop und Handy scharf aus, und die Datei bleibt klein.

Für ein Präsentationslogo gibt das 4-Fache der SVG-Größe meist genug Pixel. Ein 100-Pixel-Logo mit 4x wird 400 Pixel groß und sieht auf einer Folie scharf aus.

Für den Druck rechnen Sie über die DPI. Ein 5-Zentimeter-Logo mit 300 DPI braucht 600 Pixel, wählen Sie also die Skalierung, die mindestens diese Zahl erreicht.

Typische Probleme beheben

Sieht das PNG unscharf aus, war die Skalierung zu niedrig. Rastern Sie erneut mit einer höheren Skalierung aus dem SVG-Original, weil man ein niedrig aufgelöstes PNG nachträglich nicht schärfen kann.

Sieht der Text falsch aus, fehlt die Schrift. Wandeln Sie den Text in Ihrem Design-Tool in Pfade um und wandeln Sie erneut um.

Fehlt ein verlinktes Foto, betten Sie es als Data-URI in das SVG ein. Der Konverter kann keine externen Dateien abrufen, das Bild muss also innerhalb des SVG mitreisen.

Schlägt die Datei mit einem Fehler fehl, öffnen Sie das SVG in einem Browser. Rendert es dort, versuchen Sie, es allein statt im Stapel umzuwandeln.

Tipps für Handys und Tablets

Tippen Sie auf dem Handy auf den Upload-Bereich und wählen Sie SVG-Dateien von Ihrem Gerät. Die Umwandlung läuft auf dem Handy, und die PNGs landen auf Ihrem Gerät.

Halten Sie Stapel auf dem Handy klein, weil komplexe SVGs auf einem mobilen Prozessor Zeit zum Rastern brauchen. Zehn Dateien auf einmal sind bequem.

Downloads landen im Downloads-Ordner Ihres Handys. Auf dem iPhone schauen Sie in der Dateien-App nach, auf Android in Ihrem Dateimanager.

Für ein großes Icon-Pack nehmen Sie einen Desktop. Der schnellere Prozessor und der größere Bildschirm machen fünfzig Dateien weit leichter zu handhaben.

Ein Logo für eine Visitenkarte umwandeln

Ein Visitenkarten-Logo muss bei winziger Größe scharf drucken, rastern Sie das SVG also mit 4x. Ein kleines Logo mit genug Pixeln dahinter bleibt auf der Karte scharf.

Prüfen Sie nach der Umwandlung die Farben, weil Druckfarben sich von Bildschirmfarben unterscheiden. Ein schneller Probedruck bestätigt, dass die Markenfarben auf Papier richtig aussehen.

Schicken Sie das PNG mit dem SVG als Sicherung an die Druckerei. Die Druckerei kann das SVG selbst rastern, falls das PNG ein Problem hat, beide bereitzustellen, deckt also jeden Fall ab.

Halten Sie die PNG-Datei klein, weil ein Visitenkartendrucker kein riesiges Bild braucht. Ein 1000-Pixel-Logo reicht für eine Karte völlig, und eine größere Datei verlangsamt nur den Upload.

Bestellen Sie vor dem Druck der vollen Auflage eine Testkarte. Eine einzelne Karte bestätigt Logogröße, Farben und Schärfe, bevor Sie sich auf Hunderte festlegen.

Icons für eine Website umwandeln

Website-Icons beginnen als SVG-Dateien und werden zu PNGs für ältere Browser. Rastern Sie mit dem 2- oder 3-Fachen der Anzeigegröße, damit die Icons auf Retina-Bildschirmen scharf aussehen.

Verwenden Sie für das ganze Icon-Set dieselbe Skalierung. Einheitlichkeit zählt, wenn Icons gemeinsam auftreten, weil gemischte Größen ungleichmäßig aussehen.

Testen Sie die Icons vor der Veröffentlichung auf der tatsächlichen Website. Ein Icon, das im Design-Tool perfekt aussieht, kann gegen die Hintergrundfarbe der Seite anders wirken.

Für eine moderne Website ziehen Sie in Betracht, die SVG-Dateien direkt zu nutzen. Browser zeigen SVG nativ an, und die Icons skalieren perfekt, ohne jedes Rastern.

Behalten Sie die SVG-Originale nach der Umwandlung im Projektordner. Gestaltet sich die Website neu, lassen sich die Icons erneut in neuen Größen rastern, ohne sie neu zu zeichnen.

Ein SVG für einen T-Shirt-Druck umwandeln

Ein T-Shirt-Druck braucht ein hochauflösendes Bild, und SVG ist die ideale Quelle. Rastern Sie mit der größten Skalierung, die das Tool erlaubt, bis zur Grenze von 8000 Pixeln, für einen gestochen scharfen Druck.

Prüfen Sie das Design nach der Umwandlung, weil ein T-Shirt-Druck jeden Fehler zeigt. Ein Logo, das auf dem Bildschirm gut aussieht, kann groß auf Stoff gedruckt raue Kanten offenbaren.

Schicken Sie das PNG mit dem SVG als Sicherung an die Druckerei. Die Software der Druckerei bevorzugt vielleicht ein Format gegenüber dem anderen, beide bereitzustellen, deckt also jeden Fall ab.

Prüfen Sie bei einem dunklen T-Shirt die Transparenz. Ein Logo mit transparentem Hintergrund druckt sauber auf dunklem Stoff, während ein Logo mit weißem Kasten falsch aussieht.

Bestellen Sie vor dem Druck einer Auflage ein einzelnes Test-Shirt. Ein Probedruck bestätigt Größe, Farben und Platzierung, bevor Sie sich auf Dutzende Shirts festlegen.

Ein SVG für eine Präsentation umwandeln

Präsentationsfolien brauchen scharfe Logos, und SVG ist die ideale Quelle. Rastern Sie mit dem 4-Fachen der SVG-Größe, damit das Logo auch projiziert auf eine große Leinwand scharf bleibt.

Prüfen Sie das Logo nach der Umwandlung auf dem tatsächlichen Folienhintergrund. Ein Logo, das auf Weiß perfekt aussieht, kann auf einer farbigen Folie einen leichten Fransensaum zeigen, wenn die Qualität niedrig war.

Bei einem Deck mit vielen Folien wandeln Sie alle Logos auf einmal um. Eine Stapel-Umwandlung dauert Minuten, und die PNGs sind bereit, um in die Folien zu wandern.

Testen Sie das Deck vor dem Vortrag auf dem Projektor. Eine Folie, die auf einem Laptop scharf aussieht, kann projiziert weich wirken, und ein schneller Test fängt das Problem früh ab.

Behalten Sie die SVG-Originale nach der Umwandlung im Projektordner. Wird die Präsentation mit einer neuen Vorlage wiederverwendet, lassen sich die Logos erneut in neuen Größen rastern.

Ein SVG für ein Favicon umwandeln

Ein Favicon ist das winzige Icon im Browser-Tab und beginnt meist als SVG-Logo. Rastern Sie es mit 16, 32 und 48 Pixeln für die Standard-Favicon-Größen.

Gestalten Sie das Favicon einfach, weil winzige Größen Details verbergen. Ein komplexes Logo mit 16 Pixeln wird zu einem Fleck, während eine einfache Form erkennbar bleibt.

Testen Sie das Favicon nach dem Hinzufügen in mehreren Browsern. Ein schneller Blick bestätigt, dass es korrekt angezeigt wird, die Seite sieht also in jedem Tab gepflegt aus.

Für moderne Browser ziehen Sie in Betracht, das SVG-Favicon direkt zu nutzen. Browser zeigen SVG-Favicons nativ an, und das Icon skaliert perfekt, ohne jedes Rastern.

Behalten Sie das SVG-Original nach der Umwandlung. Gestaltet sich die Seite neu, lässt sich das Favicon erneut in neuen Größen rastern, ohne das Logo neu zu zeichnen.

Ein SVG für ein Website-Banner umwandeln

Ein Website-Banner ist ein breites Bild, und SVG ist die ideale Quelle, wenn das Banner eine Grafik statt eines Fotos ist. Rastern Sie in der Anzeigebreite des Banners für ein scharfes Ergebnis.

Prüfen Sie vor der Umwandlung die Bannermaße. Ein Banner, das mit 1200 Pixeln Breite angezeigt wird, braucht ein PNG von mindestens dieser Breite, sonst wirkt es weich.

Für ein Banner mit Text rastern Sie mit dem 2-Fachen der Anzeigegröße. Der Text bleibt auf Retina-Bildschirmen scharf, und die Datei ist trotzdem klein genug, um schnell zu laden.

Testen Sie das Banner nach der Umwandlung auf Desktop und Handy. Ein Banner, das auf einem breiten Bildschirm perfekt aussieht, kann auf einem schmalen schlecht zugeschnitten werden, und ein schneller Test fängt das ab.

Behalten Sie das SVG-Original im Projektordner. Gestaltet sich die Website mit einer neuen Bannergröße neu, lässt sich die Grafik erneut rastern, ohne sie neu zu zeichnen.

Häufige Fragen

Wie groß ist das PNG bei 1x-Skalierung?

Bei 1x entspricht das PNG der natürlichen Größe des SVG, ein 24-Pixel-Icon wird also ein 24-Pixel-PNG. Für scharfe Ergebnisse auf modernen Bildschirmen nutzen Sie 2x oder 3x, für Präsentationen oder Druck 4x. Der Export ist auf 8000 Pixel auf der längsten Seite begrenzt, was bei Icons und Logos selten eine Rolle spielt.

Kann ich SVG-Dateien auf meinem Handy umwandeln?

Ja. Öffnen Sie das Tool im Browser Ihres Handys, tippen Sie auf den Upload-Bereich und wählen Sie SVG-Dateien von Ihrem Gerät. Die Umwandlung läuft auf dem Handy, und die PNGs landen auf Ihrem Gerät. Halten Sie Stapel auf dem Handy klein, weil komplexe SVGs auf dem Handy Zeit zum Rastern brauchen.

Welchen Dateinamen behält das exportierte PNG?

Das PNG behält Ihren ursprünglichen SVG-Dateinamen mit der Endung .png, aus logo.svg wird also logo.png. Das macht es leicht auffindbar und hält Ihre Dateien organisiert. Bei einem Stapel enthält die ZIP-Datei jedes PNG mit seinem passenden Originalnamen.

Unterstützt der Konverter SVG-Animationen?

Nein, nicht wirklich. SVG-Animationen mit SMIL oder CSS werden nicht erhalten, weil der Konverter ein einzelnes statisches Einzelbild auf die Leinwand zeichnet. Das Ergebnis ist ein Standbild des SVG, wie es zu Beginn erscheint. Für ein animiertes Logo behalten Sie das SVG selbst.

Kann ich ein SVG rastern, in dem ein Bild als Data-URI eingebettet ist?

Ja. Bilder, die als Data-URIs in das SVG eingebettet sind, gehören zur Datei und rendern deshalb im PNG korrekt. Das ist der richtige Weg, Fotos in ein SVG für die Umwandlung einzubinden. Verlinkte externe Bilder dagegen werden ausgelassen, weil der Konverter sie nicht abrufen kann.

Warum sieht mein umgewandeltes PNG unscharf aus?

Die Skalierung war zu niedrig für die Größe, die Sie brauchen. Ein 24-Pixel-Icon, das man mit 1x rastert, ist nur 24 Pixel groß, und streckt man es auf 200 Pixel, wird es unscharf. Rastern Sie erneut mit einer höheren Skalierung aus dem SVG-Original, weil man ein niedrig aufgelöstes PNG nachträglich nicht schärfen kann.
