SVG in PNG umwandeln: Anleitung

SVG-Logos und -Icons in PNG umwandeln, in jeder Größe. Skalierung, Transparenz, Schriften, Verläufe und die Grenzen – alles erklärt.

Ein SVG-Logo lässt sich auf jede Größe skalieren, ohne je unscharf zu werden – doch die Hälfte der Orte, an denen man es braucht, akzeptiert kein SVG. Ein Formular, eine E-Mail oder ein altes Programm will ein PNG, und das SVG muss zu Pixeln werden.

Die Umwandlung von SVG in PNG, Rastern genannt, verwandelt die Vektorformen in ein festes Pixelraster in der Größe, die Sie wählen. Das Ergebnis ist ein gewöhnliches Bild, das sich überall öffnen lässt.

Diese Anleitung erklärt, wie das Rastern funktioniert, welche Skalierung man nimmt und welche Fallen bei Schriften, verlinkten Bildern und Transparenz lauern.

Was ist eine SVG-Datei?

SVG steht für Scalable Vector Graphics. Anders als ein Foto, das Pixel speichert, speichert ein SVG Anweisungen: Zeichne hier einen Kreis, dort eine Linie, fülle diese Form mit Blau.

Weil die Datei Formen statt Pixel beschreibt, kann sie auf jede Größe skaliert werden, ohne an Schärfe zu verlieren. Ein 24-Pixel-Icon und eine Werbetafel aus demselben SVG sehen beide perfekt aus.

SVG-Dateien sind Text, man kann sie also in einem Texteditor öffnen und den Code lesen. Das macht sie auch winzig für einfache Grafiken, oft nur ein paar Kilobyte.

Das Format ist ideal für Logos, Icons und Illustrationen. Für Fotos eignet es sich weniger, die speichert man besser als Pixel.

Was bedeutet Rastern?

Rastern verwandelt Vektorformen in ein Pixelraster. Der Konverter liest die SVG-Anweisungen, zeichnet die Formen auf eine Leinwand und speichert das Ergebnis als PNG.

Die entscheidende Wahl ist die Ausgabegröße. Ein 24-Pixel-Icon, das man mit 1x rastert, wird ein 24-Pixel-PNG, während dasselbe Icon mit 4x ein 96-Pixel-PNG wird – scharf genug für hochauflösende Bildschirme.

Ist das Bild einmal gerastert, ist es fixiert. Ein 96-Pixel-PNG lässt sich nicht auf 500 Pixel hochskalieren, ohne unscharf zu werden – anders als das SVG, aus dem es stammt.

Behalten Sie immer das SVG-Original. Es ist die Masterkopie, und Sie können es jederzeit erneut in jeder Größe rastern, wenn Sie ein anderes PNG brauchen.

Die richtige Skalierung wählen

Für ein Website-Icon reichen meist das 2- oder 3-Fache der Anzeigegröße. Ein 24-Pixel-Icon, das man auf einem Retina-Bildschirm anzeigt, braucht ein 48- oder 72-Pixel-PNG, um scharf auszusehen.

Für ein Logo auf einer Präsentationsfolie gibt 4x eine bequeme Reserve. Ein kleines Logo, das man in PowerPoint hochskaliert, bleibt scharf, wenn das PNG genug Pixel dahinter hat.

Für den Druck gehen Sie noch größer. Ein Logo, das man mit 5 Zentimetern Breite druckt, braucht bei 300 DPI mindestens 600 Pixel, wählen Sie also eine Skalierung, die diese Größe erreicht.

Die Exportskalierung ist auf 8000 Pixel auf der längsten Seite begrenzt. Für die meisten Icons und Logos spielt die Grenze nie eine Rolle, weil ein 100-Pixel-Logo mit 4x nur 400 Pixel groß ist.

Transparenz bleibt erhalten

SVG-Dateien haben oft transparente Hintergründe, und das PNG behält diese Transparenz. Ein Logo, das man in PNG rastert, sitzt sauber auf jeder Hintergrundfarbe.

Prüfen Sie das Ergebnis vor dem Herunterladen mit der Vergleichsansicht. Zoomen Sie in die Logokanten hinein und bestätigen Sie, dass die Transparenz sauber aussieht, ohne weißen Fransensaum.

Hat das SVG ein Hintergrundrechteck, wird dieses Rechteck Teil des PNG. Entfernen Sie die Hintergrundform in Ihrem Design-Tool, wenn Sie ein transparentes Ergebnis wollen.

Für ein Logo, das auf vielen Hintergründen funktionieren muss, ist Transparenz unverzichtbar. Behalten Sie das SVG-Original und rastern Sie ein transparentes PNG, wann immer Sie eines brauchen.

Schriften und Text in SVG

Text in einem SVG hängt von Schriften ab, und der Konverter hat die Schrift, die Ihr SVG nutzt, vielleicht nicht. Fehlt die Schrift, fällt der Text auf eine Standardschrift zurück, was das Aussehen verändert.

Webschriften, auf die man innerhalb eines SVG verweist, werden bei der Umwandlung nicht geladen. Der Browser kann sie im Raster-Kontext nicht abrufen, der Text rendert also in einer Ersatzschrift.

Die Lösung ist, Text vor der Umwandlung in Ihrem Design-Tool in Pfade umzuwandeln. Umgewandelter Text wird zu Formen, nicht zu Buchstaben, und rendert deshalb exakt, unabhängig von Schriften.

Für ein Logo ist umgewandelter Text ohnehin der professionelle Standard. Er garantiert, dass die Schrift auf jedem Rechner identisch aussieht, überall.

Verlinkte Fotos und externe Dateien

Ein SVG kann auf eine externe Bilddatei verweisen, etwa ein Foto, das per URL verlinkt ist. Dieses verlinkte Bild wird im PNG fehlen, weil der Konverter es nicht abrufen kann.

Dasselbe gilt für externe CSS-Dateien. Stile, die man in einer separaten Datei definiert, werden bei der Umwandlung nicht geladen, die Formen können also ohne ihre Farben rendern.

Die Lösung ist, vor der Umwandlung alles innerhalb des SVG einzubetten. Bilder sollten Data-URIs sein, und Stile sollten inline stehen, damit die Datei vollständig in sich geschlossen ist.

Die meisten Design-Tools haben eine Option, Bilder beim SVG-Export einzubetten. Nutzen Sie sie, dann stimmt das umgewandelte PNG exakt mit dem Original überein.

Verläufe, Deckkraft und Effekte

Verläufe innerhalb eines SVG rendern bei der Umwandlung korrekt. Ein weicher Übergang von einer Farbe zur anderen wird im PNG zu einem weichen Übergang.

Deckkraft funktioniert ebenfalls. Eine Form mit 50 Prozent Deckkraft erscheint im PNG halbtransparent und vermischt sich mit dem, was dahinter liegt.

Komplexe Filter, etwa Weichzeichner und Schlagschatten, die man in SVG definiert, rendern meist auch. Die SVG-Engine des Browsers kommt mit den meisten Standardfiltern korrekt zurecht.

Sehr exotische Effekte überleben vielleicht nicht. Sieht ein Filter im PNG falsch aus, vereinfachen Sie ihn im Design-Tool oder akzeptieren Sie den kleinen Unterschied.

Ein Icon-Pack im Stapel umwandeln

Sie können ein ganzes Icon-Pack aus SVGs auf einmal umwandeln. Jede Datei wird einzeln umgewandelt, und die ZIP-Datei enthält sie alle, bereit zur Verwendung.

Verwenden Sie für den ganzen Pack dieselbe Skalierung. Einheitlichkeit zählt, wenn Icons gemeinsam auftreten, weil gemischte Größen ungleichmäßig aussehen.

Dateien bis zu 25 MB pro Stück werden akzeptiert – das deckt selbst riesige illustrierte Dateien mit Tausenden von Pfaden ab. Sehr komplexe SVGs brauchen zum Rastern einfach eine Sekunde oder zwei länger.

Prüfen Sie nach der Umwandlung zwei oder drei Icons, statt alle fünfzig. Sehen diese gut aus, tun es die übrigen auch, weil die Einstellungen dieselben sind.

Wann man statt SVG PNG nimmt

Nehmen Sie PNG, wenn das Ziel kein SVG akzeptiert. Formulare, E-Mails, alte Programme und viele soziale Plattformen wollen Rasterbilder, keine Vektordateien.

Nehmen Sie PNG, wenn das Bild überall identisch aussehen muss. Ein SVG kann in verschiedenen Browsern unterschiedlich rendern, während ein PNG in jeder App gleich aussieht.

Nehmen Sie PNG für Profilbilder und Avatare in sozialen Netzwerken. Die meisten Plattformen wandeln Uploads ohnehin in Rasterformate um, ein PNG gibt Ihnen also Kontrolle über das Ergebnis.

Behalten Sie das SVG fürs Web und für künftige Bearbeitungen. Das Vektor-Original ist die Datei, zu der man zurückkehrt, wann immer man eine andere Größe oder ein anderes Format braucht.

Verändert die Umwandlung die Farben?

Die Umwandlung von SVG in PNG verändert die Farben nicht. Die Formen werden mit denselben Farbwerten gezeichnet, und das PNG speichert sie exakt.

Farbprofile sind die einzige Feinheit. Ein SVG mit eingebettetem Profil kann im PNG leicht anders rendern, der Unterschied ist aber meist unsichtbar.

Prüfen Sie bei Markenfarben das PNG gegen das Original. Öffnen Sie beide nebeneinander und bestätigen Sie, dass die Farben passen, vor allem bei gesättigten Markentönen.

Sieht eine Farbe falsch aus, liegt das Problem meist an einer fehlenden Schrift oder einem verlinkten Bild, nicht an der Farbe selbst. Prüfen Sie diese zuerst, bevor Sie die Umwandlung beschuldigen.

Dateigrößen nach der Umwandlung

Ein kleines SVG-Icon von 5 KB kann je nach Skalierung zu einem PNG von 20 KB oder mehr werden. Pixel kosten mehr Bytes als Vektor-Anweisungen, vor allem bei großen Größen.

Die PNG-Größe wächst mit dem Quadrat der Skalierung. Verdoppelt man die Skalierung, vervierfacht sich die Pixelzahl, ein 4x-PNG ist also sechzehnmal größer als ein 1x-PNG.

Wählen Sie die kleinste Skalierung, die den Bedarf deckt. Ein 2x-PNG für ein Website-Icon reicht völlig, und ein 4x-PNG für dasselbe Icon verschwendet Bytes ohne sichtbaren Nutzen.

Für ein großes Druck-PNG ist die Größe unvermeidlich. Eine Druckdatei mit 300 DPI braucht viele Pixel, und das PNG wird groß sein – was für den Druck richtig ist.

Typische Probleme und Lösungen

Schlägt ein SVG beim Rastern mit einem Fehler fehl, enthält die Datei vielleicht nicht unterstützte Funktionen oder fehlerhaften Code. Öffnen Sie es zuerst in einem Browser, um zu bestätigen, dass es dort rendert.

Sieht der Text falsch aus, fehlt die Schrift. Wandeln Sie den Text in Ihrem Design-Tool in Pfade um und wandeln Sie erneut um.

Fehlt ein verlinktes Foto, betten Sie es als Data-URI in das SVG ein. Der Konverter kann keine externen Dateien abrufen, das Bild muss also innerhalb des SVG selbst mitreisen.

Sieht das PNG unscharf aus, war die Skalierung zu niedrig. Rastern Sie erneut mit einer höheren Skalierung, weil man ein niedrig aufgelöstes PNG nachträglich nicht schärfen kann.

SVG-Logos für soziale Netzwerke

Soziale Netzwerke akzeptieren keine SVG-Uploads, ein Logo muss also zu einem PNG werden, bevor es ein Profilbild oder ein Titelbild sein kann. Rastern in der richtigen Größe ergibt ein scharfes Ergebnis.

Für ein Profilbild rastern Sie mit 400 mal 400 Pixeln. Das Bild sieht auf Desktop und Handy scharf aus, und die Datei bleibt klein genug, um schnell hochzuladen.

Für ein Titelbild rastern Sie in der empfohlenen Größe der Plattform. Facebook, X und LinkedIn haben jeweils unterschiedliche Titelmaße, und die richtige Größe zählt mehr als das Format.

Prüfen Sie das Logo nach der Umwandlung, weil soziale Plattformen Profilbilder kreisförmig zuschneiden. Ein Logo mit wichtigen Details nahe den Rändern kann sie durch den kreisförmigen Zuschnitt verlieren.

Behalten Sie das SVG-Original für die nächste Plattform. Ein neues soziales Netzwerk mit anderen Größen braucht nur ein frisches Rastern, kein Redesign.

SVG-Icons für Apps

App-Icons beginnen als SVG-Dateien im Design-Tool und werden zu PNGs für die App-Stores. Jeder Store hat eigene Größenanforderungen, ein SVG erzeugt also viele PNGs.

Rastern Sie das Icon mit 1024 mal 1024 Pixeln für den App Store und skalieren Sie dann für kleinere Größen herunter. Ein großer Master erzeugt bei jeder kleineren Größe scharfe Ergebnisse.

Für Android rastern Sie in den Größen, die der Play Store aufführt – meist 512 mal 512 für das Store-Icon und kleinere Größen für den Launcher. Dasselbe SVG bedient sie alle.

Testen Sie die Icons vor der Einreichung auf hellem und dunklem Hintergrund. Ein Icon, das auf einen weißen Hintergrund angewiesen ist, verschwindet auf einem dunklen Theme – die Lösung ist eine transparente Version.

Behalten Sie die SVG-Originale im Projekt-Repository. Sie sind die Quell-Assets, und jeder Plattform-Build stammt von ihnen, sie verdienen also Versionskontrolle.

SVG für Druckmaterialien

Druckmaterialien wie Visitenkarten, Flyer und Poster brauchen hochauflösende Bilder, und SVG ist die ideale Quelle. Rastern Sie mit 300 DPI für einen gestochen scharfen Druck.

Für ein Visitenkarten-Logo rastern Sie mit dem 4-Fachen der SVG-Größe. Ein kleines Logo, das man im Druck hochskaliert, bleibt scharf, wenn das PNG genug Pixel dahinter hat.

Für ein Poster rastern Sie mit der größten Skalierung, die das Tool erlaubt, bis zur Grenze von 8000 Pixeln. Ein großer Druck braucht viele Pixel, und die Grenze schränkt echte Posterarbeit selten ein.

Prüfen Sie nach der Umwandlung die Farben, weil Druckfarben sich von Bildschirmfarben unterscheiden. Ein schneller Probedruck bestätigt, dass die Markenfarben auf Papier richtig aussehen.

Schicken Sie das PNG mit dem SVG als Sicherung an die Druckerei. Die Druckerei kann das SVG selbst rastern, falls das PNG ein Problem hat, beide bereitzustellen, deckt also jeden Fall ab.

SVG für E-Mail-Signaturen

E-Mail-Signaturen brauchen ein kleines Logo, und SVG wird in den meisten E-Mail-Programmen nicht unterstützt. Rastern Sie das Logo in PNG in kleiner Größe, meist 100 bis 200 Pixel breit.

Halten Sie die PNG-Datei klein, wenn möglich unter 50 KB. Ein großes Logo in jeder E-Mail verschwendet Bandbreite und nervt die Empfänger, während ein kleines sofort lädt.

Hosten Sie das Logo auf Ihrer Website und verlinken Sie es in der Signatur, statt es anzuhängen. Ein verlinktes Bild lädt von Ihrem Server und hält die E-Mail selbst klein.

Testen Sie die Signatur vor der Einführung in mehreren E-Mail-Programmen. Ein schneller Test in Gmail, Outlook und Apple Mail fängt die kaputten Bilder ab, bevor Ihre Kontakte sie sehen.

Für ein Logo mit Transparenz behält das PNG sie. Das Signatur-Logo sitzt sauber auf jedem E-Mail-Hintergrund, während eine JPG-Version einen weißen Kasten zeigen würde.

SVG für Favicons

Ein Favicon ist das winzige Icon im Browser-Tab und beginnt meist als SVG-Logo. Rastern Sie es mit 16, 32 und 48 Pixeln für die Standard-Favicon-Größen.

Moderne Browser akzeptieren auch SVG-Favicons direkt, Sie müssen also vielleicht gar nicht umwandeln. Prüfen Sie die Browser-Unterstützung für Ihr Publikum, bevor Sie entscheiden.

Für ältere Browser ist das PNG-Favicon die sichere Wahl. Ein 32-Pixel-PNG funktioniert in jedem Browser, während ein SVG-Favicon auf einem alten scheitern kann.

Gestalten Sie das Favicon einfach, weil winzige Größen Details verbergen. Ein komplexes Logo mit 16 Pixeln wird zu einem Fleck, während eine einfache Form erkennbar bleibt.

Testen Sie das Favicon nach dem Hinzufügen in mehreren Browsern. Ein schneller Blick bestätigt, dass es korrekt angezeigt wird, die Seite sieht also in jedem Tab gepflegt aus.

Bereit zum Rastern? Öffnen Sie das SVG-zu-PNG-Tool und ziehen Sie Ihre Dateien hinein. Die Schritte finden Sie unter SVG in PNG konvertieren, und zur Vektor-gegen-Raster-Frage lesen Sie SVG vs PNG: Vektor vs Raster erklärt. Wenn Ihre SVGs Teil eines gemischten Stapels sind, übernimmt sie der Bild-Konverter ebenfalls.

Häufige Fragen

Welche Skalierung sollte ich wählen, um aus einem 24-Pixel-Icon ein scharfes PNG zu machen?

Nehmen Sie 4x für ein 96-Pixel-PNG, das auf Retina-Bildschirmen und in Präsentationen scharf aussieht. Für ein Website-Icon reichen meist 2x oder 3x. Für den Druck wählen Sie eine Skalierung, die bei der Druckgröße mindestens 300 DPI erreicht. Der Export ist auf 8000 Pixel auf der längsten Seite begrenzt, was selten eine Rolle spielt.

Behält SVG in PNG den transparenten Hintergrund?

Ja. SVG-Dateien mit transparentem Hintergrund ergeben transparente PNGs, ein Logo sitzt also sauber auf jeder Hintergrundfarbe. Hat das SVG ein Hintergrundrechteck, wird dieses Rechteck Teil des PNG – entfernen Sie es also zuerst in Ihrem Design-Tool, wenn Sie Transparenz wollen.

Warum fehlt ein verlinktes Foto in meinem umgewandelten PNG?

Der Konverter kann bei der Umwandlung keine externen Dateien abrufen, ein Bild, das per URL verlinkt ist, wird also ausgelassen. Betten Sie das Bild vor der Umwandlung als Data-URI in das SVG ein, damit die Datei vollständig in sich geschlossen ist. Die meisten Design-Tools haben eine Option, Bilder beim SVG-Export einzubetten.

Kann ich eine Webschrift in einem SVG für den PNG-Export nutzen?

Nicht verlässlich. Webschriften, auf die man innerhalb eines SVG verweist, werden bei der Umwandlung nicht geladen, der Text fällt also auf eine Standardschrift zurück. Wandeln Sie Text vor der Umwandlung in Ihrem Design-Tool in Pfade um, damit die Schrift zu Formen wird und exakt rendert, unabhängig von Schriften.

Wie groß ist das größte PNG, das ein SVG erzeugen kann?

Die Exportskalierung ist auf 8000 Pixel auf der längsten Seite begrenzt, ein sehr großes SVG mit 4x stoppt also an dieser Obergrenze. Für die meisten Icons und Logos spielt die Grenze nie eine Rolle, weil ein 100-Pixel-Logo mit 4x nur 400 Pixel groß ist. Prüfen Sie für Druckarbeiten, ob die begrenzte Größe Ihre DPI-Anforderungen noch erfüllt.

Ist die PNG-Ausgabe verlustfrei?

Ja. PNG ist ein verlustfreies Format, die gerasterten Pixel werden also exakt gespeichert, wie sie gezeichnet wurden. Das PNG kann allerdings nicht schärfer sein als das Rastern, weil die Vektorformen in der gewählten Skalierung in Pixel fixiert werden. Für ein schärferes Ergebnis rastern Sie erneut mit einer höheren Skalierung aus dem SVG-Original.
