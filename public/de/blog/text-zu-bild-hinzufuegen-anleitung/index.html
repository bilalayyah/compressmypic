Text zu Bildern hinzufügen: Die komplette Anleitung

Text verwandelt ein Bild in eine Botschaft. Eine Bildunterschrift erklärt, was das Foto zeigt, ein Titel gibt ihm einen Namen und ein Zitat gibt ihm eine Stimme.

Text zu einem Bild hinzuzufügen, ist eine einfache Fähigkeit mit vielen Verwendungen: Social-Media-Beiträge, Memes, Präsentationen, Produktetiketten und kommentierte Screenshots beruhen alle darauf.

Diese Anleitung erklärt, wie man Text gut hinzufügt. Sie behandelt Schriftarten, Größe, Farbe, Kontrast, Konturen, Positionierung und die Fehler, die Text unlesbar machen.

Was Text auf einem Bild bewirkt

Text fügt Bedeutung hinzu, die das Bild allein nicht tragen kann. Ein Foto eines Berges ist nur ein Berg, doch dasselbe Foto mit einer Bildunterschrift wird zu einer Erinnerung, einem Witz oder einer Einladung.

Text fügt auch Kontext hinzu. Ein Datum, ein Ort oder ein Name, der auf das Bild geschrieben wird, sagt dem Betrachter, was er sieht – ohne dass eine separate Erklärung nötig wäre.

Für Unternehmen ist Text auf einem Bild ein Etikett. Ein Produktfoto mit Preis, ein Sale-Banner mit Rabatt oder ein Poster mit Veranstaltungsdatum nutzen alle Text zum Verkaufen.

Der Schlüssel ist Zurückhaltung. Ein paar gut platzierte Worte stärken ein Bild, während ein Absatz, der auf ein Foto gequetscht wird, genau das verbirgt, was er beschreiben sollte.

Bildunterschriften, Titel und Wasserzeichen sind verschiedene Aufgaben

Eine Bildunterschrift erklärt das Bild. Sie sitzt nah am Motiv, ist leicht zu lesen und soll von jedem gesehen werden, der das Foto betrachtet.

Ein Titel benennt das Bild. Er ist meist größer und fetter als eine Bildunterschrift und gibt den Ton für alles andere auf der Seite oder im Beitrag vor.

Ein Wasserzeichen schützt das Bild. Es identifiziert den Besitzer, ist oft halbtransparent und soll Kopieren und erneutes Posten überleben.

Verwechseln Sie die drei nicht. Eine Bildunterschrift, die wie ein Wasserzeichen aussieht, wird ignoriert, und ein Wasserzeichen, das wie eine Bildunterschrift aussieht, schützt nichts.

Schriftarten: Eine Schrift wählen, die passt

Die Schriftart bestimmt die Stimmung des Textes, bevor jemand die Worte liest. Eine fette serifenlose Schrift wirkt modern und direkt, während eine Serifenschrift klassisch und formell wirkt.

Wählen Sie eine Schriftart, die zum Bild passt. Ein verspieltes Meme braucht eine fette, klobige Schrift, während ein Hochzeitsfoto etwas Elegantes und Leichtes braucht.

Beschränken Sie sich auf eine oder zwei Schriftarten pro Bild. Viele Schriftarten zu mischen, wirkt chaotisch, während eine einzige konsistente Schrift das Design sauber und professionell hält.

Prüfen Sie die Schriftart in der Größe, in der Sie sie nutzen werden. Eine dekorative Schrift, die in großen Größen wunderschön aussieht, kann unlesbar werden, wenn sie klein ist.

Textgröße: Kleine Fotos oder große Fotos

Die Textgröße wird als Prozentsatz des Bildes festgelegt, von 2 Prozent bis 22 Prozent. Das heißt: Dieselbe Einstellung wirkt auf einem kleinen Thumbnail und einem riesigen Kamerafoto konsistent.

Eine Größe, die auf einem großen Foto richtig aussieht, kann auf einem kleinen Foto unsichtbar sein, wenn sie in Pixeln festgelegt ist. Die Prozentbemessung vermeidet dieses Problem vollständig.

Für eine Schlagzeile nutzen Sie eine größere Größe nahe am oberen Ende des Bereichs. Für eine Bildunterschrift oder eine Quellenangabe nutzen Sie eine kleinere Größe, die lesbar bleibt, ohne das Bild zu dominieren.

Prüfen Sie den Text in der tatsächlichen Größe, in der Sie ihn teilen werden. Eine Schlagzeile, die in voller Größe fett aussieht, kann in einer Social-Media-Feed-Vorschau winzig sein, und eine Bildunterschrift, die für ein Thumbnail bemessen ist, kann einen großen Druck dominieren.

Farbe und Kontrast: Text lesbar machen

Weißer Text funktioniert auf dunklen Hintergründen und schwarzer Text auf hellen, doch die meisten Fotos enthalten beides. Eine einzige Farbe verschwindet immer irgendwo im Bild.

Kontrast ist es, was Text lesbar macht, nicht Farbe allein. Eine helle Farbe auf hellem Hintergrund versagt, während eine dunkle Farbe auf dunklem Hintergrund genauso versagt.

Platzieren Sie Text über dem schlichtesten Teil des Fotos. Eine Bildunterschrift über einem klaren Himmel oder einer leeren Wand ist weitaus leichter zu lesen als eine über einer belebten Menschenmenge oder einem Wald.

Wenn kein schlichter Bereich existiert, fügen Sie eine Hintergrundfläche hinzu. Ein halbtransparenter dunkler Kasten hinter weißem Text macht ihn überall lesbar, auch wenn er mehr vom Bild verdeckt.

Konturen und Schlagschatten

Eine Kontur ist ein Rand, der um jeden Buchstaben gezogen wird. Eine dünne dunkle Kontur um weißen Text hält ihn auf einem hellen Himmel lesbar – darum nutzen Memes sie.

Ein Schlagschatten hebt den Text vom Hintergrund ab. Er fügt eine weiche dunkle Kante hinter den Buchstaben hinzu, die ihnen hilft, hervorzustechen, ohne den harten Look einer Kontur.

Nutzen Sie das eine oder das andere, nicht beides in voller Stärke. Eine Kontur plus ein starker Schatten lässt den Text überladen wirken, während ein einzelner Effekt ihn sauber hält.

Für klassischen Meme-Text nutzen Sie weiße Buchstaben mit einer dicken dunklen Kontur. Die Kombination ist auf fast jedem Hintergrund lesbar – darum wurde sie zum Standard.

Positionierung und Ebenen

Textebenen lassen sich überall auf dem Bild verschieben. Ziehen Sie eine Ebene, um sie zu platzieren, und das Tool lässt Sie jede Ebene separat auswählen, wenn Sie mehrere haben.

Oben und unten sind die klassischen Positionen für Bildunterschriften. Eine Schlagzeile oben und eine Pointe unten ist das Meme-Format – und es funktioniert, weil das Auge von oben nach unten liest.

Halten Sie Text von den Rändern fern. Eine Bildunterschrift, die den Rand berührt, wirkt beengt, und Plattformen schneiden die Ränder für verschiedene Bildschirmgrößen oft erneut zu.

Wenn Sie mehrere Ebenen haben, wählen Sie die aus, die Sie bearbeiten möchten, bevor Sie sie ändern. Die falsche Ebene zu bearbeiten, ist ein häufiger Fehler, und er lässt sich leicht vermeiden, indem Sie prüfen, welche Ebene aktiv ist.

Text für Wirkung drehen

Text lässt sich in eigenen Winkeln kippen, was einem Design Energie verleiht. Eine leicht diagonale Schlagzeile wirkt dynamisch, während gerader Text ruhig und formell wirkt.

Nutzen Sie Drehung sparsam. Eine kleine Neigung von wenigen Grad fügt Charakter hinzu, während ein steiler Winkel den Text schwer lesbar macht und wie ein Fehler aussieht.

Diagonaler Text funktioniert gut auf Postern und Social-Media-Grafiken, bei denen das Design ins Auge fallen soll. Er funktioniert schlecht bei Anleitungen und Etiketten, bei denen Klarheit am wichtigsten ist.

Prüfen Sie gedrehten Text in der Größe, in der er betrachtet wird. Eine Neigung, die in voller Größe gut aussieht, kann kleinen Text in einer Feed-Vorschau unlesbar machen.

Mehrzeilige Bildunterschriften

Das Drücken der Eingabetaste innerhalb des Textinhalts erzeugt eine neue Zeile. So können Sie eine Bildunterschrift schreiben, die sich über zwei oder drei Zeilen erstreckt, ohne für jede eine separate Ebene zu erstellen.

Halten Sie Zeilen kurz. Eine Bildunterschrift, die über die gesamte Breite des Bildes verläuft, ist schwer zu lesen, während kurze Zeilen, die auf das Motiv zentriert sind, leicht zu verfolgen sind.

Brechen Sie Zeilen an natürlichen Pausen im Satz um. Ein Zeilenumbruch in der Mitte einer Phrase wirkt unbeholfen, während ein Umbruch zwischen Phrasen bewusst wirkt.

Für ein Meme nutzen Sie eine Ebene für die obere Bildunterschrift und eine für die untere. Separate Ebenen lassen Sie jede Zeile exakt dort positionieren, wo sie hingehört.

Memes erstellen

Ein Meme ist ein Foto mit einer kurzen, lustigen Bildunterschrift – meist in weißem Text mit dicker dunkler Kontur oben und unten. Das Format ist einfach, und genau diese Einfachheit ist der Punkt.

Halten Sie den Text kurz. Ein Meme mit einem Absatz Text ist nicht lustig, weil niemand einen Absatz auf einem Witzbild liest. Eine Zeile oben und eine unten reichen aus.

Nutzen Sie eine fette, klobige Schriftart. Der klassische Meme-Look nutzt eine schwere serifenlose Schrift, die bei kleinen Größen und auf belebten Hintergründen lesbar bleibt.

Platzieren Sie die obere Zeile zuerst und die untere Zeile als Zweites. Das Auge liest den Aufbau oben, schaut auf das Bild und liest dann die Pointe unten.

Zitate, Titel und Social-Media-Grafiken

Ein Zitat auf einem Foto ist ein beliebtes Social-Media-Format. Der Text ist meist groß, zentriert und über einen schlichten Bereich des Bildes oder einen abgedunkelten Hintergrund gesetzt.

Halten Sie Zitate kurz. Ein einzelner Satz funktioniert weitaus besser als ein Absatz, weil Bild und Worte sich den Raum teilen und keines dominieren sollte.

Für Titel nutzen Sie eine größere Größe und eine fettere Schrift als für Bildunterschriften. Der Titel sollte das Erste sein, was das Auge findet, und das Bild sollte ihn unterstützen, nicht mit ihm konkurrieren.

Dunkeln Sie das Bild hinter dem Text leicht ab, wenn das Foto belebt ist. Eine halbtransparente Überlagerung macht weißen Text lesbar, ohne das Foto vollständig zu verbergen.

Anmerkungen und Etiketten

Anmerkungen erklären Teile eines Bildes. Ein Etikett mit Pfeil, ein nummerierter Schritt oder eine kurze Notiz verwandelt einen Screenshot in eine Anleitung.

Halten Sie Anmerkungen kurz und platzieren Sie sie nah bei dem, was sie beschreiben. Ein Etikett weit entfernt von seinem Motiv verwirrt den Betrachter, während ein Etikett direkt daneben offensichtlich ist.

Nutzen Sie einen konsistenten Stil für alle Anmerkungen auf einem Bild. Dieselbe Schriftart, Größe und Farbe für jedes Etikett lässt das Bild professionell und leicht verfolgbar aussehen.

Kommentieren Sie Screenshots mit dem Tool „Text zu Bild hinzufügen“ nach dem Zuschneiden. Ein enger Zuschnitt plus ein paar klare Etiketten ist weitaus nützlicher als ein vollständiger Screenshot ohne Anleitung.

Formate und Export

Das Tool nimmt gängige Bildformate an, darunter JPG, PNG, WebP und HEIC, mit Dateien bis zu 20 MB. Sie können je nach Bedarf als JPG, PNG oder WebP exportieren.

Der Export als PNG oder WebP erhält Transparenz im Grundbild. Wenn Ihre Quelle ein transparenter PNG-Sticker ist, behält der Textexport die durchsichtigen Bereiche intakt.

Für Fotos mit Text funktioniert JPG mit hoher Qualitätseinstellung gut. Textkanten können unter JPG-Kompression leicht weicher werden – halten Sie also die Qualität für kleine Bildunterschriften hoch.

Der Qualitätsregler erscheint bei JPG- und WebP-Exporten und verschwindet bei PNG, weil PNG verlustfrei ist und keine Qualitätseinstellung zum Anpassen hat.

Datenschutz: Text hinzufügen ohne Hochladen

Alle Textbearbeitung passiert in Ihrem Browser. Ihre Fotos werden nie auf einen Server hochgeladen – wichtig, wenn es sich um persönliche Bilder, Familienfotos oder Arbeits-Screenshots handelt.

Das ist ein echter Vorteil gegenüber Cloud-Editoren. Ein Familienfoto mit Bildunterschrift sollte nicht zu einem Server reisen, den Sie nicht sehen können, nur um ein paar Worte hinzuzufügen.

Das Tool entfernt beim Export außerdem EXIF-GPS-Daten. Ein Foto mit Bildunterschrift, das Sie aus dem Tool herunterladen, enthält keinen Hinweis mehr darauf, wo es aufgenommen wurde.

Bewahren Sie das Originalfoto ohne Text auf. Sobald Text in einen Export eingebrannt ist, lässt er sich aus dieser Datei nicht mehr entfernen – das Original ist also Ihre einzige saubere Kopie.

Häufige Fehler beim Hinzufügen von Text

Der häufigste Fehler ist Text, der zu klein ist. Eine Bildunterschrift, die in voller Größe gut aussieht, kann in einem Social-Media-Feed unlesbar sein, wo das Bild viel kleiner gezeigt wird.

Ein weiterer Fehler ist schlechter Kontrast. Weißer Text auf hellem Himmel und schwarzer Text auf dunklem Hintergrund verschwinden beide – prüfen Sie den Text also auf dem tatsächlichen Foto, nicht auf einer leeren Leinwand.

Viele schreiben auch zu viel. Ein Absatz Text auf einem Foto verbirgt das Bild und überwältigt den Betrachter, während ein paar gut gewählte Worte den Auftrag besser erledigen.

Und platzieren Sie Text nicht dort, wo die Plattform ihn zuschneiden wird. Soziale Apps beschneiden die Ränder von Bildern für verschiedene Bildschirme – halten Sie wichtige Worte also gut innerhalb des Rahmens.

Text auf Produktfotos

Produktfotos tragen oft kurzen Text: einen Preis, einen Rabatt oder ein Merkmal. Der Text sollte groß, fett und dort platziert sein, wo er das Produkt selbst nicht verdeckt.

Setzen Sie Preis oder Angebot in eine Ecke, nicht über die Mitte. Ein Eckenetikett lässt das Produkt sichtbar, während ein zentrales Etikett genau das verbirgt, was Sie verkaufen.

Nutzen Sie einen konsistenten Stil in Ihrem gesamten Katalog. Dieselbe Schriftart, Größe und Farbe für jedes Preisetikett lässt den Shop professionell und vertrauenswürdig aussehen.

Halten Sie den Text kurz. Ein Preis und ein einzelnes Wort wie „Sale“ oder „Neu“ reichen aus. Ein Absatz auf einem Produktfoto lenkt den Käufer vom Produkt ab.

Häufige Fragen

Welche Schriftart ist die beste für Text auf einem Foto?

Eine fette serifenlose Schrift ist für die meisten Fotos die sicherste Wahl, da sie bei kleinen Größen und auf belebten Hintergründen lesbar bleibt. Serifenschriften passen zu formellen Bildern wie Hochzeitsfotos, während dekorative Schriften nur in großen Größen funktionieren. Beschränken Sie sich auf eine oder zwei Schriftarten pro Bild.

Wie mache ich weißen Text auf einem hellen Foto lesbar?

Fügen Sie eine dunkle Kontur oder einen Schlagschatten um die Buchstaben hinzu, die sie auf hellen Bereichen sichtbar halten. Den Text über den dunkelsten Teil des Fotos zu platzieren, hilft ebenfalls. Eine halbtransparente dunkle Fläche hinter dem Text funktioniert, wenn kein schlichter Bereich existiert.

Kann ich mehr als eine Textzeile zu einem Bild hinzufügen?

Ja. Drücken Sie die Eingabetaste innerhalb des Textinhalts, um eine neue Zeile in derselben Ebene zu erzeugen, oder fügen Sie eine separate Ebene für jede Zeile hinzu. Separate Ebenen lassen Sie eine obere und eine untere Bildunterschrift unabhängig positionieren – das klassische Meme-Layout.

Was ist der Unterschied zwischen Text hinzufügen und Wasserzeichen?

Text hinzufügen erzeugt eine Bildunterschrift, einen Titel oder eine Anmerkung, die von jedem gelesen werden soll. Wasserzeichen fügt eine halbtransparente Eigentumsmarkierung hinzu, die Kopieren überleben soll. Nutzen Sie das Text-Tool für Botschaften und das Wasserzeichen-Tool für Schutz.

Wie groß sollte Text auf einem Bild für soziale Medien sein?

Groß genug, um in einer kleinen Feed-Vorschau lesbar zu sein, nicht nur in voller Größe. Schlagzeilen brauchen eine Größe nahe am oberen Ende des Bereichs von 2 bis 22 Prozent, während Bildunterschriften kleiner sein können. Testen Sie das Ergebnis, indem Sie das Bild in der Größe betrachten, in der es im Feed erscheint.

Entfernt das Hinzufügen von Text zu einem Foto seine Standortdaten?

Ja, der Export aus dem Tool entfernt EXIF-GPS-Markierungen aus der Datei. Der Text wird ins Bild eingebrannt und der Standortnachweis im selben Schritt entfernt. Bewahren Sie die Originaldatei auf, wenn Sie diese Daten erhalten wollen.
