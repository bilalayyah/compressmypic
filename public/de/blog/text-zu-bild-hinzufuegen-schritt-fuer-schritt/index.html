Text zu einem Bild hinzufügen: Anleitung

Fügen Sie in Minuten Text zu jedem Bild hinzu: hochladen, Bildunterschrift tippen, Schriftart und Größe wählen, Farbe und Kontur festlegen, Ebenen positionieren und herunterladen.

Text zu einem Foto hinzuzufügen, dauert nur wenige Minuten. Sie laden das Bild hoch, tippen Ihre Worte, wählen eine Schriftart und eine Farbe und platzieren den Text, wo er hingehört.

Diese Anleitung führt Sie Schritt für Schritt durch den gesamten Ablauf. Sie behandelt einzelne und mehrere Ebenen, Schriftart- und Größenwahl, Konturen und Schatten sowie die Exporteinstellungen, die Text scharf halten.

Am Ende können Sie auf jedem Gerät ein Foto mit Bildunterschrift versehen, ein Meme erstellen, einen Screenshot beschriften oder eine Social-Media-Grafik gestalten. Bewahren Sie das Originalfoto auf, bis Sie das Ergebnis geprüft haben.

Vorbereitung: Planen Sie Ihre Worte

Schreiben Sie Ihren Text, bevor Sie das Tool öffnen. Eine im Voraus entschiedene Bildunterschrift ist kürzer und klarer als eine, die erfunden wird, während man auf den Editor starrt.

Halten Sie ihn kurz. Eine Schlagzeile aus wenigen Worten und eine Bildunterschrift aus einer Zeile funktionieren weitaus besser als ein Absatz, der das Foto verbirgt und den Betrachter überwältigt.

Entscheiden Sie auch die Stimmung. Eine fette Schrift passt zu einem Meme oder einem Sale-Banner, während eine leichte Serifenschrift zu einem Hochzeitsfoto oder einer Zitatgrafik passt.

Öffnen Sie das Tool „Text zu Bild hinzufügen“ in Ihrem Browser. Alles läuft lokal, Ihr Foto wird also nie auf einen Server hochgeladen.

Text in sechs Schritten zu einem Bild hinzufügen

Der Ablauf ist für eine Bildunterschrift, ein Meme oder ein Etikett derselbe. Hochladen, tippen, gestalten, positionieren, prüfen und herunterladen.

Nehmen Sie sich Zeit für den Schritt mit der Gestaltung. Schriftart, Größe, Farbe und Kontur entscheiden, ob der Text lesbar ist oder im Foto verschwindet.

  1. Laden Sie Ihr Bild hoch, indem Sie es in die Ablagefläche ziehen, auf Ihrem Gerät auswählen oder einen Screenshot mit Strg+V einfügen.
  2. Klicken Sie auf „Text hinzufügen“ und tippen Sie Ihre Bildunterschrift in das Textinhaltsfeld, mit der Eingabetaste für zusätzliche Zeilen.
  3. Wählen Sie eine Schriftart, stellen Sie die Textgröße zwischen 2 % und 22 % ein und wählen Sie eine Farbe, die mit dem Foto kontrastiert.
  4. Fügen Sie eine Textkontur oder einen Schlagschatten hinzu, wenn der Hintergrund belebt ist, und ziehen Sie dann die Ebene an ihre Position.
  5. Fügen Sie weitere Ebenen für zusätzliche Zeilen hinzu und wählen Sie jede einzeln aus, um sie für sich zu gestalten.
  6. Wählen Sie Exportformat und Qualität und klicken Sie dann auf „Herunterladen“, um das Bild mit Bildunterschrift zu speichern.

Öffnen Sie die heruntergeladene Datei einmal, bevor Sie sie teilen. Bestätigen Sie, dass der Text klar lesbar ist und nichts Wichtiges im Foto verdeckt wird.

Ihre erste Textebene hinzufügen

Klicken Sie auf „Text hinzufügen“, um Ihre erste Ebene zu erstellen. Das Tool platziert eine Standard-Bildunterschrift auf dem Bild, und Sie ersetzen sie in das Textinhaltsfeld mit Ihren eigenen Worten.

Tippen Sie die Worte exakt so, wie sie erscheinen sollen. Rechtschreibfehler auf einem Bild sind schwer zu übersehen – lesen Sie den Text also zweimal, bevor Sie weitermachen.

Die Ebene erscheint standardmäßig in der Mitte des Bildes. Ziehen Sie sie an die Position, die Sie möchten – etwa nach oben für eine Schlagzeile oder nach unten für eine Bildunterschrift.

Jede Ebene ist unabhängig. Sie können eine Ebene in großer, fetter Schrift gestalten und eine andere in kleiner, leichter Schrift, ohne dass die beiden sich gegenseitig beeinflussen.

Eine Schriftart wählen

Das Tool enthält eine Reihe eingebauter Schriftarten, von fetten serifenlosen bis zu klassischen Serifen. Wählen Sie die, die zur Stimmung Ihres Bildes und Ihrer Botschaft passt.

Für Memes und Sale-Banner nutzen Sie eine fette serifenlose Schrift. Die schweren Buchstaben bleiben bei kleinen Größen und auf belebten Hintergründen lesbar – genau das, was ein Meme braucht.

Für Zitate und Hochzeitsfotos nutzen Sie eine Serifen- oder eine elegante Schrift. Die leichteren Striche wirken formell und ruhig – passend zu einer nachdenklichen Botschaft.

Prüfen Sie die Schriftart in der Größe, in der Sie sie nutzen werden. Eine dekorative Schrift, die in großen Größen wunderschön aussieht, kann unlesbar werden, wenn sie klein ist.

Die Textgröße einstellen

Die Textgröße reicht von 2 Prozent bis 22 Prozent des Bildes. Eine Schlagzeile braucht eine größere Größe nahe am oberen Ende des Bereichs, während eine Bildunterschrift oder eine Quellenangabe eine kleinere braucht.

Die Prozentbemessung hält den Text bei unterschiedlichen Bildgrößen konsistent. Dieselbe Einstellung sieht auf einem kleinen Thumbnail und einem riesigen Kamerafoto richtig aus.

Testen Sie die Größe in den Maßen, in denen Sie sie teilen werden. Eine Schlagzeile, die in voller Größe fett aussieht, kann in einer Social-Media-Feed-Vorschau winzig sein, wo das Bild viel kleiner gezeigt wird.

Wenn Sie zwei Ebenen haben, bemessen Sie sie unterschiedlich. Eine große Schlagzeile mit einer kleineren Bildunterschrift schafft eine klare Hierarchie, und der Betrachter weiß, was er zuerst lesen soll.

Eine Textfarbe wählen

Weißer Text funktioniert auf dunklen Hintergründen und schwarzer Text auf hellen, doch die meisten Fotos enthalten beides. Prüfen Sie die Farbe an dem tatsächlichen Bereich, in dem der Text sitzen wird.

Platzieren Sie den Text über dem schlichtesten Teil des Fotos. Eine Bildunterschrift über einem klaren Himmel oder einer leeren Wand ist weitaus leichter zu lesen als eine über einer belebten Menschenmenge.

Helle Farben können für kurze Schlagzeilen funktionieren, sind aber in langen Bildunterschriften schwerer zu lesen. Reservieren Sie starke Farben für wenige Worte und nutzen Sie Weiß oder Schwarz für den Rest.

Wenn keine Farbe funktioniert, fügen Sie eine Hintergrundfläche hinzu. Ein halbtransparenter dunkler Kasten hinter weißem Text macht ihn überall lesbar, auch wenn er mehr vom Bild verdeckt.

Eine Kontur oder einen Schlagschatten hinzufügen

Eine Kontur zieht einen Rand um jeden Buchstaben. Eine dünne dunkle Kontur um weißen Text hält ihn auf einem hellen Himmel lesbar – darum nutzen Memes sie.

Ein Schlagschatten hebt den Text vom Hintergrund ab. Er fügt eine weiche dunkle Kante hinter den Buchstaben hinzu, die ihnen hilft, hervorzustechen, ohne den harten Look einer Kontur.

Nutzen Sie das eine oder das andere, nicht beides in voller Stärke. Eine Kontur plus ein starker Schatten lässt den Text überladen wirken, während ein einzelner Effekt ihn sauber hält.

Für klassischen Meme-Text nutzen Sie weiße Buchstaben mit einer dicken dunklen Kontur. Die Kombination ist auf fast jedem Hintergrund lesbar – darum wurde sie zum Standard.

Ebenen verschieben und auswählen

Ziehen Sie eine Ebene, um sie überall auf dem Bild zu verschieben. Das Tool lässt Sie jede Ebene separat auswählen, wenn Sie mehrere haben, sodass Sie eine bearbeiten können, ohne die anderen zu berühren.

Klicken Sie auf die Ebene, die Sie bearbeiten möchten, bevor Sie ihre Schriftart, Größe oder Farbe ändern. Die falsche Ebene zu bearbeiten, ist ein häufiger Fehler, und er lässt sich leicht vermeiden, indem Sie prüfen, welche Ebene aktiv ist.

Oben und unten sind die klassischen Positionen für Bildunterschriften. Eine Schlagzeile oben und eine Pointe unten ist das Meme-Format – und es funktioniert, weil das Auge von oben nach unten liest.

Halten Sie Text von den Rändern fern. Eine Bildunterschrift, die den Rand berührt, wirkt beengt, und Plattformen schneiden die Ränder für verschiedene Bildschirmgrößen oft erneut zu.

Textebenen drehen

Textebenen lassen sich in eigenen Winkeln kippen, was einem Design Energie verleiht. Eine leicht diagonale Schlagzeile wirkt dynamisch, während gerader Text ruhig und formell wirkt.

Nutzen Sie Drehung sparsam. Eine kleine Neigung von wenigen Grad fügt Charakter hinzu, während ein steiler Winkel den Text schwer lesbar macht und wie ein Fehler aussieht.

Diagonaler Text funktioniert gut auf Postern und Social-Media-Grafiken, bei denen das Design ins Auge fallen soll. Er funktioniert schlecht bei Anleitungen und Etiketten, bei denen Klarheit am wichtigsten ist.

Prüfen Sie gedrehten Text in der Größe, in der er betrachtet wird. Eine Neigung, die in voller Größe gut aussieht, kann kleinen Text in einer Feed-Vorschau unlesbar machen.

Mehrzeilige Bildunterschriften und Meme-Layouts

Drücken Sie die Eingabetaste innerhalb des Textinhaltsfelds, um eine neue Zeile in derselben Ebene zu erzeugen. So können Sie eine Bildunterschrift schreiben, die sich über zwei oder drei Zeilen erstreckt, ohne zusätzliche Ebenen.

Für ein Meme nutzen Sie eine Ebene für die obere Bildunterschrift und eine für die untere. Separate Ebenen lassen Sie jede Zeile exakt dort positionieren, wo sie hingehört.

Halten Sie Zeilen kurz. Eine Bildunterschrift, die über die gesamte Breite des Bildes verläuft, ist schwer zu lesen, während kurze Zeilen, die auf das Motiv zentriert sind, leicht zu verfolgen sind.

Brechen Sie Zeilen an natürlichen Pausen im Satz um. Ein Zeilenumbruch in der Mitte einer Phrase wirkt unbeholfen, während ein Umbruch zwischen Phrasen bewusst wirkt.

In Minuten ein Meme erstellen

Ein Meme ist ein Foto mit einer kurzen, lustigen Bildunterschrift – meist in weißem Text mit dicker dunkler Kontur oben und unten. Das Format ist einfach, und genau diese Einfachheit ist der Punkt.

Laden Sie das Foto hoch, fügen Sie eine obere Ebene für den Aufbau und eine untere Ebene für die Pointe hinzu. Halten Sie jede Zeile auf wenige Worte, damit der Witz schnell landet.

Nutzen Sie eine fette, klobige Schriftart mit dunkler Kontur. Der klassische Meme-Look bleibt auf fast jedem Hintergrund lesbar – darum wurde er zum Standard.

Schauen Sie sich das Meme in der Größe an, in der es geteilt wird, in der Vorschau. Ein Witz, der in voller Größe klar ist, kann in einer kleinen Feed-Vorschau unlesbar sein – prüfen Sie also vor dem Posten.

Vorschau und Export

Schauen Sie sich das Ergebnis immer vor dem Herunterladen an. Prüfen Sie, ob der Text klar lesbar ist, ob nichts Wichtiges im Foto verdeckt wird und ob die Ebenen an den richtigen Stellen sind.

Wählen Sie JPG für Fotos mit Text bei hoher Qualitätseinstellung. Textkanten können unter JPG-Kompression leicht weicher werden – halten Sie also die Qualität für kleine Bildunterschriften hoch.

Wählen Sie PNG für Screenshots und Grafiken mit Text. PNG ist verlustfrei, sodass die Kanten von Buchstaben scharf bleiben, und es erhält Transparenz, wenn Sie sie brauchen.

Beachten Sie, dass der Qualitätsregler bei PNG verschwindet, weil PNG verlustfrei ist und keine Qualitätseinstellung zum Anpassen hat. Das ist normales Verhalten, kein Problem mit dem Tool.

Text auf Handy oder Tablet hinzufügen

Das Tool funktioniert auf Touchscreens, sodass Sie ein Foto auf dem Handy mit Bildunterschrift versehen können, mit dem es aufgenommen wurde. Laden Sie es aus Ihrer Galerie hoch, tippen Sie den Text und ziehen Sie die Ebene mit dem Finger an ihre Position.

Das Tippen auf einer Handytastatur ist langsamer – schreiben Sie Ihre Bildunterschrift also, bevor Sie das Tool öffnen. Eine kurze, geplante Bildunterschrift ist leichter zu tippen als eine, die spontan erfunden wird.

Das Ziehen von Ebenen mit dem Finger ist weniger präzise als mit der Maus. Nutzen Sie Mitte, Oberseite und Unterseite als Orientierung und zoomen Sie hinein, um die Platzierung zu prüfen.

Heruntergeladene Dateien landen in Ihrem üblichen Download-Ordner. Von dort aus können Sie das Bild mit Bildunterschrift direkt in eine Chat-App, eine E-Mail oder einen Social-Media-Beitrag teilen.

Häufige Textprobleme lösen

Ist der Text unlesbar, passt die Farbe wahrscheinlich zum Hintergrund. Ändern Sie die Farbe, fügen Sie eine Kontur hinzu oder verschieben Sie die Ebene in einen schlichteren Teil des Fotos.

Wenn Sie die falsche Ebene bearbeitet haben, klicken Sie auf die Ebene, die Sie ändern wollten, und versuchen Sie es erneut. Das Tool wählt Ebenen eine nach der anderen aus – prüfen Sie also vor dem Gestalten, welche aktiv ist.

Wenn sich eine Ebene nicht verschieben lässt, prüfen Sie, ob Sie sie zuerst ausgewählt haben. Eine Ebene muss aktiv sein, bevor sie gezogen werden kann, und ein einmaliges Anklicken wählt sie meist aus.

Sieht der Text nach dem Export unscharf aus, ist die JPG-Qualitätseinstellung womöglich zu niedrig. Exportieren Sie erneut mit höherer Qualität oder wechseln Sie zu PNG für die schärfsten Textkanten.

Kurztipps für besseren Text auf Bildern

Halten Sie den Text kurz. Ein paar gut gewählte Worte stärken ein Bild, während ein Absatz, der auf ein Foto gequetscht wird, genau das verbirgt, was er beschreiben sollte.

Nutzen Sie höchstens eine Schriftart für die Schlagzeile und eine für die Bildunterschrift. Viele Schriftarten zu mischen, wirkt chaotisch, während ein konsistentes Paar das Design sauber hält.

Prüfen Sie den Text in der Größe, in der er betrachtet wird. Eine Bildunterschrift, die in voller Größe gut aussieht, kann in einer Social-Media-Feed-Vorschau unlesbar sein.

Speichern Sie das Originalfoto ohne Text. Sobald Text in einen Export eingebrannt ist, lässt er sich aus dieser Datei nicht mehr entfernen – das Original ist also Ihre einzige saubere Kopie.

Text zu einem Präsentationsfolien-Bild hinzufügen

Ein Foto, das als Folienhintergrund genutzt wird, braucht oft einen Titel darüber. Fügen Sie den Titel als Textebene hinzu und nutzen Sie eine große, fette Schrift, die vom hinteren Teil des Raumes aus lesbar bleibt.

Platzieren Sie den Titel über dem schlichtesten Teil des Fotos. Eine Schlagzeile über einem klaren Himmel oder einer leeren Wand ist weitaus leichter zu lesen als eine über einer belebten Menschenmenge.

Nutzen Sie eine dunkle Kontur oder einen Schatten, wenn der Hintergrund belebt ist. Der Effekt hebt die Buchstaben gerade genug vom Foto ab, um lesbar zu sein, ohne das Bild darunter zu verbergen.

Exportieren Sie das Folienbild als JPG mit hoher Qualitätseinstellung. Der Text muss scharf bleiben, wenn die Folie projiziert wird, und ein Export mit niedriger Qualität macht die Buchstaben weich.

Häufige Fragen

Wie füge ich auf meinem Handy Text zu einem Foto hinzu?

Öffnen Sie das Tool „Text zu Bild hinzufügen“ im Browser Ihres Handys, laden Sie das Foto aus Ihrer Galerie hoch und tippen Sie auf „Text hinzufügen“. Tippen Sie Ihre Bildunterschrift, wählen Sie Schriftart und Größe, ziehen Sie die Ebene mit dem Finger an ihre Position und laden Sie dann das Ergebnis herunter.

Kann ich zwei verschiedene Bildunterschriften zu einem Bild hinzufügen?

Ja. Fügen Sie für jede Bildunterschrift eine separate Ebene hinzu – etwa eine oben und eine unten. Wählen Sie jede Ebene für sich aus, um sie unterschiedlich zu gestalten, sodass die Schlagzeile groß und fett sein kann, während die Bildunterschrift kleiner bleibt.

Warum sieht mein Text nach dem Herunterladen des Bildes unscharf aus?

Die JPG-Qualitätseinstellung ist wahrscheinlich zu niedrig, was die Kanten der Buchstaben weicher macht. Exportieren Sie erneut mit höherer Qualitätseinstellung oder wechseln Sie zu PNG, das verlustfrei ist und Textkanten scharf hält.

Wie erstelle ich ein klassisches Meme mit Text oben und unten?

Laden Sie das Foto hoch, fügen Sie eine Ebene für die obere Zeile und eine weitere für die untere Zeile hinzu und nutzen Sie eine fette serifenlose Schrift in Weiß mit dicker dunkler Kontur. Halten Sie jede Zeile auf wenige Worte, damit der Witz schnell landet.

Kann ich Text verschieben, nachdem ich ihn getippt habe?

Ja. Wählen Sie die Ebene aus und ziehen Sie sie überall auf dem Bild hin. Sie können eine Ebene vor dem Herunterladen jederzeit verschieben, skalieren, umfärben und drehen. Sobald das Bild exportiert ist, ist der Text eingebrannt und lässt sich nicht mehr verschieben.

Welche Größe sollte Text für einen Instagram-Beitrag haben?

Groß genug, um in einer kleinen Feed-Vorschau lesbar zu sein, nicht nur in voller Größe. Schlagzeilen brauchen eine Größe nahe am oberen Ende des Bereichs von 2 bis 22 Prozent. Testen Sie das Ergebnis, indem Sie das exportierte Bild in der Größe betrachten, in der es im Feed erscheint.
