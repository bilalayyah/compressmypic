Cómo optimizar imágenes para la velocidad del sitio web

Paso a paso: optimice imágenes para la velocidad del sitio web con ajustes predefinidos, dimensiones correctas, carga diferida y etiquetas HTML para copiar y pegar.

Las imágenes son la parte más pesada de la mayoría de los sitios web. Una página que carga lento normalmente tiene imágenes culpables, y arreglarlas es la victoria de velocidad más rápida disponible.

Esta guía recorre todo el proceso de optimización. Auditará la página, elegirá el ajuste correcto, optimizará las imágenes y pegará el HTML en su lugar.

Funciona para blogs, tiendas y sitios de negocios, y no necesita experiencia en programación más allá de copiar y pegar.

Paso 1: audite primero la página

Antes de optimizar nada, descubra qué imágenes son el problema. Abra la página y anote qué imágenes tardan en aparecer.

Use una herramienta gratuita de velocidad para medir la página. Enumera las imágenes más pesadas y muestra cuánto cuesta cada una en tiempo de carga.

Anote el peso total de imágenes de la página. Una página con 5 MB de imágenes tiene un problema obvio, mientras que una página con 500 KB ya está en buena forma.

Escriba las tres peores imágenes. Arreglar esas primero da la mayor ganancia de velocidad con el menor esfuerzo.

Paso 2: abra el Optimizador de imágenes para web

Abra el Optimizador de imágenes para web en su navegador. No necesita cuenta ni instalación.

La herramienta se ejecuta por completo en su dispositivo. Sus imágenes se procesan de forma local y nunca se suben a un servidor.

Si está optimizando todo un sitio, trabaje por lotes. Treinta imágenes a la vez es un tamaño de lote cómodo para la mayoría de los navegadores.

Marque la página. La optimización de imágenes es un trabajo recurrente, y es una herramienta a la que volverá seguido.

Paso 3: elija el ajuste correcto

Elija el ajuste que coincida con dónde aparecerá la imagen. Una imagen principal, una foto de producto y una miniatura tienen cada una su propio ajuste.

El ajuste Producto de comercio electrónico es el valor por defecto. Limita las imágenes a 1200 píxeles de ancho en WebP con 82 por ciento de calidad, lo cual sirve para la mayoría de las fotos de producto.

Para una imagen destacada de blog, use el ajuste de imagen principal o de tarjeta según el diseño. Haga coincidir el ajuste con el tamaño de visualización, no con el tamaño de archivo.

Para imágenes de uso compartido social, use el ajuste Social OG. Cambia el formato a JPG de forma automática, ya que las plataformas sociales lo prefieren.

Paso 4: suba las imágenes

Arrastre las imágenes a la zona de subida o toque para buscar. Se aceptan archivos JPG, PNG, WebP y HEIC.

Suba los originales de mayor calidad que tenga. Un original de 12 megapíxeles le da al optimizador mucho más con qué trabajar que una copia pequeña.

Para un lote, añada todas las imágenes de una página a la vez. Comparten el ajuste, lo que mantiene los resultados consistentes.

Espere a que termine la subida antes de cambiar ajustes. La herramienta necesita los archivos completos antes de poder optimizarlos.

Paso 5: personalice los ajustes

Después de elegir un ajuste, ajuste la configuración si el espacio lo exige. Cambie las dimensiones, el formato o la calidad según el diseño.

Mantenga las dimensiones cerca del tamaño de visualización. Una imagen que se muestra a 800 píxeles de ancho no necesita tener 2400 píxeles en el archivo.

Active Solo reducir cuando el lote mezcle imágenes grandes y pequeñas. Protege a los íconos y las miniaturas de ser estirados más grandes.

Mueva el control de calidad solo cuando sea necesario. La mayoría de los ajustes se ubica entre 75 y 85 por ciento, que es el rango correcto para casi cada imagen.

Paso 6: revise los resultados

Revise cada imagen optimizada a tamaño completo antes de descargar. Una miniatura pequeña esconde problemas que son obvios a tamaño completo.

Revise primero el detalle fino. La textura de la tela, el texto y los bordes son lo primero que se suaviza con la compresión.

Compare algunos resultados con sus originales. Las diferencias pequeñas son normales; el texto ilegible o la piel manchada no lo son.

Revise también los tamaños de archivo. El resumen muestra cuánto se redujo cada imagen y el ahorro total en todo el lote.

Paso 7: copie la etiqueta HTML

Haga clic en Copiar etiqueta de imagen para cada imagen. La etiqueta incluye la fuente, las dimensiones, el texto alternativo y el comportamiento de carga, lista para pegar.

Revise el texto alternativo de la etiqueta. Edítelo si el texto generado no describe bien la imagen.

Confirme que el atributo de carga sea correcto. Las imágenes principales deberían cargar de inmediato, mientras que las imágenes por debajo del pliegue deberían cargarse de forma diferida.

Pegue la etiqueta en su página donde pertenece la imagen. Reemplace la etiqueta de imagen vieja por completo, en lugar de editarla a mano.

Paso 8: suba y pruebe la página

Suba las imágenes optimizadas a su sitio. Use los mismos nombres de archivo que produjo la herramienta, para que las etiquetas HTML coincidan con los archivos.

Abra la página en una pestaña nueva del navegador. Compruebe que cada imagen aparece y que nada se ve estirado o borroso.

Ejecute la herramienta de velocidad de nuevo y compare los números. El peso total de imágenes debería haber bajado bruscamente, y el tiempo de carga con él.

Pruebe también en un teléfono además de una laptop. La mayoría de los visitantes navega en móvil, y la página debe sentirse rápida ahí primero.

Cómo resolver problemas comunes

Si una imagen se ve borrosa, la fuente quizá era demasiado pequeña. Vuelva a optimizar desde un original mayor con el mismo ajuste.

Si la página aún carga lento, revise si hay imágenes sin optimizar. Un solo banner olvidado de 5 MB puede deshacer todo el lote.

Si las imágenes aparecen estiradas, las dimensiones de la etiqueta no coinciden con el archivo. Vuelva a copiar la etiqueta desde la herramienta en lugar de editarla a mano.

Si un uso compartido social no muestra imagen, revise el formato. Las plataformas sociales prefieren JPG, y el ajuste Social OG maneja eso de forma automática.

Flujo de trabajo: una entrada de blog

Reúna las imágenes de la entrada y súbalas como un solo lote. Use el ajuste de tarjeta para miniaturas y el ajuste de imagen principal para la imagen destacada.

Revise la imagen destacada con cuidado. Es la imagen más grande de la página y la que los lectores juzgan primero.

Copie las etiquetas HTML y péguelas en la entrada. Revise el texto alternativo de cada una antes de publicar.

Publique la entrada y pruébela en un teléfono. Las imágenes deberían cargar rápido y verse nítidas mientras se desplaza.

Flujo de trabajo: una página de producto

Reúna las fotos de producto y súbalas como un solo lote. Use el ajuste Producto de comercio electrónico para resultados consistentes.

Revise primero los productos más detallados. La textura de la tela y las etiquetas impresas son lo primero que se suaviza.

Copie las etiquetas HTML y péguelas en la página de producto. Confirme que el atributo de carga sea correcto para cada posición de imagen.

Revise la página de producto en un teléfono después de subir. La mayoría de los compradores navega en móvil, y las imágenes deben verse bien ahí.

Cómo usar bien las herramientas gratuitas de velocidad

Las herramientas gratuitas de velocidad miden su página y enumeran los problemas. Son el mejor punto de partida para cualquier trabajo de optimización.

Ejecute la herramienta en la página en vivo, no en una copia local. La página en vivo incluye el alojamiento, la CDN y las condiciones reales que enfrentan sus visitantes.

Lea primero las recomendaciones de imagen. Nombran los archivos exactos que cuestan más tiempo, lo que le dice por dónde empezar.

Ignore la puntuación perfecta. Una puntuación en el rango verde es suficiente; perseguir 100 desperdicia tiempo que se usa mejor en contenido.

Vuelva a ejecutar la herramienta después de cada ronda de correcciones. Los números cambiantes muestran si su trabajo está rindiendo.

Cómo elegir tamaños según el espacio de página

Cada espacio de una página tiene un tamaño natural de imagen. Hacer coincidir el archivo con el espacio es la habilidad central de la optimización web.

Las imágenes principales necesitan los archivos más grandes, muchas veces de 1200 a 1600 píxeles de ancho. Llenan la pantalla, así que deben mantenerse nítidas.

Las imágenes destacadas en entradas de blog sirven de 800 a 1200 píxeles. Son grandes pero no a pantalla completa, así que un tamaño medio funciona.

Las miniaturas y los avatares necesitan solo 200 a 400 píxeles. Cualquier cosa mayor desperdicia ancho de banda en detalle que nadie puede ver.

Mida el espacio en su tema antes de elegir. El ancho mostrado decide el ancho del archivo, y adivinar mal desperdicia kilobytes.

Imágenes responsivas en la práctica

Las imágenes responsivas sirven archivos distintos a pantallas distintas. Un teléfono recibe un archivo pequeño, mientras que una computadora recibe uno mayor.

El atributo srcset enumera los tamaños disponibles, y el navegador elige el correcto para la pantalla en la que se ejecuta.

Genere dos o tres tamaños por imagen. Un tamaño móvil, un tamaño de tableta y un tamaño de escritorio cubren a casi cada visitante.

Pruebe en un teléfono real después de añadir imágenes responsivas. La mejora de carga en móvil muchas veces es dramática.

Mantenga el HTML sencillo. Un srcset con tres tamaños basta; diez tamaños añaden complejidad sin beneficio visible.

SEO de imágenes mientras optimiza

La optimización y el SEO van juntos. Una página rápida con imágenes bien descritas posiciona mejor que una página lenta con archivos anónimos.

Use nombres de archivo descriptivos. Un nombre como camisa-algodon-azul.jpg le dice a los buscadores qué muestra la imagen.

Escriba texto alternativo real para cada imagen. Describa el contenido en una frase e incluya el detalle clave que un buscador buscaría.

No rellene las palabras clave en los nombres de archivo ni en el texto alternativo. Una descripción natural ayuda a los lectores y a los buscadores por igual.

Envíe un mapa del sitio de imágenes si su sitio depende de la búsqueda de imágenes. Ayuda a los buscadores a descubrir imágenes que de otro modo pasarían por alto.

Cómo mantener las imágenes optimizadas con el tiempo

La optimización no es un trabajo de una sola vez. Las imágenes nuevas llegan cada semana, y cada una necesita el mismo tratamiento que la anterior.

Incorpore la optimización a la lista de verificación de publicación. Cada entrada debería pasar por el optimizador antes de publicarse.

Audite el sitio cada trimestre. Las imágenes viejas de antes del hábito de optimización muchas veces aún son pesadas, y un lote las arregla rápido.

Vigile los cambios de tema. Un tema nuevo puede mostrar imágenes más grandes que el viejo, lo que significa que los archivos viejos de repente son demasiado pequeños.

Conserve los originales a salvo. Cuando cambia el diseño, los originales le permiten volver a optimizar a los tamaños nuevos sin pérdida de calidad.

Estándares de optimización para equipos

Los equipos que publican juntos necesitan un estándar compartido. Acuerden el ajuste, el patrón de nombres y el presupuesto de tamaño antes de la primera entrada.

Escriba el estándar en una página. Una guía corta en la wiki del equipo evita cien preguntas pequeñas.

Asigne a una persona para revisar el peso de imágenes en cada publicación. Un segundo par de ojos detecta la imagen pesada que el autor pasó por alto.

Revise el estándar cuando cambia el diseño. Los ajustes que servían para el tema del año pasado quizá no sirvan para el diseño de este año.

Los buenos estándares hacen rutinaria la velocidad. El equipo deja de pensar en la optimización porque el proceso la maneja de forma automática.

Mitos de velocidad que vale la pena ignorar

Un mito dice que solo la página principal importa para la velocidad. En realidad, los visitantes llegan a entradas de blog y páginas de producto, y esas también deben ser rápidas.

Otro mito dice que un alojamiento rápido arregla las imágenes lentas. El alojamiento ayuda, pero una imagen de 5 MB es lenta en cualquier alojamiento, y la optimización es la única solución.

Un tercer mito dice que WebP por sí solo resuelve todo. El formato ayuda, pero las dimensiones y la carga diferida importan tanto como la elección de formato.

La verdad es aburrida y práctica: tamaño correcto, formato correcto, carga diferida por debajo del pliegue y dimensiones en cada etiqueta. Haga esas cuatro cosas y la página será rápida.

Pruebe sus propias páginas para resolver la pregunta. Los números de velocidad no se preocupan por los mitos, y le dirán qué funciona realmente.

Una revisión final antes de publicar

Ejecute la herramienta de velocidad una última vez después de optimizar todas las imágenes. Confirme que el peso total de imágenes bajó y que el tiempo de carga mejoró.

Cargue la página en un teléfono real con una conexión móvil. Los números de una prueba de laboratorio son útiles, pero la sensación en un teléfono es la verdad.

Revise cada imagen visualmente una vez más. Una página rápida con una imagen principal borrosa no es un éxito, y una revisión cuidadosa lo detecta.

Siga aprendiendo de cada página

Cada página que optimiza enseña algo. Anote qué ajuste funcionó, qué imagen fue la más difícil y qué hicieron los números de velocidad, porque esas lecciones se acumulan con cada página que arregla y cada sitio que mejora.

Esas notas se convierten en su manual. La próxima página toma menos tiempo porque la última página ya respondió las preguntas.

Preguntas frecuentes

¿Cuánto más rápido será mi sitio después de optimizar las imágenes?

Depende de qué tan pesadas eran las imágenes. Una página con 5 MB de imágenes que baja a 500 KB puede cargar varios segundos más rápido, sobre todo en móvil. Ejecute una prueba de velocidad antes y después para ver la mejora exacta de su página.

¿Debo optimizar las imágenes antes o después de subirlas a mi sitio?

Antes. Optimizar primero le da control sobre dimensiones, formato y calidad, además de la etiqueta HTML lista. Subir primero y confiar en que la plataforma las comprima normalmente produce peores resultados.

¿Puedo optimizar treinta imágenes de blog en un solo lote?

Sí. Añada las treinta imágenes, elija un ajuste y descárguelas juntas. Revise algunos resultados antes de descargar todo el lote, y mantenga el ajuste consistente para que las imágenes se vean uniformes en el sitio.

¿Por qué mi imagen principal sigue siendo lenta después de optimizarla?

Revise que la carga diferida esté apagada para la imagen principal, ya que retrasarla daña la velocidad de carga. También confirme que las dimensiones de la imagen principal coincidan con el tamaño de visualización; una imagen principal sobredimensionada desperdicia ancho de banda. Precargar la imagen principal puede ayudar más.

¿Necesito actualizar el HTML cuando reemplazo una imagen?

Sí, si cambiaron las dimensiones o el nombre de archivo. La etiqueta HTML lleva el ancho, el alto y la fuente, así que una etiqueta desactualizada puede estirar la imagen o romper el diseño. Copie una etiqueta nueva desde la herramienta cada vez que reemplace una imagen.

¿Qué tamaño de imagen debo usar para una imagen destacada de blog?

Haga coincidir el tamaño de visualización de su tema, normalmente 1200 píxeles de ancho o menos. El ajuste de imagen principal o de tarjeta maneja esto de forma automática. Servir una imagen con el doble de ancho que su visualización desperdicia ancho de banda sin beneficio visible.
