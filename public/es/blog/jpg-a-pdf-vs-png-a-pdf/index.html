JPG a PDF vs PNG a PDF: mejores ajustes para documentos

¿Tu PDF debe usar imágenes JPG o PNG? Tamaño de archivo, nitidez del texto, transparencia y los mejores ajustes para cada tipo de documento.

Cuando construyes un PDF a partir de imágenes, el formato de esas imágenes importa más de lo que la mayoría espera. Una página JPG y una página PNG pueden verse idénticas en pantalla y aun así comportarse de forma muy distinta.

La elección afecta el tamaño del archivo, la nitidez del texto y cómo se imprime el PDF. Para un álbum de fotos gana un formato; para un contrato escaneado, gana el otro.

Este artículo compara JPG y PNG dentro de los PDF, para que puedas elegir el formato correcto antes de generar, no después. Cuando ya sepa cuál formato le conviene, puede armar su PDF gratis en el navegador con la herramienta Imagen a PDF, que combina varias imágenes en un solo documento.

Imágenes JPG dentro de un PDF

JPG es un formato con pérdida, lo cual significa que descarta detalle para achicar el archivo. Dentro de un PDF, una página JPG guarda la foto con esa misma compresión, manteniendo el documento pequeño.

Las fotos se comprimen de maravilla como JPG. Una fotografía de página completa con 85 por ciento de calidad se ve limpia y mantiene el PDF lo bastante ligero para enviar por correo.

La debilidad es el texto. Las letras pequeñas y las líneas nítidas se suavizan en JPG, porque la compresión difumina los límites de alto contraste. Una página escaneada de letra pequeña sufre primero.

Usa JPG dentro de los PDF para fotografías, álbumes de fotos y cualquier página donde la imagen importe más que el texto que lleva.

Imágenes PNG dentro de un PDF

PNG es un formato sin pérdida, así que cada píxel se guarda con exactitud. Dentro de un PDF, una página PNG es una copia perfecta de la imagen de origen, sin ningún daño de compresión.

El texto y el arte lineal se mantienen nítidos en PNG. Un contrato escaneado, un formulario o un diagrama se ven en el PDF tan limpios como en el escaneo original.

El precio es el tamaño del archivo. Una fotografía detallada guardada como PNG puede ser varias veces más grande que la misma foto como JPG, y un PDF largo de fotos PNG se vuelve pesado rápido.

Usa PNG dentro de los PDF para documentos escaneados, formularios, recibos y cualquier página donde el texto legible sea la prioridad.

Tamaño de archivo: la gran diferencia

Un álbum de fotos de diez páginas construido con JPG puede pesar 3 MB, mientras que el mismo álbum construido con PNG puede pesar 15 MB o más. Esa brecha importa para los adjuntos de correo y las conexiones lentas.

La brecha se achica para imágenes simples. Un formulario escaneado casi todo blanco se comprime bien como PNG, porque las áreas planas grandes cuestan poco de guardar sin pérdida.

Crece para fotos detalladas. Un paisaje con mucho detalle o un retrato de grupo tiene textura sin fin, y PNG debe describir cada píxel con exactitud.

Si el PDF debe mantenerse por debajo de un límite de correo, JPG es la opción práctica. Si el tamaño no importa, PNG te da el resultado más nítido.

Nitidez del texto: donde gana PNG

El texto escaneado es el caso más claro a favor de PNG. Las letras son formas de alto contraste, y la compresión JPG difumina sus bordes, haciendo la letra pequeña más difícil de leer.

Con alta calidad JPG, el desenfoque es leve, pero sigue ahí. Con calidad media, la letra pequeña puede volverse realmente difícil de leer, sobre todo después de imprimir.

PNG mantiene cada borde nítido. Una firma, un sello o una nota escrita a mano se mantienen tan nítidos como el escaneo, lo cual importa para documentos oficiales.

Para cualquier documento que se vaya a leer y no a admirar, PNG es el formato más seguro. El archivo es más grande, pero las palabras son lo importante.

Documentos con fotos: retratos y fotos de documentos de identidad

Las fotos de documentos de identidad y los retratos son fotografías, así que JPG es la opción natural. Los tonos de piel y los degradados suaves se comprimen bien, y el archivo se mantiene pequeño.

Una foto de pasaporte dentro de un PDF no necesita almacenamiento sin pérdida. La cara se mantiene reconocible con 85 por ciento de calidad JPG, y el PDF sigue siendo fácil de enviar.

PNG solo ayuda para fotos de documentos de identidad cuando la foto tiene texto nítido superpuesto, como un nombre impreso sobre la imagen. En ese caso raro, PNG mantiene el texto nítido.

Para un conjunto de fotos de documentos de identidad, JPG mantiene el PDF ligero y las caras claras. Esa es la combinación que esperan la mayoría de los sistemas de envío.

Documentos escaneados: contratos y formularios

Un contrato escaneado es sobre todo texto sobre papel blanco. PNG guarda eso de forma eficiente, porque las áreas blancas grandes cuestan casi nada en un formato sin pérdida.

El texto se mantiene nítido, la firma se mantiene legible y el sello se mantiene claro. Un escaneo JPG de la misma página suavizaría los tres.

Los escaneos de documentos viejos o descoloridos se benefician aún más. Las marcas tenues de lápiz y los sellos claros son justo los detalles que la compresión JPG destruye primero.

Para cualquier escaneo que deba leerse, archivarse o enviarse de forma oficial, construye el PDF a partir de archivos PNG. El tamaño extra es un precio justo por la legibilidad.

Transparencia: qué pasa con ella

Ningún formato conserva la transparencia dentro de un PDF como podrías esperar. Las áreas PNG transparentes se vuelven blancas cuando se genera el PDF, porque la página del PDF necesita un fondo.

Para la mayoría de los documentos, el blanco es lo correcto. Un logotipo transparente sobre una página blanca se ve justo como debe y se imprime limpio.

Si necesitas un logotipo sobre un fondo de color, convierte el PNG a JPG primero con un color mate que combine. El conversor PNG a JPG te deja elegir el color de relleno exacto.

Las fotografías nunca tienen transparencia, así que esto solo importa para logotipos y gráficos. Para documentos comunes, puedes ignorarlo.

Ajustes de calidad para cada formato

Para páginas JPG, pon el control de calidad del PDF en alto para documentos con texto y en medio para álbumes de fotos. Lo alto mantiene la letra pequeña legible; lo medio mantiene pequeños los PDF de fotos.

Para páginas PNG, el control de calidad tiene menos efecto, porque PNG no tiene pérdida. El PDF igual comprime los datos de la imagen, pero los píxeles en sí se guardan con exactitud.

Una regla práctica: JPG al 85 por ciento para fotos, PNG en cualquier ajuste para texto. Esa combinación cubre casi todos los documentos que vas a construir.

Genera siempre una vez y revisa el resultado. Abre el PDF, acércate al texto más pequeño y confirma que se lee limpio antes de enviarlo.

Lotes mezclados: fotos y escaneos juntos

Los documentos reales suelen ser mezclados. Una solicitud de visa puede contener una foto JPG, un escaneo PNG de un pasaporte y un escaneo JPG de un estado de cuenta.

El constructor de PDF acepta formatos mezclados en un solo documento. Cada página conserva su formato de origen, así no necesitas convertir todo a un solo formato primero.

Convierte solo las páginas que lo necesiten. Convierte una foto PNG a JPG para ahorrar espacio, pero deja solo un escaneo PNG para que su texto se mantenga nítido.

Revisa el tamaño final del archivo después de generar. Si es demasiado grande, las páginas de fotos son el mejor lugar para ahorrar espacio, no las páginas de texto.

¿Qué formato deberías elegir?

Elige JPG cuando las páginas sean fotografías. Los álbumes, los portafolios y las fotos de documentos de identidad van bien con JPG, y el PDF se mantiene pequeño y fácil de compartir.

Elige PNG cuando las páginas sean documentos. Los contratos, los formularios, los recibos y los escaneos van bien con PNG, y el texto se mantiene nítido a cualquier nivel de acercamiento.

Elige una mezcla cuando el documento tenga ambas cosas. Fotos como JPG y escaneos como PNG te dan lo mejor de los dos mundos en un solo PDF.

Cuando dudes, pregúntate qué hará el lector. Si va a leerlo, usa PNG. Si va a mirarlo, usa JPG.

Tres ejemplos reales

Un estudiante que envía un escaneo de tesis usa páginas PNG en A4 con colocación Ajustar. Cada página es legible, y el PDF se imprime limpio para el examinador.

Un fotógrafo que envía un portafolio usa páginas JPG en Ajustar al tamaño de la imagen. Las fotos se ven ricas, el archivo es lo bastante pequeño para enviar por correo y ningún cliente se queja del tiempo de descarga.

Un freelancer que factura a un cliente usa PNG para los recibos escaneados y JPG para la foto del trabajo entregado. El PDF mezclado es nítido donde importa y pequeño donde cuenta.

Cada ejemplo sigue la misma regla: el texto va en PNG, las fotos van en JPG y el documento sirve primero a su lector.

Consejos de flujo de trabajo para mejores PDF

Prepara tus imágenes antes de construir el PDF. Convierte fotos PNG a JPG cuando el tamaño importa, y convierte escaneos JPG a PNG solo cuando necesites editarlos varias veces.

Ponles a tus archivos de origen nombres en orden de página, como 01-passport.png y 02-photo.jpg. El constructor añade los archivos en el orden en que los eliges, y los nombres numerados evitan errores.

Genera una vez, revisa y vuelve a generar si hace falta. El control de calidad y los ajustes de colocación se cambian rápido, y una segunda generación cuesta solo segundos.

Conserva las imágenes de origen después de generar. Si el destinatario pide otro tamaño de página o un archivo más pequeño, puedes reconstruirlo desde los originales sin volver a escanear nada.

Resolución y DPI dentro de los PDF

La resolución decide qué tan nítida se ve una imagen al imprimirse desde un PDF. Una página construida con una imagen de 150 DPI se ve bien en pantalla pero suave en papel, mientras que una imagen de 300 DPI se imprime nítida.

La mayoría de las fotos de teléfono y los escaneos tienen resolución suficiente para verse en pantalla. Solo se vuelven un problema al imprimirse en tamaños grandes, donde los píxeles se estiran demasiado.

JPG y PNG manejan la resolución igual dentro de un PDF. El formato no fija el DPI, lo fija el número de píxeles, así que un JPG de alta resolución se imprime tan nítido como un PNG de alta resolución.

Revisa las dimensiones en píxeles de tus imágenes de origen antes de construir. Una imagen de 1000 píxeles de ancho impresa en una página A4 tiene más o menos 120 DPI, lo cual es aceptable pero no excelente.

Para documentos que se van a imprimir, usa las fuentes de mayor resolución que tengas. Una fuente nítida hace un PDF nítido, sin importar si el formato es JPG o PNG.

Color: páginas RGB vs. escala de grises

La mayoría de las imágenes son RGB, a todo color, mientras que algunos escaneos son en escala de grises, con solo tonos de gris. La elección afecta tanto el tamaño del archivo como la legibilidad.

Los escaneos en escala de grises son más pequeños que los escaneos a color, porque guardan un valor por píxel en lugar de tres. Un contrato en escala de grises suele tener la mitad del tamaño de la versión a color.

El color importa para sellos, firmas y texto resaltado. Un sello rojo en escala de grises se ve gris, lo cual puede reducir su valor como evidencia, así que conserva el color para documentos oficiales.

JPG maneja la escala de grises de forma eficiente, comprimiendo bien el único canal. PNG también la maneja, aunque el archivo es más grande, porque el almacenamiento sin pérdida no puede descartar la textura del papel.

Para un documento que debe leerse y no admirarse, JPG en escala de grises con alta calidad es la opción práctica. Es pequeño, nítido y honesto sobre lo que contiene el documento.

Cuándo convertir fotos antes de construir

A veces las imágenes de origen necesitan convertirse antes de entrar al PDF. Una foto PNG de 12 MB inflará el PDF, mientras que la misma foto como JPG pesa 1 MB.

Convierte fotos PNG a JPG antes de construir cuando el PDF deba mantenerse pequeño. El conversor PNG a JPG las achica de forma drástica con poco cambio visible.

Convierte fotos HEIC a JPG primero si el constructor de PDF tiene problemas con ellas. El conversor HEIC a JPG produce archivos estándar que cualquier herramienta puede manejar.

No conviertas escaneos PNG a JPG antes de construir. El texto del escaneo es el contenido, y la compresión JPG lo suaviza, mientras que PNG lo mantiene nítido a través del PDF.

La regla es simple: convierte fotos por tamaño, conserva escaneos como PNG por nitidez. Esa división te da el PDF más pequeño que aún se lee limpio.

Límites de tamaño de archivo en portales de subida

La mayoría de los portales de subida limitan el tamaño del PDF a 5 MB, 10 MB o 25 MB. Un PDF largo de escaneos de alta calidad puede superar fácilmente el menor de esos límites.

Las páginas JPG ayudan aquí, porque se comprimen mucho mejor que las páginas PNG. Un documento de fotos de diez páginas como JPG puede pesar 3 MB, mientras que el mismo documento como PNG puede pesar 15 MB.

Si el PDF es demasiado grande, baja el control de calidad un paso y genera de nuevo. Las fotos se comprimen bien con calidad media, mientras que los escaneos necesitan un toque más suave.

Divide un documento muy largo en dos PDF si el tamaño sigue superando el límite. Dos archivos de 8 MB cada uno pasan un límite de 10 MB, mientras que un archivo de 16 MB no pasa.

Revisa siempre las reglas del portal antes de generar. El límite de tamaño, el tamaño de página y los formatos aceptados suelen estar en la página de subida, y leerlos te ahorra una reconstrucción.

Cómo escanear con el DPI correcto

El DPI decide qué tan nítido se ve un escaneo al imprimirse desde un PDF. Un escaneo a 150 DPI se ve bien en pantalla pero suave en papel, mientras que un escaneo a 300 DPI se imprime nítido.

La mayoría de los documentos necesitan de 200 a 300 DPI. Los escaneos de texto a 200 DPI son legibles, mientras que 300 DPI es mejor para documentos con letra pequeña o firmas finas.

Las fotos necesitan DPI más alto cuando se imprimen grandes. Una foto escaneada a 300 DPI se imprime bien en su tamaño original, pero una impresión más grande necesita un escaneo de mayor resolución.

Un DPI más alto significa archivos más grandes, tanto en JPG como en PNG. Un escaneo a 600 DPI es cuatro veces más grande que un escaneo a 300 DPI, así que elige el DPI más bajo que cubra la necesidad.

Para documentos que solo se verán en pantalla, 150 DPI es suficiente. La pantalla no puede mostrar más detalle que su propia resolución, así que el DPI extra solo desperdicia bytes.

La elección de formato es una decisión pequeña con un resultado visible. Las fotos quieren JPG, los documentos quieren PNG y los documentos mezclados quieren ambos. Para la guía completa, lee la guía completa de Imagen a PDF o sigue los pasos en Cómo convertir una imagen a PDF.

Para preparar imágenes primero, usa el Conversor de imágenes o el conversor JPG a PNG.

Preguntas frecuentes

¿Puedo mezclar imágenes JPG y PNG en el mismo PDF?

Sí. El constructor de PDF acepta formatos mezclados, y cada página conserva su formato de origen. Esa es en realidad la mejor opción para documentos mezclados: fotos como JPG para ahorrar espacio y escaneos como PNG para mantener el texto nítido. No necesitas convertir todo a un solo formato primero.

¿Por qué mi PDF con fotos PNG es mucho más grande que con JPG?

PNG guarda cada píxel con exactitud, así que una fotografía detallada necesita muchos más datos que la misma foto como JPG. La brecha es mayor para fotos con mucho detalle y menor para escaneos simples. Si el tamaño importa, convierte las páginas de fotos a JPG antes de construir el PDF, y conserva PNG solo para las páginas de texto.

¿JPG o PNG se imprime mejor desde un PDF?

PNG imprime texto y arte lineal más nítidos, mientras que JPG imprime fotos igual de bien con alta calidad. Para un documento que se va a imprimir y leer, PNG es mejor. Para un álbum de fotos que se va a imprimir y admirar, JPG con alta calidad está bien.

¿Debería convertir mis escaneos JPG a PNG antes de hacer un PDF?

Solo si necesitas editarlos de nuevo. Convertir un escaneo JPG a PNG no restaura el detalle que el JPG ya perdió, y hace el archivo mucho más grande. Para un trabajo directo de escaneo a PDF, usa el JPG como está y pon el control de calidad en alto.

¿Cuál es el mejor formato para una firma escaneada en un PDF?

PNG es lo mejor para firmas, porque las líneas finas de la escritura a mano se mantienen nítidas. Una firma JPG puede verse borrosa en los bordes, sobre todo después de imprimir. Escanea la firma como PNG, mantenla con buena resolución y colócala con Ajustar para que nada se recorte.

¿Puedo reducir el tamaño de un PDF hecho con imágenes PNG?

Sí. Baja el control de calidad al generar, o convierte las páginas de fotos a JPG antes de construir. Las páginas de texto deben mantenerse en PNG, pero las páginas de fotos pueden pasar a JPG con 85 por ciento de calidad con poco cambio visible. Esa combinación suele reducir el tamaño del archivo a la mitad.
