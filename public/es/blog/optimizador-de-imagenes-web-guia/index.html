Optimizador de imágenes web: guía completa

Un sitio web es tan rápido como sus imágenes. El texto carga en milisegundos, pero una sola foto sin optimizar puede detener una página por segundos.

El Optimizador de imágenes para web está hecho para ese problema. Comprime imágenes para espacios específicos del sitio web y luego le entrega el HTML para pegarlo directo en su página.

Esta guía explica los ajustes predefinidos, la configuración y cómo usar la herramienta para hacer más rápido todo un sitio.

¿Qué es la optimización de imágenes web?

La optimización web significa preparar una imagen para un trabajo específico en una página. Una imagen principal, una foto de producto y una miniatura necesitan tamaños y formatos distintos.

Cubre cuatro cosas: tamaño de archivo, dimensiones, formato y HTML. Hacer bien las cuatro hace que la imagen cargue rápido y se vea nítida.

El tamaño de archivo decide la velocidad de descarga. Las dimensiones deciden cómo encaja la imagen en su espacio. El formato decide la compatibilidad y la calidad.

El HTML decide cómo trata el navegador a la imagen. La carga diferida, el ancho, el alto y el texto alternativo viven en la etiqueta, y todos afectan la velocidad y la accesibilidad.

El optimizador maneja las cuatro juntas. Eso es lo que lo diferencia de un compresor sencillo, que solo maneja el tamaño de archivo.

Los cinco ajustes predefinidos de rendimiento web

La herramienta ofrece cinco ajustes predefinidos, cada uno asignado a un espacio real del sitio web. Fijan las dimensiones, el formato y la calidad en un clic.

Producto de comercio electrónico es el valor por defecto. Limita las imágenes a 1200 píxeles de ancho en WebP con 82 por ciento de calidad, lo cual sirve perfecto para fotos de producto.

Otros ajustes cubren imágenes principales, tarjetas, miniaturas y uso compartido social. Cada uno coincide con el espacio para el que se nombra.

Los ajustes son puntos de partida, no prisiones. Puede personalizar cualquier ajuste después de elegir uno, mezclando y combinando según su página.

Empiece con el ajuste más cercano a su espacio. Ajuste desde ahí solo si el resultado no sirve para el diseño.

Cómo optimizar imágenes principales

Las imágenes principales llenan la parte superior de la página, así que importan más para las primeras impresiones y para el Largest Contentful Paint.

Una imagen principal debería ser lo bastante grande para verse nítida en pantallas anchas, pero no más grande. Una imagen principal sobredimensionada desperdicia ancho de banda en píxeles que nadie ve.

Use WebP para las imágenes principales en sitios modernos. Mantiene la imagen grande más ligera que JPG con la misma calidad.

Nunca cargue de forma diferida una imagen principal. Está por encima del pliegue, así que el navegador debería obtenerla de inmediato, no esperar un desplazamiento.

Precargue la imagen principal cuando pueda. Avisar al navegador temprano sobre la imagen más importante recorta tiempo real de la primera pintura.

Cómo optimizar imágenes de producto

Las imágenes de producto venden el producto, así que deben mantenerse nítidas. El ajuste de comercio electrónico las limita a 1200 píxeles, lo cual sirve para la mayoría de los diseños de tienda.

Mantenga el fondo limpio y el producto centrado. Una foto de producto ordenada se comprime mejor y se ve más profesional.

Use dimensiones consistentes en todo el catálogo. Una cuadrícula de tamaños mixtos se ve desordenada, por muy buena que sea la compresión.

WebP es ideal para fotos de producto en tiendas modernas. Para mercados que exigen JPG, cambie el formato y mantenga las mismas dimensiones.

Revise la página de producto en un teléfono después de subir. La mayoría de los compradores navega en móvil, y la imagen debe verse bien ahí primero.

Tarjetas y miniaturas

Las tarjetas y miniaturas se muestran pequeñas, así que necesitan la menor cantidad de datos. Una imagen de 400 píxeles basta para una tarjeta que se muestra a 300 píxeles.

Las imágenes pequeñas toleran una compresión más fuerte. Una miniatura con menor calidad aún se ve limpia, porque el tamaño de visualización esconde la suavidad.

Cargue de forma diferida las tarjetas por debajo del pliegue. No son visibles cuando se abre la página, así que el navegador puede obtenerlas después.

Mantenga la proporción consistente en todas las tarjetas. Una cuadrícula de proporciones mixtas se ve desordenada y obliga al navegador a reacomodar el diseño.

Las miniaturas son donde la optimización rinde más. Una página con veinte tarjetas ahorra megabytes cuando cada miniatura tiene el tamaño adecuado.

El botón Copiar etiqueta de imagen

El botón Copiar etiqueta de imagen escribe el HTML completo de su imagen optimizada. Incluye la fuente, las dimensiones, el texto alternativo y el comportamiento de carga.

El texto alternativo se genera desde el nombre de archivo o su descripción. Un buen texto alternativo ayuda a la accesibilidad y a que los buscadores entiendan la imagen.

La etiqueta incluye atributos de ancho y alto. Esos evitan el cambio de diseño, que es una métrica de Core Web Vitals que afecta las posiciones.

La carga diferida está incluida para imágenes por debajo del pliegue. Le dice al navegador que espere hasta que la imagen se acerque a la ventana antes de descargarla.

Pegue la etiqueta directo en su página. Está lista para usar, sin necesidad de edición manual.

La carga diferida bien hecha

La carga diferida retrasa las imágenes hasta que se necesitan. Es una de las victorias de velocidad más fáciles en cualquier página con muchas imágenes.

Aplíquela a las imágenes por debajo del pliegue. No son visibles cuando se abre la página, así que descargarlas temprano desperdicia ancho de banda.

Nunca cargue de forma diferida la imagen principal ni el logo. Son visibles de inmediato, y retrasarlos daña la primera impresión y la puntuación LCP.

El optimizador añade la carga diferida de forma automática para los ajustes adecuados. El ajuste de imagen principal la deja apagada, que es el comportamiento correcto.

Pruebe la página después de añadir la carga diferida. Desplácese hacia abajo y confirme que las imágenes aparecen con suavidad a medida que entran en vista.

Formatos para la web

WebP es el mejor formato para la mayoría de las imágenes web. Es más pequeño que JPG con la misma calidad y admite transparencia como PNG.

JPG sigue siendo esencial para la compatibilidad. El correo, el uso compartido social y los sistemas antiguos aún prefieren JPG, y el ajuste Social OG cambia a él de forma automática.

PNG sirve para gráficos de interfaz, no para fotos. Un logo o ícono se mantiene perfecto en PNG, mientras que una foto en PNG desperdicia ancho de banda.

SVG no lo maneja esta herramienta. Es un formato vectorial, y el optimizador trabaja con imágenes rasterizadas como JPG, PNG y WebP.

Cuando tenga dudas, use WebP para el sitio y JPG para compartir. El optimizador hace que cambiar entre ellos sea un trabajo de un clic.

El control de calidad: de 20 a 95 por ciento

El control de calidad va de 20 a 95 por ciento, no de 0 a 100. Ese rango es deliberado y lo protege de malas decisiones.

Por debajo del 20 por ciento, las imágenes se deshacen de forma visible. Ningún espacio de sitio web se beneficia de una calidad tan baja, así que la herramienta no la ofrece.

Por encima del 95 por ciento, el archivo crece rápido con casi ninguna ganancia visible. Los datos extra preservan detalle que el ojo no puede ver.

La mayoría de los ajustes se ubica entre 75 y 85 por ciento. Ese rango da resultados limpios con tamaños de archivo pequeños para casi cada imagen.

Ajuste el control solo cuando el resultado del ajuste no sirva para la imagen. Una foto detallada puede querer 85, mientras que un gráfico sencillo está bien con 70.

Eliminación de EXIF y peso de página

Las fotos de cámara llevan metadatos ocultos: ubicación GPS, modelo de cámara y ajustes. Esos datos añaden peso y filtran información privada.

El optimizador elimina los datos EXIF y GPS durante la compresión. El archivo descargado no lleva registro de dónde o cuándo se tomó.

Eliminarlos ahorra solo unos pocos kilobytes por imagen, pero se suma. Veinte imágenes ahorran una cantidad significativa juntas.

La privacidad es el beneficio mayor. Una foto publicada en un sitio público no debería contener la ubicación donde se tomó.

Para el trabajo de clientes, eliminarlos es esencial. Los productos sin lanzar y las ubicaciones privadas no deben filtrarse a través de los metadatos de imagen.

Optimización por lotes para sitios completos

Puede optimizar muchas imágenes en un lote. Suelte treinta imágenes de blog, elija un ajuste y descárguelas todas juntas.

El modo por lotes es ideal para migraciones de sitio. Mover un blog a un tema nuevo significa volver a optimizar cada imagen, y un lote lo maneja en minutos.

Revise algunos resultados antes de descargar todo el lote. Una sola imagen suave puede esconderse entre las buenas.

Mantenga el ajuste consistente en todo el lote. Los ajustes mixtos producen resultados mixtos, que se ven desordenados en el sitio en vivo.

Para objetivos exactos de tamaño de archivo en lugar de ajustes, el compresor de tamaño de archivo deseado acepta cualquier número que escriba.

Uso compartido social e imágenes Open Graph

Cuando alguien comparte su página, la plataforma muestra una imagen de vista previa. Esa imagen es muchas veces lo primero que ve un visitante nuevo.

Las imágenes Open Graph necesitan dimensiones específicas, normalmente 1200 por 630 píxeles. El ajuste Social OG las dimensiona bien y cambia a JPG.

Mantenga el archivo por debajo de unos pocos cientos de kilobytes. Una imagen de vista previa pesada carga lento en la tarjeta de uso compartido, y algunas plataformas la omiten por completo.

Pruebe la tarjeta de uso compartido antes de publicar. Cada plataforma importante ofrece un depurador que muestra exactamente cómo se verá la vista previa.

Una buena imagen para compartir es sencilla y audaz. El texto debería ser grande, el sujeto debería estar centrado y el fondo debería estar despejado.

Pantallas Retina y de alta densidad

Las pantallas Retina concentran más píxeles en el mismo tamaño físico. Una imagen que se ve nítida en una pantalla normal puede verse suave en una pantalla Retina.

La solución es servir una imagen con el doble de ancho que su tamaño de visualización. Una miniatura que se muestra a 400 píxeles de ancho debería tener 800 píxeles en el archivo.

Los ajustes del optimizador tienen esto en cuenta. Un ajuste de tarjeta produce una imagen que se mantiene nítida en pantallas de alta densidad sin desperdiciar ancho de banda.

Para las miniaturas pequeñas, esto importa poco. Para las imágenes destacadas grandes, la diferencia entre estándar y lista para Retina es visible.

Pruebe en una pantalla real de alta densidad cuando pueda. Las capturas del resultado esconden justo la suavidad que está tratando de revisar.

Texto alternativo y accesibilidad

Cada imagen web necesita texto alternativo. Describe la imagen para los lectores de pantalla y para los buscadores, y se muestra cuando la imagen no carga.

El optimizador genera texto alternativo desde el nombre de archivo o su descripción. Edítelo cuando el texto generado no describa bien la imagen.

Escriba el texto alternativo como una frase. Describa qué muestra la imagen, no para qué es, y manténgalo por debajo de unos 125 caracteres.

Las imágenes decorativas necesitan texto alternativo vacío, no una descripción. Un alt en blanco les dice a los lectores de pantalla que omitan la imagen por completo.

Un buen texto alternativo también ayuda al SEO. Los buscadores lo leen para entender la imagen, lo que puede traer tráfico desde la búsqueda de imágenes.

CDN y caché para imágenes

Una red de entrega de contenido sirve sus imágenes desde servidores cercanos a cada visitante. Eso reduce el tiempo de descarga, sobre todo para una audiencia global.

Las imágenes optimizadas se benefician más de una CDN. Un archivo pequeño servido cerca carga casi al instante, mientras que un archivo grande servido lejos se arrastra.

Los encabezados de caché les dicen a los navegadores que guarden las imágenes localmente. Un visitante que regresa luego carga la página sin descargar las imágenes de nuevo.

Fije tiempos largos de caché para imágenes que rara vez cambian. Un logo o una foto de producto puede guardarse en caché por meses con seguridad.

La optimización y la entrega trabajan juntas. Una imagen pequeña en una CDN rápida supera a una imagen grande en un servidor lento siempre.

WebP con un respaldo JPG

Algunos navegadores antiguos no pueden abrir WebP. Servir solo WebP dejaría a esos visitantes con imágenes rotas.

El elemento picture resuelve esto. Enumera WebP primero y JPG segundo, y el navegador elige el primer formato que admite.

Genere ambas versiones de cada imagen. El optimizador produce la copia WebP, y una copia JPG del mismo ajuste sirve como respaldo.

Pruebe el respaldo en un navegador o dispositivo antiguo. La versión JPG debería aparecer sin problemas, sin diferencia visible.

A medida que crece la compatibilidad con WebP, el respaldo importa menos. Por ahora, es un seguro barato contra imágenes rotas.

Cómo medir la mejora

Los números de antes y después hacen concreto el beneficio. Anote el peso total de imágenes y el tiempo de carga antes de optimizar, luego mida de nuevo después.

Una página típica baja de varios megabytes a menos de uno. Ese cambio se muestra de inmediato en las puntuaciones de velocidad y en cómo se siente la página.

Revise las Core Web Vitals después de optimizar. El LCP debería mejorar más, ya que la imagen principal suele ser la pintura más grande.

Pida a un colega que cargue la página en su teléfono. Un dispositivo nuevo con una conexión real es la prueba honesta de su trabajo.

Lleve un registro sencillo de los ahorros. Cuando alguien pregunte por qué hay que optimizar las imágenes, los números responden mejor que cualquier argumento.

Para los pasos prácticos, lea Cómo optimizar imágenes para la velocidad del sitio web. Para la explicación profunda de Core Web Vitals, vea Optimización de imágenes para Core Web Vitals: LCP y tamaño de archivo. Para objetivos sencillos de tamaño, el compresor de 200 KB cubre la mayoría de las imágenes web.

Preguntas frecuentes

¿Qué ajuste predefinido debo usar para una imagen principal?

Use el ajuste de imagen principal, que dimensiona la imagen para un banner de ancho completo y mantiene alta la calidad. Nunca cargue de forma diferida una imagen principal, ya que está por encima del pliegue y afecta el Largest Contentful Paint. Use WebP cuando el sitio lo admita para el archivo más pequeño con esa calidad.

¿Por qué la herramienta cambia a JPG para imágenes de uso compartido social?

Las plataformas sociales y los clientes de correo manejan JPG con más fiabilidad que WebP. Los ajustes Social OG y Correo cambian el formato de forma automática para que sus imágenes compartidas se muestren bien en todas partes, incluso en sistemas antiguos que no pueden abrir WebP.

¿Debo mantener la carga diferida en mi imagen principal?

No. La carga diferida retrasa la descarga hasta que la imagen se acerca a la ventana, lo cual es incorrecto para una imagen principal visible de inmediato. Dañará su puntuación de Largest Contentful Paint. Mantenga la carga diferida solo para imágenes por debajo del pliegue.

¿Qué hace la opción Solo reducir?

Protege a las imágenes pequeñas de ser ampliadas. Cuando está activada, la herramienta solo reduce las imágenes más grandes que las dimensiones del ajuste y deja intactas las más pequeñas. Esto mantiene los íconos y las miniaturas nítidos en lugar de estirarlos.

¿Por qué los archivos descargados se nombran con -web al final?

El sufijo -web marca el archivo como la versión optimizada para web, así que no se confundirá con el original. Un nombre como hero-1200-web.webp le dice al instante que el archivo está listo para el sitio web.

¿Puedo usar el Optimizador de imágenes para web en lugar del Compresor de imágenes en lote?

Use el Optimizador web cuando necesite ajustes predefinidos, etiquetas HTML y tamaños específicos por espacio para un sitio web. Use el Compresor en lote cuando solo necesite archivos más pequeños sin ajustes específicos web. Para límites exactos de tamaño de archivo, use el compresor de tamaño de archivo deseado.
