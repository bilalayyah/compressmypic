Cómo usar Optimizador de imágenes para web

Siga estos pasos sencillos para completar su tarea, directamente en su navegador.

1

Seleccione una de las 5 plantillas de rendimiento web

Elija Encabezado / Banner (1600 px WebP 80 %), Producto de comercio electrónico (1200 px WebP 82 %), Tarjeta / Miniatura (640 px WebP 75 %), OG social / Correo (1200 px JPG 82 %) o Gráfico Retina 2× (1920 px WebP 88 %).

2

Personalice el formato web, la dimensión máxima o la calidad

Cambie entre WebP, JPG o PNG, ajuste la Dimensión máxima (borde largo) de 640 px a 1920 px (o Conservar dimensiones originales) y afine la Calidad del 20 % al 95 %.

3

Suelte los recursos web sin procesar en la zona de subida

Suba imágenes JPG, PNG, WebP, HEIC, SVG, BMP, GIF o AVIF de hasta 25 MB cada una, con la opción Solo reducir imágenes más grandes marcada para evitar inflar los íconos pequeños.

4

Revise el ahorro de peso de página y compare la calidad

Revise el Resumen de rendimiento web para ver el peso total de página ahorrado, verifique las insignias Listo para web por tarjeta e inspeccione los bordes lado a lado con Comparar.

5

Copie fragmentos HTML <img> responsivos

Pulse Copiar <img> en cualquier tarjeta terminada para obtener el marcado listo para pegar, con ancho, alto, loading="lazy" y decoding="async".

6

Descargue recursos -web individuales o el paquete ZIP

Guarde archivos individuales <nombre>-web o pulse Descargar todo (ZIP) para descargar web_optimized_compressmypic.zip limpiamente.

¿Por qué usar Optimizador de imágenes para web de CompressMyPic?

Plantillas listas para web

Límites de dimensión preconfigurados y puntos ideales de calidad WebP/JPG pensados para LCP y PageSpeed Insights.

Fragmento HTML <img> copiable

Genera atributos responsivos de ancho, alto, loading="lazy" y decoding="async" para evitar el cambio de diseño (CLS).

Eliminación automática de EXIF y protección contra ampliación

Elimina los metadatos inflados de la cámara y evita ampliar sin necesidad los íconos más pequeños.

Inspector interactivo de antes y después

Verifique la claridad visual lado a lado antes de desplegar los recursos en producción.
