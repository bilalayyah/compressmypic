Comment convertir SVG en PNG

Convertissez vos logos et icônes SVG en PNG à la taille dont vous avez besoin. Téléversez, choisissez une échelle, vérifiez le résultat et téléchargez — un seul fichier ou tout un lot.

Un logo SVG est infiniment adaptable, mais beaucoup d’endroits veulent encore un PNG. Le convertir prend quelques secondes, et la seule décision qui compte est la taille de sortie.

Choisissez la bonne échelle, et le PNG est parfait. Choisissez la mauvaise, et il ressort flou ou inutilement énorme.

Ce guide vous accompagne étape par étape, du téléversement du SVG au téléchargement d’un PNG net.

Avant de commencer : préparez le SVG

Ouvrez d’abord le SVG dans un navigateur et confirmez qu’il s’y affiche correctement. S’il a l’air incorrect, il aura aussi l’air incorrect en PNG.

Convertissez le texte en contours dans votre outil de design si le SVG contient du lettrage. Le texte vectorisé devient des formes, donc il s’affiche exactement, quelles que soient les polices.

Intégrez toute image liée comme URI de données dans le SVG. Le convertisseur ne peut pas récupérer de fichiers externes, donc une photo liée manquera dans le PNG.

Retirez tout rectangle d’arrière-plan si vous voulez un PNG transparent. Une forme d’arrière-plan devient partie intégrante de l’image, alors qu’un SVG transparent reste transparent.

Étape 1 : ouvrir l’outil SVG en PNG

Ouvrez l’outil SVG en PNG dans votre navigateur. La page fonctionne sur Windows, Mac, Linux, ChromeOS, Android et iOS.

Vous verrez une zone de téléversement et un sélecteur d’échelle. Ces deux réglages constituent tout le travail.

Aucun compte n’est nécessaire, et rien n’est téléversé. La conversion se fait sur votre appareil, ce qui compte pour les logos de clients et les ressources de marque.

Sur téléphone, la page fonctionne dans votre navigateur mobile. Touchez la zone de téléversement pour choisir des fichiers SVG sur votre appareil.

Étape 2 : téléverser vos fichiers SVG

Glissez vos fichiers SVG sur la zone de téléversement, ou cliquez dessus pour ouvrir le sélecteur de fichiers. Vous pouvez sélectionner plusieurs fichiers à la fois pour un lot.

Chaque fichier apparaît sous forme de carte avec une miniature, pour confirmer que les bons fichiers sont chargés. Un mauvais fichier est facile à repérer et à retirer.

Les fichiers jusqu’à 25 Mo chacun sont acceptés, ce qui couvre même les énormes fichiers illustrés avec des milliers de chemins. Les SVG très complexes prennent simplement une ou deux secondes de plus.

Vous pouvez aussi coller un SVG copié avec Ctrl+V sur un ordinateur. C’est pratique quand le code SVG est dans votre presse-papiers, venu d’une autre application.

Étape 3 : choisir l’échelle de sortie

Le sélecteur d’échelle propose 1x, 2x, 3x et 4x. L’échelle multiplie la taille naturelle du SVG, donc une icône de 24 pixels à 4x devient un PNG de 96 pixels.

Pour une icône de site web, 2x ou 3x suffit généralement. Le PNG est net sur les écrans Retina sans gaspiller d’octets.

Pour un logo sur une diapositive de présentation, 4x donne une marge confortable. Un petit logo agrandi dans PowerPoint reste net quand le PNG a assez de pixels.

Pour l’impression, choisissez l’échelle qui atteint 300 PPP à la taille imprimée. Un logo imprimé sur 5 cm de large a besoin d’au moins 600 pixels, donc partez de la taille d’impression pour calculer.

Étape 4 : convertir les fichiers

Cliquez sur le bouton Convertir. L’outil dessine chaque SVG sur un canevas à l’échelle choisie et encode le résultat en PNG.

La conversion est rapide, généralement une ou deux secondes par fichier. Les SVG très complexes avec des milliers de chemins prennent un peu plus de temps à dessiner.

Chaque carte se met à jour avec la nouvelle taille et les nouvelles dimensions du PNG. Vérifiez les dimensions pour confirmer que l’échelle a produit la taille attendue.

Si un fichier échoue avec une erreur, le SVG contient peut-être des fonctionnalités non prises en charge ou du code mal formé. Ouvrez-le dans un navigateur pour confirmer qu’il s’y affiche d’abord.

Étape 5 : vérifier le résultat

Cliquez sur Comparer sur une carte pour voir le SVG et le PNG côte à côte. Zoomez sur les bords du logo et confirmez qu’ils sont nets et propres.

Vérifiez d’abord le texte, si le SVG en contient. Un texte qui a l’air incorrect signifie une police manquante, et la solution est de convertir le texte en contours et de convertir à nouveau.

Vérifiez les images manquantes. Un espace vide là où une photo devrait être signifie que l’image était liée en externe, et vous devez l’intégrer comme URI de données.

Vérifiez la transparence. Un logo qui devrait être transparent ne doit montrer aucun cadre blanc autour de lui, sinon le SVG avait un rectangle d’arrière-plan à retirer.

Étape 6 : télécharger les fichiers PNG

Cliquez sur Télécharger sur une carte pour enregistrer un seul PNG. Le nom de fichier garde votre nom d’origine avec une extension .png.

Pour un lot, cliquez sur Tout télécharger pour obtenir un seul ZIP contenant tous les PNG convertis. C’est bien plus rapide que de les télécharger un par un.

Vérifiez une fois les fichiers téléchargés avant de les utiliser. Ouvrez un PNG dans votre visionneuse photo et confirmez qu’il est net à la taille dont vous avez besoin.

Gardez aussi les fichiers SVG d’origine. Ce sont les originaux, et vous pourrez les rastériser à nouveau à n’importe quelle taille dès qu’un PNG différent devient nécessaire.

  1. Ouvrez l’outil SVG en PNG et téléversez vos fichiers SVG.
  2. Choisissez une échelle : 2x pour le web, 4x pour les présentations et l’impression.
  3. Convertissez et vérifiez les bords, le texte et la transparence.
  4. Téléchargez les PNG un par un ou tout le lot en ZIP.

Convertir tout un lot d’icônes

Sélectionnez toutes les icônes SVG à la fois dans le sélecteur de fichiers. Elles se chargent dans la file, et un seul clic les convertit toutes à la même échelle.

Utilisez la même échelle pour tout le lot. La cohérence compte quand les icônes apparaissent ensemble, car des tailles mélangées paraissent irrégulières.

Vérifiez deux ou trois icônes après la conversion, plutôt que les cinquante. Si celles-là sont bonnes, les autres le seront aussi, puisque les réglages sont les mêmes.

Téléversez les icônes PNG là où elles sont nécessaires. Un favicon, une icône d’application ou un diaporama acceptent tous les fichiers PNG sans autre conversion.

Choisir la taille pour chaque usage

Pour un favicon, rastérisez aux tailles exactes dont le site a besoin, généralement 16, 32 et 48 pixels. Le générateur de favicon peut aussi créer ces tailles à partir d’un PNG.

Pour un avatar de réseau social, 400 × 400 pixels est une bonne taille. Il est net sur ordinateur et mobile, et le fichier reste petit.

Pour un logo de présentation, 4x la taille du SVG donne généralement assez de pixels. Un logo de 100 pixels à 4x devient 400 pixels, ce qui est net sur une diapositive.

Pour l’impression, calculez à partir des PPP. Un logo de 5 cm à 300 PPP a besoin de 600 pixels, donc choisissez l’échelle qui atteint au moins ce nombre.

Résoudre les problèmes courants

Si le PNG paraît flou, l’échelle était trop basse. Rastérisez à nouveau à une échelle plus élevée à partir de l’original SVG, car un PNG basse résolution ne peut pas être affiné.

Si le texte a l’air incorrect, la police manque. Convertissez le texte en contours dans votre outil de design et convertissez à nouveau.

Si une photo liée manque, intégrez-la comme URI de données dans le SVG. Le convertisseur ne peut pas récupérer de fichiers externes, donc l’image doit voyager à l’intérieur du SVG.

Si le fichier échoue avec une erreur, ouvrez le SVG dans un navigateur. S’il s’y affiche, essayez de le convertir seul plutôt qu’en lot.

Conseils pour téléphones et tablettes

Sur téléphone, touchez la zone de téléversement et choisissez des fichiers SVG sur votre appareil. La conversion s’exécute sur le téléphone, et les PNG sont téléchargés sur votre appareil.

Gardez les lots modestes sur téléphone, car les SVG complexes prennent du temps à rastériser sur un processeur mobile. Dix fichiers à la fois, c’est confortable.

Les téléchargements atterrissent dans le dossier Téléchargements de votre téléphone. Sur iPhone, vérifiez l’application Fichiers ; sur Android, vérifiez votre gestionnaire de fichiers.

Pour un gros lot d’icônes, utilisez un ordinateur. Le processeur plus rapide et le plus grand écran rendent la gestion de cinquante fichiers bien plus facile.

Convertir un logo pour une carte de visite

Un logo de carte de visite doit s’imprimer nettement à une taille minuscule, donc rastérisez le SVG à 4x. Un petit logo avec assez de pixels derrière lui reste net sur la carte.

Vérifiez les couleurs après la conversion, car les couleurs d’impression diffèrent des couleurs d’écran. Un tirage d’essai rapide confirme que les couleurs de marque sont correctes sur papier.

Envoyez le PNG à l’imprimerie avec le SVG en sauvegarde. L’imprimerie peut rastériser le SVG elle-même si le PNG a un problème, donc fournir les deux couvre tous les cas.

Gardez le fichier PNG petit, car une imprimerie de cartes de visite n’a pas besoin d’une énorme image. Un logo de 1000 pixels suffit amplement pour une carte, et un fichier plus gros ne fait que ralentir le téléversement.

Commandez une carte d’essai avant d’imprimer tout le lot. Une seule carte confirme la taille du logo, les couleurs et la netteté avant de vous engager sur des centaines.

Convertir des icônes pour un site web

Les icônes de sites web commencent en fichiers SVG, et elles deviennent des PNG pour les navigateurs plus anciens. Rastérisez à 2x ou 3x la taille d’affichage, pour que les icônes soient nettes sur les écrans Retina.

Utilisez la même échelle pour tout le jeu d’icônes. La cohérence compte quand les icônes apparaissent ensemble, car des tailles mélangées paraissent irrégulières.

Testez les icônes sur le site web réel avant de les publier. Une icône parfaite dans l’outil de design peut paraître différente sur la couleur d’arrière-plan du site.

Pour un site web moderne, envisagez d’utiliser directement les fichiers SVG. Les navigateurs affichent le SVG nativement, et les icônes s’adaptent parfaitement sans aucune rastérisation.

Gardez les originaux SVG dans le dossier du projet après la conversion. Si le site web est refondu, les icônes peuvent être rastérisées à nouveau à de nouvelles tailles sans être redessinées.

Convertir un SVG pour un t-shirt imprimé

Un t-shirt imprimé a besoin d’une image en haute résolution, et le SVG est la source idéale. Rastérisez à la plus grande échelle permise par l’outil, jusqu’au plafond de 8000 pixels, pour une impression nette.

Vérifiez le visuel après la conversion, car un t-shirt imprimé montre chaque défaut. Un logo qui a l’air correct à l’écran peut révéler des bords rugueux une fois imprimé en grand sur du tissu.

Envoyez le PNG à l’imprimerie avec le SVG en sauvegarde. Le logiciel de l’imprimerie peut préférer un format à l’autre, et fournir les deux couvre tous les cas.

Pour un t-shirt sombre, vérifiez la transparence. Un logo à l’arrière-plan transparent s’imprime proprement sur un tissu sombre, alors qu’un logo encadré de blanc a l’air incorrect.

Commandez un seul t-shirt d’essai avant d’imprimer un lot. Un tirage d’essai confirme la taille, les couleurs et le placement avant de vous engager sur des dizaines de t-shirts.

Convertir un SVG pour une présentation

Les diapositives de présentation ont besoin de logos nets, et le SVG est la source idéale. Rastérisez à 4x la taille du SVG, pour que le logo reste net quand il est projeté sur un grand écran.

Vérifiez le logo sur l’arrière-plan réel de la diapositive après la conversion. Un logo parfait sur blanc peut montrer une légère frange sur une diapositive colorée si la qualité était basse.

Pour un diaporama avec beaucoup de diapositives, convertissez tous les logos d’un coup. Une conversion par lots prend quelques minutes, et les PNG sont prêts à être glissés dans les diapositives.

Testez le diaporama sur le projecteur avant l’exposé. Une diapositive nette sur un portable peut paraître douce une fois projetée, et un test rapide repère le problème tôt.

Gardez les originaux SVG dans le dossier du projet après la conversion. Si la présentation est réutilisée avec un nouveau modèle, les logos peuvent être rastérisés à nouveau à de nouvelles tailles.

Convertir un SVG pour un favicon

Un favicon est la minuscule icône dans l’onglet du navigateur, et il commence généralement comme un logo SVG. Rastérisez-le à 16, 32 et 48 pixels pour les tailles de favicon standard.

Concevez le favicon simplement, car les minuscules tailles cachent les détails. Un logo complexe à 16 pixels devient un flou, alors qu’une forme simple reste reconnaissable.

Testez le favicon dans plusieurs navigateurs après l’avoir ajouté. Une vérification rapide confirme qu’il s’affiche correctement, pour que le site ait l’air soigné dans chaque onglet.

Pour les navigateurs modernes, envisagez d’utiliser directement le favicon SVG. Les navigateurs affichent les favicons SVG nativement, et l’icône s’adapte parfaitement sans aucune rastérisation.

Gardez l’original SVG après la conversion. Si le site est refondu, le favicon peut être rastérisé à nouveau à de nouvelles tailles sans redessiner le logo.

Convertir un SVG pour une bannière de site web

Une bannière de site web est une image large, et le SVG est la source idéale quand la bannière est un visuel plutôt qu’une photo. Rastérisez à la largeur d’affichage de la bannière pour un résultat net.

Vérifiez les dimensions de la bannière avant de convertir. Une bannière affichée sur 1200 pixels de large a besoin d’un PNG d’au moins cette largeur, sinon elle paraîtra douce.

Pour une bannière avec du texte, rastérisez à 2x la taille d’affichage. Le texte reste net sur les écrans Retina, et le fichier est encore assez petit pour se charger rapidement.

Testez la bannière sur ordinateur et téléphone après la conversion. Une bannière parfaite sur un écran large peut être mal recadrée sur un écran étroit, et un test rapide le repère.

Gardez l’original SVG dans le dossier du projet. Si le site web est refondu avec une nouvelle taille de bannière, le visuel peut être rastérisé à nouveau sans être redessiné.

Voilà tout le processus : préparer, téléverser, choisir une échelle, télécharger. Questions fréquentes

Quelle taille fait le PNG à l’échelle 1x ?

À 1x, le PNG correspond à la taille naturelle du SVG, donc une icône de 24 px devient un PNG de 24 px. Pour des résultats nets sur les écrans modernes, utilisez 2x ou 3x, et pour les présentations ou l’impression, utilisez 4x. L’exportation est plafonnée à 8000 px sur le côté le plus long, ce qui a rarement d’importance pour les icônes et les logos.

Peut-on convertir des fichiers SVG sur son téléphone ?

Oui. Ouvrez l’outil dans le navigateur de votre téléphone, touchez la zone de téléversement et choisissez des fichiers SVG sur votre appareil. La conversion s’exécute sur le téléphone, et les PNG sont téléchargés sur votre appareil. Gardez les lots modestes sur téléphone, car les SVG complexes prennent du temps à rastériser sur mobile.

Quel nom de fichier gardera le PNG exporté ?

Le PNG garde le nom de fichier de votre SVG d’origine avec une extension .png, donc logo.svg devient logo.png. Cela facilite la recherche et garde vos fichiers organisés. Pour un lot, le ZIP contient chaque PNG avec son nom d’origine correspondant.

Le convertisseur prend-il en charge les animations SVG ?

Non, pas vraiment. Les animations SVG utilisant SMIL ou CSS ne sont pas préservées, puisque le convertisseur dessine une seule image fixe sur le canevas. Le résultat est un PNG fixe du SVG tel qu’il apparaît au début. Pour un logo animé, gardez le SVG lui-même.

Peut-on rastériser un SVG avec une image intégrée comme URI de données ?

Oui. Les images intégrées comme URI de données dans le SVG font partie du fichier, donc elles s’affichent correctement dans le PNG. C’est la bonne façon d’inclure des photos dans un SVG pour la conversion. Les images externes liées, en revanche, sont laissées de côté, puisque le convertisseur ne peut pas les récupérer.

Pourquoi mon PNG converti paraît-il flou ?

L’échelle était trop basse pour la taille dont vous avez besoin. Une icône de 24 px rastérisée à 1x ne fait que 24 pixels, et l’étirer jusqu’à 200 pixels la rend floue. Rastérisez à nouveau à une échelle plus élevée à partir de l’original SVG, car un PNG basse résolution ne peut pas être affiné ensuite.
