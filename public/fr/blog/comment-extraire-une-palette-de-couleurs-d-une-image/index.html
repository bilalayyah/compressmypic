Comment extraire une palette de couleurs d’une image

Extrayez une palette de couleurs de n’importe quelle photo en cinq étapes : envoyez, choisissez 3 à 12 nuances, lisez les pourcentages, et copiez le CSS ou le JSON — gratuit, dans votre navigateur.

Vous avez une photo dont vous adorez les couleurs, et il vous faut ces couleurs en palette pour un site web, une affiche ou une marque. Les copier à l'œil est lent et imprécis.

Ce guide vous accompagne pour extraire une palette de couleurs d'une image en cinq étapes : envoyez, choisissez le nombre de nuances, lisez les pourcentages, et copiez ou téléchargez le résultat.

Tout le processus prend moins d'une minute quand on le connaît. Aucun logiciel à installer, aucun compte à créer, et aucun fichier envoyé sur un serveur.

Ce qu'il vous faut avant de commencer

Il vous faut l'image qui contient les couleurs, en format JPG, PNG ou WebP, jusqu'à 20 Mo. Une photo, une photo de produit, une capture ou une œuvre d'art conviennent toutes.

Sachez à quoi sert la palette. Un thème de site web a besoin de quatre à six couleurs, une identité de marque en demande quelques-unes de plus, et une planche d'ambiance peut utiliser les douze.

Un navigateur est le seul logiciel nécessaire. L'outil fonctionne sur Chrome, Safari, Firefox et Edge, sur ordinateur et sur mobile, sans extension.

Enfin, utilisez le fichier original le plus propre possible. Une copie recompressée ou une capture de la photo peut décaler légèrement les valeurs de pixels et changer la palette obtenue.

Étape 1 : envoyez l'image ou collez une capture

Ouvrez l'extracteur de palette de couleurs d'image et glissez votre image dans la zone d'envoi. Vous pouvez aussi cliquer sur la zone pour choisir un fichier sur votre appareil.

Si les couleurs sont sur votre écran en ce moment, faites une capture et collez-la avec Ctrl+V. L'outil accepte directement les images du presse-papiers, donc vous pouvez extraire une palette de n'importe quel site web ou application que vous regardez.

La palette apparaît dès que l'image se charge, en commençant par la valeur par défaut de 6 nuances. Chaque nuance montre sa couleur, ses codes, et le pourcentage de l'image qu'elle couvre.

Si vous avez envoyé le mauvais fichier, passez à une autre photo depuis l'outil. L'ancienne palette est remplacée, et vous pouvez continuer à travailler sans recharger la page.

Étape 2 : choisissez combien de nuances vous voulez

Déplacez le curseur pour régler le nombre de nuances entre 3 et 12. La palette se reconstruit instantanément à chaque déplacement, pour que vous puissiez comparer les nombres en quelques secondes.

Commencez avec 6 et regardez le résultat. Si deux nuances paraissent presque identiques, baissez le nombre à 4 ou 5 et regardez les doublons fusionner en une seule couleur plus nette.

Si une couleur d'accent qui vous tient à cœur manque, augmentez le nombre vers 12. Plus de nuances donnent aux petits détails leur propre boîte, donc une minuscule enseigne néon ou une petite fleur peut apparaître.

Il n'y a pas de nombre unique juste. Un site web minimal veut 3 ou 4, une riche planche de marque veut 8 ou 10, et le curseur existe pour que vous trouviez le nombre qui convient à votre projet.

Étape 3 : lisez les pourcentages et la bande

Chaque nuance porte un badge de pourcentage montrant la part de l'image couverte par cette couleur. Le plus grand pourcentage est la couleur dominante, et les plus petits sont les accents.

Lisez les pourcentages comme une hiérarchie pour votre design. La couleur dominante devrait prendre le plus d'espace, la couleur secondaire un rôle de soutien, et les plus petites couleurs seulement les points forts.

Regardez la bande de couleurs proportionnelle sous les nuances. Elle montre la même hiérarchie sous forme de barre, avec des largeurs de segments correspondant aux pourcentages, ce qui rend l'équilibre facile à juger.

Si la bande est surtout d'une couleur, la photo a un ton dominant fort, et votre design paraîtra calme. Si la bande est divisée uniformément, la photo est chargée, et votre design aura besoin de retenue ailleurs.

Étape 4 : copiez la palette en CSS ou en JSON

Cliquez sur Copier le CSS pour copier toutes les nuances sous forme de propriétés personnalisées CSS. Les variables sont nommées dans l'ordre, chacune avec une valeur HEX, et elles se collent directement dans une feuille de style.

Cliquez sur Copier le JSON quand la palette alimente du code plutôt qu'une feuille de style. Le JSON inclut les valeurs HEX, RGB et HSL de chaque couleur plus sa part en pourcentage, sous une forme qu'un script peut analyser.

Changez le nombre de nuances et les exports se mettent à jour. Vous pouvez passer de 6 couleurs à 4 sans renvoyer l'image, et le CSS ou le JSON copié reflète immédiatement le nouvel ensemble.

Enregistrez l'export avec le projet. Une palette qui ne vit que dans un onglet de navigateur disparaît quand l'onglet se ferme, tandis qu'un fichier enregistré est là quand le projet reprend.

Étape 5 : téléchargez la carte de palette

Cliquez sur Télécharger la palette en PNG pour générer une carte de palette : la photo originale avec la bande de nuances et les couleurs disposées en dessous. C'est le résumé visuel de l'extraction.

Partagez la carte avec un client ou une équipe. Une image de la palette communique plus vite qu'une liste de codes HEX, surtout pour les gens qui ne lisent pas le code.

Utilisez la carte dans les planches d'ambiance, les documents de marque et les présentations. Elle montre d'où viennent les couleurs, ce qui renforce la confiance, parce que le client peut voir la photo source.

Gardez la carte avec les fichiers du projet. Quand la palette sera remise en question des mois plus tard, la carte montre la source et le raisonnement en une seule image.

Extraire une palette depuis une photo

Les photos sont la meilleure source de palettes, parce que leurs couleurs fonctionnent déjà ensemble dans le monde réel. Un coucher de soleil, une scène de rue ou une photo de produit peut fournir tout un schéma.

Commencez par les plus grandes zones uniformes de la photo. Un ciel dégagé, un mur peint ou un vêtement donne une couleur stable que l'extracteur classe haut et de façon fiable.

Méfiez-vous de l'éclairage mélangé. Une photo avec une lumière chaude d'un côté et une ombre froide de l'autre peut produire deux versions de la même couleur, qui paraissent des doublons dans la palette.

Quand cela arrive, choisissez la version qui correspond à l'ambiance voulue. La version chaude convient à un design cosy, la version froide à un design net, et garder les deux brouille généralement la palette.

Extraire une palette depuis un logo

Les logos sont un cas de précision, parce qu'une palette de marque doit correspondre exactement. Commencez avec le fichier de logo de la meilleure qualité possible, idéalement un PNG sur fond plein.

Les fonds transparents sont gérés par l'extracteur, qui ignore les pixels entièrement transparents. Mais un logo sur fond transparent peut quand même produire des résultats étranges si les bords sont semi-transparents.

Pour le résultat le plus net, placez d'abord le logo sur un fond blanc ou de couleur de marque et extrayez à partir de cette version. La palette reflète alors les couleurs du logo, pas la gestion de la transparence.

Vérifiez ensuite les couleurs clés avec le sélecteur de couleurs d'image. Le sélecteur lit le pixel exact, ce qui confirme la couleur de marque quand la valeur de l'extracteur paraît légèrement décalée.

Extraire une palette depuis une capture d'écran

Les captures sont le moyen le plus rapide de capturer la palette d'un site web ou d'une application que vous admirez. Capturez l'écran, collez-le avec Ctrl+V, et la palette apparaît.

L'extracteur classe les couleurs de l'interface par couverture, donc le fond et les surfaces principales dominent, tandis que les couleurs des boutons et des liens apparaissent comme de petits accents.

Faites attention au texte. Une capture pleine de texte produit des nuances grises et noires venant des lettres, qui ne font pas partie de la palette de design et devraient être ignorées.

Rappelez-vous la question d'originalité. Une palette inspirée par un autre site est acceptable, mais copier en bloc la palette d'une marque concurrente est un mauvais choix pour le travail client.

Quand un petit accent disparaît

Un minuscule accent peut disparaître d'une palette parce que l'extracteur classe les couleurs par couverture. Une enseigne néon couvrant 1 pour cent d'une photo peut être repliée dans une couleur voisine.

Augmentez d'abord le nombre de nuances vers 12. Plus de nuances donnent aux petits détails leurs propres boîtes, donc l'accent a une meilleure chance d'apparaître.

S'il n'apparaît toujours pas, attrapez-le avec la pipette. Le sélecteur de couleurs d'image lit le pixel exact, et vous pouvez ajouter cette couleur à la palette extraite à la main.

Notez le pourcentage de l'accent quand vous l'ajoutez manuellement. Un accent à 1 pour cent est une couleur de point fort, pas une couleur principale, et l'utiliser pour de grandes surfaces submergera le design.

Corriger les teintes en double dans la palette

Deux nuances qui paraissent presque identiques viennent généralement d'un dégradé, comme un ciel qui passe graduellement du bleu clair au bleu plus sombre. L'algorithme divise le dégradé en deux boîtes.

Gardez la teinte qui convient le mieux à votre design et retirez l'autre. Une palette avec un seul bleu est plus nette qu'une palette avec deux bleus que personne ne peut distinguer.

Sinon, baissez le nombre de nuances. À 6 couleurs, le dégradé tombe généralement dans une seule boîte, et le doublon disparaît sans aucune modification manuelle.

Quand vous retirez un doublon, vérifiez les pourcentages. La couleur gardée devrait porter la part combinée dans votre design, parce que les deux teintes ensemble couvraient cette part de la photo.

Utiliser la palette dans Figma, Canva et le CSS

Dans Figma, collez chaque code HEX dans un style de couleur. Créez un style par nuance, nommé par son rôle, comme fond, primaire et accent, pour que l'équipe les utilise de façon cohérente.

Dans Canva, collez les codes HEX dans le kit de marque ou dans le sélecteur de couleurs de chaque élément. La palette reste alors disponible dans chaque design du compte.

En CSS, collez les propriétés personnalisées copiées dans votre feuille de style et référencez les variables partout. Une palette basée sur des variables est facile à mettre à jour, parce que changer une valeur met à jour tout le site.

Pour un système de design, stockez l'export JSON comme source de vérité. Un pipeline de jetons peut le lire et générer le CSS, les variables Figma et la documentation à partir du même fichier.

Changer le nombre sans renvoyer l'image

Vous pouvez changer le nombre de nuances à tout moment sans renvoyer l'image. Déplacez le curseur et la palette se reconstruit instantanément à partir des mêmes données d'image.

C'est utile pour comparer les nombres. Essayez 4, puis 6, puis 8, et regardez comment la palette gagne en détail puis commence à dupliquer les teintes. Le bon nombre est généralement juste avant l'apparition des doublons.

Copiez le CSS ou le JSON après chaque changement si vous voulez garder plusieurs versions. L'export reflète toujours le nombre actuel, donc une version appréciée peut être perdue si vous déplacez à nouveau le curseur.

Envoyer une nouvelle image efface automatiquement l'ancienne palette. Cela garde l'outil bien rangé, mais cela veut dire que vous devriez enregistrer toute palette à conserver avant de changer d'image.

Extraire une palette depuis des photos de produits

Les photos de produits sont un cas particulier, parce que la palette doit servir le produit, pas seulement la photo. Une photo de produit sur fond blanc donne une palette dominée par le blanc, ce qui vous dit peu de choses sur le produit lui-même.

Pour le travail sur les produits, extrayez plutôt depuis une photo lifestyle que depuis une photo studio. Un produit photographié en utilisation, dans une pièce ou en extérieur, porte les couleurs de son contexte, et ces couleurs font une meilleure palette.

Quand seule une photo studio existe, recadrez le produit étroitement avant l'extraction. Retirer le fond blanc force l'extracteur à classer les couleurs du produit au lieu de l'espace vide autour.

Vérifiez la palette par rapport aux couleurs du produit que vous connaissez. Si la couleur de marque du produit manque ou est décalée, vérifiez-la avec la pipette et ajoutez-la à la palette à la main.

Les palettes de produits alimentent les fiches, les emballages et la publicité, donc la cohérence compte plus que d'habitude. Enregistrez l'export CSS ou JSON avec les fichiers du produit, et utilisez la même palette sur chaque canal où le produit apparaît.

Pour une gamme de produits, extrayez une palette de chaque produit et comparez-les. Des produits qui partagent une famille de palettes ressemblent à une gamme, tandis que des produits avec des palettes sans rapport ressemblent à un assortiment aléatoire.

Les produits saisonniers méritent des palettes saisonnières. Une photo de produit d'été donne des couleurs vives et chaudes, tandis que la version hivernale du même produit donne des tons plus profonds, et la palette devrait changer avec la saison.

Enfin, testez la palette sur la fiche de la place de marché elle-même. Une palette qui paraît bonne dans un outil de design peut échouer contre le fond blanc et les couleurs d'interface de la place de marché, donc vérifiez-la en place avant le lancement.

Aide-mémoire rapide

Envoyez l'original le plus propre, réglez le nombre de nuances, lisez les pourcentages et la bande, puis copiez le CSS ou le JSON et téléchargez la carte de palette.

Élaguez les quasi-doublons, sauvez les accents manquants avec la pipette, et enregistrez l'export avec le projet avant de fermer l'onglet.

Questions fréquentes

Comment choisir les couleurs extraites à utiliser réellement ?

Commencez par la couleur au plus grand pourcentage comme dominante, prenez la deuxième plus grande comme secondaire, et utilisez les plus petites comme accents. Quatre à six couleurs suffisent pour la plupart des designs. Retirez les quasi-doublons et toute couleur qui ne convient pas à l’ambiance, même si elle est bien classée.

Puis-je extraire une palette depuis une image de vidéo ou une image de film ?

Oui. Faites une capture de l’image, collez-la dans l’extracteur, et la palette apparaît. Les images de films sont d’excellentes sources parce que les directeurs de la photographie conçoivent leurs schémas de couleurs avec soin. Utilisez la palette comme inspiration plutôt que de copier en bloc un style de film pour le travail client.

Pourquoi les pourcentages ne totalisent-ils pas 100 pour cent ?

Ils le font généralement, à l’arrondi près. Chaque pourcentage de nuance est arrondi à un nombre entier, donc les valeurs affichées peuvent totaliser 99 ou 101 pour cent. Les parts sous-jacentes sont exactes, et l’arrondi ne concerne que leur affichage.

Quelle est la différence entre la carte de palette et l’export CSS ?

La carte de palette est une image PNG montrant la photo avec ses nuances, faite pour partager avec des gens. L’export CSS est du texte avec les variables de couleur, fait pour coller dans du code. Utilisez la carte pour les clients et les présentations, et le CSS pour les développeurs.

Puis-je extraire une palette depuis une image en noir et blanc ?

Oui, mais le résultat sera des nuances de gris. Les pourcentages montrent quand même la structure tonale de la photo, ce qui est utile quand vous concevez en monochrome. Une palette grise tirée d’une photo forte peut être une base élégante pour un design minimal.

Comment partager une palette extraite avec un client qui n’utilise pas d’outils de design ?

Téléchargez la carte de palette en PNG et envoyez-la. La carte montre la photo source avec les nuances en dessous, donc tout le monde peut voir les couleurs et leur origine. Incluez aussi les codes HEX dans le message, pour que le client puisse s’y référer plus tard.
