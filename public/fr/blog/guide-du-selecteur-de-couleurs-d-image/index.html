Sélecteur de couleurs d’image

Tous les designers connaissent ce moment : une couleur apparaît à l'écran et il faut son code exact. Une capture, une photo, un logo ou une maquette peut contenir la teinte parfaite, mais la deviner ne marche jamais.

Un sélecteur de couleurs d'image règle le problème en quelques secondes. Vous ouvrez une image, vous pointez n'importe quel pixel, et vous lisez son code exact en HEX, RGB, HSL et CMYK.

Ce guide explique comment fonctionne le sélecteur de couleurs de CompressMyPic, ce que signifie chaque code couleur, et comment utiliser vos couleurs prélevées dans un vrai travail de design et de développement.

Qu'est-ce qu'un sélecteur de couleurs d'image ?

Un sélecteur de couleurs d'image est un outil en ligne qui lit la couleur de n'importe quel pixel d'une image que vous envoyez. Il fonctionne comme la pipette d'un logiciel de design, mais sans rien installer.

Vous déposez une photo ou une capture dans l'outil, vous déplacez le curseur sur l'image, et l'outil affiche la couleur qui se trouve exactement sous ce point. La valeur se met à jour en direct pendant que vous bougez.

L'outil accepte les formats d'image courants, comme JPG, PNG, WebP et GIF. Les fichiers jusqu'à 20 Mo sont pris en charge, ce qui couvre presque toutes les photos, tous les logos et toutes les captures que vous aurez à échantillonner.

Tout se passe en local, dans votre navigateur. Votre image n'est jamais envoyée sur un serveur, donc les maquettes des clients et les travaux de marque non publiés restent privés pendant que vous les échantillonnez.

Comment la pipette lit un pixel

Chaque image numérique est une grille de minuscules carrés appelés pixels. Chaque pixel contient une seule couleur, décrite par trois nombres qui correspondent à la lumière rouge, verte et bleue.

Quand vous cliquez sur un point de l'image, l'outil lit les valeurs rouge, verte et bleue de ce pixel précis. Il convertit ensuite ces trois nombres dans tous les formats de couleur dont vous pourriez avoir besoin.

La lecture est exacte, pas une estimation. Le pixel est vraiment de cette couleur, et le code que vous copiez la reproduira fidèlement dans un fichier de design, une feuille de style ou un document imprimé.

Un seul pixel peut pourtant réserver des surprises. Sur une photo, les pixels voisins diffèrent souvent légèrement, donc un pas de côté peut changer le dernier chiffre d'un code HEX.

Les codes couleur obtenus : HEX, RGB, HSL, CMYK

Chaque pixel prélevé produit plusieurs codes couleur à la fois. Le HEX est le code à six chiffres que les développeurs web utilisent en CSS, comme #2563EB pour un bleu bien affirmé.

Le RGB décrit la même couleur avec trois nombres de 0 à 255, un pour le rouge, un pour le vert et un pour le bleu. C'est le format que la plupart des outils de design et des éditeurs d'images comprennent nativement.

Le HSL décrit la couleur par sa teinte, sa saturation et sa luminosité. Les designers l'apprécient parce qu'il correspond à notre façon de penser la couleur : on choisit une teinte, puis on la rend plus riche ou plus claire.

Le CMYK décrit la couleur en pourcentages d'encre pour l'impression. Ce n'est qu'une approximation à l'écran, puisque les écrans utilisent la lumière et les imprimantes l'encre, mais c'est un bon point de départ pour le travail imprimé.

La loupe 11x11 : pourquoi le grossissement compte

Choisir le bon pixel est difficile au zoom normal. Une ligne fine, une petite icône ou un bord d'un pixel se rate facilement d'un cheveu, et un raté donne la mauvaise couleur.

L'outil résout ce problème avec une loupe grossissante de 11 par 11. Elle montre une vue agrandie des pixels autour de votre curseur, pour que vous voyiez exactement quel pixel vous allez échantillonner.

La loupe est particulièrement utile pour les captures d'interface. Les boutons, les séparateurs et le texte se trouvent souvent sur des bords adoucis, où la couleur se mélange sur deux ou trois pixels.

Avec le grossissement, vous pouvez viser le centre plein d'une forme plutôt que son bord mélangé. Ce simple choix fait souvent la différence entre la vraie couleur de la marque et une teinte intermédiaire brouillée.

Nuances prélevées : constituer une collection

Une seule couleur suffit rarement. Une palette de marque, un thème de site web ou une présentation a besoin de plusieurs couleurs qui fonctionnent ensemble, et l'outil vous permet de les réunir une par une.

Chaque clic ajoute la couleur échantillonnée à votre palette de nuances prélevées. Vous pouvez réunir la couleur principale, l'accent, le fond et la couleur du texte à partir de la même image.

Les nuances restent visibles pendant que vous travaillez, pour que vous puissiez les comparer côte à côte. Si deux prélèvements se ressemblent trop, vous pouvez en retirer un et garder la version la plus nette.

Cliquer deux fois sur la même valeur HEX ne crée pas de doublon. L'outil garde votre collection bien rangée, ce qui compte quand vous échantillonnez une photo pleine de teintes presque identiques.

Exporter le CSS : de l'image à la feuille de style

Les nuances réunies ne servent à quelque chose que si vous pouvez les emporter dans votre projet. Le bouton Exporter le CSS télécharge vos couleurs prélevées sous forme de propriétés personnalisées CSS, prêtes à l'emploi.

Le téléchargement vous donne des variables comme --color-1, --color-2, et ainsi de suite, chacune avec une valeur HEX. Vous pouvez les coller dans une feuille de style et les utiliser partout dans votre design.

C'est bien mieux que de copier les codes un par un dans un fichier texte. L'export regroupe toutes les couleurs au même endroit, dans le bon ordre, sans erreur de recopie.

Pour un travail de palette plus complet, l'extracteur de palette de couleurs d'image construit automatiquement une palette classée. Utilisez le sélecteur quand vous voulez des pixels exacts, et l'extracteur quand vous voulez les couleurs dominantes d'une photo entière.

Prélever des couleurs sur des photos

Les photos sont la source la plus courante de couleurs prélevées. Un coucher de soleil, une photo de produit ou une photo de voyage peut fournir une palette entière dont les couleurs s'accordent déjà naturellement.

Commencez par les grandes zones uniformes de la photo. Un ciel dégagé, un mur peint ou un vêtement donne une couleur stable, qui résiste bien mieux à l'échantillonnage qu'une texture chargée.

Évitez les reflets les plus lumineux et les ombres les plus profondes. Ces zones sont souvent écrêtées, ce qui veut dire que la vraie information de couleur est perdue, et que le code obtenu n'est que du blanc ou du noir.

Échantillonnez la même zone plusieurs fois et comparez les résultats. Si les codes se regroupent autour d'une valeur, c'est la vraie couleur de la surface. S'ils s'éparpillent, prenez le milieu du groupe.

Prélever des couleurs sur des logos et des captures d'écran

Les logos et les captures d'interface sont le cas où la précision compte. Une couleur de marque doit correspondre exactement, parce qu'une teinte proche paraît fausse à côté du vrai logo.

Pour les logos, échantillonnez le milieu d'une grande forme uniforme. Le centre d'une lettre ou d'un bloc est plein, tandis que les bords se fondent dans le fond et donnent des valeurs mélangées.

Pour les captures, collez directement avec Ctrl+V quand c'est possible. L'outil accepte les images du presse-papiers, donc vous pouvez capturer l'écran et l'échantillonner sans enregistrer de fichier d'abord.

Quand vous échantillonnez une capture, regardez les coordonnées de pixel affichées dans l'inspecteur de pixels. Elles vous aident à revenir exactement au même endroit si vous devez vérifier une valeur plus tard.

Précision des couleurs : bruit JPEG et transparence

La compression JPEG modifie légèrement la couleur des pixels. Ce format stocke les couleurs par petits blocs, donc deux pixels voisins dans un ciel uniforme peuvent différer d'un chiffre ou deux.

Cette variation est normale et sans conséquence pour la plupart des travaux. Prenez la valeur qui apparaît le plus souvent dans la zone, et votre résultat paraîtra juste à l'œil.

Les fichiers PNG se comportent différemment. Un PNG stocke les couleurs exactes, donc le code que vous lisez est celui que le fichier contient, sans aucun bruit de compression.

Les zones transparentes demandent de l'attention. Échantillonner une partie transparente d'un logo PNG lit la couleur située sous la transparence, qui peut être du blanc ou du noir plutôt que la couleur attendue.

Prélever des couleurs sur mobile et sur écran tactile

Le sélecteur de couleurs fonctionne aussi sur téléphone et tablette, comme sur ordinateur. Vous touchez l'image au lieu de cliquer, et les mêmes fonctions de loupe et de nuances s'appliquent.

Le toucher est moins précis qu'une souris, parce qu'un doigt couvre beaucoup de pixels à la fois. La loupe grossissante compte encore plus ici, puisqu'elle montre ce qui se trouve sous votre doigt.

Zoomez sur l'image dans votre navigateur avant de toucher si la cible est petite. Une image plus grande donne à votre doigt une cible plus large et réduit le risque d'échantillonner un pixel voisin.

Pour les couleurs de marque critiques, vérifiez le prélèvement plus tard sur un ordinateur. Un toucher sur téléphone donne une bonne approximation, mais un clic de souris sur le pixel exact est la vérification finale fiable.

Erreurs courantes quand on prélève des couleurs

L'erreur la plus fréquente est d'échantillonner un bord au lieu d'une zone uniforme. Les bords adoucis mélangent deux couleurs, et la valeur mélangée n'appartient à aucune des deux.

Une autre erreur est de se fier à un seul clic sur une photo bruitée. Un pixel d'une image granuleuse peut être un cas isolé, donc échantillonnez toujours le même endroit deux ou trois fois.

On oublie aussi que les écrans diffèrent. Le même code HEX peut paraître légèrement différent sur deux moniteurs, donc jugez une couleur à son code, et pas seulement à son apparence sur votre écran.

Enfin, n'échantillonnez pas une capture d'une capture. Chaque capture et chaque nouvel enregistrement peut décaler légèrement les couleurs, donc travaillez toujours à partir du fichier original le plus propre possible.

Sélecteur de couleurs ou extracteur de palette

Le sélecteur de couleurs et l'extracteur de palette répondent à des questions différentes. Le sélecteur donne la couleur exacte d'un pixel que vous choisissez, tandis que l'extracteur trouve les couleurs dominantes de toute l'image.

Utilisez le sélecteur quand vous savez ce que vous voulez : le bleu exact d'un logo, la teinte exacte d'un bouton, ou le ton exact d'un mur sur une photo.

Utilisez l'extracteur quand vous cherchez des idées : les cinq ou six couleurs qui définissent une photo, classées selon la surface qu'elles couvrent. C'est le chemin le plus rapide vers une palette complète.

Beaucoup de designers utilisent les deux. Ils extraient une palette pour le schéma général, puis utilisent le sélecteur pour attraper une couleur d'accent précise que l'extracteur avait classée trop bas pour l'inclure.

Qui utilise un sélecteur de couleurs d'image ?

Les développeurs web l'utilisent pour correspondre exactement à une maquette de design. Quand un client envoie une capture au lieu d'un fichier de design, le sélecteur retrouve les vrais codes HEX.

Les graphistes l'utilisent pour construire des palettes à partir de photos de référence. Une photo d'ambiance peut fournir tout le schéma de couleurs d'une affiche ou d'une identité de marque.

Les designers print utilisent la lecture CMYK comme point de départ. Ce n'est pas une correspondance parfaite pour l'impression, mais elle leur dit si une couleur vive à l'écran survivra sur papier.

Les créateurs de contenu l'utilisent pour les miniatures et les visuels des réseaux sociaux. Accorder un accent de miniature à une couleur de marque garde une chaîne cohérente sur des dizaines de vidéos.

Confidentialité : vos images restent dans votre navigateur

La confidentialité compte quand l'image est une maquette de client, une photo de produit non publiée ou une photo personnelle. Envoyer de tels fichiers sur un serveur au hasard est un risque inutile.

Cet outil traite tout en local. L'image est lue par votre navigateur, les pixels sont échantillonnés sur votre appareil, et rien ne quitte votre ordinateur.

Cela veut aussi dire que l'outil fonctionne hors ligne une fois la page chargée. Vous pouvez échantillonner des couleurs dans un avion, en salle de réunion, ou partout sans connexion.

Si vous manipulez des ressources de marque sensibles, le traitement local est la fonction décisive. Aucun envoi ne veut dire aucune copie du fichier sur un serveur que vous ne contrôlez pas.

Échantillonner des couleurs sur des dégradés et des motifs

Les dégradés sont un cas particulier, parce que la couleur change en douceur d'un bout à l'autre. Il n'y a pas une seule couleur juste dans un dégradé, seulement la couleur du point exact que vous échantillonnez.

Pour capturer un dégradé, échantillonnez plusieurs points sur sa longueur. Prenez la couleur de début, celle du milieu et celle de fin, et vous pourrez reconstruire le dégradé en CSS avec ces trois étapes.

Les motifs demandent le même soin. Une surface rayée ou à carreaux contient au moins deux couleurs, et le sélecteur ne lit que le pixel sous votre curseur, pas le motif dans son ensemble.

Pour un motif, échantillonnez chaque bande distincte séparément et enregistrez-les toutes comme nuances. L'ensemble des nuances décrit alors le motif, même si aucun clic ne pouvait le faire à lui seul.

Les surfaces texturées comme le bois, le tissu ou la pierre sont le cas le plus difficile. Leur couleur varie d'un pixel à l'autre, donc une seule lecture n'a presque aucun sens.

Avec les textures, échantillonnez cinq ou six pixels proches et cherchez la moyenne. La valeur la plus fréquente dans le groupe est le meilleur représentant unique de cette surface, et elle paraîtra juste dans votre design.

Comment utiliser le sélecteur de couleurs d'image

Ouvrez le sélecteur de couleurs d'image dans votre navigateur. Glissez votre image dans la zone d'envoi, ou collez une capture directement depuis le presse-papiers.

Une couleur par défaut apparaît dès que l'image se charge, échantillonnée au centre de la photo. Déplacez votre curseur pour explorer, et regardez la loupe zoomer sur les pixels sous votre pointeur.

Cliquez sur n'importe quel pixel pour l'ajouter à vos nuances prélevées. Continuez à cliquer pour réunir toutes les couleurs dont votre design a besoin.

Quand votre collection est complète, cliquez sur Exporter le CSS pour télécharger les couleurs sous forme de variables de feuille de style. Ensuite, lisez la version pas à pas dans Comment choisir une couleur sur une image, ou découvrez les formats de code dans HEX, RGB et HSL : les codes couleur expliqués.

Questions fréquentes

Quelle est la différence entre prélever une couleur et extraire une palette ?

Prélever, c’est lire un pixel exact que vous choisissez, donc vous contrôlez précisément la couleur obtenue. Extraire, c’est analyser toute l’image et classer automatiquement ses couleurs les plus fréquentes. Utilisez le sélecteur pour les couleurs de marque exactes, et l’extracteur quand vous voulez une palette prête à l’emploi à partir d’une photo.

Pourquoi deux clics sur la même zone donnent-ils des codes HEX légèrement différents ?

Sur les photos, les pixels voisins sont rarement identiques à cause du bruit du capteur et de la compression JPEG. Chaque pixel a sa propre couleur, donc un déplacement d’un pixel peut changer le dernier chiffre. Échantillonnez le milieu d’une zone uniforme et prenez la valeur qui apparaît le plus souvent.

Puis-je utiliser les couleurs prélevées directement dans une feuille de style de site web ?

Oui. Le bouton Exporter le CSS télécharge vos nuances sous forme de propriétés personnalisées CSS avec des valeurs HEX. Collez-les dans votre feuille de style et utilisez les variables partout où cette couleur est nécessaire. Les codes HEX fonctionnent aussi dans n’importe quel outil de design qui accepte les valeurs de couleur collées.

Le sélecteur de couleurs modifie-t-il ou compresse-t-il mon image ?

Non. L’outil lit seulement les valeurs des pixels et ne modifie, n’enregistre ni ne compresse jamais votre fichier. Votre image originale reste intacte, et vous pouvez fermer la page en sachant que le fichier sur votre appareil est exactement comme avant.

Comment prélever une couleur sur un site web dont je ne peux pas télécharger d’image ?

Faites une capture d’écran de la page, puis collez-la dans l’outil avec Ctrl+V ou envoyez le fichier de capture. Le sélecteur lit les pixels de la capture comme ceux de n’importe quelle autre image, donc vous pouvez échantillonner les boutons, les fonds et les couleurs de texte de n’importe quel site.

Que faire si la couleur prélevée paraît différente dans mon outil de design ?

Vérifiez d’abord que vous avez copié le code HEX complet, sans oublier un chiffre. Ensuite, rappelez-vous que les moniteurs et les profils de couleur varient, donc le même code peut paraître légèrement différent sur deux écrans. Fiez-vous au code lui-même, et comparez-le à l’image originale sur le même écran.
