Comment utiliser Optimiseur d'images pour le web

Suivez ces étapes simples pour accomplir votre tâche, directement dans votre navigateur.

1

Sélectionnez l'un des 5 préréglages de performance web

Choisissez Hero / Bannière (1 600 px WebP 80 %), Produit e-commerce (1 200 px WebP 82 %), Carte / Miniature (640 px WebP 75 %), OG social / E-mail (1 200 px JPG 82 %) ou Graphique Retina 2× (1 920 px WebP 88 %).

2

Personnalisez le format web, la dimension maximale ou la qualité

Basculez entre WebP, JPG ou PNG, ajustez la dimension maximale (bord long) de 640 px à 1 920 px (ou Conserver les dimensions d'origine) et affinez la qualité de 20 % à 95 %.

3

Déposez les ressources web brutes dans la zone de dépôt

Téléversez des images JPG, PNG, WebP, HEIC, SVG, BMP, GIF ou AVIF jusqu'à 25 Mo chacune, avec l'option Réduire uniquement les images plus grandes cochée pour éviter de gonfler les petites icônes.

4

Vérifiez le gain de poids de page et comparez la qualité

Consultez le résumé des performances web pour voir le poids total de page économisé, vérifiez les badges Prêt pour le web par carte et inspectez les bords côte à côte via Comparer.

5

Copiez des extraits HTML <img> responsifs

Cliquez sur Copier <img> sur n'importe quelle carte terminée pour obtenir le balisage prêt à coller, avec largeur, hauteur, loading="lazy" et decoding="async".

6

Téléchargez des ressources -web individuelles ou le paquet ZIP

Enregistrez des fichiers individuels <nom>-web ou cliquez sur Télécharger tout (ZIP) pour télécharger web_optimized_compressmypic.zip proprement.

Pourquoi utiliser Optimiseur d'images pour le web de CompressMyPic ?

Préréglages prêts pour le web

Limites de dimension préconfigurées et points idéaux de qualité WebP/JPG pensés pour le LCP et PageSpeed Insights.

Extrait HTML <img> copiable

Génère des attributs responsifs de largeur, hauteur, loading="lazy" et decoding="async" pour éviter le décalage de mise en page (CLS).

Suppression automatique des EXIF et protection contre l'agrandissement

Supprime les métadonnées gonflées de l'appareil photo et évite d'agrandir inutilement les icônes plus petites.

Inspecteur interactif avant/après

Vérifiez la clarté visuelle côte à côte avant de déployer les ressources en production.
