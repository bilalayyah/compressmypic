Cara Melihat Metadata Gambar

Panduan langkah demi langkah melihat metadata gambar: buka foto di penampil, baca kolom EXIF dan GPS, ekspor laporan JSON, dan verifikasi file yang sudah dibersihkan.

Melihat metadata gambar terdengar teknis, tetapi sebenarnya kurang dari satu menit. Anda membuka foto di penampil, membaca laporannya, lalu memutuskan apakah ada isinya yang harus tetap privat.

Panduan ini memandu Anda langkah demi langkah dengan Penampil Metadata Gambar yang gratis. Alat ini berjalan di browser, tanpa akun, dan tidak pernah mengunggah foto Anda.

Di akhir panduan, Anda akan tahu cara menemukan koordinat GPS, membaca pengaturan kamera, mengekspor laporan JSON, dan memeriksa bahwa file yang sudah dibersihkan benar-benar bersih.

Yang Perlu Disiapkan Sebelum Memulai

Anda membutuhkan file gambar itu sendiri, yang tersimpan di perangkat Anda. File asli dari galeri kamera atau kartu memori kamera membawa metadata paling lengkap.

Foto yang diunduh dari WhatsApp, Instagram, atau Facebook bukan bahan uji yang bagus. Layanan-layanan itu menghapus header EXIF dan GPS saat diunggah, sehingga penampil hanya menemukan sedikit atau tidak menemukan apa-apa.

Tangkapan layar juga bukan bahan uji yang bagus. Papan klip sistem operasi hanya meneruskan piksel mentah, bukan file kamera asli, sehingga tangkapan layar yang ditempel hanya menampilkan dimensi dan format.

Gunakan file JPG, PNG, WebP, HEIC, GIF, BMP, atau SVG hingga 20 MB. Ukuran itu sudah mencakup foto ponsel resolusi penuh, JPEG DSLR, dan ekspor PNG yang detail.

Buka penampil di browser modern apa pun. Chrome, Firefox, Safari, dan Edge semuanya berfungsi, baik di desktop maupun di ponsel.

Langkah 1: Buka Penampil

Buka halaman Penampil Metadata Gambar. Anda akan melihat zona unggah dan penjelasan singkat tentang fungsi alat ini.

Tidak ada layar masuk dan tidak ada dinding berbayar. Alat ini gratis, dan Anda bisa memeriksa foto sebanyak yang Anda mau, satu per satu.

Jika Anda memakai ponsel, buka halaman di Safari atau Chrome seluler. Tata letaknya menyesuaikan, dan Anda bisa memilih foto langsung dari galeri.

Simpan halaman ini sebagai markah jika Anda sering memeriksa foto. Fotografer, penjual, dan orang tua cenderung menggunakannya sebelum setiap unggahan publik, jadi akses cepat sangat membantu.

Langkah 2: Unggah Gambar Anda

Seret gambar ke zona unggah, atau klik zona itu untuk memilih file dari perangkat Anda. File langsung di-parsing di browser Anda.

Anda juga bisa menempel gambar dengan Ctrl+V di Windows atau Cmd+V di Mac. Menempel praktis untuk foto yang sudah ada di papan klip, tetapi ingat bahwa gambar dari papan klip tidak membawa header kamera.

Parsing terjadi secara lokal dengan membaca byte File ArrayBuffer. Nol byte meninggalkan komputer atau ponsel Anda, dan memang itulah inti dari alat privasi.

Jika file lebih besar dari 20 MB, unggahan tidak akan berhasil. Kompres dulu dengan alat kompres gambar, lalu periksa salinan yang lebih kecil.

Dalam sekejap bilah ringkasan muncul. Itulah hasil pertama Anda, dan bilah itu langsung menjawab pertanyaan terpenting: apakah file ini membawa data sensitif?

Langkah 3: Baca Ringkasan dan Spanduk Privasi

Bilah ringkasan menampilkan format wadah yang terdeteksi, dimensi piksel, dan ukuran file. Bilah itu juga menyatakan apakah ada jenis tag metadata sensitif yang tertanam.

Baca formatnya dulu. Penampil memeriksa magic bytes biner yang sebenarnya, bukan mempercayai nama file, sehingga PNG yang diganti namanya menjadi .jpg tetap dilaporkan sebagai PNG.

Selanjutnya, baca spanduk risiko privasi. Jika ada tag sensitif, spanduk menyatakannya dengan jelas. Jika tidak ada yang sensitif, spanduk menyatakan itu juga.

Ringkasan yang bersih tidak selalu berarti file itu asli. Foto yang sudah dihapus metadatanya oleh aplikasi pesan juga menampilkan ringkasan bersih, karena metadatanya sudah dihapus di hulu.

Bandingkan ringkasan dengan yang Anda harapkan. JPEG DSLR seharusnya menampilkan data kamera. Tangkapan layar seharusnya hampir tidak menampilkan apa-apa. Ketidakcocokan menandakan file pernah diproses di tengah jalan.

Langkah 4: Periksa Peringatan Lokasi GPS

Koordinat GPS adalah hal pertama yang harus diperiksa, karena itu kolom paling sensitif yang dapat dibawa sebuah foto. Gulir ke area peringatan tepat di atas tabel properti.

Jika ada tag GPSIFD, spanduk kuning bertuliskan “GPS Location Coordinates Detected” akan muncul. Spanduk itu menampilkan garis lintang dan garis bujur yang sudah diterjemahkan ke bentuk desimal.

Dua angka itu dapat menunjuk ke rumah, sekolah, tempat kerja, atau titik persis tempat foto diambil. Perlakukan keduanya sebagai data privat sampai Anda memutuskan sebaliknya.

Kotak peringatan juga menyediakan jalan pintas sekali klik ke Hapus Metadata Gambar. Jika Anda berencana membagikan foto itu, ikuti tautan tersebut dan hapus tagnya dulu.

Jika tidak ada peringatan GPS yang muncul, foto tidak membawa data lokasi. Itulah hasil yang Anda inginkan sebelum mengunggah apa pun yang diambil di rumah atau di dekat anak-anak Anda.

Langkah 5: Baca Tabel Metadata

Di bawah spanduk ada tabel metadata hasil ekstraksi. Entri dikelompokkan supaya Anda bisa memindainya tanpa membaca setiap baris.

Kelompok Kamera berisi merek, model, lensa, dan perangkat lunak. Kelompok EXIF berisi kecepatan rana, bukaan, ISO, panjang fokus, lampu kilat, dan mode pengukuran.

Kelompok GPS berisi garis lintang, garis bujur, dan ketinggian jika ada. Kelompok chunk PNG atau WebP berisi IHDR, pHYs, chunk teks, dan penanda VP8X.

Kelompok Info file berisi format wadah, dimensi, dan ukuran. Ini fakta tentang file itu sendiri, bukan tentang kamera.

Entri sensitif ditandai label kuning “Privacy Tag”. Cari koordinat GPS, stempel waktu pengambilan yang persis, nama fotografer atau seniman, nomor seri kamera, dan nama model perangkat.

Luangkan waktu untuk membaca stempel waktu. Tanggal dan waktu persis foto diambil dapat mengungkap rutinitas, misalnya kapan rumah kosong atau kapan anak pulang sekolah.

Langkah 6: Salin atau Ekspor Laporan JSON

Jika Anda butuh catatan tentang isi file, ekspor laporannya. Klik Copy JSON di bilah ringkasan untuk menyalin seluruh laporan terstruktur ke papan klip.

Klik Export JSON untuk mengunduh file yang namanya mengikuti nama gambar Anda dengan akhiran _metadata. File ini berupa laporan JSON yang rapi, bisa disimpan, dilampirkan ke tiket bantuan, atau dibandingkan nanti.

Pengembang memakai laporan ini untuk men-debug alur kerja gambar. Jika sebuah kolom hilang di antara dua tahap pemrosesan, laporan JSON menunjukkan persis di mana kolom itu hilang.

Fotografer memakainya untuk menyimpan resep pencahayaan. JSON mempertahankan ISO, bukaan, dan kecepatan rana dari foto yang layak diulang.

Untuk penjelasan lebih dalam tentang arti setiap kolom, baca Data EXIF: Apa yang Foto Anda Ungkapkan. Untuk gambaran lengkap alatnya, baca Panduan Lengkap Melihat Metadata Gambar.

Langkah 7: Verifikasi File yang Sudah Dibersihkan

Setelah menghapus metadata dari foto, masukkan kembali hasil bersihnya ke penampil. Pemeriksaan kedua ini membuktikan pembersihan berhasil.

Jika pembersihan berhasil, spanduk hijau memastikan tidak ada tag EXIF, GPS, atau kamera tersembunyi yang terdeteksi. Tidak ada peringatan GPS yang muncul.

Jika masih ada tag, tabel menunjukkan persis tag mana yang bertahan. Sisa yang umum adalah chunk teks PNG dan komentar JPEG, yang sering terlewat oleh alat pembersih.

Saat ada sisa, bersihkan file lagi dengan Full Canvas Re-encode di alat Hapus Metadata Gambar. Opsi ini membangun ulang piksel dari nol dan membuang semua segmen warisan.

Jadikan ini kebiasaan dua langkah untuk foto sensitif. Periksa, bersihkan, periksa lagi. Pemeriksaan kedua hanya butuh beberapa detik dan menghilangkan semua keraguan.

Melihat Metadata di Ponsel

Kebanyakan foto tersimpan di ponsel, dan pemeriksaan paling penting dilakukan tepat sebelum mengunggah. Buka penampil di Safari atau Chrome seluler dan pilih foto dari galeri Anda.

Ringkasan, peringatan GPS, dan tabel berkelompok semuanya tampil sama seperti di desktop. Copy JSON dan Strip Metadata juga bekerja dengan cara yang sama.

Periksa foto sebelum Anda membuka aplikasi sosial, bukan sesudahnya. Begitu foto diunggah, siapa pun bisa mengunduhnya dan membaca apa pun yang masih tersimpan di dalamnya.

Jika Anda menemukan data GPS, hapus di ponsel sebelum dibagikan. Alat Hapus Metadata Gambar berjalan di browser seluler, sehingga seluruh alur kerja muat di saku Anda.

Cara Membaca Pengaturan Kamera di Laporan

Pengaturan kamera menceritakan bagaimana sebuah foto dibuat. Setiap kolom punya arti yang jelas begitu Anda tahu yang harus dicari.

ISO adalah sensitivitas sensor. ISO rendah berarti suasana terang atau memakai tripod; ISO tinggi berarti suasana gelap dan biasanya lebih banyak noise.

Bukaan, yang ditampilkan sebagai angka F, adalah seberapa lebar lensa terbuka. Angka F kecil berarti bukaan lebar dan latar belakang buram; angka besar berarti suasana tajam sampai ke belakang.

Kecepatan rana adalah lamanya sensor terpapar cahaya. Kecepatan tinggi membekukan gerakan, kecepatan lambat mengaburkannya. Penampil menampilkannya sebagai pecahan detik atau detik utuh.

Panjang fokus adalah zoom lensa saat foto diambil. Panjang pendek berarti pandangan lebar; panjang jauh berarti pandangan yang diperbesar.

Status lampu kilat memberi tahu apakah kilat menyala. Mode pengukuran memberi tahu cara kamera mengukur cahaya. Bersama-sama, kolom-kolom ini memungkinkan fotografer lain menciptakan ulang foto tersebut.

Mengatasi Masalah: Saat Laporan Terlihat Kosong

Laporan yang kosong biasanya punya penyebab sederhana. Telusuri daftar di bawah ini sebelum menganggap penampil rusak.

  • Foto berasal dari WhatsApp, Instagram, atau Facebook. Layanan ini menghapus EXIF dan GPS saat diunggah, sehingga file tiba dalam keadaan bersih.
  • Anda menempel tangkapan layar. Papan klip hanya meneruskan piksel mentah, sehingga gambar yang ditempel sama sekali tidak membawa header kamera.
  • File berupa HEIC, GIF, BMP, atau SVG. Penampil melaporkan info wadah dan dimensi untuk format ini, tetapi chunk EXIF biner lengkap hanya diekstrak untuk JPEG, PNG, dan WebP.
  • Foto diedit lalu diekspor ulang. Banyak editor menghapus EXIF saat mengekspor, kecuali Anda memintanya untuk mempertahankannya.
  • File sudah dibersihkan sebelumnya. Foto yang dihapus metadatanya dengan alat Hapus Metadata Gambar akan menampilkan spanduk hijau tanpa tag, dan itu hasil yang benar.

Jika Anda mengharapkan data kamera tetapi tidak mendapatkannya, uji dengan file asli yang baru diambil dari galeri. Cara ini memberi tahu apakah penyebabnya ada pada file atau pada penampil.

Jika file asli juga tidak menampilkan apa-apa, periksa pengaturan aplikasi kamera Anda. Sebagian ponsel memungkinkan Anda mematikan perekaman lokasi, sehingga tag GPS tidak ditulis sejak awal.

Kesalahan Umum yang Harus Dihindari

Kesalahan paling umum adalah memeriksa file yang salah. Orang memeriksa salinan yang sudah diunggah, melihat tidak ada apa-apa, lalu menganggap file aslinya juga bersih. Selalu periksa file yang akan Anda bagikan.

Kesalahan lain adalah mempercayai nama file. File .jpg bisa jadi sebenarnya PNG, dan penampil melaporkan format sebenarnya dari magic bytes. Baca ringkasannya, bukan ekstensinya.

Kesalahan ketiga adalah melewatkan pemeriksaan kedua. Menghapus terasa selesai begitu hasil unduhan muncul, tetapi hanya pemeriksaan ulang yang membuktikan tag benar-benar hilang.

Kesalahan keempat adalah melupakan stempel waktu. Orang mencari GPS dan mengabaikan waktu pengambilan, padahal stempel waktu yang persis dapat mengungkap rutinitas sama jelasnya seperti lokasi.

Terakhir, jangan menganggap laporan yang bersih berarti foto aman. Gambar itu sendiri masih bisa menampilkan nomor rumah, seragam sekolah, atau pelat nomor kendaraan. Metadata hanyalah separuh dari pemeriksaan privasi.

Membandingkan Dua Foto Berdampingan

Terkadang satu laporan tidak cukup. Membandingkan dua foto menunjukkan apa yang berubah di antara keduanya, dan ini berguna saat sebuah file melewati beberapa aplikasi.

Buka foto pertama, ekspor laporan JSON-nya, dan simpan filenya. Lalu kosongkan penampil dengan ikon tempat sampah merah dan buka foto kedua dengan cara yang sama.

Letakkan kedua laporan JSON berdampingan. Kolom yang ada di satu laporan dan hilang di laporan lain berarti ditambahkan atau dihapus oleh pemrosesan di antaranya.

Perbandingan inilah cara pengembang menemukan tahap mana dalam alur kerja yang menghilangkan sebuah kolom. Cara ini juga dipakai fotografer untuk mengetahui editor mana yang mempertahankan data kamera dan mana yang membuangnya.

Uji yang umum adalah membandingkan foto asli dengan salinan dari media sosial. Foto asli menampilkan EXIF dan GPS lengkap, sedangkan salinan dari media sosial hampir tidak menampilkan apa-apa. Selisih itu membuktikan platform menghapus data tersebut.

Uji lain yang berguna adalah membandingkan foto asli dengan salinan yang sudah dibersihkan. Salinan bersih seharusnya menampilkan spanduk hijau tanpa tag, sedangkan foto asli menampilkan tabel lengkap. Kontras itulah bukti bahwa pembersihan berhasil.

Menyimpan Laporan untuk Nanti

Laporan JSON hasil ekspor layak disimpan saat fotonya penting. Laporan adalah file teks kecil, mudah disimpan berdampingan dengan gambar atau di folder proyek.

Simpan laporan untuk pekerjaan klien, saat klien mungkin bertanya kapan dan di mana foto diambil. JSON menjawab pertanyaan itu tanpa harus membagikan file asli.

Simpan juga untuk keperluan debug. Saat sebuah gambar berperilaku aneh berbulan-bulan kemudian, laporan yang tersimpan menunjukkan isi file sebelum pemrosesan lebih lanjut.

Beri nama laporan yang jelas, misalnya wedding-photo-metadata.json, supaya mudah ditemukan nanti. Nama bawaan sudah memuat nama file gambar dengan akhiran _metadata, dan itu sudah menjadi awal yang baik.

Ringkasan Cepat

Buka Penampil Metadata Gambar, masukkan file asli, dan baca spanduk ringkasan dulu. Lalu periksa peringatan GPS, pindai tabel berkelompok, dan catat label kuning “Privacy Tag” apa pun.

Ekspor JSON jika Anda butuh catatan. Bersihkan file dengan Hapus Metadata Gambar jika ada yang sensitif, lalu periksa kembali salinan bersihnya untuk memastikan.

Seluruh rutinitas ini kurang dari satu menit. Jadikan kebiasaan sebelum setiap unggahan publik, dan foto Anda hanya akan menampilkan apa yang Anda pilih untuk dibagikan.

Pertanyaan umum

Bagaimana cara melihat metadata foto yang sudah saya unggah ke internet?

Unduh dulu foto yang sudah diunggah itu, lalu masukkan file unduhannya ke penampil. Kebanyakan platform sosial menghapus metadata saat diunggah, sehingga salinan yang diunduh biasanya tidak menampilkan apa-apa — tetapi jika platform menyimpan tagnya, penampil akan menemukannya. Perlu diingat, proses mengunduh dari platform itu sendiri bisa menghapus data, jadi yang Anda periksa adalah salinan publiknya, bukan file asli Anda.

Bisakah saya melihat metadata tanpa memasang perangkat lunak apa pun?

Ya. Penampil Metadata Gambar berjalan sepenuhnya di browser Anda — tanpa instalasi, tanpa akun, dan tanpa unggahan. Masukkan filenya, baca laporannya, lalu tutup tab. Foto Anda tidak pernah meninggalkan perangkat Anda.

Apa yang harus saya lakukan jika penampil menemukan koordinat GPS di foto saya?

Jangan bagikan file itu apa adanya. Buka alat Hapus Metadata Gambar, masukkan fotonya, dan unduh salinan bersihnya. Lalu masukkan kembali salinan bersih itu ke penampil untuk memastikan peringatan GPS sudah hilang sebelum Anda mengunggahnya.

Mengapa penampil menampilkan kolom berbeda untuk foto yang sama dalam format berbeda?

Setiap format menyimpan metadata dengan cara berbeda. JPEG menyimpan direktori EXIF, PNG menyimpan chunk teks dan eXIf, dan WebP menyimpan chunk EXIF plus penanda VP8X. Mengonversi foto antarformat dapat menghilangkan kolom, sehingga foto yang sama dalam JPG dan PNG akan menampilkan tabel yang berbeda.

Bisakah saya melihat metadata banyak foto sekaligus?

Penampil memeriksa satu file dalam satu waktu. Untuk memeriksa banyak file, periksa satu per satu — klik ikon tempat sampah merah di bilah ringkasan untuk mengatur ulang, lalu masukkan foto berikutnya. Setiap pemeriksaan hanya butuh beberapa detik, jadi memeriksa sejumlah kecil foto berlangsung cepat.

Apakah melihat metadata mengubah foto saya dengan cara apa pun?

Tidak. Penampil ini sepenuhnya hanya-baca. Alat ini membaca header dari memori browser dan menampilkannya, tanpa memodifikasi, mengompres, atau menghapus apa pun dari file asli Anda. File Anda di perangkat tetap persis seperti semula.
