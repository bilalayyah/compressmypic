Cara Menghapus Metadata dari Gambar

Panduan langkah demi langkah menghapus metadata dari gambar: unggah, hapus EXIF dan GPS, pilih metode yang tepat, unduh file bersih, dan verifikasi hasilnya.

Menghapus metadata dari gambar kurang dari satu menit. Anda mengunggah foto, alat menghapus data tersembunyi, dan Anda mengunduh salinan yang bersih.

Panduan ini memandu Anda langkah demi langkah dengan alat gratis Hapus Metadata Gambar. Alat ini bekerja di browser, tanpa akun, dan tidak pernah mengunggah foto Anda ke mana pun.

Di akhir panduan, Anda akan tahu cara membersihkan satu foto, membersihkan banyak foto sekaligus, memilih metode penghapusan yang tepat, dan membuktikan hasilnya bersih.

Yang Perlu Disiapkan Sebelum Memulai

Anda membutuhkan file gambar yang akan dibagikan, yang tersimpan di perangkat Anda. Bekerjalah dari file asli, bukan dari salinan yang sudah pernah Anda unggah di tempat lain.

Alat ini menerima file JPG, PNG, WebP, dan HEIC hingga 20 MB per file. Ukuran itu sudah mencakup foto ponsel, JPEG DSLR, ekspor PNG, dan file HEIC iPhone.

Simpan salinan privat file asli jika metadatanya penting bagi Anda. Penghapusan bersifat permanen untuk salinan yang dibersihkan, dan pengaturan kamera atau data GPS tidak bisa dipulihkan dari salinan itu nanti.

Buka alat di browser modern apa pun. Chrome, Firefox, Safari, dan Edge semuanya berfungsi, baik di desktop maupun di ponsel.

Jika Anda tidak yakin apa isi foto Anda, periksa dulu di Penampil Metadata Gambar. Penampil menunjukkan setiap tag sebelum Anda memutuskan apa yang harus dihapus.

Langkah 1: Buka Alat

Buka halaman Hapus Metadata Gambar. Anda akan melihat kotak unggah dan penjelasan singkat tentang fungsi alat ini.

Tidak ada layar masuk dan tidak ada dinding berbayar. Alat ini gratis, dan Anda bisa membersihkan foto tanpa batas, tanpa watermark atau biaya.

Di ponsel, buka halaman di Safari atau Chrome seluler. Tata letaknya menyesuaikan, dan Anda bisa memilih foto langsung dari galeri.

Simpan halaman ini sebagai markah jika Anda sering membersihkan foto. Penjual, wartawan, dan orang tua cenderung menggunakannya sebelum setiap unggahan publik, jadi akses cepat sangat membantu.

Langkah 2: Unggah Foto Anda

Seret foto ke kotak unggah, atau klik kotak itu untuk memilih file dari perangkat Anda. Anda bisa memasukkan satu foto atau banyak foto sekaligus.

Anda juga bisa menempel dengan Ctrl+V di Windows atau Cmd+V di Mac. Gambar atau tangkapan layar yang disalin langsung masuk ke antrean unggah dan dibersihkan otomatis.

Pembersihan dimulai segera setelah diunggah. Tidak ada tombol mulai yang harus ditekan, dan tidak ada penantian untuk server, karena semua pekerjaan terjadi di dalam memori browser Anda.

Setiap file dapat berukuran hingga 20 MB. Jika ada file yang lebih besar, kompres dulu dengan alat kompres gambar, lalu bersihkan salinan yang lebih kecil.

Dalam sekejap, sebuah kartu muncul untuk setiap foto. Kartu itu menampilkan nama file, hasil penghapusan, dan lencana verifikasi.

Langkah 3: Periksa Lencana Verifikasi

Setelah diunggah, setiap kartu dipindai ulang otomatis dan menampilkan berapa tag metadata yang dihapus, misalnya “Stripped X metadata tags to 0 remaining”.

Lencana hijau atau hijau zamrud berarti output sudah terverifikasi bersih. Alat menjalankan parser metadata kedua kalinya pada file output, sehingga lencana itu adalah pemeriksaan nyata, bukan tebakan.

Jika sebuah foto menampilkan “Verified clean” tepat setelah diunggah, sumbernya memang sudah berisi nol tag EXIF, GPS, atau chunk teks. Tangkapan layar dan foto yang diunduh dari aplikasi pesan umumnya memang sudah seperti itu.

Tunggu sampai lencana berubah hijau di semua kartu sebelum mengunduh. Sebuah batch baru selesai saat setiap kartu terverifikasi.

Jika sebuah kartu masih menunjukkan tag tersisa, file itu butuh langkah pembersihan lagi. Ubah metode penghapusan dan klik Re-clean All, seperti dijelaskan pada langkah 5.

Langkah 4: Pilih Metode Penghapusan

Metode bawaannya adalah Lossless Binary Strip, dan metode ini adalah pilihan tepat untuk sebagian besar foto JPG dan PNG. Metode ini menghapus segmen metadata tanpa mendekode atau mengompres satu piksel pun.

Pertahankan metode ini saat Anda menginginkan nol perubahan kualitas. JPG Anda tetap JPG, PNG Anda tetap PNG, dan latar transparan PNG bertahan byte demi byte.

Pilih Full Canvas Re-encode saat Anda menginginkan bitmap yang benar-benar baru tanpa segmen warisan. Metode ini juga dipakai otomatis untuk input WebP dan HEIC, dan setiap kali Anda mengubah format output.

Re-encode juga memperbaiki orientasi. Jika JPEG vertikal tampak miring setelah penghapusan lossless, penanda orientasi terhapus tanpa memutar pikselnya. Canvas re-encode menanamkan orientasi tegak ke dalam gambar yang diekspor.

Pilihan ini bisa diubah sebelum Anda mengunduh. Ubah metodenya, klik Re-clean All, dan batch diproses lagi dengan pengaturan yang baru.

Langkah 5: Atur Format Output dan Kualitas

Secara bawaan alat mempertahankan format asli, sehingga JPG tetap JPG dan PNG tetap PNG. Itu pilihan paling aman saat Anda hanya ingin metadata hilang.

Untuk mengonversi sambil membersihkan, pilih JPG, PNG, atau WebP di Output Format. Setiap file di-encode ulang dengan bersih lewat Canvas, semua metadata dihapus, dan format yang dipilih diterapkan.

Atur slider Re-encode Quality antara 50 dan 100 persen saat Anda melakukan re-encode. Kualitas sekitar 85 persen adalah bawaan yang bagus untuk ekspor WebP dan JPG, menyeimbangkan ukuran dan detail.

Slider tidak berpengaruh apa pun pada file Lossless Binary Strip, karena tidak ada piksel yang di-encode ulang. Slider hanya berlaku untuk input WebP dan HEIC, atau untuk ekspor Full Canvas Re-encode.

Setelah mengubah pengaturan apa pun, klik Re-clean All. File langsung dibersihkan saat dimasukkan dengan pengaturan aktif Anda, sehingga tombol ini menerapkan opsi terbaru Anda ke seluruh batch.

Untuk perbandingan lengkap kedua metode, baca Panduan Lengkap Menghapus Metadata Gambar.

Langkah 6: Unduh File Bersih

Saat lencana sudah hijau, unduh file Anda. Klik Download Clean pada kartu masing-masing untuk menyimpan foto itu, atau klik Download All Clean (ZIP) untuk seluruh batch.

File ZIP itu bernama clean_images_no_metadata.zip. File ini berisi semua foto bersih dari batch, siap diunggah ke marketplace, forum, atau iklan.

Unduhan adalah file terpisah. File asli Anda di perangkat tidak tersentuh, karena browser tidak bisa menimpa file di folder lokal Anda.

Simpan file bersih di tempat yang bisa Anda bedakan dari file asli, misalnya folder bernama clean atau ready-to-post. Mencampur keduanya justru menggagalkan tujuannya.

Bagikan salinan yang sudah dibersihkan, bukan file aslinya. Jika Anda keliru mengunggah file asli, metadatanya ikut terunggah.

Langkah 7: Verifikasi File yang Sudah Dibersihkan

Verifikasi adalah langkah yang paling sering dilewati orang, dan langkah inilah yang membuktikan pekerjaan selesai. Masukkan file bersih yang sudah diunduh ke Penampil Metadata Gambar.

Jika pembersihan berhasil, spanduk hijau memastikan tidak ada tag EXIF, GPS, atau kamera tersembunyi yang terdeteksi, dan tidak ada peringatan GPS yang muncul. Itu adalah pemeriksaan independen terhadap byte file.

Jika masih ada tag, tabel penampil menunjukkan persis tag mana yang bertahan. Sisa yang umum adalah chunk teks PNG dan komentar JPEG, yang sering terlewat oleh alat pembersih.

Saat ada sisa, kembali ke alat penghapus, beralih ke Full Canvas Re-encode, klik Re-clean All, lalu unduh lagi. Kemudian verifikasi file yang baru dengan cara yang sama.

Jadikan ini kebiasaan dua langkah untuk foto sensitif: periksa, hapus, periksa lagi. Pemeriksaan kedua hanya butuh beberapa detik dan menghilangkan semua keraguan.

Menghapus Metadata di Ponsel

Kebanyakan foto dibagikan dari ponsel, jadi alur kerja ini berfungsi di browser seluler. Buka alat di Safari iOS atau Chrome Android dan pilih foto dari galeri Anda.

File dibersihkan saat diunggah, lencana berubah hijau, dan Anda mengunduh salinan bersih langsung ke perangkat. Lalu bagikan file yang sudah dibersihkan dari galeri Anda.

Bersihkan sebelum Anda membuka aplikasi sosial atau marketplace, bukan sesudahnya. Begitu foto diunggah, siapa pun mungkin sudah mengunduh file asli beserta metadatanya.

Jika kamera ponsel Anda merekam lokasi secara bawaan, pertimbangkan mematikan lokasi untuk aplikasi kamera. Cara itu menghentikan tag GPS sejak awal, sehingga foto berikutnya tidak perlu dibersihkan untuk lokasi.

Membersihkan Batch untuk Marketplace

Penjual memotret produk di rumah, dan foto-foto itu dapat membawa koordinat GPS yang menunjuk langsung ke alamat penjual. Pembersihan massal menghilangkan risiko itu untuk seluruh hasil pemotretan sekaligus.

Masukkan seluruh set foto iklan bersamaan dan tunggu sampai lencana berubah hijau di semua kartu. Lalu klik Download All Clean (ZIP) dan unggah file yang sudah dibersihkan ke iklan Anda.

Gunakan rutinitas yang sama untuk unggahan forum, iklan sewa, dan iklan baris. Di mana pun orang asing mengunduh gambar resolusi penuh, metadata adalah risiko yang layak dihapus.

Tidak ada batas jumlah file, selain batas 20 MB per file. Seratus foto iklan dibersihkan semudah satu foto, tanpa watermark, tanpa pendaftaran, dan tanpa biaya.

Penjual juga sebaiknya membersihkan foto sebelum dikirim ke pembeli lewat email. Lampiran email mempertahankan file asli, sehingga koordinat rumah bisa ikut terkirim bersama foto produk yang sudah terjual.

Buat folder khusus untuk foto yang sudah dibersihkan, misalnya “siap-unggah”. Dengan begitu, Anda tidak perlu menebak mana file asli dan mana file bersih saat sedang terburu-buru menyiapkan iklan.

Jika Anda menjual dari rumah, pertimbangkan juga mematikan lokasi kamera. Foto produk yang diambil tanpa GPS tidak membawa risiko alamat, bahkan jika Anda lupa membersihkannya.

Untuk risiko privasi di balik rutinitas ini, baca Privasi Foto: Risiko GPS, EXIF, dan Metadata.

Mengatasi Masalah: Saat Pembersihan Tidak Berjalan Seperti yang Diharapkan

Kebanyakan masalah punya penyebab sederhana. Telusuri daftar di bawah ini sebelum menganggap alat rusak.

  • Foto tampak miring setelah dibersihkan. Penghapusan lossless menghapus penanda orientasi EXIF. Beralihlah ke Full Canvas Re-encode dan klik Re-clean All untuk menanamkan orientasi tegak ke dalam piksel.
  • File masih menampilkan tag setelah dibersihkan. Sebagian chunk teks PNG atau komentar JPEG dapat bertahan setelah langkah pertama. Coba Full Canvas Re-encode, yang membangun ulang gambar dari nol.
  • Slider kualitas tampaknya tidak berpengaruh. Slider hanya berlaku untuk input WebP dan HEIC, atau untuk ekspor Full Canvas Re-encode. Lossless Binary Strip tidak pernah meng-encode ulang piksel, sehingga slider tidak berpengaruh di sana.
  • File tidak bisa diunggah. Periksa ukurannya: batasnya 20 MB per file. Kompres gambar dulu, lalu bersihkan salinan yang lebih kecil.
  • File yang diunduh tampak identik dengan file asli. Itu benar. Pembersihan menghapus data tersembunyi, bukan piksel, sehingga pembersihan yang berhasil tampak persis sama seperti file asli.
  • Lencana langsung menampilkan “Verified clean”. Sumbernya memang sudah tidak punya metadata, yang umum terjadi pada tangkapan layar dan foto dari aplikasi pesan. Tidak ada yang salah.

Jika masalah berlanjut, uji dengan file asli yang baru diambil dari galeri. Cara itu memberi tahu apakah penyebabnya ada pada file atau pada pengaturan.

Menghapus Metadata dari Foto HEIC

Foto iPhone sering tiba sebagai file HEIC, dan file ini butuh penanganan yang sedikit berbeda. Alat menerima unggahan HEIC hingga 20 MB, sama seperti JPG dan PNG.

File HEIC tidak dihapus dengan Lossless Binary Strip. Sebagai gantinya, alat menggambar piksel ke Canvas yang baru, sehingga dijamin semua header metadata terbuang.

Artinya pembersihan HEIC selalu berupa re-encode. Atur slider Re-encode Quality sebelum mengunduh: sekitar 85 persen adalah bawaan yang bagus, dan 90 sampai 100 persen mempertahankan detail paling banyak.

Anda juga bisa mengonversi foto HEIC sambil membersihkannya. Pilih JPG, PNG, atau WebP di Output Format, dan alat mengekspor salinan bersih dalam format yang Anda pilih.

Mengonversi HEIC ke JPG adalah langkah umum sebelum dibagikan, karena JPG terbuka di mana-mana. Konversi dan pembersihan terjadi dalam satu langkah, sehingga tidak perlu langkah kedua.

Setelah mengunduh, verifikasi hasilnya sama seperti file lainnya. Masukkan salinan bersih ke Penampil Metadata Gambar dan pastikan spanduk hijaunya muncul.

Apa yang Harus Dilakukan Setelah Mengunduh

Mengunduh file bersih bukan langkah terakhir. Beberapa kebiasaan kecil setelah mengunduh memastikan salinan bersihlah yang benar-benar dibagikan.

Pertama, periksa nama file. Unduhan yang dibersihkan mungkin berbagi nama dengan file asli, jadi simpan di folder terpisah agar tidak tertukar.

Kedua, verifikasi setidaknya satu file dari setiap batch. Buka salinan bersih di penampil dan pastikan spanduk hijau tanpa tag muncul sebelum Anda mengunggahnya ke mana pun.

Ketiga, hapus salinan bersih dari folder unduhan setelah diunggah, jika file asli tersimpan di tempat lain. Salinan bersih lama yang tercampur dengan file asli menimbulkan kebingungan nanti.

Keempat, jika Anda berbagi dari ponsel, pastikan lembar berbagi memilih file yang sudah dibersihkan. Aplikasi galeri bisa tampak identik untuk file asli dan salinan bersih, jadi periksa nama file atau foldernya.

Simpan salinan asli di folder privat yang terpisah dari folder unggahan. Pemisahan ini mencegah Anda mengunggah file asli secara tidak sengaja saat sedang terburu-buru.

Ringkasan Cepat

Buka alat Hapus Metadata Gambar, masukkan foto Anda, dan tunggu lencana verifikasi hijau. Pilih Lossless Binary Strip untuk JPG dan PNG, atau Full Canvas Re-encode untuk WebP, HEIC, perubahan format, atau foto yang miring.

Unduh file bersih atau ZIP-nya, lalu verifikasi satu file di Penampil Metadata Gambar. Saat spanduk hijau muncul, foto aman untuk dibagikan.

Seluruh rutinitas ini kurang dari satu menit. Jadikan kebiasaan sebelum setiap unggahan publik, dan foto Anda hanya akan membawa apa yang Anda pilih untuk dibagikan.

Pertanyaan umum

Bagaimana cara menghapus metadata foto di iPhone?

Buka alat Hapus Metadata Gambar di Safari seluler, pilih foto dari galeri Anda, dan tunggu lencana verifikasi hijau. Lalu ketuk Download Clean untuk menyimpan salinan bersih ke perangkat Anda. Bagikan salinan bersih itu, bukan file asli dari galeri Anda.

Bisakah saya menghapus metadata dari tangkapan layar?

Tangkapan layar biasanya memang tidak membawa metadata kamera sejak awal, karena papan klip hanya meneruskan piksel mentah, bukan file kamera asli. Memasukkan tangkapan layar ke alat biasanya langsung menampilkan “Verified clean”. Alat tetap memeriksanya, jadi Anda tidak rugi apa-apa dengan menjalankannya.

Apa cara tercepat membersihkan banyak foto sebelum iklan tayang?

Masukkan seluruh set foto ke alat sekaligus, tunggu lencana hijau di semua kartu, lalu klik Download All Clean (ZIP). ZIP itu berisi semua foto bersih dalam satu file. Unggah file yang sudah dibersihkan ke iklan Anda — jangan pernah mengunggah file aslinya.

Apakah saya perlu membersihkan foto jika hanya mengirimkannya ke satu teman?

Tergantung salurannya. Aplikasi pesan seperti WhatsApp menghapus metadata otomatis, sehingga foto yang dikirim lewat jalur itu biasanya tiba dalam keadaan bersih. Lampiran email dan transfer file langsung sering kali mempertahankan file asli, jadi bersihkan dulu fotonya jika Anda mengirimkannya sebagai file.

Mengapa foto saya yang sudah dibersihkan berukuran lebih kecil daripada file asli?

Foto kamera sering membawa thumbnail pratinjau EXIF yang tertanam, blok XMP, dan segmen komentar. Menghapusnya dalam mode Lossless Binary Strip sering memangkas puluhan kilobyte tanpa perubahan ketajaman gambar. Ukuran yang lebih kecil itu adalah bonus, bukan tanda kehilangan kualitas.

Bisakah saya membatalkan penghapusan metadata setelah mengunduh file bersih?

Tidak. Salinan yang sudah dibersihkan tidak lagi punya metadata untuk dipulihkan. Karena itu simpan file asli Anda di folder privat sebelum membersihkan. File asli mempertahankan pengaturan kamera dan data GPS untuk catatan Anda sendiri, sementara salinan bersih adalah yang Anda bagikan.
