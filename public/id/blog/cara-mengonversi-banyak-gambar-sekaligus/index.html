Cara Mengonversi Banyak Gambar Sekaligus

Ubah seluruh folder gambar ke JPG, PNG, atau WebP dalam satu proses. Unggah, pilih format, atur kualitas, lalu unduh satu file ZIP.

Mengonversi gambar satu per satu baik-baik saja untuk satu foto. Untuk folder berisi lima puluh gambar, itu adalah pekerjaan membosankan yang memakan satu sore. Konversi batch menyelesaikan seluruh folder dalam satu proses.

Prosesnya sederhana: unggah folder, pilih satu format output, atur kualitas sekali, lalu unduh satu ZIP berisi semuanya.

Panduan ini membahas setiap langkah, beserta pengaturan yang penting untuk batch yang bersih dan konsisten.

Langkah 0: Siapkan Folder Anda Dulu

Letakkan setiap gambar yang ingin Anda konversi dalam satu folder sebelum memulai. Folder yang rapi berarti Anda mengunggah sekali, bukan berburu file yang tertinggal di drive Anda.

Hapus file yang tidak termasuk. Screenshot lama, duplikat, dan foto yang tidak terkait hanya memperlambat batch dan mengacaukan ZIP.

Periksa file bermasalah. File bernama .jpg yang sebenarnya adalah WebP, atau gambar yang unduhannya setengah jalan, akan gagal selama konversi. Perbaiki atau hapus file-file itu dulu.

Jaga file asli tetap aman. Konverter tidak pernah mengubahnya, tetapi salinan cadangan di folder terpisah adalah praktik yang baik sebelum pekerjaan batch apa pun.

Langkah 1: Unggah Seluruh Batch

Buka Konversi Gambar Massal di browser Anda. Halaman ini berfungsi di desktop dan seluler, tanpa ada yang perlu diinstal.

Seret folder ke area unggahan, atau klik untuk memilih banyak file. Anda bisa memilih puluhan file sekaligus di pemilih file.

Setiap file muncul sebagai kartu beserta nama, dimensi, dan ukurannya. Pindai daftar itu dengan cepat untuk memastikan tidak ada yang hilang dan tidak ada yang ekstra menyelinap masuk.

File hingga 25MB masing-masing diterima. Itu mencakup foto ponsel, hasil kamera, dan screenshot besar, sehingga sebagian besar folder terunggah tanpa persiapan apa pun.

Langkah 2: Pilih Format Target

Pilih JPG ketika batch sebagian besar berisi foto dan tujuannya umum. Setiap sistem menerima JPG, dan file tetap kecil serta portabel.

Pilih WebP ketika batch ditujukan untuk website. Format ini lebih kecil daripada JPG pada kualitas yang sama dan mempertahankan transparansi, yang cocok untuk batch campuran foto dan logo.

Pilih PNG ketika batch berisi grafis, ikon, atau screenshot berisi teks. PNG menjaga tepi tetap tajam dan transparansi tetap utuh, meskipun file lebih besar.

Ingatlah bahwa satu format berlaku untuk seluruh batch. Jika Anda membutuhkan dua format, jalankan batch dua kali, bukan membaginya dengan tangan.

Langkah 3: Atur Kualitas Sekali

Slider kualitas berlaku untuk setiap file dalam batch. Untuk output JPG atau WebP, 80 hingga 85 persen adalah bawaan yang aman untuk batch foto campuran.

Untuk batch berisi screenshot padat teks, pilih WebP pada 85 persen. Format ini menjaga huruf kecil tetap terbaca, sementara JPG cenderung mengaburkannya.

Untuk batch yang Anda rencanakan untuk dicetak, naikkan kualitas ke 90 persen atau lebih. Cetakan mengungkap cacat yang disembunyikan layar, dan ukuran tambahan itu sepadan.

Jika Anda memilih PNG, slider itu menghilang. PNG bersifat lossless, jadi tidak ada level kualitas yang bisa dipilih, dan setiap file menyimpan pikselnya secara persis.

Langkah 4: Putuskan tentang Transparansi

Jika target Anda JPG, pilih warna isian matte untuk area transparan. Putih cocok untuk sebagian besar penggunaan, sementara warna merek cocok dengan latar website tertentu.

Periksa kartu logo setelah konversi pertama untuk melihat tampilan isiannya. Kotak hitam di belakang logo berarti warna isiannya salah, dan Anda bisa mengubahnya.

Jika target Anda PNG atau WebP, lewati langkah ini. Kedua format mempertahankan transparansi, sehingga logo dan stiker tetap tembus pandang tanpa isian apa pun.

Batch campuran membutuhkan pemikiran sejenak di sini. Logo dan foto dalam batch JPG yang sama berbagi warna isian, tetapi isian itu hanya memengaruhi bagian yang transparan, sehingga foto tidak tersentuh.

Langkah 5: Konversi dan Awasi Kemajuannya

Klik tombol Convert lalu perhatikan kartu-kartu berubah. Setiap file terkonversi secara mandiri, sehingga Anda bisa melihat kemajuan file demi file, bukan menunggu tanpa arah.

Batch besar memakan waktu sedikit, karena setiap file didekode dan dienkode ulang di perangkat Anda. Batch berisi lima puluh foto biasanya selesai dalam satu atau dua menit.

Perhatikan lencana kesalahan saat batch berjalan. Satu file korup menampilkan peringatan tanpa menghentikan file lainnya, sehingga file yang bagus tetap selesai.

Anda bisa menambahkan lebih banyak file selagi batch berjalan. File baru bergabung ke antrean dan terkonversi dengan pengaturan yang sama seperti yang lain.

Langkah 6: Tinjau Hasilnya Kartu demi Kartu

Setiap kartu hasil konversi menampilkan ukuran file baru di samping ukuran lama. Pindaian cepat memberi tahu apakah batch benar-benar menghemat ruang.

Klik Compare pada sebuah kartu untuk memeriksa sebelum dan sesudah secara berdampingan. Periksa wajah, teks, dan tepi, yang merupakan tempat pertama kualitas rendah terlihat.

Perhatikan ringkasan batch di akhir. Ringkasan itu menjumlahkan ukuran asli dan ukuran hasil konversi, sehingga Anda bisa melihat penghematan keseluruhan dalam satu angka.

Jika totalnya justru membesar, bukan menyusut, formatnya salah untuk batch itu. Beralihlah dari PNG ke WebP atau JPG lalu konversi lagi.

Langkah 7: Unduh Semuanya sebagai Satu ZIP

Klik Download All untuk menggabungkan seluruh batch menjadi satu arsip ZIP. Nama ZIP itu mengidentifikasi format target, sehingga Anda tahu apa isinya.

Ekstrak ke folder baru, bukan menimpa file asli Anda. Folder terpisah menjaga file hasil konversi tetap terorganisasi dan mencegah penimpaan yang tidak disengaja.

Jika Anda mengatur akhiran nama file, setiap output membawanya. Akhiran seperti -webp membuat file hasil konversi mudah dibedakan dari file asli.

Periksa beberapa file dari ZIP sebelum Anda menggunakannya. Buka satu foto dan satu logo, pastikan tampilannya benar, dan periksa formatnya sesuai dengan yang Anda inginkan.

  1. Siapkan satu folder berisi semua gambar yang akan dikonversi.
  2. Unggah folder itu ke Konversi Gambar Massal.
  3. Pilih satu format output lalu atur kualitas sekali.
  4. Konversi, tinjau ringkasan batch, lalu unduh ZIP-nya.

Memperbaiki File yang Gagal

File yang gagal menampilkan lencana kesalahan pada kartunya. Bacalah pesannya, karena pesan itu biasanya menyebutkan masalahnya, seperti file yang tidak didukung atau korup.

Hapus file yang gagal dari daftar lalu konversi sisanya. Anda bisa menangani file bermasalah itu secara terpisah, bukan membiarkannya menahan batch.

Untuk file yang gagal berulang kali, periksa format aslinya. Buka di penampil foto atau periksa propertinya, karena ekstensinya mungkin salah.

Konversi file yang bandel satu per satu di Konversi Gambar umum. Satu file lebih mudah dipecahkan masalahnya daripada batch berisi lima puluh file.

Mengonversi Batch yang Sama ke Format Lain

Anda tidak perlu mengunggah ulang untuk membuat versi kedua. Setelah konversi pertama, ubah format output lalu konversi lagi.

File asli tetap ada di antrean di antara kedua proses, sehingga batch JPG dan batch WebP berasal dari satu unggahan. Unduh setiap ZIP sebelum berganti format.

Gunakan akhiran nama file untuk membedakan kedua batch itu. Akhiran -jpg untuk proses pertama dan -webp untuk proses kedua menjaga output tetap terorganisasi.

Alur kerja dua format ini umum untuk website. JPG melayani sistem lama, sementara WebP melayani browser modern, dan keduanya berasal dari folder sumber yang sama.

Tips Batch untuk Ponsel

Konversi batch berfungsi di browser ponsel, tetapi lebih lambat dan layarnya kecil. Batasi batch ponsel hingga selusin file atau kurang.

Pilih beberapa foto sekaligus dari galeri Anda. Area unggahan menerima multi-pilih, sehingga Anda tidak perlu menambahkan foto satu per satu.

Unduhan masuk ke folder Downloads ponsel Anda sebagai ZIP. Anda mungkin membutuhkan aplikasi pengelola file untuk mengekstraknya, tergantung ponsel Anda.

Untuk folder besar, gunakan desktop. Layar yang lebih besar dan prosesor yang lebih cepat membuat batch seratus file jauh lebih nyaman.

Menjaga File Asli Tetap Aman

Konverter tidak pernah mengubah file asli Anda. Konverter membacanya, membuat file baru, dan membiarkan sumbernya persis seperti semula.

Meskipun demikian, simpan cadangan folder sumber sebelum batch besar. Satu kesalahan pada langkah berikutnya, seperti mengekstrak menimpa file asli, tetap bisa menimbulkan masalah.

Gunakan akhiran nama file untuk mencegah tabrakan. Ketika file hasil konversi membawa tag seperti -converted, file itu tidak bisa menimpa file asli secara tidak sengaja.

Simpan file asli dan salinan hasil konversi di folder terpisah. Pemisahan yang jelas adalah cara paling sederhana untuk menghindari kebingungan nanti.

Memilah File Sebelum Mengunggah

Pemilahan cepat sebelum mengunggah menghemat waktu nanti. Kelompokkan file berdasarkan jenisnya, sehingga foto, logo, dan screenshot masing-masing mendapatkan batch sendiri dengan pengaturan yang tepat.

Foto menginginkan JPG atau WebP pada kualitas 80 hingga 85 persen. Logo menginginkan PNG atau WebP dengan transparansi dipertahankan. Screenshot berisi teks menginginkan WebP pada 85 persen.

Memilah memakan waktu beberapa menit dan mencegah pengerjaan ulang. Batch campuran memaksakan pengaturan kompromi yang tidak cocok sempurna untuk siapa pun, sementara batch yang sudah dipilah masing-masing mendapatkan pengaturan terbaiknya.

Hapus duplikat dan file yang ditolak selama pemilahan. Setiap file tambahan membutuhkan waktu konversi dan mengacaukan ZIP, jadi pemangkasan cepat sebelum mengunggah sepadan dengan usaha itu.

Letakkan kelompok yang sudah dipilah di folder terpisah dengan nama yang jelas, seperti photos-to-webp dan logos-to-webp. Folder-folder itu menjaga batch tetap terorganisasi dari awal hingga akhir.

Mengonversi Foto Liburan

Foto liburan adalah pekerjaan massal klasik. Ratusan file HEIC dari iPhone perlu menjadi JPG sebelum bisa dibagikan kepada keluarga atau diunggah ke mana pun.

Pilah dulu foto-fotonya, hapus foto yang buram dan duplikat. Album liburan berisi tiga ratus foto sering kali hanya memiliki lima puluh yang layak disimpan, dan mengonversi hanya foto-foto itu menghemat waktu nyata.

Konversi foto yang disimpan ke JPG pada kualitas 90 persen. Foto-foto itu tampak paling bagus, file terbuka di mana saja, dan album siap dibagikan kepada siapa pun.

Untuk foto yang akan masuk website atau blog, konversi ke WebP. File sepertiga lebih kecil, halaman dimuat lebih cepat, dan gambar tampak identik.

Simpan file HEIC asli di folder arsip setelah mengonversi. File-file itu adalah salinan berkualitas terbaik, dan Anda bisa mengonversinya lagi jika membutuhkan format berbeda nanti.

Mengonversi Dokumen Kerja secara Massal

Dokumen kerja sering tiba sebagai folder berisi scan dalam format campuran. Mengonversi semuanya ke satu format membuat kumpulan itu konsisten dan lebih mudah diarsipkan.

Untuk scan yang harus tetap terbaca, konversi ke PNG. Teks tetap tajam melalui pengeditan dan penyimpanan ulang, dan itu penting untuk kontrak dan formulir.

Untuk scan yang harus tetap kecil, konversi ke JPG pada kualitas 85 persen. File menyusut secara dramatis, dan teks tetap terbaca pada pengaturan itu.

Beri nama file hasil konversi berdasarkan dokumen dan tanggal, seperti contract-2026-11.jpg. Nama yang jelas membantu rekan kerja menemukan file yang tepat tanpa membuka sepuluh kandidat.

Simpan dokumen hasil konversi di drive bersama dengan struktur folder yang sama seperti file asli. Struktur yang dicerminkan menjaga arsip tetap bisa dijelajahi semua orang.

Memakai Ulang Pengaturan untuk Batch Berulang

Batch berulang itu umum: foto produk yang sama setiap minggu, screenshot yang sama setiap bulan. Menuliskan pengaturan sekali membuat setiap batch berulang menjadi identik.

Simpan satu baris catatan per pekerjaan, seperti WebP 85 persen, matte putih. Baris itu adalah seluruh resepnya, dan siapa pun bisa mengikutinya tanpa menebak-nebak.

Simpan catatan itu di folder pekerjaan, di samping file sumber. Batch berikutnya dimulai dengan membaca catatan, bukan dengan mengingat apa yang berhasil terakhir kali.

Ketika pengaturan berubah, perbarui catatan itu segera. Catatan yang basi lebih buruk daripada tidak ada catatan, karena menghasilkan batch yang tampak berbeda dari batch sebelumnya.

Tinjau catatan itu setiap beberapa bulan. Pengaturan yang masuk akal untuk lima puluh gambar mungkin tidak cocok untuk lima ratus, dan penyesuaian kecil bisa menghemat banyak waktu.

Mengonversi Gambar untuk Serah Terima Klien

Serah terima klien membutuhkan gambar dalam format yang bisa dibuka klien, dan JPG adalah pilihan paling aman. Folder berisi file WebP bisa gagal di komputer lama klien, sementara JPG terbuka di mana saja.

Konversi gambar dalam satu batch, memakai kualitas yang sama untuk semuanya. Konsistensi penting ketika klien meninjau kumpulan itu, karena kualitas yang tercampur tampak ceroboh.

Beri nama file hasil konversi dengan jelas, beserta proyek dan tanggalnya. File bernama website-hero-nov-2026.jpg memberi tahu klien apa isinya, sementara IMG_4821.jpg tidak memberi tahu apa pun.

Sertakan readme singkat bersama pengiriman, yang mencantumkan format dan pengaturan yang dipakai. Satu baris catatan mencegah klien bertanya mengapa ada dua salinan dari setiap gambar.

Simpan file asli di arsip Anda sendiri setelah serah terima. Jika klien meminta format berbeda nanti, file asli memungkinkan Anda mengonversi lagi tanpa meminta file itu kembali.

Batch foto dari acara, seperti pernikahan atau wisuda, layak mendapat perlakuan khusus. Foto-foto itu sering diambil oleh beberapa fotografer dengan kamera yang berbeda, sehingga ukuran dan profil warnanya beragam. Pilah berdasarkan fotografer atau sesi sebelum mengonversi, agar setiap kelompok mendapatkan pengaturan yang paling cocok.

Untuk batch yang akan diunggah ke platform tertentu, periksa aturan platform itu dulu. Marketplace, portal lowongan, dan sistem sekolah masing-masing punya batas ukuran dan format yang diterima. Mengetahui aturan itu sebelum mengonversi mencegah batch yang harus dibuat ulang karena satu detail kecil.

Jika batch berisi file dengan nama yang sama dari folder berbeda, berhati-hatilah saat mengekstrak ZIP. Dua file bernama photo.jpg dari folder yang berbeda akan bertabrakan di folder tujuan. Gunakan akhiran nama file atau ekstrak ke subfolder terpisah, agar tidak ada file yang tertimpa tanpa sengaja.

Itulah seluruh proses batch, dari folder yang berantakan menjadi satu ZIP yang rapi. Untuk latar belakang lengkap, baca Konversi Gambar Massal: Panduan Lengkap, dan untuk alur kerja folder dan penamaan, lihat Konversi Batch: Alur Kerja Folder dan Penamaan File. Jika folder Anda sebagian besar berisi foto iPhone, konverter HEIC ke JPG adalah titik awal yang lebih cepat.

Pertanyaan umum

Bisakah saya menyeret seluruh folder ke konverter massal?

Bisa, Anda bisa menyeret folder ke area unggahan, dan alat akan mengambil file gambar di dalamnya. Anda juga bisa mengklik area itu lalu memilih banyak file sekaligus di pemilih file. Dengan cara apa pun, setiap gambar yang valid bergabung ke antrean konversi yang sama.

Jenis file apa yang bisa saya campur dalam satu batch massal?

JPG, PNG, WebP, HEIC, SVG, BMP, GIF, dan AVIF semuanya bisa berada dalam satu antrean yang sama. Setiap file yang valid terkonversi ke format output yang Anda pilih. Satu-satunya pengecualian adalah GIF animasi, yang menjadi gambar diam karena hanya frame pertama yang dikonversi.

Bagaimana cara menghentikan file hasil konversi menimpa file asli saya?

Gunakan akhiran nama file opsional, seperti -webp atau -converted, agar setiap output memiliki nama yang berbeda dari aslinya. Ekstrak juga ZIP ke folder baru, bukan menimpa file asli. Bersama-sama, kedua kebiasaan itu membuat penimpaan menjadi mustahil.

Mengapa satu file dalam batch saya jauh lebih besar setelah dikonversi?

File itu mungkin berpindah dari format lossy ke PNG, yang menyimpan setiap piksel secara persis dan bisa beberapa kali lebih besar. Atau slider kualitas diatur sangat tinggi untuk gambar sederhana. Periksa kartu file itu, dan pertimbangkan untuk mengonversinya secara terpisah dengan pengaturan berbeda.

Bisakah saya menjeda konversi massal di tengah jalan?

Tidak ada tombol jeda, tetapi setiap file terkonversi secara mandiri, jadi Anda cukup menunggu file yang sedang berjalan lalu berhenti menambahkan file baru. File yang sudah selesai tetap terkonversi dan bisa diunduh. Untuk memulai ulang, cukup unggah file yang tersisa sebagai batch baru.

Apakah konverter massal berfungsi tanpa koneksi internet?

Setelah halaman dimuat, konversi berjalan secara lokal di browser Anda dan tidak membutuhkan internet. Anda hanya butuh koneksi untuk membuka halaman pertama kali. Setelah itu, Anda bisa mengonversi batch secara offline sampai menutup tab.
