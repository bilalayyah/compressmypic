Cara Mengubah AVIF ke JPG

Ubah gambar AVIF ke JPG dalam beberapa langkah. Unggah, atur kualitas, tangani transparansi, lalu unduh — satu file atau satu batch sekaligus.

Gambar AVIF yang diunduh dari website modern sering menolak dibuka di aplikasi yang Anda butuhkan. Mengubahnya ke JPG hanya butuh kurang dari satu menit, dan hasilnya bisa dipakai di mana saja.

Satu-satunya bagian yang agak rumit adalah transparansi, dan satu-satunya syarat adalah browser modern yang memang bisa mendekode AVIF sejak awal.

Panduan ini memandu Anda langkah demi langkah, supaya konversi pertama Anda langsung bersih.

Sebelum Mulai: Periksa Browser Anda

Anda membutuhkan browser modern yang mendekode AVIF secara bawaan. Versi terbaru Chrome, Edge, Firefox, dan Safari semuanya bisa, jadi perbarui browser Anda jika sudah lama.

Temukan file AVIF di perangkat Anda. Mereka biasanya berasal dari unduhan, di mana website menyajikan AVIF sebagai ganti JPG tanpa memberi tahu Anda.

Periksa apakah gambar memiliki transparansi. Foto biasanya tidak, sementara logo dan stiker mungkin punya, dan area transparan membutuhkan warna matte.

File sampai 25MB per file diterima. Itu mencakup unduhan beresolusi tinggi dan capture kamera tanpa persiapan apa pun.

Jika browser Anda sudah lama tidak diperbarui, perbarui dulu sebelum mulai. Browser lama tidak bisa mendekode AVIF sama sekali, dan tidak ada pengaturan di alat yang bisa mengatasi hal itu. Pembaruan biasanya gratis dan hanya butuh beberapa menit.

Langkah 1: Buka Alat AVIF ke JPG

Buka alat AVIF ke JPG di browser Anda. Halaman ini bisa dipakai di Windows, Mac, Linux, ChromeOS, Android, dan iOS.

Anda akan melihat area unggah, pemilih warna matte, dan penggeser kualitas. Tiga kontrol itu saja sudah cukup untuk seluruh pekerjaan.

Tidak perlu akun, dan tidak ada yang diunggah ke server. Konversi terjadi di perangkat Anda, dan itu penting untuk gambar pribadi serta file unduhan.

Jika Anda memakai ponsel, halaman ini bisa dibuka di browser seluler. Ketuk area unggah untuk memilih file AVIF dari unduhan atau galeri Anda.

Langkah 2: Unggah File AVIF Anda

Seret file AVIF Anda ke area unggah, atau klik untuk membuka pemilih file. Anda bisa memilih banyak file sekaligus untuk satu batch.

Setiap file muncul sebagai kartu dengan gambar mini, dimensi, dan ukurannya. Pemeriksaan cepat memastikan file yang benar sudah dimuat dan tidak ada file lain yang ikut masuk.

Jika sebuah file gagal dimuat, browser Anda mungkin tidak mendekode AVIF. Perbarui browser ke versi terbaru lalu coba lagi.

Anda juga bisa menempel gambar yang disalin dengan Ctrl+V di komputer. Cara ini praktis ketika AVIF ada di clipboard dari aplikasi lain.

Langkah 3: Pilih Warna Matte

Klik pemilih warna matte untuk memilih isian bagi area transparan. Putih adalah bawaan dan cocok untuk sebagian besar keperluan.

Pilih hitam untuk desain gelap, atau masukkan kode hex agar persis sama dengan latar website tertentu. Latar yang cocok membuat logo terlihat menyatu dengan halaman.

Jika AVIF Anda tidak memiliki transparansi, pengaturan ini tidak berpengaruh. Foto lewat begitu saja tanpa berubah, apa pun warna yang Anda pilih.

Periksa kartu logo setelah mengonversi untuk melihat bagaimana matte tampil. Warna yang salah langsung terlihat jelas, dan Anda bisa menggantinya lalu mengonversi lagi.

Langkah 4: Atur Penggeser Kualitas

Untuk sebagian besar foto AVIF, kualitas JPG 85 persen adalah titik yang ideal. Foto terlihat bersih, ukuran file wajar, dan kehilangan tidak terlihat.

Gunakan 90 persen atau lebih untuk gambar yang akan dicetak. Cetakan memperlihatkan cacat yang tersembunyi di layar, dan ukuran ekstra itu murah untuk satu gambar penting.

Untuk gambar yang menuju formulir dengan batas ukuran, mulai dari 85 lalu turun bertahap. Periksa ukurannya setelah setiap langkah, dan berhenti begitu file muat.

Foto AVIF sering berkualitas sangat tinggi, jadi ia tahan terhadap konversi dengan baik. JPG pada 85 persen biasanya terlihat identik dengan AVIF pada ukuran tampilan normal.

Untuk foto yang akan dicetak, jangan ragu memakai kualitas 90 persen. Biaya ukuran file yang lebih besar tidak sebanding dengan kekecewaan melihat foto cetak yang buram, dan satu gambar penting layak mendapatkan kualitas terbaik.

Langkah 5: Konversi dan Pratinjau Hasilnya

Klik tombol Convert. Setiap file dikonversi secara terpisah, jadi Anda bisa melihat kemajuan kartu demi kartu.

Setiap kartu menunjukkan ukuran JPG baru di samping ukuran AVIF lama. Harapkan JPG lebih besar, karena AVIF lebih efisien daripada JPG.

Klik Compare pada kartu untuk memeriksa hasilnya berdampingan. Geser pembatas ke seluruh gambar dan periksa wajah, teks, serta warna.

Jika hasilnya terlihat lembut, naikkan kualitas lima poin lalu konversi lagi. AVIF asli tetap ada di antrean, jadi Anda tidak perlu mengunggah ulang.

Langkah 6: Unduh File JPG

Klik Download pada satu kartu untuk menyimpan satu JPG. Nama file tetap memakai nama asli Anda dengan ekstensi .jpg.

Untuk batch, klik Download All untuk mendapatkan satu ZIP berisi semua JPG hasil konversi. Itu jauh lebih cepat daripada mengunduhnya satu per satu.

Periksa file yang diunduh sekali sebelum menggunakannya. Buka JPG di penampil foto Anda, pastikan tampilannya benar, dan pastikan ia terbuka di aplikasi yang membutuhkannya.

Simpan juga file AVIF aslinya. Itu salinan berkualitas terbaik yang Anda miliki, dan Anda selalu bisa mengonversinya lagi jika kelak butuh format lain.

  1. Buka alat AVIF ke JPG dan unggah file AVIF Anda.
  2. Pilih warna matte untuk area transparan.
  3. Atur penggeser kualitas ke 85 persen.
  4. Konversi, pratinjau dengan Compare, lalu unduh JPG-nya.

Mengonversi Beberapa Unduhan AVIF Sekaligus

Pilih banyak file AVIF sekaligus di pemilih file. Semuanya dimuat ke antrean, dan sekali klik mengubah semuanya ke JPG.

Gunakan warna matte dan kualitas yang sama untuk seluruh batch. Konsistensi penting ketika gambar-gambar itu milik proyek atau dokumen yang sama.

Perhatikan lencana kesalahan selama batch berjalan. File yang tidak bisa didekode browser Anda menampilkan peringatan, dan memperbarui browser biasanya memperbaikinya.

Unduh batch sebagai ZIP lalu ekstrak ke folder baru. Mencampur JPG hasil konversi dengan file AVIF asli dalam satu folder akan membingungkan nantinya.

Memperbaiki Masalah Umum

Jika konversi gagal, perbarui browser Anda. Dekode AVIF membutuhkan versi terbaru, dan browser lama tidak bisa membaca file itu sama sekali.

Jika JPG terlihat kusam, warna HDR atau wide-gamut bergeser selama konversi. Penyesuaian saturasi kecil di aplikasi foto apa pun mengembalikan kesan hidupnya.

Jika AVIF transparan mendapat kotak hitam, warna matte-nya hitam atau belum diatur. Ganti ke putih atau warna halaman Anda lalu konversi lagi.

Jika hasil pertama terlihat salah, sesuaikan pengaturannya dan coba lagi. File asli tetap ada di antrean, jadi percobaan kedua hanya butuh beberapa detik.

Jika masalah terus muncul setelah memperbarui browser, coba buka file AVIF di browser lain. Kadang satu browser gagal membaca file tertentu sementara browser lain berhasil, dan itu menunjukkan masalahnya ada pada decoder, bukan pada file Anda.

Setelah Mengonversi: Apa yang Dilakukan Berikutnya

Jika JPG untuk formulir, periksa batas ukuran sebelum mengunggah. JPG hasil konversi pada kualitas 85 persen bisa melebihi batas 2MB, dan Anda mungkin perlu mengompresinya.

Gunakan kompresor 100KB atau kompresor ukuran file target ketika portal menuntut ukuran yang persis. Ubah dulu, lalu kompres, dalam urutan itu.

Jika JPG untuk website, pertimbangkan mengubahnya ke WebP sebagai gantinya. Konverter JPG ke WebP mengambil JPG baru Anda dan mengecilkannya untuk web.

Jika JPG untuk dicetak, pertahankan pada 90 persen atau lebih. Cetakan memperlihatkan cacat kompresi, dan JPG berkualitas tinggi adalah pilihan paling aman.

Tips untuk Ponsel dan Tablet

Di ponsel, ketuk area unggah lalu pilih file AVIF dari unduhan atau galeri Anda. Konversi berjalan di ponsel, dan JPG-nya terunduh ke perangkat Anda.

Pertahankan batch ponsel tetap kecil, karena file AVIF besar membutuhkan waktu untuk didekode di prosesor seluler. Sepuluh file sekaligus sudah nyaman.

Unduhan tersimpan di folder Downloads ponsel Anda. Di iPhone, periksa aplikasi Files; di Android, periksa pengelola file Anda.

Untuk batch unduhan yang besar, gunakan desktop. Prosesor yang lebih cepat dan layar yang lebih besar membuat banyak file jauh lebih mudah dikelola.

Di ponsel, unduhan AVIF sering tersimpan di folder Downloads tanpa Anda sadari. Periksa folder itu dulu sebelum mencari di galeri, karena banyak browser menyimpan file unduhan di sana, bukan di rol kamera.

Mengonversi AVIF untuk Formulir

Formulir unggah mencantumkan JPG dan PNG sebagai format yang diterima, dan file AVIF langsung terpental. Ubah ke JPG sebelum mengunggah, dan periksa dulu aturan formulirnya.

Ubah gambar ke JPG dengan kualitas 85 persen. Foto terlihat bersih, ukuran file wajar, dan formulir menerimanya tanpa kesulitan apa pun.

Periksa batas ukuran file setelah mengonversi. Formulir yang membatasi unggahan pada 2MB bisa menolak JPG 4MB, dan Anda mungkin perlu mengompresinya dengan alat 100KB atau 200KB.

Periksa dimensi selain formatnya. Formulir yang menuntut ukuran piksel tertentu akan menolak gambar yang formatnya benar tapi bentuknya salah.

Unggah gambar hasil konversi lebih awal, sebelum tenggat. Konversi di menit terakhir tidak menyisakan waktu untuk memperbaiki masalah, sementara unggahan awal menyisakan ruang untuk mencoba lagi.

Mengonversi AVIF untuk Email

Klien email menampilkan JPG dengan andal, sementara dukungan AVIF tidak konsisten. Lampiran AVIF bisa tampil sebagai gambar rusak, dan itu terlihat tidak profesional dalam email bisnis.

Ubah AVIF ke JPG sebelum melampirkannya. JPG tampil dengan benar di setiap klien email, pada semua perangkat, dan pesan sampai utuh.

Pertahankan kualitas 85 persen untuk gambar email. Foto terlihat bersih, file cukup kecil untuk dikirim, dan penerima melihat gambar yang sama dengan Anda.

Untuk beberapa gambar, ubah batch lalu lampirkan JPG-nya bersamaan. Sekumpulan file AVIF yang diubah ke JPG jauh lebih kecil dan jauh lebih kompatibel daripada aslinya.

Periksa total ukuran sebelum mengirim. Sekilas pandang pada ukuran lampiran mencegah pesan terpental yang menjengkelkan yang tiba setelah Anda mengira email sudah terkirim.

Mengonversi AVIF untuk Presentasi

Slide presentasi membutuhkan gambar yang terbuka di komputer presentasi, dan AVIF bisa gagal di mesin yang lebih lama. Ubah dulu ke JPG, dan slide berfungsi di mana saja.

Ubah gambar AVIF ke JPG dengan kualitas 85 sampai 90 persen sebelum menambahkannya ke deck. JPG tertanam dengan bersih di semua versi PowerPoint.

Untuk deck dengan banyak gambar, ubah seluruhnya sekaligus. Konversi batch hanya butuh beberapa menit, dan JPG-nya siap dimasukkan ke slide.

Periksa total ukuran deck setelah mengonversi. Presentasi di atas 50MB bisa kesulitan dikirim lewat email atau diunggah, jadi kompres gambarnya jika file terlalu besar.

Uji deck di komputer presentasi sebelum berbicara. Slide yang terlihat baik di laptop bisa menunjukkan gambar rusak di mesin yang lebih lama, dan uji cepat menangkapnya.

Mengonversi AVIF untuk Klien

Klien sering menerima file AVIF dari website dan tidak bisa membukanya. Mengubah file ke JPG memberi mereka gambar yang berfungsi di setiap aplikasi yang mereka miliki.

Tanyakan dulu kepada klien untuk apa gambar itu dibutuhkan sebelum mengonversi. Klien yang membutuhkannya untuk website menginginkan WebP, sementara klien yang membutuhkannya untuk dokumen menginginkan JPG.

Serahkan kedua format ketika ragu. File JPG berfungsi di mana saja, sementara AVIF asli tetap kecil untuk web, dan klien bisa memilih per keperluan.

Beri nama file hasil konversi dengan jelas, beserta tujuan dan tanggalnya. File bernama hero-photo.jpg memberi tahu klien apa isinya, sementara file bernama download.avif tidak memberi tahu apa-apa.

Sertakan catatan singkat bersama pengiriman yang menjelaskan formatnya. Satu baris catatan mencegah klien bertanya kenapa ada dua salinan dari setiap gambar.

Mengonversi AVIF di Komputer Lama

Komputer lama mungkin tidak mendekode AVIF sama sekali, karena format itu membutuhkan browser terbaru. Perbarui dulu browsernya, dan konversi seharusnya berfungsi.

Jika browser tidak bisa diperbarui, pindahkan file AVIF ke perangkat yang lebih baru lalu konversi di sana. Ponsel atau laptop yang lebih baru menangani dekode tanpa masalah.

Untuk satu gambar, konverter online di perangkat yang lebih baru adalah jalan tercepat. Ubah, unduh JPG-nya, lalu pindahkan JPG kembali ke komputer lama.

Simpan JPG hasil konversi di komputer lama setelah memindahkannya. JPG terbuka di semua aplikasi di mesin lama, sementara file AVIF tidak akan pernah terbuka.

Pertimbangkan memperbarui perangkat lunak komputer lama jika sering dipakai. Browser modern menyelesaikan masalah AVIF dan banyak masalah lain, dan pembaruannya biasanya gratis.

Mengonversi AVIF untuk Portofolio

Portofolio harus terlihat sempurna, dan pengaturan konversi harus mencerminkan itu. Ubah gambar AVIF ke JPG dengan kualitas 90 persen, supaya foto tetap tajam bahkan ketika klien memperbesarnya.

Pilih dulu gambar terkuat, lalu ubah berdasarkan urutan kepentingan. Gambar hero layak mendapat perhatian paling besar, karena ia menentukan kesan untuk seluruh portofolio.

Periksa setiap gambar setelah mengonversi, bukan hanya sampelnya. Portofolio hanya memiliki sedikit gambar, dan masing-masing penting, jadi tinjauan cepat atas semuanya sepadan dengan waktunya.

Perbarui situs portofolio dengan file JPG, dan uji di desktop serta ponsel. Gambar rusak di portofolio berarti klien yang hilang, jadi pastikan setiap gambar dimuat.

Simpan AVIF asli di folder portofolio. Jika klien meminta versi WebP atau AVIF, ia sudah siap tanpa unduhan baru.

Itulah seluruh prosesnya: unggah, pilih matte, atur kualitas, unduh. Pertanyaan umum

Bagaimana cara mengonversi beberapa unduhan AVIF sekaligus?

Pilih banyak file AVIF sekaligus di pemilih file, atau seret ke area unggah. Sekali klik mengubah semuanya dengan pengaturan kualitas dan matte yang sama, dan Anda mengunduh seluruh batch sebagai satu ZIP. Setiap file dikonversi secara terpisah, jadi satu file yang buruk tidak menghentikan sisanya.

Apa yang harus saya lakukan jika browser saya tidak bisa mendekode file AVIF?

Perbarui browser Anda ke versi terbaru, karena dukungan AVIF tiba di rilis terbaru Chrome, Edge, Firefox, dan Safari. Jika file tetap gagal, pastikan itu benar-benar AVIF dengan membukanya di browser lain. Unduhan yang rusak membutuhkan salinan baru dari website sumbernya.

Persentase kualitas berapa yang paling cocok untuk foto AVIF?

85 persen adalah bawaan terbaik untuk sebagian besar foto AVIF, menyeimbangkan ukuran dan kualitas dengan baik. Gunakan 90 persen atau lebih untuk gambar yang akan dicetak, dan turun bertahap hanya ketika batas ukuran file memaksa. Foto AVIF berkualitas tinggi, jadi ia tahan terhadap konversi dengan baik.

Bisakah saya memeriksa JPG hasil konversi sebelum mengunduh?

Ya. Klik Compare pada kartu mana pun untuk melihat AVIF dan JPG berdampingan. Geser pembatas ke seluruh gambar dan periksa wajah, teks, serta warna. Jika hasil pertama terlihat salah, sesuaikan kualitas atau warna matte lalu konversi lagi dari file asli, yang tetap ada di antrean.

Apakah AVIF ke JPG bisa dipakai di browser seluler?

Ya. Buka alat ini di browser ponsel Anda, pilih file AVIF dari unduhan atau galeri, dan unduh JPG-nya. Konversi berjalan di ponsel, dan file terunduh ke perangkat Anda. Pertahankan batch ponsel tetap kecil, karena file AVIF besar membutuhkan waktu untuk didekode di seluler.

Kapan sebaiknya saya mengubah AVIF ke JPG daripada AVIF ke PNG?

Pilih JPG ketika tujuannya memang menuntutnya atau ketika kompatibilitas paling penting, karena JPG terbuka di mana saja dan file lebih kecil. Pilih PNG ketika Anda perlu menjaga transparansi atau berencana mengedit gambar berkali-kali, karena PNG bersifat lossless dan mempertahankan kanal alpha.
