Cara Mengubah DPI Gambar

Ubah DPI gambar menjadi 72, 150, 300, atau 600 dalam 4 langkah — atau nilai kustom apa pun hingga 2400. Dukungan batch, unduhan ZIP, dan lencana Verified DPI.

Gambar Anda sudah siap, tapi platform meminta 300 DPI sementara file Anda bilang 72, atau tidak bilang apa-apa sama sekali. Perbaikannya memakan waktu kurang dari satu menit begitu Anda tahu langkah-langkahnya.

Panduan ini memandu Anda mengubah DPI gambar dalam empat langkah praktis: unggah, pilih nilainya, verifikasi lencananya, dan unduh. Panduan ini juga membahas batch, tangkapan layar, dan masalah umum yang sering menjebak orang.

Tanpa software yang perlu diinstal, tanpa akun yang perlu dibuat, dan tanpa piksel yang dirugikan. Perubahan ini adalah edit metadata, sehingga gambar Anda terlihat persis sama saat selesai.

Yang Anda Butuhkan Sebelum Memulai

Anda membutuhkan file gambar dalam format JPEG atau PNG. Hanya kedua format itulah yang menyimpan tag DPI dengan cara yang standar, sehingga alat hanya menerima keduanya.

Ketahui nilai DPI yang diinginkan tujuan Anda. Printer buku dan jurnal biasanya meminta 300, cetakan draf menerima 150, dan layar senang dengan 72 atau 96.

Periksa dimensi piksel sebelum memulai. DPI tidak bisa menyelamatkan gambar dengan piksel terlalu sedikit, jadi konfirmasikan dimensinya cukup besar untuk ukuran cetak yang Anda butuhkan.

Browser adalah satu-satunya software yang Anda butuhkan. Alat ini berjalan di Chrome, Safari, Firefox, dan Edge, di desktop dan di HP, tanpa ekstensi.

Langkah 1: Unggah File JPEG atau PNG Anda

Buka pengubah DPI gambar dan seret file Anda ke area unggah. Anda bisa menjatuhkan satu gambar atau satu batch penuh sekaligus.

Anda juga bisa mengklik area unggah untuk mencari file, atau menempel tangkapan layar dari clipboard dengan Ctrl+V untuk langsung memberinya stempel tanpa menyimpannya terlebih dahulu.

Setiap file muncul dalam daftar dengan DPI saat ini ditampilkan di sampingnya. Banyak foto akan terbaca Before: Not set, yang artinya file belum punya tag DPI.

Jika sebuah file ditolak, periksa formatnya. File WebP, HEIC, BMP, GIF, dan SVG tidak didukung di sini, dan alat akan memberi tahu Anda hal itu, bukan gagal secara diam-diam.

Langkah 2: Pilih Preset atau DPI Kustom

Pilih satu dari lima preset: 72 untuk layar, 96 untuk Windows, 150 untuk cetak draf, 300 untuk cetak tinggi, atau 600 untuk pekerjaan arsip. Untuk sebagian besar pekerjaan penerbitan, 300 adalah pilihan yang tepat.

Jika tujuan Anda meminta angka yang berbeda, ketik angka itu di kolom DPI kustom. Angka bulat apa pun dari 1 sampai 2400 diterima, sehingga nilai seperti 200 atau 350 bisa dipakai.

Nilai yang sama berlaku untuk setiap file dalam batch. Jika gambar yang berbeda butuh nilai DPI yang berbeda, proses dalam batch terpisah, satu nilai setiap kalinya.

Periksa kembali angkanya sebelum memproses. Salah ketik yang mengubah 300 menjadi 3000 mudah terjadi dan akan ditulis dengan setia, jadi baca kolom itu sekali lagi.

Langkah 3: Proses dan Cari Lencana Terverifikasi

Klik untuk memproses file-file itu. Alat menulis ulang tag DPI di header setiap file, lalu membaca kembali file untuk mengonfirmasi nilai baru tersimpan dengan benar.

Setiap file yang berhasil menampilkan lencana Verified DPI. Lencana itu adalah konfirmasi Anda bahwa file akan melaporkan DPI yang sama di pembaca mana pun yang mengikuti standar, termasuk platform penerbitan Anda.

Jika sebuah file menampilkan error, baca pesannya. JPEG yang rusak atau format yang tidak didukung akan ditandai dengan jelas, dan sisa batch tetap diproses secara normal.

Jangan lewatkan langkah verifikasi. File yang diproses tapi tidak terverifikasi hanyalah tebakan, dan pengiriman yang gagal menghabiskan waktu jauh lebih banyak daripada sekilas melihat lencana.

Langkah 4: Unduh File yang Sudah Diberi Stempel

Unduh setiap file satu per satu, atau klik unduhan ZIP untuk mendapatkan seluruh batch dalam satu arsip. ZIP mempertahankan nama file aslinya, sehingga gambar langsung kembali ke proyek Anda.

File output diberi nama yang jelas agar Anda bisa membedakannya dari file asli. Simpan juga file aslinya, sehingga Anda selalu punya salinan yang tidak tersentuh untuk kembali.

Buka satu file yang diunduh di platform Anda atau di penampil gambar dan konfirmasikan DPI-nya terbaca dengan benar. Pemeriksaan akhir itu memakan waktu beberapa detik dan menangkap kesalahpahaman sebelum pengiriman.

Kirim file yang sudah diberi stempel ke platform Anda. Jika platform masih mengeluh, masalahnya biasanya dimensi piksel, bukan DPI, jadi periksa itu berikutnya.

Mengubah DPI untuk Satu Batch Penuh

Buku, katalog, dan artikel jurnal membutuhkan puluhan gambar pada DPI yang sama. Alur kerja batch menangani semuanya dalam satu proses dengan satu preset.

Jatuhkan seluruh folder ke dalam alat dan pilih nilainya sekali. Setiap file diberi stempel, diverifikasi, dan dicantumkan bersama lencananya, sehingga Anda bisa melihat sekilas apakah ada file yang gagal.

Unduh batch sebagai satu ZIP. Arsip itu mempertahankan nama file, dan itu penting saat gambar dirujuk berdasarkan nama di dokumen atau file layout.

Jika beberapa file dalam batch adalah WebP atau HEIC, konversi dulu. Konverter gambar mengubahnya menjadi JPG atau PNG, lalu mereka bisa bergabung dengan batch berikutnya.

DPI untuk Penerbitan Cetak dan Jurnal

Platform buku seperti Amazon KDP memeriksa DPI pada setiap gambar dalam naskah. Sampul atau gambar interior yang diberi tag di bawah minimum akan ditolak, dan seluruh pengiriman terhenti.

Jurnal akademik lebih ketat lagi. Banyak yang menuntut 300 DPI untuk foto dan 600 DPI untuk line art, dan mereka memeriksa tag itu sebelum memeriksa isinya.

Alur kerjanya sama di kedua kasus: konfirmasi dimensi piksel dulu, beri stempel DPI kedua, verifikasi lencana ketiga, dan kirim keempat. Melewatkan langkah pertama adalah penyebab paling umum dari penolakan kedua.

Untuk line art, gunakan preset 600 DPI. Garis tipis dan teks kecil membutuhkan kerapatan ekstra, dan gambar garis 300 DPI bisa terlihat bergerigi saat dicetak pada ukuran penuh.

Memperbaiki File 72 DPI yang Ditolak

Penolakan 72 DPI adalah masalah DPI yang paling umum, dan juga yang paling mudah diperbaiki. Pikselnya biasanya baik-baik saja; hanya tag metadata yang salah.

Unggah file, pilih preset 300 DPI, lalu proses. Alat menulis ulang tagnya, memverifikasinya, dan file yang diunduh lolos pemeriksaan platform.

Sebelum mengirim ulang, konfirmasikan dimensinya. File 72 DPI yang juga kecil dalam piksel akan gagal lagi, kali ini pada dimensi, dan tidak ada nilai DPI yang bisa memperbaikinya.

Jika file itu tangkapan layar, perbaikan yang sama berlaku. Tangkapan layar biasanya membawa tag 72 atau 96 DPI, dan memberi stempel 300 DPI membuatnya bisa diterima alur kerja cetak, asalkan pikselnya cukup.

DPI untuk Tangkapan Layar

Tangkapan layar adalah perbaikan DPI tercepat, karena Anda bisa menempelnya langsung dari clipboard. Salin layar, tekan Ctrl+V di alat, dan tangkapan layar siap diberi stempel.

Pilih 300 DPI untuk tangkapan layar yang akan muncul di manual cetak atau buku. Pikselnya adalah apa pun yang ditangkap layar, tapi tagnya akan memuaskan alur kerja cetak.

Bersikaplah jujur tentang batasnya. Tangkapan layar dari kotak dialog kecil punya sedikit piksel, dan memberinya stempel 300 DPI menjadikannya cetakan yang sangat kecil, bukan cetakan besar yang tajam.

Untuk tangkapan layar yang harus tercetak besar, tangkap dengan skala tampilan yang lebih tinggi terlebih dahulu. Tangkapan layar yang diambil di layar retina membawa piksel dua kali lipat dan tercetak dua kali lebih besar.

Menghapus atau Melepas Tag DPI

Terkadang Anda tidak menginginkan tag DPI sama sekali, bukan tag yang berbeda. Alat ini bisa menghapus metadata DPI dari file, sambil membiarkan piksel tidak tersentuh.

Menghapus berguna saat file membawa tag yang salah dan membingungkan software Anda. Foto yang diberi tag dengan nilai aneh bisa membuat program layout menskalakannya secara tak terduga, dan menghapus tag itu mengatur ulang perilakunya.

Untuk menghapus tag, gunakan opsi remove di alat dan proses file. File yang diunduh tidak punya metadata DPI, dan software yang membukanya akan kembali ke default-nya sendiri.

Hapus tag hanya saat Anda punya alasan. Sebagian besar alur kerja penerbitan menginginkan tag ada, dan file tanpa tag bisa ditolak semudah file dengan tag yang salah.

Troubleshooting Format yang Tidak Didukung

Jika alat menolak file Anda, hal pertama yang harus diperiksa adalah formatnya. File WebP, HEIC, BMP, GIF, dan SVG tidak didukung, dan alat akan menyatakannya dengan jelas.

Konversi file ke JPG atau PNG lalu coba lagi. Konverter gambar menangani WebP dan HEIC, dan konversi itu mempertahankan piksel sambil memberi file format yang bisa membawa tag DPI.

Waspadai file yang salah nama. File WebP yang disimpan dengan ekstensi .jpg akan ditolak meskipun namanya terlihat benar, karena alat membaca isi file yang sebenarnya.

Saat ragu, buka file di penampil gambar dan simpan ulang sebagai JPG atau PNG. Penyimpanan ulang yang bersih menjamin formatnya cocok dengan ekstensinya.

Troubleshooting File yang Rusak

JPEG yang rusak akan gagal dengan pesan error, dan sisa batch akan terus diproses. Error itu spesifik untuk file tersebut, bukan untuk alatnya.

Coba buka file di penampil gambar. Jika penampil juga gagal, file itu rusak dan perlu diunduh ulang atau diekspor ulang dari sumbernya.

File yang terbuka di penampil tapi gagal di alat mungkin headernya rusak. Menyimpan ulang dari penampil akan menulis header baru, dan file baru itu biasanya bisa diproses dengan baik.

Jangan pernah mengirim file yang gagal diproses. File rusak yang lolos ke pekerjaan cetak bisa menghentikan seluruh pengiriman, jadi perbaiki atau ganti sebelum Anda melanjutkan.

Memeriksa Hasil Setelah Mengunduh

Setelah mengunduh, buka satu file dan konfirmasikan DPI-nya. Di Windows, klik kanan file, pilih Properties, dan lihat tab details. Di Mac, buka di Preview dan periksa inspectornya.

Angkanya harus cocok dengan yang Anda pilih. JPEG yang diberi stempel 300 DPI terbaca kembali sebagai 300, sementara PNG bisa terbaca sebagai 299 karena cara PNG menyimpan resolusi dalam piksel per meter.

Jika angkanya salah, proses ulang file asli, bukan file yang sudah diunduh. Memberi stempel ulang pada file yang sudah diberi stempel memang bisa, tapi memulai dari file asli menjaga rantai perubahan tetap bersih.

Catat nilai yang Anda pakai untuk setiap proyek. Saat gambar yang sama dikirim ke platform kedua dengan aturan berbeda, catatan itu memberi tahu apa yang harus diubah tanpa memeriksa ulang setiap file.

DPI untuk Gambar E-commerce dan Marketplace

Gambar marketplace hidup di layar, sehingga DPI tampak tidak relevan, tapi penjual tetap tersandung olehnya. Kebingungan biasanya dimulai saat halaman bantuan marketplace menyebut DPI berdampingan dengan dimensi piksel.

Untuk listing produk, dimensi piksel adalah aturan yang penting. Marketplace yang menginginkan 1000 piksel di sisi terpanjang memeriksa jumlah piksel, bukan tag DPI, dan file yang diberi stempel 300 DPI dengan hanya 600 piksel tetap gagal.

Meski begitu, memberi stempel 300 DPI pada gambar marketplace tidak merugikan dan kadang membantu. Beberapa alat penjual dan layanan print-on-demand membaca tag itu, dan nilai yang benar menjaga alur kerja itu tetap lancar.

Pendekatan praktisnya adalah memperbaiki piksel dulu, lalu DPI. Konfirmasikan dimensi dengan pemeriksa dimensi, ubah ukuran bila perlu, lalu beri stempel 300 DPI sebagai langkah akhir sebelum mengunggah gambar listing.

Untuk produk print-on-demand seperti mug, kaos, dan poster, DPI sangat penting. Produknya dicetak, sehingga standar 300 DPI yang sama berlaku, dan hitungan piksel menentukan seberapa besar desain bisa dicetak.

Periksa persyaratan print-on-demand untuk setiap produk sebelum mengunggah. Desain yang cocok untuk mug bisa jadi terlalu kecil untuk poster, dan tag DPI saja tidak akan menjembatani selisih itu.

Penjual di Shopee dan Tokopedia sering mengunggah foto produk langsung dari HP. Foto HP modern sebenarnya punya piksel yang cukup, tapi tag DPI-nya sering kosong atau 72, dan itu membingungkan alat penjual tertentu.

Untuk listing, fokuslah pada piksel dan pencahayaan terlebih dahulu. Foto yang terang dan tajam dengan latar bersih menjual lebih baik daripada foto yang sekadar diberi stempel 300 DPI.

Layanan print-on-demand lokal, seperti cetak kaos dan mug, memakai standar yang sama dengan layanan global. Desain untuk mug membutuhkan DPI dan piksel yang cukup, karena produknya dicetak secara fisik.

Sebelum mengunggah desain ke layanan print-on-demand, unduh template ukuran dari penyedia itu. Template memberi tahu dimensi piksel dan DPI yang tepat untuk setiap produk, sehingga Anda tidak menebak.

Simpan satu file master beresolusi tinggi untuk setiap desain produk. Dari file master itu Anda bisa mengekspor versi marketplace, versi cetak, dan versi media sosial tanpa kehilangan kualitas.

Menerapkan Nilai DPI yang Berbeda

Proyek berubah, dan file yang diberi stempel 300 DPI mungkin nanti butuh 600 DPI untuk arsip atau cetakan seni rupa. Alat ini memungkinkan Anda menerapkan nilai baru ke file yang sama.

Unggah file lagi, pilih preset baru atau nilai kustom, lalu proses. Setiap proses bersifat lossless, sehingga piksel tidak pernah terdegradasi oleh pemberian stempel berulang.

Anda juga bisa bergerak sebaliknya, dari 600 turun ke 300, dengan keamanan yang sama. Header ditulis ulang setiap kali dan data piksel tidak pernah disentuh.

Pertanyaan umum

Berapa lama waktu yang dibutuhkan untuk mengubah DPI gambar?

Hitungan detik. Alat menulis ulang beberapa byte di header file dan tidak meng-encode ulang piksel apa pun, sehingga batch yang besar pun selesai dengan cepat. Waktu yang Anda habiskan sebagian besar untuk mengunggah dan mengunduh, bukan untuk memproses.

Bisakah saya mengubah DPI banyak gambar sekaligus?

Bisa. Jatuhkan seluruh batch ke dalam alat, pilih satu nilai DPI, dan setiap JPEG dan PNG dalam batch diberi stempel dalam satu proses. Unduh hasilnya sebagai satu file ZIP dengan nama file asli tetap terjaga.

Apa yang terjadi jika saya salah memasukkan DPI kustom?

Alat menulis angka berapa pun yang Anda masukkan, dari 1 sampai 2400, dan memverifikasinya dengan lencana. Jika Anda menyadari kesalahannya, proses ulang saja file aslinya dengan nilai yang benar. Setiap proses bersifat lossless, sehingga kesalahan itu hanya menghabiskan waktu satu menit, bukan gambarnya.

Apakah mengubah DPI memengaruhi kualitas atau warna gambar?

Tidak. Hanya metadata resolusi di header yang berubah. Piksel, kompresi, data EXIF, dan profil warna ICC semuanya tetap persis seperti sebelumnya. Gambar terlihat identik di layar sebelum dan sesudahnya.

Bisakah saya menempel tangkapan layar dan langsung mengubah DPI-nya?

Bisa. Salin tangkapan layar, tekan Ctrl+V di alat, dan tangkapan itu muncul siap diberi stempel. Pilih 300 DPI untuk penggunaan cetak, proses, lalu unduh hasilnya. Ini rute tercepat dari screen capture ke file siap cetak.

Kenapa file saya ditolak oleh pengubah DPI?

Penyebab umumnya adalah format yang tidak didukung seperti WebP atau HEIC, file yang melebihi batas ukuran, atau JPEG yang rusak. Konversi dulu format yang tidak didukung menjadi JPG atau PNG, dan ekspor ulang file apa pun yang tidak bisa dibuka di penampil gambar.
