Cara Mengubah Format Gambar

Ubah gambar apa pun ke JPG, PNG, atau WebP dalam enam langkah cepat. Unggah, pilih format, atur kualitas, pratinjau, lalu unduh — semua di browser.

Mengubah format gambar terdengar teknis, tetapi seluruh pekerjaan itu memakan waktu kurang dari satu menit. Anda mengunggah file, memilih format yang dibutuhkan, lalu mengunduh hasilnya.

Tidak ada perangkat lunak yang harus diinstal, tidak ada akun yang harus dibuat, dan tidak ada penantian unggahan ke server yang jauh. Semuanya terjadi di browser Anda, di perangkat Anda sendiri.

Panduan ini membahas setiap langkah secara berurutan, beserta pengaturan yang penting dan kesalahan yang harus dihindari. Pada akhirnya, Anda akan mengonversi gambar apa pun dengan percaya diri.

Sebelum Memulai: Yang Anda Butuhkan

Anda membutuhkan file gambar dan browser modern. Chrome, Edge, Firefox, dan Safari semuanya bisa dipakai, di desktop maupun di ponsel. Tidak ada yang perlu diunduh terlebih dahulu.

Carilah file asli terbaik yang Anda miliki. Konversi tidak bisa menambah detail, jadi mulailah dari salinan dengan kualitas tertinggi. Jika Anda punya JPG dan PNG dari gambar yang sama, gunakan PNG-nya.

Ketahui format mana yang Anda butuhkan sebelum memulai. Formulir yang meminta JPG akan menolak PNG, dan website yang menginginkan WebP tidak akan menerima BMP. Periksa dulu persyaratannya agar Anda tidak mengonversi dua kali.

File hingga 20MB diterima di sini. Itu mencakup foto ponsel, hasil kamera, dan screenshot besar. Jika file Anda lebih besar, perkecil dulu dengan kompresor.

Langkah 1: Unggah Gambar Anda

Buka alat Konversi Gambar di browser Anda. Anda akan melihat area unggahan besar di tengah halaman.

Seret file gambar Anda ke area itu, atau klik untuk membuka pemilih file. Anda juga bisa menempel screenshot langsung dari clipboard dengan Ctrl+V, yang praktis untuk konversi cepat.

File itu muncul di antrean beserta nama, dimensi, dan ukurannya. Thumbnail menunjukkan persis gambar mana yang Anda muat, sehingga file yang salah mudah dikenali.

Anda bisa menambahkan lebih banyak file pada tahap ini jika ingin mengonversi beberapa sekaligus. Setiap file terkonversi secara mandiri, dan Anda mengunduhnya bersama-sama sebagai ZIP nanti.

Langkah 2: Pilih Format Output

Carilah pemilih Format Output lalu pilih JPG, PNG, atau WebP. Ini adalah satu-satunya pilihan terpenting dalam seluruh proses, jadi luangkan waktu sejenak untuk berpikir.

Pilih JPG untuk foto, terutama ketika file dikirim ke formulir, email, atau program lama. JPG berfungsi di mana saja dan menjaga foto tetap kecil.

Pilih PNG ketika gambar memiliki transparansi, teks tajam, atau warna datar. Logo, ikon, dan screenshot dengan teks yang harus terbaca semuanya termasuk PNG.

Pilih WebP ketika gambar ditujukan untuk website. Format ini lebih kecil daripada JPG pada kualitas yang sama dan mendukung transparansi, sehingga menjadi serba bisa terbaik untuk web.

Langkah 3: Atur Slider Kualitas

Jika Anda memilih JPG atau WebP, slider kualitas akan muncul. Slider ini berjalan dari 10 persen hingga 100 persen, dan ia mengontrol seberapa banyak detail yang dipertahankan encoder.

Untuk sebagian besar foto, 80 hingga 85 persen adalah titik ideal. File menyusut banyak, tetapi gambar masih tampak bersih pada ukuran tampilan normal.

Naikkan slider ke 90 persen atau lebih untuk gambar yang akan dicetak atau diedit lebih lanjut. Cetakan memperlihatkan cacat yang disembunyikan layar, dan mengedit file berkualitas rendah hanya memperburuk keadaan.

Jika Anda memilih PNG, slider itu menghilang. PNG bersifat lossless, jadi tidak ada level kualitas yang bisa dipilih, dan file menyimpan setiap piksel persis seperti aslinya.

Langkah 4: Tangani Transparansi (Hanya JPG)

Langkah ini hanya penting ketika gambar sumber memiliki area transparan dan targetnya adalah JPG. Karena JPG tidak bisa menyimpan transparansi, area tersebut membutuhkan warna isian.

Klik swatch Warna Isian Transparansi untuk memilih warna. Putih adalah bawaan dan cocok untuk sebagian besar dokumen, halaman web, dan formulir.

Pilih hitam jika gambar akan diletakkan di latar gelap, atau masukkan kode hex untuk mencocokkan warna website tertentu secara persis. Latar yang cocok membuat logo tampak seperti memang berada di sana.

Jika target Anda PNG atau WebP, lewati langkah ini sepenuhnya. Kedua format itu mempertahankan transparansi, sehingga area yang tembus pandang tetap tembus pandang tanpa isian apa pun.

Langkah 5: Konversi dan Pratinjau Hasilnya

Klik tombol Convert lalu tunggu satu atau dua detik. Alat ini mendekode gambar Anda, menggambarnya ulang di canvas, lalu mengenkodenya dalam format baru.

Setiap kartu hasil konversi menampilkan ukuran file baru di samping ukuran lama. Perbandingan itu langsung memberi tahu apakah konversi menghemat ruang.

Klik Compare pada sebuah kartu untuk membuka penampil berdampingan. Seret gagang pemisah melintasi gambar lalu perhatikan wajah, teks, dan tepinya dengan saksama.

Jika hasilnya tampak lembut atau warnanya salah, ubah kualitas atau warna matte lalu konversi lagi. File asli tetap ada di antrean, jadi Anda tidak perlu mengunggah ulang.

Langkah 6: Unduh Gambar Hasil Konversi

Klik tombol Download pada satu kartu untuk menyimpan satu file. Nama file mempertahankan nama asli Anda dengan ekstensi baru, sehingga mudah ditemukan.

Jika Anda mengonversi beberapa file, klik Download All untuk mendapatkan arsip ZIP berisi semuanya. Nama ZIP itu adalah converted_images_compressmypic.zip.

Periksa file yang diunduh sekali sebelum Anda menggunakannya. Buka di penampil foto Anda, pastikan tampilannya benar, dan periksa bahwa formatnya sesuai dengan yang Anda inginkan.

Simpan juga file aslinya. JPG hasil konversi tidak pernah bisa menjadi PNG yang sempurna lagi, jadi file asli adalah jaring pengaman Anda jika nanti butuh format lain.

  1. Buka Konverter Gambar lalu unggah gambar Anda.
  2. Pilih JPG, PNG, atau WebP sebagai format output.
  3. Atur slider kualitas dan warna isian transparansi jika perlu.
  4. Konversi, pratinjau dengan Compare, lalu unduh hasilnya.

Mengonversi Gambar di Ponsel

Konverter bekerja dengan cara yang sama di browser ponsel. Buka halamannya, ketuk area unggahan, lalu pilih foto dari galeri Anda.

Foto iPhone adalah konversi ponsel yang paling umum. File HEIC dari rol kamera terkonversi ke JPG dalam hitungan detik, dan hasilnya terbuka di aplikasi apa pun.

Kontrol sentuh berfungsi untuk setiap pengaturan. Slider kualitas, pemilih format, dan swatch warna isian semuanya bisa diketuk, dan penampil Compare berfungsi dengan seretan jari.

Unduhan masuk ke folder Downloads ponsel Anda. Di iPhone, periksa aplikasi Files; di Android, periksa folder Downloads di pengelola file Anda.

Mengonversi Banyak File Sekaligus

Letakkan seluruh batch ke dalam antrean, jangan mengonversi satu file demi satu file. Alat ini menerima format campuran, sehingga JPG, PNG, dan HEIC bisa berada dalam satu batch yang sama.

Setiap file terkonversi ke format output yang sama dengan yang Anda pilih. Jika Anda membutuhkan format berbeda untuk file yang berbeda, jalankan dua batch, bukan satu.

Perhatikan lencana kesalahan saat batch berjalan. Satu file korup menampilkan peringatan tanpa menghentikan file lainnya, sehingga file yang bagus tetap selesai.

Gunakan Download All untuk mengambil seluruh batch sebagai satu ZIP. Itu jauh lebih cepat daripada mengetuk Download pada dua puluh kartu terpisah.

Memperbaiki Masalah Umum

Jika sebuah file gagal terkonversi, periksa dulu formatnya. File bernama .jpg yang sebenarnya adalah WebP akan membingungkan dekoder, jadi pastikan format aslinya sebelum mencoba lagi.

Jika output terlihat terlalu besar, turunkan slider kualitas sepuluh poin lalu konversi lagi. Penurunan dari 90 ke 80 persen sering memangkas ukuran file hingga setengah dengan sedikit perubahan yang terlihat.

Jika logo transparan mendapat kotak hitam di JPG, Anda lupa warna matte. Atur warna isian ke putih atau warna halaman Anda lalu konversi lagi.

Jika GIF animasi keluar sebagai gambar diam, itu memang sudah seharusnya. Konverter hanya menggambar frame pertama, jadi gunakan Kompresor GIF ketika gerakannya penting.

Memeriksa Hasil Sebelum Mengirimnya

Buka file hasil konversi di aplikasi yang akan menggunakannya. JPG untuk formulir harus terbuka di penampil foto Anda; WebP untuk website harus terbuka di browser Anda.

Periksa ukuran file terhadap batas apa pun. Formulir yang membatasi unggahan hingga 2MB akan menolak JPG 3MB, meskipun formatnya sudah benar.

Perbesar gambar ke ukuran penuh sekali. Teks kecil, garis tipis, dan wajah adalah tempat pertama kualitas rendah terlihat, dan perbesaran cepat menangkap masalah lebih awal.

Pastikan dimensinya tidak berubah. Konversi mempertahankan lebar dan tinggi, tetapi tetap layak dilirik, terutama untuk gambar dengan aturan ukuran yang ketat.

Kapan Menggunakan Konverter Khusus

Konverter umum sempurna untuk pekerjaan sehari-hari, tetapi alat khusus menangani pasangan tertentu dengan lebih baik. Konverter HEIC ke JPG disetel untuk foto iPhone, dengan kualitas bawaan 90 persen yang cocok untuk foto tersebut.

Untuk logo, konverter SVG ke PNG menawarkan pilihan skala hingga 8000 piksel, yang tidak dimiliki konverter umum. Skala penting ketika ikon kecil harus menjadi file cetak besar.

Untuk seluruh folder, Konversi Gambar Massal menambahkan akhiran nama file dan ringkasan batch, yang membantu ketika Anda mengonversi ratusan file sekaligus.

Gunakan konverter umum ketika Anda punya batch campuran dan kebutuhan sederhana. Beralihlah ke alat khusus ketika pekerjaan itu punya persyaratan khusus.

Memilih Antara Konversi Tunggal dan Batch

Konversi tunggal cocok untuk pekerjaan sekali saja, seperti foto untuk formulir atau logo untuk dokumen. Konverter umum menanganinya dalam hitungan detik, dan Anda langsung mengunduh hasilnya.

Konversi batch cocok untuk folder berisi gambar yang semuanya membutuhkan format yang sama. Konverter massal menerapkan satu pengaturan ke setiap file, yang jauh lebih cepat daripada mengonversinya satu per satu.

Gunakan konverter tunggal ketika file-file itu membutuhkan pengaturan berbeda. Foto yang menginginkan kualitas 85 persen dan logo yang menginginkan PNG tidak bisa berbagi satu pengaturan batch, jadi konversi secara terpisah.

Gunakan konverter batch ketika file-file itu berbagi tujuan. Pustaka gambar website, katalog produk, atau album liburan semuanya menginginkan satu format dan satu level kualitas, dan itulah yang dilakukan konversi batch.

Ketika ragu, mulailah dengan satu file. Konversi satu gambar, periksa hasilnya, dan jika pengaturannya berhasil, terapkan ke seluruh batch dengan percaya diri.

Mengonversi Gambar dari Lampiran Email

Gambar sering tiba sebagai lampiran email dalam format yang salah. Klien mengirim foto HEIC, rekan kerja mengirim screenshot BMP, dan Anda membutuhkan JPG sebelum bisa memakai keduanya.

Simpan dulu lampiran itu ke perangkat Anda, lalu letakkan ke konverter. Mengonversi langsung dari aplikasi email jarang berhasil, karena file harus sudah ada di perangkat Anda.

Periksa ukuran lampiran sebelum mengonversi. Layanan email sering mengompres gambar secara otomatis, sehingga lampiran itu mungkin sudah berkualitas lebih rendah daripada foto aslinya.

Setelah mengonversi, balaslah dengan JPG yang dilampirkan, bukan dengan meneruskan file asli. Penerima bisa membuka JPG di mana saja, sementara format asli mungkin gagal di perangkat mereka juga.

Simpan lampiran asli di email Anda sebagai cadangan. Jika konversi gagal, Anda bisa mengunduhnya lagi dan mencoba pengaturan lain tanpa meminta pengirim mengirim ulang.

Mengonversi Gambar untuk Media Sosial

Platform media sosial menerima unggahan JPG dan PNG, dan mereka tetap mengonversi semuanya ke format mereka sendiri. JPG berkualitas tinggi adalah input paling sederhana untuk sebagian besar platform.

Periksa aturan ukuran dan dimensi platform sebelum mengonversi. Instagram, Facebook, dan X masing-masing punya ukuran yang disukai, dan konversi tidak bisa memperbaiki gambar yang ukurannya salah.

Untuk foto profil, konversi ke JPG pada kualitas 90 persen. Ukurannya yang kecil menjaga wajah tetap tajam, dan file diunggah dengan cepat bahkan pada koneksi lambat.

Untuk postingan berisi teks, seperti grafis pengumuman, gunakan PNG atau WebP. Teks tetap lebih tajam dalam format itu, sementara JPG mengaburkan huruf-huruf kecil.

Unduh file hasil konversi lalu unggah dari perangkat Anda, jangan membagikan tautan. Unggahan langsung mempertahankan kualitas yang Anda pilih, sementara tautan yang dibagikan bisa memicu putaran kompresi lain.

Apa yang Harus Dilakukan Ketika Hasilnya Tampak Salah

Jika gambar hasil konversi tampak pudar, profil warnanya mungkin bergeser. Bandingkan dengan file asli dan periksa apakah perbedaannya penting untuk tujuannya, karena sebagian besar pergeseran itu halus.

Jika gambar tampak buram, pengaturan kualitasnya terlalu rendah atau sumbernya memang sudah lembut. Naikkan kualitas ke 90 persen lalu konversi lagi dari file asli.

Jika warnanya tampak salah, sumbernya mungkin memakai ruang warna yang tidak biasa seperti CMYK. Konversi ekspor RGB dari gambar itu, karena browser dan layar mengharapkan RGB.

Jika format filenya salah, periksa pemilih output sebelum mengonversi. Sangat mudah membiarkan format tetap di PNG padahal Anda bermaksud JPG, dan perbaikannya hanya satu klik.

Jika tidak ada yang membantu, coba konverter khusus untuk pasangan format itu. Alat HEIC ke JPG dan alat SVG ke PNG menangani pasangan spesifik mereka dengan bawaan yang disetel dan tidak ditawarkan konverter umum.

Perhatikan juga nama file sebelum mengunggah. Nama seperti IMG_20261117.jpg tidak memberi tahu Anda apa isinya, dan setelah dikonversi Anda akan kesulitan menemukannya lagi. Ganti nama menjadi sesuatu yang deskriptif, seperti foto-pantai-bali.jpg, sebelum memulai konversi, agar hasil akhirnya langsung mudah dikenali.

Ukuran file juga layak diperiksa sebelum dikirim ke tujuan. Formulir pendaftaran, portal lowongan, dan sistem sekolah sering membatasi unggahan hingga 2MB atau 5MB. Jika JPG hasil konversi masih terlalu besar, kompres dulu ke ukuran yang diminta, jangan mengonversi ulang dengan kualitas yang lebih rendah secara membabi buta.

Simpan pengaturan yang berhasil untuk pekerjaan yang berulang. Jika Anda sering mengonversi foto untuk toko online, catat format dan kualitas yang dipakai, misalnya WebP 80 persen dengan matte putih. Catatan satu baris itu membuat batch berikutnya konsisten tanpa perlu menebak-nebak lagi.

Terakhir, biasakan memeriksa hasil di perangkat tujuan, bukan hanya di komputer Anda. Gambar yang tampak sempurna di layar laptop bisa tampak berbeda di ponsel penerima. Buka file hasil konversi di ponsel Anda sekali, dan Anda akan tahu persis apa yang dilihat penerima.

Itulah seluruh prosesnya: unggah, pilih, konversi, unduh. Pertanyaan umum

Berapa lama waktu yang dibutuhkan untuk mengonversi format gambar?

Biasanya satu atau dua detik per file di perangkat modern, karena konversi berjalan secara lokal di browser Anda. Foto yang sangat besar atau file HEIC mungkin memakan waktu sedikit lebih lama karena dekoder harus membaca lebih banyak data. Konversi batch memproses setiap file secara bergiliran, jadi dua puluh file memakan waktu kira-kira dua puluh kali lebih lama.

Bisakah saya mengonversi format gambar di ponsel tanpa aplikasi?

Bisa. Buka konverter di browser ponsel Anda, ketuk area unggahan, lalu pilih foto dari galeri. Semua pengaturan berfungsi dengan sentuhan, dan file hasil konversi terunduh ke ponsel Anda. Tidak perlu instalasi aplikasi atau akun.

Format apa yang harus saya konversi untuk foto lamaran kerja?

JPG adalah pilihan paling aman untuk portal lowongan dan formulir lamaran, karena semua sistem menerimanya. Jaga kualitasnya pada 85 persen atau lebih agar foto Anda tampak profesional. Periksa dulu aturan portalnya, karena beberapa juga menuntut ukuran file maksimum atau dimensi yang persis.

Bisakah saya mengonversi screenshot ke format yang lebih kecil?

Bisa. Screenshot yang disimpan sebagai PNG sering berukuran beberapa megabyte, dan mengubahnya ke JPG pada kualitas 80 persen biasanya memangkas ukurannya secara drastis. Jika screenshot itu berisi teks yang harus tetap tajam, gunakan WebP, yang mempertahankan tepi lebih baik pada ukuran kecil.

Mengapa file WebP hasil konversi saya lebih besar daripada JPG aslinya?

Ini terjadi pada JPG yang sederhana atau sudah terkompres, di mana WebP tidak punya banyak lagi yang bisa dihemat. Ini juga terjadi ketika slider kualitas diatur sangat tinggi. Coba turunkan kualitas ke 80 persen, atau pertahankan JPG jika WebP itu ternyata tidak lebih kecil.

Bisakah saya mengonversi gambar yang sama ke dua format tanpa mengunggah ulang?

Bisa. Setelah konversi pertama, ubah format output lalu konversi lagi. File asli tetap ada di antrean, sehingga Anda bisa menghasilkan JPG dan WebP dari satu unggahan. Ingatlah untuk mengunduh setiap hasil sebelum berganti format.
