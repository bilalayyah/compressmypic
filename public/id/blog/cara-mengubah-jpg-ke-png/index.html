Cara Mengubah JPG ke PNG

Ubah gambar JPG ke PNG dalam hitungan detik, satu file atau 20 file sekaligus. Unggah, konversi, bandingkan, lalu unduh — semua di browser.

Mengonversi JPG ke PNG adalah pekerjaan sederhana, tetapi layak dilakukan dengan benar. Konversi yang benar menulis ulang file sebagai PNG yang asli, bukan sekadar JPG yang diganti namanya.

Proses ini memakan waktu beberapa detik per file, dan Anda bisa mengonversi hingga dua puluh gambar sekaligus. Semuanya berjalan di browser Anda, tanpa ada yang perlu diinstal.

Panduan ini membahas setiap langkah, dan menjelaskan apa yang harus diperiksa sebelum Anda memakai hasilnya.

Sebelum Memulai: Ketahui Alasan Anda Mengonversi

Tanyakan pada diri sendiri untuk apa PNG itu. Mengedit, pekerjaan desain, dan hamparan teks adalah alasan yang bagus. Membuat foto lebih tajam atau lebih kecil bukan alasan, karena PNG tidak melakukan keduanya.

Periksa apakah PNG memang dibutuhkan. Beberapa alat menuntutnya, tetapi banyak yang menerima JPG atau WebP, yang jauh lebih kecil untuk foto.

Carilah file JPG asli terbaik yang Anda miliki. PNG akan mempertahankannya secara persis, termasuk cacatnya, jadi mulailah dari salinan berkualitas tertinggi.

File hingga 25MB masing-masing diterima. Itu mencakup ekspor kamera beresolusi tinggi dan karya digital lebar tanpa persiapan apa pun.

Langkah 1: Buka Alat JPG ke PNG

Buka alat JPG ke PNG di browser Anda. Halaman ini berfungsi di Windows, Mac, Linux, ChromeOS, Android, dan iOS.

Anda akan melihat area unggahan dan tombol konversi. Tidak ada slider kualitas, karena PNG bersifat lossless dan tidak ada level kualitas yang bisa dipilih.

Tidak perlu akun, dan tidak ada yang diunggah. Konversi terjadi di perangkat Anda, dan itu penting untuk foto pribadi dan dokumen hasil scan.

Jika Anda memakai ponsel, halaman ini berfungsi di browser seluler Anda. Ketuk area unggahan untuk memilih foto dari galeri Anda.

Langkah 2: Unggah File JPG Anda

Seret file JPG Anda ke area unggahan, atau klik untuk membuka pemilih file. Ekstensi .jpg dan .jpeg keduanya diterima.

Anda bisa mengunggah hingga dua puluh file sekaligus. Masing-masing muncul sebagai kartu beserta nama, dimensi, dan ukurannya, sehingga Anda bisa memastikan file yang benar sudah dimuat.

Periksa dimensi pada setiap kartu. PNG akan mempertahankan lebar dan tinggi piksel yang persis dari JPG, sehingga file yang salah mudah dikenali di sini.

Anda juga bisa menempel gambar yang disalin dengan Ctrl+V di komputer. Itu praktis ketika JPG itu ada di clipboard Anda dari aplikasi lain.

Langkah 3: Konversi File-File Itu

Klik tombol Convert. Alat mendekode setiap JPG, menggambarnya ke canvas, lalu mengenkodenya sebagai PNG.

Konversi berlangsung cepat, biasanya satu atau dua detik per file. File yang lebih besar memakan waktu sedikit lebih lama, karena ada lebih banyak piksel untuk dienkode secara lossless.

Setiap kartu diperbarui dengan ukuran PNG baru di samping ukuran JPG lama. Harapkan PNG jauh lebih besar, sering kali lima hingga sepuluh kali ukuran JPG untuk foto.

Jika sebuah file gagal, bacalah pesan kesalahannya. JPG yang korup atau file yang salah nama adalah penyebab yang biasa, dan sisa batch tetap terkonversi.

Langkah 4: Bandingkan Hasilnya

Klik Compare pada sebuah kartu untuk membuka penampil berdampingan. Penampil itu menunjukkan JPG dan PNG bersebelahan, sehingga Anda bisa memastikan nol pergeseran warna.

Perhatikan tepi dan teks dengan saksama. PNG harus tampak identik dengan JPG, karena konversi mempertahankan setiap piksel secara persis.

Periksa juga dimensi di penampil. Lebar dan tinggi harus cocok persis dengan JPG asli, tanpa pemotongan atau penskalaan.

Jika ada yang tampak berbeda, sesuatu berjalan salah. Unggah ulang JPG asli lalu konversi lagi, jangan mencoba memperbaiki PNG-nya.

Langkah 5: Unduh File PNG

Klik Download pada satu kartu untuk menyimpan satu PNG. Nama file mempertahankan nama asli Anda dengan ekstensi .png.

Untuk batch, klik Download All untuk mendapatkan satu ZIP berisi setiap PNG hasil konversi. Itu jauh lebih cepat daripada mengunduh dua puluh file satu per satu.

Periksa file yang diunduh sekali sebelum Anda menggunakannya. Buka PNG di penampil foto Anda lalu pastikan tampilannya benar dan terbuka di aplikasi yang membutuhkannya.

Simpan juga file JPG asli. PNG adalah salinan kerja, dan JPG tetap menjadi versi yang lebih kecil dan lebih portabel dari gambar yang sama.

  1. Buka alat JPG ke PNG lalu unggah file JPG Anda.
  2. Klik Convert lalu tunggu setiap kartu selesai.
  3. Bandingkan sebuah kartu untuk memastikan warnanya cocok persis.
  4. Unduh PNG tunggal atau seluruh batch sebagai ZIP.

Mengonversi Batch Berisi Dua Puluh File

Pilih hingga dua puluh JPG di pemilih file sekaligus. Semuanya dimuat ke antrean, dan Anda mengonversinya bersama-sama dengan satu klik.

Perhatikan kolom Change saat batch berjalan. Kolom itu menunjukkan pertumbuhan ukuran file dengan bersih, sehingga Anda bisa melihat file mana yang paling membesar.

Foto paling membesar, karena teksturnya terkompres buruk sebagai PNG. Scan sederhana dan grafis jauh lebih sedikit membesar, karena area datarnya terkompres baik.

Unduh batch sebagai ZIP lalu ekstrak ke folder baru. Mencampur PNG dengan JPG asli dalam satu folder menimbulkan kebingungan nanti.

Memeriksa Ukuran File Sebelum Mengirimnya

Selalu periksa ukuran PNG terhadap batas apa pun. Formulir yang membatasi unggahan hingga 5MB bisa menolak PNG yang berawal dari JPG 1MB.

Jika PNG terlalu besar, pertimbangkan kembali apakah PNG memang dibutuhkan. File WebP sering kali merupakan kompromi yang lebih baik, menawarkan kualitas lossless pada ukuran yang lebih kecil.

Untuk lampiran email, batch PNG besar bisa melebihi batas. Kirim JPG-nya, atau kompres PNG setelah mengonversi, jika penerima menerimanya.

Kolom Change pada setiap kartu menunjukkan pertumbuhan itu dengan jelas. Gunakan kolom itu untuk memutuskan apakah konversi sepadan dengan byte tambahannya.

Menggunakan PNG untuk Mengedit

Buka PNG di editor pilihan Anda. Photoshop, Figma, Canva, dan PowerPoint semuanya menerima PNG secara native, dan format lossless bertahan melalui penyimpanan berulang.

Tambahkan teks, anotasi, atau hamparan Anda ke versi PNG. Setiap penyimpanan menjaga gambar tetap tajam seperti sebelumnya, tanpa kerusakan yang menumpuk.

Ekspor hasil akhir dalam format yang dibutuhkan tujuan. Halaman web menginginkan WebP atau JPG, sementara percetakan mungkin menginginkan PNG itu sendiri.

Simpan master PNG setelah mengekspor. Jika Anda membutuhkan ekspor lain nanti, Anda bisa membuatnya dari PNG tanpa membuka lagi JPG asli.

Memperbaiki Masalah Umum

Jika PNG keluar jauh lebih besar daripada yang diharapkan, itu normal untuk foto. PNG menyimpan setiap piksel secara persis, dan foto detail membutuhkan banyak byte untuk melakukannya.

Jika warnanya tampak bergeser, JPG sumber mungkin memakai warna cetak CMYK. Konversi ekspor RGB, atau periksa hasilnya dengan saksama sebelum menggunakannya.

Jika sebuah file gagal terkonversi, periksa bahwa file itu adalah JPG asli. File bernama .jpg yang sebenarnya adalah WebP atau PNG akan membingungkan dekoder, dan menamainya dengan benar memperbaiki masalahnya.

Jika orientasinya tampak salah, data orientasi JPG mungkin tidak biasa. Buka dulu JPG di penampil foto, pastikan tampil dengan benar di sana, lalu konversi.

Tips untuk Ponsel dan Tablet

Di ponsel, ketuk area unggahan lalu pilih JPG dari galeri Anda. Konversi berjalan di ponsel, dan PNG terunduh ke perangkat Anda.

Jaga batch ponsel tetap kecil, karena PNG besar membutuhkan waktu untuk dienkode pada prosesor seluler. Lima file sekaligus terasa nyaman; dua puluh file terasa lambat.

Unduhan masuk ke folder Downloads ponsel Anda. Di iPhone, periksa aplikasi Files; di Android, periksa pengelola file Anda.

Untuk batch besar, gunakan desktop. Prosesor yang lebih cepat dan layar yang lebih besar membuat dua puluh file jauh lebih mudah dikelola.

Mengonversi Foto Keluarga Lama

Foto keluarga lama sering dipindai sebagai JPG, dan mengonversinya ke PNG menciptakan salinan kerja lossless untuk restorasi. PNG mempertahankan scan secara persis, termasuk cacatnya, tanpa menambah kerusakan lebih lanjut.

Mulailah dari scan terbaik yang Anda miliki. Scan beresolusi tinggi pada 600 DPI menangkap detail yang dibutuhkan restorasi, sementara scan beresolusi rendah tidak bisa diperbaiki oleh format apa pun.

Konversi scan ke PNG sekali, di awal restorasi. Semua pengeditan, dari penghapusan debu hingga koreksi warna, terjadi pada versi PNG, yang bertahan melalui penyimpanan berulang.

Ekspor hasil restorasi sebagai JPG untuk dibagikan. Keluarga mendapatkan file kecil yang terbuka di mana saja, sementara master PNG tetap berada di arsip untuk pekerjaan di masa depan.

Simpan master PNG dengan nama dan tanggal yang jelas. Nama seperti grandma-wedding-1962-restored.png berguna puluhan tahun kemudian, sementara nama seperti scan001.png tidak berguna.

Mengonversi Screenshot untuk Manual

Manual pengguna penuh dengan screenshot, dan screenshot itu harus tetap terbaca melalui banyak putaran pengeditan. Mengonversinya ke PNG di awal melindungi teksnya.

Ambil screenshot pada resolusi tertinggi yang tersedia. Screenshot retina memiliki piksel dua kali lipat, dan teks tetap tajam bahkan setelah manual dicetak.

Konversi setiap screenshot ke PNG sebelum menambahkan anotasi. Panah, lingkaran, dan label yang ditambahkan ke PNG tetap renyah, sementara anotasi yang sama pada JPG melembut dengan setiap penyimpanan.

Simpan screenshot PNG di folder per bab. Folder bab berisi gambar bernomor mudah dijelajahi, dan manual tersusun sendiri secara berurutan.

Ekspor manual yang sudah jadi sebagai PDF dengan gambar PNG di dalamnya. Teks tetap tajam di dalam PDF, dan pembaca bisa mengikuti setiap langkah tanpa menyipitkan mata.

Mengonversi Gambar untuk Desainer

Desainer lebih menyukai file PNG, karena terbuka secara native di Photoshop, Figma, dan Illustrator. JPG yang dikirim ke desainer sering dikonversi ke PNG juga, sehingga mengirim PNG menghemat satu langkah.

Konversi gambar sebelum mengirimnya, dan beri nama dengan jelas. File bernama hero-photo.png memberi tahu desainer apa isinya, sementara IMG_4821.png tidak memberi tahu apa pun.

Kirim versi berkualitas tertinggi yang Anda miliki. Desainer yang bekerja dari JPG berkualitas rendah tidak bisa menghasilkan hasil yang tajam, seberapa pun terampilnya mereka.

Sertakan juga file JPG asli, jika desainer membutuhkannya. Folder berisi kedua format memberi desainer pilihan tanpa meminta Anda mengirim ulang apa pun.

Sepakati format pengiriman sebelum proyek dimulai. Percakapan singkat tentang JPG versus PNG mencegah folder berisi file berformat salah nanti.

Mengonversi Foto Produk untuk Diedit

Foto produk perlu diedit sebelum masuk ke halaman toko. Memotong, membersihkan latar, dan mengoreksi warna semuanya bekerja lebih baik dari master PNG daripada dari JPG.

Konversi JPG produk ke PNG sekali, di awal sesi pengeditan. Semua penyesuaian terjadi pada versi PNG, yang bertahan melalui penyimpanan berulang tanpa menurun.

Edit dulu satu foto produk lalu sepakati tampilannya dengan tim. Satu contoh yang disetujui menetapkan standar untuk seluruh katalog, sehingga sisanya mengikuti gaya yang sama.

Ekspor foto produk yang sudah jadi sebagai WebP atau JPG untuk website. Toko membutuhkan file kecil yang dimuat cepat, dan master PNG tetap berada di arsip.

Simpan master PNG secara terorganisasi berdasarkan produk dan tanggal. Struktur folder yang jelas memudahkan menemukan foto produk lagi ketika listing perlu diperbarui.

Mengonversi Gambar untuk Cetak

Pekerjaan cetak membutuhkan kualitas tertinggi yang tersedia, dan PNG adalah format yang lebih aman untuk gambar berisi teks. Poster, flyer, atau brosur dengan huruf yang tajam tercetak bersih dari PNG.

Periksa resolusinya sebelum mengonversi. Gambar 1000 piksel yang dicetak pada 10 inci hanya 100 DPI, dan tampak lembut di atas kertas, apa pun formatnya.

Konversi gambar ke PNG pada resolusi penuh, lalu kirim ke percetakan. Percetakan bisa memperkecilnya jika perlu, tetapi tidak bisa menambahkan detail yang tidak pernah ada.

Tanyakan kepada percetakan tentang profil warna sebelum mengirim. PNG dengan profil yang salah bisa tercetak dengan warna bergeser, dan percetakan bisa memberi nasihat tentang pengaturan yang benar.

Pesan cetakan uji untuk pekerjaan penting. Satu cetakan kecil memastikan warna dan ketajaman sebelum Anda berkomitmen pada pesanan besar.

Mengonversi Gambar untuk Tugas Sekolah

Tugas sekolah sering membutuhkan gambar dari web, dan gambar-gambar itu biasanya JPG. Mengonversinya ke PNG memberikan salinan kerja lossless untuk memotong dan memberi anotasi.

Konversi gambar ke PNG sebelum menambahkannya ke tugas. PNG bertahan melalui pengeditan berulang, sementara setiap penyimpanan JPG menambah sedikit kerusakan pada teks dan diagram.

Untuk tugas dengan banyak gambar, konversi seluruh kumpulan sekaligus. Konversi batch memakan waktu beberapa menit, dan PNG siap dimasukkan ke dokumen.

Periksa gambar setelah mengonversi. Sekilas pada setiap gambar memastikan gambar itu tampil dengan benar, sehingga tugas tidak memiliki gambar rusak pada hari pengiriman.

Kutip sumber gambar dalam tugas. Gambar hasil konversi tetap milik pembuatnya, dan kredit yang benar menunjukkan praktik akademik yang baik.

Tugas yang melibatkan banyak gambar, seperti laporan praktikum atau presentasi kelompok, juga mendapat manfaat dari konversi batch. Kumpulkan semua gambar dari anggota kelompok, konversi sekaligus, lalu bagikan folder hasilnya. Semua orang bekerja dengan format yang sama, dan tidak ada yang kebingungan karena file yang tidak bisa dibuka.

Untuk gambar yang diambil dari internet, periksa resolusinya sebelum mengonversi. Gambar kecil yang diunduh dari website sering kali hanya 500 piksel lebarnya, dan mengonversinya ke PNG tidak membuatnya lebih tajam. Cari sumber beresolusi lebih tinggi, atau terima keterbatasannya, daripada berharap konversi melakukan sulap.

Jika Anda mengajar atau membuat materi pelatihan, biasakan memakai PNG untuk semua tangkapan layar di materi. Peserta pelatihan sering mencetak materi itu, dan teks yang tajam di atas kertas membuat materi jauh lebih mudah diikuti daripada teks yang buram.

Terakhir, simpan salinan JPG asli di samping master PNG. JPG adalah versi yang paling mudah dibagikan, dan ketika seseorang meminta gambar dengan cepat lewat chat, Anda bisa mengirim JPG tanpa harus mengekspor ulang dari PNG yang besar.

Itulah seluruh prosesnya: unggah, konversi, bandingkan, unduh. Untuk latar belakangnya, baca JPG ke PNG: Panduan Lengkap, dan untuk pertanyaan transparansi, lihat JPG vs PNG: Kapan Transparansi Itu Penting. Jika Anda membutuhkan file yang lebih kecil, bukan yang lebih besar, konverter JPG ke WebP adalah alat yang harus dipakai.

Pertanyaan umum

Berapa banyak file JPG yang bisa saya konversi ke PNG sekaligus?

Anda bisa mengonversi hingga dua puluh file JPG dalam satu batch lalu mengunduhnya sebagai satu ZIP. Setiap file terkonversi secara mandiri, sehingga satu file buruk tidak menghentikan sisanya. Untuk kumpulan yang lebih besar, jalankan beberapa batch berisi dua puluh file.

Bisakah saya mengonversi JPG ke PNG tanpa filenya menjadi lebih besar?

Tidak, tidak sungguh-sungguh. PNG bersifat lossless, sehingga harus menyimpan setiap piksel secara persis, dan foto yang dikonversi dari JPG hampir selalu tumbuh beberapa kali lebih besar. Jika ukuran file penting, gunakan WebP, yang menjaga kualitas tetap tinggi pada ukuran yang jauh lebih kecil.

Apakah konversi JPG ke PNG berfungsi offline?

Setelah halaman dimuat di browser Anda, konversi berjalan secara lokal dan tidak membutuhkan internet. Anda hanya butuh koneksi untuk membuka halaman pertama kali. Setelah itu, Anda bisa mengonversi JPG secara offline sampai menutup tab.

Apakah PNG saya akan terbuka di Photoshop dan Canva?

Ya. PNG adalah format universal untuk alat desain, dan terbuka di Photoshop, Illustrator, Figma, Canva, PowerPoint, dan setiap browser modern. PNG hasil konversi adalah file standar tanpa persyaratan khusus.

Apa yang harus saya lakukan jika PNG terlalu besar untuk diunggah?

Pertama, periksa apakah PNG memang dibutuhkan. Jika tujuan menerima WebP atau JPG, konversi ke salah satunya untuk file yang jauh lebih kecil. Jika PNG wajib, kurangi dimensi gambar dengan pengubah ukuran sebelum mengonversi, karena piksel yang lebih sedikit berarti PNG yang lebih kecil.

Bisakah saya mengonversi screenshot JPG ke PNG untuk anotasi?

Bisa, dan itu adalah salah satu penggunaan terbaik alat ini. Screenshot yang dikonversi ke PNG tetap tajam melalui banyak putaran anotasi, pemotongan, dan penyimpanan ulang. Tambahkan panah dan teks Anda ke versi PNG, lalu ekspor hasil akhir untuk dibagikan.
