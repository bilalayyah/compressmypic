Cara Mengubah JPG ke WebP

Ubah foto JPG ke WebP dalam beberapa langkah. Unggah, atur kualitas, periksa penghematannya, lalu unduh — satu foto atau satu folder penuh.

Mengonversi JPG ke WebP adalah salah satu kemenangan kecepatan termudah untuk website. Fotonya tampak sama, filenya sepertiga lebih kecil, dan halamannya dimuat lebih cepat.

Proses ini memakan waktu beberapa detik per foto, dan Anda bisa mengonversi seluruh folder sekaligus. Semuanya berjalan di browser Anda, tanpa ada yang perlu diinstal.

Panduan ini membahas setiap langkah, beserta pengaturan yang penting untuk hasil yang bersih.

Sebelum Memulai: Yang Anda Butuhkan

Anda membutuhkan file JPG dan browser modern. Chrome, Edge, Firefox, dan Safari semuanya berfungsi, di desktop maupun di seluler.

Carilah file JPG asli terbaik yang Anda miliki. Konversi tidak bisa menambah detail, jadi mulailah dari salinan berkualitas tertinggi, bukan dari thumbnail yang sudah terkompres.

Ketahui ke mana file WebP itu akan pergi. Website menginginkan kualitas 80 persen, sementara foto yang Anda rencanakan untuk diperbesar menginginkan 85 persen.

File hingga 25MB masing-masing diterima. Itu mencakup foto kamera beresolusi tinggi dan screenshot besar tanpa persiapan apa pun.

Langkah 1: Buka Alat JPG ke WebP

Buka alat JPG ke WebP di browser Anda. Halaman ini berfungsi di Windows, Mac, Linux, ChromeOS, Android, dan iOS.

Anda akan melihat area unggahan, slider kualitas, dan tombol konversi. Ketiga kontrol itu adalah seluruh pekerjaan.

Tidak perlu akun, dan tidak ada yang diunggah. Konversi terjadi di perangkat Anda, dan itu penting untuk foto klien dan gambar pribadi.

Jika Anda memakai ponsel, halaman ini berfungsi di browser seluler Anda. Ketuk area unggahan untuk memilih foto dari galeri Anda.

Langkah 2: Unggah File JPG Anda

Seret file JPG Anda ke area unggahan, atau klik untuk membuka pemilih file. Ekstensi .jpg dan .jpeg keduanya diterima.

Anda bisa mengunggah banyak file sekaligus untuk batch. Masing-masing muncul sebagai kartu beserta nama, dimensi, dan ukurannya, sehingga Anda bisa memastikan file yang benar sudah dimuat.

Periksa dimensi pada setiap kartu. WebP akan mempertahankan lebar dan tinggi piksel yang persis dari JPG, sehingga file yang salah mudah dikenali di sini.

Anda juga bisa menempel gambar yang disalin dengan Ctrl+V di komputer. Itu praktis ketika JPG itu ada di clipboard Anda dari aplikasi lain.

Langkah 3: Atur Slider Kualitas

Slider kualitas mengontrol seberapa banyak detail yang dipertahankan encoder WebP. Untuk sebagian besar foto website, 80 persen adalah pengaturan yang tepat.

Gunakan 75 persen untuk gambar hero besar di mana kecepatan pemuatan paling penting. Pelembutan yang sedikit tidak terlihat pada ukuran layar penuh, dan file menyusut lebih jauh.

Gunakan 85 persen untuk foto produk yang diperbesar pengunjung. Kualitas tambahan melindungi detail halus yang diperiksa pembeli dengan saksama.

Jangan turun di bawah 70 persen untuk foto yang dilihat orang. Kelembutannya menjadi terlihat, dan penghematan tambahannya kecil dibandingkan kerusakannya.

Langkah 4: Konversi File-File Itu

Klik tombol Convert. Alat mendekode setiap JPG, menggambarnya ulang di canvas, lalu mengenkodenya sebagai WebP.

Konversi berlangsung cepat, biasanya satu atau dua detik per foto. File yang lebih besar memakan waktu sedikit lebih lama, karena ada lebih banyak piksel untuk dienkode.

Setiap kartu diperbarui dengan ukuran WebP baru di samping ukuran JPG lama. Konversi yang bagus menunjukkan penghematan 25 hingga 35 persen pada sebagian besar foto.

Jika sebuah file gagal, bacalah pesan kesalahannya. JPG yang korup atau file yang salah nama adalah penyebab yang biasa, dan sisa batch tetap terkonversi.

Langkah 5: Pratinjau dan Periksa Penghematannya

Klik Compare pada sebuah kartu untuk melihat JPG dan WebP secara berdampingan. Seret gagang pemisah melintasi gambar untuk memeriksa wajah, teks, dan detail halus.

Periksa juga ukuran filenya. Jika WebP lebih besar daripada JPG, file asli sudah sangat terkompres, dan Anda harus mempertahankan JPG untuk file itu.

Perhatikan juga warnanya. Sebagian besar foto mempertahankan warnanya secara akurat, meskipun gambar yang sangat jenuh bisa sedikit bergeser selama konversi.

Jika hasilnya tampak lembut, naikkan kualitas lima poin lalu konversi lagi. JPG asli tetap ada di antrean, sehingga Anda tidak perlu mengunggah ulang.

Langkah 6: Unduh File WebP

Klik Download pada satu kartu untuk menyimpan satu WebP. Nama file mempertahankan nama asli Anda dengan ekstensi .webp.

Untuk batch, klik Download All untuk mendapatkan satu ZIP berisi setiap WebP hasil konversi. Itu jauh lebih cepat daripada mengunduhnya satu per satu.

Periksa file yang diunduh sekali sebelum Anda menggunakannya. Buka WebP di browser Anda lalu pastikan gambar itu tampil dengan benar.

Simpan juga file JPG asli. Jika tujuan menolak WebP, Anda bisa mengunggah JPG itu, tanpa mengonversi lagi.

  1. Buka alat JPG ke WebP lalu unggah file JPG Anda.
  2. Atur slider kualitas ke 80 persen untuk website.
  3. Konversi lalu periksa penghematan pada setiap kartu.
  4. Pratinjau dengan Compare, lalu unduh file WebP.

Mengonversi Seluruh Folder Gambar Blog

Pilih semua JPG di folder gambar blog Anda sekaligus. Semuanya dimuat ke antrean, dan satu klik mengonversi semuanya ke WebP.

Gunakan pengaturan kualitas yang sama untuk seluruh folder. Konsistensi penting ketika gambar berbagi halaman, karena kualitas yang tercampur tampak tidak rata.

Perhatikan ringkasan batch setelah mengonversi. Ringkasan itu menjumlahkan penghematan di semua file, dan batch yang bagus sering menyusut sepertiga secara keseluruhan.

Unggah file WebP ke situs Anda menggantikan JPG. Perbarui referensi gambar, lalu uji halaman untuk memastikan semuanya tampil dengan benar.

Mengubah Kualitas Setelah Konversi Pertama

Anda bisa mengubah slider kualitas setelah mengonversi tanpa mengunggah ulang. JPG asli tetap ada di antrean, sehingga pengaturan baru hanya berjarak satu klik.

Coba dulu 80 persen, lalu 75 persen, dan bandingkan kedua hasilnya. Perbedaannya sering kali tidak terlihat, dan file yang lebih kecil adalah pilihan yang tepat.

Untuk satu foto penting, coba juga 85 persen dan 90 persen. Pengaturan terbaik adalah pengaturan terendah di mana Anda tidak bisa melihat perbedaan apa pun.

Unduh setiap versi sebelum berganti pengaturan. Tombol unduh menyimpan konversi saat ini, jadi ambil dulu sebelum Anda mengubah apa pun.

Memperbaiki Masalah Umum

Jika WebP keluar lebih besar daripada JPG, file asli sudah sangat terkompres. Pertahankan JPG untuk file itu lalu lanjutkan.

Jika gambar tampak lembut, kualitasnya terlalu rendah. Naikkan slider ke 85 persen lalu konversi lagi dari JPG asli.

Jika sebuah file gagal terkonversi, periksa bahwa file itu adalah JPG asli. File bernama .jpg yang sebenarnya adalah PNG atau WebP akan membingungkan dekoder.

Jika warnanya tampak bergeser, sumbernya mungkin memiliki profil warna yang tidak biasa. Bandingkan WebP dengan JPG secara saksama, dan pertahankan JPG jika pergeserannya penting.

Mengunggah WebP ke Website Anda

Unggah file WebP hasil konversi ke pustaka media Anda seperti gambar lainnya. WordPress, Shopify, dan Wix semuanya menerima unggahan WebP sekarang.

Uji dulu satu gambar. Unggah gambar itu, lihat halamannya, lalu pastikan gambar itu tampil dengan benar di desktop dan di ponsel Anda.

Untuk browser lama, sajikan cadangan JPG di samping WebP. Sebagian besar platform menangani ini secara otomatis, atau Anda bisa memakai elemen picture di HTML Anda.

Ukur kecepatan halaman setelah beralih. Halaman dengan gambar WebP harus dimuat jauh lebih cepat, dan itulah inti konversi ini.

Mengonversi Pustaka Gambar Blog

Pustaka gambar blog tumbuh selama bertahun-tahun, dan mengonversi semuanya sekaligus adalah proyek, bukan pekerjaan kecil. Rencanakan dalam batch, satu bulan atau satu kategori setiap kalinya.

Mulailah dengan postingan yang paling banyak dikunjungi, karena postingan itu paling mendapat manfaat dari pemuatan yang lebih cepat. Postingan populer dengan gambar WebP melayani ribuan pembaca lebih baik daripada postingan yang tidak dikenal.

Konversi setiap batch pada kualitas 80 persen, lalu perbarui referensi gambar di postingan. Referensi yang rusak lebih buruk daripada gambar yang lambat, jadi periksa setiap postingan setelah memperbaruinya.

Simpan file JPG asli di pustaka media sebagai cadangan. Jika browser pembaca tidak bisa menampilkan WebP, versi JPG dimuat sebagai gantinya, dan tidak ada yang melihat gambar rusak.

Lacak kemajuan dalam daftar sederhana. Bulan yang sudah dicentang berarti selesai, dan bulan yang belum dicentang masih menunggu, sehingga postingan tidak terkonversi dua kali atau tidak terkonversi sama sekali.

Mengonversi Foto Produk untuk Toko

Foto produk membutuhkan perhatian, karena pelanggan memperbesarnya. Konversi pada kualitas 80 hingga 85 persen, agar tekstur kain, jahitan, dan detail kecil tetap terlihat.

Pilah produk berdasarkan kategori sebelum mengonversi. Sepatu, baju, dan aksesori mungkin membutuhkan pengaturan berbeda, dan memilah dulu berarti satu batch bersih per kelompok.

Periksa tiga atau empat produk setelah mengonversi, bukan kelima ratusnya. Jika produk-produk itu tampak bagus, sisanya juga akan bagus, karena pengaturannya sama di seluruh batch.

Unggah file WebP lalu perbarui listing produk. Uji beberapa halaman produk di desktop dan ponsel untuk memastikan gambar tampil dengan benar.

Simpan juga file JPG asli, karena beberapa marketplace menuntut JPG. Produk yang terdaftar di Amazon dan di toko Anda sendiri membutuhkan kedua format yang siap.

Mengonversi Foto untuk Portofolio

Portofolio harus tampak sempurna, dan pengaturan konversi harus mencerminkan itu. Gunakan kualitas 85 persen, agar gambar tetap tajam bahkan ketika klien memperbesar dengan saksama.

Pilih gambar terkuat dulu, lalu konversi sesuai urutan kepentingannya. Gambar hero layak mendapat perhatian paling besar, karena menentukan kesan untuk seluruh portofolio.

Periksa setiap gambar setelah mengonversi, bukan hanya sampel. Portofolio hanya memiliki sedikit gambar, dan masing-masing penting, sehingga tinjauan cepat atas semuanya sepadan dengan waktu itu.

Perbarui situs portofolio dengan file WebP, lalu uji di desktop dan ponsel. Gambar rusak di portofolio berarti klien yang hilang, jadi verifikasi setiap gambar dimuat.

Simpan file JPG asli di folder portofolio. Jika klien meminta versi JPG, file itu sudah siap tanpa konversi baru.

Mengonversi Gambar untuk Media Sosial

Platform media sosial mengonversi unggahan ke format mereka sendiri, sehingga format sumber kurang penting daripada kualitas. Input WebP berkualitas tinggi memberikan hasil yang lebih baik daripada input JPG berkualitas rendah.

Konversi gambar ke WebP pada kualitas 85 persen sebelum mengunggah. Kompresi platform memiliki pekerjaan yang lebih sedikit, dan gambar akhir tampak lebih bersih.

Periksa dimensi yang disukai platform sebelum mengonversi. Instagram, Facebook, dan X masing-masing punya ukuran ideal, dan konversi tidak bisa memperbaiki gambar yang ukurannya salah.

Untuk grafis berisi teks, WebP pada 85 persen menjaga huruf lebih tajam daripada JPG. Teks tetap terbaca setelah kompresi platform, dan itulah inti grafis itu.

Unduh file hasil konversi lalu unggah dari perangkat Anda, jangan membagikan tautan. Unggahan langsung mempertahankan kualitas yang Anda pilih, sementara tautan yang dibagikan bisa memicu putaran kompresi lain.

Memperbarui Referensi JPG Lama

Setelah mengonversi, website masih merujuk file JPG lama. Memperbarui referensi itu adalah langkah yang dilupakan orang, dan referensi yang terlupakan berarti file WebP duduk tanpa dipakai.

Cari referensi gambar ke file hasil konversi di situs. Pencarian sederhana untuk .jpg di konten mengungkap setiap tempat yang perlu diperbarui.

Perbarui referensi agar menunjuk ke file WebP, dengan JPG sebagai cadangan. Elemen picture menyajikan WebP kepada browser modern dan JPG kepada yang lain.

Uji halaman yang diperbarui secara menyeluruh. Klik situs itu, periksa setiap gambar, dan pastikan tidak ada yang rusak sebelum beralih ke batch berikutnya.

Hapus referensi JPG lama hanya setelah pengujian. Halaman yang sudah diuji dengan gambar WebP yang berfungsi itu aman, sementara perubahan yang belum diuji bisa menyembunyikan gambar rusak.

Mengonversi Gambar untuk Peluncuran Website Baru

Peluncuran website baru membutuhkan setiap gambar dalam format yang tepat sejak hari pertama. Mengonversi foto JPG ke WebP sebelum peluncuran membuat situs cepat sejak pengunjung pertama.

Konversi gambar peluncuran dalam satu batch pada kualitas 80 persen. Foto tampak bersih, file sepertiga lebih kecil, dan halaman dimuat cepat di setiap perangkat.

Uji situs yang diluncurkan di desktop dan ponsel sebelum mengumumkannya. Gambar rusak pada hari peluncuran adalah kesan pertama yang buruk, sementara uji cepat menangkapnya.

Simpan file JPG asli di pustaka media sebagai cadangan. Jika browser pengunjung tidak bisa menampilkan WebP, versi JPG dimuat sebagai gantinya, dan tidak ada yang melihat gambar rusak.

Dokumentasikan pilihan format itu dalam catatan proyek. Satu baris catatan mencegah orang berikutnya mengunggah JPG ke situs yang seharusnya memakai WebP.

Untuk website yang sudah berjalan lama, migrasikan gambar secara bertahap, bukan sekaligus. Mulailah dengan halaman yang paling banyak dikunjungi, lalu lanjutkan ke halaman lain setiap minggu. Migrasi bertahap mengurangi risiko referensi rusak, dan setiap batch yang selesai langsung memberikan manfaat kecepatan.

Perhatikan juga gambar yang dipakai di beberapa tempat sekaligus, seperti logo di header dan footer. Mengonversi satu file yang dipakai di banyak halaman memberikan manfaat ganda, karena setiap halaman yang memuatnya menjadi lebih cepat. Prioritaskan file yang paling sering dipakai.

Jika Anda memakai CDN, pastikan CDN itu mendukung WebP dan tidak mengonversi ulang gambar Anda dengan kualitas yang lebih rendah. Beberapa CDN mengompres gambar secara otomatis, dan pengaturan itu bisa merusak kualitas WebP yang sudah Anda atur dengan hati-hati. Periksa pengaturan CDN setelah migrasi.

Terakhir, dokumentasikan proses migrasi untuk tim Anda. Catatan singkat tentang kualitas yang dipakai dan langkah pengujian membantu anggota tim baru mengikuti standar yang sama, dan mencegah seseorang mengunggah JPG besar ke situs yang seharusnya memakai WebP.

Untuk website yang memakai gambar dari banyak kontributor, buatlah panduan format singkat untuk semua penulis. Satu halaman panduan yang menyatakan bahwa semua foto harus WebP 80 persen mencegah campuran format yang membuat situs lambat dan tidak konsisten.

Jika Anda memakai plugin optimasi gambar di WordPress, periksa apakah plugin itu mengonversi ulang WebP Anda. Beberapa plugin menerapkan kompresi tambahan yang menurunkan kualitas di bawah pengaturan Anda. Nonaktifkan kompresi ganda itu, agar file WebP Anda tetap seperti yang Anda buat.

Itulah seluruh prosesnya: unggah, atur kualitas, konversi, unduh. Untuk latar belakangnya, baca JPG ke WebP: Panduan Lengkap, dan untuk perbandingan langsung, lihat JPG vs WebP: Ukuran File, Kualitas, dan Dukungan Browser. Jika gambar Anda adalah PNG, bukan JPG, konverter PNG ke WebP adalah alat yang cocok.

Pertanyaan umum

Bagaimana cara mengonversi folder berisi gambar blog JPG ke WebP?

Pilih semua JPG di folder itu sekaligus di pemilih file, atau seret folder ke area unggahan. Atur kualitas ke 80 persen, konversi, lalu unduh ZIP-nya. Unggah file WebP ke situs Anda menggantikan JPG, lalu uji halaman untuk memastikan semuanya tampil.

Bisakah saya mengubah kualitas setelah mengonversi ke WebP?

Bisa. JPG asli tetap ada di antrean setelah konversi pertama, sehingga Anda bisa menggeser slider kualitas lalu mengonversi lagi tanpa mengunggah ulang. Unduh setiap versi sebelum berganti pengaturan, karena tombol unduh menyimpan konversi saat ini.

Pengaturan kualitas apa yang terbaik untuk foto produk?

80 hingga 85 persen adalah yang terbaik untuk foto produk, karena pelanggan memperbesarnya dan memeriksa detail halus. Pengaturan yang lebih rendah melembutkan tekstur kain dan fitur kecil, yang bisa merugikan penjualan. Untuk gambar hero besar, 75 persen sudah cukup, karena pelembutan yang sedikit tidak terlihat pada ukuran layar penuh.

Apakah gambar WebP saya akan berfungsi di WordPress?

Ya. WordPress sudah mendukung unggahan WebP sejak versi 5.8. Unggah file hasil konversi ke pustaka media seperti gambar lainnya. Uji dulu satu gambar untuk memastikan gambar itu tampil dengan benar, lalu unggah sisa batch.

Bisakah saya mengonversi JPG ke WebP tanpa koneksi internet?

Setelah halaman dimuat, konversi berjalan secara lokal di browser Anda dan tidak membutuhkan internet. Anda hanya butuh koneksi untuk membuka halaman pertama kali. Setelah itu, Anda bisa mengonversi JPG secara offline sampai menutup tab.

Apa yang harus saya lakukan jika file WebP tidak mau terbuka di perangkat lama?

Konversi gambar itu kembali ke JPG dengan konverter WebP ke JPG, lalu gunakan JPG untuk perangkat lama. Untuk website, sajikan cadangan JPG di samping WebP, sehingga browser modern mendapatkan file yang lebih kecil dan browser lama mendapatkan file yang kompatibel.
