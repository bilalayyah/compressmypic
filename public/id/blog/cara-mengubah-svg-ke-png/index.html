Cara Mengubah SVG ke PNG

Ubah logo dan ikon SVG ke PNG sesuai ukuran yang Anda butuhkan. Unggah, pilih skala, periksa hasilnya, lalu unduh — satu file atau satu paket sekaligus.

Logo SVG bisa diperbesar tanpa batas, tapi banyak tempat masih menginginkan PNG. Mengubahnya hanya butuh beberapa detik, dan satu-satunya keputusan yang penting adalah ukuran output.

Pilih skala yang tepat, dan PNG terlihat sempurna. Pilih yang salah, dan ia keluar buram atau besar tanpa perlu.

Panduan ini memandu Anda langkah demi langkah, dari mengunggah SVG sampai mengunduh PNG yang tajam.

Sebelum Mulai: Siapkan SVG-nya

Buka SVG di browser dulu dan pastikan ia dirender dengan benar. Jika terlihat salah di sana, ia juga akan terlihat salah sebagai PNG.

Ubah teks menjadi outline di alat desain Anda jika SVG berisi huruf. Teks yang di-outline menjadi bentuk, jadi ia dirender secara persis apa pun fontnya.

Sematkan gambar tertaut apa pun sebagai data URI di dalam SVG. Konverter tidak bisa mengambil file eksternal, jadi foto yang ditautkan akan hilang dari PNG.

Hapus persegi latar apa pun jika Anda menginginkan PNG transparan. Bentuk latar menjadi bagian dari gambar, sementara SVG transparan tetap transparan.

Luangkan waktu sebentar untuk memeriksa SVG di browser sebelum mengonversi. Logo yang terlihat rusak di browser akan tetap rusak sebagai PNG, dan memperbaikinya lebih mudah di alat desain daripada setelah diraster. Perbaikan di tahap SVG hanya butuh beberapa klik, sementara perbaikan di PNG berarti menggambar ulang dari awal.

Langkah 1: Buka Alat SVG ke PNG

Buka alat SVG ke PNG di browser Anda. Halaman ini bisa dipakai di Windows, Mac, Linux, ChromeOS, Android, dan iOS.

Anda akan melihat area unggah dan pemilih skala. Dua kontrol itu saja sudah cukup untuk seluruh pekerjaan.

Tidak perlu akun, dan tidak ada yang diunggah ke server. Konversi terjadi di perangkat Anda, dan itu penting untuk logo klien dan aset merek.

Jika Anda memakai ponsel, halaman ini bisa dibuka di browser seluler. Ketuk area unggah untuk memilih file SVG dari perangkat Anda.

Langkah 2: Unggah File SVG Anda

Seret file SVG Anda ke area unggah, atau klik untuk membuka pemilih file. Anda bisa memilih banyak file sekaligus untuk satu batch.

Setiap file muncul sebagai kartu dengan gambar mini, sehingga Anda bisa memastikan file yang benar sudah dimuat. File yang salah mudah dikenali dan dihapus.

File sampai 25MB per file diterima, dan itu mencakup bahkan file ilustrasi besar dengan ribuan path. SVG yang sangat kompleks hanya butuh satu atau dua detik lebih lama.

Anda juga bisa menempel SVG yang disalin dengan Ctrl+V di komputer. Cara ini praktis ketika kode SVG ada di clipboard dari aplikasi lain.

Langkah 3: Pilih Skala Output

Pemilih skala menawarkan 1x, 2x, 3x, dan 4x. Skala mengalikan ukuran alami SVG, jadi ikon 24 piksel pada 4x menjadi PNG 96 piksel.

Untuk ikon website, 2x atau 3x biasanya cukup. PNG terlihat tajam di layar retina tanpa membuang byte.

Untuk logo pada slide presentasi, 4x memberi margin yang nyaman. Logo kecil yang diperbesar di PowerPoint tetap tajam ketika PNG memiliki cukup piksel.

Untuk cetak, pilih skala yang mencapai 300 DPI pada ukuran cetak. Logo yang dicetak selebar 2 inci membutuhkan setidaknya 600 piksel, jadi hitung mundur dari ukuran cetak.

Jika Anda mengonversi untuk beberapa keperluan sekaligus, rasterisasi pada skala tertinggi yang Anda butuhkan. PNG besar bisa diperkecil dengan mudah, sementara PNG kecil tidak bisa diperbesar tanpa kehilangan ketajaman.

Langkah 4: Konversi File

Klik tombol Convert. Alat menggambar setiap SVG ke kanvas pada skala yang dipilih dan mengenkode hasilnya sebagai PNG.

Konversi berlangsung cepat, biasanya satu atau dua detik per file. SVG yang sangat kompleks dengan ribuan path butuh sedikit lebih lama untuk digambar.

Setiap kartu diperbarui dengan ukuran dan dimensi PNG baru. Periksa dimensinya untuk memastikan skala menghasilkan ukuran yang Anda harapkan.

Jika sebuah file gagal dengan kesalahan, SVG mungkin berisi fitur yang tidak didukung atau kode yang rusak. Buka dulu di browser untuk memastikan ia dirender di sana.

Langkah 5: Periksa Hasilnya

Klik Compare pada kartu untuk melihat SVG dan PNG berdampingan. Perbesar tepi logo dan pastikan semuanya tajam dan bersih.

Periksa dulu teksnya, jika SVG berisi teks. Teks yang terlihat salah berarti font hilang, dan perbaikannya adalah mengubah teks menjadi outline lalu mengonversi lagi.

Periksa gambar yang hilang. Ruang kosong di tempat foto seharusnya berada berarti gambar ditautkan secara eksternal, dan Anda perlu menyematkannya sebagai data URI.

Periksa transparansinya. Logo yang seharusnya transparan tidak boleh menunjukkan kotak putih di sekelilingnya, atau SVG memiliki persegi latar yang perlu Anda hapus.

Langkah 6: Unduh File PNG

Klik Download pada satu kartu untuk menyimpan satu PNG. Nama file tetap memakai nama asli Anda dengan ekstensi .png.

Untuk batch, klik Download All untuk mendapatkan satu ZIP berisi semua PNG hasil konversi. Itu jauh lebih cepat daripada mengunduhnya satu per satu.

Periksa file yang diunduh sekali sebelum menggunakannya. Buka PNG di penampil foto Anda dan pastikan tampilannya tajam pada ukuran yang Anda butuhkan.

Simpan juga file SVG aslinya. Mereka adalah master, dan Anda bisa merasterisasinya lagi dalam ukuran apa pun kapan pun Anda membutuhkan PNG berbeda.

  1. Buka alat SVG ke PNG dan unggah file SVG Anda.
  2. Pilih skala: 2x untuk web, 4x untuk presentasi dan cetak.
  3. Konversi dan periksa tepi, teks, serta transparansi.
  4. Unduh PNG satu per satu atau seluruh batch sebagai ZIP.

Mengonversi Satu Paket Ikon Sekaligus

Pilih semua ikon SVG sekaligus di pemilih file. Semuanya dimuat ke antrean, dan sekali klik mengubah semuanya pada skala yang sama.

Gunakan skala yang sama untuk seluruh paket. Konsistensi penting ketika ikon tampil bersama, karena ukuran campuran terlihat tidak rata.

Periksa dua atau tiga ikon setelah mengonversi, bukan kelima puluhnya. Jika yang itu terlihat bagus, sisanya juga akan bagus, karena pengaturannya sama.

Unggah ikon PNG ke tempat yang membutuhkannya. Favicon, ikon aplikasi, atau deck slide semuanya menerima file PNG tanpa konversi lebih lanjut.

Memilih Ukuran untuk Setiap Keperluan

Untuk favicon, rasterisasi pada ukuran persis yang dibutuhkan situs, biasanya 16, 32, dan 48 piksel. Generator favicon juga bisa membuat ukuran itu dari PNG.

Untuk avatar media sosial, 400 kali 400 piksel adalah ukuran yang bagus. Ia terlihat tajam di desktop dan seluler, dan file tetap kecil.

Untuk logo presentasi, 4x ukuran SVG biasanya memberi cukup piksel. Logo 100 piksel pada 4x menjadi 400 piksel, dan itu terlihat tajam di slide.

Untuk cetak, hitung dari DPI. Logo 2 inci pada 300 DPI membutuhkan 600 piksel, jadi pilih skala yang mencapai setidaknya angka itu.

Memperbaiki Masalah Umum

Jika PNG terlihat buram, skalanya terlalu rendah. Rasterisasi lagi pada skala yang lebih tinggi dari SVG asli, karena PNG beresolusi rendah tidak bisa ditajamkan.

Jika teks terlihat salah, fontnya hilang. Ubah teks menjadi outline di alat desain Anda lalu konversi lagi.

Jika foto tertaut hilang, sematkan sebagai data URI di dalam SVG. Konverter tidak bisa mengambil file eksternal, jadi gambar harus ikut di dalam SVG.

Jika file gagal dengan kesalahan, buka SVG di browser. Jika ia dirender di sana, coba konversi sendiri, bukan dalam batch.

Simpan catatan tentang skala yang Anda pakai untuk setiap keperluan. Ketika logo perlu dibuat lagi bulan depan, catatan itu menghemat waktu dan memastikan hasilnya konsisten dengan yang sebelumnya.

Tips untuk Ponsel dan Tablet

Di ponsel, ketuk area unggah lalu pilih file SVG dari perangkat Anda. Konversi berjalan di ponsel, dan PNG-nya terunduh ke perangkat Anda.

Pertahankan batch ponsel tetap kecil, karena SVG kompleks membutuhkan waktu untuk diraster di prosesor seluler. Sepuluh file sekaligus sudah nyaman.

Unduhan tersimpan di folder Downloads ponsel Anda. Di iPhone, periksa aplikasi Files; di Android, periksa pengelola file Anda.

Untuk paket ikon yang besar, gunakan desktop. Prosesor yang lebih cepat dan layar yang lebih besar membuat lima puluh file jauh lebih mudah dikelola.

Untuk paket ikon yang besar, kerjakan di desktop dengan layar yang lebar. Memeriksa lima puluh ikon di layar ponsel memakan waktu dan melelahkan, sementara di desktop Anda bisa melihat banyak kartu sekaligus.

Mengonversi Logo untuk Kartu Nama

Logo kartu nama harus tercetak tajam pada ukuran yang sangat kecil, jadi rasterisasi SVG pada 4x. Logo kecil dengan cukup piksel di belakangnya tetap tajam di kartu.

Periksa warna setelah mengonversi, karena warna cetak berbeda dari warna layar. Satu cetakan percobaan memastikan warna merek terlihat benar di atas kertas.

Kirim PNG ke percetakan beserta SVG sebagai cadangan. Percetakan bisa meraster SVG itu sendiri jika PNG bermasalah, jadi menyediakan keduanya mencakup semua kemungkinan.

Pertahankan file PNG tetap kecil, karena printer kartu nama tidak membutuhkan gambar besar. Logo 1000 piksel sudah cukup untuk kartu, dan file yang lebih besar hanya memperlambat unggahan.

Pesan satu kartu percobaan sebelum mencetak seluruh batch. Satu kartu memastikan ukuran logo, warna, dan ketajaman sebelum Anda berkomitmen pada ratusan kartu.

Mengonversi Ikon untuk Website

Ikon website dimulai sebagai file SVG, dan menjadi PNG untuk browser lama. Rasterisasi pada 2x atau 3x ukuran tampilan, supaya ikon terlihat tajam di layar retina.

Gunakan skala yang sama untuk seluruh set ikon. Konsistensi penting ketika ikon tampil bersama, karena ukuran campuran terlihat tidak rata.

Uji ikon di website yang sebenarnya sebelum menerbitkannya. Ikon yang terlihat sempurna di alat desain bisa terlihat berbeda dengan warna latar situs.

Untuk website modern, pertimbangkan memakai file SVG secara langsung. Browser menampilkan SVG secara bawaan, dan ikon diperbesar dengan sempurna tanpa rasterisasi apa pun.

Simpan master SVG di folder proyek setelah mengonversi. Jika website didesain ulang, ikon bisa diraster lagi pada ukuran baru tanpa menggambar ulang.

Mengonversi SVG untuk Cetak Kaos

Cetakan kaos membutuhkan gambar beresolusi tinggi, dan SVG adalah sumber yang ideal. Rasterisasi pada skala terbesar yang diizinkan alat, sampai batas 8000 piksel, untuk cetakan yang tajam.

Periksa desain setelah mengonversi, karena cetakan kaos menunjukkan setiap cacat. Logo yang terlihat baik di layar bisa memperlihatkan tepi kasar saat dicetak besar di atas kain.

Kirim PNG ke percetakan beserta SVG sebagai cadangan. Perangkat lunak percetakan mungkin lebih menyukai satu format daripada yang lain, dan menyediakan keduanya mencakup semua kemungkinan.

Untuk kaos gelap, periksa transparansinya. Logo dengan latar transparan tercetak bersih di kain gelap, sementara logo berkotak putih terlihat salah.

Pesan satu kaos percobaan sebelum mencetak satu batch. Cetakan percobaan memastikan ukuran, warna, dan penempatan sebelum Anda berkomitmen pada puluhan kaos.

Mengonversi SVG untuk Presentasi

Slide presentasi membutuhkan logo yang tajam, dan SVG adalah sumber yang ideal. Rasterisasi pada 4x ukuran SVG, supaya logo tetap tajam saat diproyeksikan ke layar besar.

Periksa logo pada latar slide yang sebenarnya setelah mengonversi. Logo yang terlihat sempurna di atas putih bisa menunjukkan pinggiran samar pada slide berwarna jika kualitasnya rendah.

Untuk deck dengan banyak slide, ubah semua logo sekaligus. Konversi batch hanya butuh beberapa menit, dan PNG-nya siap dimasukkan ke slide.

Uji deck di proyektor sebelum berbicara. Slide yang terlihat tajam di laptop bisa terlihat lembut saat diproyeksikan, dan uji cepat menangkap masalah itu lebih awal.

Simpan master SVG di folder proyek setelah mengonversi. Jika presentasi dipakai lagi dengan template baru, logo bisa diraster lagi pada ukuran baru.

Mengonversi SVG untuk Favicon

Favicon adalah ikon kecil di tab browser, dan biasanya dimulai sebagai logo SVG. Rasterisasi pada 16, 32, dan 48 piksel untuk ukuran favicon standar.

Rancang favicon dengan sederhana, karena ukuran kecil menyembunyikan detail. Logo yang kompleks pada 16 piksel menjadi buram, sementara bentuk sederhana tetap mudah dikenali.

Uji favicon di beberapa browser setelah menambahkannya. Pemeriksaan cepat memastikan tampilannya benar, sehingga situs terlihat rapi di setiap tab.

Untuk browser modern, pertimbangkan memakai favicon SVG secara langsung. Browser menampilkan favicon SVG secara bawaan, dan ikon diperbesar dengan sempurna tanpa rasterisasi apa pun.

Simpan master SVG setelah mengonversi. Jika situs didesain ulang, favicon bisa diraster lagi pada ukuran baru tanpa menggambar ulang logo.

Mengonversi SVG untuk Banner Website

Banner website adalah gambar lebar, dan SVG adalah sumber yang ideal ketika banner berupa grafis, bukan foto. Rasterisasi pada lebar tampilan banner untuk hasil yang tajam.

Periksa dimensi banner sebelum mengonversi. Banner yang ditampilkan selebar 1200 piksel membutuhkan PNG setidaknya selebar itu, atau ia akan terlihat lembut.

Untuk banner berisi teks, rasterisasi pada 2x ukuran tampilan. Teks tetap tajam di layar retina, dan file tetap cukup kecil untuk dimuat cepat.

Uji banner di desktop dan ponsel setelah mengonversi. Banner yang terlihat sempurna di layar lebar bisa terpotong buruk di layar sempit, dan uji cepat menangkapnya.

Simpan master SVG di folder proyek. Jika website didesain ulang dengan ukuran banner baru, grafis bisa diraster lagi tanpa menggambar ulang.

Itulah seluruh prosesnya: siapkan, unggah, pilih skala, unduh. Untuk latar belakangnya, baca SVG ke PNG: Panduan Lengkap, dan untuk soal vektor versus raster, lihat SVG vs PNG: Vektor vs Raster Dijelaskan. Jika SVG Anda bagian dari batch campuran, Konverter Gambar juga menanganinya.

Pertanyaan umum

Berapa ukuran PNG pada skala 1x?

Pada 1x, PNG cocok dengan ukuran alami SVG, jadi ikon 24px menjadi PNG 24px. Untuk hasil yang tajam di layar modern, gunakan 2x atau 3x, dan untuk presentasi atau cetak, gunakan 4x. Ekspor dibatasi 8000px pada sisi terpanjang, dan itu jarang penting untuk ikon dan logo.

Bisakah saya mengonversi file SVG di ponsel?

Ya. Buka alat ini di browser ponsel Anda, ketuk area unggah, dan pilih file SVG dari perangkat Anda. Konversi berjalan di ponsel, dan PNG-nya terunduh ke perangkat Anda. Pertahankan batch ponsel tetap kecil, karena SVG kompleks membutuhkan waktu untuk diraster di seluler.

Nama file apa yang akan dipertahankan PNG hasil ekspor?

PNG mempertahankan nama file SVG asli Anda dengan ekstensi .png, jadi logo.svg menjadi logo.png. Itu memudahkan pencarian dan menjaga file Anda tetap terorganisasi. Untuk batch, ZIP berisi setiap PNG dengan nama asli yang cocok.

Apakah konverter mendukung animasi SVG?

Tidak, tidak sungguh. Animasi SVG yang memakai SMIL atau CSS tidak dipertahankan, karena konverter menggambar satu frame statis ke kanvas. Hasilnya berupa PNG diam dari SVG seperti tampilannya di awal. Untuk logo bergerak, pertahankan SVG itu sendiri.

Bisakah saya meraster SVG dengan gambar yang disematkan sebagai data URI?

Ya. Gambar yang disematkan sebagai data URI di dalam SVG adalah bagian dari file, jadi ia dirender dengan benar di PNG. Itulah cara yang tepat untuk menyertakan foto dalam SVG untuk konversi. Gambar eksternal yang ditautkan, sebaliknya, tertinggal, karena konverter tidak bisa mengambilnya.

Kenapa PNG hasil konversi saya terlihat buram?

Skalanya terlalu rendah untuk ukuran yang Anda butuhkan. Ikon 24px yang diraster pada 1x hanya 24 piksel, dan merentangkannya ke 200 piksel membuatnya buram. Rasterisasi lagi pada skala yang lebih tinggi dari SVG asli, karena PNG beresolusi rendah tidak bisa ditajamkan setelahnya.
