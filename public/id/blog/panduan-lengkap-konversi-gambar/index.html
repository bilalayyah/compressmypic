Konversi Gambar: Panduan Lengkap

Ubah gambar JPG, PNG, WebP, HEIC, SVG, BMP, GIF, dan AVIF langsung di browser. Format, kualitas, transparansi, dan tips konversi massal dijelaskan lengkap.

Setiap gambar di perangkat Anda tersimpan dalam sebuah format, dan format-format itu tidak selalu cocok satu sama lain. Ponsel menyimpan HEIC, kamera menyimpan JPG, desainer bekerja dengan PNG, dan website menyajikan WebP. Ketika format yang salah bertemu aplikasi yang salah, file itu langsung menolak dibuka.

Konverter gambar menyelesaikan ketidakcocokan itu. Alat ini membaca file dalam satu format lalu menulisnya kembali dalam format lain, tanpa mengubah gambarnya sendiri. Pikselnya tetap sama, hanya wadahnya yang berubah, sehingga file bisa dipakai di mana pun Anda butuhkan.

Panduan ini menjelaskan cara kerja konversi gambar, format mana yang sebaiknya dipilih, dan cara mendapatkan hasil yang bersih setiap kali. Anda akan belajar tentang pengaturan kualitas, transparansi, konversi massal, dan kesalahan yang paling banyak membuang waktu.

Apa Itu Konverter Gambar?

Konverter gambar adalah alat yang mengubah format file sebuah foto tanpa mengubah apa yang ditampilkan foto itu. Anda memberinya sebuah JPG, dan ia mengembalikan PNG, WebP, atau format lain yang didukungnya.

Konversi ini menulis ulang cara piksel disimpan. JPG menyimpan warna dengan kompresi lossy, sedangkan PNG menyimpannya tanpa kehilangan data. Gambarnya tampak sama, tetapi file itu berperilaku berbeda di aplikasi dan website.

Orang mengonversi gambar karena alasan praktis, bukan untuk bersenang-senang. Sebuah formulir mungkin hanya menerima JPG, website mungkin menuntut WebP, atau percetakan mungkin bersikeras memakai PNG. Konverter menjembatani jarak antara file yang Anda punya dan file yang diminta.

Konverter CompressMyPic berjalan sepenuhnya di browser Anda. Tidak ada yang diunggah ke server, jadi foto Anda tetap berada di perangkat Anda sendiri saat formatnya berubah.

Format Apa Saja yang Ditangani Konverter Ini?

Konverter ini menerima JPG, PNG, WebP, HEIC, SVG, BMP, GIF, dan AVIF sebagai input. Cakupannya meliputi foto ponsel, hasil kamera, screenshot, logo, dan unduhan dari website modern.

Untuk output, Anda bisa memilih JPG, PNG, atau WebP. Ketiga format ini mencakup hampir semua kebutuhan nyata: JPG untuk foto, PNG untuk grafis dan transparansi, serta WebP untuk website.

HEIC layak disebut secara khusus karena iPhone menyimpan foto dalam format ini secara bawaan. Banyak program Windows dan formulir unggahan masih menolak file HEIC, sehingga mengubahnya ke JPG adalah salah satu pekerjaan paling umum di sini.

AVIF adalah format terbaru dalam daftar ini. Ia muncul di website modern dan di beberapa galeri Android, tetapi perangkat lunak lama tidak bisa membukanya. Mengubah AVIF ke JPG atau PNG membuat file tersebut bisa dipakai di mana saja.

Bagaimana Cara Kerja Konversi di Browser?

Ketika Anda meletakkan file ke konverter, browser mendekode file itu menjadi piksel menggunakan dukungan gambar bawaan. Untuk file HEIC, sebuah dekoder WebAssembly kecil berjalan di dalam tab, karena browser tidak bisa mendekode HEIC secara native.

Piksel-piksel itu kemudian digambar ke HTML5 Canvas, yaitu permukaan gambar milik browser. Canvas lalu mengenkode piksel tersebut sekali lagi, kali ini dalam format yang Anda pilih, pada kualitas yang Anda tentukan.

Karena semuanya terjadi secara lokal, kecepatan konversi bergantung pada perangkat Anda, bukan pada koneksi internet. Foto berukuran besar terkonversi dalam satu atau dua detik di ponsel atau laptop modern.

Pendekatan lokal ini juga melindungi privasi. Screenshot rekening bank, foto KTP, dan foto keluarga tidak pernah meninggalkan perangkat Anda, dan itu jauh lebih penting daripada yang disadari kebanyakan orang.

Memilih Format Output yang Tepat

JPG adalah pilihan paling aman untuk foto. Format ini menangani gradasi halus, warna kulit, dan pemandangan yang ramai dengan baik, dan semua perangkat serta website di dunia bisa membukanya. Pakailah JPG ketika kompatibilitas adalah yang paling penting.

PNG adalah pilihan yang tepat ketika Anda butuh transparansi atau tepi yang sangat tajam. Logo, ikon, screenshot berisi teks, dan grafis dengan warna datar semuanya tampak paling bagus sebagai file PNG.

WebP adalah pilihan terbaik untuk website. Format ini menghasilkan file yang lebih kecil daripada JPG pada kualitas yang setara, dan ia mendukung transparansi seperti PNG. Sebagian besar browser modern dan pembuat website sudah menerimanya sekarang.

Ketika Anda ragu, tanyakan file itu untuk apa. Foto untuk formulir membutuhkan JPG, logo untuk website membutuhkan PNG atau WebP, dan gambar untuk postingan blog biasanya membutuhkan WebP.

Penjelasan tentang Pengaturan Kualitas

Slider kualitas mengatur seberapa banyak detail yang dipertahankan encoder saat menulis file JPG atau WebP. Angka yang lebih tinggi mempertahankan lebih banyak detail dan menghasilkan file yang lebih besar, sedangkan angka yang lebih rendah memperkecil file dan melembutkan gambar.

Pengaturan sekitar 80 hingga 85 persen cocok untuk sebagian besar foto. Pada level itu, file jauh lebih kecil daripada aslinya, tetapi perbedaannya sulit terlihat tanpa memperbesar gambar.

Slider ini tidak aktif ketika PNG dipilih, dan itu bukan bug. PNG adalah format lossless, jadi tidak ada level kualitas yang bisa dipilih. Setiap piksel disimpan secara persis, dan ukuran file menjadi berapapun yang dibutuhkan.

Untuk foto WebP di website, kisaran 75 hingga 85 persen sudah bagus. Untuk foto yang akan dicetak, naikkan kualitas ke 90 persen atau lebih, karena cetakan memperlihatkan cacat yang disembunyikan layar.

Transparansi dan Warna Isian Matte

JPG tidak bisa menyimpan transparansi, jadi sesuatu harus mengisi bagian yang tembus pandang ketika PNG diubah menjadi JPG. Sesuatu itu disebut warna isian matte, dan Anda bisa memilihnya sebelum mengonversi.

Putih adalah pilihan yang biasa, karena sebagian besar dokumen dan halaman web berlatar putih. Logo yang dikonversi di atas warna putih tampak natural di halaman putih atau di dokumen Word.

Hitam lebih cocok untuk desain gelap, dan warna merek bisa disesuaikan dengan latar website tertentu. Konverter memungkinkan Anda memilih warna hex apa pun, sehingga Anda bisa mencocokkannya dengan halaman secara persis.

Ketika mengonversi ke PNG atau WebP, transparansi justru dipertahankan. Area yang tembus pandang tetap tembus pandang, dan itulah alasan format-format itu cocok untuk logo dan stiker.

Mengonversi Banyak File dan Unduhan ZIP

Anda tidak perlu mengonversi satu file demi satu file. Letakkan seluruh folder berisi format campuran ke dalam antrean, pilih satu format output, lalu konversi semuanya sekaligus.

Setiap file terkonversi secara mandiri, sehingga satu file yang rusak tidak bisa menghentikan file lainnya. Gambar yang korup menampilkan lencana kesalahan, sementara file yang valid tetap selesai dan bisa diunduh seperti biasa.

Ketika dua file atau lebih selesai, tombol Download All menggabungkannya menjadi satu arsip ZIP. Itu jauh lebih mudah daripada mengunduh dua puluh file satu per satu.

Nama file output mempertahankan nama asli Anda dan hanya mengganti ekstensinya. File bernama beach-day.heic menjadi beach-day.jpg, sehingga Anda selalu tahu file mana yang mana.

Foto HEIC dari iPhone

iPhone menyimpan foto sebagai HEIC karena format ini menyimpan kualitas yang sama dalam ruang sekitar setengah dari JPG. Konsekuensinya adalah kompatibilitas, karena banyak program di luar dunia Apple sama sekali tidak bisa membuka HEIC.

Konverter mendekode file HEIC dengan dekoder WebAssembly yang berjalan di dalam tab browser Anda. Ia membaca wadah HEIC secara lokal, merender fotonya, lalu mengekspor JPG, PNG, atau WebP standar.

JPG hasil konversi sering tampak lebih besar dalam megabyte daripada file HEIC aslinya. Itu normal, karena HEIC adalah format yang lebih efisien. JPG-nya tidak lebih buruk, ia hanya disimpan dengan cara yang kurang efisien.

Jika iPhone Anda terus menghasilkan file HEIC dan Anda lebih suka JPG, Anda bisa mengubah pengaturan kamera di ponsel itu sendiri. Sampai saat itu, mengonversi setiap batch hanya memakan beberapa detik.

File SVG dan Vektor

File SVG berbeda dari format lain karena ia mendeskripsikan bentuk dengan kode, bukan dengan piksel. Logo yang disimpan sebagai SVG bisa diperbesar ke ukuran apa pun tanpa pernah menjadi buram.

Mengonversi SVG ke PNG atau WebP mengubah bentuk-bentuk itu menjadi piksel pada ukuran yang tetap. Hasilnya adalah gambar raster biasa yang bisa dibuka aplikasi apa pun, dan itu berguna ketika website atau formulir tidak menerima SVG.

Gambar tertaut di dalam SVG tidak akan selamat dalam perjalanan ini, karena browser tidak bisa mengambilnya selama konversi. Sematkan gambar sebagai data URI di dalam SVG jika gambar itu harus muncul di PNG.

Font web di dalam SVG juga bisa kembali ke font bawaan selama konversi. Untuk logo, ubah teks menjadi outline di alat desain Anda sebelum mengonversi, agar hurufnya tetap persis.

Memeriksa Kualitas Sebelum Menyimpan

Setiap kartu hasil konversi memiliki tombol Compare yang membuka tampilan berdampingan antara file asli dan file hasil konversi. Seret gagang pemisah melintasi gambar untuk memeriksa tepi, teks, dan detail halus.

Perbandingan ini juga menampilkan ukuran file sebelum dan sesudah. Angka itu memberi tahu apakah konversi benar-benar menghemat ruang, yang memang menjadi tujuan utama untuk gambar web.

Perbesar area yang paling penting. Wajah, teks kecil, dan garis diagonal yang tajam paling dulu memperlihatkan kerusakan kompresi, sementara langit yang halus dan latar yang buram menyembunyikannya dengan baik.

Jika hasilnya tampak lembut, naikkan slider kualitas lalu konversi lagi. File asli masih ada di antrean, jadi Anda tidak perlu mengunggahnya ulang untuk mencoba pengaturan lain.

Privasi: Apa yang Terjadi pada File Anda?

Konversi terjadi di perangkat Anda, jadi file Anda tidak pernah diunggah ke server. Itulah keunggulan privasi terbesar konverter browser dibandingkan layanan cloud.

Menggambar gambar ke Canvas juga menghapus metadata tersembunyi. Data EXIF kamera, tag lokasi GPS, dan nomor seri kamera tidak selamat dari konversi, dan itu melindungi Anda saat membagikan file secara online.

Tidak ada akun, tidak ada antrean unggahan di server, dan tidak ada salinan foto Anda yang tertinggal. Menutup tab berarti mengakhiri sesi sepenuhnya.

Untuk file sensitif seperti scan KTP dan dokumen medis, pendekatan lokal ini adalah pilihan paling aman. Jangan pernah mengunggah dokumen identitas ke konverter yang tidak Anda percayai.

Kesalahan Umum yang Harus Dihindari

Kesalahan paling umum adalah mengonversi JPG lossy menjadi PNG lalu berharap kualitasnya meningkat. Itu tidak akan terjadi. PNG menyimpan piksel yang rusak itu dengan sempurna, sehingga file menjadi lebih besar sementara gambarnya tetap cacat seperti sebelumnya.

Kesalahan lain adalah mengabaikan warna isian matte. Logo transparan yang dikonversi ke JPG dengan isian hitam tampak rusak di halaman putih, dan perbaikannya hanyalah perubahan warna selama sepuluh detik sebelum mengonversi.

Orang juga lupa bahwa GIF animasi menjadi gambar diam di sini. Canvas hanya menggambar frame pertama, sehingga gerakannya hilang. Gunakan Kompresor GIF jika Anda perlu mempertahankan animasinya.

Terakhir, jangan mengonversi file yang sama bolak-balik antara format lossy. Setiap putaran enkoding JPG menambah kerusakan baru, jadi selalu konversi dari file asli terbaik yang Anda miliki.

Mengonversi untuk Tujuan yang Berbeda

Setiap tujuan punya format favoritnya sendiri, dan konverter harus menyesuaikan dengan tujuan itu, bukan dengan kebiasaan Anda. Website menginginkan WebP, formulir menginginkan JPG, dan alat desain menginginkan PNG, sehingga gambar sumber yang sama mungkin butuh tiga konversi berbeda.

Untuk website, WebP adalah target yang cerdas. Format ini menjaga halaman tetap cepat dan mendukung transparansi, sehingga cocok untuk logo maupun foto. Konversi gambar ke WebP pada kualitas 80 persen lalu unggah versi itu ke situs Anda.

Untuk email, JPG adalah target yang aman. Klien email menampilkan JPG dengan andal, sementara dukungan WebP tidak konsisten dan file PNG sering terlalu besar untuk batas lampiran. JPG pada kualitas 85 persen adalah pilihan yang praktis.

Untuk cetak, JPG pada kualitas 90 persen atau PNG adalah target yang tepat, tergantung isinya. Foto tercetak baik sebagai JPG berkualitas tinggi, sementara dokumen berisi teks tercetak lebih baik sebagai PNG, karena hurufnya tetap tajam di atas kertas.

Untuk media sosial, periksa dulu platformnya. Sebagian besar platform tetap mengonversi unggahan ke format mereka sendiri, jadi JPG berkualitas tinggi biasanya merupakan input yang paling sederhana. PNG juga bisa dipakai, meskipun file yang lebih besar diunggah lebih lambat.

Penamaan File dan Pengorganisasian Setelah Konversi

File hasil konversi layak diberi nama yang jelas, karena folder berisi IMG_4821.jpg tidak berguna sebulan kemudian. Pertahankan nama aslinya, ubah ekstensinya, dan tambahkan tag pendek yang menjelaskan tujuannya, seperti hero-web.webp atau passport-photo.jpg.

Simpan file hasil konversi secara terpisah dari file asli. Folder bernama converted atau web-ready memisahkan kedua kelompok itu, sehingga Anda tidak pernah menimpa salinan master secara tidak sengaja atau mengirim versi yang salah.

Ketika satu batch menghasilkan beberapa format, gunakan subfolder untuk setiap format. Folder untuk file WebP dan folder lain untuk file JPG lebih mudah dijelajahi daripada satu folder yang berisi keduanya, terutama ketika namanya mirip.

Hapus konversi yang gagal atau duplikat dengan segera. Folder yang penuh dengan percobaan setengah jadi memperlambat Anda setiap kali mencarinya, sementara folder yang rapi membuat pekerjaan berikutnya lebih cepat.

Cadangkan file asli sebelum pekerjaan konversi besar apa pun. File hasil konversi tidak pernah bisa menjadi file asli yang sempurna lagi, jadi file master layak mendapat salinan aman di drive terpisah atau di penyimpanan cloud.

Foto lama hasil scan juga sering membutuhkan konversi. Scan lama biasanya tersimpan sebagai BMP atau TIFF, dan kedua format itu jarang diterima formulir online maupun aplikasi chat. Mengubahnya ke JPG membuat foto keluarga lama bisa dibagikan kepada kerabat tanpa meminta mereka menginstal perangkat lunak khusus apa pun.

Arsip keluarga layak mendapat perhatian khusus. Simpan salinan master dalam format lossless seperti PNG, lalu buat salinan JPG untuk dibagikan. Dengan cara ini, foto asli tetap aman di arsip, sementara versi yang dibagikan bisa dibuka siapa saja, di perangkat apa pun, tanpa masalah kompatibilitas.

Untuk versi langkah demi langkah, baca Cara Mengubah Format Gambar, dan untuk ilmu kualitasnya, lihat Konversi Format Gambar: Apakah Kualitas Menurun dan Kapan Harus Mengonversi. Pertanyaan umum

Apa bedanya mengonversi gambar dan mengompres gambar?

Mengonversi mengubah format file, misalnya JPG menjadi PNG, sedangkan mengompres mengurangi ukuran file, biasanya dalam format yang sama. Konversi juga bisa memperkecil file, contohnya JPG ke WebP, tetapi tugas utamanya adalah kompatibilitas. Kompresi mempertahankan format dan menargetkan ukuran yang lebih kecil.

Apakah mengonversi gambar mengubah dimensi pikselnya?

Tidak, konversi mempertahankan lebar dan tinggi yang sama secara bawaan. Foto 4000 x 3000 piksel tetap 4000 x 3000 setelah dikonversi, hanya format dan ukuran filenya yang berubah. Jika Anda juga butuh dimensi yang lebih kecil, gunakan alat Pengubah Ukuran Gambar setelah mengonversi.

Bisakah saya mengonversi gambar tanpa kehilangan kualitas sama sekali?

Bisa, ketika format tujuannya lossless. Mengubah JPG ke PNG tidak menghilangkan apa pun di luar kerusakan yang sudah ada di JPG, dan mengubah PNG ke WebP dalam mode lossless mempertahankan setiap piksel. Mengubah ke JPG selalu melibatkan sedikit kehilangan, jadi jaga slider kualitas tetap tinggi untuk foto penting.

Mengapa file hasil konversi saya namanya berbeda?

Konverter mempertahankan nama file asli Anda dan hanya mengganti ekstensinya, sehingga beach-day.heic menjadi beach-day.jpg. Ini menjaga file Anda tetap rapi dan memperjelas file mana yang merupakan salinan hasil konversi. Jika dua file bertabrakan namanya, unduhan browser menambahkan angka.

Apakah saya perlu menginstal sesuatu untuk mengonversi gambar di browser?

Tidak. Konverter berjalan sepenuhnya di browser modern pada Windows, Mac, Linux, ChromeOS, Android, dan iOS. Tidak ada aplikasi yang harus diinstal dan tidak ada akun yang harus dibuat. Cukup buka halamannya, letakkan file, lalu unduh hasilnya.

Apa yang harus saya lakukan jika gambar hasil konversi tampak lebih buruk daripada aslinya?

Naikkan slider kualitas lalu konversi lagi dari file asli, karena file asli masih ada di antrean. Periksa apakah Anda mengonversi ke format yang salah, misalnya foto detail ke JPG berkualitas rendah. Jika sumbernya sendiri sudah berkualitas rendah, tidak ada pengaturan yang bisa mengembalikan detail yang memang tidak pernah ada.
