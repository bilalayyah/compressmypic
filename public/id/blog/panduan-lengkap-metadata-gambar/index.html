Panduan Lengkap Melihat Metadata Gambar

Pelajari apa saja yang ditampilkan penampil metadata gambar, mulai dari pengaturan kamera EXIF dan koordinat GPS hingga chunk PNG dan WebP, serta cara memeriksa foto apa pun secara privat di browser.

Setiap foto yang Anda ambil menyimpan lapisan informasi tersembunyi. Pengaturan kamera, waktu pemotretan, model perangkat, dan terkadang lokasi persis Anda ikut tersimpan di dalam file, tanpa terlihat pada gambarnya.

Penampil metadata gambar membaca lapisan tersembunyi itu dan menampilkannya dalam bahasa yang mudah dipahami. Data biner yang rumit diubah menjadi laporan yang bisa Anda gunakan.

Panduan ini menjelaskan apa itu metadata gambar, apa saja yang diungkap penampil, dan cara menggunakannya sebelum Anda membagikan foto. Anda juga akan mempelajari risiko privasi, ekspor JSON, dan cara memeriksa file yang sudah dibersihkan.

Penampil Metadata Gambar berjalan sepenuhnya di browser Anda. Foto Anda tidak pernah meninggalkan perangkat, dan memang itu intinya: privasi.

Apa Itu Metadata Gambar?

Metadata gambar adalah data yang disimpan di dalam file gambar, berdampingan dengan pikselnya. Data ini mendeskripsikan foto, bukan menampilkannya, seperti label yang ditempel di balik foto cetak.

Jenis yang paling umum adalah EXIF, singkatan dari Exchangeable Image File Format. Kamera dan ponsel menulis data EXIF secara otomatis setiap kali Anda menekan tombol rana.

EXIF dapat berisi merek dan model kamera, detail lensa, bukaan, kecepatan rana, ISO, panjang fokus, status lampu kilat, serta tanggal dan waktu persis foto diambil.

Metadata lain tersimpan di tempat yang berbeda. File PNG membawa chunk teks berisi nama penulis, perangkat lunak, dan waktu pembuatan. File WebP dapat menyimpan blok EXIF dan penanda animasi. File JPEG juga dapat membawa paket XMP dan komentar.

Semua ini tidak terlihat saat Anda melihat gambarnya. Anda membutuhkan penampil untuk melihatnya, dan kebanyakan orang tidak pernah memeriksa. Karena itu foto yang dibagikan di internet sering membocorkan lebih banyak daripada yang disadari pemiliknya.

Apa yang Ditampilkan Penampil

Masukkan gambar ke penampil, dan alat ini akan membaca byte mentah file langsung di perangkat Anda. Dalam sekejap Anda mendapat ringkasan, spanduk risiko privasi, dan tabel berisi semua kolom yang ditemukan.

Ringkasan menampilkan format wadah yang terdeteksi, dimensi piksel, dan ukuran file. Ringkasan juga memberi tahu apakah ada jenis tag metadata sensitif yang tertanam.

Tabel mengelompokkan entri agar mudah dipindai. Kolom kamera dikelompokkan bersama, kolom pencahayaan EXIF bersama, kolom GPS bersama, dan chunk PNG atau WebP mendapat kelompok sendiri.

Kolom sensitif ditandai label kuning “Privacy Tag”. Contohnya meliputi koordinat GPS, stempel waktu pengambilan yang persis, nama fotografer, nomor seri kamera, dan nama model perangkat.

Jika ada data GPS, kotak peringatan akan menampilkan garis lintang dan garis bujur yang sudah diterjemahkan. Kotak itu juga menyediakan jalan pintas sekali klik ke alat Hapus Metadata Gambar, supaya Anda bisa langsung membersihkan file.

Penjelasan Kolom EXIF

EXIF disusun ke dalam direktori yang disebut IFD. Penampil membaca tabel TIFF IFD0, ExifIFD, dan GPSIFD dari file JPEG, ditambah blok eXIf PNG dan chunk EXIF WebP.

IFD0 menyimpan fakta dasar tentang gambar dan perangkat. Merek dan model kamera ada di sini, bersama perangkat lunak yang terakhir mengedit file dan catatan hak cipta apa pun.

ExifIFD menyimpan data telemetri pencahayaan yang direkam saat foto diambil. Kecepatan rana, bukaan, ISO, panjang fokus, mode pengukuran, dan status lampu kilat semuanya ada di direktori ini.

GPSIFD menyimpan data lokasi sebagai bilangan rasional. Penampil mengubah derajat, menit, dan detik menjadi garis lintang dan garis bujur desimal secara otomatis, sehingga Anda bisa membaca koordinatnya langsung.

Tidak semua kolom muncul di setiap foto. Tangkapan layar tidak punya data kamera, dan foto yang diunduh dari aplikasi pesan biasanya tidak punya EXIF sama sekali, karena aplikasi menghapusnya saat diunggah.

Kolom yang hilang pun memberi informasi berguna. Itu menandakan file sudah pernah diproses, atau foto itu memang bukan file asli dari kamera.

Data GPS dan Privasi

Koordinat GPS adalah hal paling sensitif yang dapat dibawa sebuah foto. Sepasang angka saja dapat menunjuk ke rumah Anda, tempat kerja, sekolah anak Anda, atau titik persis tempat foto diambil.

Ponsel merekam data GPS secara bawaan di kebanyakan aplikasi kamera. Koordinat tersimpan diam-diam, dan tidak ada petunjuk apa pun pada foto yang menandakan keberadaannya.

Membagikan foto yang belum dibersihkan di internet berarti siapa pun yang mengunduhnya dapat membaca lokasi Anda lewat penampil metadata. Termasuk orang asing di marketplace, forum, dan platform sosial.

Penampil membuat risiko ini terlihat jelas. Saat ada tag GPSIFD, spanduk kuning “GPS Location Coordinates Detected” muncul tepat di atas tabel properti, lengkap dengan koordinat yang sudah diterjemahkan.

Memeriksa sebelum mengunggah hanya butuh beberapa detik. Jika koordinat muncul, bersihkan dulu dengan alat Hapus Metadata Gambar sebelum foto itu sampai ke tempat publik.

Header Teknis PNG dan WebP

JPEG paling sering dibahas, tetapi file PNG dan WebP juga membawa metadata sendiri. Penampil membaca chunk teknis ini supaya tidak ada yang tersembunyi.

Untuk file PNG, penampil membaca chunk IHDR yang berisi kedalaman bit dan tipe warna. Penampil juga membaca pHYs, chunk yang menyimpan kepadatan piksel fisik untuk keperluan cetak atau tata letak.

Chunk teks PNG juga penting bagi privasi. Chunk tEXt dan iTXt dapat berisi nama perangkat lunak, nama penulis, komentar, dan waktu pembuatan. Chunk tIME mencatat kapan file terakhir diubah.

Untuk file WebP, penampil membaca penanda VP8X yang menunjukkan apakah gambar punya saluran alfa atau animasi. Chunk EXIF WebP diterjemahkan bersamaan, sehingga data kamera dalam file WebP tidak terlewat.

Penampil juga melaporkan format wadah sebenarnya dengan memeriksa magic bytes biner, bukan nama file. File PNG yang diganti namanya menjadi .jpg tetap dilaporkan sebagai PNG.

Cara Menggunakan Penampil

Menggunakan penampil hanya butuh lima langkah, dan tidak satu pun membutuhkan akun atau unggahan. Semua terjadi di perangkat Anda sendiri.

  1. Seret atau pilih gambar yang ingin diperiksa. File JPG, PNG, WebP, HEIC, GIF, BMP, dan SVG hingga 20 MB diterima, atau tempel dengan Ctrl+V.
  2. Periksa ringkasan dan spanduk risiko privasi di bagian atas. Di sana terlihat format, dimensi, ukuran file, dan apakah ada tag sensitif yang ditemukan.
  3. Perhatikan peringatan lokasi GPS. Jika ada koordinat, kotak peringatan menampilkan garis lintang dan garis bujur yang persis.
  4. Jelajahi tabel metadata hasil ekstraksi. Entri dikelompokkan berdasarkan Kamera, EXIF, GPS, chunk PNG atau WebP, dan Info file, dengan label kuning “Privacy Tag” pada kolom sensitif.
  5. Salin atau ekspor JSON, atau bersihkan tag. Klik Copy JSON untuk laporan lengkap, Export JSON untuk menyimpan file .json, atau Strip Metadata untuk membersihkan file.

Penampil ini sepenuhnya hanya-baca. Alat ini membaca header dari memori browser untuk menunjukkan isi file, tanpa mengubah, mengompres, atau menghapus apa pun dari file asli Anda.

Anda bisa memeriksa file satu demi satu tanpa memuat ulang halaman. Klik ikon tempat sampah merah di bilah ringkasan untuk kembali ke zona unggah, lalu masukkan gambar berikutnya.

Menyalin dan Mengekspor Laporan JSON

Terkadang Anda membutuhkan metadata dalam bentuk yang bisa disimpan, dibagikan, atau ditempel ke laporan bug. Penampil mengekspor seluruh laporan hasil parsing sebagai JSON terstruktur.

Klik Copy JSON di bilah ringkasan untuk menyalin seluruh ImageMetadataReport ke papan klip. Laporan siap ditempel ke dokumen, tiket bantuan, atau pesan obrolan.

Klik Export JSON untuk mengunduh file yang namanya mengikuti nama gambar Anda dengan akhiran _metadata. Pengembang memakai laporan ini untuk men-debug alur kerja gambar dan mendokumentasikan perilaku file.

JSON memuat semua kolom yang berhasil diterjemahkan penampil, dikelompokkan sama seperti tabel di layar. Hal ini memudahkan Anda membandingkan dua file, atau menyimpan catatan tentang isi file sebelum dibersihkan.

Untuk panduan langkah demi langkah memeriksa foto, baca Cara Melihat Metadata Gambar. Untuk mengetahui apa yang sebenarnya diungkap kolom-kolom itu tentang Anda, baca Data EXIF: Apa yang Foto Anda Ungkapkan.

Memverifikasi File yang Sudah Dibersihkan

Salah satu pekerjaan paling berguna bagi penampil metadata adalah memeriksa hasil kerja alat lain. Setelah membersihkan foto, masukkan kembali hasil bersihnya ke penampil untuk memastikan tag benar-benar hilang.

Jika pembersihan berhasil, spanduk status hijau memastikan tidak ada tag EXIF, GPS, atau kamera tersembunyi yang terdeteksi, dan tidak ada peringatan GPS yang muncul. Ini pemeriksaan nyata terhadap byte file, bukan tebakan.

Hal ini penting karena sebagian alat mengklaim menghapus metadata tetapi menyisakan chunk. Blok tEXt PNG atau komentar JPEG bisa lolos dari alat pembersih yang ceroboh. Penampil menangkap sisa-sisa itu.

Jadikan verifikasi sebagai kebiasaan untuk foto sensitif. Periksa, bersihkan, lalu periksa lagi. Pemeriksaan kedua hanya butuh beberapa detik dan membuktikan langkah pertama berhasil.

Jika file yang sudah dibersihkan masih menampilkan tag, coba opsi Full Canvas Re-encode di alat Hapus Metadata Gambar. Opsi ini membangun ulang piksel dari nol, sehingga semua segmen biner warisan ikut terbuang.

Kapan Harus Memeriksa Metadata

Periksa metadata setiap kali foto keluar dari penyimpanan pribadi Anda. Risikonya bukan pada fotonya sendiri, melainkan pada siapa yang bisa mengunduhnya dan apa yang bisa mereka baca dari file itu.

  • Sebelum mengunggah ke iklan marketplace, tempat pembeli mengunduh gambar resolusi penuh.
  • Sebelum membagikan foto keluarga di media sosial, terutama foto yang diambil di rumah atau sekolah.
  • Sebelum mengirim foto ke wartawan, klien, atau orang asing yang mungkin meneruskannya lagi.
  • Sebelum memublikasikan foto di blog atau situs web, tempat file bisa diunduh bertahun-tahun.
  • Setelah menerima foto, untuk mengetahui kapan dan di mana foto itu diambil serta dengan kamera apa.
  • Saat men-debug alur kerja gambar, untuk melihat kolom mana yang bertahan di setiap tahap pemrosesan.

Fotografer memeriksa metadata dengan alasan berbeda. Pengaturan pencahayaan dari foto yang bagus adalah resep yang layak disimpan, dan penampil membaca ISO, bukaan, dan kecepatan rana dalam hitungan detik.

Pengembang memeriksanya saat gambar berperilaku aneh. Penanda orientasi yang salah, nilai DPI yang tidak terduga, atau profil warna tersembunyi sering menjelaskan bug tampilan.

Foto yang dikirim lewat email atau tautan cloud juga layak diperiksa. Jalur itu mempertahankan file asli, sehingga metadata ikut terkirim bersama foto. Pemeriksaan lima detik dapat mencegah alamat rumah ikut tersebar.

Periksa juga foto lama sebelum diunggah ulang. Foto dari arsip keluarga mungkin diambil bertahun-tahun lalu, tetapi koordinat GPS di dalamnya tetap akurat. Lokasi rumah lama atau sekolah lama tetap bisa dibaca orang lain.

Terakhir, biasakan memeriksa foto sebelum dibagikan ke grup besar. Sekali foto tersebar di grup, Anda tidak bisa menarik kembali salinan yang sudah diunduh anggota lain.

Apa yang Tidak Bisa Dilakukan Penampil

Penampil ini jujur tentang batasannya. Parser chunk biner mendalamnya menargetkan wadah JPEG, PNG, dan WebP secara native dalam JavaScript, dan ketiga format itu mendapat laporan paling lengkap.

Untuk file HEIC, GIF, BMP, dan SVG, penampil melaporkan info wadah, ukuran file, dan dimensi piksel yang andal. Chunk EXIF biner lengkap tidak diekstrak untuk format-format itu, sehingga file HEIC bisa menampilkan detail lebih sedikit dibanding foto yang sama dalam JPEG.

Tangkapan layar yang ditempel biasanya tidak menampilkan tag kamera. Papan klip sistem operasi hanya meneruskan bitmap raster mentah, bukan file kamera asli, sehingga gambar dari papan klip sama sekali tidak punya header kamera.

Foto yang diunduh dari WhatsApp atau Instagram menunjukkan nol tag EXIF karena alasan serupa. Jejaring sosial dan aplikasi pesan menghapus header EXIF, kamera, dan GPS secara otomatis saat Anda mengunggah lewat server mereka.

Batas 20 MB per file sudah mencakup JPEG DSLR resolusi penuh, ekspor PNG yang detail, dan file BMP tanpa kompresi. File yang lebih besar perlu dikompres dulu, misalnya dengan alat kompres gambar.

Memeriksa Metadata di Ponsel

Kebanyakan foto diambil dengan ponsel, jadi penampil juga berfungsi di browser seluler. Buka halaman di Safari atau Chrome seluler dan pilih foto langsung dari galeri Anda.

Anda bisa memeriksa koordinat GPS tersembunyi dan detail kamera di ponsel sebelum mengunggah foto ke internet. Di momen itulah pemeriksaan paling penting, karena unggahan biasanya dilakukan dari ponsel.

Tampilannya sama seperti di desktop. Spanduk ringkasan, peringatan GPS, dan tabel berkelompok semuanya muncul, dan tindakan Copy JSON serta Strip Metadata bekerja dengan cara yang sama.

Jika Anda menemukan data GPS pada foto ponsel, bersihkan dulu sebelum dibagikan. Alat Hapus Metadata Gambar juga berfungsi di ponsel, sehingga seluruh alur periksa-dan-bersihkan muat di saku Anda.

Di ponsel, pemeriksaan paling efektif dilakukan sebelum foto masuk ke aplikasi apa pun. Begitu foto dibagikan lewat galeri, salinan aslinya sudah berpindah, dan Anda tidak bisa lagi mengontrol siapa yang menyimpannya.

Versi Singkat

Metadata gambar adalah data tersembunyi di dalam setiap foto: pengaturan kamera, stempel waktu, catatan perangkat lunak, dan terkadang koordinat GPS. Penampil membuatnya terlihat.

Periksa foto apa pun sebelum dibagikan ke publik, terutama foto yang diambil di rumah, di sekolah, atau di tempat kerja. Cari peringatan GPS dulu, lalu pindai label kuning “Privacy Tag”.

Ekspor JSON saat Anda butuh catatan, dan verifikasi file yang sudah dibersihkan dengan memeriksanya lagi. Penampil ini gratis, tanpa pendaftaran, dan tidak pernah mengunggah foto Anda ke mana pun.

Mulailah dengan Penampil Metadata Gambar, dan saat file perlu dibersihkan, langsung lanjut ke alat Hapus Metadata Gambar. Foto Anda seharusnya hanya menunjukkan apa yang Anda pilih untuk dibagikan, dan tidak lebih.

Pertanyaan umum

Apa bedanya metadata EXIF, XMP, dan IPTC?

EXIF adalah data yang ditulis kamera, seperti pengaturan pencahayaan, stempel waktu, dan koordinat GPS. XMP adalah paket XML dari Adobe yang dapat berisi riwayat pengeditan, penilaian, dan deskripsi. IPTC adalah standar pers dan penerbitan untuk keterangan, kredit, dan kata kunci. Satu foto dapat membawa ketiganya sekaligus, dan penampil menampilkan kolom EXIF dan kolom bergaya XMP beserta chunk teks PNG dalam satu tabel berkelompok.

Apakah penampil metadata bisa memberi tahu lokasi foto diambil?

Ya, jika foto berisi koordinat GPS. Penampil menerjemahkan tag GPSIFD menjadi garis lintang dan garis bujur desimal, lalu menampilkannya di spanduk peringatan. Tanpa tag GPS, penampil tidak bisa menebak lokasi — penampil hanya bisa menunjukkan waktu pengambilan dan detail kamera, yang mungkin memberi petunjuk tentang tempat, tetapi tidak pernah membuktikannya.

Apakah penampil berfungsi untuk foto dari kamera DSLR atau mirrorless?

Ya. Kamera DSLR dan mirrorless menulis data EXIF yang kaya, termasuk model lensa, panjang fokus, bukaan, kecepatan rana, ISO, dan mode pengukuran. Penampil menerjemahkan semuanya dari direktori ExifIFD. File JPEG resolusi penuh hingga 20 MB didukung, dan itu sudah mencakup sebagian besar hasil ekspor kamera.

Mengapa sebagian foto saya menampilkan metadata dan sebagian lagi tidak?

File asli dari galeri kamera menyimpan metadata lengkap. Foto yang melewati WhatsApp, Instagram, Facebook, atau email biasanya tiba dalam keadaan terhapus, karena layanan-layanan itu menghilangkan header EXIF dan GPS saat diunggah. Tangkapan layar juga tidak menampilkan tag kamera, karena papan klip hanya meneruskan piksel mentah, bukan file kamera asli.

Apakah aman memeriksa foto pribadi di penampil metadata online?

Tergantung alatnya. Penampil ini mem-parsing byte file secara lokal di browser Anda, jadi nol byte meninggalkan perangkat Anda — tidak ada yang diunggah ke server. Hindari penampil yang mengharuskan unggahan, karena mengirim foto yang belum dibersihkan ke server sama saja menyerahkan data GPS dan detail kamera Anda ke pihak ketiga.

Bisakah saya memakai penampil untuk memeriksa foto kiriman orang lain?

Ya. Simpan fotonya, masukkan ke penampil, dan baca tabel berkelompoknya. Anda bisa melihat kapan foto diambil, dengan kamera apa, dan apakah foto itu membawa koordinat GPS. Ingat, file yang sudah dibersihkan tidak menampilkan apa-apa — itu hanya membuktikan metadatanya sudah dihapus, bukan membuktikan foto itu asli.
