Come Cambiare il DPI di un’Immagine

Cambia il DPI di un’immagine a 72, 150, 300 o 600 in quattro passaggi — oppure qualsiasi valore personalizzato fino a 2400. Supporto in blocco, download ZIP e badge DPI Verificato inclusi.

La tua immagine è pronta, ma la piattaforma vuole 300 DPI e il tuo file dice 72, oppure non dice nulla. La correzione richiede meno di un minuto, una volta che conosci i passaggi.

Questa guida ti accompagna nel cambiare il DPI dell’immagine in quattro passaggi pratici: carica, scegli il valore, verifica il badge e scarica. Copre anche i lotti, gli screenshot e i problemi comuni che fanno inciampare le persone.

Nessun software da installare, nessun account da creare e nessun pixel danneggiato. La modifica è un intervento sui metadati, quindi la tua immagine sembra esattamente uguale quando hai finito.

Cosa Ti Serve Prima di Cominciare

Ti servono i file di immagine in formato JPEG o PNG. Sono gli unici formati che memorizzano un tag DPI in modo standard, quindi lo strumento accetta solo quei due.

Sappi quale valore DPI vuole la tua destinazione. I tipografi di libri e le riviste di solito chiedono 300, le bozze di stampa accettano 150, e gli schermi sono contenti con 72 o 96.

Controlla le dimensioni in pixel prima di cominciare. I DPI non possono salvare un’immagine con troppo pochi pixel, quindi conferma che le dimensioni siano abbastanza grandi per la dimensione di stampa che ti serve.

Un browser è tutto il software che ti serve. Lo strumento gira su Chrome, Safari, Firefox ed Edge, su desktop e su mobile, senza estensioni.

Passaggio 1: Carica i Tuoi File JPEG o PNG

Apri lo strumento per cambiare il DPI dell’immagine e trascina i file nell’area di caricamento. Puoi caricare un’immagine sola o un intero lotto in una volta.

Puoi anche fare clic sull’area di caricamento per cercare i file, oppure incollare uno screenshot dagli appunti con Ctrl+V per timbrarlo subito senza salvarlo prima.

Ogni file compare in un elenco con i suoi DPI attuali accanto. Molte foto leggeranno “Prima: Non impostato”, che significa semplicemente che il file non ha ancora un tag DPI.

Se un file viene rifiutato, controlla il suo formato. I file WebP, HEIC, BMP, GIF e SVG non sono supportati qui, e lo strumento te lo dirà invece di fallire in silenzio.

Passaggio 2: Scegli un Preset o un DPI Personalizzato

Scegli uno dei cinque preset: 72 per schermo, 96 per Windows, 150 per bozze di stampa, 300 per stampa di alta qualità oppure 600 per lavoro d’archivio. Per la maggior parte dei lavori editoriali, 300 è la scelta giusta.

Se la tua destinazione chiede un numero diverso, digitalo nel campo DPI personalizzato. Qualsiasi numero intero da 1 a 2400 è accettato, quindi valori come 200 o 350 vanno bene.

Lo stesso valore si applica a ogni file del lotto. Se immagini diverse hanno bisogno di valori DPI diversi, elaborale in lotti separati, un valore alla volta.

Ricontrolla il numero prima di elaborare. Un refuso che trasforma 300 in 3000 è facile da fare e verrà scritto fedelmente, quindi rileggi il campo ancora una volta.

Passaggio 3: Elabora e Cerca il Badge di Verifica

Fai clic per elaborare i file. Lo strumento riscrive il tag DPI nell’intestazione di ogni file e poi rilegge il file per confermare che il nuovo valore sia memorizzato correttamente.

Ogni file riuscito mostra un badge DPI Verificato. Quel badge è la conferma che il file riporterà lo stesso DPI in qualsiasi lettore conforme agli standard, inclusa la tua piattaforma editoriale.

Se un file mostra invece un errore, leggi il messaggio. Un JPEG corrotto o un formato non supportato verrà segnalato chiaramente, e il resto del lotto continuerà a elaborarsi normalmente.

Non saltare il passaggio di verifica. Un file elaborato ma non verificato è un azzardo, e un invio fallito costa molto più tempo di una seconda occhiata al badge.

Passaggio 4: Scarica i File Timbrati

Scarica ogni file singolarmente, oppure fai clic sul download ZIP per ottenere l’intero lotto in un unico archivio. Lo ZIP mantiene i nomi di file originali, così le immagini rientrano direttamente nel tuo progetto.

I file di output hanno nomi chiari, così puoi distinguerli dagli originali. Conserva anche gli originali, così hai sempre una copia intatta a cui tornare.

Apri un file scaricato nella tua piattaforma o in un visualizzatore di immagini e conferma che i DPI si leggano correttamente. Quella verifica finale richiede pochi secondi e individua qualsiasi malinteso prima dell’invio.

Invia i file timbrati alla tua piattaforma. Se la piattaforma si lamenta ancora, il problema di solito è nelle dimensioni in pixel, non nei DPI, quindi controlla quelle dopo.

Cambiare i DPI per un Intero Lotto

Libri, cataloghi e articoli di rivista hanno bisogno di decine di immagini allo stesso DPI. Il flusso in blocco le gestisce tutte in un unico passaggio con un solo preset.

Trascina l’intera cartella nello strumento e scegli il valore una volta sola. Ogni file viene timbrato, verificato ed elencato con il suo badge, così vedi a colpo d’occhio se qualche file è fallito.

Scarica il lotto come un unico ZIP. L’archivio conserva i nomi dei file, e questo conta quando le immagini sono richiamate per nome in un documento o in un file di layout.

Se alcuni file del lotto sono WebP o HEIC, convertili prima. Lo strumento per convertire immagini li trasforma in JPG o PNG, e poi possono unirsi al lotto successivo.

DPI per Editoria di Stampa e Riviste

Le piattaforme di libri come Amazon KDP controllano i DPI di ogni immagine del manoscritto. Una copertina o un’immagine interna con tag sotto il loro minimo viene rifiutata, e l’intero invio si blocca.

Le riviste accademiche sono ancora più rigide. Molte richiedono 300 DPI per le fotografie e 600 DPI per i disegni al tratto, e controllano il tag prima di controllare il contenuto.

Il flusso di lavoro è lo stesso in entrambi i casi: conferma prima le dimensioni in pixel, timbra i DPI per secondi, verifica il badge per terzi e invia per quarti. Saltare il primo passaggio è la causa più comune di un secondo rifiuto.

Per i disegni al tratto, usa il preset a 600 DPI. Le linee sottili e il testo piccolo hanno bisogno della densità extra, e un disegno a 300 DPI può sembrare seghettato quando viene stampato a dimensione piena.

Correggere un File a 72 DPI che È Stato Rifiutato

Un rifiuto a 72 DPI è il problema DPI più comune, ed è anche il più facile da risolvere. I pixel di solito vanno bene; solo il tag dei metadati è sbagliato.

Carica il file, scegli il preset a 300 DPI ed elaboralo. Lo strumento riscrive il tag, lo verifica, e il file scaricato supera il controllo della piattaforma.

Prima di inviarlo di nuovo, conferma le dimensioni. Un file a 72 DPI che è anche piccolo in pixel fallirà di nuovo, questa volta sulle dimensioni, e nessun valore DPI può risolvere quello.

Se il file è uno screenshot, si applica la stessa correzione. Gli screenshot di solito portano un tag a 72 o 96 DPI, e timbrarli a 300 DPI li rende accettabili per i flussi di stampa, a condizione che i pixel bastino.

DPI per gli Screenshot

Gli screenshot sono la correzione DPI più rapida di tutte, perché puoi incollarli direttamente dagli appunti. Copia lo schermo, premi Ctrl+V nello strumento, e lo screenshot è pronto da timbrare.

Scegli 300 DPI per uno screenshot che apparirà in un manuale stampato o in un libro. I pixel sono quelli catturati dallo schermo, ma il tag soddisferà il flusso di stampa.

Sii onesto sui limiti. Uno screenshot di una piccola finestra di dialogo ha pochi pixel, e timbrarlo a 300 DPI lo rende una stampa molto piccola, non una stampa grande e nitida.

Per screenshot che devono stampare grandi, catturali prima a una scala di visualizzazione più alta. Uno screenshot fatto su un display retina porta il doppio dei pixel e stampa il doppio più grande.

Rimuovere o Eliminare un Tag DPI

A volte non vuoi alcun tag DPI, invece di uno diverso. Lo strumento può rimuovere i metadati DPI da un file, lasciando intatti i pixel.

La rimozione è utile quando un file porta un tag sbagliato che confonde il tuo software. Una foto con un valore strano può far scalare un programma di layout in modo inatteso, e rimuovere il tag ripristina il comportamento.

Per rimuovere il tag, usa l’opzione di rimozione nello strumento ed elabora il file. Il file scaricato non ha metadati DPI, e il software che lo apre tornerà al suo valore predefinito.

Rimuovi un tag solo quando hai un motivo. La maggior parte dei flussi editoriali vuole un tag presente, e un file senza tag può essere rifiutato tanto facilmente quanto un file con il tag sbagliato.

Risoluzione dei Problemi con Formati Non Supportati

Se lo strumento rifiuta il tuo file, la prima cosa da controllare è il formato. I file WebP, HEIC, BMP, GIF e SVG non sono supportati, e lo strumento lo dirà chiaramente.

Converti il file in JPG o PNG e riprova. Lo strumento per convertire immagini gestisce WebP e HEIC, e la conversione conserva i pixel dando al file un formato che può portare un tag DPI.

Fai attenzione ai file con nomi sbagliati. Un file WebP salvato con estensione .jpg verrà rifiutato anche se il nome sembra giusto, perché lo strumento legge il contenuto reale del file.

Quando hai dubbi, apri il file in un visualizzatore di immagini e risalvalo come JPG o PNG. Un nuovo salvataggio pulito garantisce che il formato corrisponda all’estensione.

Risoluzione dei Problemi con File Corrotti

Un JPEG corrotto fallirà con un messaggio di errore, e il resto del lotto continuerà a elaborarsi. L’errore è specifico di quel file, non dello strumento.

Prova ad aprire il file in un visualizzatore di immagini. Se anche il visualizzatore fallisce, il file è danneggiato e deve essere scaricato di nuovo o riesportato dalla sua fonte.

Un file che si apre nel visualizzatore ma fallisce nello strumento potrebbe avere un’intestazione danneggiata. Risalvarlo dal visualizzatore scrive una nuova intestazione, e il nuovo file di solito si elabora bene.

Non inviare mai un file la cui elaborazione è fallita. Un file corrotto che scivola in un lavoro di stampa può bloccare l’intero invio, quindi sistemalo o sostituiscilo prima di andare avanti.

Controllare il Risultato Dopo il Download

Dopo il download, apri un file e conferma i suoi DPI. Su Windows, fai clic destro sul file, scegli Proprietà e guarda la scheda dei dettagli. Su Mac, aprilo in Anteprima e controlla l’ispettore.

Il numero dovrebbe corrispondere a quello che hai scelto. Un JPEG timbrato a 300 DPI si rilegge come 300, mentre un PNG può rileggersi come 299 a causa di come il PNG memorizza la risoluzione in pixel per metro.

Se il numero è sbagliato, rielabora l’originale invece del file scaricato. Ritimbrare un file già timbrato funziona, ma partire dall’originale mantiene pulita la catena delle modifiche.

Annota il valore che hai usato per ogni progetto. Quando le stesse immagini vanno a una seconda piattaforma con regole diverse, la nota ti dice cosa cambiare senza ricontrollare ogni file.

DPI per Immagini E-commerce e Marketplace

Le immagini dei marketplace vivono sugli schermi, quindi i DPI sembrano irrilevanti per loro, ma i venditori inciampano comunque. La confusione di solito comincia quando una pagina di aiuto del marketplace menziona i DPI insieme alle dimensioni in pixel.

Per le inserzioni di prodotto, le dimensioni in pixel sono la regola che conta. Un marketplace che vuole 1000 pixel sul lato più lungo controlla il numero di pixel, non il tag DPI, e un file timbrato a 300 DPI con solo 600 pixel fallisce comunque.

Detto questo, timbrare le immagini del marketplace a 300 DPI non fa male e occasionalmente aiuta. Alcuni strumenti per venditori e servizi di stampa su richiesta leggono il tag, e un valore corretto mantiene fluidi quei flussi di lavoro.

L’approccio pratico è sistemare prima i pixel e poi i DPI. Conferma le dimensioni con il verificatore di dimensioni, ridimensiona se serve, e poi timbra 300 DPI come passaggio finale prima di caricare le immagini dell’inserzione.

Per i prodotti di stampa su richiesta come tazze, magliette e poster, i DPI contano moltissimo. Il prodotto viene stampato, quindi si applica lo stesso standard di 300 DPI, e il calcolo dei pixel decide quanto grande si può stampare il design.

Controlla i requisiti di stampa su richiesta per ogni prodotto prima di caricare. Un design che funziona su una tazza potrebbe essere troppo piccolo per un poster, e il solo tag DPI non colmerà quel divario.

Riapplicare un Valore DPI Diverso

I progetti cambiano, e un file timbrato a 300 DPI potrebbe in seguito richiedere 600 DPI per un archivio o una stampa di belle arti. Lo strumento ti permette di riapplicare un nuovo valore agli stessi file.

Carica di nuovo i file, scegli il nuovo preset o valore personalizzato ed elaborali. Ogni passaggio è senza perdita, quindi i pixel non vengono mai degradati da timbrature ripetute.

Puoi anche andare nell’altra direzione, da 600 di nuovo a 300, con la stessa sicurezza. L’intestazione viene riscritta ogni volta e i dati dei pixel non vengono mai toccati.

Per il quadro completo su cosa significhi DPI, leggi la Guida Completa allo Strumento per Cambiare il DPI, e per il confronto con i PPI di schermo, vedi DPI vs PPI: Cosa Conta per Stampa e Web.

Domande frequenti

Quanto tempo ci vuole per cambiare i DPI di un’immagine?

Pochi secondi. Lo strumento riscrive alcuni byte nell’intestazione del file e non ricodifica alcun pixel, quindi anche un lotto grande finisce in fretta. Il tempo che spendi è soprattutto per caricare e scaricare, non per elaborare.

Posso cambiare i DPI di molte immagini in una volta?

Sì. Trascina l’intero lotto nello strumento, scegli un unico valore DPI, e ogni JPEG e PNG del lotto viene timbrato in un unico passaggio. Scarica i risultati come un unico file ZIP con i nomi di file originali conservati.

Cosa succede se inserisco per errore un DPI personalizzato sbagliato?

Lo strumento scrive qualsiasi numero inserisci, da 1 a 2400, e lo verifica con il badge. Se noti l’errore, rielabora semplicemente i file originali con il valore corretto. Ogni passaggio è senza perdita, quindi l’errore ti costa un minuto, non l’immagine.

Cambiare i DPI influisce sulla qualità o sui colori dell’immagine?

No. Cambiano solo i metadati di risoluzione nell’intestazione. I pixel, la compressione, i dati EXIF e il profilo colore ICC restano esattamente com’erano. L’immagine sembra identica sullo schermo prima e dopo.

Posso incollare uno screenshot e cambiarne subito i DPI?

Sì. Copia lo screenshot, premi Ctrl+V nello strumento, e compare pronto da timbrare. Scegli 300 DPI per l’uso di stampa, elaboralo e scarica il risultato. È la strada più veloce dalla cattura di schermo al file pronto per la stampa.

Perché il mio file è stato rifiutato dallo strumento DPI?

I motivi usuali sono un formato non supportato come WebP o HEIC, un file oltre il limite di dimensione, oppure un JPEG corrotto. Converti prima i formati non supportati in JPG o PNG, e riesporta qualsiasi file che non si apre in un visualizzatore di immagini.
