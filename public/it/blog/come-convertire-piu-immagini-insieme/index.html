Come convertire più immagini insieme

Converti un’intera cartella di immagini in JPG, PNG o WebP in un unico passaggio. Carica, scegli il formato, imposta la qualità e scarica un unico ZIP.

Convertire una cartella di immagini una per una è un lavoro che ruba ore. Convertirle insieme, in un unico passaggio, richiede minuti.

Questa guida segue i passaggi in ordine: preparare la cartella, caricare il lotto, scegliere il formato e scaricare lo ZIP.

Alla fine, saprai convertire decine di immagini senza errori e senza perdere gli originali.

Passaggio 0: prepara prima la tua cartella

Metti ogni immagine che vuoi convertire in un’unica cartella prima di iniziare. Cercare file a metà lavoro è il modo più sicuro per dimenticarne uno.

Ordina i file per tipo, se puoi. Foto, loghi e screenshot vogliono impostazioni diverse, e ordinarli ora ti fa risparmiare lavoro dopo.

Controlla che ogni file sia valido. Un file danneggiato in mezzo al lotto mostra un errore, ma è meglio scoprirlo prima che durante la conversione.

Rinomina i file importanti con nomi chiari. Un nome come maglia-cotone-blu.jpg dice subito cosa contiene, mentre IMG_4821.jpg non dice niente.

Passaggio 1: carica l’intero lotto

Apri il convertitore di immagini in lotto nel tuo browser. Vedrai una grande area di caricamento al centro della pagina.

Trascina l’intera cartella sull’area di caricamento, e lo strumento raccoglie i file di immagine al suo interno. Puoi anche cliccare l’area e selezionare molti file in una volta nel selettore di file.

In entrambi i casi, ogni immagine valida entra nella stessa coda di conversione. Vengono accettati file fino a 25 MB ciascuno.

Controlla la coda dopo il caricamento. I nomi dei file ti dicono se manca qualcosa o se è entrato un file che non volevi.

Se hai trascinato una cartella intera, controlla che non siano entrati file che non c’entrano, come miniature o file di sistema. Lo strumento prende solo le immagini, ma una verifica non costa niente.

Guarda anche le dimensioni dei file nella coda. Un file da 25 MB tra tanti file da 500 KB potrebbe essere un’immagine a risoluzione enorme che rallenta tutto il lotto.

Se trovi un file sospetto, rimuovilo dalla coda e convertilo separatamente. È meglio un lotto pulito che un lotto con un file che blocca tutto.

Infine, conta i file: il numero nella coda dovrebbe corrispondere al numero di immagini nella cartella. Se manca qualcosa, ricarica la cartella.

Passaggio 2: scegli il formato di destinazione

Scegli JPG quando il lotto è composto soprattutto da fotografie e la destinazione è generica. Il JPG funziona ovunque e mantiene le foto piccole.

Scegli PNG quando il lotto contiene loghi, icone o screenshot con testo che deve restare nitido. Il PNG conserva ogni pixel esattamente.

Scegli WebP quando il lotto è per un sito web. È più piccolo del JPG a parità di qualità e supporta la trasparenza, il che lo rende il migliore tuttofare per il web.

Un lotto produce un unico formato di uscita. Se ti servono due formati, eseguirai il lotto due volte, e va bene così.

Passaggio 3: imposta la qualità una volta sola

Il cursore della qualità si applica a ogni file del lotto. Impostarlo una volta è il vantaggio del lotto, ma anche il suo limite.

Per l’uscita JPG o WebP, l’80–85% è un valore predefinito sicuro per i lotti di foto miste. Le foto sembrano pulite e i file restano leggeri.

Per i lotti con screenshot ricchi di testo, preferisci WebP all’85%. Il testo resta leggibile, e i file sono comunque piccoli.

Per i lotti che pensi di stampare, porta la qualità al 90% o oltre. La stampa mostra difetti che lo schermo nasconde.

Passaggio 4: decidi sulla trasparenza

Se la destinazione è JPG, scegli un colore di riempimento per le aree trasparenti. Il bianco è la scelta predefinita e va bene per la maggior parte dei casi.

Un colore sbagliato rovina l’intero lotto, non un solo file. Controlla una scheda convertita prima di scaricare lo ZIP.

Se la destinazione è PNG o WebP, salta questo passaggio. Entrambi i formati mantengono la trasparenza, quindi le zone trasparenti restano trasparenti.

Quando il lotto mescola loghi trasparenti e foto, dividilo in due. I loghi vogliono trasparenza, le foto vogliono JPG: due lotti, due impostazioni giuste.

Passaggio 5: converti e osserva l’avanzamento

Clicca sul pulsante Converti e osserva le schede cambiare. Ogni file viene convertito a turno, e puoi vedere l’avanzamento in tempo reale.

Per i lotti grandi, la conversione richiede qualche minuto. Aspetta che finisca: chiudere la scheda a metà significa ricominciare.

Fai attenzione agli avvisi di errore mentre il lotto è in esecuzione. Un singolo file danneggiato mostra un avviso senza fermare gli altri.

Se un file fallisce, non preoccuparti. I file validi finiscono comunque, e potrai occuparti del file problematico dopo.

Passaggio 6: rivedi i risultati scheda per scheda

Ogni scheda convertita mostra la nuova dimensione del file accanto a quella vecchia. Quel confronto ti dice subito se la conversione ha risparmiato spazio.

Controlla le prime cinque schede con attenzione. Se le impostazioni sono sbagliate, meglio scoprirlo su cinque file che su cinquanta.

Clicca su Confronta su una scheda per aprire il visualizzatore affiancato. Guarda volti, testo e bordi, e verifica che la qualità sia quella che volevi.

Se un file sembra sbagliato, convertilo di nuovo da solo con impostazioni diverse. L’originale è ancora in coda, quindi non devi caricarlo di nuovo.

Passaggio 7: scarica tutto come un unico ZIP

Clicca su Scarica tutto per raccogliere l’intero lotto in un unico archivio ZIP. È molto più rapido che scaricare venti file uno per uno.

Decomprimi lo ZIP in una cartella nuova, non sopra gli originali. È la regola che rende impossibili le sovrascritture accidentali.

Controlla la cartella decompressa prima di consegnare. I nomi dei file sono quelli originali con la nuova estensione, quindi sai sempre quale file è quale.

Conserva lo ZIP come backup del lotto convertito. Se dovrai inviarlo di nuovo, lo avrai pronto senza rigenerarlo.

Correggere i file che non sono riusciti

Se un file fallisce, controlla prima il suo formato reale. Un file chiamato .jpg che in realtà è un WebP confonde il decodificatore.

Prova a convertire il file da solo, fuori dal lotto. Se funziona da solo, il problema era il lotto; se fallisce ovunque, il file è probabilmente danneggiato.

Se il file è danneggiato, cerca una copia migliore. Una foto danneggiata non si ripara con la conversione, e meglio scoprirlo ora che dopo la consegna.

Non lasciare che un file fallito blocchi il lotto. Scarica lo ZIP dei file riusciti, poi risolvi il file problematico separatamente.

Convertire di nuovo lo stesso lotto in un altro formato

Dopo la prima conversione, puoi cambiare il formato di uscita e convertire di nuovo. Gli originali restano in coda, quindi non devi caricarli un’altra volta.

Scarica ogni versione prima di cambiare formato. Il pulsante di download salva la conversione corrente, non quelle precedenti.

Usa suffissi diversi per i nomi dei file, come -webp e -jpg, così le uscite restano distinte. Due cartelle con lo stesso nome creano solo confusione.

È il modo più semplice per preparare sia versioni WebP sia versioni JPG per un sito. Le versioni WebP vanno per prime, le JPG come riserva.

Consigli per i lotti da telefono

Il convertitore in lotto funziona nel browser del telefono, ma i lotti grandi sono più facili su un computer. I telefoni gestiscono bene i lotti piccoli.

Per i lotti da telefono, tieni il numero di file basso, dieci o venti al massimo. L’elaborazione è più lenta e lo schermo rende scomodo rivedere molte schede.

Carica le foto direttamente dalla galleria, senza passarle per altre app. Ogni passaggio in più è un’occasione per perdere qualità o ordine.

I download finiscono nella cartella Download del telefono. Su iPhone, cercali nell’app File; su Android, nel file manager.

Tenere al sicuro gli originali

Gli originali non vengono mai modificati o eliminati dal convertitore. Restano esattamente dove erano, intatti, e lo ZIP contiene solo le copie convertite.

Usa il suffisso facoltativo per i nomi dei file, come -webp o -convertito, così ogni uscita ha un nome diverso dal suo originale.

Decomprimi lo ZIP in una cartella nuova, non sopra gli originali. Insieme, queste due abitudini rendono impossibili le sovrascritture.

Fai un backup degli originali prima di qualsiasi lavoro di lotto importante. Un file convertito non può mai tornare a essere un originale perfetto.

Ordinare i file prima del caricamento

Ordina i file prima di caricarli, per tipo o per destinazione. Foto, loghi e screenshot vogliono impostazioni diverse, e ordinarli ora ti fa risparmiare lavoro dopo.

Un lotto misto costringe a un’impostazione di compromesso che non va bene per nessuno. Ordinare richiede minuti e fa risparmiare rilavorazioni.

Nomina i file in ordine, come 01-foto.jpg e 02-foto.jpg, così la coda è già nella sequenza giusta. L’ordine di caricamento diventa l’ordine del documento.

Convertire le foto di un viaggio

Per le foto di un viaggio, converti solo le migliori in JPG con qualità al 90%. Le foto del viaggio sono ricordi, e meritano la migliore qualità.

Nomina i file per luogo e data, come roma-colosseo-2026.jpg. Tra un anno, troverai subito la foto che cerchi.

Conserva gli originali in una cartella separata. Se vorrai stampare una foto in grande, avrai bisogno della copia originale, non di quella convertita.

Condividi le versioni convertite, non gli originali. Le versioni leggere si inviano facilmente, e gli originali restano al sicuro.

Convertire documenti di lavoro in lotto

Per i documenti di lavoro, converti le scansioni in JPG con qualità all’85%. Il testo resta leggibile e i file sono abbastanza leggeri da inviare via email.

Nomina i file convertiti per documento e data, come contratto-2026-11.jpg. Un nome chiaro aiuta chiunque a trovare il documento giusto.

Controlla le prime cinque schede prima di scaricare lo ZIP. Se il testo è sfocato, alza la qualità e converti di nuovo.

Tieni un appunto di una riga per lavoro, come WebP 85%, riempimento bianco. È la nota che ti salva quando dovrai rifare lo stesso lavoro tra mesi.

Riutilizzare le impostazioni per lotti ripetuti

Se converti lo stesso tipo di lotto ogni settimana, annota le impostazioni. Formato, qualità e colore di riempimento: tre valori che ti fanno risparmiare tempo ogni volta.

Un file chiamato sito-hero-nov-2026.jpg dice al cliente cosa contiene, mentre IMG_4821.jpg non dice niente a nessuno.

Crea una piccola lista di controllo per i lotti ripetuti. Carica, scegli il formato, imposta la qualità, controlla le prime cinque schede, scarica lo ZIP.

Con il tempo, il flusso diventa automatico. E un flusso automatico è un flusso senza errori.

Un esempio: un blogger che pubblica tre articoli a settimana, con cinque immagini per articolo, converte quindici immagini a settimana.

Con una lista di controllo scritta, il lavoro richiede dieci minuti: caricare, scegliere WebP all’80%, controllare le prime schede, scaricare lo ZIP, caricare sul sito.

Senza lista, ogni volta devi ricordare formato, qualità e colore di riempimento. E ogni volta rischi di dimenticare qualcosa.

Scrivi la lista una volta, usala per sempre. È il modo più semplice per rendere il lavoro ripetitivo anche affidabile.

Un esempio di lista per un blog: formato WebP, qualità 80%, riempimento bianco, controllare le prime cinque schede, scaricare lo ZIP, caricare sul sito, testare la pagina.

Sette voci, un minuto di lettura, zero errori. È la lista che trasforma un lavoro noioso in un lavoro sicuro.

Se lavori in team, condividi la lista con tutti. Chiunque esegua il lotto seguirà gli stessi passaggi, e i risultati saranno coerenti.

Aggiorna la lista quando cambia qualcosa: un nuovo formato, una nuova qualità, un nuovo strumento. Una lista vecchia è peggio di nessuna lista.

Convertire immagini per la consegna a un cliente

Per la consegna a un cliente, converti le immagini nel formato richiesto e nomina i file in modo chiaro. Il cliente deve capire cosa riceve senza chiedertelo.

Controlla ogni file prima di consegnare. Un file sbagliato in una consegna sembra trascuratezza, anche se il resto è perfetto.

Consegna lo ZIP con un nome chiaro, come sito-cliente-nov-2026.zip. È il nome che il cliente troverà facilmente tra i suoi file.

Conserva una copia dello ZIP consegnato. Se il cliente perde i file, potrai inviarli di nuovo in un attimo.

Domande frequenti

Posso trascinare un’intera cartella nel convertitore in lotto?

Sì, puoi trascinare una cartella sull’area di caricamento, e lo strumento raccoglie i file di immagine al suo interno. Puoi anche cliccare l’area e selezionare molti file in una volta nel selettore di file. In entrambi i casi, ogni immagine valida entra nella stessa coda di conversione.

Quali tipi di file posso mescolare in un unico lotto?

JPG, PNG, WebP, HEIC, SVG, BMP, GIF e AVIF possono stare tutti nella stessa coda. Ogni file valido viene convertito nel formato di uscita che hai selezionato. L’unica eccezione sono i GIF animati, che diventano immagini fisse perché viene convertito solo il primo fotogramma.

Come faccio a evitare che i file convertiti sovrascrivano gli originali?

Usa il suffisso facoltativo per i nomi dei file, come -webp o -convertito, così ogni uscita ha un nome diverso dal suo originale. Decomprimi inoltre lo ZIP in una cartella nuova, invece che sopra gli originali. Insieme, queste due abitudini rendono impossibili le sovrascritture.

Perché un file del mio lotto è molto più grande dopo la conversione?

Quel file probabilmente è passato da un formato con perdite a PNG, che memorizza ogni pixel esattamente e può essere diverse volte più grande. Oppure il cursore della qualità era impostato molto in alto per un’immagine semplice. Controlla quella scheda del file e valuta di convertirlo separatamente con impostazioni diverse.

Posso mettere in pausa una conversione in lotto a metà?

Non c’è un pulsante di pausa, ma ogni file viene convertito in modo indipendente, quindi puoi semplicemente aspettare il file corrente e poi smettere di aggiungerne di nuovi. I file già finiti restano convertiti e scaricabili. Per ricominciare, carica i file rimanenti come un nuovo lotto.

Il convertitore in lotto funziona senza connessione internet?

Una volta caricata la pagina, la conversione avviene in locale nel browser e non ha bisogno di internet. Ti serve una connessione solo per aprire la pagina la prima volta. Dopo, puoi convertire lotti offline finché non chiudi la scheda.
