Come Convertire SVG in PNG

Converti loghi e icone SVG in PNG alla dimensione che ti serve. Carica, scegli una scala, controlla il risultato e scarica: un file solo o un intero pacchetto.

Un logo SVG è scalabile all’infinito, ma molti posti vogliono ancora un PNG. Convertirlo richiede pochi secondi, e l’unica decisione che conta è la dimensione di output.

Scegli la scala giusta e il PNG appare perfetto. Scegli quella sbagliata e risulta sfocato o inutilmente enorme.

Questa guida ti accompagna passo dopo passo, dal caricamento dell’SVG al download di un PNG nitido.

Prima di Iniziare: Prepara l’SVG

Apri prima l’SVG in un browser e verifica che venga reso correttamente. Se lì sembra sbagliato, sembrerà sbagliato anche come PNG.

Converti il testo in tracciati nel tuo strumento di design se l’SVG contiene scritte. Il testo convertito in tracciati diventa forme, quindi viene reso esattamente indipendentemente dai font.

Incorpora le immagini collegate come data URI dentro l’SVG. Il convertitore non può recuperare file esterni, quindi una foto collegata mancherà nel PNG.

Rimuovi qualsiasi rettangolo di sfondo se vuoi un PNG trasparente. Una forma di sfondo diventa parte dell’immagine, mentre un SVG trasparente resta trasparente.

Passaggio 1: Apri lo Strumento Converti SVG in PNG

Apri lo strumento Converti SVG in PNG nel browser. La pagina funziona su Windows, Mac, Linux, ChromeOS, Android e iOS.

Vedrai un’area di caricamento e un selettore di scala. Questi due controlli sono tutto il lavoro.

Non serve un account e nulla viene caricato online. La conversione avviene sul tuo dispositivo, e per i loghi dei clienti e le risorse di brand è importante.

Se sei sul telefono, la pagina funziona nel browser mobile. Tocca l’area di caricamento per scegliere i file SVG dal tuo dispositivo.

Passaggio 2: Carica i Tuoi File SVG

Trascina i file SVG sull’area di caricamento, oppure cliccala per aprire il selettore dei file. Puoi selezionare molti file in una volta per una serie.

Ogni file appare come una scheda con miniatura, così puoi verificare che siano stati caricati i file giusti. Un file sbagliato è facile da individuare e rimuovere.

Si accettano file fino a 25 MB ciascuno, una soglia che copre anche file illustrati enormi con migliaia di tracciati. Gli SVG molto complessi richiedono semplicemente un secondo o due in più.

Puoi anche incollare un SVG copiato con Ctrl+V su computer. È comodo quando il codice SVG è negli appunti da un’altra app.

Passaggio 3: Scegli la Scala di Output

Il selettore di scala offre 1x, 2x, 3x e 4x. La scala moltiplica la dimensione naturale dell’SVG, quindi un’icona da 24 pixel a 4x diventa un PNG da 96 pixel.

Per un’icona di sito, 2x o 3x di solito bastano. Il PNG appare nitido sugli schermi retina senza sprecare byte.

Per un logo su una diapositiva di presentazione, 4x dà un margine comodo. Un piccolo logo ingrandito in PowerPoint resta nitido quando il PNG ha abbastanza pixel.

Per la stampa, scegli la scala che raggiunge 300 DPI alla dimensione stampata. Un logo stampato largo 5 cm ha bisogno di almeno 600 pixel, quindi calcola a ritroso dalla dimensione di stampa.

Passaggio 4: Converti i File

Clicca il pulsante Converti. Lo strumento disegna ogni SVG su una tela alla scala scelta e codifica il risultato come PNG.

La conversione è veloce, di solito un secondo o due per file. Gli SVG molto complessi con migliaia di tracciati richiedono un po’ più di tempo per essere disegnati.

Ogni scheda si aggiorna con il nuovo peso e le nuove dimensioni del PNG. Controlla le dimensioni per verificare che la scala abbia prodotto la dimensione che ti aspettavi.

Se un file fallisce con un errore, l’SVG potrebbe contenere funzioni non supportate o codice malformato. Aprilo in un browser per verificare che venga reso lì prima di tutto.

Passaggio 5: Controlla il Risultato

Clicca Confronta su una scheda per vedere l’SVG e il PNG fianco a fianco. Ingrandisci i bordi del logo e verifica che siano nitidi e puliti.

Controlla prima il testo, se l’SVG ne contiene. Un testo dall’aspetto sbagliato significa un font mancante, e la soluzione è convertire il testo in tracciati e convertire di nuovo.

Controlla le immagini mancanti. Uno spazio vuoto dove dovrebbe esserci una foto significa che l’immagine era collegata esternamente, e devi incorporarla come data URI.

Controlla la trasparenza. Un logo che dovrebbe essere trasparente non deve mostrare alcun riquadro bianco intorno, altrimenti l’SVG aveva un rettangolo di sfondo da rimuovere.

Passaggio 6: Scarica i File PNG

Clicca Scarica su una singola scheda per salvare un PNG. Il nome del file mantiene il nome originale con estensione .png.

Per una serie, clicca Scarica tutto per ottenere un unico ZIP con tutti i PNG convertiti dentro. È molto più rapido che scaricarli uno per uno.

Controlla i file scaricati una volta prima di usarli. Apri un PNG nel visualizzatore di foto e verifica che appaia nitido alla dimensione che ti serve.

Tieni anche i file SVG originali. Sono gli originali, e puoi rasterizzarli di nuovo a qualsiasi dimensione ogni volta che ti serve un PNG diverso.

  1. Apri lo strumento Converti SVG in PNG e carica i tuoi file SVG.
  2. Scegli una scala: 2x per il web, 4x per presentazioni e stampa.
  3. Converti e controlla bordi, testo e trasparenza.
  4. Scarica singoli PNG o l’intera serie come ZIP.

Convertire un Intero Pacchetto di Icone

Seleziona tutte le icone SVG in una volta nel selettore dei file. Si caricano in coda e un clic le converte tutte alla stessa scala.

Usa la stessa scala per l’intero pacchetto. La coerenza conta quando le icone appaiono insieme, perché dimensioni miste sembrano disomogenee.

Controlla due o tre icone dopo la conversione, invece di tutte e cinquanta. Se quelle sembrano buone, lo saranno anche le altre, perché le impostazioni sono le stesse.

Carica le icone PNG dove servono. Una favicon, un’icona di app o una presentazione accettano tutte i file PNG senza ulteriori conversioni.

Scegliere la Dimensione per Ogni Scopo

Per una favicon, rasterizza alle misure esatte di cui ha bisogno il sito, di solito 16, 32 e 48 pixel. Anche il generatore di favicon può creare quelle dimensioni da un PNG.

Per un avatar dei social media, 400 × 400 pixel è una buona dimensione. Appare nitido su desktop e mobile, e il file resta piccolo.

Per il logo di una presentazione, 4x la dimensione SVG di solito dà abbastanza pixel. Un logo da 100 pixel a 4x diventa 400 pixel, e appare nitido su una diapositiva.

Per la stampa, calcola dai DPI. Un logo da 5 cm a 300 DPI ha bisogno di 600 pixel, quindi scegli la scala che raggiunge almeno quel numero.

Risolvere i Problemi Comuni

Se il PNG sembra sfocato, la scala era troppo bassa. Rasterizza di nuovo a una scala più alta dall’originale SVG, perché un PNG a bassa risoluzione non può essere reso nitido in seguito.

Se il testo sembra sbagliato, il font manca. Converti il testo in tracciati nel tuo strumento di design e converti di nuovo.

Se manca una foto collegata, incorporala come data URI dentro l’SVG. Il convertitore non può recuperare file esterni, quindi l’immagine deve viaggiare dentro l’SVG.

Se il file fallisce con un errore, apri l’SVG in un browser. Se viene reso lì, prova a convertirlo da solo invece che in una serie.

Consigli per Telefoni e Tablet

Sul telefono, tocca l’area di caricamento e scegli i file SVG dal tuo dispositivo. La conversione avviene sul telefono e i PNG vengono scaricati sul dispositivo.

Tieni piccole le serie sul telefono, perché gli SVG complessi richiedono tempo per essere rasterizzati da un processore mobile. Dieci file alla volta sono comodi.

I download finiscono nella cartella Download del telefono. Su iPhone, controlla l’app File; su Android, controlla il gestore file.

Per un grande pacchetto di icone, usa un computer. Il processore più veloce e lo schermo più grande rendono cinquanta file molto più facili da gestire.

Convertire un Logo per un Biglietto da Visita

Il logo di un biglietto da visita deve stampare nitidamente a una dimensione minuscola, quindi rasterizza l’SVG a 4x. Un piccolo logo con abbastanza pixel dietro di sé resta nitido sul biglietto.

Controlla i colori dopo la conversione, perché i colori di stampa differiscono da quelli dello schermo. Una rapida stampa di prova conferma che i colori del brand appaiono giusti sulla carta.

Invia il PNG alla tipografia con l’SVG come backup. La tipografia può rasterizzare l’SVG da sé se il PNG ha un problema, quindi fornire entrambi copre ogni caso.

Tieni piccolo il file PNG, perché una tipografia di biglietti da visita non ha bisogno di un’immagine enorme. Un logo da 1000 pixel è più che sufficiente per un biglietto, e un file più grande rallenta solo il caricamento.

Ordina un biglietto di prova prima di stampare l’intera serie. Un singolo biglietto conferma dimensione del logo, colori e nitidezza prima di impegnarti in centinaia di copie.

Convertire le Icone per un Sito Web

Le icone dei siti iniziano come file SVG, e diventano PNG per i browser più vecchi. Rasterizza a 2x o 3x la dimensione di visualizzazione, così le icone appaiono nitide sugli schermi retina.

Usa la stessa scala per l’intero set di icone. La coerenza conta quando le icone appaiono insieme, perché dimensioni miste sembrano disomogenee.

Prova le icone sul sito reale prima di pubblicarle. Un’icona perfetta nello strumento di design potrebbe apparire diversa contro il colore di sfondo del sito.

Per un sito moderno, considera di usare direttamente i file SVG. I browser mostrano l’SVG nativamente e le icone scalano perfettamente senza alcuna rasterizzazione.

Tieni gli originali SVG nella cartella del progetto dopo la conversione. Se il sito viene riprogettato, le icone possono essere rasterizzate di nuovo a nuove dimensioni senza ridisegnarle.

Convertire un SVG per una Stampa su Maglietta

Una stampa su maglietta ha bisogno di un’immagine ad alta risoluzione, e l’SVG è la fonte ideale. Rasterizza alla scala più grande consentita dallo strumento, fino al limite di 8000 pixel, per una stampa nitida.

Controlla il design dopo la conversione, perché una stampa su maglietta mostra ogni difetto. Un logo che sembra buono sullo schermo potrebbe rivelare bordi ruvidi quando viene stampato grande sul tessuto.

Invia il PNG alla tipografia con l’SVG come backup. Il software della tipografia potrebbe preferire un formato rispetto all’altro, e fornire entrambi copre ogni caso.

Per una maglietta scura, controlla la trasparenza. Un logo con sfondo trasparente stampa in modo pulito sul tessuto scuro, mentre un logo con riquadro bianco sembra sbagliato.

Ordina una singola maglietta di prova prima di stamparne una serie. Una stampa di prova conferma dimensione, colori e posizionamento prima di impegnarti in decine di magliette.

Convertire un SVG per una Presentazione

Le diapositive di una presentazione hanno bisogno di loghi nitidi, e l’SVG è la fonte ideale. Rasterizza a 4x la dimensione SVG, così il logo resta nitido quando viene proiettato su uno schermo grande.

Controlla il logo sullo sfondo reale della diapositiva dopo la conversione. Un logo perfetto sul bianco potrebbe mostrare una leggera frangia su una diapositiva colorata se la qualità era bassa.

Per una presentazione con molte diapositive, converti tutti i loghi in una volta. Una conversione in serie richiede pochi minuti, e i PNG sono pronti da inserire nelle diapositive.

Prova la presentazione sul proiettore prima del discorso. Una diapositiva nitida sul portatile potrebbe sembrare morbida quando viene proiettata, e una rapida prova rileva il problema in anticipo.

Tieni gli originali SVG nella cartella del progetto dopo la conversione. Se la presentazione viene riutilizzata con un nuovo modello, i loghi possono essere rasterizzati di nuovo a nuove dimensioni.

Convertire un SVG per una Favicon

Una favicon è la piccola icona nella scheda del browser, e di solito inizia come un logo SVG. Rasterizzala a 16, 32 e 48 pixel per le dimensioni standard delle favicon.

Progetta la favicon in modo semplice, perché le dimensioni minuscole nascondono i dettagli. Un logo complesso a 16 pixel diventa una macchia, mentre una forma semplice resta riconoscibile.

Prova la favicon in diversi browser dopo averla aggiunta. Una rapida verifica conferma che viene visualizzata correttamente, così il sito sembra curato in ogni scheda.

Per i browser moderni, considera di usare direttamente la favicon SVG. I browser mostrano le favicon SVG nativamente e l’icona scala perfettamente senza alcuna rasterizzazione.

Tieni l’originale SVG dopo la conversione. Se il sito viene riprogettato, la favicon può essere rasterizzata di nuovo a nuove dimensioni senza ridisegnare il logo.

Convertire un SVG per un Banner di Sito

Un banner di sito è un’immagine larga, e l’SVG è la fonte ideale quando il banner è una grafica e non una foto. Rasterizza alla larghezza di visualizzazione del banner per un risultato nitido.

Controlla le dimensioni del banner prima di convertire. Un banner mostrato largo 1200 pixel ha bisogno di un PNG di almeno quella larghezza, altrimenti sembrerà morbido.

Per un banner con testo, rasterizza a 2x la dimensione di visualizzazione. Il testo resta nitido sugli schermi retina e il file è comunque abbastanza piccolo da caricarsi in fretta.

Prova il banner su desktop e telefono dopo la conversione. Un banner perfetto su uno schermo largo potrebbe ritagliarsi male su uno stretto, e una rapida prova lo rileva.

Tieni l’originale SVG nella cartella del progetto. Se il sito viene riprogettato con una nuova dimensione di banner, la grafica può essere rasterizzata di nuovo senza ridisegnarla.

Questo è l’intero processo: prepara, carica, scegli una scala, scarica. Domande frequenti

Qual è la dimensione del PNG con scala 1x?

A 1x, il PNG corrisponde alla dimensione naturale dell’SVG, quindi un’icona da 24 px diventa un PNG da 24 px. Per risultati nitidi sugli schermi moderni, usa 2x o 3x, e per presentazioni o stampa, usa 4x. L’esportazione è limitata a 8000 px sul lato più lungo, e questo raramente conta per icone e loghi.

Posso convertire i file SVG sul mio telefono?

Sì. Apri lo strumento nel browser del telefono, tocca l’area di caricamento e scegli i file SVG dal tuo dispositivo. La conversione avviene sul telefono e i PNG vengono scaricati sul dispositivo. Tieni piccole le serie sul telefono, perché gli SVG complessi richiedono tempo per essere rasterizzati su mobile.

Quale nome di file manterrà il PNG esportato?

Il PNG mantiene il nome del file SVG originale con estensione .png, quindi logo.svg diventa logo.png. Questo rende facile trovarlo e mantiene organizzati i tuoi file. Per una serie, lo ZIP contiene ogni PNG con il suo nome originale corrispondente.

Il convertitore supporta le animazioni SVG?

No, non davvero. Le animazioni SVG che usano SMIL o CSS non vengono conservate, perché il convertitore disegna un singolo fotogramma statico sulla tela. Il risultato è un PNG fermo dell’SVG così come appare all’inizio. Per un logo animato, tieni l’SVG stesso.

Posso rasterizzare un SVG con un’immagine incorporata come data URI?

Sì. Le immagini incorporate come data URI dentro l’SVG fanno parte del file, quindi vengono rese correttamente nel PNG. È il modo giusto per includere foto in un SVG per la conversione. Le immagini esterne collegate, invece, vengono lasciate fuori, perché il convertitore non può recuperarle.

Perché il mio PNG convertito sembra sfocato?

La scala era troppo bassa per la dimensione che ti serve. Un’icona da 24 px rasterizzata a 1x è solo 24 pixel, e stirarla a 200 pixel la rende sfocata. Rasterizza di nuovo a una scala più alta dall’originale SVG, perché un PNG a bassa risoluzione non può essere reso nitido in seguito.
