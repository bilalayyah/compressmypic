EXIF情報とは？写真に隠れたデータとプライバシーリスクを解説

写真は一瞬を写します。EXIF情報は、その一瞬のまわりの物語を語ります。どのカメラで撮ったのか、いつ、どこで、どんな設定で撮ったのか。

ほとんどの人はこの層を目にしたことがありません。ファイルの中で静かに移動し、コピーや転送、ダウンロードを生き延びて、削除されるまで残り続けます。

この記事ではEXIFを深く解説します。どういう構造なのか、各項目が何を明かすのか、どう漏れるのか、そしてどう読んでどう削除するのか。余計な話は抜きにして、データが実際に何を含んでいるかだけをお伝えします。

EXIFとは何か

EXIFはExchangeable Image File Formatの略で、画像ファイルの中にメタデータを保存するための標準規格です。カメラやスマホが撮影の瞬間に書き込みます。

技術的には、EXIFデータはファイルに埋め込まれたTIFF形式の構造体に保存されます。JPEGではAPP1セグメント、PNGではeXIfチャンク、WebPではEXIFチャンクに入っています。

構造は、IFD（Image File Directory）と呼ばれるディレクトリの集まりです。各IFDには番号付きのタグがあり、各タグには数値や文字列、分数の集合といった値が入っています。

ツールはJPEGファイルから3つのIFDを読み取ります。端末の基本情報が入ったIFD0、露出情報が入ったExifIFD、位置情報が入ったGPSIFDです。興味深い情報のほとんどはここにあります。

EXIFは写真の中の唯一のメタデータではありません。XMPパケット、IPTC項目、JPEGコメント、PNGテキストチャンクが並んで入ることもあります。ただし、EXIFが最も情報量が多く、最も標準化されているのです。

IFD0：端末の身元情報

IFD0は最初のディレクトリで、端末を特定する情報が入っています。カメラのメーカーと機種が代表的な項目ですが、それだけではありません。

ソフト名の項目には、最後にファイルを書き込んだプログラムが記録されます。カメラのファームウェアのバージョン、スマホのOS、Lightroomのような編集アプリなどが入ります。

カメラによってはシリアル番号や所有者名がここに記録されます。こうした項目があると、匿名の写真が特定の1台の端末に、場合によっては特定の1人の人物に結びついてしまいます。

アーティスト名の項目には写真家の名前、著作権の項目には権利表示が入ることがあります。プロにとっては正当な情報ですが、どちらも個人を特定する手がかりになります。

画像の画素数や向きフラグもこの近くにあります。向きタグは、写真を正しい向きに回転させて表示するための情報です。雑に削除すると、写真が横向きになってしまう原因にもなります。

ExifIFD：露出の記録

ExifIFDはEXIFの技術的な中心です。撮影の瞬間にカメラが決めた露出設定、あるいは撮影者が決めた露出設定が記録されています。

ISO感度、絞り、シャッタースピード、焦点距離は、写真家が最も気にする4つの項目です。これらを組み合わせると、光の具合、被写界深度、動きの表現が分かります。

露出時間は1/250秒のような分数で保存されます。絞りはF値で、焦点距離はミリ単位で記録され、35mm換算の値が併記されることもあります。

フラッシュの状態には、発光したかどうかと発光モードが記録されます。測光モードには、カメラが画面の光をどう測ったか（平均、中央重点、スポット、マルチパターンなど）が記録されます。

ホワイトバランス、露出プログラム、露出補正もさらに詳しい情報を加えます。訓練された人なら、これらの項目だけで撮影条件を再現できます。だからこそ写真家にとっては価値があり、単体では無害なのです。

GPSIFD：位置情報のディレクトリ

GPSIFDは最も小さなディレクトリであり、最も危険なディレクトリでもあります。緯度、経度、高度が、度・分・秒の分数で記録されています。

ツールはこれらの分数を自動で10進数の座標に変換します。25.2048、55.2708のような2つの数字は、地図上の正確な地点を示し、建物を特定できるほどの精度があります。

GPSタグにはタイムスタンプや、北緯・南緯、東経・西経の基準も含まれます。日付スタンプは位置を測定した日時を記録し、通常は撮影時刻と一致します。

高度も記録されていることが多く、水平方向の座標ほど正確ではありませんが、地上で撮ったのか高層階で撮ったのかは分かる場合があります。

ほとんどのカメラアプリでは、スマホが初期設定でGPSを記録します。座標は写真に何の痕跡も残さず静かに書き込まれ、持ち主のほとんどは存在に気づいていません。

写真が明かすあなたの情報

1枚の写真が明かす情報は少しだけです。でも、たくさんの写真が集まると、多くのことが分かります。EXIFは写真のコレクションを、場所や生活習慣、端末の年表に変えてしまうのです。

多くの写真の撮影日時を並べると、自宅にいる時間、旅行する時期、普段留守にしている時間が分かります。これは生活習慣そのものであり、悪意のある読み手にとって価値のある情報です。

多くの写真のGPS座標を地図に並べると、自宅、職場、ジム、子どもの学校が浮かび上がります。名前がなくても、地図上のパターンは一目瞭然です。

カメラのシリアル番号は、写真を1台の端末に結びつけます。同じシリアル番号が別の名前の写真に現れれば、それらの人物のつながりが見えてしまいます。

ソフト名の項目は、使っている編集ツールやOSを明かします。単体では大したことではありませんが、撮影日時や位置情報と組み合わさると、詳細なプロフィールの一部になります。

大切なのは、個々の項目が秘密だということではありません。項目が組み合わさることで、あなたが公開すると決めた覚えのない生活の全体像ができあがってしまうことです。

EXIFはどう残り、どう消えるか

EXIFはコピーしても、メールで送っても、フォルダ間で移動しても残ります。ファイルの一部ですから、積極的に削除する何かがない限り、ファイルと一緒にどこへでも移動します。

SNSやメッセージアプリは、EXIFを削除する最大の存在です。WhatsApp、Instagram、Facebookは、サーバーへのアップロード時にEXIF・カメラ・GPSヘッダーを自動で削除します。

だからこそ、Instagramからダウンロードした写真は画像メタデータ確認ツールで調べてもEXIFタグがゼロになるのです。プラットフォームが削除したのであって、あなたが削除したのではありません。

編集アプリはさまざまです。書き出し時にEXIFを残すもの、削除するもの、選べるものがあります。編集して再書き出しした写真は、画素はそのままでカメラ情報だけ失っていることがあります。

スクリーンショットには、最初からEXIFがありません。クリップボードは生の画素データを渡すため、スクリーンショットには画素数と形式しか含まれないのです。

フリマアプリや掲示板、メール添付は別です。元のファイルをそのまま保管するものが多く、EXIFやGPSは見知らぬ人のダウンロードフォルダまで生き延びます。

EXIFの読み方

EXIFを読むにはツールが必要です。OSの標準機能だけでは全体像は表示されません。画像メタデータ確認ツールは、生のバイト列を端末の中で解析し、項目をグループ分けして表示します。

まず概要バナーを見ます。形式、画素数、注意が必要な種類のタグが見つかったかどうかが分かります。次にGPS警告を確認し、座標があればデコードされた値が表示されます。

次にグループ分けされた一覧を読みます。カメラの項目で端末が分かり、EXIFの項目で露出が分かり、GPSの項目で位置が分かります。琥珀色のPrivacy Tagラベルが、注意が必要な項目を示します。

記録が必要な場合はJSONで保存します。「Copy JSON」で構造化されたレポート全体をクリップボードにコピーでき、「Export JSON」でファイルとして保存し、バグ報告に添付できます。

手順を一つずつ確認したい方は、画像メタデータの見方をお読みください。ツールの全体像は、画像メタデータ確認ツール完全ガイドで説明しています。

EXIFとXMP、IPTCの違い

EXIFだけが存在するわけではありません。ほかの2つの標準規格が同じファイルに共存することもあり、それぞれ異なる情報を明かします。

XMPはAdobeのXML形式のパケットで、ファイルに埋め込まれます。編集履歴、評価、ラベル、説明文などを記録できます。LightroomやPhotoshopで編集した写真には、すべての調整の長いXMP履歴が残っていることがよくあります。

IPTCは報道・出版業界の標準規格です。キャプション、見出し、キーワード、クレジット、著作権情報を扱います。報道写真やストックフォトにはIPTC項目が豊富に含まれます。

EXIFはカメラが書き込み、XMPは編集ソフトが書き込み、IPTCは人や出版社が書き込みます。1枚の写真に3つすべてが入り、それぞれが物語の異なる部分を語ることがあります。

EXIFだけを削除しても十分とは限りません。本当にきれいにするには、XMPパケット、IPTC項目、JPEGコメント、PNGテキストチャンクも削除する必要があります。画像メタデータ削除ツールは、まさにそれを行います。

EXIFの向き情報：写真が横向きになる問題

向きタグは小さなEXIF項目ですが、影響はとても大きいです。写真を正しい向きに回転させて表示するよう指示するもので、カメラは画素を一方向で保存し、正しい向きをメタデータに記録することが多いからです。

画素を回転させずにこのタグだけ削除すると、縦向きの写真が横向きに表示されることがあります。画像データは変わっていませんが、正しい向きにするための指示が消えてしまったのです。

だからこそ、画像メタデータ削除ツールには2つの方法があります。「Lossless Binary Strip」は、向きフラグを含むAPP1ブロックを削除しますが、画素には一切触れません。

「Full Canvas Re-encode」は別の方法です。画素を新しいキャンバスに描き直し、正しい向きを画像そのものに焼き付けて書き出すため、タグがなくても写真は正しい向きのままです。

ロスレス削除のあと縦向きのJPEGが横向きに見える場合は、「Full Canvas Re-encode」に切り替えて「Re-clean All」をクリックしてください。画素そのものが修正され、向きタグは不要になります。

写真家と開発者にとってのEXIF

EXIFはプライバシーのリスクだけではありません。写真家にとっては学びの道具であり、開発者にとっては不具合調査の手がかりです。

写真家は、素晴らしい一枚の露出設定を読み取って再現できます。ISO感度、絞り、シャッタースピード、焦点距離を組み合わせると、似た光の中で同じ雰囲気を出すためのレシピになります。

開発者はEXIFを読むことで、奇妙な挙動の理由を説明できます。向きフラグの誤り、PNGのpHYsチャンクによる想定外のDPI値、隠れたカラープロファイルなどが、表示バグの原因になっていることがよくあります。

2つのファイルを比べるのは、よくある調査方法です。それぞれからJSONを書き出して比べると、どの処理ステップで項目が消えたり変わったりしたかが分かります。

サイズが問題のときは、画像サイズ確認ツールと組み合わせると便利です。画素数とDPIを合わせることで、その写真が印刷に適しているのか、画面表示だけに適しているのかが判断できます。

EXIFを安全に削除する方法

EXIFを読むことは仕事の半分にすぎません。もう半分は、写真を公開する前に削除することです。

画像メタデータ削除ツールは、EXIF、GPS、XMP、IPTC、コメント、PNGテキストチャンクをブラウザの中で削除します。アップロードは一切ありません。

「Lossless Binary Strip」はJPGとPNGに対応し、メタデータ部分だけを削除して画素を再圧縮しません。画質はまったく変わりません。

「Full Canvas Re-encode」は画素から画像を再構築するため、受け継いだバイナリ部分が確実にすべて消えます。WebPとHEICの入力には自動で使われ、出力形式を変えるときにも使われます。

削除したあとは必ず確認しましょう。きれいになったファイルを画像メタデータ確認ツールにドラッグし、緑色のバナーで「EXIF、GPS、隠れたカメラタグは検出されませんでした」と表示されることを確かめます。

削除の完全ガイドは、画像メタデータ削除完全ガイドをお読みください。データに潜むプライバシーリスクについては、写真のプライバシーリスクで解説しています。

EXIFにまつわるよくある誤解

EXIFについての誤解はいくつも広まっており、それぞれが誤った安心感につながります。ここではっきり訂正しておきます。

誤解その1：写真をリサイズすればメタデータが消える。たいてい消えません。リサイズしてもGPS座標はそのまま残ることが多く、ツールが明示的に削除しない限り消えません。小さくなった写真も、元の写真と同じ座標を持っているのです。

誤解その2：形式を変換すればメタデータが消える。JPGからPNGに変換するとEXIFが消えることもありますが、eXIfチャンクに引き継がれることもあります。変換で何かがきれいになったと決めつけてはいけません。

誤解その3：切り取れば位置情報が消える。切り取りは画素を変えるだけで、ヘッダーは変わりません。ツールが削除しない限り、GPSタグは残ります。

誤解その4：場所が写っていない写真は安全。位置情報は画像ではなくヘッダーにあります。真っ白な壁の写真でも、正確な座標が入っていることがあります。

誤解その5：気にするのはプロだけ。スマホのカメラもプロのカメラと同じようにEXIFを書き込み、GPSも含まれます。写真を共有するすべての人に関係する話です。

まとめ

EXIFとは、カメラがすべての写真に書き込む隠れたデータのことです。端末の身元情報、露出設定、撮影日時、GPS座標が含まれ、IFDディレクトリに整理され、削除されるまでファイルと一緒に移動します。

SNSアプリは自動で削除しますが、フリマアプリや掲示板、メールはたいてい削除しません。たくさんの写真が集まれば、生活習慣や場所、使っている端末が明らかになってしまいます。

画像メタデータ確認ツールで読み、画像メタデータ削除ツールで削除し、きれいになったファイルをもう一度確認しましょう。写真には、自分が共有すると決めたものだけを載せればいいのです。

よくある質問

削除したEXIF情報を復元できますか？

できません。ファイルからメタデータ部分を削除すると、その情報はそのコピーから完全に消えます。復元するものは何も残りません。カメラ設定や位置情報を自分の記録として残したい場合は、削除する前にオリジナルを保管しておきましょう。削除済みのコピーを元の状態に戻すことはできません。

EXIF情報は画質やファイルサイズに影響しますか？

画素の見た目には影響しませんが、ファイルサイズには影響します。カメラの写真には、埋め込みプレビューサムネイルやXMPブロック、コメント部分が含まれていることが多く、数十KBも増えることがあります。これらを削除すれば、画質を変えずにファイルが小さくなります。プライバシーに加えて得られる小さなメリットです。

すべてのカメラやスマホがEXIF情報を書き込みますか？

ほぼすべてのデジタルカメラとスマホが、初期設定でEXIF情報を書き込みます。メーカー、機種、露出設定、撮影日時などが含まれます。GPS座標は、位置情報サービスがオンになっている場合に記録されます。カメラアプリによっては位置情報の記録をオフにでき、その場合はGPSタグだけが記録されず、ほかの項目は残ります。

EXIF情報は写真の撮影日時や場所の証拠になりますか？

証拠にはなりますが、証明にはなりません。撮影日時は編集できますし、GPS情報も偽造できます。削除済みのファイルには何も残りません。法的な場面や報道では、EXIFは主張を裏付ける材料にはなりますが、ほかの証拠と照らし合わせるべきです。ただしプライバシーの面では、正確だと考えて行動しましょう。見る側はそう受け取ります。

同じ写真のコピーでEXIF情報が違うのはなぜですか？

各コピーが異なる処理を経ているからです。片方はSNSアプリを経由してすべて削除され、もう片方はオリジナルのまま残っている、ということがあります。編集や変換、再書き出しのたびに、項目が追加・変更・削除されます。ファイルのEXIFは元の風景ではなく、そのファイルを説明するものです。処理が違えば、コピーごとに内容が変わります。

EXIF情報は写真の透かしと同じですか？

いいえ、違います。透かしは画素の中に見える形で入るロゴや文字です。EXIFは写真を説明する、目に見えないヘッダーデータです。透かしはスクリーンショットや再保存でも残りますが、EXIFは削除すれば消えます。目的も異なります。透かしは所有権を目に見える形で示し、EXIFは事実を目に見えない形で記録します。
