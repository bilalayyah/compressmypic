画像メタデータ確認ツール完全ガイド｜EXIF・GPS情報を安全に調べる方法

写真には、目に見えない情報が隠れています。カメラの設定、撮影日時、使った機種、そして場合によっては撮影場所まで。ファイルの中に静かに記録されているのです。

画像メタデータ確認ツールは、その隠れた情報を読み取り、分かりやすい形で表示してくれます。難解なバイナリデータを、誰でも読めるレポートに変えてくれるのです。

この記事では、画像のメタデータとは何か、ツールで何が分かるのか、そして写真を共有する前にどう確認すればいいのかを解説します。プライバシーのリスク、JSONでの保存方法、削除済みファイルの確認方法も取り上げます。

画像メタデータ確認ツールは、ブラウザの中だけで動作します。写真が自分の端末から外に出ることはありません。プライバシーのためのツールですから、これが何より大切なポイントです。

画像のメタデータとは

画像のメタデータとは、画素そのものとは別に、画像ファイルの中に保存されているデータのことです。写真そのものではなく、写真についての情報を記録した、いわば裏面のラベルのようなものです。

最も一般的なのがEXIF（エグジフ）です。正式にはExchangeable Image File Formatといい、カメラやスマホがシャッターを切るたびに自動で書き込みます。

EXIFには、カメラのメーカーや機種、レンズの情報、絞り、シャッタースピード、ISO感度、焦点距離、フラッシュの状態、撮影した正確な日時などが含まれます。

ほかのメタデータは別の場所に保存されています。PNGファイルには、作成者やソフト名、作成時刻などを記録するテキストチャンクがあります。WebPファイルにはEXIFブロックやアニメーション情報が入ることもあります。JPEGファイルにも、XMPパケットやコメントが含まれることがあります。

こうした情報は、写真を眺めているだけでは決して見えません。確認するには専用のツールが必要です。ほとんどの人は一度も調べたことがありません。そのため、ネットに公開された写真は、持ち主が気づかないうちに多くの情報を漏らしているのです。

ツールで確認できる情報

画像をツールにドラッグすると、ファイルの生データを端末上で解析します。すぐに概要とプライバシーリスクの表示、そして見つかった項目をグループ分けした一覧が表示されます。

概要には、ファイル形式、画素数（ピクセルサイズ）、ファイルサイズが表示されます。さらに、注意が必要な種類のメタデータが含まれているかどうかも分かります。

一覧は見やすくグループ分けされています。カメラ関連の項目、露出関連のEXIF項目、GPS関連の項目、PNGやWebPのチャンクが、それぞれまとまって表示されます。

注意が必要な項目には、琥珀色の「Privacy Tag」ラベルが付きます。代表的な例は、GPS座標、正確な撮影日時、撮影者名、カメラのシリアル番号、機種名などです。

GPSデータがある場合は、警告ボックスにデコードされた緯度と経度が正確に表示されます。ワンクリックで画像メタデータ削除ツールに移動できるので、すぐにファイルをきれいにできます。

EXIFの項目を解説

EXIFは、IFDと呼ばれるディレクトリに整理されています。ツールはJPEGファイルからTIFF IFD0、ExifIFD、GPSIFDの各テーブルを読み取るほか、PNGのeXIfブロックやWebPのEXIFチャンクも解析します。

IFD0には、画像と端末に関する基本情報が入っています。カメラのメーカーや機種はここにあり、最後にファイルを編集したソフト名や著作権表示もここに記録されます。

ExifIFDには、撮影時の露出情報が記録されています。シャッタースピード、絞り、ISO感度、焦点距離、測光モード、フラッシュの状態などが、このディレクトリに含まれます。

GPSIFDには、位置情報が有理数（分数）で記録されています。ツールは度・分・秒を自動で10進数の緯度・経度に変換するので、座標をそのまま読むことができます。

すべての項目がすべての写真にあるわけではありません。スクリーンショットにはカメラ情報がありませんし、メッセージアプリ経由で受け取った写真は、送信時にメタデータが削除されているためEXIFが残っていないことがほとんどです。

項目が見つからないこと自体も、有益な情報です。そのファイルがすでに加工されているか、もともとカメラのオリジナルではなかったことを教えてくれるからです。

GPS情報とプライバシー

GPS座標は、写真に含まれる情報の中で最も注意が必要です。たった2つの数字だけで、自宅や職場、子どもの学校、写真を撮った正確な場所まで特定できてしまいます。

ほとんどのカメラアプリでは、スマホがGPS情報を初期設定で記録します。座標は写真に何の痕跡も残さず静かに保存されるため、持ち主は存在に気づきません。

削除されていない写真をネットで共有すると、ダウンロードした誰もがメタデータ確認ツールで位置情報を読み取れます。フリマアプリや掲示板、SNSの利用者も例外ではありません。

ツールはこのリスクを目に見える形にします。GPSIFDタグがある場合、項目一覧のすぐ上に「GPS Location Coordinates Detected」という琥珀色のバナーが表示され、デコードされた座標が示されます。

投稿前の確認は数秒で終わります。座標が表示されたら、公開する前に画像メタデータ削除ツールで削除しましょう。

PNG・WebPの技術情報

JPEGばかりが注目されがちですが、PNGやWebPにも独自のメタデータがあります。ツールはこうした技術的なチャンクも読み取るので、隠れた情報は見逃しません。

PNGファイルでは、ビット深度やカラータイプを記録するIHDRチャンクを読み取ります。印刷や表示の解像度を記録するpHYsチャンクも確認できます。

PNGのテキストチャンクもプライバシーの観点で重要です。tEXtやiTXtチャンクにはソフト名、作成者名、コメント、作成時刻などが入ることがあります。tIMEチャンクにはファイルの最終更新時刻が記録されます。

WebPファイルでは、アルファチャンネルやアニメーションの有無を示すVP8Xフラグを読み取ります。WebPのEXIFチャンクも同時にデコードされるので、WebPに含まれるカメラ情報も見逃しません。

さらにツールは、ファイル名ではなくバイナリの「マジックバイト」から本当のファイル形式を判定します。PNGファイルを.jpgという名前に変えても、PNGとして正しく表示されます。

使い方：5つのステップ

ツールの使い方は5ステップで、アカウント登録もアップロードも不要です。すべて自分の端末の中で行われます。

  1. 調べたい画像をドラッグするか、選択します。JPG、PNG、WebP、HEIC、GIF、BMP、SVGに対応し、1ファイル最大20MBまで。Ctrl+Vでの貼り付けもできます。
  2. 上部の概要とプライバシーリスク表示を確認します。形式、画素数、ファイルサイズと、注意が必要なタグが見つかったかどうかが分かります。
  3. GPS位置情報の警告を確認します。座標があれば、警告ボックスに正確な緯度と経度が表示されます。
  4. 抽出されたメタデータの一覧を確認します。カメラ、EXIF、GPS、PNG・WebPチャンク、ファイル情報ごとにグループ分けされ、注意が必要な項目には琥珀色のPrivacy Tagラベルが付きます。
  5. JSONでコピー・エクスポートするか、メタデータを削除します。「Copy JSON」でレポート全体をコピー、「Export JSON」で.jsonファイルを保存、「Strip Metadata」でファイルをきれいにできます。

このツールは読み取り専用です。ブラウザのメモリ上でヘッダーを読んで表示するだけで、元のファイルを変更したり、圧縮したり、削除したりすることはありません。

更新せずに次々とファイルを調べることもできます。概要バーの赤いゴミ箱アイコンをクリックしてアップロード画面に戻し、次の画像をドラッグするだけです。

JSONレポートのコピーと保存

メタデータを記録として残したり、誰かと共有したり、バグ報告に貼り付けたりしたい場面があります。ツールは解析結果全体を構造化されたJSON形式で出力できます。

概要バーの「Copy JSON」をクリックすると、ImageMetadataReport全体がクリップボードにコピーされます。ドキュメントやチケット、チャットメッセージにそのまま貼り付けられます。

「Export JSON」をクリックすると、画像のファイル名に「_metadata」を付けた.jsonファイルがダウンロードされます。開発者はこうしたレポートを、画像処理の不具合調査やファイル仕様の記録に使います。

JSONには、ツールがデコードしたすべての項目が、画面の一覧と同じグループ分けで含まれます。2つのファイルを比較したり、削除前の状態を記録しておいたりするのに便利です。

確認手順を実際に試したい方は、画像メタデータの見方もご覧ください。各項目が何を意味するのかは、EXIF情報とは？写真に隠れたデータを解説で詳しく説明しています。

削除済みファイルの確認方法

メタデータ確認ツールの最も便利な使い方の一つが、ほかのツールの仕上がりをチェックすることです。写真のメタデータを削除したら、きれいになったファイルをもう一度ツールにドラッグして、本当にタグが消えたか確認しましょう。

削除が成功していれば、緑色のバナーで「EXIF、GPS、隠れたカメラタグは検出されませんでした」と表示され、GPS警告も出ません。これは推測ではなく、ファイルのバイト列を実際に調べた結果です。

この確認が重要なのは、削除をうたうツールの中には、一部のチャンクを残してしまうものがあるからです。PNGのtEXtブロックやJPEGのコメントが、いい加減なクリーナーでは残ることがあります。ツールはそうした残り物も見逃しません。

大切な写真では「確認→削除→再確認」を習慣にしましょう。2回目の確認は数秒で終わり、1回目の作業が確実だったことを証明してくれます。

削除後のファイルにまだタグが残っている場合は、画像メタデータ削除ツールの「Full Canvas Re-encode」オプションを試してください。画素を一から再構築するため、受け継いだバイナリ部分がすべて消えます。

チェックすべきタイミング

写真が自分の手元を離れるときは、いつでもメタデータを確認しましょう。リスクは写真そのものではなく、誰がダウンロードして何を読み取れるかにあります。

  • フリマアプリに出品する前。購入者はフル解像度の画像をダウンロードできます。
  • 家族写真をSNSに投稿する前。特に自宅や学校で撮った写真は要注意です。
  • 写真を記者やクライアント、見知らぬ人に送る前。さらに転送される可能性があります。
  • ブログやウェブサイトに写真を掲載する前。ファイルは何年もダウンロード可能な状態で残ります。
  • 写真を受け取った後。いつ・どこで・どのカメラで撮られたかが分かります。
  • 画像処理の不具合を調べるとき。各処理ステップでどの項目が残るかが分かります。

写真家がメタデータを確認する理由は別にあります。素晴らしい一枚の露出設定は、再現したいレシピそのものです。ISO、絞り、シャッタースピードはツールですぐに読み取れます。

開発者が確認するのは、画像の挙動がおかしいときです。向きフラグの誤り、想定外のDPI値、隠れたカラープロファイルなどが、表示バグの原因になっていることがよくあります。

ツールの限界

このツールは、限界についても正直です。JavaScriptで動作する本格的なバイナリ解析はJPEG、PNG、WebPを対象としており、この3形式で最も詳しいレポートが得られます。

HEIC、GIF、BMP、SVGについては、ファイル形式、ファイルサイズ、画素数といった基本情報を確実に表示します。ただし、バイナリのEXIFチャンク全体の抽出はこれらの形式では行われないため、同じ写真でもJPEGより情報が少なくなる場合があります。

貼り付けたスクリーンショットには、通常カメラタグがありません。OSのクリップボードは元のカメラファイルではなく生の画像データを渡すため、カメラヘッダーがそもそも存在しないのです。

WhatsAppやInstagramからダウンロードした写真も、EXIFタグがゼロの場合がほとんどです。SNSやメッセージアプリは、サーバーへのアップロード時にEXIF・カメラ・GPSヘッダーを自動で削除するからです。

1ファイル20MBまでの制限は、フル解像度のデジタル一眼レフのJPEGや、詳細なPNG書き出し、非圧縮のBMPファイルにも十分対応します。もっと大きなファイルは、まず画像圧縮ツールで小さくしてから確認しましょう。

スマホでの確認方法

写真のほとんどはスマホで撮られるため、ツールはモバイルブラウザでも使えます。モバイル版SafariやChromeでページを開き、カメラロールから写真を選ぶだけです。

ネットに投稿する直前に、隠れたGPS座標やカメラ情報をスマホで確認できます。このタイミングこそ確認が最も重要です。投稿のほとんどはスマホから行われるからです。

画面の構成はパソコンと同じです。概要バナー、GPS警告、グループ分けされた一覧が表示され、「Copy JSON」や「Strip Metadata」も同じように使えます。

スマホの写真にGPS情報が見つかったら、共有する前に削除しましょう。画像メタデータ削除ツールもモバイルで動作するので、確認から削除までの一連の作業がポケットの中で完結します。

まとめ

画像のメタデータとは、すべての写真に隠れているデータのことです。カメラの設定、撮影日時、ソフトの記録、そして場合によってはGPS座標まで含まれます。確認ツールを使えば、それらが見えるようになります。

写真を公開する前、特に自宅や学校、職場で撮った写真は必ず確認しましょう。まずGPS警告を見て、次に琥珀色のPrivacy Tagラベルをチェックします。

記録が必要なときはJSONで保存し、削除したファイルは再確認して本当にきれいになったか確かめます。ツールは無料で、登録不要。写真がアップロードされることは決してありません。

まずは画像メタデータ確認ツールで調べて、削除が必要なファイルはそのまま画像メタデータ削除ツールへ。写真には、自分が共有すると決めたものだけを載せましょう。

よくある質問

EXIF、XMP、IPTCのメタデータは何が違うのですか？

EXIFはカメラが書き込むデータで、露出設定や撮影日時、GPS座標などが含まれます。XMPはAdobeのXML形式のパケットで、編集履歴や評価、説明文などを記録できます。IPTCは報道・出版業界の標準で、キャプションやクレジット、キーワードを扱います。1枚の写真に3つすべてが入っていることもあり、ツールはEXIFやXMP形式の項目、PNGのテキストチャンクをまとめて一覧表示します。

メタデータ確認ツールで写真の撮影場所が分かりますか？

写真にGPS座標が含まれていれば分かります。ツールはGPSIFDタグを10進数の緯度・経度に変換し、警告バナーで表示します。GPSタグがなければ場所を推測することはできません。撮影日時やカメラ情報から場所を想像できる場合もありますが、証明にはなりません。

デジタル一眼レフやミラーレスで撮った写真にも対応していますか？

はい、対応しています。デジタル一眼レフやミラーレスカメラは、レンズの機種、焦点距離、絞り、シャッタースピード、ISO感度、測光モードなど、豊富なEXIFデータを書き込みます。ツールはExifIFDディレクトリからこれらをすべて読み取ります。最大20MBまでのフル解像度JPEGに対応しているので、ほとんどのカメラの書き出しファイルを扱えます。

写真によってメタデータがあったりなかったりするのはなぜですか？

カメラロールにあるオリジナルファイルには、メタデータが丸ごと残っています。一方、WhatsAppやInstagram、Facebook、メールを経由した写真は、アップロード時にEXIFやGPSヘッダーが削除されるため、ほとんど残っていません。スクリーンショットもカメラタグがありません。クリップボードが渡すのは生の画素データだけで、元のカメラファイルではないからです。

オンラインのメタデータ確認ツールでプライベートな写真を調べても安全ですか？

ツールによります。このツールはブラウザの中でファイルのバイト列を解析するため、1バイトも端末の外に出ません。サーバーへのアップロードは一切ありません。逆に、アップロードを要求するツールは避けましょう。削除されていない写真をサーバーに送ると、GPS情報やカメラの詳細を第三者に渡すことになります。

ほかの人から送られてきた写真も確認できますか？

はい、できます。写真を保存してツールにドラッグすれば、いつ撮影されたか、どのカメラで撮られたか、GPS座標があるかどうかが一覧で分かります。ただし、削除済みのファイルは何も表示されません。それはメタデータが削除された証拠であって、写真がオリジナルである証拠ではない点に注意してください。
