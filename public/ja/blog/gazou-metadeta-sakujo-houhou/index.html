画像からメタデータを削除する方法｜EXIF・GPSを消す手順

画像からメタデータを削除する手順を解説。アップロードしてEXIFとGPSを削除し、適切な方法を選び、きれいなファイルをダウンロードして結果を確認するまでを紹介します。無料ツールで処理できるので、共有前のプライバシー対策も安心です。削除後に確認すれば、GPSや撮影情報が残っていないか確かめられます。

画像からメタデータを削除する作業は、1分もかかりません。写真をアップロードし、ツールが隠れたデータを削除し、きれいになったコピーをダウンロードするだけです。

この記事では、無料の画像メタデータ削除ツールを使った手順を一つずつ説明します。ブラウザで動作し、アカウント登録は不要で、写真がどこかにアップロードされることもありません。

読み終わるころには、1枚の写真をきれいにする方法、まとめて削除する方法、適切な削除方法の選び方、結果がきれいだと証明する方法が分かるようになります。

始める前に用意するもの

必要なのは、共有する予定の画像ファイルです。すでにどこかに投稿したコピーではなく、オリジナルのファイルを使いましょう。

ツールはJPG、PNG、WebP、HEICに対応し、1ファイル最大20MBまでです。スマホの写真、デジタル一眼レフのJPEG、PNG書き出し、iPhoneのHEICファイルにも対応します。

メタデータが自分にとって大切なら、オリジナルの非公開コピーを残しておきましょう。削除は、きれいになったコピーについては永久です。カメラ設定やGPS情報はあとから取り戻せません。

ツールはどのモダンブラウザでも開けます。Chrome、Firefox、Safari、Edgeのいずれも、パソコンでもスマホでも動作します。

写真に何が含まれているか分からない場合は、まず画像メタデータ確認ツールで調べましょう。削除する前に、すべてのタグが表示されます。

ステップ1：ツールを開く

画像メタデータ削除ツールのページを開きます。アップロードボックスと、ツールの簡単な説明が表示されます。

サインイン画面も有料の壁もありません。無料で、何枚でも透かしや料金なしで削除できます。

スマホの場合は、モバイル版SafariやChromeでページを開きます。画面が自動で調整され、カメラロールから直接写真を選べます。

写真を頻繁にきれいにする方は、ページをブックマークしておきましょう。出品者、記者、子育て中の方は、公開するたびに使うことが多いので、すぐ開けるようにしておくと便利です。

ステップ2：写真をアップロードする

写真をアップロードボックスにドラッグするか、クリックして端末からファイルを選びます。1枚でも、まとめてでもアップロードできます。

WindowsならCtrl+V、MacならCmd+Vでの貼り付けもできます。コピーした画像やスクリーンショットは、そのままアップロード待ちの列に入り、自動で削除されます。

削除はアップロードと同時に始まります。開始ボタンを押す必要も、サーバーを待つ必要もありません。すべての作業はブラウザのメモリの中で行われます。

1ファイルの上限は20MBです。もっと大きなファイルは、まず画像圧縮ツールで圧縮してから、小さくなったコピーを削除しましょう。

しばらくすると、写真ごとにカードが表示されます。カードにはファイル名、削除結果、確認バッジが示されます。

ステップ3：確認バッジをチェックする

アップロード後、各カードは自動で再スキャンされ、何個のメタデータタグが削除されたかが表示されます。たとえば「Stripped X metadata tags to 0 remaining」のように表示されます。

緑色やエメラルド色のバッジは、出力がきれいだと確認されたことを意味します。ツールは出力ファイルに対してメタデータ解析ツールをもう一度実行するため、このバッジは推測ではなく本当のチェック結果です。

アップロード直後に「Verified clean」と表示された写真は、最初からEXIF、GPS、テキストチャンクがゼロだったという意味です。スクリーンショットやメッセージアプリからダウンロードした写真によくある状態です。

ダウンロードする前に、すべてのカードのバッジが緑色になるのを待ちましょう。まとめて処理する場合、すべてのカードが確認されるまで完了ではありません。

タグが残っているカードがあれば、そのファイルはもう一度処理が必要です。削除方法を変えて「Re-clean All」をクリックしましょう。詳しくはステップ5で説明します。

ステップ4：削除方法を選ぶ

初期設定の方法は「Lossless Binary Strip」で、ほとんどのJPGとPNGの写真に適しています。画素をデコードも再圧縮もせずに、メタデータ部分だけを削除します。

画質を一切変えたくない場合は、この方法のままにしましょう。JPGはJPGのまま、PNGはPNGのまま、透明なPNG背景もバイト単位でそのまま残ります。

受け継いだ部分のない真新しい画像がほしい場合は、「Full Canvas Re-encode」を選びましょう。WebPとHEICの入力には自動で使われ、出力形式を変えるときにも使われます。

再エンコードは向きの問題も解決します。ロスレス削除のあと縦向きのJPEGが横向きに見えるのは、向きフラグが削除され、画素が回転されていないからです。キャンバス再エンコードは、正しい向きを書き出される画像に焼き付けます。

ダウンロードする前なら、選択はいつでも変えられます。方法を変えて「Re-clean All」をクリックすれば、まとめたもの全体が新しい設定で再処理されます。

ステップ5：出力形式と画質を設定する

初期設定では元の形式が維持されます。JPGはJPGのまま、PNGはPNGのままです。メタデータだけを消したい場合、これが最も安全な選択です。

削除しながら変換するには、「Output Format」でJPG、PNG、WebPを選びます。各ファイルはキャンバス経由できれいに再エンコードされ、メタデータが削除された状態で選んだ形式が適用されます。

再エンコードする場合は、「Re-encode Quality」スライダーを50から100％の間で設定します。WebPとJPGの書き出しでは、85％前後がサイズと細部のバランスがよい初期設定です。

スライダーが影響するのは、WebPとHEICの入力、またはFull Canvas Re-encodeでの書き出しだけです。「Lossless Binary Strip」のファイルには、画素が再エンコードされないため、スライダーは何の影響も与えません。

設定を変更したら「Re-clean All」をクリックしましょう。ファイルはアップロード時に現在の設定で削除されるため、このボタンで更新した設定がまとめたもの全体に適用されます。

2つの方法の詳しい比較は、画像メタデータ削除完全ガイドをお読みください。

ステップ6：きれいなファイルをダウンロードする

バッジが緑色になったら、ファイルをダウンロードします。個別のカードの「Download Clean」をクリックしてその写真を保存するか、まとめて「Download All Clean (ZIP)」をクリックします。

ZIPファイルの名前はclean_images_no_metadata.zipです。まとめたものの中のきれいな写真がすべて入っており、フリマアプリや掲示板、出品ページにそのままアップロードできます。

ダウンロードされるのは別のファイルです。ディスク上のオリジナルは変更されません。ブラウザはローカルフォルダのファイルを上書きできないからです。

きれいなファイルは、オリジナルと区別できる場所に保存しましょう。「clean」や「ready-to-post」のようなフォルダが便利です。混ぜてしまうと、せっかくの作業が無駄になります。

共有するのは、きれいになったコピーです。オリジナルではありません。間違えてオリジナルをアップロードすれば、メタデータも一緒に届いてしまいます。

ステップ7：削除後のファイルを確認する

確認は、最も多くの人が省いてしまうステップであり、作業が終わったことを証明するステップです。ダウンロードしたきれいなファイルを画像メタデータ確認ツールにドラッグしましょう。

削除が成功していれば、緑色のバナーで「EXIF、GPS、隠れたカメラタグは検出されませんでした」と表示され、GPS警告も出ません。これはファイルのバイト列に対する独立したチェックです。

タグが残っている場合は、一覧に残った項目が正確に表示されます。残りやすいのはPNGのテキストチャンクやJPEGのコメントで、いい加減なクリーナーでは見落とされがちです。

残り物が見つかったら、削除ツールに戻って「Full Canvas Re-encode」に切り替え、「Re-clean All」をクリックして、もう一度ダウンロードしましょう。次に新しいファイルも同じ方法で確認します。

大切な写真では「確認→削除→再確認」の2回チェックを習慣にしましょう。2回目は数秒で終わり、すべての疑問が消えます。

スマホでメタデータを削除する

写真の共有のほとんどはスマホから行われるため、この手順はモバイルブラウザでも使えます。iOS SafariやAndroid Chromeでツールを開き、カメラロールから写真を選びます。

ファイルはアップロードと同時に削除され、バッジが緑色になり、きれいなコピーを端末に直接ダウンロードできます。次にギャラリーから共有するのは、きれいになったファイルです。

削除するのは、SNSやフリマアプリを開いたあとではなく、開く前です。写真が一度投稿されてしまえば、誰かがすでに元のファイルをメタデータ付きでダウンロードしている可能性があります。

スマホのカメラが初期設定で位置情報を記録している場合は、カメラアプリの位置情報をオフにすることを検討しましょう。そうすれば今後の写真には最初からGPSタグが入らず、位置情報の削除が不要になります。

フリマ出品のためのまとめて削除

出品者は自宅で商品を撮影することが多く、その写真には自宅の住所を示すGPS座標が含まれている可能性があります。まとめて削除すれば、撮影分全体のリスクを一度に消すことができます。

出品用の写真をまとめてドラッグし、すべてのカードのバッジが緑色になるのを待ちます。次に「Download All Clean (ZIP)」をクリックし、きれいになったファイルを出品ページにアップロードします。

掲示板への投稿、賃貸物件の掲載、クラシファイド広告にも同じ手順を使いましょう。見知らぬ人がフル解像度の画像をダウンロードする場所では、メタデータは削除する価値のあるリスクです。

ファイル数の制限はありません。1ファイル20MBまでという上限だけです。出品用の写真100枚も、1枚と同じくらい簡単にきれいにでき、透かしも登録も料金もありません。

この手順の背景にあるプライバシーリスクについては、写真のプライバシーリスクをお読みください。

うまくいかないときの対処法

ほとんどの問題は、原因が単純です。ツールが壊れたと決めつける前に、次のリストを確認してください。

  • 削除後に写真が横向きに見える。ロスレス削除でEXIFの向きフラグが削除されました。「Full Canvas Re-encode」に切り替えて「Re-clean All」をクリックし、正しい向きを画素に焼き付けましょう。
  • 削除後もファイルにタグが残っている。PNGのテキストチャンクやJPEGのコメントが、1回目の処理で残ることがあります。画像を一から再構築する「Full Canvas Re-encode」を試しましょう。
  • 画質スライダーが何も変えないように見える。スライダーが影響するのは、WebPとHEICの入力、またはFull Canvas Re-encodeでの書き出しだけです。「Lossless Binary Strip」は画素を再エンコードしないため、スライダーは影響しません。
  • ファイルがアップロードできない。サイズを確認しましょう。上限は1ファイル20MBです。まず画像を圧縮してから、小さくなったコピーを削除してください。
  • ダウンロードしたファイルがオリジナルと同じに見える。それで正しいのです。削除で消えるのは隠れたデータだけで、画素ではありません。削除が成功したファイルは、オリジナルとまったく同じに見えます。
  • バッジがすぐに「Verified clean」と表示される。元のファイルに最初からメタデータがありませんでした。スクリーンショットやメッセージアプリからの写真によくある状態です。何も問題ありません。

問題が続く場合は、カメラロールから取り出したばかりの新しいオリジナルで試してみましょう。ファイル側の問題か、設定側の問題かが分かります。

HEIC写真のメタデータを削除する

iPhoneの写真はHEICファイルで届くことが多く、扱いが少し異なります。ツールはJPGやPNGと同じように、最大20MBまでのHEICアップロードに対応しています。

HEICファイルは「Lossless Binary Strip」では削除されません。代わりに、ツールは画素を新しいキャンバスに描き直すため、すべてのメタデータヘッダーが確実に削除されます。

つまり、HEICの削除は常に再エンコードです。ダウンロードする前に「Re-encode Quality」スライダーを設定しましょう。85％前後がよい初期設定で、90から100％なら最も多くの細部が残ります。

削除しながらHEIC写真を変換することもできます。「Output Format」でJPG、PNG、WebPを選べば、選んだ形式のきれいなコピーが書き出されます。

HEICをJPGに変換するのは、共有前によく行われる方法です。JPGはどこでも開けるからです。変換と削除が1ステップで終わるため、2回目の作業は不要です。

ダウンロードしたあとは、ほかのファイルと同じ方法で結果を確認しましょう。きれいになったコピーを画像メタデータ確認ツールにドラッグし、緑色のバナーを確かめます。

ダウンロードしたあとにすること

きれいなファイルをダウンロードすることが、最後のステップではありません。ダウンロード後の小さな習慣が、きれいなコピーこそが実際に共有されることを確実にします。

まず、ファイル名を確認しましょう。削除後のダウンロードファイルはオリジナルと同じ名前になることがあるため、混ざらないよう別のフォルダに保管します。

次に、まとめたものの中から少なくとも1ファイルを確認します。きれいになったコピーを確認ツールで開き、アップロードする前に緑色の「タグなし」バナーを確かめます。

3つ目に、投稿が終わったら、ダウンロードフォルダに残ったきれいなコピーを削除しましょう。オリジナルが別の場所にある場合、古いコピーが混ざるとあとで混乱します。

4つ目に、スマホから共有する場合は、共有画面できれいなファイルが選ばれていることを確認します。ギャラリーアプリではオリジナルときれいなコピーが同じように見えるため、ファイル名やフォルダで確認しましょう。

まとめ：手順のおさらい

画像メタデータ削除ツールを開き、写真をドラッグして、緑色の確認バッジを待ちます。JPGとPNGには「Lossless Binary Strip」を、WebP、HEIC、形式の変更、横向きの写真には「Full Canvas Re-encode」を選びましょう。

きれいなファイルやZIPをダウンロードしたら、1つを画像メタデータ確認ツールで確認します。緑色のバナーが表示されれば、その写真は安心して共有できます。

一連の作業は1分もかかりません。公開するたびに習慣にすれば、写真には自分が共有すると決めたものだけが載るようになります。

よくある質問

iPhoneで写真のメタデータを削除するにはどうすればいいですか？

モバイル版Safariで画像メタデータ削除ツールを開き、カメラロールから写真を選んで、緑色の確認バッジが表示されるのを待ちます。次に「Download Clean」をタップして、きれいになったコピーを端末に保存します。共有するのはきれいになったコピーで、カメラロールのオリジナルではありません。

スクリーンショットのメタデータも削除できますか？

スクリーンショットには、そもそもカメラのメタデータがほとんど含まれていません。クリップボードは元のカメラファイルではなく生の画素データを渡すからです。スクリーンショットをツールにドラッグすると、たいていすぐに「Verified clean」と表示されます。それでもツールは確認を行うため、通してみても損はありません。

出品前にたくさんの写真を最も速くきれいにする方法は？

写真をまとめてツールにドラッグし、すべてのカードの緑色のバッジが表示されるのを待って、「Download All Clean (ZIP)」をクリックします。ZIPには、きれいになった写真がすべて1つのファイルにまとまっています。出品ページには、きれいになったファイルをアップロードしましょう。オリジナルは決してアップロードしません。

友だち1人に送るだけなら、写真をきれいにする必要はありますか？

送る方法によります。WhatsAppのようなメッセージアプリはメタデータを自動で削除するため、その方法で送った写真はたいていきれいな状態で届きます。一方、メール添付や直接のファイル転送では、オリジナルがそのまま残ることが多いです。ファイルとして送る場合は、まず写真をきれいにしましょう。

きれいになった写真のファイルサイズがオリジナルより小さいのはなぜですか？

カメラの写真には、EXIFに埋め込まれたプレビューサムネイルやXMPブロック、コメント部分が含まれていることが多いです。「Lossless Binary Strip」モードでこれらを削除すると、画質を変えずに数十KBも軽くなることがよくあります。サイズが小さくなるのは、画質が落ちたサインではなく、おまけのメリットです。

メタデータの削除をあとから元に戻せますか？

いいえ、戻せません。きれいになったコピーには、復元できるメタデータが残っていません。だからこそ、削除する前にオリジナルのファイルを非公開のフォルダに保管しておきましょう。オリジナルにはカメラ設定やGPS情報が自分の記録として残り、共有するのはきれいになったコピーです。
