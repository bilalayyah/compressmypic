共有するすべての写真には、隠れたデータが含まれている可能性があります。撮影場所、使ったカメラ、撮った正確な時刻。画像のメタデータを削除すれば、ほかの誰かが読み取る前にこのデータを消すことができます。

この記事では、メタデータ削除の仕組み、どちらの方法を選ぶべきか、まとめて削除する方法、結果の確認方法を解説します。無料の画像メタデータ削除ツールを前提に説明します。ブラウザの中だけで動作します。

アカウント登録もアップロードも透かしもありません。写真が端末の外に出ることは決してありません。プライバシーのためのツールとして、これが唯一筋の通った形です。

メタデータ削除とは何か

メタデータ削除とは、画像ファイルの中に保存されている隠れたデータを削除し、画素はそのまま残すことです。写真の見た目はまったく同じで、含まれる情報だけが減ります。

削除の対象は、EXIFのカメラ情報、GPSの緯度・経度、撮影日時、AdobeのXMPパケット、IPTC項目、JPEGコメント、PNGのテキストチャンクと時刻チャンクです。

EXIFに埋め込まれたプレビューサムネイルも削除されます。カメラの写真には、メタデータの中に小さなプレビュー画像が入っていることが多く、そのプレビュー自体が撮影の詳細を明かすことがあります。

削除は、きれいになったコピーについては永久です。削除した部分が消えれば、そのファイルから情報を取り戻すことはできません。自分用にデータを残したい場合は、オリジナルを保管しておきましょう。

ディスク上のオリジナルファイルが変更されることはありません。ブラウザはローカルフォルダのファイルを上書きできないため、削除はいつも別のダウンロードファイルとして作られ、オリジナルはそのまま残ります。

共有前に削除する理由

理由はシンプルです。写真をダウンロードするのが誰で、その中のデータをどう使うか分からないからです。フリマアプリの購入者、掲示板の閲覧者、見知らぬ人が、どんな画像でもメタデータ確認ツールで開くことができます。

GPS座標が最も鋭いリスクです。自宅で撮った1枚の写真が、ダウンロードした誰にでも住所を明かしてしまいます。何枚も集まれば、毎日の生活習慣まで分かります。

カメラのシリアル番号は、もっと静かなリスクです。写真を1台の端末に結びつけ、同じシリアル番号が別の名前で現れれば、それらの人物のつながりが見えてしまいます。

撮影日時も生活習慣を明かします。撮影時刻のパターンから、自宅にいる時間、旅行する時期、家が空きやすい時間が分かります。

出品者、記者、子育て中の方、そして公開の場に投稿するすべての人にとって、メタデータの削除は基本的な衛生習慣です。数秒で終わり、リスクの種類そのものを一つ消すことができます。

2つの削除方法

ツールには写真をきれいにする方法が2つあり、どちらを選ぶかが重要です。どちらもメタデータを削除しますが、仕組みが異なります。

「Lossless Binary Strip」は、JPGとPNGの初期設定です。ファイルの構造を直接解析し、JPEGのAPP1からAPP15やCOMセグメント、PNGのeXIf、tEXt、iTXt、tIMEチャンクといったメタデータ部分を削除します。画素をデコードも再圧縮もしません。

画素を再エンコードしないため、画質はまったく変わりません。ファイルは小さくなり、多くの場合数十KBも軽くなりますが、シャープさは変わりません。透明なPNG背景も、補助チャンクだけが削除されるため、バイト単位でそのまま残ります。

「Full Canvas Re-encode」は別の方法です。画素を新しいHTML5キャンバスに描き直し、受け継いだバイナリ部分が一切ない、真新しい圧縮画像を作ります。

再エンコードは、WebPとHEICの入力には自動で使われ、出力形式を変えるときにも使われます。何も残っていないことを確実にしたいときや、ロスレス削除で写真が横向きになってしまったときにも、この方法が適しています。

ロスレス削除とキャンバス再エンコードの比較

画質を一切変えずに最もきれいな結果がほしい場合は、「Lossless Binary Strip」を選びましょう。元の形式のまま残るJPGとPNGの写真に最適な初期設定です。

出力形式を変える場合、入力がWebPやHEICの場合、受け継いだ部分のない真新しい画像がほしい場合は、「Full Canvas Re-encode」を選びましょう。

再エンコードには1つだけ注意点があります。画素を再圧縮するため、画質は「Re-encode Quality」スライダー（50％から100％）に左右されます。ロスレス削除にはこうした注意点がありません。画素に一切触れないからです。

画質スライダーが影響するのは、WebPとHEICの入力、またはFull Canvas Re-encodeでの書き出しだけです。Lossless Binary Stripのファイルには、スライダーの値をどう設定しても影響しません。

向きの扱いも違います。ロスレス削除はEXIFの向きフラグを削除するため、縦向きのJPEGが横向きに見えることがあります。キャンバス再エンコードは、正しい向きを画素そのものに焼き付けます。

ロスレス削除のあと縦向きの写真が横向きに見えたら、「Full Canvas Re-encode」に切り替えて「Re-clean All」をクリックしてください。向きタグがなくても、書き出された画像は正しい向きになります。

削除の手順：5つのステップ

写真をきれいにする作業は5ステップで、最初のステップはアップロードした瞬間に自動で始まります。

  1. 写真をアップロードボックスにドラッグします。JPG、PNG、WebP、HEICに対応し、1ファイル最大20MBまで。Ctrl+Vでの貼り付けもできます。
  2. 自動削除と確認バッジを確認します。ファイルはアップロードと同時に削除され、自動で再スキャンされます。「Stripped X tags to 0 remaining」のように、何個のタグが削除されたかが表示されます。
  3. 必要に応じて削除方法を選びます。JPGとPNGは「Lossless Binary Strip」のまま、真新しい画像がほしい場合は「Full Canvas Re-encode」を選びます。
  4. 出力形式と画質を任意で設定します。「Original」「JPG」「PNG」「WebP」から選び、「Re-encode Quality」を50から100％の間で調整して「Re-clean All」をクリックします。
  5. きれいになったファイルを個別に、またはZIPでまとめてダウンロードします。「Download Clean」で個別に保存するか、「Download All Clean (ZIP)」でclean_images_no_metadata.zipとして保存します。

すべての出力ファイルは、内蔵のメタデータ解析ツールで自動的に再スキャンされます。確認バッジで「注意が必要なEXIF・GPSタグがゼロ」と表示されるため、推測ではありません。

画面付きの詳しい手順は、画像からメタデータを削除する方法をお読みください。

まとめて削除する方法

1枚の削除は簡単ですが、出品者や写真家は数十枚をまとめてきれいにしたいことがあります。ツールは追加の設定なしでまとめて処理できます。

複数の写真をまとめてドラッグし、すべてのカードの確認バッジが緑色になるまで少し待ちます。各ファイルは個別に削除され、個別に再スキャンされます。

「Download All Clean (ZIP)」をクリックすると、まとめたものがclean_images_no_metadata.zipとして保存されます。フリマアプリや出品ページにアップロードする準備が整った、きれいな写真がすべて入っています。

まとめて削除する方法は、フリマアプリや掲示板、出品ページへの投稿前に最適です。自宅で商品を撮影する出品者なら、撮影分すべてを一度にきれいにでき、GPS情報が購入者に届くことはありません。

ファイル数の制限はありません。1ファイル20MBまでという上限だけです。写真の枚数に制限はなく、透かしも登録も料金もありません。

出力形式と画質

初期設定では元の形式が維持されます。JPGはJPGのまま、PNGはPNGのままです。メタデータだけを消してほかを変えたくない場合、これが最も安全な選択です。

削除しながら変換することもできます。「Output Format」でJPG、PNG、WebPを選び、画質を設定して「Re-clean All」をクリックします。各ファイルはキャンバス経由できれいに再エンコードされ、メタデータが削除された状態で選んだ形式が適用されます。

きれいなPNGを直接WebPやJPGに変換するのは、出品ページでより小さなファイルが必要なときに便利です。変換と削除が1ステップで終わるため、2回目の作業は不要です。

ただし、PNGの透明度はロスレス削除では維持されますが、すべての変換で維持されるわけではない点に注意しましょう。透明な背景が必要な場合は、PNG形式のまま「Lossless Binary Strip」を使ってください。

WebPとJPGの書き出しでは、85％前後の画質がよい初期設定です。値を上げると細部がより残り、下げるとファイルが小さくなります。スライダーが影響するのは、再エンコードされる書き出しだけです。

削除後の確認方法

信じることも大切ですが、確認することも大切です。削除したあとは、ダウンロードしたファイルを画像メタデータ確認ツールにドラッグして、タグが本当に消えたか確かめましょう。

ツールは生のバイナリヘッダーを独立して解析します。削除が成功していれば、緑色のバナーで「EXIF、GPS、隠れたカメラタグは検出されませんでした」と表示され、GPS警告も出ません。

ツール自体も出力を確認します。各画像を削除したあと、メタデータ解析ツールをもう一度出力に実行し、「Stripped X metadata tags to 0 remaining」や「Verified clean」といったエメラルド色のバッジを表示します。

アップロード直後に「Verified clean」と表示されたファイルは、最初からEXIF、GPS、テキストチャンクがゼロだったという意味です。スクリーンショットやメッセージアプリからダウンロードした写真によくある状態です。

大切な写真では確認を習慣にしましょう。元のファイルを確認し、削除し、きれいになったコピーを確認する。この一連の流れは1分もかかりません。

スマホでメタデータを削除する

写真の共有のほとんどはスマホから行われるため、ツールはモバイルブラウザでも使えます。iOS SafariやAndroid Chromeでページを開き、カメラロールから直接写真を選びます。

緑色の確認バッジが表示されたら、きれいになったコピーを端末に直接ダウンロードします。次に共有するのは、きれいになったファイルです。オリジナルではありません。

確認と削除は、投稿したあとではなく、投稿する前に行いましょう。写真がフリマアプリやSNSにアップロードされてしまえば、誰かがすでに元のファイルをメタデータ付きでダウンロードしている可能性があります。

貼り付けも、対応しているモバイルでは使えます。パソコンではCtrl+VやCmd+Vで、コピーした画像やスクリーンショットをそのままアップロードできます。

削除ではできないこと

メタデータを削除しても、写真に写っているものは変わりません。番地、学校の制服、ナンバープレート、見覚えのある背景は、画素の中にそのまま残ります。

目に見える透かしも削除されませんし、顔や文字をぼかすこともできません。そうした作業には、画像切り取りツールで注意が必要な部分を切り取るか、ぼかしツールで隠しましょう。

画像そのものがあなたを特定してしまう場合、写真を匿名にすることもできません。メタデータ削除はプライバシーの1層であって、完全な変装ではありません。

画素数も減りません。4000ピクセルの写真は、削除後も4000ピクセルのままです。小さな画像が必要な場合は、削除の前後に画像サイズ変更ツールでリサイズしましょう。

そして、すでに共有した写真を守ることはできません。削除されていない写真が一度公開されれば、コピーがほかの場所に存在する可能性があります。削除が助けるのは次の写真であって、前の写真ではありません。

入手先別の削除方法

写真の入手方法はさまざまで、入手先によって削除すべき内容が変わります。カメラロールから直接取り出した写真は、GPSやEXIFを丸ごと含み、最も多くのメタデータを持っています。

メールで受け取った写真は、たいてい元のまま届きます。オリジナルのメタデータがそのまま残っているため、転送や投稿の前に削除しましょう。送った人が何を含んでいるか気づいていない可能性があります。

メッセージアプリからダウンロードした写真は、すでにきれいなことが多いです。WhatsAppなどのアプリはアップロード時にEXIFやGPSを削除するため、受け取ったファイルには削除すべきものがほとんど残っていません。

スクリーンショットは、ほとんどの場合削除の必要がありません。クリップボードは生の画素データを渡すため、カメラヘッダーがそもそも存在しません。ツールは単に「すでにきれいです」と確認するだけです。

編集した写真は予測がつきません。EXIFを残す編集ソフトもあれば、捨てるソフトもあり、独自のソフトタグを追加するソフトもあります。元の写真がきれいだったとしても、編集後の書き出しは共有前に必ず確認しましょう。

迷ったときは、すべてのファイルをクリーナーに通しましょう。かかる時間は数秒です。すでにきれいだったファイルは「Verified clean」のバッジが表示されるだけで、何も失いません。

削除後のファイルサイズ

メタデータを削除すると、ファイルはたいてい小さくなります。その節約量は、多くの人が想像するより大きいです。隠れたデータは、ほんの数個の数字だけではないからです。

カメラの写真には、EXIFブロックの中に埋め込みプレビューサムネイルが入っていることがよくあります。このサムネイル自体が小さなJPEGであり、削除すれば確かな容量が空きます。

AdobeのXMPパケットも容量を増やします。編集した写真には、すべての調整を記録した長いXML履歴が含まれ、数十KBになることもあります。

PNGファイルも、テキストチャンクや時刻チャンクが積み重なります。作成者名やコメント、作成時刻は1つずつは小さいですが、チャンクが多いファイルでは削除によって目に見える軽量化が得られます。

「Lossless Binary Strip」モードでは、画素を再エンコードしないため、画質を落とさずに容量が減ります。ファイルが小さくなればアップロードも速くなり、写真の多い出品ページでは実用的なメリットです。

プライバシーよりもファイルサイズが主な目的なら、削除と圧縮を組み合わせましょう。まず写真をきれいにし、次に画像圧縮ツールで圧縮すれば、最も小さく安全なファイルになります。

まとめ

画像のメタデータを削除すると、写真の中の隠れたEXIF、GPS、XMP、IPTC、テキスト情報が消え、画素はそのまま残ります。写真を公開する前の、最もシンプルなプライバシー対策です。

画質を一切変えたくないJPGとPNGのファイルには「Lossless Binary Strip」を使いましょう。WebP、HEIC、形式の変更、確実に真新しい画像がほしい場合は「Full Canvas Re-encode」を使います。

まとめて削除してZIPでダウンロードし、きれいになったファイルを画像メタデータ確認ツールで確認します。これで安心して共有できます。写真には、自分が共有すると決めたものだけを載せましょう。

よくある質問

メタデータを削除すると、写真の見た目は変わりますか？

いいえ、変わりません。「Lossless Binary Strip」はメタデータ部分だけを削除し、画素には一切触れないため、画像はバイト単位で同じ見た目のままです。「Full Canvas Re-encode」は画素を再構築するため、画質は「Re-encode Quality」スライダーに左右されます。90から100％なら違いは目に見えず、低い値では軽い圧縮による柔らかさが出ることがあります。

メタデータを削除する前に、オリジナルの写真を残しておくべきですか？

はい、メタデータが自分にとって大切なら残しておきましょう。削除は、きれいになったコピーについては永久です。カメラ設定やGPS座標、撮影日時はそのコピーから取り戻せません。オリジナルは非公開のフォルダに保管し、共有するのはきれいになったコピーだけにしましょう。

メタデータを削除すると、写真の向きも消えてしまいますか？

ロスレス削除ではEXIFの向きフラグが削除されるため、一部の表示方法では縦向きのJPEGが横向きに見えることがあります。「Full Canvas Re-encode」は正しい向きを画素に焼き付けるため、写真は正しい向きのまま残ります。削除後に写真が横向きになった場合は、「Full Canvas Re-encode」に切り替えて「Re-clean All」をクリックしてください。

すでにネットに投稿した写真のメタデータを削除できますか？

自分のコピーをきれいにすることはできますが、ほかの人がすでにダウンロードしたコピーをきれいにすることはできません。削除されていない写真が一度公開されれば、ほかの端末に残っている可能性があります。投稿した写真を削除するか、きれいなバージョンに差し替え、今後のアップロード前には必ずメタデータを削除しましょう。

自分の写真からメタデータを削除するのは合法ですか？

はい、合法です。自分の写真からメタデータを削除することは、自分のデータを公開しないと選ぶことです。注意が必要なのは、自分のものではない写真です。ほかの人の作品から著作権表示やクレジット情報を削除すると、ライセンス条件に違反する可能性があります。自分が撮っていない写真の帰属情報は、そのまま残しましょう。

写真に自宅や通りが写っている場合、メタデータ削除で守れますか？

いいえ、守れません。メタデータ削除で消えるのは、隠れたヘッダーデータだけです。画素の中に見えるもの、つまり番地や通り名、学校の制服、ナンバープレートはそのまま残ります。目に見える情報は、共有する前に切り取るかぼかして隠し、メタデータも合わせて削除しましょう。
