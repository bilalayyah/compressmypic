이미지가 화면에서는 완벽해 보여도 올리는 순간 실패할 수 있습니다. 마켓플레이스가 너무 작다고 거부하거나, 인쇄소가 예상과 다르게 자르거나, 웹사이트가 늘려서 흐릿하게 만들 수 있습니다.

원인은 거의 대부분 크기, 즉 픽셀 단위의 너비와 높이입니다. 대부분 사람은 뭔가 고장 날 때까지 확인하지 않고, 그때는 이미 마감이 코앞인 경우가 많습니다.

이 글에서는 CompressMyPic 이미지 크기 확인 도구의 작동 방식과 보고서의 모든 숫자가 뜻하는 것, 그리고 고객에게 닿기 전에 크기 문제를 잡아내는 방법을 설명합니다.

이미지 크기 확인 도구란?

이미지 크기 확인 도구는 이미지의 픽셀 너비와 높이를 읽어 깔끔한 표로 보여줍니다. 파일 하나뿐 아니라 한 번에 여러 파일을 통째로 넣어도 동작합니다.

JPG, PNG, WebP, GIF, BMP, HEIC, SVG 파일을 최대 20MB까지 지원합니다. 파일 이름에서 운영체제가 추측하는 크기가 아니라, 파일 안에 실제로 저장된 크기를 읽습니다.

너비와 높이뿐 아니라 화면비, 메가픽셀, 파일 크기, 투명도 여부도 보고서에 포함됩니다. 모든 이미지의 300 DPI 인쇄 크기도 계산해 줍니다.

모든 처리는 브라우저 안에서 로컬로 이뤄집니다. 이미지가 서버로 업로드되지 않으니, 아직 공개되지 않은 제품 사진이나 기밀 광고 크리에이티브도 확인하는 동안 안전합니다.

픽셀, 너비, 높이 설명

이미지는 픽셀의 격자이고, 크기는 그 격자의 열과 행 개수에 불과합니다. 1920×1080이라고 설명되는 이미지는 가로 1,920픽셀, 세로 1,080픽셀입니다.

쌍에서는 너비가 항상 먼저 나옵니다. 1200×800 이미지는 가로형이고, 800×1200 이미지는 세로형입니다. 두 이미지의 픽셀 수는 같아도 방향이 다릅니다.

화면에서는 픽셀만이 중요합니다. 화면은 전체 확대 상태에서 이미지 픽셀 하나를 화면 픽셀 하나에 표시하기 때문에, 너비 400픽셀짜리 이미지는 너비 1200픽셀 공간을 늘리지 않고 채울 수 없습니다.

그렇게 늘리는 것이 바로 흐릿한 이미지의 원인입니다. 브라우저가 없는 픽셀을 만들어내는데, 만들어낸 부분은 진짜보다 항상 더 부드럽게 보입니다.

화면비 설명

화면비는 너비와 높이의 관계로, 16:9나 4:3처럼 콜론을 사이에 둔 두 숫자로 적습니다. 이미지의 크기가 아니라 모양을 설명합니다.

1920×1080 이미지와 1280×720 이미지는 같은 16:9 비율을 공유합니다. 둘 다 같은 비율로 나눠떨어지기 때문입니다. 크기는 다르지만 모양은 같습니다.

확인 도구는 16:9, 4:3, 1:1, 3:2, 4:5 같은 일반적인 비율과 각각을 비교합니다. 표준 모양 사이에 낀 이미지에는 정확한 비율도 함께 보여줍니다.

비율이 중요한 이유는 플랫폼이 비율에 맞춰 자르기 때문입니다. 인스타그램 세로 슬롯은 4:5를 기대하니, 16:9 사진을 올리면 양쪽이 잘려 나갑니다. 비율을 먼저 확인하면 무엇이 살아남을지 알 수 있습니다.

메가픽셀 설명

메가픽셀은 이미지의 전체 픽셀 수를 백만 단위로 나타낸 것입니다. 너비에 높이를 곱하고 백만으로 나누면 구할 수 있습니다.

4000×3000 사진은 12메가픽셀입니다. 4,000 곱하기 3,000이 12,000,000픽셀이기 때문입니다. 1920×1080 이미지는 약 2.1메가픽셀입니다.

카메라 제조사는 메가픽셀을 대표 숫자로 쓰지만, 모양은 숨겨집니다. 12메가픽셀 파노라마와 12메가픽셀 정사각형은 픽셀 수는 같지만 크기가 완전히 다릅니다.

인쇄에서는 메가픽셀이 얼마나 크게 인쇄할 수 있는지를 대략 알려줍니다. 12메가픽셀 파일은 A4 크기로 잘 인쇄되고, 2메가픽셀 파일은 엽서보다 커지면 부드러워지기 시작합니다.

대량 확인: 여러 이미지를 한 번에

제품 카탈로그나 사진 촬영본을 검증해야 할 때 이미지를 하나씩 확인하는 건 느립니다. 크기 확인 도구는 한 번의 드롭으로 전체 묶음을 받아줍니다.

폴더나 파일 묶음을 도구에 드래그하면 모든 이미지가 담긴 표가 하나 만들어집니다. 각 행에는 파일 이름, 크기, 비율, 메가픽셀, 파일 크기, 투명도 상태가 표시됩니다.

나중에 묶음을 더 추가할 수도 있습니다. 두 번째 폴더가 나중에 도착하면 드롭하면 되고, 새 행이 기존 보고서를 대체하지 않고 합쳐집니다.

큰 묶음에서 파일 하나를 읽을 수 없으면 도구는 그 파일을 오류로 보고하고 계속 진행합니다. 나머지 묶음은 계속 확인되니, 파일 하나가 전체 작업을 막지 않습니다.

최소 너비, 최소 높이 검증기

많은 플랫폼이 최소 픽셀 크기를 공개합니다. 아마존, 엣시, 쇼피파이는 모두 일정 너비 이하의 제품 이미지를 거부하는데, 정확한 숫자는 플랫폼마다 다릅니다.

확인 도구에는 최소 너비 검사와 최소 높이 검사가 포함돼 있습니다. 플랫폼이 요구하는 숫자를 입력하면 기준에 못 미치는 이미지를 전부 표시해 줍니다.

표시된 이미지가 반드시 쓸 수 없는 건 아니지만 주의가 필요합니다. 더 크게 리사이즈할 수 있지만 부드러워지고, 원본으로 돌아가 더 큰 크기로 내보내는 게 나을 수도 있습니다.

검증기는 팀 안에서도 유용합니다. 최소값을 한 번 정해서 도구에 입력해 두면, 모든 묶음이 눈대중이 아니라 같은 기준으로 판단됩니다.

300 DPI 인쇄 크기

보고서에는 300 DPI 인쇄 크기 열이 있습니다. 픽셀 크기를 인쇄 품질 기준의 물리적 인치로 변환해, 선명도를 잃지 않고 얼마나 크게 인쇄할 수 있는지 알려줍니다.

계산은 간단합니다. 픽셀 너비를 300으로 나누면 인쇄 가능한 너비가 인치로 나옵니다. 너비 3000픽셀짜리 이미지는 300 DPI에서 너비 10인치로 인쇄됩니다.

150 DPI에서는 같은 이미지가 두 배 크게 인쇄되지만 디테일이 눈에 띄게 부드러워집니다. 300 DPI 수치는 브로슈어, 책, 제품 포장에 안전한 숫자입니다.

이 열은 흔한 실수를 막아줍니다. 화면에서는 괜찮아 보이는 너비 1200픽셀짜리 이미지는 300 DPI에서 너비 4인치로만 인쇄돼 포스터에는 턱없이 작습니다.

투명도 감지: 알파 채널

어떤 이미지는 알파라고 부르는 투명도 채널을 가지고 있어서, 이미지의 일부가 뒤에 있는 것을 비추게 합니다. 로고와 아이콘은 보통 필요하고, 사진은 거의 필요하지 않습니다.

확인 도구는 PNG나 WebP에 실제로 알파 채널이 있는지 감지합니다. PNG로 저장됐다고 해서 투명도가 있는 건 아니기 때문에 중요한데, 완전히 불투명한 PNG도 있기 때문입니다.

이걸 알면 창피한 일을 막을 수 있습니다. 편집기에서는 투명해 보이던 로고가 실제로는 불투명해서, 색 배경 위에 올리면 흰색 박스가 보일 수 있습니다.

투명도를 바꾸려면 파일을 제대로 변환해야 합니다. JPG를 PNG로 저장한다고 투명도가 생기지 않고, 확인 도구는 그걸 라이브 사이트에서 발견하기 전에 알려줍니다.

보고서 내보내기: CSV와 JSON

확인은 일의 절반이고, 나머지 절반은 결과를 공유하는 것입니다. 도구는 전체 표를 클릭 한 번으로 CSV나 JSON으로 내보냅니다.

CSV 내보내기에는 파일 이름, 크기, 화면비, 메가픽셀, 파일 크기, 투명도, 인쇄 크기 열이 포함됩니다. 스프레드시트에서 바로 열려 정렬하고 필터링할 수 있습니다.

JSON 내보내기는 같은 데이터를 개발자용 구조화 형식으로 담습니다. 보고서가 스크립트나 콘텐츠 파이프라인, 품질 대시보드로 들어갈 때 맞는 선택입니다.

탭을 닫기 전에 내보내세요. 표는 브라우저 안에만 존재하고, 새로고침하면 사라집니다. 저장된 CSV가 팀이 다시 참고할 수 있는 기록입니다.

SVG 파일과 고유 크기

SVG 그래픽은 픽셀이 아니라 벡터라 크기가 다르게 동작합니다. SVG는 너비, 높이, viewBox 속성으로 정의되는 고유 크기를 가지고 있고, 확인 도구는 이를 읽습니다.

SVG는 선명도를 잃지 않고 어떤 크기로든 확대할 수 있기 때문에 유용합니다. 고유 크기는 얼마나 크게 할 수 있는지의 한계가 아니라 디자이너가 의도한 크기를 알려줍니다.

viewBox는 있지만 너비나 높이가 없는 SVG는 주의하세요. 비율은 있지만 고정된 크기가 없어서, 확인 도구는 절대 크기 없이 비율을 표시합니다.

로고와 아이콘에서는 SVG 판독값이 의도한 비율을 확인해 줍니다. viewBox 비율이 레이아웃이 기대하는 비율과 맞지 않으면 아이콘이 일그러지거나 빈 공간이 생깁니다.

주요 플랫폼 요구사항

모든 플랫폼은 저마다의 크기 규칙을 가지고 있고, 자주 바뀝니다. 아래 표는 출발점일 뿐이고, 대량 업로드 전에는 항상 플랫폼에서 현재 숫자를 확인하세요.

아마존, 엣시 같은 마켓플레이스는 크고 정사각형에 가까운 제품 이미지를 원하고, 긴 쪽이 1000픽셀 이상인 경우가 많습니다. 더 작은 이미지는 최소값 검사에서 떨어지고, 구매자가 확대하면 보기도 좋지 않습니다.

소셜 플랫폼은 각각 원하는 모양이 다릅니다. 정사각형은 피드 게시물에 맞고, 4:5 세로형은 휴대폰 화면을 더 잘 채우며, 16:9 가로형은 동영상 썸네일이나 커버 이미지에 어울립니다.

인쇄 서비스는 줄 수 있는 픽셀을 최대한 많이 원합니다. 300 DPI 기준이면 전면 인쇄에는 대략 2500×3300픽셀이 필요하고, 이는 어떤 웹 이미지보다 훨씬 많습니다.

검사에서 떨어진 이미지 고치기

떨어진 이미지는 보통 세 가지 문제 중 하나입니다. 너무 작거나, 비율이 틀렸거나, 형식이 작업에 맞지 않는 것입니다. 각각 고치는 방법이 다릅니다.

너무 작은 게 고치기 가장 어렵습니다. 업스케일링은 원래 없던 픽셀을 더하니, 결과는 진짜 고해상도 원본보다 부드러워집니다. 가능하면 원본 파일로 돌아가세요.

틀린 비율은 자르기로 고칩니다. 이미지 자르기로 플랫폼이 원하는 비율에 맞춰 이미지를 자르세요. 피사체는 가운데에 두고 중요한 디테일은 프레임 안에 남기세요.

틀린 형식은 변환으로 고칩니다. PNG로 저장된 사진은 웹용 JPG로 바꿀 수 있고, JPG로 저장된 로고는 가장자리가 선명하고 배경이 투명하게 유지되도록 PNG가 돼야 합니다.

크기 확인 도구 vs 이미지 리사이저

확인 도구와 리사이저는 경쟁자가 아니라 짝꿍 도구입니다. 확인 도구는 이미지 크기가 어떤지 알려주고, 리사이저는 답이 틀렸을 때 크기를 바꿉니다.

먼저 진단 단계로 확인 도구를 쓰세요. 묶음에서 어느 이미지가 떨어지는지, 얼마나 모자라는지 알려주니, 손대야 할 것만 리사이즈하면 됩니다.

다음으로 표시된 파일에만 이미지 리사이저를 쓰세요. 묶음 전체를 리사이즈하면 시간만 낭비하고 이미 맞았던 이미지를 망칠 수 있습니다.

그런 다음 리사이즈한 파일을 확인 도구로 다시 실행하세요. 두 번째 검사가 수정이 됐는지 확인해 주고, 프로젝트에 보관할 최종 보고서를 제공합니다.

개인정보: 브라우저 안에서 대량 처리

제품 사진 묶음에는 아직 공개되지 않은 상품이 들어 있을 수 있고, 광고 크리에이티브에는 아직 공개되지 않은 가격이 들어 있을 수 있습니다. 그런 파일을 서버에 올리는 건 위험합니다.

확인 도구는 모든 파일을 로컬에서 읽습니다. 브라우저가 각 이미지를 열고, 측정하고, 표를 만드는데, 단 1바이트도 어디로든 보내지 않습니다.

그래서 하루 제한도 없고 요금도 없습니다. 한 세션에 이미지 천 장을 확인해도 비용은 내 컴퓨터가 파일을 읽는 데 걸리는 시간뿐입니다.

기밀 자료를 다루는 팀에게는 로컬 처리가 이 도구를 쓸 수 있게 만드는 기능입니다. 업로드가 없으니 내 기기 밖에 파일 복사본이 존재하지 않습니다.

이미지 크기 확인 도구 사용법

이미지 크기 확인 도구를 열고 이미지를 업로드 영역에 드롭하세요. 클립보드 이미지를 바로 붙여넣어 픽셀 해상도를 몇 초 만에 확인할 수도 있습니다.

각 파일을 읽을 때마다 표가 채워집니다. 크기, 비율, 메가픽셀 열을 먼저 확인하고, 인쇄 크기와 투명도 열에서 작업에 중요한 세부사항을 보세요.

플랫폼이 요구한다면 최소 너비와 최소 높이 값을 설정하세요. 표시된 행이 눈에 띄게 보이니 어느 파일을 손봐야 할지 정확히 알 수 있습니다.

다 마치면 보고서를 CSV나 JSON으로 내보내고, 실전 단계는 이미지 크기 확인하는 방법에서, 비교 설명은 크기 vs 해상도 vs 파일 크기 정리에서 읽어보세요. 파일을 바꿔야 한다면 이미지 DPI 변경 도구로 인쇄 메타데이터를 다음에 고칠 수 있습니다.

자주 묻는 질문

이미지 크기와 이미지 해상도는 어떻게 다른가요?

크기는 1920×1080 같은 픽셀 너비와 높이입니다. 해상도는 DPI나 PPI 같은 밀도로, 1인치에 픽셀이 몇 개 들어가는지를 말합니다. 이미지는 크기가 크면서 해상도가 낮을 수도 있고, 크기가 작으면서 해상도가 높을 수도 있습니다. 자세한 비교는 크기 vs 해상도 vs 파일 크기 글에서 확인하세요.

한 번에 이미지를 몇 장까지 확인할 수 있나요?

도구에 정해진 제한은 없습니다. 폴더 통째로 이미지를 드롭하면 표가 행 단위로 만들어집니다. 아주 큰 묶음은 브라우저가 파일을 하나씩 읽기 때문에 시간이 더 걸리지만, 하루 제한도 없고 대량 확인에 요금도 없습니다.

왜 내 이미지가 앱마다 크기가 다르게 나오나요?

어떤 앱은 픽셀 크기를 보여주고, 어떤 앱은 DPI 값이나 디스플레이 배율을 적용한 뒤의 크기를 보여주기 때문입니다. 확인 도구는 파일 안에 저장된 진짜 픽셀 너비와 높이를 읽는데, 업로드와 인쇄에서 실제로 중요한 숫자가 바로 이것입니다.

이 도구가 이미지를 잘 인쇄할 수 있는지 알려주나요?

네, 300 DPI 인쇄 크기 열을 통해서 알 수 있습니다. 픽셀 크기를 인쇄 품질 기준의 물리적 인치로 변환해 줍니다. 인쇄 크기가 필요한 크기보다 작으면, 더 크게 인쇄할 때 이미지가 부드럽게 보입니다.

대량으로 크기를 확인하려면 설치가 필요한가요?

아니요. 확인 도구는 데스크톱과 모바일 브라우저에서 동작하고, 설치도 계정도 필요 없습니다. 파일을 드롭하고 표를 읽은 뒤 보고서를 CSV나 JSON으로 내보내면 됩니다.

확인한 뒤 내 이미지는 어떻게 되나요?

아무 일도 일어나지 않습니다. 파일은 브라우저 안에서 로컬로 읽히고 어디에도 업로드되지 않습니다. 탭을 닫으면 표가 메모리에서 사라지니, 결과를 보관하려면 먼저 CSV나 JSON 보고서를 내보내세요.
