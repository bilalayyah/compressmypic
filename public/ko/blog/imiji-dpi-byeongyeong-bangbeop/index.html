이미지 DPI 변경하는 방법: 300 DPI로 바꾸는 4단계

이미지 DPI를 72, 150, 300, 600으로 4단계 만에 바꾸세요. 최대 2400까지 직접 입력도 가능합니다. 대량 처리, ZIP 다운로드, 검증된 DPI 배지 포함. 인쇄소·출판사 제출용으로 알맞은 DPI를 골라 검증하는 과정을 안내합니다.

이미지는 준비됐는데 플랫폼이 300 DPI를 원하고 내 파일은 72라고 하거나, 아예 아무것도 적혀 있지 않습니다. 단계를 알면 1분도 안 걸리는 수정입니다.

이 글에서는 이미지 DPI를 바꾸는 과정을 네 단계로 나눠 설명합니다. 업로드하고, 값을 고르고, 배지를 검증하고, 다운로드하는 순서입니다. 묶음 처리와 스크린샷, 흔히 걸리는 문제도 함께 다룹니다.

설치할 소프트웨어도, 만들 계정도 없고, 픽셀 하나 다치지 않습니다. 변경은 메타데이터 편집이라 이미지는 마쳤을 때 정확히 똑같이 보입니다.

시작하기 전에 준비할 것

JPEG나 PNG 형식의 이미지 파일이 필요합니다. 표준 방식으로 DPI 태그를 저장하는 형식은 이 두 가지뿐이라 도구는 이 두 가지만 받습니다.

목적지가 원하는 DPI 값을 알아두세요. 도서 인쇄소와 학술지는 보통 300을 요구하고, 초안 인쇄는 150을 받아주고, 화면은 72나 96이면 충분합니다.

시작하기 전에 픽셀 크기를 확인하세요. DPI는 픽셀이 너무 적은 이미지를 구해줄 수 없으니, 필요한 인쇄 크기에 크기가 충분한지 먼저 확인하세요.

소프트웨어는 브라우저 하나면 충분합니다. 크롬, 사파리, 파이어폭스, 엣지에서 데스크톱과 모바일 모두 동작하고, 확장 프로그램이 필요 없습니다.

1단계: JPEG나 PNG 파일 업로드

이미지 DPI 변경 도구를 열고 파일을 업로드 영역으로 드래그하세요. 이미지 하나를 드롭할 수도 있고, 묶음 전체를 한 번에 넣을 수도 있습니다.

업로드 영역을 클릭해서 파일을 찾아볼 수도 있고, Ctrl+V로 클립보드 스크린샷을 붙여넣어 저장하지 않고 바로 찍을 수도 있습니다.

각 파일은 현재 DPI가 옆에 표시된 채 목록에 나타납니다. 많은 사진이 처리 전: 설정 안 됨이라고 읽히는데, 이는 파일에 아직 DPI 태그가 없다는 뜻일 뿐입니다.

파일이 거부되면 형식을 확인하세요. WebP, HEIC, BMP, GIF, SVG 파일은 지원되지 않고, 도구는 조용히 실패하는 대신 그렇게 알려줍니다.

2단계: 프리셋 또는 직접 입력 DPI 고르기

다섯 가지 프리셋 중 하나를 고르세요. 화면용 72, 윈도우용 96, 초안 인쇄용 150, 고품질 인쇄용 300, 아카이브 작업용 600입니다. 대부분의 출판 작업에는 300이 맞습니다.

목적지가 다른 숫자를 요구한다면 직접 입력 DPI 필드에 입력하세요. 1부터 2400까지의 정수면 모두 받아주니 200이나 350 같은 값도 잘 동작합니다.

같은 값이 묶음의 모든 파일에 적용됩니다. 이미지마다 다른 DPI 값이 필요하다면 값을 하나씩 나눠서 묶음을 따로 처리하세요.

처리하기 전에 숫자를 다시 확인하세요. 300을 3000으로 잘못 입력하는 실수는 쉽게 일어나고, 그대로 충실히 기록될 수 있으니 필드를 한 번 더 읽어보세요.

3단계: 처리하고 검증 배지 확인하기

클릭해서 파일을 처리하세요. 도구는 각 파일 헤더의 DPI 태그를 다시 쓰고, 파일을 다시 읽어 새 값이 제대로 저장됐는지 확인합니다.

성공한 파일마다 검증된 DPI 배지가 표시됩니다. 그 배지는 출판 플랫폼을 포함한 표준을 지키는 어떤 리더에서도 파일이 같은 DPI를 보고할 것이라는 확인입니다.

파일에 배지 대신 오류가 표시되면 메시지를 읽어보세요. 손상된 JPEG나 지원되지 않는 형식은 명확히 표시되고, 나머지 묶음은 정상적으로 계속 처리됩니다.

검증 단계를 건너뛰지 마세요. 처리됐지만 검증되지 않은 파일은 추측이고, 제출 실패는 배지를 한 번 더 보는 것보다 훨씬 많은 시간을 잡아먹습니다.

4단계: 찍힌 파일 다운로드

파일을 하나씩 다운로드하거나, ZIP 다운로드를 눌러 묶음 전체를 하나의 아카이브로 받으세요. ZIP은 원래 파일 이름을 유지하기 때문에 이미지가 프로젝트로 바로 다시 들어갑니다.

출력 파일은 원본과 구별할 수 있게 이름이 명확히 붙습니다. 원본도 함께 보관해서 손대지 않은 복사본으로 언제든 돌아갈 수 있게 하세요.

다운로드한 파일 하나를 플랫폼이나 이미지 뷰어에서 열고 DPI가 제대로 읽히는지 확인하세요. 이 최종 확인은 몇 초밖에 안 걸리고, 제출 전에 오해를 잡아냅니다.

찍힌 파일을 플랫폼에 제출하세요. 플랫폼이 여전히 불평한다면 문제는 보통 DPI가 아니라 픽셀 크기이니, 그다음에는 크기를 확인하세요.

묶음 전체의 DPI 바꾸기

책, 카탈로그, 학술지 논문은 같은 DPI의 이미지가 수십 장 필요합니다. 묶음 작업은 한 번의 처리로 한 번의 프리셋으로 모두 처리합니다.

폴더 전체를 도구에 드롭하고 값을 한 번 고르세요. 모든 파일이 찍히고, 검증되고, 배지와 함께 나열돼 어느 파일이 실패했는지 한눈에 알 수 있습니다.

묶음을 하나의 ZIP으로 다운로드하세요. 아카이브는 파일 이름을 보존하는데, 문서나 레이아웃 파일에서 이름으로 이미지를 참조할 때 중요합니다.

묶음에 WebP나 HEIC 파일이 몇 개 있다면 먼저 변환하세요. 이미지 변환기가 JPG나 PNG로 바꿔주고, 그다음 다음 묶음에 들어갈 수 있습니다.

인쇄 출판과 학술지용 DPI

아마존 KDP 같은 도서 플랫폼은 원고의 모든 이미지에서 DPI를 검사합니다. 표지나 본문 이미지가 최소값 아래로 태그되면 거부되고, 제출 전체가 멈춥니다.

학술지는 더 엄격합니다. 사진은 300 DPI, 선화는 600 DPI를 요구하는 경우가 많고, 내용을 보기 전에 태그부터 검사합니다.

작업 흐름은 두 경우 모두 같습니다. 픽셀 크기를 먼저 확인하고, DPI를 두 번째로 찍고, 배지를 세 번째로 검증하고, 네 번째로 제출하세요. 첫 단계를 건너뛰는 게 두 번째 거부의 가장 흔한 원인입니다.

선화에는 600 DPI 프리셋을 쓰세요. 얇은 선과 작은 글자는 추가 밀도가 필요하고, 300 DPI 선화는 전체 크기로 인쇄하면 거칠게 보일 수 있습니다.

거부된 72 DPI 파일 고치기

72 DPI 거부는 가장 흔한 DPI 문제이면서 고치기도 가장 쉽습니다. 픽셀은 보통 괜찮고, 메타데이터 태그만 틀린 경우가 많습니다.

파일을 업로드하고 300 DPI 프리셋을 골라 처리하세요. 도구는 태그를 다시 쓰고, 검증하고, 다운로드한 파일은 플랫폼 검사를 통과합니다.

다시 제출하기 전에 크기를 확인하세요. 72 DPI 파일이 픽셀도 작으면 이번에는 크기 때문에 다시 떨어지고, 어떤 DPI 값으로도 고칠 수 없습니다.

파일이 스크린샷이라면 같은 수정이 적용됩니다. 스크린샷은 보통 72나 96 DPI 태그를 가지고 있고, 300 DPI로 찍으면 픽셀이 충분하다는 조건 아래 인쇄 작업 흐름에 맞게 됩니다.

스크린샷용 DPI

스크린샷은 가장 빠른 DPI 수정입니다. 클립보드에서 바로 붙여넣을 수 있기 때문입니다. 화면을 복사하고 도구에서 Ctrl+V를 누르면 스크린샷이 바로 찍을 준비가 됩니다.

인쇄된 매뉴얼이나 책에 들어갈 스크린샷에는 300 DPI를 고르세요. 픽셀은 화면이 캡처한 그대로지만, 태그가 인쇄 작업 흐름을 만족시킵니다.

한계는 솔직하게 받아들이세요. 작은 대화 상자의 스크린샷은 픽셀이 적고, 300 DPI로 찍으면 아주 작은 인쇄물이 될 뿐 선명한 큰 인쇄물이 되지 않습니다.

크게 인쇄해야 하는 스크린샷은 먼저 더 높은 디스플레이 배율로 캡처하세요. 레티나 디스플레이에서 찍은 스크린샷은 픽셀이 두 배라 두 배 크게 인쇄됩니다.

DPI 태그 제거하기

가끔은 다른 태그가 아니라 태그 자체가 없는 게 좋을 때가 있습니다. 도구는 파일에서 DPI 메타데이터를 제거해 픽셀은 그대로 둘 수 있습니다.

제거는 잘못된 태그가 든 파일이 소프트웨어를 헷갈리게 할 때 유용합니다. 이상한 값으로 태그된 사진은 레이아웃 프로그램이 예상과 다르게 크기를 조절하게 만들 수 있고, 태그를 제거하면 동작이 초기화됩니다.

태그를 제거하려면 도구의 제거 옵션을 쓰고 파일을 처리하세요. 다운로드한 파일에는 DPI 메타데이터가 없고, 여는 소프트웨어는 자체 기본값으로 돌아갑니다.

이유가 있을 때만 태그를 제거하세요. 대부분의 출판 작업 흐름은 태그가 있길 원하고, 태그가 없는 파일은 틀린 태그가 있는 파일만큼 쉽게 거부될 수 있습니다.

지원되지 않는 형식 문제 해결

도구가 파일을 거부하면 가장 먼저 형식을 확인하세요. WebP, HEIC, BMP, GIF, SVG 파일은 지원되지 않고, 도구는 명확히 그렇게 알려줍니다.

파일을 JPG나 PNG로 변환한 뒤 다시 시도하세요. 이미지 변환기는 WebP와 HEIC를 처리하고, 변환은 픽셀을 보존하면서 DPI 태그를 담을 수 있는 형식을 파일에 부여합니다.

이름이 잘못된 파일도 주의하세요. .jpg 확장자로 저장된 WebP 파일은 이름이 맞게 보여도 거부됩니다. 도구는 실제 파일 내용을 읽기 때문입니다.

확신이 안 서면 이미지 뷰어에서 파일을 열고 JPG나 PNG로 다시 저장하세요. 깨끗하게 다시 저장하면 형식과 확장자가 일치하는 것이 보장됩니다.

손상된 파일 문제 해결

손상된 JPEG는 오류 메시지와 함께 실패하고, 나머지 묶음은 계속 처리됩니다. 오류는 그 파일에만 해당하고 도구 전체의 문제는 아닙니다.

이미지 뷰어에서 파일을 열어보세요. 뷰어에서도 안 열리면 파일이 손상된 것이니 다시 다운로드하거나 원본에서 다시 내보내야 합니다.

뷰어에서는 열리지만 도구에서 실패하는 파일은 헤더가 손상됐을 수 있습니다. 뷰어에서 다시 저장하면 새 헤더가 기록되고, 새 파일은 보통 잘 처리됩니다.

처리에 실패한 파일은 절대 제출하지 마세요. 인쇄 작업에 들어간 손상된 파일은 제출 전체를 멈추게 할 수 있으니, 진행하기 전에 고치거나 교체하세요.

다운로드 뒤 결과 확인하기

다운로드한 뒤 파일 하나를 열어 DPI를 확인하세요. 윈도우에서는 파일을 마우스 오른쪽 버튼으로 클릭하고 속성을 선택한 뒤 세부 정보 탭을 보세요. 맥에서는 미리보기에서 열고 검사기를 확인하세요.

숫자는 고른 값과 일치해야 합니다. 300 DPI로 찍힌 JPEG는 300으로 다시 읽히고, PNG는 미터당 픽셀로 해상도를 저장하는 방식 때문에 299로 읽힐 수 있습니다.

숫자가 틀렸다면 다운로드한 파일이 아니라 원본을 다시 처리하세요. 찍힌 파일에 다시 찍는 것도 되지만, 원본에서 시작하면 변경의 연결이 깔끔하게 유지됩니다.

각 프로젝트에 쓴 값을 메모해 두세요. 같은 이미지가 규칙이 다른 두 번째 플랫폼으로 갈 때, 메모가 모든 파일을 다시 확인하지 않고 무엇을 바꿀지 알려줍니다.

이커머스와 마켓플레이스 이미지용 DPI

마켓플레이스 이미지는 화면에 존재하니 DPI가 무관해 보이지만, 판매자도 여전히 헷갈립니다. 혼란은 보통 마켓플레이스 도움말 페이지가 픽셀 크기와 함께 DPI를 언급할 때 시작됩니다.

제품 목록에서는 픽셀 크기가 중요한 규칙입니다. 긴 쪽이 1000픽셀을 원하는 마켓플레이스는 픽셀 수를 검사하지 DPI 태그를 검사하지 않으며, 600픽셀짜리 파일을 300 DPI로 찍어도 여전히 떨어집니다.

그렇다고 마켓플레이스 이미지를 300 DPI로 찍는다고 해가 되는 것은 아니고, 가끔 도움이 됩니다. 일부 판매자 도구와 주문형 인쇄 서비스가 태그를 읽고, 올바른 값이 그런 작업 흐름을 원활하게 유지해 줍니다.

실용적인 접근은 픽셀을 먼저 고치고 DPI를 두 번째로 고치는 것입니다. 크기 확인 도구로 크기를 확인하고, 필요하면 리사이즈한 뒤, 목록 이미지를 업로드하기 전 마지막 단계로 300 DPI를 찍으세요.

머그컵, 셔츠, 포스터 같은 주문형 인쇄 상품에서는 DPI가 아주 중요합니다. 상품이 인쇄되는 것이기 때문에 같은 300 DPI 기준이 적용되고, 픽셀 계산이 디자인을 얼마나 크게 인쇄할 수 있는지 결정합니다.

업로드하기 전에 각 상품의 주문형 인쇄 요구사항을 확인하세요. 머그컵에 맞는 디자인이 포스터에는 너무 작을 수 있고, DPI 태그만으로는 그 차이를 메울 수 없습니다.

다른 DPI 값 다시 적용하기

프로젝트가 바뀌면 300 DPI로 찍힌 파일이 나중에 아카이브나 미술품 인쇄용으로 600 DPI가 필요할 수 있습니다. 도구는 같은 파일에 새 값을 다시 적용할 수 있게 해줍니다.

파일을 다시 업로드하고 새 프리셋이나 직접 입력 값을 고른 뒤 처리하세요. 각 처리는 무손실이라 픽셀이 반복 찍기로 손상되지 않습니다.

반대로 600에서 300으로 낮추는 것도 같은 안전함으로 할 수 있습니다. 헤더는 매번 다시 쓰고 픽셀 데이터는 절대 건드리지 않습니다.

DPI가 무엇을 뜻하는지에 대한 전체 배경은 이미지 DPI 변경 완전 가이드에서, 화면 PPI와 비교는 DPI vs PPI: 인쇄와 웹에서 중요한 것에서 확인하세요.

자주 묻는 질문

이미지 DPI를 바꾸는 데 얼마나 걸리나요?

몇 초면 됩니다. 도구는 파일 헤더의 몇 바이트만 다시 쓰고 픽셀을 다시 인코딩하지 않기 때문에, 큰 묶음도 빠르게 끝납니다. 걸리는 시간은 대부분 업로드와 다운로드이지 처리가 아닙니다.

이미지 여러 장의 DPI를 한 번에 바꿀 수 있나요?

네, 가능합니다. 묶음 전체를 도구에 드롭하고 DPI 값 하나를 고르면, 묶음의 모든 JPEG와 PNG가 한 번의 처리로 찍힙니다. 원래 파일 이름을 유지한 채 하나의 ZIP 파일로 결과를 다운로드하세요.

직접 입력 DPI를 실수로 잘못 입력하면 어떻게 되나요?

도구는 1부터 2400까지 입력한 숫자를 그대로 쓰고 배지로 검증합니다. 실수를 알아차리면 원본 파일을 올바른 값으로 다시 처리하면 됩니다. 각 처리는 무손실이라 실수는 이미지가 아니라 1분의 시간만 잃게 합니다.

DPI를 바꾸면 이미지 품질이나 색이 영향을 받나요?

아니요. 헤더의 해상도 메타데이터만 바뀝니다. 픽셀, 압축, EXIF 데이터, ICC 색상 프로파일은 모두 정확히 그대로입니다. 이미지는 전후로 화면에서 똑같이 보입니다.

스크린샷을 붙여넣고 바로 DPI를 바꿀 수 있나요?

네, 가능합니다. 스크린샷을 복사하고 도구에서 Ctrl+V를 누르면 바로 찍을 준비가 됩니다. 인쇄용으로는 300 DPI를 고르고, 처리한 뒤 결과를 다운로드하세요. 화면 캡처에서 인쇄용 파일로 가는 가장 빠른 방법입니다.

파일이 DPI 변경 도구에서 거부된 이유는?

흔한 이유는 WebP나 HEIC 같은 지원되지 않는 형식, 크기 제한을 넘는 파일, 손상된 JPEG입니다. 지원되지 않는 형식은 먼저 JPG나 PNG로 변환하고, 이미지 뷰어에서 열리지 않는 파일은 다시 내보내세요.
