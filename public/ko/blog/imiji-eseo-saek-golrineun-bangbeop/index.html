이미지에서 색 뽑는 방법: 4단계로 정확한 색상 코드 찾기

사진, 로고, 스크린샷에서 정확한 색을 4단계로 뽑아보세요. 돋보기로 조준하고, 스와치를 모으고, CSS로 내보내기까지 — 설치 없이, 업로드 없이. 로고·사진에서 브랜드 색을 뽑아 스와치로 모으는 과정을 안내합니다.

사진이나 스크린샷에서 딱 맞는 색을 찾았는데, 이제 그 코드가 필요합니다. 감으로 맞히면 시간만 낭비하고, 아슬아슬하게 빗나간 색은 원본 옆에서 바로 티가 납니다.

이 글에서는 이미지에서 색을 뽑는 과정을 네 단계로 나눠 설명합니다. 이미지를 올리고, 돋보기로 조준하고, 색을 저장하고, 프로젝트용으로 내보내는 순서입니다.

한 번 익히면 1분도 안 걸립니다. 설치할 소프트웨어도, 만들 계정도 없고, 파일이 서버로 올라가지도 않습니다.

시작하기 전에 준비할 것

색이 들어 있는 이미지가 필요합니다. 사진, 로고 파일, 스크린샷, 디자인 시안 모두 되며, JPG, PNG, WebP, GIF 형식을 지원합니다.

파일은 최대 20MB까지 올릴 수 있어서 휴대폰 사진이나 고해상도 스크린샷도 거뜬히 들어갑니다. 그보다 크면 먼저 압축하거나 새로 스크린샷을 찍으세요.

브라우저만 있으면 됩니다. 크롬, 사파리, 파이어폭스, 엣지에서 데스크톱과 모바일 모두 동작하고, 확장 프로그램이나 플러그인이 필요 없습니다.

마지막으로 이미지 안에서 색이 어디쯤 있는지 대략 알아두세요. 비슷한 색이 많은 복잡한 사진일수록 위치를 아는 게 시간을 아껴줍니다.

1단계: 이미지 업로드 또는 스크린샷 붙여넣기

이미지 색상 추출기를 열고 이미지를 업로드 영역으로 드래그하세요. 영역을 클릭해서 기기에서 파일을 선택할 수도 있습니다.

원하는 색이 지금 화면에 있다면 스크린샷을 찍어 Ctrl+V(윈도우) 또는 Cmd+V(맥)로 붙여넣으세요. 클립보드 이미지를 바로 받아줍니다.

이미지가 로드되면 추출기에 바로 나타납니다. 사진 중심에서 샘플링한 색이 즉시 표시되니 도구가 준비됐다는 걸 바로 알 수 있습니다.

잘못된 파일을 올렸다면 도구 안에서 다른 사진으로 바꾸면 됩니다. 이전에 모은 스와치는 그대로 유지되니, 필요하면 여러 이미지에서 계속 색을 모을 수 있습니다.

2단계: 돋보기로 조준하기

커서를 이미지 위로 움직이면 11×11 배율의 돋보기가 나타납니다. 포인터 주변 픽셀을 확대한 격자로 보여주고, 목표 픽셀이 가운데에 표시됩니다.

원하는 색에 가까워지면 천천히 움직이세요. 돋보기 덕분에 도형의 단단한 중심과 섞인 가장자리를 구분할 수 있습니다.

평평한 부분의 중심을 노리세요. 버튼, 벽, 단색 블록은 중심이 단단하고 테두리에서 색이 섞이기 때문에, 중심에서 나온 값이 진짜 값입니다.

움직이면서 픽셀 검사기도 확인하세요. 커서 아래 픽셀의 정확한 좌표와 실시간 HEX, RGB, HSL, CMYK 값을 보여줍니다.

3단계: 클릭해서 스와치 저장하기

돋보기에 원하는 픽셀이 보이면 클릭하세요. 색이 뽑은 색 스와치함에 들어가고, 코드가 복사할 수 있게 표시됩니다.

HEX 코드를 클릭하면 복사됩니다. HEX는 CSS, 피그마, 캔바, 대부분의 디자인 도구에 바로 붙여넣을 수 있어서 가장 많이 쓰이는 형식입니다.

페이지를 떠나기 전에 필요한 색을 전부 모아두세요. 같은 이미지에서 메인 색, 포인트 색, 배경 색, 텍스트 색까지 한 세트로 모을 수 있습니다.

스와치 두 개가 똑같아 보이면 도구는 중복으로 저장하지 않습니다. 같은 HEX 값을 두 번 클릭해도 깔끔하게 한 개만 남습니다.

4단계: CSS로 내보내거나 코드 복사하기

스와치가 완성되면 CSS 내보내기를 클릭하세요. 색이 CSS 커스텀 프로퍼티 형태의 파일로 다운로드돼 스타일시트에 바로 붙여넣을 수 있습니다.

색이 하나만 필요하다면 검사기에서 HEX 코드를 직접 복사하는 게 더 빠릅니다. 하나의 값 때문에 파일을 다운로드할 필요가 없습니다.

인쇄 작업이라면 각 색에 표시되는 CMYK 값을 메모해 두세요. 근사값이긴 하지만, 제대로 변환하기 전에 인쇄 디자이너에게 전달하기에 유용합니다.

색을 프로젝트에 바로 적용해서 테스트하세요. 코드를 붙여넣고 원래 이미지 옆에 놓고 비교한 뒤, 일치하는 것을 확인하고 나서 그 위에 작업을 쌓아가세요.

사진에서 색 뽑기

사진은 평평한 그래픽과 조금 다르게 다뤄야 합니다. 카메라 노이즈와 JPEG 압축 때문에 이웃한 픽셀이 제각각이라, 한 번의 클릭만으로는 전체를 알 수 없습니다.

같은 부분을 세네 번 샘플링하되, 매번 한두 픽셀씩 옮겨가세요. 코드 앞 다섯 자리가 일치한다면 그게 진짜 색입니다.

찾을 수 있는 가장 큰 평평한 부분에서 뽑으세요. 맑은 하늘, 칠해진 문, 단색 셔츠는 질감이 복잡한 표면보다 훨씬 안정적인 값을 줍니다.

밝은 하이라이트와 깊은 그림자는 피하세요. 그 부분은 색 정보가 사라져서 읽은 코드가 흰색, 검은색, 회색인 경우가 많습니다.

로고에서 색 뽑기

로고는 정밀도가 중요합니다. 브랜드 색이 한 자릿수만 어긋나도 틀린 것처럼 보이니까요. 가능한 가장 고품질의 로고 파일, 되도록 PNG로 시작하세요.

PNG 파일은 색을 정확히 저장하기 때문에 측정값을 믿을 수 있습니다. JPEG 로고는 압축 노이즈 때문에 HEX 코드의 마지막 자릿수가 흔들릴 수 있습니다.

로고에서 가장 큰 평평한 도형의 중심을 샘플링하세요. 글자나 블록의 가운데는 단단하고, 가장자리는 배경과 섞입니다.

결과를 확인하려면 뽑은 색을 같은 화면에서 로고 옆에 놓아보세요. 일치하면 그게 브랜드 색입니다. 아니라면 한두 픽셀 안쪽으로 다시 시도하세요.

스크린샷에서 색 뽑기

스크린샷은 UI 색을 얻는 가장 빠른 방법입니다. 화면을 캡처하고 Ctrl+V로 붙여넣으면 버튼, 헤더, 배경을 바로 샘플링할 수 있습니다.

스크린샷에서는 돋보기를 조심스럽게 쓰세요. 인터페이스 요소는 가장자리가 안티앨리어싱 처리돼 테두리 픽셀이 요소와 배경이 섞인 색입니다.

텍스트 색은 글자의 가장 두꺼운 부분, 예를 들어 볼드 획의 가운데에서 샘플링하세요. 얇은 텍스트는 대부분 가장자리 픽셀이라 혼합값으로 읽힙니다.

작업하면서 픽셀 좌표를 메모해 두세요. 동료가 값을 의심하면 좌표 덕분에 둘 다 정확히 같은 자리로 돌아가 확인할 수 있습니다.

휴대폰이나 태블릿에서 색 뽑기

터치스크린에서는 클릭 대신 탭하고, 돋보기와 스와치 도구도 똑같이 적용됩니다. 갤러리에서 이미지를 올리거나 스크린샷을 붙여넣으세요.

손가락이 픽셀 수십 개를 가리니 먼저 이미지를 확대하세요. 이미지가 커지면 목표도 커지고, 원하는 픽셀을 맞힐 확률이 올라갑니다.

탭하기 전에 돋보기로 확인하세요. 손가락이 화면에 닿아 있는 동안에는 손가락 아래가 보이지 않기 때문에 돋보기가 대신 보여줍니다.

반드시 정확해야 하는 브랜드 색은 데스크톱에서 최종 확인을 하세요. 한 픽셀을 찍는 마우스 클릭이 손가락 탭보다 믿을 만합니다.

색이 이상하게 나올 때 해결법

뽑은 색이 너무 밝거나 어둡게 보인다면 하이라이트나 그림자를 샘플링했을 가능성이 큽니다. 도형의 가운데 쪽으로 이동해서 다시 시도하세요.

색이 탁하게 보인다면 안티앨리어싱된 가장자리를 잡았을 가능성이 높습니다. 한두 픽셀 안쪽으로 이동하면 색이 단단하고 섞이지 않은 지점이 나옵니다.

클릭할 때마다 HEX 코드가 바뀐다면 그 영역이 노이즈가 많은 곳입니다. 근처 픽셀을 여러 개 샘플링하고 가장 자주 나오는 값을 쓰세요.

추출기에서는 맞는 색인데 디자인 도구에서 다르게 보인다면 붙여넣은 코드를 확인하세요. 자릿수가 빠지거나 문자가 바뀐 경우가 대부분이고, 추출기 문제는 아닙니다.

뽑은 색을 프로젝트에 적용하기

웹사이트에서는 HEX 코드를 CSS에 붙여넣거나, 내보낸 커스텀 프로퍼티를 쓰세요. 변수 방식은 사이트 전체에서 색을 일관되게 유지해 줍니다.

피그마, 캔바, 포토샵에서는 색상 필드에 HEX 코드를 붙여넣으세요. 주요 디자인 도구는 전부 HEX를 받아주기 때문에 변환 없이 그대로 전달됩니다.

발표 자료나 문서에서는 RGB 값을 쓰세요. 오피스 도구는 색을 숫자 세 개로 표시하는 경우가 많고, RGB 표시가 그 형식과 정확히 일치합니다.

인쇄는 CMYK 근사값에서 시작해 인쇄소와 확인하세요. 화면과 인쇄기는 색을 다르게 재현하니 테스트 인쇄를 한 번 해보는 게 좋습니다.

이미지 한 장으로 팔레트 완성하기

이미지 한 장이 팔레트 전체를 제공할 수 있습니다. 지배적인 배경 색, 주요 피사체 색, 포인트 색 하나, 텍스트용 어두운 톤을 뽑아보세요.

개수는 적게 유지하세요. 대부분의 디자인에는 네 개에서 여섯 개 색이면 충분하고, 그보다 많으면 레이아웃이 산만해지기 쉽습니다.

내보내기 전에 스와치를 함께 놓고 확인하세요. 두 색이 거의 똑같으면 하나를 빼고, 균형이 안 맞으면 한 색을 더 밝거나 어두운 톤으로 바꾸세요.

이미지 전체를 보는 방식이 필요하다면 이미지 색상 팔레트 추출기를 써보세요. 대표색을 자동으로 순위 매겨 보여주니, 손으로 뽑은 세트와 비교하기에 빠릅니다.

차트와 데이터 시각화에서 색 뽑기

차트와 그래프는 색으로 데이터 계열을 구분합니다. 같은 데이터를 바탕으로 보고서나 대시보드를 만들 때는 그 계열 색을 맞추는 게 중요합니다. 추출기는 차트 이미지에서 모든 계열 색을 되찾을 수 있습니다.

각 막대, 선, 원형 조각의 중심을 샘플링하세요. 색이 배경과 섞이는 가장자리에서 멀리 떨어진 곳이 좋습니다. 두꺼운 막대는 샘플링이 쉽고, 얇은 선은 돋보기로 중심을 맞춰야 합니다.

범례부터 살펴보세요. 범례는 보통 각 계열 색을 단단한 블록으로 보여주기 때문에 차트 전체에서 가장 깨끗한 샘플입니다.

두 계열 색이 거의 똑같아 보이면 HEX 코드를 먼저 확인하세요. 화면에서는 같아 보여도 나란히 놓으면 차이가 날 수 있습니다.

계열 색은 범례 순서대로 저장하세요. 새 차트에서도 색과 계열의 대응이 그대로 유지돼, 원본을 본 독자가 헷갈리지 않습니다.

대시보드라면 배경과 격자선 색도 함께 뽑으세요. 원래 배경과 격자 톤을 재사용한 대시보드는 의도한 대로 보이지만, 감으로 맞힌 것은 어딘가 어색해 보입니다.

뽑은 색 저장하고 정리하기

뽑은 색은 나중에 다시 찾을 수 있어야 쓸모가 있습니다. CSS 내보내기 다운로드가 가장 간단한 저장법입니다. 모든 스와치가 변수 이름과 함께 한 파일에 담기니까요.

내보낸 파일 이름은 날짜가 아니라 프로젝트명으로 지으세요. homepage-refresh-colors.css 같은 이름은 몇 달 뒤에도 유용하지만, colors-2026-11-17.css는 색이 어디에 속하는지 알려주지 않습니다.

디자인 도구를 쓴다면 HEX 코드를 그 도구의 색상 스타일이나 변수 패널에도 붙여넣으세요. 스타일시트와 디자인 파일에 같은 값을 유지하면 둘이 따로 노는 일을 막을 수 있습니다.

브랜드 색은 HEX 코드 옆에 RGB와 CMYK 값도 함께 기록하세요. 팀마다 필요한 형식이 다르고, 모든 형식을 적은 가이드는 사람들이 그때그때 변환하다가 실수하는 일을 막아줍니다.

각 팔레트마다 색의 출처를 짧게 메모해 두세요. 가을 캠페인 사진에서 샘플링함 같은 한 줄이, 나중에 온 디자이너에게 이 색들이 왜 함께 있는지 알려줍니다.

마지막으로 내보낸 CSS 파일을 프로젝트 나머지 파일과 함께 백업하세요. 브라우저 탭에만 있는 팔레트는 탭을 닫는 순간 사라지고, 같은 픽셀을 두 번 다시 뽑는 건 시간 낭비입니다.

빠른 체크리스트

스크린샷의 스크린샷이 아닌 가장 깨끗한 원본 파일을 올리세요. 저장할 때마다 색이 조금씩 이동할 수 있습니다.

돋보기로 조준하고, 평평한 부분의 중심을 샘플링하고, 값을 확인하려고 근처 픽셀 두세 개를 클릭하세요.

웹과 디자인 작업에는 HEX 코드를, 문서에는 RGB 값을, 인쇄 브리프에는 CMYK 근사값을 복사하세요.

스와치가 두 개 이상이면 CSS로 내보내고, 본격적으로 만들기 전에 프로젝트에서 색을 검증하세요. 전체 배경은 이미지 색상 추출 완전 가이드에서, 코드 형식 비교는 HEX vs RGB vs HSL: 색상 코드 완벽 정리에서 확인하세요.

자주 묻는 질문

이미지 한 장에서 색을 몇 개까지 뽑을 수 있나요?

세션 중 모을 수 있는 스와치 수에 실질적인 제한은 없습니다. 디자인에 필요한 만큼 뽑으세요. 다만 일관된 팔레트에는 보통 네 개에서 여섯 개 색이면 충분합니다. 같은 HEX 값을 두 번 클릭해도 중복 항목이 생기지 않습니다.

이미지에서 색을 뽑으려면 설치가 필요한가요?

아니요. 추출기는 크롬, 사파리, 파이어폭스, 엣지 브라우저 안에서 전부 동작합니다. 확장 프로그램도, 플러그인도, 계정도 필요 없습니다. 도구 페이지를 열고 이미지를 올린 뒤 클릭만 하면 됩니다.

동영상 프레임이나 일시정지한 영상에서 색을 뽑을 수 있나요?

간접적으로 가능합니다. 영상을 일시정지하고 프레임을 스크린샷으로 찍은 뒤 Ctrl+V로 추출기에 붙여넣으세요. 도구는 스크린샷 픽셀을 다른 이미지와 똑같이 읽으니 어떤 프레임에서든 색을 샘플링할 수 있습니다.

돋보기가 일반 이미지가 아니라 격자로 보이는 이유는?

돋보기는 커서 주변 픽셀을 확대해서 하나하나 따로 보이게 하기 때문입니다. 격자 덕분에 가운데 픽셀이 어느 것이고 옆 픽셀이 어느 것인지 분명해집니다. 이 정밀함이 섞인 가장자리 픽셀을 피하게 해줍니다.

색상 추출기는 어떤 이미지 형식을 지원하나요?

JPG, PNG, WebP, GIF 파일을 최대 20MB까지 지원합니다. 정확도가 중요할 때는 PNG가 가장 좋습니다. 압축 노이즈 없이 색을 저장하기 때문입니다. 스크린샷은 클립보드에서 바로 붙여넣을 수 있습니다.

휴대폰에 있는 이미지에서도 색을 뽑을 수 있나요?

네, 가능합니다. 갤러리에서 이미지를 올리고 원하는 색을 탭하세요. 손가락 크기 때문에 조준에는 돋보기가 도움이 됩니다. 브랜드 색처럼 반드시 정확해야 하는 색은 데스크톱에서 마우스 클릭으로 최종 확인하세요.
