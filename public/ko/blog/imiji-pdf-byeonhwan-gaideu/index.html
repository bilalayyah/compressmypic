이미지 PDF 변환 완전 가이드: A4·여백·화질까지 한 번에

PDF는 여러 장의 이미지를 하나의 문서로 공유하는 가장 확실한 방법입니다. 어떤 기기에서든 똑같이 열리고, 인쇄도 예측 가능하게 되고, 페이지 순서가 절대 흐트러지지 않습니다.

이미지를 PDF로 바꾸는 일은 예전에는 프로그램을 설치하거나 웹사이트에 파일을 올려야 했습니다. 이제는 브라우저에서 할 수 있고, 이미지가 내 기기를 벗어나지 않습니다.

이 글에서는 전체 과정을 설명합니다. 용지 크기, 방향, 여백, 화질, 그리고 PDF를 전문적으로 보이게 만드는 작은 결정들을 배우게 됩니다.

이미지 PDF 변환이란?

이미지 PDF 변환은 이미지 파일 하나 이상을 가져와 PDF 문서를 만드는 일입니다. 이미지 한 장이 한 페이지가 되고, 페이지는 내가 정한 순서대로 유지됩니다.

결과는 누구나 열 수 있는 파일 하나입니다. 휴대폰, 컴퓨터, 프린터 모두 PDF를 읽고, 레이아웃은 설정한 그대로 유지됩니다.

스캔한 문서, 신분증 사진, 영수증, 숙제, 포트폴리오, 사진첩에 사람들이 이 기능을 씁니다. 여러 이미지가 함께 속할 때는 PDF가 깔끔하게 보내는 방법입니다.

CompressMyPic 도구는 브라우저 안에서 로컬로 PDF를 만듭니다. 스캔본과 신분증 사진이 서버로 업로드되지 않으니 민감한 문서에도 안심할 수 있습니다.

이미지를 따로 보내지 않고 PDF로 보내는 이유

이미지 스무 장이 든 폴더는 보내기도 어색하고 잃어버리기도 쉽습니다. PDF 하나면 모든 것이 순서대로, 하나의 파일명으로 함께 유지됩니다.

PDF는 레이아웃도 지켜줍니다. 채팅 앱에 붙여넣은 이미지는 압축되거나 순서가 바뀔 수 있지만, PDF는 정확한 페이지 순서와 크기를 그대로 보존합니다.

인쇄도 또 다른 이유입니다. PDF는 한 페이지에 이미지 한 장씩 예측 가능한 크기로 인쇄하지만, 이미지를 따로 인쇄하면 예상 밖의 결과가 나오기 쉽습니다.

마지막으로, 많은 공식 시스템은 PDF 업로드만 받습니다. 비자 서식, 대학 포털, 세금 웹사이트는 사진 파일이 아니라 문서를 기대하고, 이 도구가 그 간격을 메워줍니다.

용지 크기: A4, Letter, 이미지 크기에 맞춤

A4는 세계 대부분의 표준 용지 크기입니다. 210×297밀리미터이고, 문서, 서식, 인쇄 제출물의 기본 선택입니다.

US Letter는 A4보다 조금 넓고 조금 짧습니다. 미국과 캐나다의 표준이라 받는 사람이 미국인이거나 서식에 Letter라고 적혀 있을 때 쓰세요.

이미지 크기에 맞춤은 각 이미지와 정확히 같은 크기의 페이지를 만듭니다. 여백도 없고 자르기도 없습니다. 이미지가 페이지 전체를 끝에서 끝까지 채웁니다.

PDF를 인쇄하거나 공식 시스템에 제출할 때는 A4나 Letter를 고르세요. 사진 모음이나 스캔 보관함일 때는 이미지 크기에 맞춤을 고르세요.

방향과 자동 방향

방향은 페이지가 세로인지 가로인지 정합니다. 키가 큰 사진은 세로 페이지에, 넓은 사진은 가로 페이지에 속합니다.

자동 방향은 각 이미지를 읽고 맞는 방향을 골라줍니다. 세로 사진과 가로 사진이 섞인 묶음도 모든 페이지가 자동으로 올바른 레이아웃을 얻습니다.

이미지 크기에 맞춤을 고르면 방향 조절은 비활성화됩니다. 당연합니다. 페이지 크기가 이미지를 따라가니 따로 고를 방향이 없습니다.

스캔한 문서에는 세로 방향이 거의 항상 맞습니다. 스크린샷이나 넓은 사진은 모든 것에 한 가지 레이아웃을 강제하지 말고 자동 방향에 맡기세요.

맞춤(Contain)과 채움(Cover) 배치

맞춤은 이미지를 페이지 안에 통째로 넣습니다. 가장자리에 여백이 생길 수 있지만 아무것도 잘리지 않으니 문서의 어떤 부분도 잘려나가지 않습니다.

채움은 페이지 전체를 채우고 넘치는 부분을 자릅니다. 페이지는 끝에서 끝까지 가득 차 보이지만 이미지의 가장자리가 잘릴 수 있습니다.

문서, 신분증, 영수증에는 항상 맞춤을 쓰세요. 잘린 서명이나 신분증 모서리 하나가 제출을 반려시킬 수 있습니다.

사진첩이나 발표 자료에는 채움이 더 보기 좋습니다. 끝에서 끝까지 가득 찬 레이아웃은 의도적으로 느껴지고, 사진은 조금 잘려도 대개 문제되지 않습니다.

여백: 없음, 작게, 중간

여백 없음은 이미지를 페이지 가장자리까지 바로 붙입니다. 이미지 크기에 맞춤과 전체 페이지 사진에 어울립니다. 여백이 있으면 실수처럼 보이기 때문입니다.

작은 여백은 이미지 주위에 얇은 흰 테두리를 더합니다. 화면에서 깔끔해 보이고, 인쇄할 때 이미지가 페이지 가장자리에서 떨어져 있습니다.

중간 여백은 더 넓은 테두리를 더합니다. 공식 문서나 인쇄해서 철할 모든 것에 어울립니다. 여유 공간이 프린터 가장자리로부터 이미지를 지켜줍니다.

프린터는 종이의 맨 가장자리까지 인쇄할 수 없습니다. 여백 없는 PDF는 종이 위에서 이미지 한 조각을 잃을 수 있습니다. 인쇄할 것에는 최소 작은 여백을 쓰세요.

PDF 이미지 화질 슬라이더

화질 슬라이더는 PDF 안에서 이미지가 얼마나 압축되는지를 정합니다. 화질이 높으면 디테일이 많이 남고 PDF가 커지고, 화질이 낮으면 파일이 작아집니다.

스캔한 문서와 신분증 사진은 화질을 높게 유지하세요. 글자와 작은 인쇄물은 저화질에서 금방 흐릿해지고, 흐릿한 신분증은 반려되는 신분증입니다.

화면으로 볼 사진 모음에는 중간 화질이면 충분합니다. 휴대폰이나 노트북에서는 이미지가 여전히 깨끗해 보이고, PDF는 이메일로 보낼 만큼 작게 유지됩니다.

만든 뒤 최종 파일 크기를 확인하세요. PDF가 이메일 첨부에 너무 크면 화질을 한 단계 낮추고 다시 만드세요.

만들기 전에 페이지 순서 바꾸기

페이지 순서는 곧 문서 순서이니 만들기 전에 제대로 맞추세요. 도구에는 페이지 순서 목록이 있어 페이지를 올바른 순서로 끌어서 놓을 수 있습니다.

목록을 살펴본 뒤 사진을 더 추가할 수도 있습니다. 새 이미지는 대기열 맨 뒤에 들어가고, 나머지와 마찬가지로 끌어서 제자리에 놓으면 됩니다.

공식 제출물은 순서를 두 번 확인하세요. 비자 신청서에서 페이지 순서가 틀리면 각 페이지가 완벽해도 부주의해 보입니다.

중복되거나 거꾸로 된 페이지가 있으면 그 자리에서 지우세요. 지금 순서를 고치는 것이 나중에 PDF를 다시 만드는 것보다 훨씬 쉽습니다.

HEIC 사진을 바로 PDF로

아이폰 사진은 따로 변환하는 단계 없이 PDF 제작기에 바로 들어갈 수 있습니다. 도구가 브라우저에서 HEIC 파일을 풀고 다른 JPG처럼 페이지에 배치합니다.

아이폰 사용자에게는 단계 하나가 통째로 줄어듭니다. HEIC를 JPG로 바꾼 뒤 PDF를 만드는 대신 HEIC 파일을 넣고 한 번만 만들면 됩니다.

풀어낸 이미지는 전체 해상도와 방향을 그대로 유지합니다. 세로 사진은 세로로 남고 넓은 사진은 넓게 남습니다. 자동 방향 처리 덕분입니다.

HEIC 파일이 불러와지지 않으면 HEIC를 JPG로 변환하는 도구로 먼저 JPG로 바꾼 뒤 PDF에 JPG를 추가하세요. 두 단계 경로가 모든 파일에 통합니다.

PDF 속 투명도

투명한 PNG나 WebP 이미지는 PDF 안에서 흰 배경을 얻습니다. PDF 형식은 이미지 파일처럼 투명도를 담지 않으니 도구가 투명한 부분을 채웁니다.

대부분의 문서에서는 흰색이 정확히 맞습니다. 흰색 위의 투명 로고는 깔끔해 보이고 어떤 프린터에서도 잘 인쇄됩니다.

이미지에 투명 배경이 있고 색 있는 페이지 위에 올려야 한다면, 먼저 어울리는 매트 색상으로 JPG로 변환하세요. PNG를 JPG로 변환하는 도구에서 채우기 색상을 고를 수 있습니다.

스캔한 문서에는 투명도가 절대 없으니 이 문제는 로고, 스티커, 그래픽에만 해당합니다. 일반 사진이라면 완전히 무시해도 됩니다.

파일명과 PDF 다운로드

저장하기 전에 출력 파일명을 직접 정할 수 있습니다. passport-application.pdf처럼 분명한 이름은 나중에 찾기 쉽고, 일반적인 다운로드 이름보다 낫습니다.

만드는 동안에는 페이지 X/Y 인코딩 중이라는 진행 메시지가 표시돼 긴 문서가 만들어지는 과정을 볼 수 있습니다. 스무 페이지짜리 PDF도 몇 분이 아니라 몇 초면 됩니다.

브라우저 다운로드 창이 사라졌다면 다운로드 폴더를 확인하세요. 실수로 창을 닫았어도 파일은 자동으로 그곳에 저장됩니다.

완성된 PDF는 보내기 전에 한 번 열어보세요. 페이지 수, 순서, 가장 작은 글자의 가독성을 확인한 뒤 자신 있게 공유하세요.

개인정보: 신분증과 영수증에도 안전한가요?

PDF는 전적으로 브라우저 안에서 만들어지니 여권, 신분증, 세금 영수증이 어디에도 업로드되지 않습니다. 그래서 이 도구는 가진 문서 중 가장 민감한 것에도 안전합니다.

PDF를 만든다고 워터마크, 바닥글 로고, 페이지 도장이 추가되지 않습니다. 문서에는 내가 배열한 이미지 그대로만 들어갑니다.

개인정보 관련 참고사항 하나: PDF를 만든다고 이미지 안의 EXIF 메타데이터가 지워지지는 않습니다. 사진에 GPS 태그가 있다면 먼저 메타데이터 도구로 지우는 것을 고려하세요.

다운로드한 뒤 PDF는 내 기기에만 존재합니다. 탭을 닫으면 서버에 사본이 남지 않습니다. 서버가 애초에 관여하지 않았기 때문입니다.

학교와 대학교용 PDF

학생들은 숙제 스캔본부터 논문 제출까지 PDF를 끊임없이 만듭니다. PDF 하나면 모든 페이지가 순서대로 유지돼 심사위원이 수십 건의 제출물을 읽을 때 도움이 됩니다.

과제에는 맞춤 배치와 작은 여백의 A4 용지 크기를 쓰세요. 이 조합은 화면에서 전문적으로 보이고 인쇄해서 채점하기도 깔끔합니다.

손으로 쓴 스캔본은 화질 슬라이더를 높게 유지하세요. 손글씨는 저화질에서 금방 흐릿해지고, 심사위원이 답을 읽을 수 없으면 채점도 할 수 없습니다.

파일명에는 이름과 과제를 넣으세요. ahmed-essay-3.pdf처럼 말입니다. 분명한 이름은 선생님이 제대로 정리하는 데 도움이 되고 다른 학생과 헷갈리는 일을 막습니다.

제출 전에 파일 크기를 확인하세요. 대학 포털은 종종 5MB나 10MB로 업로드를 제한하고, 고화질 스캔이 긴 PDF는 제한을 넘을 수 있습니다.

직장과 비즈니스용 PDF

청구서, 계약서, 영수증은 비즈니스에서 모두 PDF로 오갑니다. 문서 하나가 이미지 폴더보다 정리하고, 전달하고, 보관하기 쉽습니다.

청구서에는 맞춤 배치와 중간 여백의 A4를 쓰세요. 격식 있는 레이아웃이 전문적으로 보이고, 여백이 프린터 가장자리로부터 내용을 지켜줍니다.

영수증에는 이미지 크기에 맞춤이 잘 맞을 수 있습니다. 영수증은 모양이 제각각이라 각 페이지가 영수증에 정확히 맞으면 낭비되는 여백이 없습니다.

보낸 PDF는 사본을 보관하세요. 거래처와 월별로 정리된 발송 폴더가 있으면 나중에 질문이 생겼을 때 문서를 다시 찾기 쉽습니다.

민감한 비즈니스 문서는 PDF가 로컬에서 만들어진다는 점을 기억하세요. 계약서와 재무 기록은 변환 중에 내 기기를 벗어나지 않습니다.

깔끔한 PDF를 위한 스캔 팁

깔끔한 스캔이 깔끔한 PDF를 만듭니다. 어떤 설정도 나쁜 스캔을 구해줄 수 없습니다. 페이지를 스캐너에 평평하게 놓고, 모서리를 맞추고, 접히거나 그림자가 진 곳이 없는지 확인하세요.

글자가 있는 문서는 200 DPI 이상으로 스캔하세요. 해상도가 낮으면 작은 인쇄물이 흐릿해지고, PDF가 스캐너가 담지 못한 것을 선명하게 만들 수는 없습니다.

도장, 서명, 색 형광펜이 있는 문서는 컬러 스캔을 쓰세요. 흑백 스캔은 더 작지만 진위를 증명하는 색상 정보를 잃습니다.

중요한 작업을 하기 전에 스캐너 유리를 닦으세요. 먼지 한 점이 모든 페이지에 검은 점이 되고, 공식 문서에서는 전문적이지 않게 보입니다.

각 스캔은 PDF에 추가하기 전에 미리보기를 확인하세요. 옆으로 돌아갔거나 거꾸로 된 페이지는 스캔 단계에서 고치기 쉽고 나중에 고치기는 귀찮습니다.

완성된 PDF 공유와 보관

완성된 PDF는 이메일, 채팅, 클라우드 저장소로 쉽게 공유할 수 있습니다. 파일 하나로 첨부돼 폴더가 불완전하게 도착하는 일이 없습니다.

이메일로 보내기 전에 파일 크기를 확인하세요. 대부분의 이메일 서비스는 첨부를 20~25MB로 제한하고, 고화질 스캔이 긴 PDF는 그 제한을 넘을 수 있습니다.

PDF가 크면 첨부 대신 클라우드 링크를 쓰세요. 파일을 드라이브에 올리고 링크를 공유하면 받는 사람은 크기 문제 없이 다운로드합니다.

완성된 PDF는 용도와 날짜별로 정리된 폴더에 보관하세요. 2026-11-visa-documents라는 폴더는 몇 년 뒤에도 찾기 쉽지만 stuff라는 폴더는 그렇지 않습니다.

PDF를 만든 뒤에도 원본 이미지는 보관하세요. 받는 사람이 다른 용지 크기나 더 작은 파일을 원하면 다시 스캔하지 않고 원본에서 다시 만들 수 있습니다.

여행 서류용 PDF

여행 서류는 휴대폰 속 하나의 PDF에 들어가야 합니다. 여권 사본, 비자, 호텔 예약, 항공권이 한 파일에 있으면 국경이나 체크인 데스크에서 찾기 쉽습니다.

맞춤 배치의 A4 용지 크기를 써서 모든 서류가 페이지에 통째로 들어가게 하세요. 잘린 여권 번호나 빠진 비자 도장이 여행 PDF에서 가장 흔한 문제입니다.

여행 서류는 화질 슬라이더를 높게 유지하세요. 흐릿한 여권 사본은 국경에서 반려될 수 있지만, 선명한 사본은 두 번 보지 않고 통과합니다.

PDF는 휴대폰과 클라우드 저장소에 보관하세요. 휴대폰은 잃어버리거나 도난당할 수 있고, 클라우드 사본이 있으면 어떤 기기에서든 서류를 볼 수 있습니다.

원본 이미지도 함께 보관하세요. 공무원이 다른 형식을 요구하면 원본으로 다시 스캔하지 않고 PDF를 다시 만들 수 있습니다.

문서를 만들 준비가 됐나요? 이미지 PDF 변환 도구를 열고 이미지를 끌어다 놓은 뒤 만드세요. 단계별 설명은 이미지를 PDF로 변환하는 방법에서, JPG와 PNG 중 무엇을 고를지는 JPG를 PDF로 vs PNG를 PDF로: 문서용 최적 설정에서 확인하세요. 이미지를 먼저 크기 조절해야 한다면 이미지 변환 도구가 준비를 도와줍니다.

자주 묻는 질문

하나의 PDF에 이미지를 몇 장까지 넣을 수 있나요?

도구에 고정된 페이지 수 제한은 없고, 수십 장 묶음도 잘 동작합니다. 아주 큰 문서는 만드는 데 시간이 더 걸리고 파일도 커지니 이메일로 보낼 수 있는 수준으로 개수를 조절하세요. 사진 50장짜리 앨범이라면 PDF 두 개로 나누는 것을 고려하세요.

만든 PDF가 모든 기기에서 똑같이 보이나요?

네. 그게 PDF의 가장 큰 장점입니다. 설정한 용지 크기, 순서, 레이아웃이 휴대폰, 컴퓨터, 프린터에서 그대로 유지됩니다. 받는 사람은 어떤 앱으로 열든 내가 보는 그대로를 봅니다.

기존 PDF와 이미지를 합쳐서 하나의 문서로 만들 수 있나요?

이 도구로는 안 됩니다. 이미지에서만 PDF를 만드는 도구이기 때문입니다. 이미 PDF가 있다면 전용 PDF 병합 도구로 새 이미지 PDF와 합치세요. 이미지 PDF를 먼저 만든 뒤 두 파일을 병합하면 됩니다.

만든 PDF 파일이 왜 이렇게 큰가요?

PDF 크기는 이미지 수와 화질 슬라이더에 따라 정해집니다. 고화질 스캔이 여러 페이지면 금방 커집니다. 화질 슬라이더를 한 단계 낮추거나 이미지 수를 줄이고 다시 만드세요. 사진은 중간 화질에서도 스캔보다 훨씬 잘 압축됩니다.

인터넷 연결 없이 이미지를 PDF로 변환할 수 있나요?

페이지가 브라우저에 한 번 로드되고 나면 PDF 만들기는 로컬에서 돌아가 인터넷이 필요 없습니다. 인터넷은 처음에 페이지를 열 때만 필요합니다. 그 뒤로는 탭을 닫기 전까지 오프라인으로 PDF를 만들 수 있습니다.

스캔 문서 PDF에 가장 좋은 용지 크기는 무엇인가요?

대부분의 나라에서는 A4가 스캔 문서의 가장 좋은 기본값입니다. 프린터와 공식 시스템이 A4를 기대하기 때문입니다. US Letter는 받는 사람이 미국이나 캐나다에 있을 때만 쓰세요. 이미지 크기에 맞춤은 사진에는 맞지만 문서에는 맞지 않습니다. 이미지마다 페이지 크기가 바뀌기 때문입니다.
