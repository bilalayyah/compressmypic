색상 팔레트 추출기란?

색상 팔레트 추출기는 이미지를 분석해서 가장 중요한 색을 스와치 세트로 돌려줍니다. 각 스와치는 색과 HEX, RGB, HSL 값, 이미지를 차지하는 비율을 보여줍니다.

사진을 업로드하고 원하는 색 수를 고르면 도구가 팔레트를 만듭니다. 결과는 이미 어울리는 색으로 구성된 바로 쓸 수 있는 색 구성입니다. 색이 같은 사진에서 왔기 때문입니다.

도구는 최대 20MB까지 일반적인 이미지 형식을 받습니다. 휴대폰 사진, 제품 사진, 스크린샷, 브랜드 이미지를 커버합니다. 모든 처리는 브라우저 안에서 로컬로 이뤄지니, 고객 무드보드와 아직 공개되지 않은 콘셉트도 안전하게 유지됩니다.

디자이너는 프로젝트를 시작할 때 쓰고, 개발자는 히어로 이미지에서 웹사이트 테마를 만들 때 쓰고, 콘텐츠 크리에이터는 썸네일과 그래픽을 일관되게 유지할 때 씁니다.

미디언 컷 양자화는 어떻게 동작할까

추출기는 미디언 컷 양자화라는 알고리즘으로 팔레트를 만듭니다. 수천 가지 색을 작은 대표 세트로 줄이는 표준 기법입니다.

알고리즘은 이미지의 모든 픽셀을 하나의 상자로 시작합니다. 범위가 가장 넓은 색상 채널을 찾고, 상자를 중앙값에서 절반으로 나눈 뒤, 원하는 개수만큼 상자가 될 때까지 나누기를 반복합니다.

각 상자는 하나의 색을 기여합니다. 그 안에 있는 픽셀들의 평균입니다. 결과는 이미지 전체를 공정하게 대표하는 색 세트입니다. 큰 영역은 자기 스와치를 얻고, 작은 디테일은 하나를 공유합니다.

미디언 컷은 빠르고 예측 가능해서 어디서든 도구에 쓰입니다. 서버나 머신러닝 모델이 필요 없고, 브라우저에서 즉시 실행됩니다.

몇 가지 색: 3개에서 12개 스와치

슬라이더가 팔레트에 들어가는 스와치 수를 3개에서 12개까지 조절하고, 기본값은 6개입니다. 개수는 팔레트의 길이뿐 아니라 성격도 바꿉니다.

세 가지 색은 최소한의 구성을 줍니다. 지배적인 색, 보조 색, 포인트 색입니다. 깔끔한 웹사이트, 단순한 포스터, 로고 작업에 충분합니다.

여섯 가지 색은 균형 잡힌 기본값입니다. 대부분의 사진의 주요 톤을 잡아내면서, 비슷한 음영을 구별하기 어려운 거의 중복된 색으로 나누지 않습니다.

열두 가지 색은 최대값으로, 서로 다른 영역이 많은 복잡한 사진에 어울립니다. 대가는 비슷한 음영이 두 번 나타나기 시작한다는 것이니, 12색 팔레트는 종종 손으로 조금 다듬어야 합니다.

각 스와치의 백분율 배지

모든 스와치는 그 색이 이미지를 얼마나 차지하는지 보여주는 백분율 배지를 가지고 있습니다. 42%인 색은 사진을 지배하고, 3%인 색은 작은 포인트입니다.

백분율은 팔레트의 위계를 알려줍니다. 가장 큰 색은 보통 배경이나 주요 피사체이고, 가장 작은 색은 이미지에 개성을 주는 디테일입니다.

디자인을 만들 때 백분율을 활용하세요. 흔한 규칙은 지배적인 색에 가장 많은 공간을 주고, 보조 색에 지원하는 역할을 주고, 가장 작은 색은 포인트와 하이라이트에만 쓰는 것입니다.

두 스와치의 백분율과 색이 거의 같다면, 알고리즘이 하나의 색을 나눈 것일 가능성이 큽니다. 하나를 남기고 다른 하나를 빼면 팔레트가 더 깔끔해집니다.

비례 색상 막대

스와치 아래에는 도구가 비례 색상 막대를 보여줍니다. 각 색이 이미지를 차지하는 비율에 맞춰 나눈 하나의 막대입니다. 팔레트를 그림으로 보여주는 것입니다.

막대는 균형을 한눈에 보이게 합니다. 한 구간이 아주 크고 여러 조각이 작은 사진은 지배적인 색이 강하고 포인트가 작은 사진이고, 고른 막대는 바쁘고 다채로운 이미지라는 뜻입니다.

디자이너는 막대로 팔레트가 동작할지 판단합니다. 막대가 대부분 한 가지 색인 팔레트는 차분한 디자인을 만들고, 구간이 많이 고른 팔레트는 바쁜 디자인을 만듭니다.

막대는 포인트를 찾는 데도 도움이 됩니다. 가장 작은 구간이 종종 사진을 기억에 남게 만드는 색이고, 버튼과 하이라이트에 맞는 선택인 경우가 많습니다.

CSS 복사: 한 번의 클릭으로 커스텀 프로퍼티

CSS 복사 버튼은 모든 스와치를 한 번의 동작으로 CSS 커스텀 프로퍼티로 복사합니다. --color-1부터 --color-6 같은 변수가 HEX 값과 함께 담겨 스타일시트에 바로 붙여넣을 수 있습니다.

코드를 하나씩 복사하는 것보다 빠르고 안전합니다. 내보내기는 모든 색을 순서대로 유지하고, 옮겨 적는 오류도 없고, 빠진 스와치도 없습니다.

스와치 수를 바꾸면 내보내기도 업데이트됩니다. 이미지를 다시 업로드하지 않고 6개 색에서 4개로 바꿀 수 있고, 복사한 CSS는 새 세트를 바로 반영합니다.

전체 팔레트가 아니라 하나의 정확한 픽셀을 원한다면 이미지 색상 추출기를 쓰세요. 추출기는 내가 고른 픽셀 하나를 읽고, 팔레트 추출기는 이미지 전체의 색을 순위 매깁니다.

JSON 복사: 개발자용 구조화 데이터

JSON 복사 버튼은 팔레트를 구조화 데이터로 내보냅니다. 각 색이 HEX, RGB, HSL 값과 이미지에서 차지하는 백분율과 함께 나열됩니다.

JSON은 팔레트가 스타일시트가 아니라 코드로 들어갈 때 맞는 형식입니다. 디자인 토큰 파이프라인, 테마 생성기, 설정 파일은 모두 JSON을 직접 소비할 수 있습니다.

내보내기에는 화면에 보이는 같은 데이터가 스크립트가 파싱할 수 있는 형태로 포함돼 있습니다. 그래서 팔레트는 값을 다시 입력하지 않고 여러 프로젝트에서 재사용할 수 있습니다.

JSON 파일을 프로젝트와 함께 보관하세요. 몇 달 뒤 디자인 시스템이 팔레트를 다시 필요로 할 때, 파일이 유일한 기준이 되고 아무도 사진에서 다시 추출할 필요가 없습니다.

팔레트 PNG 다운로드: 공유할 수 있는 카드

팔레트 PNG 다운로드 버튼은 팔레트 카드 이미지를 만들어줍니다. 원래 사진과 그 아래에 배치된 스와치 막대와 색이 담긴 추출의 시각적 요약입니다.

카드는 고객이나 팀과 팔레트를 공유하는 데 유용합니다. 팔레트 사진은 HEX 코드 목록보다 빠르게 소통하고, 특히 코드를 읽지 않는 사람에게는 더 그렇습니다.

무드보드, 브랜드 문서, 발표 자료에 카드를 쓰세요. 색이 어디에서 왔는지 보여줘서 팔레트에 대한 신뢰를 만듭니다. 고객이 원본 사진을 볼 수 있기 때문입니다.

카드는 도구의 다른 모든 것처럼 브라우저 안에서 로컬로 만들어집니다. 카드를 만들려고 이미지 데이터가 기기를 떠나지 않습니다.

추출기 vs 스포이트: 다른 질문

추출기와 스포이트는 다른 질문에 답합니다. 추출기는 이미지 전체를 정의하는 색이 무엇인지 묻고, 스포이트는 이 픽셀 하나의 색이 무엇인지 묻습니다.

아이디어가 필요할 때는 추출기를 쓰세요. 사진이 이미 담고 있는 팔레트를 차지하는 면적 순으로 보여주고, 눈으로 골랐을 때는 놓쳤을 색을 종종 드러냅니다.

정밀도가 필요할 때는 스포이트를 쓰세요. 로고의 정확한 파랑, 버튼의 정확한 색조, 벽의 정확한 톤은 모두 단일 픽셀 측정이 필요합니다.

많은 디자이너는 하나의 작업 흐름에서 둘 다 씁니다. 전체 구성은 팔레트를 추출하고, 추출기가 순위를 낮게 매겨 빠뜨린 정확한 포인트 하나는 추출기로 가져옵니다.

PNG의 투명 배경

PNG 파일은 투명도를 담을 수 있고, 추출기는 팔레트를 만들 때 완전히 투명한 픽셀을 무시함으로써 이를 처리합니다. 투명한 배경의 로고는 보이는 색만 기여합니다.

이는 투명한 영역에 자기 색이 없기 때문에 중요합니다. 포함하면 보통 흰색이나 검은색인 거짓 스와치가 더해져 디자인에 아무것도 나타내지 않습니다.

반투명 픽셀은 애매한 영역입니다. 절반 투명한 픽셀은 뒤에 있는 것과 색이 섞이기 때문에, 추출기는 순수한 색이 아니라 섞인 결과를 읽습니다.

로고에는 단단한 배경 위에서 추출기가 가장 잘 동작합니다. 팔레트가 이상하게 보이면 로고를 먼저 흰색이나 브랜드 색 배경 위에 놓고 그 버전에서 추출하세요.

작은 네온 포인트가 안 나타나는 이유

작은 밝은 포인트는 사진에서 가장 기억에 남는 부분이어도 팔레트에서 사라질 수 있습니다. 이유는 차지하는 면적입니다. 추출기는 이미지를 얼마나 채우는지로 색의 순위를 매기기 때문입니다.

사진의 1%를 차지하는 네온 간판은 작은 비율이라서, 알고리즘이 자기 스와치를 주는 대신 이웃 색으로 접을 수 있습니다.

스와치 수를 올리면 도움이 됩니다. 12개 색에서는 이미지가 더 잘게 나눠지기 때문에 작은 포인트가 자기 상자를 얻을 확률이 높아집니다.

포인트가 여전히 안 나타나면 대신 스포이트로 가져오세요. 이미지 색상 추출기가 정확한 픽셀을 읽고, 그 색을 손으로 추출한 팔레트에 더할 수 있습니다.

비슷한 음영이 두 개 나타나는 이유

12색 팔레트에는 거의 똑같이 보이는 스와치가 두 개 나타나는 경우가 있습니다. 이미지의 넓은 영역에 옅은 그라데이션이 있을 때, 예를 들어 하늘이 밝은 파랑에서 조금 더 어두운 파랑으로 이동할 때 일어납니다.

알고리즘은 그 그라데이션을 두 상자로 나누고, 각 상자는 자기 평균을 기여합니다. 두 평균은 가깝지만 이미지의 진짜 다른 부분입니다.

거의 중복된 색을 보면 디자인에 더 맞는 쪽을 남기고 다른 쪽을 빼세요. 파랑 하나인 팔레트가 아무도 구별할 수 없는 파랑 두 개인 팔레트보다 깔끔합니다.

대신 스와치 수를 낮추는 방법도 있습니다. 6개 색에서는 그라데이션이 보통 하나의 상자에 들어가고, 중복이 저절로 사라집니다.

개인정보: 추출은 브라우저 안에서

팔레트 추출은 민감한 이미지를 다루는 경우가 많습니다. 고객 브랜드 콘셉트, 아직 공개되지 않은 무드보드, 개인 사진이 그렇습니다. 그런 이미지를 서버에 올리는 건 감수할 필요가 없는 위험입니다.

추출기는 이미지를 로컬에서 읽습니다. 브라우저가 픽셀을 샘플링하고, 양자화를 실행하고, 팔레트를 만드는데, 단 1바이트도 어디로든 보내지 않습니다.

그래서 페이지가 한 번 로드되고 나면 오프라인에서도 도구가 동작합니다. 비행기 안이나 회의실, 보안 사무실에서 연결 없이도 팔레트를 추출할 수 있습니다.

기밀 브랜드 작업을 다루는 팀에게는 로컬 처리가 결정적인 기능입니다. 작업 흐름의 어느 시점에도 내 기기 밖에 이미지 복사본이 존재하지 않습니다.

백분율로 디자인에 가중치 주기

백분율 배지는 라벨 그 이상입니다. 디자인의 레시피입니다. 사진의 45%를 차지하는 색은 레이아웃의 약 45%를 차지해야 합니다. 그 비율이 사진을 균형 있게 느끼게 만든 것이기 때문입니다.

가장 큰 색을 배경에 할당하며 레이아웃을 시작하세요. 눈이 넓은 영역에서 보는 데 가장 익숙한 색이라서, 그 색으로 만든 페이지는 첫눈에 차분하고 익숙하게 느껴집니다.

두 번째로 큰 색을 주요 콘텐츠 영역에 주세요. 카드, 패널, 섹션입니다. 배경과 경쟁하지 않으면서 받쳐주고, 둘이 함께 페이지의 구조를 만듭니다.

가장 작은 색은 반드시 눈에 띄어야 하는 요소에 남겨두세요. 버튼, 링크, 하이라이트입니다. 레이아웃의 3%에 쓰인 3% 색은 사진에서 눈을 끌었던 바로 그곳으로 눈을 끕니다.

백분율이 레이아웃에 맞지 않으면 의도적으로 조정하세요. 대시보드는 사진보다 보조 색이 더 필요할 수 있고, 그건 실수가 아니라 결정이라면 괜찮습니다.

비례 막대는 가중치를 확인하는 가장 빠른 방법입니다. 막대와 레이아웃을 나란히 비교하면, 불일치가 있다면 바로 보입니다.

이미지 색상 팔레트 추출기 사용법

이미지 색상 팔레트 추출기를 열고 이미지를 업로드 영역에 드롭하거나, 스크린샷을 클립보드에서 바로 붙여넣으세요. 최대 20MB까지 파일을 받습니다.

슬라이더를 움직여 3개에서 12개 사이의 스와치를 고르세요. 기본값은 6개입니다. 팔레트는 즉시 다시 만들어지고, 백분율과 비례 막대가 함께 업데이트됩니다.

팔레트를 CSS 커스텀 프로퍼티나 JSON으로 복사하거나, 팔레트 카드를 PNG로 다운로드해서 팀과 공유하세요.

자주 묻는 질문

웹사이트 팔레트에 가장 좋은 색 수는 몇 개인가요?

여섯 개가 좋은 기본값이고, 도구가 시작하는 숫자이기도 합니다. 대부분의 사진의 주요 톤을 잡아내면서 비슷한 음영을 중복으로 나누지 않습니다. 최소한의 사이트라면 3개나 4개로 줄이세요. 풍부한 브랜드 시스템이라면 8개나 10개로 올린 뒤 거의 중복되는 색을 손으로 다듬으세요.

웹사이트 스크린샷에서 팔레트를 추출할 수 있나요?

네, 가능합니다. Ctrl+V로 스크린샷을 바로 붙여넣거나 스크린샷 파일을 업로드하세요. 추출기는 인터페이스의 색을 순위 매겨서, 마음에 드는 사이트의 팔레트를 되찾는 빠른 방법이 됩니다. 다른 브랜드의 팔레트를 통째로 복사하면 고객 작업에서 독창성 문제가 생길 수 있다는 점은 염두에 두세요.

같은 사진을 다시 업로드하면 팔레트가 바뀌는 이유는?

파일이 똑같다면 바뀌지 않아야 합니다. 팔레트가 바뀐다면 업로드 사이에 파일이 다시 저장되거나 다시 압축돼 픽셀 값이 살짝 이동했을 가능성이 큽니다. 항상 원본 파일에서 추출하고, 사진의 스크린샷이나 다시 내보낸 복사본에서는 추출하지 마세요.

추출한 팔레트를 피그마나 캔바에서 어떻게 쓰나요?

스와치에서 HEX 코드를 복사하거나, CSS 내보내기를 복사해서 거기서 값을 읽으세요. 각 HEX 코드를 피그마나 캔바의 색상 필드에 붙여넣어 팔레트를 색상 스타일로 다시 만드세요. 개발자가 같은 팔레트를 코드로 자동화한다면 JSON 내보내기가 유용합니다.

흑백 사진에서도 추출기가 동작하나요?

네, 동작하지만 팔레트는 거의 검은색에서 거의 흰색까지의 회색 음영이 되고, 백분율은 각 음영이 사진을 얼마나 차지하는지 보여줍니다. 사실 유용합니다. 사진의 회색조는 색조 구조를 드러내서, 단색으로 디자인할 때 도움이 됩니다.

휴대폰에 있는 이미지에서 팔레트를 추출할 수 있나요?

네, 가능합니다. 추출기는 iOS와 안드로이드의 모바일 브라우저에서 동작합니다. 갤러리에서 사진을 업로드하고, 슬라이더를 움직여 스와치 수를 고르고, CSS를 복사하거나 팔레트 카드를 다운로드하세요. 작업 흐름은 데스크톱과 같습니다.
