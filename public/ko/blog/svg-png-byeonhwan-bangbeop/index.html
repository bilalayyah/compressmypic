SVG를 PNG로 변환하는 방법

SVG 로고와 아이콘을 필요한 크기의 PNG로 변환하는 방법. 업로드하고, 배율을 고르고, 결과를 확인한 뒤 다운로드하세요. 파일 하나든 아이콘 팩이든 가능합니다. 웹사이트·앱·인쇄용 크기를 고르는 과정을 안내합니다.

SVG 로고는 무한히 키울 수 있지만, 많은 곳은 여전히 PNG을 원합니다. 변환은 몇 초면 되고, 유일하게 중요한 결정은 출력 크기입니다.

알맞은 배율을 고르면 PNG이 완벽하게 보입니다. 잘못 고르면 흐릿하거나 불필요하게 거대하게 나옵니다.

이 가이드에서는 SVG을 업로드해 선명한 PNG을 다운로드하는 각 단계를 하나씩 짚어 드립니다.

시작하기 전에: SVG 준비하기

먼저 브라우저에서 SVG을 열어 제대로 렌더링되는지 확인하세요. 그곳에서 이상해 보이면 PNG으로도 이상하게 나옵니다.

SVG에 글자가 있다면 디자인 도구에서 글자를 아웃라인으로 바꾸세요. 아웃라인 글자는 도형이 되므로 폰트와 관계없이 정확히 렌더링됩니다.

링크된 이미지는 데이터 URI로 SVG 안에 내장하세요. 변환기가 외부 파일을 가져올 수 없어서 링크된 사진은 PNG에서 빠집니다.

투명한 PNG을 원한다면 배경 사각형을 지우세요. 배경 도형은 이미지의 일부가 되지만, 투명한 SVG은 그대로 투명하게 유지됩니다.

1단계: SVG를 PNG로 변환하는 도구 열기

브라우저에서 SVG를 PNG로 변환하는 도구를 여세요. 윈도우, 맥, 리눅스, 크롬OS, 안드로이드, iOS에서 모두 쓸 수 있습니다.

업로드 영역과 배율 선택기가 보일 것입니다. 이 두 가지 컨트롤이 작업의 전부입니다.

계정이 필요 없고, 아무것도 업로드되지 않습니다. 변환은 기기 안에서 이뤄지므로 고객 로고와 브랜드 자산도 안심하고 쓸 수 있습니다.

휴대폰이라면 모바일 브라우저에서 페이지가 그대로 동작합니다. 업로드 영역을 눌러 기기에서 SVG 파일을 고르세요.

2단계: SVG 파일 업로드하기

SVG 파일을 업로드 영역으로 드래그하거나, 영역을 클릭해 파일 선택 창을 여세요. 여러 파일을 한 번에 골라 일괄 변환할 수도 있습니다.

각 파일은 썸네일이 있는 카드로 나타나서 올바른 파일이 올라왔는지 확인할 수 있습니다. 잘못된 파일은 눈에 띄고 지우기도 쉽습니다.

파일 하나당 최대 25MB까지 받을 수 있어, 수천 개의 패스가 들어간 거대한 일러스트 파일도 충분히 들어갑니다. 아주 복잡한 SVG는 래스터화하는 데 1~2초 더 걸릴 뿐입니다.

컴퓨터에서는 복사한 SVG을 Ctrl+V로 붙여넣을 수도 있습니다. SVG 코드가 다른 앱에서 클립보드에 복사되어 있을 때 편리합니다.

3단계: 출력 배율 고르기

배율 선택기는 1배, 2배, 3배, 4배를 제공합니다. 배율은 SVG의 자연 크기에 곱해지니, 24픽셀짜리 아이콘을 4배로 하면 96픽셀짜리 PNG이 됩니다.

웹사이트 아이콘이라면 2배나 3배가 대개 충분합니다. 레티나 화면에서도 PNG이 선명하게 보이고 바이트도 낭비하지 않습니다.

발표 슬라이드의 로고라면 4배가 여유 있는 선택입니다. 파워포인트에서 작게 키운 로고도 PNG 뒤에 픽셀이 충분하면 선명하게 유지됩니다.

인쇄용이라면 인쇄 크기에서 300 DPI에 닿는 배율을 고르세요. 2인치 너비로 인쇄되는 로고는 최소 600픽셀이 필요하니 인쇄 크기에서 거꾸로 계산하세요.

4단계: 파일 변환하기

변환 버튼을 클릭하세요. 도구가 각 SVG을 선택한 배율로 캔버스에 그린 뒤 결과물을 PNG으로 인코딩합니다.

변환은 빠르고, 파일 하나당 대개 1~2초면 됩니다. 수천 개의 패스가 들어간 아주 복잡한 SVG는 그리는 데 조금 더 걸립니다.

각 카드에는 새 PNG 크기와 해상도가 표시됩니다. 해상도를 확인해 배율이 예상한 크기를 만들었는지 보세요.

파일이 오류와 함께 실패한다면 SVG에 지원되지 않는 기능이나 잘못된 코드가 있을 수 있습니다. 먼저 브라우저에서 열어 그곳에서 렌더링되는지 확인하세요.

5단계: 결과 확인하기

카드의 비교 버튼을 클릭해 SVG과 PNG을 나란히 보세요. 로고 가장자리를 확대해 날카롭고 깔끔한지 확인합니다.

SVG에 글자가 있다면 글자부터 확인하세요. 이상해 보이는 글자는 폰트가 없다는 뜻이고, 해결책은 글자를 아웃라인으로 바꾸고 다시 변환하는 것입니다.

빠진 이미지가 없는지 확인하세요. 사진이 있어야 할 자리가 비어 있다면 이미지가 외부에 링크된 것이고, 데이터 URI로 내장해야 합니다.

투명도를 확인하세요. 투명해야 하는 로고 주변에 흰 상자가 보이면 안 되고, 보인다면 SVG에 지워야 할 배경 사각형이 있는 것입니다.

6단계: PNG 파일 다운로드하기

카드의 다운로드 버튼을 클릭하면 PNG 하나를 저장할 수 있습니다. 파일 이름은 원래 이름을 유지하고 확장자만 .png로 바뀝니다.

일괄 변환했다면 모두 다운로드를 클릭해 변환된 PNG이 전부 들어 있는 ZIP 파일 하나를 받으세요. 하나씩 받는 것보다 훨씬 빠릅니다.

다운로드한 파일은 쓰기 전에 한 번 확인하세요. 사진 뷰어로 PNG을 열어 필요한 크기에서 선명하게 보이는지 확인합니다.

원래 SVG 파일도 함께 보관하세요. 원본이고, 다른 크기의 PNG이 필요할 때마다 다시 래스터화할 수 있습니다.

  1. SVG를 PNG로 변환하는 도구를 열고 SVG 파일을 업로드합니다.
  2. 배율을 고릅니다. 웹용은 2배, 발표와 인쇄용은 4배입니다.
  3. 변환한 뒤 가장자리, 글자, 투명도를 확인합니다.
  4. PNG 하나씩 다운로드하거나 전체 배치를 ZIP으로 받습니다.

아이콘 팩 통째로 변환하기

파일 선택 창에서 SVG 아이콘을 한 번에 모두 고르세요. 대기열에 올라가고, 한 번의 클릭으로 모두 같은 배율로 변환됩니다.

팩 전체에 같은 배율을 쓰세요. 아이콘이 함께 나타날 때는 일관성이 중요하고, 크기가 섞이면 고르지 않아 보입니다.

변환한 뒤에는 50개를 모두 확인할 필요 없이 두세 개 아이콘만 확인하세요. 설정이 같으므로 그 몇 개가 좋아 보이면 나머지도 마찬가지입니다.

PNG 아이콘은 필요한 곳에 업로드하세요. 파비콘, 앱 아이콘, 슬라이드 덱은 모두 추가 변환 없이 PNG 파일을 받습니다.

용도별 크기 고르기

파비콘이라면 사이트가 필요로 하는 정확한 크기, 대개 16, 32, 48픽셀로 래스터화하세요. 파비콘 생성기가 PNG에서도 그 크기를 만들 수 있습니다.

소셜 미디어 아바타라면 400×400픽셀이 좋은 크기입니다. 데스크톱과 모바일에서 선명하게 보이고, 파일도 작게 유지됩니다.

발표용 로고라면 SVG 크기의 4배가 대개 충분한 픽셀을 줍니다. 100픽셀짜리 로고를 4배로 하면 400픽셀이 되어 슬라이드에서 선명하게 보입니다.

인쇄용이라면 DPI에서 계산하세요. 300 DPI에서 2인치 로고는 600픽셀이 필요하니, 최소 그 숫자에 닿는 배율을 고르세요.

흔한 문제 해결하기

PNG이 흐릿해 보이면 배율이 너무 낮았던 것입니다. 낮은 해상도의 PNG은 나중에 선명하게 만들 수 없으니 SVG 원본에서 더 높은 배율로 다시 래스터화하세요.

글자가 이상해 보이면 폰트가 없는 것입니다. 디자인 도구에서 글자를 아웃라인으로 바꾸고 다시 변환하세요.

링크된 사진이 빠져 있다면 이미지로 데이터 URI로 SVG 안에 내장하세요. 변환기가 외부 파일을 가져올 수 없어서 이미지는 SVG 자체 안에 함께 있어야 합니다.

파일이 오류와 함께 실패하면 브라우저에서 SVG을 여세요. 그곳에서 렌더링된다면 배치로 변환하지 말고 단독으로 변환해 보세요.

휴대폰과 태블릿에서 쓰는 요령

휴대폰에서는 업로드 영역을 눌러 기기에서 SVG 파일을 고르세요. 변환은 휴대폰 안에서 이뤄지고, PNG은 기기에 다운로드됩니다.

휴대폰에서는 배치를 작게 유지하세요. 복잡한 SVG은 모바일 프로세서로 래스터화하는 데 시간이 걸립니다. 한 번에 열 개 정도가 적당합니다.

다운로드한 파일은 휴대폰의 다운로드 폴더에 저장됩니다. 아이폰은 파일 앱에서, 안드로이드는 파일 관리자에서 확인하세요.

아이콘 팩이 크다면 데스크톱을 쓰세요. 더 빠른 프로세서와 큰 화면 덕분에 50개 파일을 훨씬 쉽게 관리할 수 있습니다.

명함용 로고 변환하기

명함 로고는 아주 작은 크기로 선명하게 인쇄되어야 하니 SVG을 4배로 래스터화하세요. 뒤에 픽셀이 충분한 작은 로고는 카드 위에서 선명하게 유지됩니다.

변환한 뒤 색상을 확인하세요. 인쇄 색상은 화면 색상과 다릅니다. 빠른 테스트 인쇄로 브랜드 색상이 종이 위에서 알맞게 보이는지 확인할 수 있습니다.

PNG을 인쇄소에 보낼 때 SVG도 백업으로 함께 보내세요. PNG에 문제가 생기면 인쇄소가 SVG을 직접 래스터화할 수 있으니, 둘 다 제공하면 모든 경우를 아우릅니다.

PNG 파일은 작게 유지하세요. 명함 인쇄소는 거대한 이미지가 필요 없습니다. 1000픽셀짜리 로고면 카드에 충분하고, 더 큰 파일은 업로드만 느리게 합니다.

전체 배치를 인쇄하기 전에 테스트 카드 한 장을 주문하세요. 카드 한 장으로 로고 크기, 색상, 선명도를 확인한 뒤 수백 장을 맡기는 것이 안전합니다.

웹사이트용 아이콘 변환하기

웹사이트 아이콘은 SVG 파일로 시작해 오래된 브라우저용 PNG이 됩니다. 표시 크기의 2배나 3배로 래스터화하면 레티나 화면에서도 아이콘이 선명하게 보입니다.

아이콘 세트 전체에 같은 배율을 쓰세요. 아이콘이 함께 나타날 때는 일관성이 중요하고, 크기가 섞이면 고르지 않아 보입니다.

게시하기 전에 실제 웹사이트에서 아이콘을 테스트하세요. 디자인 도구에서는 완벽해 보이던 아이콘이 사이트 배경색 앞에서는 다르게 보일 수 있습니다.

최신 웹사이트라면 SVG 파일을 직접 쓰는 것도 고려하세요. 브라우저는 SVG을 기본으로 표시하고, 아이콘은 래스터화 없이도 완벽하게 크기가 조정됩니다.

변환한 뒤에는 SVG 원본을 프로젝트 폴더에 보관하세요. 웹사이트가 새로 디자인되면 아이콘을 다시 그릴 것 없이 새 크기로 다시 래스터화할 수 있습니다.

티셔츠 인쇄용 SVG 변환하기

티셔츠 인쇄에는 고해상도 이미지가 필요하고, SVG이 이상적인 원본입니다. 선명한 인쇄를 위해 도구가 허용하는 가장 큰 배율, 최대 8000픽셀까지 래스터화하세요.

변환한 뒤 디자인을 확인하세요. 티셔츠 인쇄는 모든 결함을 보여 줍니다. 화면에서는 괜찮아 보이던 로고도 원단에 크게 인쇄하면 거친 가장자리가 드러날 수 있습니다.

PNG을 인쇄소에 보낼 때 SVG도 백업으로 함께 보내세요. 인쇄소 소프트웨어는 한 포맷을 다른 포맷보다 선호할 수 있고, 둘 다 제공하면 모든 경우를 아우릅니다.

어두운 티셔츠라면 투명도를 확인하세요. 배경이 투명한 로고는 어두운 원단에 깔끔하게 인쇄되지만, 흰 상자가 있는 로고는 이상하게 보입니다.

배치를 인쇄하기 전에 테스트용 티셔츠 한 장을 주문하세요. 테스트 인쇄로 수십 장을 맡기기 전에 크기, 색상, 배치를 확인할 수 있습니다.

발표용 SVG 변환하기

발표 슬라이드는 선명한 로고가 필요하고, SVG이 이상적인 원본입니다. SVG 크기의 4배로 래스터화하면 큰 화면에 투사해도 로고가 선명하게 유지됩니다.

변환한 뒤 실제 슬라이드 배경에서 로고를 확인하세요. 흰 배경에서는 완벽해 보이던 로고가 유색 슬라이드에서는 화질이 낮으면 희미한 테두리를 보일 수 있습니다.

슬라이드가 많은 덱이라면 모든 로고를 한 번에 변환하세요. 일괄 변환은 몇 분이면 끝나고, PNG은 슬라이드에 바로 넣을 수 있습니다.

발표 전에 프로젝터로 덱을 테스트하세요. 노트북에서는 선명해 보이던 슬라이드가 프로젝터에서는 부드럽게 보일 수 있고, 빠른 테스트가 문제를 미리 잡아냅니다.

변환한 뒤에는 SVG 원본을 프로젝트 폴더에 보관하세요. 새 템플릿으로 발표를 다시 쓰면 로고를 새 크기로 다시 래스터화할 수 있습니다.

파비콘용 SVG 변환하기

파비콘은 브라우저 탭에 있는 작은 아이콘으로, 대개 SVG 로고에서 시작합니다. 표준 파비콘 크기인 16, 32, 48픽셀로 래스터화하세요.

파비콘은 단순하게 디자인하세요. 작은 크기에서는 디테일이 숨기 때문입니다. 16픽셀에서 복잡한 로고는 흐릿해지지만, 단순한 도형은 알아볼 수 있게 유지됩니다.

추가한 뒤 여러 브라우저에서 파비콘을 테스트하세요. 빠르게 확인하면 모든 탭에서 사이트가 깔끔하게 보입니다.

최신 브라우저라면 SVG 파비콘을 직접 쓰는 것도 고려하세요. 브라우저는 SVG 파비콘을 기본으로 표시하고, 아이콘은 래스터화 없이도 완벽하게 크기가 조정됩니다.

변환한 뒤에는 SVG 원본을 보관하세요. 사이트가 새로 디자인되면 파비콘을 다시 그릴 것 없이 새 크기로 다시 래스터화할 수 있습니다.

웹사이트 배너용 SVG 변환하기

웹사이트 배너는 넓은 이미지이고, 배너가 사진이 아니라 그래픽이라면 SVG이 이상적인 원본입니다. 선명한 결과를 위해 배너 표시 너비로 래스터화하세요.

변환 전에 배너 크기를 확인하세요. 1200픽셀 너비로 표시되는 배너는 최소 그 너비의 PNG이 필요하고, 그렇지 않으면 부드럽게 보입니다.

글자가 들어간 배너라면 표시 크기의 2배로 래스터화하세요. 레티나 화면에서도 글자가 선명하게 유지되고, 파일은 빨리 로딩될 만큼 작게 유지됩니다.

변환한 뒤 데스크톱과 휴대폰에서 배너를 테스트하세요. 넓은 화면에서는 완벽해 보이던 배너가 좁은 화면에서는 심하게 잘릴 수 있고, 빠른 테스트가 이를 잡아냅니다.

SVG 원본은 프로젝트 폴더에 보관하세요. 웹사이트가 새 배너 크기로 새로 디자인되면 그래픽을 다시 그릴 것 없이 다시 래스터화할 수 있습니다.

과정은 이것뿐입니다. 준비하고, 업로드하고, 배율을 고르고, 다운로드하면 됩니다. 배경 지식은 SVG를 PNG로 변환하는 방법 완벽 가이드에서, 벡터와 래스터 문제는 SVG vs PNG: 벡터 vs 래스터 설명에서 확인하세요. SVG이 섞인 배치라면 이미지 변환기도 처리합니다.

자주 묻는 질문

1배 배율에서 PNG의 크기는 어떻게 되나요?

1배에서는 PNG이 SVG 자연 크기와 같아져서 24픽셀짜리 아이콘은 24픽셀짜리 PNG이 됩니다. 최신 화면에서 선명한 결과를 원하면 2배나 3배를, 발표나 인쇄용이라면 4배를 쓰세요. 내보내기는 가장 긴 변 기준 8000픽셀로 제한되는데, 아이콘과 로고에서는 거의 문제가 되지 않습니다.

휴대폰에서 SVG 파일을 변환할 수 있나요?

네, 가능합니다. 휴대폰 브라우저에서 도구를 열고 업로드 영역을 눌러 기기에서 SVG 파일을 고르세요. 변환은 휴대폰 안에서 이뤄지고 PNG은 기기에 다운로드됩니다. 복잡한 SVG은 모바일에서 래스터화하는 데 시간이 걸리니 휴대폰에서는 배치를 작게 유지하세요.

내보낸 PNG은 어떤 파일 이름을 유지하나요?

PNG은 원래 SVG 파일 이름에 .png 확장자를 붙여 유지합니다. logo.svg가 logo.png이 되는 식입니다. 찾기 쉽고 파일도 정리된 상태를 유지합니다. 일괄 변환이라면 ZIP 파일에 원래 이름과 맞는 PNG이 모두 들어 있습니다.

변환기가 SVG 애니메이션을 지원하나요?

사실상 지원하지 않습니다. SMIL이나 CSS를 쓰는 SVG 애니메이션은 보존되지 않는데, 변환기가 캔버스에 정지된 프레임 하나만 그리기 때문입니다. 결과물은 시작 모습의 SVG을 담은 정지 PNG입니다. 움직이는 로고라면 SVG 자체를 그대로 두세요.

데이터 URI로 내장된 이미지가 있는 SVG을 래스터화할 수 있나요?

네, 가능합니다. 데이터 URI로 SVG 안에 내장된 이미지는 파일의 일부라 PNG에서도 제대로 렌더링됩니다. 변환용으로 SVG에 사진을 포함하는 올바른 방법입니다. 반대로 링크된 외부 이미지는 변환기가 가져올 수 없어서 빠집니다.

왜 변환한 PNG이 흐릿하게 보이나요?

필요한 크기보다 배율이 너무 낮았던 것입니다. 1배로 래스터화한 24픽셀짜리 아이콘은 24픽셀에 불과해서 200픽셀로 늘리면 흐릿해집니다. 낮은 해상도의 PNG은 나중에 선명하게 만들 수 없으니 SVG 원본에서 더 높은 배율로 다시 래스터화하세요.
