GIF 압축기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

최대 30MB 애니메이션 또는 정적 GIF를 드롭하세요

.gif 파일(최대 30MB)을 드롭존에 업로드하면 프레임, 치수, 폐기 방식, 시간 지연을 로컬에서 디코딩합니다.

2

빠른 프리셋을 선택하거나 사용자 지정 설정을 조정하세요

가벼움(192색, 100%), 균형(96색, 85%), 최대 축소(64색, 75%, 2프레임마다 건너뛰기)를 클릭하거나 각 수단을 수동으로 조정하세요.

3

색상 팔레트 한도를 낮추세요(16–256색)

색상 팔레트 한도 슬라이더를 256에서 32나 16색 방향으로 드래그하거나 빠른 256, 128, 64, 32 버튼을 클릭해 LZW 색상 테이블을 축소하세요.

4

출력 배율과 프레임 속도 최적화를 조정하세요

출력 배율 프리셋(100%, 85%, 75%, 50%, 25%)을 선택하고, 실제 재생 속도를 자동으로 유지하면서 선택적으로 2프레임마다 또는 3프레임 중 2프레임을 건너뛰세요.

5

GIF 압축을 실행하고 실시간 애니메이션을 비교하세요

원본 대 압축 실시간 애니메이션 미리보기를 나란히 보고 정확한 바이트, 프레임 수, 절약 백분율을 검토하세요.

6

압축된 GIF 다운로드

압축된 GIF 다운로드를 클릭해 <파일이름>_compressed.gif을 서버 왕복이나 워터마크 없이 로컬에 저장하세요.

CompressMyPic GIF 압축기을 사용해야 하는 이유

진정한 클라이언트 측 GIF 다시 인코딩

GIF 프레임, 폐기 방식, 반복 횟수를 로컬에서 디코딩한 뒤 필요 시 로드되는 색상 양자화를 사용해 다시 인코딩합니다. 서버 업로드가 전혀 없습니다.

3가지 압축 수단

팔레트 색상 축소(256 → 32색), 치수 스케일링(100% → 25%), 스마트 프레임 건너뛰기로 크기를 줄입니다.

시간을 보존하는 프레임 건너뛰기

2프레임마다 또는 3프레임마다 건너뛸 때 유지된 프레임의 지연이 자동으로 합쳐져 재생 속도가 자연스럽게 유지됩니다.

정직한 바이트 비교

전후 파일 크기와 프레임 수를 정확히 표시하고, 더 강한 팔레트나 배율 축소가 필요할 때 명확히 알려줍니다.
