GIF 메이커 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

프레임 이미지 2장 이상 업로드

프레임 드롭존에 JPG, PNG, WebP, HEIC, GIF, BMP, SVG 파일을 파일당 최대 20MB까지 드롭하세요(나중에 프레임 추가를 사용해 더 추가할 수 있습니다).

2

프레임 재정렬, 복제, 삭제

프레임 카드를 그립 핸들로 드래그하거나 화살표 버튼을 사용해 순서를 정하고, 핵심 프레임을 복제하거나 원하지 않는 장면을 제거하세요.

3

전체 속도와 프레임별 지연 시간 설정

기본 프레임 지속 시간 슬라이더(50~3000ms)나 1~10 FPS 프리셋을 선택하고, 필요하면 개별 프레임에 사용자 지정 지연 시간(ms)을 입력하세요.

4

반복 동작과 프레임 맞춤 설정

무한 반복, 반복 횟수 설정(2~50회), 한 번 재생 중 하나를 선택한 뒤 Contain 또는 Cover 맞춤과 배경 매트 색상을 선택하세요.

5

출력 크기와 팔레트 품질 조정

480px, 640px, 800px, 원본 프리셋 중 하나를 선택하거나 너비/높이를 16~2000px 범위에서 입력하고, 색상 팔레트 품질을 10%~100%로 설정하세요.

6

애니메이션 GIF 생성 및 다운로드

애니메이션 GIF 생성을 클릭해 실시간 타이밍 재생을 미리 보거나 로컬에서 인코딩해 animated_compressmypic.gif로 저장하세요.

CompressMyPic GIF 메이커을 사용해야 하는 이유

실제 클라이언트 측 GIF89a 인코딩

브라우저 안에서 빠른 색상 양자화기와 LZW GIF 인코더를 사용합니다(필요할 때 지연 로드) — 외부 API 호출이나 서버 업로드가 없습니다.

전체 및 프레임별 지연 시간

밀리초 단위나 FPS 프리셋으로 균일한 프레임 속도를 설정하고, 필요하면 개별 핵심 프레임의 시간을 따로 지정할 수 있습니다.

유연한 반복 및 맞춤 제어

무한 반복, 한 번 재생, 정확한 재생 횟수 중 선택하고 Contain 또는 Cover 프레임 맞춤을 더할 수 있습니다.

큰 파일 크기 경고

인코딩된 GIF가 무거워지면(5~15MB 초과) 자동으로 경고해 채팅 앱에 맞게 크기나 품질을 최적화할 수 있습니다.

GIF 메이커 — 자주 묻는 질문

애니메이션 GIF 생성을 클릭하면 페이지가 로컬 JavaScript GIF89a 인코더와 색상 양자화기를 브라우저 탭 안에서 필요할 때 지연 로드합니다. 각 프레임은 선택한 크기로 오프스크린 캔버스에 렌더링된 뒤 로컬에서 LZW로 압축됩니다. 첫 클릭 시 인코더를 로드하는 데 시간이 걸릴 수 있으니 잠시 기다렸다가, 실패하면 다시 시도해 보세요.
