이미지 Base64 변환기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

이미지를 드롭, 선택, 붙여넣기 하세요

최대 15MB의 JPG, PNG, WebP, SVG, GIF, BMP, ICO, AVIF 파일을 드롭존에 업로드하거나 Ctrl+V로 클립보드 이미지를 붙여 넣으세요.

2

파일 크기와 문자 오버헤드를 검토하세요

상단 요약 카드에서 이미지 썸네일, 원본 바이트 크기, 자연 크기(해당 시), 정확한 출력 문자 수, Base64 오버헤드 비율을 확인하세요.

3

4가지 개발자 출력 탭 사이를 전환하세요

데이터 URL, 원시 Base64, HTML <img>, CSS url()을 클릭해 JSON 페이로드, HTML 인라인 이미지, 스타일시트용으로 인코딩된 문자열 형식을 지정하세요.

4

클립보드에 복사하거나 .txt 파일로 저장하세요

출력 복사 버튼을 클릭하거나 코드 상자 안을 클릭해 모두 선택한 뒤 복사하거나, .TXT로 저장을 클릭해 <파일명>_<탭>.txt를 다운로드하세요.

5

다른 인코딩을 클릭해 파일을 교체하세요

다음 아이콘이나 스프라이트를 인코딩할 준비가 되면 다른 인코딩을 클릭해 출력을 지우고 로컬 객체 메모리를 해제하세요.

이미지 Base64 변환기 — 자주 묻는 질문

Base64는 3개의 이진 바이트(24비트)를 4개의 인쇄 가능한 ASCII 문자(각 6비트)로 표현하고, 끝에 최대 두 개의 패딩 등호를 추가합니다. 그 결과 30KB 이미지는 항상 약 40KB의 Base64 텍스트로 인코딩되며, 요약 표시줄이 이를 자동으로 추적합니다.
