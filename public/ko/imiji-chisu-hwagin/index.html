이미지 치수 검사기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

이미지 한 장 또는 여러 장을 드롭하거나 선택하세요

JPG, PNG, WebP, HEIC, SVG, BMP, GIF, AVIF 파일을 장당 최대 20MB까지 드롭 영역에 업로드하거나 Ctrl+V로 붙여넣으세요.

2

픽셀 치수와 종횡비를 확인하세요

표에서 정확한 너비 × 높이(px), 메가픽셀, 방향(가로, 세로, 정사각형), 단순화/소수 종횡비를 확인하세요.

3

파일 용량, 형식, 알파 채널을 확인하세요

크기/형식 열의 값을 확인해 실제로 감지된 컨테이너 유형, 바이트 수, 투명 알파 픽셀 존재 여부를 파악하세요.

4

예상 300 DPI 인쇄 크기를 확인하세요

인쇄 @300 DPI 열에서 인쇄소에 업로드하기 전에 선명하게 인쇄할 수 있는 최대 실제 인쇄 치수(인치, 너비 × 높이)를 확인하세요.

5

최소 사양 검사를 실행하고 CSV 또는 JSON으로 내보내세요

선택 사항인 최소 너비 검사(px)와 최소 높이 검사(px) 규칙을 입력해 통과 또는 최소 미달로 표시한 뒤, CSV 내보내기 또는 JSON 내보내기를 클릭하세요.

CompressMyPic 이미지 치수 검사기을 사용해야 하는 이유

일괄 치수 검사

수십 개의 자산을 한 번에 검사하세요. 스토어 상품 이미지, 광고 소재, 앱 스크린샷 검증에 이상적입니다.

정확한 종횡비와 일반 종횡비

수학적으로 단순화된 비율을 계산하고 16:9, 4:3, 1:1, 4:5 같은 일반 표준과도 매칭합니다.

사용자 지정 최소/최대 검증기

선택 사항인 최소 또는 최대 너비/높이 규칙을 설정해 사양을 통과하거나 통과하지 못한 이미지를 즉시 강조 표시하세요.

CSV 및 JSON 내보내기

검사한 모든 이미지 치수를 깔끔한 CSV 스프레드시트 또는 JSON 요약으로 다운로드하세요.

이미지 치수 검사기 — 자주 묻는 질문

아니요. 검사기는 브라우저 메모리 안에서만 자연 픽셀 치수와 파일 바이트, 컨테이너 속성을 읽습니다. 압축, 자르기, 덮어쓰기, 외부 서버 업로드는 전혀 이루어지지 않습니다.

함께 사용하면 좋은 도구: 이미지 크기 조정기 · 이미지 메타데이터 뷰어 · 이미지 색상 추출기

관련 무료 이미지 도구

이미지 크기 조정기

픽셀, 비율 또는 소셜 프리셋으로 이미지 크기를 조정하세요.

이미지 메타데이터 뷰어

EXIF 카메라 설정, GPS 좌표, PNG/WebP 데이터를 확인하세요.

이미지 색상 추출기

어떤 이미지에서든 HEX, RGB, HSL, CMYK로 정확한 픽셀 색상을 추출하세요.

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

이미지 DPI 변경기

JPEG/PNG DPI 메타데이터를 무손실로 변경하세요(72/150/300/사용자 지정).

이미지 Base64 변환기

이미지를 Base64 데이터 URL, HTML img, CSS 스니펫으로 인코딩하세요.

Base64 이미지 디코더

Base64 데이터 URL이나 원시 Base64 문자열을 다시 이미지로 디코딩하세요.

이미지 색상 팔레트 추출기

어떤 사진에서든 HEX, RGB, HSL 코드와 함께 주요 색상을 추출하고 내보내세요.
