이미지 DPI 변경기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

먼저 목표 DPI를 선택하거나 조정하세요(언제든 가능)

72 DPI(화면), 96 DPI(Windows), 150 DPI(초안 인쇄), 300 DPI(고품질 인쇄), 600 DPI(보관용) 프리셋을 클릭하거나 1에서 2,400 사이의 사용자 지정 DPI를 입력하세요.

2

이미지 하나 또는 여러 개를 업로드하세요

업로드 영역에 파일당 최대 20MB의 JPG, PNG, WebP, HEIC, GIF, BMP, SVG 파일을 드롭하거나 Ctrl+V로 붙여 넣으세요. 파일은 선택한 DPI로 즉시 처리됩니다.

3

이전 DPI, 확인된 DPI, 처리 방법을 검토하세요

각 카드에는 원본과 확인된 출력 DPI가 표시되고 무손실 JPEG 헤더 업데이트, 무손실 PNG pHYs 업데이트, pHYs DPI 포함 PNG로 변환 중 하나를 확인하는 배지가 표시됩니다.

4

필요하면 대기 중인 파일의 DPI를 동적으로 변경하세요

다른 DPI 프리셋 버튼을 클릭하거나 새 사용자 지정 DPI를 입력하고 DPI 적용을 눌러 대기열의 모든 파일을 자동으로 다시 처리하세요.

5

단일 파일을 다운로드하거나 일괄 ZIP으로 다운로드하세요

개별 결과 카드에서 다운로드(<기본이름>_<dpi>dpi.<확장자> 형식)를 클릭하거나 두 개 이상의 파일이 준비되면 모두 다운로드(ZIP)를 클릭하세요.

CompressMyPic 이미지 DPI 변경기을 사용해야 하는 이유

진정한 무손실 JPEG 및 PNG 헤더 편집

JPEG의 JFIF APP0/EXIF 밀도와 PNG의 pHYs 청크(유효한 CRC32 포함)를 이미지 픽셀을 건드리지 않고 업데이트합니다.

확인된 이전 및 이후 읽기

출력 파일을 자동으로 다시 파싱해 파일에 저장된 정확한 확인 DPI를 보여줍니다.

일괄 DPI 처리

수십 개의 인쇄용 그래픽을 한 번에 업데이트하고 ZIP 아카이브로 내보내세요.

WebP/HEIC 대체 처리

DPI 형식이 아닌 형식도 정확한 pHYs DPI 청크가 포함된 무손실 PNG로 깔끔하게 변환할 수 있습니다.

이미지 DPI 변경기 — 자주 묻는 질문

픽셀을 Canvas에서 디코딩하고 다시 압축하는 대신 이진 메타데이터 세그먼트를 직접 패치합니다. JPEG에서는 JFIF APP0과 EXIF IFD0 해상도 태그를 업데이트하거나 삽입하고, PNG에서는 유효한 CRC32 체크섬이 있는 pHYs 청크를 작성합니다. 모든 시각적 픽셀과 압축 블록은 100% 그대로 유지됩니다.

너비, 높이, 종횡비, 메가픽셀, 인쇄 크기를 확인하세요.

이미지 메타데이터 제거

이미지 압축기

이미지 색상 추출기

어떤 이미지에서든 HEX, RGB, HSL, CMYK로 정확한 픽셀 색상을 추출하세요.

이미지 Base64 변환기

이미지를 Base64 데이터 URL, HTML img, CSS 스니펫으로 인코딩하세요.

Base64 이미지 디코더

Base64 데이터 URL이나 원시 Base64 문자열을 다시 이미지로 디코딩하세요.

이미지 색상 팔레트 추출기

어떤 사진에서든 HEX, RGB, HSL 코드와 함께 주요 색상을 추출하고 내보내세요.
