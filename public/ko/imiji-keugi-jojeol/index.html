이미지 크기 조정기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

이미지 하나 또는 여러 장 업로드

파일당 최대 20MB인 JPG, PNG, WebP, HEIC, GIF, BMP 또는 SVG 파일을 업로드 영역으로 드래그 앤 드롭하거나, 기기에서 파일을 선택하거나, Ctrl+V로 바로 붙여넣으세요.

2

픽셀 또는 비율 모드 선택

정확한 크기를 최대 12,000px까지 입력하는 픽셀 기준(너비 × 높이) 모드와 슬라이더나 빠른 버튼으로 10%에서 200%까지 조정하는 비율 기준(%) 모드 중에서 전환하세요.

3

종횡비 잠금, 맞춤 모드 또는 프리셋 설정

비율에 맞게 조정하려면 종횡비 잠금을 유지하고, 잠금을 해제하면 Contain, Cover 또는 Stretch Exact 중에서 선택할 수 있습니다. 인스타그램 게시물, 유튜브 썸네일, Full HD 같은 프리셋을 클릭할 수도 있습니다.

4

출력 형식과 품질 선택

원본, JPG, PNG 또는 WebP 출력을 선택하고, 출력 품질 슬라이더를 10%에서 100%까지 조정한 뒤, JPG로 내보낼 경우 매트 배경 색상을 선택하세요.

5

설정 적용 후 시각적으로 비교

모두 크기 조정을 클릭하여 일괄 처리한 뒤, 원하는 카드에서 비교 보기를 열어 선명도와 전후 바이트 절감량을 나란히 확인하세요.

6

개별 파일 또는 ZIP 아카이브로 다운로드

크기 조정된 각 이미지를 다운로드 버튼으로 저장하거나, 두 개 이상의 파일을 함께 조정할 때는 모두 다운로드 (ZIP)를 클릭하세요.

CompressMyPic 이미지 크기 조정기을 사용해야 하는 이유

정확한 픽셀·비율 조정

정확한 픽셀 너비와 높이로 크기를 조정하거나, 잠긴 상태에서 종횡비를 자동으로 유지하며 10%에서 200%까지 깨끗하게 조정하세요.

스마트 맞춤 모드 (정확, Contain, Cover)

고정된 프리셋 크기에 이미지를 맞추는 방식을 선택하세요. 정확한 크기로 늘이거나, 자르지 않고 안에 맞추거나, 가운데를 잘라 채울 수 있습니다.

일괄 크기 조정 + ZIP 다운로드

수십 장의 상품 사진이나 블로그 썸네일을 한 번의 일괄 작업으로 처리하고 모두 하나의 ZIP 파일로 다운로드하세요.

100% 로컬 브라우저 처리

사진은 사용자의 기기에서 HTML5 Canvas로 크기가 조정되며 외부 서버에 업로드되지 않습니다.

이미지 크기 조정기 — 자주 묻는 질문

픽셀 기준에서는 정확한 너비와 높이를 픽셀 단위(최대 12,000px)로 입력하거나 소셜 미디어 프리셋을 바로 적용할 수 있습니다. 비율 기준에서는 슬라이더 또는 25%, 50%, 75%, 150%, 200% 빠른 버튼을 이용해 업로드한 모든 이미지를 10%에서 200%까지 비율에 맞게 조정합니다.

함께 사용하면 좋은 도구: 이미지 압축기 · 이미지 변환기 · 이미지 회전·뒤집기

관련 무료 이미지 도구

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

이미지 변환기

브라우저에서 JPG, PNG, WebP, HEIC, BMP, GIF, SVG를 변환하세요.

이미지 회전·뒤집기

90°, 180°, 원하는 각도로 회전하고 좌우·상하로 뒤집으세요.

이미지 치수 검사기

너비, 높이, 종횡비, 메가픽셀, 인쇄 크기를 확인하세요.

대량 이미지 크기 조정기

수십 장의 이미지를 최대 크기, 너비 또는 % 기준으로 조정하고 ZIP으로 받으세요.

이미지 PDF 변환기

JPG, PNG, WebP, HEIC 이미지를 여러 페이지 PDF로 합치세요.

이미지 메타데이터 뷰어

EXIF 카메라 설정, GPS 좌표, PNG/WebP 데이터를 확인하세요.

이미지 메타데이터 제거

EXIF, GPS 위치, 카메라 정보, 주석을 비공개로 제거하세요.
