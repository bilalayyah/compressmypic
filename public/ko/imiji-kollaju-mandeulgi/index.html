무료 온라인 이미지 콜라주 메이커

무료 온라인 이미지 콜라주 메이커로 브라우저 안에서 깔끔한 사진 그리드, 전후 비교 스트립, 소셜 스토리 레이아웃을 만드세요. 콘텐츠 크리에이터, 온라인 판매자, 가족을 위해 만들었으며, 2×2·3×3 그리드와 세로·가로 스트립, 드래그 앤 드롭 셀 교체, 조절 가능한 분할, 둥근 모서리, 사용자 지정 간격, 최대 4000px까지 워터마크 없는 JPG·PNG 내보내기를 지원합니다.

이미지 콜라주 메이커 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

콜라주 스튜디오에 사진 업로드

JPG, PNG, WebP, HEIC, GIF, BMP, SVG 이미지를 파일당 최대 20MB까지 드롭하세요. 5장 이상을 드롭하면 3×3 그리드가, 4장 이하면 2×2 그리드가 자동으로 선택됩니다.

2

그리드 또는 스트립 레이아웃 선택

콜라주 레이아웃 패널에서 2×2 그리드(4셀), 3×3 그리드(9셀), 세로 스트립, 가로 스트립 사이를 자유롭게 전환하세요.

3

콜라주 슬롯 재정렬 또는 채우기

셀을 다른 셀에 드래그해 위치를 바꾸거나, 터치스크린에서는 두 슬롯을 순서대로 탭하고, 왼쪽/오른쪽 화살표를 사용하거나, 사진 추가를 클릭해 빈 슬롯을 채우세요.

4

셀 비율, 간격, 모서리 조정

열 분할, 행 분할, 주요 셀 강조를 조정하거나(셀 균등을 클릭), 셀 간격(0~80px)과 셀 반경(0~60px)을 설정하세요.

5

배경색, 이미지 맞춤, 출력 크기 선택

Cover 또는 Contain 프레이밍을 선택하고, 배경색 견본이나 16진수 코드를 고른 뒤, 200~4000px 범위에서 크기를 입력하거나 1200×1200, 1920×1080, 1080×1920 프리셋을 클릭하세요.

6

완성된 콜라주 내보내기

JPG(10~100% 품질 슬라이더 포함) 또는 PNG(무손실)를 선택하고 콜라주 다운로드를 클릭해 전체 해상도 레이아웃을 로컬에 저장하세요.

CompressMyPic 이미지 콜라주 메이커을 사용해야 하는 이유

4가지 깔끔한 콜라주 레이아웃

균형 잡힌 2×2 정사각형, 3×3 사진 그리드, 세로 모바일 스토리, 넓은 가로 비교 스트립을 만드세요.

드래그 앤 드롭 셀 재정렬

사진 셀을 다른 슬롯에 드래그하면 위치가 즉시 바뀌고, 모바일에서는 두 셀을 탭하세요.

사용자 지정 셀 비율과 간격

열 분할, 행 분할, 주요 셀 강조, 간격, 모서리 둥글기, 배경색을 정밀하게 조정하세요.

고해상도 JPG·PNG 내보내기

HTML5 Canvas에서 워터마크 없이 최대 4000px까지 전체 해상도 콜라주를 렌더링합니다.

이미지 콜라주 메이커 — 자주 묻는 질문

2×2 그리드(4셀), 3×3 그리드(9셀), 세로 스트립(위에서 아래로 이어지는 열), 가로 스트립(나란히 이어지는 행) 사이를 즉시 전환할 수 있습니다. 세로 또는 가로 스트립을 선택하면 실용적인 기본 크기(1080×1920 또는 1920×720)가 자동으로 설정되며, 이후에 자유롭게 조정할 수 있습니다.

GIF 메이커

프레임 지연 시간과 반복 제어로 JPG, PNG, WebP에서 애니메이션 GIF를 만드세요.

이미지 분할기

이미지를 N×M 그리드 타일이나 스트립으로 나누고 ZIP으로 다운로드하세요.

이미지 테두리 생성기

단색 또는 그라데이션 테두리, 프레임, 둥근 모서리, 그림자를 추가하세요.

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

파비콘 생성기

favicon.ico, Apple Touch, Android 아이콘, 매니페스트 파일을 생성하세요.

이미지에 배경 추가

투명 이미지나 프레임 이미지를 단색, 그라데이션, 블러 배경 위에 배치하세요.

이미지 크기 조정기

픽셀, 비율 또는 소셜 프리셋으로 이미지 크기를 조정하세요.

이미지 변환기

브라우저에서 JPG, PNG, WebP, HEIC, BMP, GIF, SVG를 변환하세요.
