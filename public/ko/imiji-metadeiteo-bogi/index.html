이미지 메타데이터·EXIF 뷰어

렌즈 설정을 확인하는 사진가, 헤더를 디버깅하는 개발자, 게시 전에 개인정보를 확인하는 모든 분을 위해 만든 브라우저 이미지 메타데이터 뷰어는 원시 파일 바이트를 로컬에서 검사합니다. 숨겨진 EXIF 태그, GPS 좌표, 타임스탬프, PNG·WebP 청크를 한 픽셀도 업로드하지 않고 확인하세요.

이미지 메타데이터 뷰어 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

검사할 이미지 드롭 또는 선택

파일당 최대 20MB인 JPG, PNG, WebP, HEIC, GIF, BMP 또는 SVG 이미지를 업로드하세요(Ctrl+V로 붙여넣기 가능). 원시 바이너리 헤더가 기기에서 즉시 파싱됩니다.

2

요약·개인정보 위험 배너 확인

감지된 컨테이너 형식, 크기, 파일 크기와 민감한 삽입 메타데이터 태그 유형이 발견되었는지 확인하세요.

3

GPS 위치 경고 확인

GPSIFD 태그가 있으면 경고 상자에 디코딩된 위도와 경도가 정확히 표시되고, 이미지 메타데이터 제거로 바로 이동할 수 있는 원클릭 링크가 제공됩니다.

4

추출된 메타데이터 표 살펴보기

그룹화된 항목(카메라, EXIF, GPS, PNG/WebP 청크, 파일 정보)을 스크롤하면서 호박색 개인정보 태그 라벨이 민감한 필드를 표시하는 것을 확인하세요.

5

JSON 복사·내보내기 또는 태그 제거

JSON 복사를 클릭해 전체 보고서를 복사하거나, JSON 내보내기를 클릭해 .json 파일을 저장하거나, 메타데이터 제거를 클릭해 비공개 태그를 깨끗하게 제거하세요.

CompressMyPic 이미지 메타데이터 뷰어을 사용해야 하는 이유

심층 EXIF·GPS 감지

JPEG, PNG eXIf, WebP EXIF 청크 안에서 TIFF IFD0, ExifIFD, GPSIFD 바이너리 표를 파싱해 숨겨진 위치와 기기 태그를 찾아냅니다.

개인정보 위험 강조

GPS 위도/경도, 카메라 일련번호, 작가 이름, 촬영 타임스탬프 같은 민감한 필드를 자동으로 표시합니다.

PNG·WebP 청크 검사

PNG IHDR 색상 깊이, pHYs 물리적 DPI, tEXt/iTXt/tIME 청크, WebP VP8X 알파/애니메이션 플래그를 읽습니다.

JSON 보고서 내보내기

파싱된 모든 메타데이터 필드를 클립보드에 복사하거나 원클릭으로 깨끗한 JSON 보고서를 다운로드하세요.

이미지 메타데이터 뷰어 — 자주 묻는 질문

컨테이너 형식에 따라 파서는 이미지 헤더에서 TIFF IFD0, ExifIFD, GPSIFD 필드를 로컬로 추출합니다. 카메라 제조사와 모델, 렌즈 사양, 셔터 속도, ISO, 조리개, 타임스탬프, 편집 소프트웨어, 저작권 메모, 십진수 GPS 좌표 같은 세부 정보가 드러납니다.

함께 사용하면 좋은 도구: 이미지 메타데이터 제거 · 이미지 치수 검사기 · 이미지 압축기
