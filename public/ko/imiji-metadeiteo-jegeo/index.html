온라인 이미지 메타데이터 제거

마켓플레이스 판매자, 언론인, 부모, 개인정보를 중시하는 사용자를 위해 설계된 이 도구를 사용하면 사진을 온라인에 공유하기 전에 이미지 메타데이터를 영구적으로 제거할 수 있습니다. 무손실 바이너리 제거 또는 깨끗한 Canvas 다시 인코딩을 이용해 브라우저에서 로컬로 EXIF 카메라 모델, GPS 좌표, 촬영 타임스탬프, 숨겨진 텍스트 청크를 제거하세요.

이미지 메타데이터 제거 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

정리할 사진 드롭

파일당 최대 20MB인 JPG, PNG, WebP 또는 HEIC 이미지 하나 또는 여러 장을 업로드 상자에 업로드하거나 Ctrl+V로 붙여넣으세요.

2

자동 제거·확인 배지 확인

파일은 업로드 즉시 정리되고 자동으로 다시 스캔되어 제거된 메타데이터 태그 수(예: → 0개 남음)가 표시됩니다.

3

설정을 조정하려면 제거 방법 선택

JPEG와 PNG에서 픽셀을 다시 인코딩하지 않으려면 무손실 바이너리 제거(JPG/PNG)를 유지하고, 픽셀을 깨끗하게 평탄화하려면 전체 캔버스 다시 인코딩을 선택하세요.

4

선택 사항: 출력 형식과 품질 설정

원본, JPG, PNG 또는 WebP 출력을 선택하고, WebP/HEIC/캔버스 다시 인코딩용 다시 인코딩 품질(50%~100%)을 조정한 뒤 모두 다시 정리를 클릭하세요.

5

깨끗한 파일 또는 일괄 ZIP 다운로드

확인된 개별 카드에서 깨끗한 파일 다운로드를 클릭하거나, 모두 깨끗하게 다운로드 (ZIP)를 클릭해 clean_images_no_metadata.zip을 저장하세요.

CompressMyPic 이미지 메타데이터 제거을 사용해야 하는 이유

진정한 무손실 JPEG·PNG 제거

픽셀을 디코딩하거나 다시 압축하지 않고 바이너리 수준에서 EXIF, XMP, IPTC, 주석, PNG tEXt/eXIf 청크를 제거합니다.

확인된 깨끗한 출력

모든 출력 파일은 메타데이터 파서로 자동 다시 스캔되어 민감한 EXIF/GPS 태그가 0개 남았는지 확인합니다.

일괄 정리 + ZIP 내보내기

마켓플레이스, 포럼, 리스팅에 게시하기 전에 사진 일괄 작업을 정리하고 함께 ZIP으로 다운로드하세요.

100% 기기 내 개인정보 보호

개인정보 보호 도구는 비공개여야 합니다. GPS 데이터가 포함된 원본 사진은 브라우저를 절대 떠나지 않습니다.

이미지 메타데이터 제거 — 자주 묻는 질문

원본 형식으로 유지되는 JPEG와 PNG 파일에서 바이너리 클리너는 컨테이너 구조를 직접 파싱합니다. 메타데이터 세그먼트(JPEG APP1~APP15/COM과 PNG eXIf/tEXt/iTXt/tIME)를 픽셀 하나도 디코딩하거나 다시 압축하지 않고 제거합니다.
