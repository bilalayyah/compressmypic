이미지 PDF 변환기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

PDF에 포함할 이미지 드롭

파일당 최대 20MB인 JPG, PNG, WebP, HEIC, GIF, BMP 또는 SVG 파일 하나 또는 여러 장을 업로드하세요(Ctrl+V로 붙여넣기 가능). 각 이미지가 한 페이지가 됩니다.

2

페이지 순서 정하기

컨트롤 아래의 페이지 순서 목록을 확인하고 위로, 아래로, 삭제 버튼을 이용해 영수증, 슬라이드, 스캔본을 정확히 배열하세요.

3

페이지 크기와 방향 선택

A4(210 × 297 mm), US Letter(8.5 × 11 in) 또는 이미지 크기에 맞춤을 선택하고, 자동(사진에 맞춤), 세로 또는 가로 방향을 고르세요.

4

여백과 이미지 배치 조정

여백 없음(풀 블리드), 작은 여백 또는 중간 여백을 선택하고 Contain(전체 이미지) 또는 Cover(페이지 채우기)를 고르세요.

5

파일 이름과 PDF 이미지 품질 설정

PDF 파일 이름(.pdf로 끝남)을 원하는 대로 정하고, PDF 이미지 품질을 40%에서 98% 사이로 조정해 선명도와 전체 문서 크기의 균형을 맞추세요.

6

PDF 생성 및 다운로드

PDF 생성 및 다운로드를 클릭하면 파일이 로컬에서 생성됩니다. 초록색 확인 배너에서도 PDF 다시 다운로드를 클릭할 수 있습니다.

CompressMyPic 이미지 PDF 변환기을 사용해야 하는 이유

여러 페이지 순서 지정

PDF를 생성하기 전에 업로드한 이미지를 쉽게 재배열해 영수증, 스캔본, 슬라이드가 원하는 순서대로 나타나게 하세요.

유연한 페이지 크기·자동 방향

자동 세로/가로 방향으로 표준 A4 또는 US Letter로 내보내거나, 각 사진의 정확한 종횡비에 맞추는 이미지 크기에 맞춤을 선택하세요.

조절 가능한 여백·PDF 품질

없음, 작음, 중간 여백을 선택하고 삽입 이미지 품질을 조절해 이메일용으로 가볍게 유지하세요.

서버 업로드 없음

민감한 신분증, 계약서, 스캔 문서가 외부 서버에 닿지 않습니다. PDF 바이너리는 브라우저 메모리 안에서 로컬로 구성됩니다.

이미지 PDF 변환기 — 자주 묻는 질문

네, 문서는 원격 서버나 클라우드 대기열에 업로드되지 않습니다. JavaScript PDF 빌더는 로컬 브라우저 RAM 안에서 모든 페이지를 인코딩하고 완성된 .pdf를 기기에 직접 씁니다.
