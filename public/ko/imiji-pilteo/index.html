무료 온라인 이미지 필터

크리에이터, 블로거, 평범한 스냅사진에 통일된 분위기를 주고 싶은 모든 사람을 위한 무료 온라인 이미지 필터는 실시간 썸네일로 렌더링되는 11가지 엄선된 색감 보정을 제공합니다. 필터 강도 슬라이더로 어떤 필터든 부드럽게 섞고 브라우저에서 바로 전체 해상도 복사본을 저장하세요.

이미지 필터 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

이미지를 드롭하거나 선택하세요

최대 20MB의 JPG, PNG, WebP, HEIC, GIF, BMP, SVG 사진을 업로드하거나 디스크에서 파일을 선택하거나 Ctrl+V로 바로 붙여 넣으세요.

2

실시간 필터 썸네일을 살펴보세요

업로드한 이미지에서 생성된 원본과 11가지 스타일 보정의 실제 미니 미리보기를 보여주는 12개 카드 필터 프리셋 그리드를 확인하세요.

3

프리셋 스타일을 선택하세요

그레이스케일, 세피아, 빈티지, 웜, 쿨, 고대비, 매트 페이드, 드라마틱, 흑백 느와르, 골든 아워, 반전을 클릭해 메인 캔버스에 적용하세요.

4

필터 강도로 강도를 섞으세요

필터 강도 슬라이더를 0%에서 100% 사이로 드래그해 강한 보정을 미묘한 색감으로 부드럽게 만드세요(원본으로 돌아가려면 재설정을 클릭하세요).

5

원본을 유지하거나 비교 모달을 여세요

원본 보기 유지를 길게 눌러 즉시 A/B 확인을 하거나 비교를 클릭해 대화형 분할 슬라이더 검사 모달을 여세요.

6

출력 형식을 선택하고 다운로드하세요

원본, JPG, PNG, WebP를 선택하고 필요하면 품질(10%–100%)을 조정한 뒤 필터 적용 이미지 다운로드 버튼을 클릭하세요.

이미지 필터 — 자주 묻는 질문

원본과 함께 그리드는 그레이스케일, 세피아, 빈티지, 웜, 쿨, 고대비, 매트 페이드, 드라마틱, 흑백 느와르, 골든 아워, 반전의 실시간 썸네일을 생성합니다. 각 썸네일은 스톡 샘플 아이콘이 아니라 업로드한 사진에서 직접 렌더링됩니다.

관련 무료 이미지 도구

브라우저에서 사진 색감의 선명도를 높이거나 깔끔하게 채도를 낮추세요.

이미지 밝기 편집기

실시간 전후 미리보기로 사진을 밝게 또는 어둡게 조정하세요.

이미지 테두리 생성기

단색 또는 그라데이션 테두리, 프레임, 둥근 모서리, 그림자를 추가하세요.

이미지 압축기

이미지 회전·뒤집기

90°, 180°, 원하는 각도로 회전하고 좌우·상하로 뒤집으세요.

이미지 자르기

드래그 핸들과 종횡비, 줌 기능으로 사진을 인터랙티브하게 자르세요.

이미지 워터마크

사용자 지정 텍스트 또는 로고 워터마크를 드래그하거나 타일 형태로 사진에 추가하세요.

이미지 블러 및 픽셀화
