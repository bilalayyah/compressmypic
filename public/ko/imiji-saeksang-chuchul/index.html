이미지 색상 추출기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

이미지 업로드 또는 스크린샷 붙여넣기

최대 20MB인 JPG, PNG, WebP, HEIC, SVG, BMP 또는 GIF 파일을 드롭하거나 Ctrl+V를 눌러 클립보드에서 스크린샷을 바로 붙여넣으세요.

2

실시간 픽셀 검사기 돋보기로 마우스 가져다대기

이미지 캔버스 위에 커서를 움직이면 정확한 (x, y) 픽셀 좌표와 11×11 확대 십자선 그리드가 표시되며 스워치가 실시간으로 업데이트됩니다.

3

픽셀을 클릭해 고정하고 스워치 만들기

캔버스의 원하는 지점을 클릭하면 해당 색상이 픽셀 검사기에 고정되고 선택한 스워치에 추가됩니다(고유 색상 최대 24개).

4

HEX, RGB, HSL 또는 CMYK 값 복사

픽셀 검사기에서 HEX, RGB, HSL 또는 CMYK 옆의 복사 아이콘을 클릭하거나, 저장된 스워치 알약을 클릭하면 코드가 즉시 복사됩니다.

5

팔레트를 CSS 변수로 내보내기

선택한 스워치 카드에서 CSS 내보내기를 클릭하면 스타일시트에 바로 사용할 수 있는 깨끗한 :root 사용자 지정 속성이 포함된 picked-colors.css를 다운로드할 수 있습니다.

CompressMyPic 이미지 색상 추출기을 사용해야 하는 이유

실시간 확대 픽셀 돋보기

확대된 십자선 그리드를 이용해 데스크톱 마우스와 모바일 터치스크린 모두에서 정확한 픽셀을 타겟팅할 수 있습니다.

4가지 색상 형식을 즉시 표시

웹 개발자와 그래픽 디자이너를 위해 HEX, RGB, HSL, CMYK 표현을 동시에 표시합니다.

저장된 스워치 기록·내보내기

이미지의 여러 영역을 클릭해 사용자 지정 스워치 목록을 만들고 CSS 사용자 지정 속성이나 JSON으로 복사하세요.

100% 로컬 Canvas 샘플링

픽셀 값은 HTML5 Canvas getImageData를 이용해 로컬에서 읽히므로 디자인과 스크린샷이 완전히 비공개로 유지됩니다.

이미지 색상 추출기 — 자주 묻는 질문

모든 마우스 가져다대기와 클릭은 포인터 좌표를 이미지의 실제 naturalWidth × naturalHeight와 일치하는 오프스크린 전체 해상도 HTML5 Canvas에 비례해 매핑합니다. 큰 4K 사진이 화면에 맞게 시각적으로 축소되더라도 getImageData는 정확한 기본 픽셀을 읽습니다.

관련 무료 이미지 도구

파비콘 생성기

favicon.ico, Apple Touch, Android 아이콘, 매니페스트 파일을 생성하세요.

이미지 치수 검사기

너비, 높이, 종횡비, 메가픽셀, 인쇄 크기를 확인하세요.

이미지 크기 조정기

픽셀, 비율 또는 소셜 프리셋으로 이미지 크기를 조정하세요.

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

이미지 DPI 변경기

JPEG/PNG DPI 메타데이터를 무손실로 변경하세요(72/150/300/사용자 지정).

이미지 Base64 변환기

이미지를 Base64 데이터 URL, HTML img, CSS 스니펫으로 인코딩하세요.

Base64 이미지 디코더

Base64 데이터 URL이나 원시 Base64 문자열을 다시 이미지로 디코딩하세요.

이미지 색상 팔레트 추출기

어떤 사진에서든 HEX, RGB, HSL 코드와 함께 주요 색상을 추출하고 내보내세요.
