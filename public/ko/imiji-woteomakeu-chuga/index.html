무료 온라인 이미지 워터마크 도구

사진작가, 일러스트레이터, 엣시 판매자, 디지털 에이전시를 위해 설계된 이 비공개 브라우저 도구는 서버 업로드 없이 선명한 텍스트 또는 로고 이미지 워터마크를 추가합니다. 마크를 캔버스 위에서 자유롭게 드래그하고, 9개의 앵커 프리셋에 맞추거나, 기울어진 패턴을 사진 전체에 반복하세요.

이미지 워터마크 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

기본 사진을 업로드하세요

JPG, PNG, WebP, HEIC, GIF, BMP, SVG 이미지를 최대 20MB까지 드롭 영역에 드롭하거나 디스크에서 찾아보거나 Ctrl+V로 붙여넣으세요.

2

텍스트 워터마크 또는 로고 이미지를 선택하세요

텍스트 워터마크를 선택해 사용자 지정 브랜드 텍스트를 입력하고 색상을 고르고 크기(2%~20%)를 조절하거나, 로고 이미지를 선택해 투명 PNG 또는 SVG 로고(너비 5%~60%)를 업로드하세요.

3

불투명도와 회전을 조절하세요

불투명도를 은은한 5%부터 단단한 100%까지 설정하고, 회전을 -180°부터 +180°까지 실시간으로 기울이세요.

4

자유롭게 배치하거나 타일 반복 패턴을 활성화하세요

미리보기 이미지에서 워터마크를 직접 드래그하거나, 9개 지점 앵커 프리셋(좌상단~우하단)을 클릭하거나, 타일 반복 패턴을 켜고 타일 간격(15%~60%)을 조절하세요.

5

출력 형식과 품질을 선택하세요

원본, JPG, PNG, WebP 출력을 선택하고, 손실 형식으로 저장할 때 품질(10%~100%)을 설정하세요.

6

워터마크가 적용된 이미지를 다운로드하세요

워터마크 이미지 다운로드를 클릭해 원본 이미지 해상도 그대로 오버레이를 합성하고 <name>_watermarked로 저장하세요.

CompressMyPic 이미지 워터마크을 사용해야 하는 이유

텍스트 및 로고 워터마크

선명한 사용자 지정 타이포그래피를 사용하거나 투명 PNG/SVG 브랜드 로고를 업로드하세요.

드래그 배치 + 9개 앵커 프리셋

마크를 어느 모서리든, 정중앙이든 배치하거나 캔버스 위에서 자유롭게 드래그하세요.

대각선 타일 보호

타일 워터마크를 활성화해 텍스트나 로고를 간격 조절이 가능한 상태로 사진 전체에 반복하세요.

클라이언트 측 개인정보 보호

원본을 외부 서버로 보내지 않고 로컬에서 증명 사진과 포트폴리오 사진에 워터마크를 적용하세요.

이미지 워터마크 — 자주 묻는 질문

네, 컨트롤 패널 상단에서 텍스트 워터마크와 로고 이미지 사이를 전환하세요. 텍스트 모드는 사용자 지정 문구, 16진수 색상, 크기 조절을 지원하고, 로고 모드는 투명 PNG, SVG 또는 지원되는 모든 로고 파일을 받습니다.

함께 사용하면 좋은 도구: 이미지에 텍스트 추가 · 이미지 테두리 생성기 · 이미지 메타데이터 제거

관련 무료 이미지 도구

이미지에 텍스트 추가

드래그 가능한 스타일 텍스트 오버레이를 폰트, 외곽선, 그림자와 함께 추가하세요.

이미지 테두리 생성기

단색 또는 그라데이션 테두리, 프레임, 둥근 모서리, 그림자를 추가하세요.

이미지 메타데이터 제거

EXIF, GPS 위치, 카메라 정보, 주석을 비공개로 제거하세요.

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

이미지 회전·뒤집기

90°, 180°, 원하는 각도로 회전하고 좌우·상하로 뒤집으세요.

이미지 자르기

드래그 핸들과 종횡비, 줌 기능으로 사진을 인터랙티브하게 자르세요.

이미지 블러 및 픽셀화

사진 전체 또는 브러시로 민감한 부분만 블러/픽셀화하세요.

이미지 모서리 둥글게

균일 또는 모서리별로 둥글게 처리하고 투명 PNG로 내보내세요.
