파비콘 생성기 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

로고 또는 아이콘 그래픽 업로드

최대 20MB인 PNG, SVG, JPG, WebP 또는 HEIC 이미지를 드롭하세요(정사각형 PNG 또는 SVG가 가장 좋습니다). 또는 Ctrl+V로 클립보드에서 붙여넣으세요.

2

배경 채우기 선택

깨끗한 잘라내기 아이콘을 원하면 투명 체크박스를 켜진 상태로 유지하고, 단색 16진수 배경을 원하면 체크를 해제해 색상을 선택하세요.

3

여백과 모서리 반경 조정

여백 슬라이더를 0%에서 25% 사이로 조정해 여유 공간을 주고, 모서리 반경을 0%에서 50%까지 드래그해 둥근 사각형이나 원형 배지를 만드세요.

4

브라우저 탭 미리보기 확인

밝은 내 웹사이트 탭과 다크 모드 탭 목업 안에 렌더링된 실시간 16×16 크기 미리보기를 확인하세요.

5

개별 파일 또는 전체 ZIP 다운로드

생성된 카드에서 개별 아이콘 크기를 저장하거나, 모두 다운로드 (ZIP)를 클릭해 favicon_package_compressmypic.zip을 다운로드하세요.

6

HTML head 스니펫 복사

어두운 HTML <head> 스니펫 패널에서 HTML 복사를 클릭하고 <link> 태그를 웹사이트 템플릿에 바로 붙여넣으세요.

CompressMyPic 파비콘 생성기을 사용해야 하는 이유

진짜 여러 크기 favicon.ico

이름만 바꾼 PNG가 아니라 선명한 16×16, 32×32, 48×48 프레임을 삽입한 진짜 바이너리 .ico 파일을 만듭니다.

완전한 웹·모바일 아이콘 세트

16×16, 32×32, 48×48, 180×180(Apple Touch), 192×192, 512×512(Android/PWA) 아이콘과 site.webmanifest를 생성합니다.

실시간 브라우저 탭 미리보기

다운로드 전에 실제 브라우저 탭 크기에서 밝은 배경과 어두운 배경 모두에서 아이콘이 어떻게 보이는지 미리보세요.

바로 붙여넣을 수 있는 HTML 스니펫

깨끗한 HTML <link> 태그를 원클릭으로 <head>에 바로 복사하세요.

파비콘 생성기 — 자주 묻는 질문

ZIP을 다운로드하면 여러 프레임 favicon.ico(16×16, 32×32, 48×48), 개별 favicon-16x16.png, favicon-32x32.png, favicon-48x48.png 파일, apple-touch-icon.png(180×180), android-chrome-192x192.png, android-chrome-512x512.png이 묶여 있습니다. 업로드 준비가 된 site.webmanifest JSON 파일도 생성됩니다.

함께 사용하면 좋은 도구: 이미지 크기 조정기 · 이미지 변환기 · 이미지 색상 추출기

관련 무료 이미지 도구

이미지 크기 조정기

픽셀, 비율 또는 소셜 프리셋으로 이미지 크기를 조정하세요.

이미지 변환기

브라우저에서 JPG, PNG, WebP, HEIC, BMP, GIF, SVG를 변환하세요.

이미지 색상 추출기

어떤 이미지에서든 HEX, RGB, HSL, CMYK로 정확한 픽셀 색상을 추출하세요.

이미지 압축기

JPG, PNG, WebP, HEIC 이미지를 화질 저하 없이 압축하세요.

이미지에 배경 추가

투명 이미지나 프레임 이미지를 단색, 그라데이션, 블러 배경 위에 배치하세요.

이미지 분할기

이미지를 N×M 그리드 타일이나 스트립으로 나누고 ZIP으로 다운로드하세요.

GIF 메이커

프레임 지연 시간과 반복 제어로 JPG, PNG, WebP에서 애니메이션 GIF를 만드세요.

이미지 콜라주 메이커

드래그 교체와 내보내기로 사진을 2×2, 3×3 그리드 또는 스트립으로 배치하세요.
