SVG이미지당 최대 25MB붙여넣기(Ctrl+V) 지원

인라인 SVG 그래픽을 HTML5 Canvas로 로컬에서 래스터화하며 투명 배경을 유지합니다. 제한: 외부 <image> URL, 외부 CSS 스타일시트/웹폰트, SVG 안에 참조된 스크립트는 독립 Canvas 내보내기에서 렌더링되지 않을 수 있습니다.

SVG를 PNG로 사용 방법

브라우저에서 바로 작업을 완료하는 간단한 단계를 따라 하세요.

1

파일당 최대 25 MB의 SVG 파일을 놓으세요

인라인 도형, 패스, 그라데이션, 스타일이 있는 .svg 벡터 파일 한 개 또는 여러 개를 업로드하세요.

2

래스터 내보내기 배율 선택 (1배–4배)

SVG 고유 크기에는 1배를, 선명한 Retina와 고해상도 PNG 내보내기에는 2배–4배를 고르세요.

3

배율을 바꾼 뒤 모두 다시 변환을 클릭하세요

배율 변경은 다시 변환할 때 적용되므로 미리보기와 다운로드가 선택한 크기와 일치합니다.

4

외부 에셋에 대한 안내를 확인하세요

SVG 안의 외부 이미지, 스타일시트, 웹폰트는 브라우저 캔버스 보안 때문에 차단되어 PNG에 나타나지 않습니다.

5

래스터화된 PNG를 비교하세요

아무 카드에서나 비교를 클릭하면 분할 뷰어에서 선명한 모서리와 투명도를 확인할 수 있습니다.

6

PNG 파일을 다운로드하거나 모두 다운로드(ZIP)

개별 .png 파일을 저장하거나 배치를 한 번의 클릭으로 compressmypic_svg_to_png.zip에 묶어 다운로드하세요.

CompressMyPic SVG를 PNG로을 사용해야 하는 이유

1배, 2배, 3배, 4배 고해상도 내보내기

작은 24px 아이콘이나 100px 로고를 래스터화 전에 4배 해상도까지 깨끗하게 확대하세요.

투명 배경 유지

슬라이드, 웹 헤더, 디자인 덱에 바로 쓸 수 있는 선명한 알파 채널 PNG를 내보냅니다.

솔직한 독립 캔버스 범위

인라인 SVG 벡터 도형과 스타일은 깨끗하게 렌더링되지만, SVG 안의 외부 이미지 URL이나 외부 웹폰트는 브라우저 Canvas 샌드박스에 의해 차단될 수 있음을 명확히 안내합니다.

일괄 SVG 래스터화

아이콘 팩 전체를 한 번에 PNG로 변환하고 ZIP으로 다운로드하세요.

SVG를 PNG로 — 자주 묻는 질문

보안을 위해 브라우저는 HTML5 Canvas에 렌더링되는 SVG 파일을 샌드박스로 격리하고 외부 <image> URL 가져오기를 차단하므로, 웹에서 연결된 사진은 래스터화 중에 로드될 수 없습니다. 이미지를 SVG 파일 안에 직접 임베드하거나 인라인 벡터 도형으로 바꾸면 PNG가 온전히 렌더링됩니다.
