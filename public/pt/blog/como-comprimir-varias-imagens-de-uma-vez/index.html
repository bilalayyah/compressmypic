Como comprimir várias imagens de uma vez

Passo a passo: comprima dezenas de imagens de uma vez com predefinições, uma barra de progresso e um só download ZIP. Funciona para blogs, lojas e álbuns.

Uma imagem leva um minuto para comprimir. Cinquenta imagens levam uma tarde, a menos que você as processe em lote.

A compressão em lote processa uma pasta inteira de uma vez. Você escolhe uma predefinição, acompanha a barra de progresso e baixa tudo junto como um ZIP.

Este guia passa por todo o fluxo, desde reunir os arquivos até conferir o ZIP finalizado.

O que você precisa antes de começar

Reúna as imagens originais numa pasta. Trabalhar a partir dos originais dá a melhor qualidade; trabalhar a partir de cópias comprimidas adiciona dano.

Decida para que servem as imagens. As miniaturas precisam da predefinição Arquivo menor, enquanto as fotos de portfólio precisam de Alta qualidade.

Confira quantas imagens você tem. Um lote de vinte roda rápido em qualquer lugar, enquanto um lote de duzentas pode precisar ser dividido no celular.

Confira se você tem espaço livre suficiente. O download do ZIP precisa de espaço no seu aparelho, mais ou menos o tamanho do lote comprimido.

Passo 1: abra o compressor em lote

Abra o Compressor de imagens em lote no navegador. Não precisa de conta nem de instalação.

A ferramenta roda toda no seu aparelho. Suas fotos são processadas localmente e nunca enviadas para um servidor.

Se estiver num computador, a página funciona melhor com arrastar e soltar. No celular, o botão de envio abre sua galeria.

Salve a página nos favoritos se você comprime lotes com frequência. É o caminho mais rápido para uma biblioteca de fotos menor.

Passo 2: adicione suas imagens

Arraste suas imagens para a área de envio ou toque para procurar e selecioná-las. Você pode adicionar uma pasta inteira de uma vez na maioria dos navegadores.

Arquivos JPG, PNG, WebP e HEIC são aceitos. Lotes mistos funcionam bem, então fotos e capturas de tela podem dividir um lote.

Confira a fila depois de adicionar os arquivos. Cada imagem deve aparecer com nome e tamanho, então um arquivo faltando é fácil de perceber.

Adicione mais arquivos depois se esquecer de alguns. A fila aceita novas imagens mesmo depois que o primeiro lote terminar.

Passo 3: escolha uma predefinição

Escolha Equilibrada para a maioria dos trabalhos. Ela começa com 70% de qualidade e dá um bom meio-termo entre tamanho e aparência.

Escolha Arquivo menor para miniaturas, avatares e imagens que serão mostradas pequenas. A compressão extra é invisível em tamanhos pequenos.

Escolha Alta qualidade para portfólios, galerias e imagens de destaque. Os arquivos ficam maiores, mas os detalhes valem a pena.

A predefinição define o ponto de partida. Cada imagem continua otimizada individualmente, então um retrato simples e uma paisagem detalhada recebem tratamentos diferentes.

Passo 4: rode o lote

Comece o lote e acompanhe a barra de progresso. Ela mostra quais arquivos terminaram e quanto tamanho total já foi economizado.

O processamento acontece uma imagem de cada vez. Isso mantém o navegador responsivo em vez de travar enquanto trabalha.

Não feche a aba enquanto o lote roda. O trabalho acontece no seu navegador, então fechar a página interrompe a compressão.

Os lotes grandes levam alguns minutos. Use o tempo para preparar a pasta de destino ou escrever a postagem do blog a que as imagens pertencem.

Passo 5: veja a prévia dos resultados individuais

Quando o lote terminar, veja a prévia dos resultados antes de baixar. Clique em qualquer imagem para vê-la em tamanho cheio.

Confira primeiro as imagens mais difíceis. Uma foto detalhada ou uma captura de tela com texto pequeno vai mostrar problemas antes de um retrato simples.

Compare alguns resultados com os originais. Pequenas diferenças são normais; texto ilegível ou pele manchada, não.

Se uma imagem parecer ruim, comprima só ela de novo com outras configurações. Você não precisa rodar o lote inteiro de novo por um único arquivo.

Passo 6: baixe o ZIP

Clique em Baixar tudo para receber um só arquivo ZIP com todas as imagens comprimidas dentro. O ZIP mantém o conjunto organizado num pacote só.

Extraia o ZIP para uma pasta própria. Isso mantém o conjunto comprimido separado dos originais e fácil de encontrar depois.

Confira os arquivos extraídos. Abra alguns em tamanho cheio e confirme que estão certos antes de enviá-los para qualquer lugar.

Renomeie os arquivos com clareza se os nomes automáticos não forem descritivos o bastante. Um nome claro evita confusão quando o conjunto é grande.

Corrigindo problemas num lote

Se uma imagem ficou maior, deixe-a como ela está. A ferramenta avisa quando a recodificação deixa um arquivo maior, e o original é o arquivo melhor.

Se uma imagem parecer borrada, a fonte pode ter sido pequena demais. Comprima de novo aquele arquivo a partir de um original maior com a predefinição Alta qualidade.

Se as cores parecerem erradas, confira a transparência. Converter um PNG transparente para JPG preenche o fundo, geralmente com branco.

Se o lote estiver lento, divida em grupos menores. Os celulares se beneficiam especialmente de lotes de vinte em vez de duzentos.

Fluxo de trabalho: um conjunto de miniaturas de blog

Junte as miniaturas de um conjunto de postagens e envie como um só lote. Escolha a predefinição Equilibrada para resultados consistentes.

Veja a prévia de três ou quatro resultados, não só do primeiro. Uma única miniatura ruim pode se esconder entre as boas.

Baixe o ZIP, extraia e envie os arquivos para o seu blog. Guarde os originais caso uma postagem precise de uma imagem maior depois.

Confira as postagens publicadas no celular e no computador. As miniaturas devem carregar rápido e ficar nítidas nos dois.

Fluxo de trabalho: um catálogo de produtos

Reúna as fotos de produto de um lançamento e envie como um só lote. Use a predefinição Alta qualidade para os produtos ficarem no seu melhor.

Veja a prévia dos produtos mais detalhados primeiro. A textura do tecido e os rótulos impressos são as primeiras coisas a suavizar.

Baixe o ZIP e envie as imagens para a loja. Confira algumas páginas de produto para confirmar que as imagens aparecem corretamente.

Guarde os originais num drive compartilhado. Quando a próxima estação lançar, a equipe pode comprimir de novo a partir dos originais.

Fluxo de trabalho: um álbum de fotos compartilhado

Junte as fotos do álbum e envie como um só lote. A predefinição Equilibrada mantém o álbum leve sem prejudicar as memórias.

Veja a prévia de algumas favoritas antes de baixar. Uma foto querida merece uma conferência cuidadosa, mesmo num lote de cem.

Baixe o ZIP e compartilhe com a família ou os amigos. Um álbum comprimido baixa rápido, mesmo numa conexão lenta.

Guarde os originais em segurança. As cópias compartilhadas são descartáveis, e os originais são o que você vai querer daqui a dez anos.

Selecionando uma pasta inteira de uma vez

A maioria dos navegadores de computador permite selecionar uma pasta inteira, não só arquivos individuais. É o jeito mais rápido de começar um lote.

Procure a opção de pasta no seletor de arquivos. Ela aparece como uma escolha separada no Chrome, no Edge e no Firefox no computador.

Confira a fila depois de selecionar uma pasta. As subpastas podem ser incluídas ou ignoradas dependendo do navegador, então verifique se a contagem confere.

Remova os arquivos que não pertencem. Uma pasta costuma ter uma captura perdida ou um arquivo antigo que não deveria ser comprimido.

Nos celulares, a seleção de pastas é limitada. Escolha os arquivos em grupos na galeria e mantenha cada grupo em torno de vinte imagens.

Lendo a barra de progresso

A barra de progresso mostra o quanto o lote avançou e quanto tamanho já foi economizado. Ela atualiza conforme cada imagem termina.

Um ritmo constante significa que o lote está saudável. Se a barra travar num arquivo, esse arquivo pode ser muito grande ou complexo.

Não feche a aba enquanto a barra estiver andando. O trabalho acontece no seu navegador, e fechar a página interrompe o lote.

Se a aba do navegador adormecer em segundo plano, o lote pode pausar. Mantenha a aba visível até o lote terminar.

Para lotes muito grandes, a barra é sua melhor amiga. Ela transforma uma espera longa em progresso visível, arquivo por arquivo.

Entendendo os resultados por arquivo

Cada arquivo finalizado mostra o próprio resultado: tamanho original, tamanho comprimido e porcentagem economizada. Os números variam muito ao longo de um lote.

Os retratos simples costumam economizar 90% ou mais. As paisagens detalhadas podem economizar só 70%, porque têm mais dados que valem manter.

Um arquivo que economizou quase nada provavelmente já estava comprimido. A ferramenta fez o melhor que pôde, mas havia pouco para remover.

Um arquivo que cresceu é um aviso, não uma falha. Guarde o original desse arquivo e siga em frente com o resto do lote.

Ordene os resultados pela economia quando puder. Os menores economizadores são os arquivos com maior chance de precisar de atenção individual.

Tentando de novo arquivos com falha ou ruins

Alguns arquivos falham ou saem ruins num lote. Isso é normal, e o conserto é lidar com eles individualmente.

Tire o arquivo problemático do conjunto. Comprima só ele com a predefinição Alta qualidade e veja a prévia do resultado com cuidado.

Se o formato for o problema, troque-o. Uma foto em PNG comprimida de novo como JPG muitas vezes passa de fracasso a resultado limpo.

Se a fonte for o problema, encontre um original melhor. Um arquivo que já estava comprimido não pode ser salvo por nenhuma configuração.

Substitua o arquivo ruim no conjunto final. O lote fica intacto, e só o arquivo problemático muda.

Enviando os resultados do lote

Depois de extrair, envie os arquivos ao destino em grupos. Enviar cinquenta arquivos de uma vez pode sobrecarregar algumas plataformas.

Confira com cuidado os primeiros envios. Confirme que aparecem corretamente antes de enviar o resto do conjunto.

Combine os nomes dos arquivos com os destinos deles. Uma imagem de produto enviada para a página errada é um erro constrangedor e evitável.

Guarde o ZIP até os envios serem confirmados. Se um envio falhar, o ZIP tem o arquivo pronto sem precisar rodar de novo.

Apague as cópias comprimidas locais só depois que os envios forem verificados. Os originais ficam seguros de qualquer jeito.

Quanto tempo leva um lote?

Um lote de vinte fotos de celular leva cerca de um minuto num computador moderno. O mesmo lote pode levar três minutos num celular.

Os arquivos maiores levam mais tempo. Um lote de fotos de câmera de 10 MB precisa de mais tempo de processamento por arquivo que um lote de fotos de celular de 2 MB.

A predefinição também afeta a velocidade. Alta qualidade executa mais passos de otimização que Arquivo menor, então leva um pouco mais de tempo.

Planeje a espera. Comece o lote e use o tempo para escrever a postagem, preparar as descrições dos produtos ou organizar a pasta de destino.

Para lotes muito grandes, rode quando não precisar do computador para outro trabalho pesado. A compressão usa o processador, e fazer várias coisas ao mesmo tempo deixa tudo mais lento.

Compartilhando o ZIP com outras pessoas

O arquivo ZIP é o jeito mais fácil de compartilhar um conjunto comprimido. Um arquivo só carrega todas as imagens, prontas para extrair e usar.

Envie o ZIP por e-mail quando ele for pequeno o bastante. A maioria dos sistemas de e-mail aceita anexos de até 20 MB ou 25 MB.

Para ZIPs maiores, use um link de compartilhamento de arquivos. Envie o ZIP para um drive e compartilhe o link em vez do arquivo em si.

Diga ao destinatário o que há dentro. Uma anotação curta sobre a predefinição e a função evita confusão do lado dele.

Guarde uma cópia do ZIP para você. Se o destinatário perdê-lo, você pode reenviar sem rodar o lote de novo.

Limpando depois de um lote

Depois que um lote for enviado e verificado, limpe os arquivos de trabalho. Um espaço organizado evita misturas no próximo lote.

Apague as cópias comprimidas extraídas depois que estiverem enviadas com segurança. O ZIP fica como backup do conjunto.

Guarde os originais para sempre. Eles vivem na própria pasta, separados de cada cópia comprimida.

Arquive o ZIP junto com o projeto a que ele pertence. Um ZIP guardado com a postagem do blog ou o lançamento do produto é encontrável depois.

Um espaço limpo é um espaço rápido. Cinco minutos de limpeza agora economizam uma hora de busca depois.

Uma conferência final antes de enviar

Abra três imagens aleatórias do lote finalizado em tamanho cheio. Se parecerem limpas, o lote está bom; se uma parecer suave, confira o resto antes de enviar.

Confirme que o ZIP extraiu corretamente e que a contagem de arquivos é igual à do lote original. Um arquivo faltando agora é mais fácil de corrigir que uma imagem faltando numa página ao vivo.

Perguntas frequentes

Como comprimo uma pasta inteira de imagens de uma vez?

Abra o compressor em lote e arraste a pasta para a área de envio, ou selecione todos os arquivos de uma vez. Escolha uma predefinição, rode o lote e baixe os resultados como um só ZIP. Cada imagem é comprimida individualmente para a melhor qualidade.

Qual predefinição devo usar para miniaturas de blog?

Equilibrada funciona bem para a maioria das miniaturas, começando com 70% de qualidade. Use Arquivo menor se as miniaturas forem mostradas bem pequenas, e Alta qualidade se forem imagens de destaque grandes. Veja a prévia de alguns resultados antes de baixar o lote inteiro.

Posso comprimir imagens no celular em lote?

Sim, a ferramenta funciona no navegador do celular. Mantenha os lotes menores no celular, em torno de vinte imagens de cada vez, pois os celulares têm menos memória. Baixe o ZIP para o aplicativo Arquivos e extraia lá.

O que acontece se meu celular ficar sem memória durante um lote?

O lote pode ficar lento ou parar. Divida as imagens restantes num grupo menor e rode separadamente. Os navegadores de computador lidam com lotes maiores com mais folga, então use um computador para trabalhos bem grandes.

Preciso redimensionar as imagens antes da compressão em lote?

Não, o compressor em lote mantém as dimensões originais em pixels e só reduz o tamanho do arquivo. Se você também precisar de dimensões menores, redimensione as imagens primeiro com o redimensionador de imagens e depois comprima os arquivos redimensionados em lote.

Como sei se o lote realmente economizou espaço?

O resumo do lote informa o tamanho total antes e depois da compressão, mais a porcentagem economizada. Um lote típico de fotos cai de 80 a 90%. Você também pode comparar o tamanho do ZIP com o tamanho da pasta original.
