Decodificar Base64 e baixar a imagem

Converta Base64 para imagem em quatro passos: cole, visualize, escolha Original, PNG, JPG ou WebP e baixe. Funciona com strings seguras para URL.

Uma string Base64 está na sua área de transferência, no seu e-mail ou em uma resposta de API, e você precisa da imagem que ela contém. A conversão leva cerca de um minuto depois que você conhece os passos.

Este guia mostra como converter Base64 para uma imagem em quatro passos: cole a string, revise a prévia, escolha o formato de download e salve o arquivo.

Não há software para instalar, conta para criar nem nada enviado para lugar nenhum. A string é decodificada localmente no seu navegador do começo ao fim.

O que você precisa antes de começar

Você precisa da própria string Base64, copiada por completo. Uma string truncada não pode ser decodificada, então garanta que a cópia inclua o início e o fim.

Saiba para que a imagem serve, porque isso decide o formato de download. Original mantém o arquivo exato, PNG mantém a transparência, JPG encolhe fotografias e WebP é a escolha moderna e compacta.

Um navegador é todo o software de que você precisa. A ferramenta roda em Chrome, Safari, Firefox e Edge, no computador e no celular, sem extensão.

Se a string veio envolvida em HTML ou CSS, você pode colar o trecho inteiro. O decodificador tolera aspas e invólucros url() ao redor da string.

Passo 1: cole a string Base64

Abra o decodificador de Base64 para imagem e cole a string na área de entrada. A decodificação começa automaticamente, sem botão para clicar.

A ferramenta aceita strings com ou sem o prefixo data:image. Uma Data URL completa de uma página web e uma string bruta de uma carga JSON funcionam.

Strings seguras para URL também funcionam. Se a string usar traços e sublinhados em vez de mais e barra, o decodificador reconhece a variante e a decodifica corretamente.

Quebras de linha e espaços extras são ignorados. Uma string que foi quebrada por um cliente de e-mail ou colada com espaços em branco ao redor ainda decodifica sem nenhuma limpeza.

Passo 2: revise a prévia e as métricas

A imagem decodificada aparece sobre um fundo xadrez, com suas dimensões e tamanho de arquivo mostrados ao lado. Confira se a imagem é a que você esperava.

Olhe o xadrez com atenção. Quadrados cinza e brancos aparecendo através da imagem significam transparência, e isso decide se JPG é seguro de usar.

Confira as dimensões. Um ícone pequeno decodificado de uma string é uma imagem pequena, e nenhum formato de download vai deixá-lo maior ou mais nítido do que já é.

Confira o tamanho do arquivo binário. Ele deve ser cerca de três quartos do tamanho do texto que você colou, porque a decodificação remove o custo extra de 33 por cento da codificação.

Passo 3: escolha o formato de download

Escolha Original quando quiser o arquivo exatamente como foi codificado. Essa é a escolha mais segura, principalmente para GIFs animados e SVGs vetoriais, que perdem suas propriedades especiais quando convertidos.

Escolha PNG quando a imagem tiver transparência ou bordas nítidas. PNG preserva os pixels com exatidão e mantém o canal alfa, então logotipos e ícones sobrevivem à ida e volta.

Escolha JPG quando a imagem for uma fotografia e você quiser o menor arquivo. JPG descarta a transparência, então só use-o quando a prévia em xadrez não mostrar áreas transparentes.

Escolha WebP quando o destino for um site moderno. Ele é menor que PNG para a maioria das imagens e aceita transparência, o que o torna um bom padrão para uso na web.

Passo 4: baixe o arquivo de imagem

Clique no botão de download. O arquivo é salvo como decoded_image com a extensão correspondente ao formato escolhido, como decoded_image.png ou decoded_image.jpg.

Renomeie o arquivo para algo significativo na hora. Uma pasta cheia de arquivos chamados decoded_image é confusa, enquanto um nome como logo-empresa.png diz o que é meses depois.

Abra o arquivo baixado e confirme se parece certo. A prévia na ferramenta é confiável, mas uma verificação final do arquivo real custa segundos e detecta qualquer mal-entendido.

Se você precisar codificar a imagem de novo depois, o codificador de imagem para Base64 pega o arquivo baixado e produz uma string nova a partir dele.

Como decodificar uma string sem o prefixo

Muitas strings chegam sem o prefixo data:image, principalmente de APIs e bancos de dados. O decodificador lê o cabeçalho da imagem para identificar o formato, então o prefixo ausente não é um problema.

Cole a string bruta como ela é. A ferramenta detecta se os bytes descrevem um arquivo PNG, JPG, GIF, WebP, SVG, BMP ou ICO e mostra o formato detectado ao lado da prévia.

Se o formato for detectado errado, o próprio cabeçalho do arquivo é incomum. Baixe como Original nesse caso e inspecione o arquivo com um visualizador de imagens antes de convertê-lo.

Quando você compartilhar a string adiante, considere adicionar o prefixo você mesmo. Uma Data URL é autodescritiva, e a próxima pessoa que a receber vai saber o formato sem adivinhar.

Como decodificar uma string segura para URL

Base64 seguro para URL substitui mais por traço e barra por sublinhado, para que a string possa ficar dentro de um endereço web sem precisar de escape. Ele parece quase idêntico ao Base64 padrão.

O decodificador aceita os dois alfabetos sem nenhuma configuração para mudar. Cole a string e ela decodifica, seja qual for a variante usada.

Se uma string falhar ao decodificar, confira se há uma mistura dos dois alfabetos. Uma string parcialmente convertida, com alguns sinais de mais e alguns traços, está danificada e precisa de uma cópia nova da origem.

O preenchimento também pode faltar em strings seguras para URL, porque alguns sistemas removem os sinais de igual no final. O decodificador tolera o preenchimento ausente na maioria dos casos, mas uma string completa é sempre mais segura.

Como decodificar uma string envolvida em HTML ou CSS

Strings costumam ser copiadas com o código ao redor anexado, como uma tag de imagem com uma Data URL como fonte ou uma função CSS url() envolvendo o valor.

Você pode colar o trecho inteiro. O decodificador tolera aspas HTML e invólucros CSS url() ao redor da string e extrai o conteúdo Base64 de dentro deles.

Se a colagem falhar, retire o invólucro você mesmo. Copie só a parte entre a vírgula depois de base64 e a aspa de fechamento e cole essa string limpa.

Para uma tag de imagem HTML, a string fica dentro do atributo src depois de data:image/png;base64,. Para CSS, ela fica dentro dos parênteses de url(), geralmente envolvida em aspas.

Como converter uma string antiga de BMP ou ICO para WebP

Strings antigas de favicon e bitmap decodificam em arquivos BMP ou ICO, que são volumosos e mal aceitos na web moderna. Convertê-los para WebP resolve os dois problemas de uma vez.

Cole a string, espere a prévia e escolha WebP como formato de download. A ferramenta converte a imagem decodificada em um arquivo moderno e compacto.

Confira a transparência primeiro. Um favicon ICO geralmente tem áreas transparentes, e WebP as preserva, então o ícone convertido parece igual ao original.

Para um favicon especificamente, considere baixar como PNG. Navegadores aceitam favicons PNG amplamente, e o arquivo é mais simples de referenciar no seu HTML.

Como decodificar uma string SVG em um arquivo PNG

Uma string Base64 de SVG decodifica em código vetorial, que é nítido em qualquer tamanho, mas não é aceito em todos os lugares. Algumas plataformas querem uma imagem rasterizada, e PNG é a escolha usual.

Cole a string, confirme se a prévia mostra o gráfico vetorial corretamente e escolha PNG como formato de download. A ferramenta renderiza o SVG em um PNG nas suas dimensões intrínsecas.

O PNG resultante é uma imagem de tamanho fixo, então não vai ampliar como o SVG original. Se o destino precisar de uma imagem grande, renderize em um tamanho maior antes de baixar ou mantenha o SVG.

Se a string for uma Data URL de SVG simples sem o marcador base64, ela vai falhar com um erro de codificação. Essa string não é Base64, então salve o código SVG diretamente como arquivo.

Solução de problemas: strings corrompidas

Uma string que falha ao decodificar geralmente está truncada, alterada ou nunca foi uma imagem. A ferramenta informa um erro claro em vez de produzir um arquivo quebrado.

Confira primeiro o início e o fim da string. O truncamento geralmente corta a parte final, então uma string que termina no meio de uma palavra ou sem o preenchimento é sinal de uma cópia incompleta.

Procure caracteres que não pertencem ao Base64. Colchetes angulares, aspas dentro da string ou uma URL com parâmetros extras indicam que a cópia pegou texto ao redor.

Quando a origem é uma resposta de API, confira se a própria resposta foi cortada. Uma carga JSON truncada produz uma string truncada, e só uma nova requisição pode repará-la.

Solução de problemas: o erro de codificação de SVG

O erro de codificação de SVG aparece quando a string colada é uma Data URL de SVG simples, e não uma Base64. Ela contém tags SVG legíveis em vez de caracteres codificados.

Reconheça-o olhando para a string. Se você consegue ler palavras como svg, path ou rect dentro dela, a string é código SVG codificado por URL, não Base64.

Para obter o arquivo, copie o código SVG para fora da Data URL, decodifique qualquer escape de porcentagem e salve o resultado como um arquivo .svg em um editor de texto.

Não tente forçá-la pelo decodificador. A ferramenta espera caracteres Base64, e nenhuma configuração vai fazê-la aceitar marcação SVG simples como uma string codificada.

Como limpar a entrada para a próxima string

Strings longas são difíceis de apagar à mão, então a ferramenta oferece um botão de limpar que esvazia a entrada com um clique. Use-o entre decodificações para começar do zero.

Limpe antes de colar a próxima string, não depois. Colar sobre uma string longa pode deixar fragmentos da antiga para trás, o que corrompe a nova decodificação.

Baixe a imagem atual antes de limpar. Limpar remove a string e a prévia juntas, e a imagem decodificada existe só como o arquivo baixado depois disso.

Trabalhar com um lote de strings é rápido assim: cole, baixe, limpe e cole a próxima, sem rolagem nem seleção manual no meio.

Como codificar a imagem baixada de novo

Às vezes, a imagem decodificada precisa voltar à forma de texto, por exemplo depois de converter um BMP antigo para um WebP moderno. O codificador cuida desse passo.

Abra o codificador de imagem para Base64, envie o arquivo baixado e copie a string nova no formato de saída de que você precisa.

A string nova é mais curta que a original quando a conversão encolheu o arquivo. Um BMP convertido para WebP antes de codificar de novo produz uma string bem mais curta que a original.

Guarde as duas strings até ter certeza de que a nova funciona. A string original é a única cópia do arquivo original, e apagá-la antes de testar é um risco desnecessário.

Como decodificar imagens de mensagens de chat e documentos

Aplicativos de chat e ferramentas de colaboração às vezes expõem imagens como strings Base64 nos dados das mensagens, principalmente em bots, webhooks e conversas exportadas. Uma carga copiada pode ser decodificada para recuperar a imagem.

Quando você copia de uma exportação de chat, cuidado com a string dividida em várias linhas ou envolvida em escape JSON. Barras invertidas antes de barras e aspas são artefatos de escape, não parte da string, e precisam ser removidas antes de decodificar.

Documentos são uma fonte parecida. Um arquivo Word ou de design exportado pode conter uma imagem embutida como um bloco Base64 dentro do seu XML, e copiar esse bloco entrega a imagem diretamente.

O mesmo aviso de truncamento se aplica em todos os lugares. Uma string copiada de uma mensagem que foi cortada no meio vai falhar ao decodificar, e a única correção é uma cópia completa da origem.

Para exportações grandes de chat, decodifique uma imagem por vez e renomeie cada download na hora. Um lote de arquivos todos chamados decoded_image é confuso, enquanto nomes como foto-equipe-decodificada.png continuam úteis.

Lembre-se de que uma imagem decodificada de um registro de chat pode ser uma miniatura em vez do original. Confira as dimensões ao lado da prévia antes de assumir que o arquivo está em resolução total.

Quando a string vem de um sistema que você controla, considere mudar o fluxo para enviar arquivos em vez de strings. Uma transferência de arquivo é mais eficiente, e a ida e volta de Base64 existe principalmente para sistemas que não conseguem carregar dados binários.

Quando a string vem de um sistema que você não controla, decodificar é a única opção, e esta ferramenta lida com isso localmente sem enviar a string para lugar nenhum.

Perguntas frequentes

Posso decodificar uma string Base64 no meu celular?

Sim. O decodificador roda em navegadores de celular no iOS e no Android. Cole a string, revise a prévia e baixe a imagem. Para strings muito longas, colar pode ser lento, então use primeiro uma string de teste mais curta para confirmar o fluxo.

Qual é a maior string Base64 que posso decodificar?

Não há limite fixo na ferramenta, mas strings muito grandes demoram mais porque o navegador precisa analisar todo o texto e reconstruir os dados binários. Strings de vários megabytes funcionam, embora possam ser lentas em celulares mais antigos. Se uma string for grande demais para lidar, peça a origem da imagem como arquivo.

Por que o arquivo decodificado tem um nome diferente do original?

A string Base64 não carrega o nome original do arquivo, então a ferramenta não consegue sabê-lo. Cada download se chama decoded_image com a extensão correspondente. Renomeie o arquivo logo após baixar para suas pastas ficarem organizadas.

Posso decodificar uma string Base64 que veio de um PDF ou documento Word?

Só se a string em si for uma imagem Base64 válida. Documentos costumam guardar imagens em outras formas, como dados binários embutidos ou fluxos comprimidos, que não são Base64. Extraia a imagem do documento primeiro e depois codifique ou decodifique conforme necessário.

Decodificar uma string Base64 reduz a qualidade dela?

Não. Decodificar é o inverso exato de codificar, então os bytes que saem são os bytes que entraram. Qualquer perda de qualidade aconteceu antes da codificação, quando a imagem foi comprimida ou convertida, e decodificar não consegue aumentar nem reparar isso.

O que faço se a string decodificar, mas a imagem parecer errada?

Primeiro, confira se você baixou o formato certo. Um PNG transparente baixado como JPG tem sua transparência preenchida, e um GIF animado convertido para PNG perde a animação. Baixe como Original para ver o arquivo verdadeiro e depois decida a conversão a partir daí.
