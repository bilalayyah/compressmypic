Como embutir imagem em Base64 no código

Converta uma imagem para Base64 em quatro passos: envie, escolha Data URL, bruto, HTML ou CSS e depois copie ou baixe. Funciona para PNG, JPG, SVG, GIF e ICO.

Você precisa de uma imagem como texto: um logotipo para uma folha de estilo, um ícone para um e-mail ou uma imagem para uma carga JSON. A conversão leva cerca de um minuto depois que você conhece os passos.

Este guia mostra como converter uma imagem para Base64 em quatro passos: envie o arquivo, escolha o formato de saída, copie ou baixe a string e cole-a no seu código.

Não há software para instalar, conta para criar nem nada enviado para lugar nenhum. A imagem é codificada localmente no seu navegador do começo ao fim.

O que você precisa antes de começar

Você precisa do próprio arquivo de imagem, em formato PNG, JPG, WebP, GIF, SVG, BMP ou ICO, até 15 MB. Logotipos, ícones e fotos pequenas são os candidatos usuais.

Saiba para onde a string vai. Uma página HTML quer uma Data URL, uma folha de estilo quer um valor CSS url(), e uma API geralmente quer a string bruta sem nenhum prefixo.

Se a imagem for grande, considere encolhê-la primeiro. Uma foto de 2 MB vira uma string de 2,7 MB, difícil de copiar e lenta para analisar, enquanto uma versão comprimida pode ter um décimo disso.

Um navegador é todo o software de que você precisa. A ferramenta roda em Chrome, Safari, Firefox e Edge, no computador e no celular, sem extensão.

Passo 1: envie a imagem ou cole uma captura de tela

Abra o conversor de imagem para Base64 e arraste sua imagem para a área de envio. Você também pode clicar na área para escolher um arquivo do seu dispositivo.

Se a imagem está na sua tela agora, copie-a e cole-a com Ctrl+V. A ferramenta aceita imagens da área de transferência diretamente, então uma captura de tela pode ser codificada sem salvar um arquivo antes.

A ferramenta lê o arquivo e mostra uma prévia com suas dimensões e formato. Confira se a prévia é a imagem que você queria, porque a string que você copiar será exatamente esse arquivo.

Se você enviou o arquivo errado, codifique outro na própria ferramenta. A saída anterior é substituída, e você pode continuar trabalhando sem recarregar a página.

Passo 2: escolha o formato de saída

Quatro abas ficam acima da área de saída: Data URL, Bruto, HTML e CSS. Escolha a que combina com o destino da string.

Escolha Data URL quando precisar de uma URI completa para uma fonte de imagem ou um fundo de folha de estilo. Ela inclui o tipo de mídia e o marcador de codificação, então funciona em qualquer lugar em que uma URL funciona.

Escolha Bruto quando estiver enviando a imagem para uma API ou guardando-a em um banco de dados. A saída bruta é só a string, sem prefixo, que é a forma que a maioria das APIs espera.

Escolha HTML quando quiser um elemento de imagem pronto. A ferramenta gera a tag com a Data URL como fonte e preenche os atributos de largura e altura automaticamente. Escolha CSS quando quiser um valor url() para um fundo ou uma máscara.

Passo 3: copie a saída ou baixe-a

Clique no botão Copiar saída para colocar a string na sua área de transferência. Para strings curtas, como ícones e logotipos, isso é tudo de que você precisa.

Para strings longas, use o botão de download. Copiar uma string de vários megabytes pode ser lento ou pouco confiável, enquanto um arquivo de texto baixado carrega a saída exata sem truncamento.

Se o seu navegador bloquear o acesso à área de transferência, a ferramenta vai avisar. Permita a permissão de área de transferência para a página ou use o botão de download como alternativa que não precisa de permissão nenhuma.

Confira a porcentagem de custo extra mostrada ao lado da saída. Ela diz o quanto a string é maior que o arquivo original, o que geralmente é cerca de 33 por cento, mais um pouco pelo invólucro.

Passo 4: cole a string no seu código

Cole a saída onde ela pertence: a Data URL em uma fonte de imagem ou uma folha de estilo, a string bruta em um campo JSON, o trecho HTML em uma página ou o valor CSS em uma propriedade de fundo.

Teste o resultado na hora. Abra a página, envie o e-mail de teste ou chame a API e confirme se a imagem aparece. Uma string colada no campo errado vai falhar em silêncio ou mostrar uma imagem quebrada.

Guarde o arquivo de imagem original. Se a versão embutida precisar mudar um dia, você vai codificar de novo a partir do original em vez de decodificar a string e codificá-la novamente.

Para um logotipo ou ícone, considere salvar o trecho no seu projeto como uma variável reutilizável ou um parcial. Assim, a string longa vive em um lugar só em vez de ser colada em cada arquivo que precisa dela.

Como codificar um logotipo SVG

Logotipos SVG codificam bem porque já são texto. Envie o arquivo SVG e a ferramenta produz uma string Base64 que decodifica de volta para o mesmo gráfico vetorial.

A Data URL de um SVG começa com data:image/svg+xml;base64, seguida da string. Cole-a em uma fonte de imagem e o logotipo é renderizado com nitidez em qualquer tamanho.

Cuidado com o tamanho, porém. Um SVG complexo com muitos caminhos pode ser grande, e sua forma Base64 é um terço maior ainda. Um logotipo simples está ótimo; uma ilustração detalhada pode ser melhor vinculada como arquivo.

Para SVGs bem pequenos, considere um SVG codificado por URL simples em vez de Base64. Ele é mais curto, mas precisa de escape cuidadoso, então Base64 continua sendo o padrão mais seguro para a maioria das pessoas.

Como codificar um favicon

Arquivos ICO de favicon funcionam no conversor como qualquer outro formato. Envie o arquivo .ico e copie a Data URL para uso em uma página de arquivo único ou em um modelo de e-mail.

A maioria dos sites deve vincular o favicon como arquivo em vez de embuti-lo. Um favicon vinculado é armazenado em cache pelo navegador, enquanto um embutido é baixado com cada página que o contém.

Embutir faz sentido para páginas de arquivo único, documentos offline e modelos de e-mail, onde nenhum arquivo separado pode ser buscado. Nesses contextos, o ícone embutido é a única forma de o favicon aparecer.

Se você ainda não tem um favicon, o gerador de favicon pode criar um a partir de qualquer imagem, e depois você pode codificar o resultado aqui.

Como codificar imagens para e-mail HTML

E-mails HTML não podem depender de arquivos de imagem externos, porque muitos clientes bloqueiam imagens remotas por padrão. Embutir a imagem como Data URL faz com que ela apareça na hora, mesmo offline.

Mantenha as imagens de e-mail embutidas pequenas. Um logotipo ou um pequeno banner funciona bem, mas uma fotografia grande deixa a mensagem pesada e lenta para abrir no celular.

Teste antes de enviar. Alguns clientes de e-mail bloqueiam imagens Base64 embutidas, e sua mensagem pode chegar com imagens quebradas para esses leitores. Envie um teste para os clientes que seu público usa.

Quando um cliente bloqueia Base64, volte para uma imagem hospedada com uma URL normal. A imagem hospedada precisa que o leitor carregue conteúdo remoto, mas funciona em todos os clientes que permitem isso.

Como codificar imagens para uma carga JSON de API

JSON não consegue carregar dados binários, então endpoints de envio de imagem que aceitam JSON esperam a imagem como uma string Base64. A aba de saída bruta entrega exatamente essa forma.

Copie a string bruta para o campo JSON que a API documenta e envie o tipo de mídia em um campo separado se a API pedir. O servidor decodifica a string e reconstrói o arquivo.

Cuidado com o tamanho da carga. Uma imagem de 1 MB vira um campo JSON de 1,4 MB, e algumas APIs rejeitam cargas acima de um limite. Comprima a imagem antes de codificar se a API tiver um limite de tamanho.

Teste primeiro com uma imagem pequena. Uma ida e volta bem-sucedida com um ícone minúsculo prova que os nomes de campo e o formato estão certos antes de você enviar uma imagem grande de produção.

Como encolher uma imagem antes de codificar

Codificar uma imagem grande produz uma string bem longa, e strings longas são difíceis de copiar, lentas para analisar e pesadas para guardar. Encolher antes quase sempre vale a pena.

Comprima a imagem com o compressor de imagens antes de codificá-la. Uma foto reduzida de 2 MB para 200 KB produz uma string dez vezes mais curta, com perda de qualidade geralmente invisível.

Redimensione também quando o tamanho de exibição for pequeno. Um ícone mostrado com 64 pixels não precisa de uma origem de 2000 pixels, e a origem menor codifica em uma string bem mais curta.

Para fotos, converta para JPG antes de codificar se a transparência não for necessária. Arquivos JPG são bem menores que PNG para fotografias, e o arquivo menor significa uma string mais curta.

Solução de problemas: problemas de cópia da área de transferência

Se o botão de copiar não fizer nada, seu navegador pode ter bloqueado o acesso à área de transferência. A ferramenta vai mostrar uma mensagem explicando o bloqueio, e você pode permitir a permissão para a página.

Alguns navegadores só permitem gravações na área de transferência após um gesto do usuário em uma página segura. Clicar no botão conta como gesto, mas um navegador antigo ou uma configuração restritiva ainda pode recusar.

O botão de download é a alternativa confiável. Ele salva a saída exata como um arquivo de texto sem nenhuma área de transferência envolvida, e você pode abrir o arquivo e copiar de lá.

No celular, strings longas podem ser lentas para copiar. Baixe o arquivo de saída e compartilhe-o com o aplicativo onde você precisa dele, em vez de brigar com a área de transferência.

Solução de problemas: strings muito longas

Uma string longa é normal para uma imagem grande, mas pode deixar seu editor lento. Colar uma string de 2 MB em um arquivo de código pode congelar um editor leve por segundos.

Divida o trabalho: guarde a string em um arquivo separado ou uma variável e faça referência a ela a partir do código que precisa dela. Isso mantém seus arquivos principais legíveis e seu editor responsivo.

Se a string quebrar seu build, confira os limites de tamanho de linha. Algumas ferramentas quebram ou truncam linhas muito longas, o que corrompe a string. Um arquivo baixado evita esse problema por completo.

Quando uma string parecer longa demais para gerenciar, reconsidere embutir. Um arquivo de imagem vinculado costuma ser a melhor escolha para qualquer coisa acima de algumas centenas de kilobytes.

Como codificar outra imagem depois da primeira

Para codificar uma segunda imagem, envie-a na ferramenta sem recarregar a página. A imagem nova substitui a antiga, e a saída é atualizada para a string nova.

Copie a primeira saída antes de trocar, porque substituir a imagem apaga a string anterior. Um arquivo baixado é o registro mais seguro se você precisar das duas strings.

Trabalhar com um conjunto de ícones é rápido assim. Envie, copie, envie o próximo, copie de novo, e todo o conjunto de ícones é codificado em poucos minutos.

Mantenha os arquivos originais organizados enquanto trabalha. Uma pasta de imagens de origem e uma pasta correspondente de arquivos de texto de saída evitam as confusões que acontecem quando todas as strings parecem iguais.

Como codificar imagens para redes sociais e mensagens

Postagens sociais e mensagens de chat às vezes só aceitam imagens como texto, principalmente em bots, webhooks e fluxos automatizados. Uma string Base64 permite que uma imagem viaje dentro de uma carga de mensagem só de texto.

Mantenha essas imagens minúsculas. Uma API de chat pode limitar o tamanho da mensagem a algumas dezenas de kilobytes, e uma foto codificada em Base64 vai ultrapassar esse limite antes mesmo de chegar.

Para chatbots, um ícone pequeno ou uma miniatura com menos de 10 KB codifica em uma string que cabe confortavelmente em uma mensagem. Qualquer coisa maior deve ser enviada como arquivo e referenciada por URL.

Algumas ferramentas de automação aceitam uma Data URL onde, de outra forma, precisariam de uma imagem hospedada. Isso é útil quando a imagem é gerada na hora e ainda não há onde hospedá-la.

Teste a ida e volta completa antes de automatizar. Envie uma mensagem com a imagem codificada, confirme se ela renderiza do lado do destinatário e só então monte o fluxo em torno dela.

Lembre-se de que a string é visível para qualquer pessoa que consiga ver a carga da mensagem. Não codifique fotos privadas em mensagens, registros ou webhooks onde o texto possa ser guardado ou encaminhado.

Perguntas frequentes

Posso converter uma imagem para Base64 no meu celular?

Sim. O conversor roda em navegadores de celular no iOS e no Android. Envie a imagem da sua galeria, escolha a aba de saída e copie a string. Para strings muito longas, baixe o arquivo de saída em vez de copiar, já que áreas de transferência de celular podem ter dificuldade com textos grandes.

Por que a aba HTML adiciona largura e altura à tag de imagem?

O navegador precisa das dimensões para reservar espaço antes que a imagem decodifique. Sem elas, o layout da página muda quando a imagem aparece, o que prejudica a experiência de leitura e a pontuação de mudança de layout. A ferramenta preenche os atributos automaticamente a partir das dimensões da imagem.

Devo usar Base64 ou um arquivo de imagem normal para o logotipo do meu site?

Para um logotipo que aparece em muitas páginas, um arquivo vinculado normal geralmente é melhor porque o navegador o armazena em cache uma vez. Base64 ganha quando a página precisa ser um único arquivo, quando o logotipo é minúsculo ou quando nenhuma requisição separada é permitida. Para a maioria dos sites, vincule o logotipo.

Qual é a diferença entre uma Data URL e Base64 bruto?

Uma Data URL é a URI completa com o prefixo de dados, o tipo de mídia e o marcador de codificação, pronta para usar como fonte de imagem. Base64 bruto é só a string, sem prefixo, que é a forma que APIs e bancos de dados geralmente esperam. A ferramenta gera as duas a partir da mesma imagem.

Converter para Base64 remove os metadados da minha imagem?

A codificação em si não remove nada, porque a string carrega os bytes originais exatos. No entanto, alguns fluxos removem metadados antes de codificar para manter a string mais curta. Se a privacidade importa, remova os metadados primeiro com a ferramenta de remoção de metadados e depois codifique o arquivo limpo.

Posso codificar uma captura de tela direto, sem salvar um arquivo?

Sim. Copie a captura de tela e pressione Ctrl+V na ferramenta, e ela será codificada na hora. Essa é a forma mais rápida de obter uma Data URL para uma captura de tela, um elemento de interface ou um diagrama que você está vendo agora.
