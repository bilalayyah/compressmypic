Como converter SVG para PNG

Converta logotipos e ícones SVG para PNG no tamanho que você precisa. Envie, escolha uma escala, confira o resultado e baixe — um arquivo ou um pacote inteiro.

Um logotipo SVG é infinitamente escalável, mas muitos lugares ainda querem um PNG. Converter leva segundos, e a única decisão que importa é o tamanho de saída.

Escolha a escala certa, e o PNG fica perfeito. Escolha a errada, e ele sai borrado ou grande demais sem necessidade.

Este guia passa por cada passo, desde enviar o SVG até baixar um PNG nítido.

Antes de começar: prepare o SVG

Abra o SVG no navegador primeiro e confirme que ele renderiza certo. Se ele parecer errado lá, vai parecer errado como PNG também.

Converta o texto em curvas na sua ferramenta de design se o SVG tiver letras. Texto em curvas vira formas, então renderiza com exatidão, seja qual for a fonte.

Embuta qualquer imagem vinculada como URI de dados dentro do SVG. O conversor não consegue buscar arquivos externos, então uma foto vinculada vai faltar no PNG.

Remova qualquer retângulo de fundo se quiser um PNG transparente. Uma forma de fundo vira parte da imagem, enquanto um SVG transparente continua transparente.

Passo 1: abra a ferramenta de SVG para PNG

Abra o Conversor de SVG para PNG no seu navegador. A página funciona no Windows, Mac, Linux, ChromeOS, Android e iOS.

Você vai ver uma área de envio e um seletor de escala. Esses dois controles são o trabalho inteiro.

Não precisa de conta, e nada é enviado para lugar nenhum. A conversão acontece no seu aparelho, o que importa para logotipos de clientes e recursos de marca.

Se você estiver no celular, a página funciona no navegador do aparelho. Toque na área de envio para escolher arquivos SVG do seu aparelho.

Passo 2: envie seus arquivos SVG

Arraste seus arquivos SVG para a área de envio ou clique nela para abrir o seletor de arquivos. Dá para selecionar vários arquivos de uma vez para um lote.

Cada arquivo aparece como um cartão com miniatura, para você confirmar que os arquivos certos foram carregados. Um arquivo errado é fácil de ver e remover.

Arquivos de até 25 MB cada são aceitos, o que cobre até arquivos ilustrados enormes com milhares de caminhos. SVGs bem complexos só levam um ou dois segundos a mais.

Você também pode colar um SVG copiado com Ctrl+V no computador. Isso ajuda quando o código SVG está na área de transferência, vindo de outro aplicativo.

Passo 3: escolha a escala de saída

O seletor de escala oferece 1x, 2x, 3x e 4x. A escala multiplica o tamanho natural do SVG, então um ícone de 24 pixels em 4x vira um PNG de 96 pixels.

Para um ícone de site, 2x ou 3x geralmente basta. O PNG fica nítido em telas retina sem desperdiçar bytes.

Para um logotipo num slide de apresentação, 4x dá uma margem confortável. Um logotipo pequeno ampliado no PowerPoint continua nítido quando o PNG tem pixels suficientes.

Para impressão, escolha a escala que alcance 300 DPI no tamanho impresso. Um logotipo impresso com 5 cm de largura precisa de pelo menos 600 pixels, então calcule de trás para frente a partir do tamanho de impressão.

Passo 4: converta os arquivos

Clique no botão Converter. A ferramenta desenha cada SVG num canvas na escala escolhida e codifica o resultado como PNG.

A conversão é rápida, geralmente um ou dois segundos por arquivo. SVGs bem complexos com milhares de caminhos levam um pouco mais para desenhar.

Cada cartão é atualizado com o novo tamanho e as dimensões do PNG. Confira as dimensões para confirmar que a escala produziu o tamanho esperado.

Se um arquivo falhar com erro, o SVG pode ter recursos sem suporte ou código malformado. Abra ele no navegador para confirmar que renderiza lá primeiro.

Passo 5: confira o resultado

Clique em Comparar num cartão para ver o SVG e o PNG lado a lado. Aproxime as bordas do logotipo e confirme que elas estão nítidas e limpas.

Confira o texto primeiro, se o SVG tiver algum. Texto com aparência errada significa uma fonte faltando, e a correção é converter o texto em curvas e converter de novo.

Confira se há imagens faltando. Um espaço em branco onde uma foto deveria estar significa que a imagem estava vinculada externamente, e você precisa embutir ela como URI de dados.

Confira a transparência. Um logotipo que deveria ser transparente não pode mostrar nenhuma caixa branca ao redor, ou o SVG tinha um retângulo de fundo que você precisa remover.

Passo 6: baixe os arquivos PNG

Clique em Baixar num cartão para salvar um PNG. O nome do arquivo mantém o nome original, com a extensão .png.

Para um lote, clique em Baixar tudo para receber um único ZIP com todos os PNGs convertidos dentro. Isso é bem mais rápido que baixar um por um.

Confira os arquivos baixados uma vez antes de usar. Abra um PNG no seu visualizador de fotos e confirme que ele está nítido no tamanho que você precisa.

Guarde os arquivos SVG originais também. São os arquivos principais, e dá para rasterizar eles de novo em qualquer tamanho sempre que precisar de um PNG diferente.

  1. Abra a ferramenta de SVG para PNG e envie seus arquivos SVG.
  2. Escolha uma escala: 2x para web, 4x para apresentações e impressão.
  3. Converta e confira bordas, texto e transparência.
  4. Baixe PNGs individuais ou o lote inteiro como ZIP.

Converter um pacote inteiro de ícones

Selecione todos os ícones SVG de uma vez no seletor de arquivos. Eles entram na fila, e um clique converte todos na mesma escala.

Use a mesma escala para o pacote inteiro. A consistência importa quando os ícones aparecem juntos, já que tamanhos misturados parecem desiguais.

Confira dois ou três ícones depois de converter, em vez de todos os cinquenta. Se esses estiverem bons, os outros também vão estar, já que os ajustes são os mesmos.

Envie os ícones PNG para onde eles são necessários. Um favicon, um ícone de aplicativo ou uma apresentação aceitam arquivos PNG sem nenhuma conversão adicional.

Como escolher o tamanho para cada uso

Para um favicon, rasterize nos tamanhos exatos que o site precisa, geralmente 16, 32 e 48 pixels. O gerador de favicon também pode criar esses tamanhos a partir de um PNG.

Para um avatar de rede social, 400 por 400 pixels é um bom tamanho. Ele fica nítido no computador e no celular, e o arquivo continua pequeno.

Para um logotipo de apresentação, 4x o tamanho do SVG geralmente dá pixels suficientes. Um logotipo de 100 pixels em 4x vira 400 pixels, o que fica nítido num slide.

Para impressão, calcule a partir do DPI. Um logotipo de 5 cm a 300 DPI precisa de 600 pixels, então escolha a escala que alcance pelo menos esse número.

Como corrigir problemas comuns

Se o PNG parecer borrado, a escala estava baixa demais. Rasterize de novo numa escala maior a partir do SVG original, já que um PNG de baixa resolução não pode ser afiado.

Se o texto parecer errado, a fonte está faltando. Converta o texto em curvas na sua ferramenta de design e converta de novo.

Se uma foto vinculada estiver faltando, embuta ela como URI de dados dentro do SVG. O conversor não consegue buscar arquivos externos, então a imagem precisa viajar dentro do próprio SVG.

Se o arquivo falhar com erro, abra o SVG no navegador. Se ele renderizar lá, tente converter ele sozinho, em vez de num lote.

Dicas para celulares e tablets

No celular, toque na área de envio e escolha arquivos SVG do seu aparelho. A conversão roda no celular, e os PNGs são baixados para o aparelho.

Mantenha os lotes do celular pequenos, já que SVGs complexos levam tempo para rasterizar num processador móvel. Dez arquivos de cada vez é confortável.

Os downloads caem na pasta Downloads do celular. No iPhone, confira o aplicativo Arquivos; no Android, confira o gerenciador de arquivos.

Para um pacote grande de ícones, use um computador. O processador mais rápido e a tela maior facilitam muito gerenciar cinquenta arquivos.

Converter um logotipo para cartão de visita

Um logotipo de cartão de visita precisa imprimir nítido num tamanho minúsculo, então rasterize o SVG em 4x. Um logotipo pequeno com pixels suficientes por trás continua limpo no cartão.

Confira as cores depois de converter, já que cores de impressão diferem das cores de tela. Uma impressão de teste rápida confirma que as cores da marca parecem certas no papel.

Envie o PNG para a gráfica com o SVG como backup. A gráfica pode rasterizar o próprio SVG se o PNG tiver um problema, então fornecer os dois cobre todos os casos.

Mantenha o arquivo PNG pequeno, já que uma gráfica de cartão de visita não precisa de uma imagem enorme. Um logotipo de 1000 pixels já basta para um cartão, e um arquivo maior só deixa o envio mais lento.

Peça um cartão de teste antes de imprimir o lote inteiro. Um único cartão confirma o tamanho do logotipo, as cores e a nitidez antes de você investir em centenas.

Converter ícones para um site

Ícones de site começam como arquivos SVG e viram PNGs para navegadores mais antigos. Rasterize em 2x ou 3x o tamanho de exibição, para os ícones ficarem nítidos em telas retina.

Use a mesma escala para o conjunto inteiro de ícones. A consistência importa quando os ícones aparecem juntos, já que tamanhos misturados parecem desiguais.

Teste os ícones no site real antes de publicar. Um ícone perfeito na ferramenta de design pode parecer diferente contra a cor de fundo do site.

Para um site moderno, considere usar os arquivos SVG diretamente. Navegadores exibem SVG nativamente, e os ícones ampliam perfeitamente sem nenhuma rasterização.

Guarde os SVGs originais na pasta do projeto depois de converter. Se o site passar por um redesign, os ícones podem ser rasterizados de novo em tamanhos novos sem redesenhar eles.

Converter um SVG para estampa de camiseta

Uma estampa de camiseta precisa de uma imagem em alta resolução, e o SVG é a fonte ideal. Rasterize na maior escala que a ferramenta permite, até o limite de 8000 pixels, para uma impressão nítida.

Confira o design depois de converter, já que uma estampa de camiseta mostra cada falha. Um logotipo que parece bom na tela pode revelar bordas ásperas quando impresso grande no tecido.

Envie o PNG para a gráfica com o SVG como backup. O software da gráfica pode preferir um formato ao outro, e fornecer os dois cobre todos os casos.

Para uma camiseta escura, confira a transparência. Um logotipo com fundo transparente imprime limpo no tecido escuro, enquanto um logotipo com caixa branca parece errado.

Peça uma única camiseta de teste antes de imprimir um lote. Uma impressão de teste confirma o tamanho, as cores e o posicionamento antes de você investir em dezenas de camisetas.

Converter um SVG para uma apresentação

Slides de apresentação precisam de logotipos nítidos, e o SVG é a fonte ideal. Rasterize em 4x o tamanho do SVG, para o logotipo continuar limpo quando projetado numa tela grande.

Confira o logotipo no fundo real do slide depois de converter. Um logotipo perfeito no branco pode mostrar uma franja leve num slide colorido se a qualidade estava baixa.

Para uma apresentação com muitos slides, converta todos os logotipos de uma vez. Uma conversão em lote leva minutos, e os PNGs ficam prontos para entrar nos slides.

Teste a apresentação no projetor antes da palestra. Um slide nítido no laptop pode parecer suave quando projetado, e um teste rápido pega o problema cedo.

Guarde os SVGs originais na pasta do projeto depois de converter. Se a apresentação for reutilizada com um modelo novo, os logotipos podem ser rasterizados de novo em tamanhos novos.

Converter um SVG para um favicon

Um favicon é o ícone minúsculo na aba do navegador e geralmente começa como um logotipo SVG. Rasterize ele em 16, 32 e 48 pixels para os tamanhos padrão de favicon.

Crie o favicon de forma simples, já que tamanhos minúsculos escondem detalhes. Um logotipo complexo com 16 pixels vira um borrão, enquanto uma forma simples continua reconhecível.

Teste o favicon em vários navegadores depois de adicionar. Uma checagem rápida confirma que ele exibe certo, então o site parece caprichado em todas as abas.

Para navegadores modernos, considere usar o favicon SVG diretamente. Navegadores exibem favicons SVG nativamente, e o ícone amplia perfeitamente sem nenhuma rasterização.

Guarde o SVG principal depois de converter. Se o site passar por um redesign, o favicon pode ser rasterizado de novo em tamanhos novos sem redesenhar o logotipo.

Converter um SVG para um banner de site

Um banner de site é uma imagem larga, e o SVG é a fonte ideal quando o banner é um gráfico, não uma foto. Rasterize na largura de exibição do banner para um resultado nítido.

Confira as dimensões do banner antes de converter. Um banner exibido com 1200 pixels de largura precisa de um PNG com pelo menos essa largura, ou vai parecer suave.

Para um banner com texto, rasterize em 2x o tamanho de exibição. O texto continua nítido em telas retina, e o arquivo continua pequeno o bastante para carregar rápido.

Teste o banner no computador e no celular depois de converter. Um banner perfeito numa tela larga pode cortar mal numa estreita, e um teste rápido pega isso.

Guarde o SVG principal na pasta do projeto. Se o site passar por um redesign com um tamanho novo de banner, o gráfico pode ser rasterizado de novo sem redesenhar.

Esse é o processo inteiro: preparar, enviar, escolher uma escala, baixar. Perguntas frequentes

Qual é o tamanho do PNG na escala 1x?

Em 1x, o PNG combina com o tamanho natural do SVG, então um ícone de 24 px vira um PNG de 24 px. Para resultados nítidos em telas modernas, use 2x ou 3x, e para apresentações ou impressão, use 4x. A exportação é limitada a 8000 px no lado maior, o que raramente importa para ícones e logotipos.

Dá para converter arquivos SVG no celular?

Sim. Abra a ferramenta no navegador do celular, toque na área de envio e escolha arquivos SVG do seu aparelho. A conversão roda no celular, e os PNGs são baixados para o aparelho. Mantenha os lotes do celular pequenos, já que SVGs complexos levam tempo para rasterizar no celular.

Qual nome de arquivo o PNG exportado vai manter?

O PNG mantém o nome original do SVG, com a extensão .png, então logo.svg vira logo.png. Isso facilita encontrar e mantém seus arquivos organizados. Para um lote, o ZIP contém cada PNG com o nome original correspondente.

O conversor suporta animações SVG?

Não, não muito. Animações SVG usando SMIL ou CSS não são preservadas, já que o conversor desenha um único quadro estático no canvas. O resultado é um PNG parado do SVG como ele aparece no começo. Para um logotipo animado, mantenha o próprio SVG.

Dá para rasterizar um SVG com uma imagem embutida como URI de dados?

Sim. Imagens embutidas como URIs de dados dentro do SVG fazem parte do arquivo, então renderizam certo no PNG. Essa é a forma certa de incluir fotos num SVG para conversão. Imagens externas vinculadas, por outro lado, ficam de fora, já que o conversor não consegue buscar elas.

Por que meu PNG convertido parece borrado?

A escala estava baixa demais para o tamanho que você precisa. Um ícone de 24 px rasterizado em 1x tem só 24 pixels, e esticar ele para 200 pixels deixa borrado. Rasterize de novo numa escala maior a partir do SVG original, já que um PNG de baixa resolução não pode ser afiado depois.
