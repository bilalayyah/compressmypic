Como converter uma imagem para PDF

Transforme uma foto ou um conjunto inteiro em PDF em poucos minutos. Envie, ordene as páginas, escolha um tamanho e baixe o seu documento.

Converter uma imagem para PDF é um dos trabalhos mais úteis de arquivo do dia a dia. Uma foto vira um documento, um conjunto de digitalizações vira um único arquivo, e tudo fica pronto para enviar ou imprimir.

O processo inteiro leva alguns minutos, mesmo para um documento longo. Você envia as imagens, arruma elas, escolhe um tamanho de página e baixa o PDF pronto.

Este guia passa por cada passo em ordem, para o seu primeiro PDF sair limpo e profissional.

Passo 0: junte e prepare as suas imagens

Junte cada imagem que pertence ao documento antes de abrir a ferramenta. Um pedido de passaporte, por exemplo, pode precisar de uma foto, uma assinatura e um formulário digitalizado.

Confira se cada imagem está do lado certo. Uma digitalização torta vira uma página torta, então gire as imagens tortas primeiro com a ferramenta de rotação.

Use os originais de melhor qualidade que você tem. Uma digitalização borrada não vai ficar nítida dentro de um PDF, e uma foto de baixa resolução vai parecer pior quando impressa.

Arquivos de até 20 MB cada são aceitos. A maioria das fotos de celular e das digitalizações fica bem abaixo desse limite, então você raramente precisa encolher alguma coisa antes.

Passo 1: abra a ferramenta Imagem para PDF

Abra a ferramenta Imagem para PDF no seu navegador. A página funciona no Windows, Mac, Linux, ChromeOS, Android e iOS, sem nada para instalar.

Você vai ver uma área de envio e os ajustes do documento abaixo dela. Os ajustes ficam visíveis enquanto você trabalha, então dá para mudar eles a qualquer momento antes de gerar.

Não precisa de conta, e nada é enviado. O PDF é criado no seu aparelho, o que importa quando as imagens são documentos de identidade ou recibos.

Se você estiver no celular, a página funciona no seu navegador móvel. Toque na área de envio para escolher fotos da sua galeria.

Passo 2: envie as imagens e defina a ordem

Arraste as suas imagens para a área de envio, ou clique nela para abrir o seletor de arquivos. Você também pode colar capturas direto com Ctrl+V, o que é prático para documentos rápidos.

As imagens aparecem na lista de Ordem das páginas na sequência em que você acrescentou elas. Arraste qualquer página para cima ou para baixo para rearrumar até a ordem ficar certa.

Você pode acrescentar mais imagens depois, mesmo após conferir a lista. As imagens novas entram no fim, e você arrasta elas para o lugar como as outras.

Remova as páginas duplicadas ou indesejadas agora. É bem mais fácil corrigir a lista antes de gerar do que reconstruir o PDF depois.

Passo 3: escolha um tamanho de página

Escolha A4 para a maioria dos documentos. É o tamanho de página padrão na maior parte do mundo, e os sistemas oficiais esperam ele para formulários, pedidos e papelada digitalizada.

Escolha o tamanho Carta se o destinatário estiver nos Estados Unidos ou no Canadá, ou se o formulário pedir especificamente o tamanho Carta. A diferença é pequena, mas visível quando impressa.

Escolha Ajustar ao tamanho da imagem quando o PDF for uma coleção de fotos. Cada página acompanha a sua imagem exatamente, sem espaço em branco e sem corte, o que combina com álbuns e arquivos de digitalização.

Se estiver em dúvida, o A4 é o padrão seguro. Ele imprime certo em quase todo lugar e parece profissional na tela.

Passo 4: defina a orientação e o posicionamento

Deixe a Orientação no Automático, a menos que você tenha um motivo para mudar. O Automático lê cada imagem e dá às fotos em retrato uma página em retrato e às fotos em paisagem uma página em paisagem.

Se todas as imagens tiverem o mesmo formato, você pode forçar Retrato ou Paisagem para um documento uniforme. Páginas uniformes ficam mais arrumadas para envios formais.

Para o Posicionamento, escolha Ajustar para documentos. O Ajustar encaixa a imagem inteira dentro da página, então nenhuma assinatura ou canto é cortado.

Escolha Preencher só para coleções de fotos, em que uma página sem bordas fica melhor. O Preencher corta o que sobra, então nunca use ele para identidades ou formulários.

Passo 5: defina as margens e a qualidade

Escolha uma margem que combine com a finalidade. Sem margem serve para fotos de página inteira, a margem pequena serve para documentos em geral, e a margem média serve para qualquer coisa que você vai imprimir e arquivar.

Lembre que as impressoras não conseguem imprimir até a beirada do papel. Um PDF sem margem pode perder uma fatia da imagem no papel, então use pelo menos uma margem pequena para impressão.

Defina o controle de qualidade como alto para texto e fotos de identidade. As letras miúdas borram rápido com qualidade baixa, e um documento borrado pode ser rejeitado.

Para álbuns de fotos feitos para telas, a qualidade média serve. As imagens continuam limpas, e o PDF fica pequeno o bastante para enviar por e-mail.

Passo 6: visualize e confira tudo

Olhe a lista de Ordem das páginas mais uma vez. Confira a sequência, a orientação de cada página e se nenhuma página está de cabeça para baixo.

Confirme se o tamanho da página e as margens combinam com a finalidade. Um formulário que precisa de A4 com margens não deve chegar como Ajustar à imagem sem margens.

Confira o ajuste de nome do arquivo. Dê ao PDF um nome claro, como documentos-do-visto.pdf, para o destinatário saber o que é sem abrir.

Essa é a sua última chance de corrigir as coisas com pouco custo. Um minuto de conferência agora economiza uma reconstrução depois.

Passo 7: gere e baixe o PDF

Clique no botão Gerar. Uma mensagem de progresso mostra Codificando página X de Y, para você acompanhar o documento sendo criado página por página.

A geração leva alguns segundos para um documento curto e um pouco mais para um documento longo. Vinte páginas geralmente terminam em menos de meio minuto.

Quando a janela de download aparecer, salve o arquivo. Se a janela sumir antes de você perceber, confira a sua pasta Downloads, já que o arquivo é salvo lá automaticamente.

Abra o PDF pronto e olhe ele uma vez. Confirme a contagem de páginas, a ordem e se o menor texto é legível.

  3. Escolha um tamanho de página, orientação, margens e qualidade.
  4. Gere o PDF e confira antes de enviar.

Como converter uma única foto para PDF

Uma única foto vira um PDF de uma página com os mesmos passos. Envie a foto, escolha um tamanho de página e gere.

Para uma única foto, o Ajustar ao tamanho da imagem costuma ser a melhor escolha. A página acompanha a foto exatamente, sem bordas brancas e sem espaço desperdiçado.

Um PDF de uma foto só é útil para enviar uma foto a alguém que precisa de um formato de documento. Alguns formulários aceitam só envios em PDF, e esse é o jeito mais rápido de cumprir.

Dê ao arquivo um nome claro, como foto-de-perfil.pdf, para o destinatário reconhecer na hora.

Como converter documentos digitalizados

As digitalizações são o trabalho de PDF mais comum. Um formulário de várias páginas, um contrato ou um conjunto de recibos vira um documento arrumado.

Use tamanho de página A4 e posicionamento Ajustar para digitalizações. Essa combinação mantém cada palavra visível e cada página com o mesmo tamanho.

Mantenha o controle de qualidade alto para digitalizações. As letras miúdas e as assinaturas borram com qualidade baixa, e uma digitalização borrada pode ser rejeitada pelo órgão que recebe.

Digitalize com 200 DPI ou mais se você controla o scanner. Uma digitalização de baixa resolução não pode ser nítida depois, não importa a qualidade que você escolha no PDF.

Como corrigir problemas comuns

Se uma página sair torta, a imagem original estava torta. Gire a imagem antes de acrescentar, ou remova ela, gire e acrescente de novo.

Se o PDF estiver grande demais para enviar por e-mail, baixe o controle de qualidade um passo e gere de novo. As fotos comprimem bem com qualidade média, enquanto as digitalizações precisam de um toque mais suave.

Se uma página estiver cortada, você provavelmente escolheu o posicionamento Preencher. Troque para Ajustar e gere de novo, e a imagem inteira vai caber.

Se a janela de download sumiu, confira a pasta Downloads. O arquivo está lá mesmo que você tenha fechado a janela, então não precisa gerar de novo.

Dicas para celulares e tablets

No celular, toque na área de envio e escolha fotos da sua galeria. Você pode selecionar várias fotos de uma vez, e elas chegam na ordem em que você escolheu.

Arraste as páginas na lista de ordem com o dedo para rearrumar. A lista aceita toque, e um toque longo geralmente começa o arraste.

Os downloads caem na pasta Downloads do celular. No iPhone, abra o aplicativo Arquivos; no Android, abra o seu gerenciador de arquivos.

Para um documento longo, use um computador se puder. A tela maior facilita muito ordenar vinte páginas do que um celular.

Como converter recibos para despesas

Os pedidos de reembolso precisam de recibos, e um PDF de recibos é bem mais arrumado que uma pasta de fotos. Um documento por viagem ou mês deixa a equipe financeira feliz.

Fotografe cada recibo reto, com boa luz e sem sombras. Um recibo torto ou com sombra é difícil de ler, e a equipe financeira pode rejeitar ele.

Use tamanho de página A4 com posicionamento Ajustar, para cada recibo caber inteiro na sua página. Um total cortado ou uma data faltando é o motivo mais comum de um pedido rejeitado.

Mantenha o controle de qualidade alto para recibos. As letras miúdas, como números de imposto e linhas detalhadas, borram rápido com qualidade baixa, e o pedido precisa desses detalhes.

Dê ao PDF um nome com o mês e a finalidade, como despesas-novembro-2026.pdf. Um nome claro ajuda a equipe financeira a arquivar certo e a encontrar de novo depois.

Como criar um PDF de portfólio

Um PDF de portfólio mostra o seu melhor trabalho em um único documento que qualquer pessoa consegue abrir. Designers, fotógrafos e freelancers usam um para conquistar clientes.

Escolha primeiro as suas imagens mais fortes e depois arrume elas em uma ordem intencional. A primeira página deve ser o seu melhor trabalho, já que ela define a impressão de tudo que vem depois.

Use Ajustar ao tamanho da imagem para um portfólio, para cada imagem preencher a sua página sem bordas brancas. O layout sem bordas parece intencional e profissional, como um livro impresso.

Mantenha o tamanho do arquivo razoável. Um portfólio grande demais para enviar por e-mail não serve para nada, então equilibre qualidade com tamanho, e tente ficar abaixo de 10 MB se puder.

Inclua uma página final com os seus dados de contato. Um cliente que amar o trabalho deve encontrar o seu e-mail e telefone sem procurar.

Como combinar fotos e digitalizações em um PDF

Os documentos reais costumam misturar fotos e digitalizações. Um pedido de visto pode conter uma foto JPG, uma digitalização PNG de um passaporte e uma digitalização JPG de um extrato bancário.

O criador de PDF aceita formatos misturados em um documento só. Cada página mantém o formato original dela, então você não precisa converter tudo para um formato só antes.

Ordene as páginas com lógica, com os documentos de identidade primeiro e as evidências de apoio depois. Uma ordem clara ajuda o leitor a acompanhar a história do pedido.

Confira as páginas misturadas com cuidado depois de gerar. Uma página de foto e uma página de digitalização podem precisar de ajustes de qualidade diferentes, e o controle único é um meio-termo para as duas.

Se uma página parecer errada, ajuste a imagem original em vez dos ajustes do PDF. Converta uma foto problemática para o formato certo primeiro e depois reconstrua o PDF.

Como enviar o PDF para outra pessoa

Antes de enviar, abra o PDF pronto e leia como o destinatário leria. Confira a contagem de páginas, a ordem e se o menor texto é legível.

Para e-mail, anexe o PDF direto se ele estiver abaixo do limite de tamanho. A maioria dos serviços permite 20 MB a 25 MB, e um PDF bem feito costuma ser bem menor que isso.

Para PDFs maiores, envie para o armazenamento em nuvem e compartilhe um link. O destinatário baixa o arquivo sem nenhum problema de tamanho, e você pode revogar o link depois se precisar.

Para aplicativos de mensagens, confira se o PDF é enviado como documento e não como imagens. O WhatsApp e o Telegram aceitam anexos de PDF, que preservam o layout.

Depois de enviar, guarde uma cópia na sua pasta de enviados. Se o destinatário perder ou pedir outra versão, você pode reenviar ou reconstruir sem começar do zero.

Como converter fotos de identidade para pedidos

Os formulários de pedido costumam precisar de uma foto de identidade como página de PDF, e a foto precisa estar clara. Uma foto de identidade borrada pode atrasar um pedido por semanas, então a conversão merece cuidado.

Use uma foto recente, bem iluminada e com fundo neutro. O rosto deve estar de frente, sem sombras e sem óculos de sol, seguindo as regras de foto do pedido.

Escolha tamanho de página A4 com posicionamento Ajustar, para a foto inteira caber na página. Um queixo ou uma testa cortados é o motivo mais comum de uma foto de identidade rejeitada.

Mantenha o controle de qualidade alto para fotos de identidade. Os detalhes pequenos, como os olhos e a boca, precisam continuar nítidos, já que o sistema do pedido confere eles.

Confira o tamanho do arquivo depois de gerar. Um portal que limita envios a 2 MB pode rejeitar um PDF grande, e você pode precisar baixar a qualidade um passo.

Esse é o processo completo, de um conjunto solto de imagens a um único PDF limpo. Para a explicação mais profunda, leia o Como transformar imagem em PDF: guia completo, e para a escolha de formato, veja JPG ou PNG para PDF.

Se as suas imagens forem arquivos HEIC de um iPhone, o conversor de HEIC para JPG pode preparar elas primeiro.

Perguntas frequentes

Dá para converter uma única imagem para PDF, ou preciso de várias?

Uma única imagem funciona bem e vira um PDF de uma página. A ferramenta é feita para lotes, mas não há uma quantidade mínima. Para uma foto, o Ajustar ao tamanho da imagem geralmente dá o resultado mais limpo, já que a página acompanha a foto exatamente.

O que acontece se eu enviar as imagens na ordem errada?

Você pode corrigir a ordem antes de gerar. A lista de Ordem das páginas deixa você arrastar qualquer página para cima ou para baixo até a sequência ficar certa. Você também pode acrescentar ou remover imagens nessa etapa. Quando a ordem parecer certa, gere o PDF.

Dá para converter imagens para PDF no celular?

Sim. Abra a ferramenta no navegador do celular, toque na área de envio e escolha fotos da galeria. Todos os ajustes funcionam com o toque, e o PDF pronto baixa no celular. Para documentos longos, um computador é mais fácil, mas o celular resolve bem os curtos.

O PDF mantém a qualidade original da imagem?

Na maior parte, sim, mas o controle de qualidade importa. Com qualidade alta, as imagens dentro do PDF são quase idênticas às originais. Com qualidade baixa, elas são comprimidas e podem parecer mais suaves. Para documentos com texto, mantenha a qualidade alta.

Dá para proteger com senha o PDF que eu criar?

Não com esta ferramenta, que cria um PDF padrão sem criptografia. Se você precisar de senha, abra o PDF pronto em um aplicativo de PDF que aceite proteção e defina uma lá. O arquivo gerado em si é um PDF normal, sem proteção.

Converter imagens para PDF reduz o tamanho do arquivo?

Pode reduzir, dependendo do controle de qualidade. Com qualidade média, as imagens dentro do PDF são comprimidas, então o arquivo total costuma ficar menor que os originais separados. Com qualidade alta, o PDF pode ter tamanho parecido ou um pouco maior, por causa da estrutura do PDF em si.
