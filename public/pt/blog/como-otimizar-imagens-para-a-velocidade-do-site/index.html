Como otimizar imagens para o site

Passo a passo: otimize imagens para a velocidade do site com predefinições, dimensões corretas, carregamento preguiçoso e tags HTML prontas para colar.

As imagens são a parte mais pesada da maioria dos sites. Uma página que carrega devagar geralmente tem as imagens como culpadas, e corrigi-las é a vitória de velocidade mais rápida disponível.

Este guia passa por todo o processo de otimização. Você vai auditar a página, escolher a predefinição certa, otimizar as imagens e colar o HTML no lugar.

Funciona para blogs, lojas e sites de empresas, e você não precisa de experiência em programação além de copiar e colar.

Passo 1: audite a página primeiro

Antes de otimizar qualquer coisa, descubra quais imagens são o problema. Abra a página e anote quais imagens demoram para aparecer.

Use uma ferramenta gratuita de velocidade para medir a página. Ela lista as imagens mais pesadas e mostra quanto cada uma custa em tempo de carregamento.

Anote o peso total das imagens da página. Uma página com 5 MB de imagens tem um problema óbvio, enquanto uma página com 500 KB já está em boa forma.

Escreva as três piores imagens. Corrigir essas primeiro dá o maior ganho de velocidade com o menor esforço.

Passo 2: abra o Otimizador de imagens para web

Abra o Otimizador de imagens para web no navegador. Não precisa de conta nem de instalação.

A ferramenta roda toda no seu aparelho. Suas imagens são processadas localmente e nunca enviadas para um servidor.

Se você estiver otimizando um site inteiro, trabalhe em lotes. Trinta imagens de cada vez é um tamanho confortável de lote para a maioria dos navegadores.

Salve a página nos favoritos. A otimização de imagens é um trabalho recorrente, e é uma ferramenta à qual você vai voltar sempre.

Passo 3: escolha a predefinição certa

Escolha a predefinição que corresponde a onde a imagem vai aparecer. Uma imagem principal, uma foto de produto e uma miniatura têm cada uma sua própria predefinição.

A predefinição Produto de e-commerce é a padrão. Ela limita as imagens a 1200 pixels de largura em WebP com 82% de qualidade, o que serve à maioria das fotos de produto.

Para uma imagem de destaque de blog, use a predefinição de imagem principal ou de cartão, dependendo do layout. Combine a predefinição com o tamanho de exibição, não com o tamanho do arquivo.

Para imagens de compartilhamento social, use a predefinição Social OG. Ela troca o formato para JPG automaticamente, pois as plataformas sociais o preferem.

Passo 4: envie as imagens

Arraste as imagens para a área de envio ou toque para procurar. Arquivos JPG, PNG, WebP e HEIC são aceitos.

Envie os originais de melhor qualidade que você tiver. Um original de 12 megapixels dá ao otimizador muito mais com que trabalhar que uma cópia pequena.

Para um lote, adicione todas as imagens de uma página de uma vez. Elas compartilham a predefinição, o que mantém os resultados consistentes.

Espere o envio terminar antes de mudar as configurações. A ferramenta precisa dos arquivos completos antes de otimizá-los.

Passo 5: personalize as configurações

Depois de escolher uma predefinição, ajuste as configurações se o espaço exigir. Mude as dimensões, o formato ou a qualidade para servir ao design.

Mantenha as dimensões próximas ao tamanho de exibição. Uma imagem mostrada com 800 pixels de largura não precisa ter 2400 pixels no arquivo.

Ligue Só reduzir quando o lote misturar imagens grandes e pequenas. Isso protege ícones e miniaturas de serem esticados para maior.

Mova o controle de qualidade só quando necessário. A maioria das predefinições fica entre 75 e 85%, que é o intervalo certo para quase toda imagem.

Passo 6: veja a prévia dos resultados

Veja a prévia de cada imagem otimizada em tamanho cheio antes de baixar. Uma miniatura pequena esconde problemas óbvios em tamanho cheio.

Confira primeiro os detalhes finos. A textura do tecido, o texto e as bordas são as primeiras coisas a suavizar com a compressão.

Compare alguns resultados com os originais. Pequenas diferenças são normais; texto ilegível ou pele manchada, não.

Confira também os tamanhos dos arquivos. O resumo mostra quanto cada imagem encolheu e a economia total do lote.

Passo 7: copie a tag HTML

Clique em Copiar tag de imagem para cada imagem. A tag inclui a fonte, as dimensões, o texto alternativo e o comportamento de carregamento, pronta para colar.

Confira o texto alternativo na tag. Edite se o texto gerado não descrever bem a imagem.

Confirme se o atributo de carregamento está certo. As imagens principais devem carregar na hora, enquanto as imagens abaixo da dobra devem ter carregamento preguiçoso.

Cole a tag na sua página onde a imagem pertence. Substitua a tag antiga da imagem por completo, em vez de editá-la à mão.

Passo 8: envie e teste a página

Envie as imagens otimizadas para o seu site. Use os mesmos nomes de arquivo que a ferramenta produziu, para as tags HTML combinarem com os arquivos.

Abra a página numa nova aba do navegador. Confira se cada imagem aparece e se nada parece esticado ou borrado.

Rode a ferramenta de velocidade de novo e compare os números. O peso total das imagens deve ter caído bastante, e o tempo de carregamento junto.

Teste no celular também, além do computador. A maioria dos visitantes navega no celular, e a página precisa parecer rápida lá primeiro.

Corrigindo problemas comuns

Se uma imagem parecer borrada, a fonte pode ter sido pequena demais. Otimize de novo a partir de um original maior com a mesma predefinição.

Se a página continuar lenta, procure imagens sem otimização. Um único banner esquecido de 5 MB pode desfazer o lote inteiro.

Se as imagens aparecerem esticadas, as dimensões na tag não combinam com o arquivo. Copie a tag de novo da ferramenta em vez de editá-la à mão.

Se um compartilhamento social não mostrar imagem, confira o formato. As plataformas sociais preferem JPG, e a predefinição Social OG cuida disso automaticamente.

Fluxo de trabalho: uma postagem de blog

Junte as imagens da postagem e envie como um só lote. Use a predefinição de cartão para miniaturas e a de imagem principal para a imagem de destaque.

Veja a prévia da imagem de destaque com cuidado. É a maior imagem da página e a que os leitores julgam primeiro.

Copie as tags HTML e cole na postagem. Confira o texto alternativo de cada uma antes de publicar.

Publique a postagem e teste no celular. As imagens devem carregar rápido e ficar nítidas conforme você rola.

Fluxo de trabalho: uma página de produto

Reúna as fotos do produto e envie como um só lote. Use a predefinição Produto de e-commerce para resultados consistentes.

Veja a prévia dos produtos mais detalhados primeiro. A textura do tecido e os rótulos impressos são as primeiras coisas a suavizar.

Copie as tags HTML e cole na página do produto. Confirme se o atributo de carregamento está certo para cada posição de imagem.

Confira a página do produto no celular depois de enviar. A maioria dos compradores navega no celular, e as imagens precisam ficar boas lá.

Usando bem as ferramentas gratuitas de velocidade

As ferramentas gratuitas de velocidade medem sua página e listam os problemas. São o melhor ponto de partida para qualquer trabalho de otimização.

Rode a ferramenta na página ao vivo, não numa cópia local. A página ao vivo inclui a hospedagem, a CDN e as condições reais que seus visitantes enfrentam.

Leia primeiro as recomendações de imagem. Elas nomeiam os arquivos exatos que custam mais tempo, o que diz por onde começar.

Ignore a pontuação perfeita. Uma pontuação na faixa verde já basta; perseguir 100 desperdiça tempo que seria melhor gasto com conteúdo.

Rode a ferramenta de novo depois de cada rodada de correções. Os números que mudam mostram se seu trabalho está valendo a pena.

Escolhendo tamanhos por espaço na página

Cada espaço de uma página tem um tamanho natural de imagem. Combinar o arquivo com o espaço é a habilidade central da otimização para web.

As imagens principais precisam dos maiores arquivos, muitas vezes de 1200 a 1600 pixels de largura. Elas preenchem a tela, então precisam continuar nítidas.

As imagens de destaque em postagens de blog servem com 800 a 1200 pixels. São grandes, mas não de tela cheia, então um tamanho médio funciona.

As miniaturas e os avatares precisam de só 200 a 400 pixels. Qualquer coisa maior desperdiça banda com detalhes que ninguém consegue ver.

Meça o espaço no seu tema antes de escolher. A largura exibida decide a largura do arquivo, e adivinhar errado desperdiça kilobytes.

Imagens responsivas na prática

As imagens responsivas servem arquivos diferentes para telas diferentes. Um celular recebe um arquivo pequeno, enquanto um computador recebe um maior.

O atributo srcset lista os tamanhos disponíveis, e o navegador escolhe o certo para a tela em que roda.

Gere dois ou três tamanhos por imagem. Um tamanho para celular, um para tablet e um para computador cobrem quase todos os visitantes.

Teste num celular de verdade depois de adicionar imagens responsivas. A melhora de carregamento no celular costuma ser dramática.

Mantenha o HTML simples. Um srcset com três tamanhos basta; dez tamanhos adicionam complexidade sem benefício visível.

SEO de imagens enquanto você otimiza

Otimização e SEO andam juntas. Uma página rápida com imagens bem descritas ranqueia melhor que uma página lenta com arquivos anônimos.

Use nomes de arquivo descritivos. Um nome como camisa-algodao-azul.jpg diz aos mecanismos de busca o que a imagem mostra.

Escreva texto alternativo de verdade para cada imagem. Descreva o conteúdo numa frase e inclua o detalhe principal que um pesquisador procuraria.

Não encha os nomes de arquivo nem o texto alternativo de palavras-chave. Uma descrição natural ajuda leitores e mecanismos de busca.

Envie um sitemap de imagens se seu site depende da busca de imagens. Isso ajuda os mecanismos de busca a descobrir imagens que poderiam passar despercebidas.

Mantendo as imagens otimizadas ao longo do tempo

A otimização não é um trabalho único. Novas imagens chegam toda semana, e cada uma precisa do mesmo tratamento da anterior.

Inclua a otimização na lista de publicação. Cada postagem deve passar pelo otimizador antes de ir ao ar.

Audite o site a cada trimestre. As imagens antigas, de antes do hábito de otimização, costumam continuar pesadas, e um lote as corrige rápido.

Fique de olho nas mudanças de tema. Um tema novo pode exibir imagens maiores que o antigo, o que significa que os arquivos antigos de repente ficam pequenos demais.

Guarde os originais em segurança. Quando o design mudar, os originais permitem reotimizar para os novos tamanhos sem perda de qualidade.

Padrões de otimização para equipes

Equipes que publicam juntas precisam de um padrão compartilhado. Combinem a predefinição, o padrão de nomeação e o orçamento de tamanho antes da primeira postagem.

Escreva o padrão numa página só. Um guia curto na wiki da equipe evita uma centena de pequenas perguntas.

Designe uma pessoa para conferir o peso das imagens em cada publicação. Um segundo olhar pega a imagem pesada que o autor não percebeu.

Revise o padrão quando o design mudar. As predefinições que serviam ao tema do ano passado podem não servir ao layout deste ano.

Bons padrões tornam a velocidade rotina. A equipe para de pensar em otimização porque o processo cuida disso automaticamente.

Mitos de velocidade que vale ignorar

Um mito diz que só a página inicial importa para a velocidade. Na realidade, os visitantes chegam nas postagens de blog e nas páginas de produto, e elas também precisam ser rápidas.

Outro mito diz que uma hospedagem rápida conserta imagens lentas. A hospedagem ajuda, mas uma imagem de 5 MB é lenta em qualquer hospedagem, e a otimização é o único conserto.

Um terceiro mito diz que só o WebP resolve tudo. O formato ajuda, mas as dimensões e o carregamento preguiçoso importam tanto quanto a escolha do formato.

A verdade é chata e prática: tamanho certo, formato certo, carregamento preguiçoso abaixo da dobra e dimensões em cada tag. Faça essas quatro coisas e a página vai ser rápida.

Teste suas próprias páginas para resolver a questão. Os números de velocidade não ligam para mitos e vão dizer o que realmente funciona.

Uma conferência final antes de publicar

Rode a ferramenta de velocidade uma última vez depois que todas as imagens forem otimizadas. Confirme que o peso total das imagens caiu e o tempo de carregamento melhorou.

Carregue a página num celular de verdade com conexão móvel. Os números de um teste de laboratório são úteis, mas a sensação no celular é a verdade.

Confira cada imagem visualmente mais uma vez. Uma página rápida com uma imagem principal borrada não é um sucesso, e uma prévia cuidadosa percebe isso.

Continue aprendendo com cada página

Cada página que você otimiza ensina alguma coisa. Anote qual predefinição funcionou, qual imagem foi mais difícil e o que os números de velocidade fizeram, pois essas lições se acumulam com cada página que você corrige e cada site que você melhora.

Essas anotações viram seu manual. A próxima página leva menos tempo porque a última já respondeu às perguntas.

Para o guia completo do otimizador, leia Otimizador de imagens para web: guia completo. Para o mergulho profundo no Core Web Vitals, veja Otimização de imagens para Core Web Vitals: LCP e tamanho de arquivo. Para alvos simples de tamanho, o compressor de 200 KB cobre a maioria das imagens de web.

Perguntas frequentes

Quanto mais rápido meu site vai ficar depois de otimizar as imagens?

Depende de quão pesadas as imagens eram. Uma página com 5 MB de imagens que cai para 500 KB pode carregar vários segundos mais rápido, principalmente no celular. Rode um teste de velocidade antes e depois para ver a melhora exata da sua página.

Devo otimizar as imagens antes ou depois de enviá-las para meu site?

Antes. Otimizar primeiro dá a você controle sobre dimensões, formato e qualidade, além da tag HTML pronta. Enviar primeiro e depender da plataforma para comprimir geralmente produz resultados piores.

Posso otimizar trinta imagens de blog num só lote?

Sim. Adicione as trinta imagens, escolha uma predefinição e baixe todas juntas. Veja a prévia de alguns resultados antes de baixar o lote inteiro e mantenha a predefinição consistente para as imagens ficarem uniformes no site.

Por que minha imagem principal continua lenta depois da otimização?

Confira se o carregamento preguiçoso está desligado para a imagem principal, pois atrasá-la prejudica a velocidade de carregamento. Confirme também se as dimensões da imagem principal combinam com o tamanho de exibição; uma imagem principal gigante desperdiça banda. Pré-carregar a imagem principal pode ajudar ainda mais.

Preciso atualizar o HTML quando substituo uma imagem?

Sim, se as dimensões ou o nome do arquivo mudaram. A tag HTML carrega a largura, a altura e a fonte, então uma tag desatualizada pode esticar a imagem ou quebrar o layout. Copie uma tag nova da ferramenta sempre que substituir uma imagem.

Qual tamanho de imagem devo usar para uma imagem de destaque de blog?

Combine com o tamanho de exibição do seu tema, geralmente 1200 pixels de largura ou menos. A predefinição de imagem principal ou de cartão cuida disso automaticamente. Servir uma imagem com o dobro da largura exibida desperdiça banda sem benefício visível.
