PNG para WebP com transparência mantida

Converta PNG para WebP e tenha arquivos menores com a transparência mantida. Logotipos, ícones, capturas e imagens de destaque — ajustes e melhores usos.

PNG é o formato de logotipos, ícones e capturas, mas também é um formato pesado. Uma imagem de destaque PNG pode pesar vários megabytes, enquanto a mesma imagem como WebP pesa uma fração disso.

Converter PNG para WebP mantém a transparência que torna o PNG útil e encolhe o arquivo drasticamente. É o melhor dos dois formatos numa só conversão.

Este guia explica como a conversão funciona, quais ajustes usar e quando o WebP é o destino certo para seus arquivos PNG.

O que é a conversão de PNG para WebP?

A conversão de PNG para WebP lê um arquivo PNG e reescreve ele como WebP. Os pixels continuam os mesmos, incluindo qualquer área transparente, mas o armazenamento fica bem mais eficiente.

O WebP suporta compressão com perda e sem perda. O conversor usa WebP com perda por padrão, o que encolhe os arquivos drasticamente e mantém eles com aparência limpa.

A transparência sobrevive à conversão. Um logotipo transparente continua transparente, e sombras suaves continuam suaves, sumindo aos poucos, que é a grande vantagem sobre converter para JPG.

O resultado é um arquivo que funciona em sites modernos, carrega mais rápido e parece idêntico ao PNG de onde veio.

Quanto menor o WebP fica que o PNG?

Para fotografias salvas como PNG, o WebP costuma ser de 60% a 80% menor. Uma foto PNG de 5 MB vira um WebP de 1 MB a 2 MB com 85% de qualidade.

Para logotipos e ícones, a economia é menor, mas ainda real, muitas vezes de 25% a 50%. Gráficos simples já comprimem bem como PNG, então sobra menos para o WebP economizar.

Para capturas com texto, o WebP economiza de 50% a 70% e mantém o texto legível. Essa combinação faz dele o ideal para imagens de blog e documentação.

O WebP sem perda economiza menos que o WebP com perda, mas ainda vence o PNG por 20% a 30%. Quando cada pixel precisa ser perfeito, o WebP sem perda é a menor cópia exata disponível.

A transparência é preservada

O WebP guarda um canal alfa igual ao PNG. Áreas transparentes continuam transparentes, e pixels parcialmente transparentes mantêm o nível exato de transparência.

Sombras suaves sobrevivem à conversão. Uma sombra que some aos poucos, de sólida para invisível, mantém o gradiente suave no WebP, algo que o JPG nunca faria.

Confira o resultado com a comparação lado a lado antes de baixar. Aproxime as bordas de um logotipo e confirme que a transparência está limpa, sem halos ou franjas.

Para logotipos que precisam funcionar em vários fundos, o WebP é o melhor formato para a web. Ele mantém a transparência num tamanho menor que o PNG, e todos os navegadores modernos exibem ele.

Ajustes de qualidade que funcionam

Para logotipos PNG transparentes, 85% a 90% de qualidade é o ponto ideal. O logotipo fica nítido, as bordas ficam limpas e o arquivo é bem menor que o PNG.

Para capturas PNG com texto, 85% mantém as letras legíveis e encolhe o arquivo bastante. Ajustes menores suavizam textos pequenos, então evite eles para documentação.

Para fotografias PNG, o ideal é de 80% a 85%. A foto fica limpa, e o arquivo é uma fração do tamanho do PNG.

Para imagens de destaque de um site, 80% equilibra bem tamanho e qualidade. A imagem preenche a tela, mas o arquivo continua pequeno o bastante para carregar rápido.

Converter conjuntos inteiros de ícones

Um conjunto de cinquenta arquivos PNG vira WebP num só lote. Cada arquivo é convertido separadamente, e o ZIP guarda todos prontos para enviar.

Use o mesmo ajuste de qualidade para o conjunto inteiro. A consistência importa quando os ícones aparecem juntos, já que qualidade misturada parece desigual.

Confira dois ou três ícones depois de converter, em vez de todos os cinquenta. Se esses estiverem bons, os outros também vão estar, já que os ajustes são os mesmos.

Arquivos de até 25 MB cada são aceitos, o que cobre até os maiores arquivos de ícone e renders de produto em alta resolução sem nenhuma preparação.

Capturas com texto

O WebP preserva o texto melhor que o JPG no mesmo tamanho de arquivo. Uma captura convertida para WebP com 85% mantém as letras legíveis, enquanto a versão JPG suaviza elas.

Isso faz do WebP a melhor escolha para capturas de blog, imagens de documentação e gráficos de tutorial, onde o texto é o conteúdo.

Para capturas em que cada letra precisa ficar perfeita, como evidência legal, considere WebP sem perda ou PNG. O WebP com perda é excelente, mas não perfeito.

Confira o menor texto com a comparação lado a lado antes de baixar. Aproxime menus e textos e confirme que eles leem com clareza.

Imagens de destaque para sites

Uma imagem de destaque é o banner grande no topo de uma página, e muitas vezes é a imagem mais pesada do site. Converter ela de PNG para WebP pode cortar o peso da página drasticamente.

O WebP é melhor que o PNG para imagens de destaque porque é menor com a mesma qualidade. Uma imagem de destaque PNG de 4 MB vira um WebP de 1 MB, e a página carrega segundos mais rápido.

O WebP é melhor que o JPG para imagens de destaque quando a transparência importa. Uma imagem de destaque com sobreposição transparente ou produto recortado precisa do canal alfa que o JPG não oferece.

Para uma imagem de destaque sem transparência, tanto WebP quanto JPG servem. O WebP é menor, enquanto o JPG é mais compatível, então escolha com base no seu público.

Metadados e perfis de cor

Converter PNG para WebP remove blocos de texto do PNG, como notas do software de criação e comentários. O canvas redesenha os pixels, e os metadados não sobrevivem.

Isso é bom para a privacidade. Um PNG compartilhado como WebP não carrega registro do software que criou ele nem da máquina de onde veio.

Perfis de cor são um ponto sutil. O conversor pode não preservar o perfil de cor do PNG com exatidão, então confira cores saturadas com o original antes de usar o resultado.

Para a maioria das imagens da web, a mudança de cor é invisível. Para trabalhos críticos de cor, como fotos de produto, compare o WebP com o PNG com cuidado.

Quando o WebP sai maior

Às vezes, um WebP convertido é maior que o PNG original. Isso acontece com imagens muito simples, onde o PNG já comprime as cores planas com eficiência.

Um ícone minúsculo com duas cores pode crescer um pouco como WebP, já que o formato adiciona um cabeçalho que o PNG não precisa para imagens simples.

Quando o WebP for maior, fique com o PNG. Não há regra dizendo que o WebP precisa vencer sempre, e o objetivo são arquivos menores, não um formato específico.

Confira os tamanhos de antes e depois em cada cartão. O conversor mostra os dois números, então dá pra decidir numa olhada.

PNG para WebP ou PNG para JPG?

Escolha WebP quando a imagem tem transparência ou vai viver num site. O WebP mantém o canal alfa e produz arquivos menores que o JPG com a mesma qualidade.

Escolha JPG quando o destino exigir. Formulários, impressoras e programas antigos muitas vezes listam JPG especificamente e recusam WebP.

Escolha WebP para capturas que vão para a web. O texto fica mais nítido que no JPG, e os arquivos são menores, o que faz as páginas carregarem mais rápido.

Escolha JPG para capturas que vão para um formulário ou um e-mail. A compatibilidade importa mais que o tamanho nesses casos, e o JPG abre em qualquer lugar.

Como conferir a qualidade antes de baixar

Clique em Comparar em qualquer cartão para ver o PNG e o WebP lado a lado. Arraste a barra divisória pela imagem para inspecionar transparência, texto e bordas.

Confira as áreas transparentes primeiro. Uma borda de logotipo com halo ou franja significa que a qualidade estava baixa demais, e subir cinco pontos costuma resolver.

Você pode mudar a qualidade depois da primeira conversão sem enviar de novo. O PNG original fica na fila, então experimente outro ajuste e compare de novo.

Para um lote, confira três ou quatro arquivos representativos em vez de todos. Se esses estiverem bons, os outros também vão estar, já que os ajustes são os mesmos.

Erros comuns que você deve evitar

O erro mais comum é usar qualidade baixa demais para logotipos. As bordas transparentes sofrem primeiro, então mantenha a qualidade em 85% ou mais para qualquer logotipo.

Outro erro é converter ícones minúsculos que já são pequenos. Um ícone PNG de 10 KB não ganha nada com a conversão, e a versão WebP pode ser maior.

Muita gente também esquece de conferir o perfil de cor. Uma foto de produto saturada pode mudar um pouco durante a conversão, e uma comparação rápida pega isso antes da imagem ir ao ar.

Por fim, não converta um PNG para WebP e depois de volta para PNG esperando economizar espaço. A ida e volta adiciona dano com perda e produz um arquivo pior que o original.

WebP para logotipos de sites

Um logotipo de site como WebP carrega mais rápido que o mesmo logotipo como PNG, mantendo a transparência. A economia é modesta por logotipo, mas um site com muitos ícones e logotipos soma rápido.

Converta o logotipo para WebP com 90% de qualidade. As bordas ficam nítidas, a transparência sobrevive e o arquivo fica de um quarto a metade menor que o PNG.

Confira o logotipo em fundos claros e escuros depois de converter. Um logotipo perfeito no branco pode mostrar uma franja leve no preto se a qualidade estava baixa demais.

Guarde o PNG original como reserva para navegadores mais antigos. O elemento picture serve WebP para navegadores modernos e PNG para o resto, então todo visitante vê o logotipo.

Para um logotipo que aparece em todas as páginas, a economia de velocidade importa mais. Um logotipo de cabeçalho carrega em cada visualização de página, então um arquivo menor melhora cada visita, não só a primeira.

WebP para ícones de aplicativos

Ícones de aplicativo aparecem em vários tamanhos, de um favicon minúsculo a uma listagem grande na loja. O WebP mantém eles nítidos em todos os tamanhos e usa menos armazenamento que o PNG.

Converta o conjunto de ícones para WebP com 90% de qualidade. A transparência sobrevive, as bordas ficam limpas e os arquivos são menores que os PNGs originais.

Teste os ícones em fundos claros e escuros antes de publicar. Um ícone que depende de fundo branco some num tema escuro, e a correção é uma versão transparente.

Para uma listagem na loja de aplicativos, confira as regras de formato da plataforma primeiro. Algumas lojas aceitam WebP, enquanto outras exigem PNG, e o formato precisa combinar com a lista da loja.

Guarde os PNGs originais na pasta do projeto depois de converter. Se uma loja ou plataforma recusar WebP, os PNGs estão prontos sem uma conversão nova.

WebP para imagens de blog

Imagens de blog são o caso clássico de uso do WebP. Um post com dez fotos carrega bem mais rápido como WebP, e os leitores ficam mais tempo em páginas rápidas.

Converta as fotos PNG do blog para WebP com 80% de qualidade. As imagens parecem idênticas, os arquivos encolhem dois terços e as páginas ficam visivelmente mais rápidas.

Para capturas de blog com texto, o WebP com 85% mantém as letras legíveis. O texto fica mais nítido que no JPG no mesmo tamanho, o que importa para imagens de tutorial.

Atualize as referências das imagens depois de converter e teste o post. Uma referência de imagem quebrada é pior que uma lenta, então confira cada imagem da página.

Guarde os PNGs originais na biblioteca de mídia como reserva. Se o navegador de um leitor não exibir WebP, a versão PNG carrega no lugar, e ninguém vê uma imagem quebrada.

WebP para e-commerce

Uma loja online vive ou morre pelas imagens dela. Centenas de fotos de produto, cada uma bem menor como WebP, fazem a diferença entre uma loja rápida e uma lenta.

Converta fotos de produto para WebP com 80% a 85% de qualidade. Os clientes dão zoom nos produtos, então a qualidade extra protege os detalhes que eles inspecionam.

Para miniaturas de produto, 75% de qualidade basta. As miniaturas são pequenas, a suavização é invisível e as páginas de categoria carregam na hora.

Teste a loja no celular depois de converter. Os compradores de celular são a maioria agora, e uma loja rápida numa conexão lenta converte bem mais que uma lenta.

Meça a velocidade da loja antes e depois da troca. Uma melhora concreta no tempo de carregamento justifica o trabalho de conversão para a equipe toda.

WebP para artes de redes sociais

Artes de redes sociais muitas vezes têm texto, e o WebP mantém esse texto mais nítido que o JPG no mesmo tamanho de arquivo. Uma arte de anúncio como WebP continua legível depois da compressão da plataforma.

Converta a arte para WebP com 85% de qualidade antes de enviar. A plataforma comprime mesmo assim, e uma entrada de alta qualidade dá um resultado melhor que uma de baixa qualidade.

Confira as dimensões preferidas da plataforma antes de converter. Instagram, Facebook e X têm tamanhos ideais diferentes, e o tamanho certo importa mais que o formato.

Para uma arte com transparência, como um adesivo ou uma sobreposição, o WebP é o único formato que mantém ela. O JPG não guarda transparência, então a arte ganharia um fundo sólido.

Baixe a versão da plataforma depois de enviar e confira. Uma olhada rápida no post publicado confirma que a imagem sobreviveu ao processamento da plataforma intacta.

Perguntas frequentes

A conversão de PNG para WebP mantém mesmo os fundos transparentes?

Sim. O WebP guarda um canal alfa igual ao PNG, então áreas transparentes continuam transparentes e sombras suaves continuam suaves, sumindo aos poucos. Confira o resultado com a comparação lado a lado antes de baixar, aproximando as bordas do logotipo para confirmar que não há halos ou franjas.

Quanto menor o WebP fica que o PNG para a mesma imagem?

Para fotografias salvas como PNG, o WebP costuma ser de 60% a 80% menor. Para logotipos e ícones, a economia é de 25% a 50%, já que gráficos simples já comprimem bem como PNG. Para capturas, a economia costuma ser de 50% a 70%, com o texto ainda legível.

Qual ajuste de qualidade funciona melhor para logotipos PNG transparentes?

De 85% a 90% é o melhor para logotipos, já que as bordas transparentes sofrem primeiro com qualidade menor. O logotipo fica nítido, as bordas ficam limpas e o arquivo é bem menor que o PNG. Baixe para 80% só para imagens de destaque grandes, onde a velocidade de carregamento importa mais que a perfeição das bordas.

Dá para converter um conjunto inteiro de ícones de PNG para WebP de uma vez?

Sim. Solte o conjunto inteiro no conversor, escolha um ajuste de qualidade e baixe o ZIP com todos os WebPs dentro. Use o mesmo ajuste para o conjunto todo, para os ícones parecerem consistentes juntos. Confira dois ou três ícones depois de converter, em vez de todos os cinquenta.

O WebP é melhor que o PNG para imagens de destaque de sites?

Sim, geralmente. Uma imagem de destaque convertida de PNG para WebP muitas vezes tem um terço do tamanho, sem diferença visível, o que faz a página carregar bem mais rápido. O WebP também mantém a transparência quando a imagem de destaque tem recorte ou sobreposição. Guarde o PNG só quando o destino exigir.

Por que meu WebP convertido ficou maior que o PNG original?

Isso acontece com imagens muito simples, como ícones minúsculos com duas cores, onde o PNG já comprime as áreas planas com eficiência. O WebP adiciona um cabeçalho que o PNG não precisa para imagens simples. Quando o WebP for maior, fique com o PNG.
