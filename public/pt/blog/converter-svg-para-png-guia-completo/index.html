Converter SVG para PNG: guia completo

Converta logotipos e ícones SVG para PNG em qualquer tamanho. Escala, transparência, fontes, gradientes e os limites — tudo explicado.

Um logotipo SVG pode ampliar para qualquer tamanho sem nunca ficar borrado, mas metade dos lugares onde você precisa dele não aceita SVG. Um formulário, um e-mail ou um programa antigo quer um PNG, e o SVG precisa virar pixels.

Converter SVG para PNG, chamado de rasterização, transforma as formas vetoriais numa grade fixa de pixels no tamanho que você escolher. O resultado é uma imagem comum que abre em qualquer lugar.

Este guia explica como a rasterização funciona, qual escala escolher e as armadilhas que pegam quem lida com fontes, imagens vinculadas e transparência.

O que é um arquivo SVG?

SVG significa Scalable Vector Graphics, gráficos vetoriais escaláveis. Ao contrário de uma foto, que guarda pixels, um SVG guarda instruções: desenhe um círculo aqui, uma linha ali, preencha esta forma de azul.

Como o arquivo descreve formas em vez de pixels, ele pode ampliar para qualquer tamanho sem perder nitidez. Um ícone de 24 pixels e um outdoor do mesmo SVG ficam perfeitos.

Arquivos SVG são texto, o que significa que dá para abrir um num editor de texto e ler o código. Isso também faz eles serem minúsculos para gráficos simples, muitas vezes só alguns kilobytes.

O formato é ideal para logotipos, ícones e ilustrações. É menos adequado para fotografias, que ficam melhor guardadas como pixels.

O que significa rasterizar?

Rasterizar transforma formas vetoriais numa grade de pixels. O conversor lê as instruções do SVG, desenha as formas num canvas e salva o resultado como PNG.

A escolha principal é o tamanho de saída. Um ícone de 24 pixels rasterizado em 1x vira um PNG de 24 pixels, enquanto o mesmo ícone em 4x vira um PNG de 96 pixels, nítido o bastante para telas de alta resolução.

Depois de rasterizado, a imagem é fixa. Um PNG de 96 pixels não pode ampliar para 500 pixels sem ficar borrado, ao contrário do SVG de onde veio.

Guarde sempre o SVG original. É a cópia principal, e dá para rasterizar ele de novo em qualquer tamanho sempre que precisar de um PNG diferente.

Como escolher a escala certa

Para um ícone de site, 2x ou 3x o tamanho de exibição geralmente basta. Um ícone de 24 pixels exibido numa tela retina quer um PNG de 48 ou 72 pixels para parecer nítido.

Para um logotipo num slide de apresentação, 4x dá uma margem confortável. Um logotipo pequeno ampliado no PowerPoint continua nítido quando o PNG tem pixels suficientes por trás.

Para impressão, vá ainda maior. Um logotipo impresso com 5 cm de largura precisa de pelo menos 600 pixels a 300 DPI, então escolha uma escala que alcance esse tamanho.

A escala de exportação é limitada a 8000 pixels no lado maior. Para a maioria dos ícones e logotipos, o limite nunca importa, já que um logotipo de 100 pixels em 4x tem só 400 pixels.

A transparência é preservada

Arquivos SVG muitas vezes têm fundos transparentes, e o PNG mantém essa transparência. Um logotipo rasterizado para PNG fica limpo em qualquer cor de fundo.

Confira o resultado com a comparação lado a lado antes de baixar. Aproxime as bordas do logotipo e confirme que a transparência está limpa, sem franja branca.

Se o SVG tiver um retângulo de fundo, esse retângulo vira parte do PNG. Remova a forma de fundo na sua ferramenta de design se quiser um resultado transparente.

Para um logotipo que precisa funcionar em vários fundos, a transparência é essencial. Guarde o SVG principal e rasterize um PNG transparente sempre que precisar de um.

Fontes e texto dentro do SVG

O texto dentro de um SVG depende de fontes, e o conversor pode não ter a fonte que seu SVG usa. Quando a fonte falta, o texto cai para uma fonte padrão, o que muda a aparência.

Fontes da web referenciadas dentro de um SVG não são carregadas durante a conversão. O navegador não consegue buscar elas no contexto de rasterização, então o texto é renderizado numa fonte reserva.

A correção é converter o texto em curvas na sua ferramenta de design antes de converter. Texto em curvas vira formas, não letras, então renderiza com exatidão, seja qual for a fonte.

Para um logotipo, texto em curvas já é o padrão profissional. Ele garante que as letras pareçam idênticas em qualquer lugar, em qualquer máquina.

Fotos vinculadas e arquivos externos

Um SVG pode referenciar um arquivo de imagem externo, como uma foto vinculada por URL. Essa imagem vinculada vai faltar no PNG, já que o conversor não consegue buscar ela.

O mesmo vale para arquivos CSS externos. Estilos definidos num arquivo separado não são carregados durante a conversão, então as formas podem renderizar sem as cores delas.

A correção é embutir tudo dentro do SVG antes de converter. Imagens devem ser URIs de dados, e estilos devem ser inline, para o arquivo ficar totalmente autocontido.

A maioria das ferramentas de design tem uma opção para embutir imagens ao exportar SVG. Use ela, e o PNG convertido vai combinar com o original com exatidão.

Gradientes, opacidade e efeitos

Gradientes dentro de um SVG renderizam certo durante a conversão. Uma transição suave de uma cor para outra vira uma transição suave no PNG.

A opacidade funciona também. Uma forma com 50% de opacidade aparece semitransparente no PNG, misturando com o que estiver atrás dela.

Filtros complexos, como desfoques e sombras definidos em SVG, geralmente renderizam também. O motor SVG do navegador lida com a maioria dos filtros padrão corretamente.

Efeitos bem exóticos podem não sobreviver. Se um filtro parecer errado no PNG, simplifique ele na ferramenta de design ou aceite a pequena diferença.

Converter um pacote de ícones em lote

Dá para converter um pacote inteiro de ícones SVG de uma vez. Cada arquivo é convertido separadamente, e o ZIP guarda todos prontos para usar.

Use a mesma escala para o pacote inteiro. A consistência importa quando os ícones aparecem juntos, já que tamanhos misturados parecem desiguais.

Arquivos de até 25 MB cada são aceitos, o que cobre até arquivos ilustrados enormes com milhares de caminhos. SVGs bem complexos só levam um ou dois segundos a mais para rasterizar.

Confira dois ou três ícones depois de converter, em vez de todos os cinquenta. Se esses estiverem bons, os outros também vão estar, já que os ajustes são os mesmos.

Quando usar PNG em vez de SVG

Use PNG quando o destino não aceitar SVG. Formulários, e-mails, programas antigos e muitas plataformas sociais querem imagens raster, não arquivos vetoriais.

Use PNG quando a imagem precisar parecer idêntica em qualquer lugar. Um SVG pode renderizar diferente em navegadores diferentes, enquanto um PNG parece igual em todos os aplicativos.

Use PNG para fotos de perfil e avatares em redes sociais. A maioria das plataformas converte envios para formatos raster mesmo assim, então fornecer um PNG dá controle sobre o resultado.

Guarde o SVG para a web e para edições futuras. O arquivo vetorial principal é aquele para o qual você volta sempre que precisar de outro tamanho ou outro formato.

A conversão muda as cores?

Converter SVG para PNG não muda as cores. As formas são desenhadas com os mesmos valores de cor, e o PNG guarda eles com exatidão.

Perfis de cor são a única sutileza. Um SVG com um perfil embutido pode renderizar um pouco diferente no PNG, embora a diferença geralmente seja invisível.

Para cores de marca, confira o PNG com o original. Abra os dois lado a lado e confirme que as cores combinam, principalmente para tons de marca saturados.

Se uma cor parecer errada, o problema geralmente é uma fonte faltando ou uma imagem vinculada, não a cor em si. Confira esses primeiro antes de culpar a conversão.

Tamanhos de arquivo depois da conversão

Um ícone SVG pequeno de 5 KB pode virar um PNG de 20 KB ou mais, dependendo da escala. Pixels custam mais bytes que instruções vetoriais, principalmente em tamanhos grandes.

O tamanho do PNG cresce com o quadrado da escala. Dobrar a escala quadruplica a quantidade de pixels, então um PNG 4x é dezesseis vezes maior que um PNG 1x.

Escolha a menor escala que atenda à necessidade. Um PNG 2x para um ícone de site já basta, e um PNG 4x para o mesmo ícone desperdiça bytes sem benefício visível.

Para um PNG grande de impressão, o tamanho é inevitável. Um arquivo de impressão a 300 DPI precisa de muitos pixels, e o PNG vai ser grande, o que está certo para impressão.

Problemas comuns e correções

Se um SVG não rasterizar e der erro, o arquivo pode ter recursos sem suporte ou código malformado. Abra ele no navegador primeiro para confirmar que renderiza lá.

Se o texto parecer errado, a fonte está faltando. Converta o texto em curvas na sua ferramenta de design e converta de novo.

Se uma foto vinculada estiver faltando, embuta ela como URI de dados dentro do SVG. O conversor não consegue buscar arquivos externos, então a imagem precisa viajar dentro do próprio SVG.

Se o PNG parecer borrado, a escala estava baixa demais. Rasterize de novo numa escala maior, já que um PNG de baixa resolução não pode ser afiado depois.

Logotipos SVG para redes sociais

Plataformas de redes sociais não aceitam envios SVG, então um logotipo precisa virar PNG antes de virar foto de perfil ou imagem de capa. Rasterizar no tamanho certo dá um resultado nítido.

Para uma foto de perfil, rasterize em 400 por 400 pixels. A imagem fica nítida no computador e no celular, e o arquivo continua pequeno o bastante para enviar rápido.

Para uma imagem de capa, rasterize no tamanho recomendado da plataforma. Facebook, X e LinkedIn têm dimensões de capa diferentes, e o tamanho certo importa mais que o formato.

Confira o logotipo depois de converter, já que as plataformas cortam fotos de perfil em círculos. Um logotipo com detalhes importantes perto das bordas pode perder eles no corte circular.

Guarde o SVG original para a próxima plataforma. Uma rede social nova com tamanhos diferentes precisa só de uma rasterização nova, não de um redesign.

Ícones SVG para aplicativos

Ícones de aplicativo começam como arquivos SVG na ferramenta de design e viram PNGs para as lojas de aplicativos. Cada loja tem seus próprios requisitos de tamanho, então um SVG produz muitos PNGs.

Rasterize o ícone em 1024 por 1024 pixels para a App Store e depois reduza para tamanhos menores. Um arquivo principal grande produz resultados nítidos em todos os tamanhos menores.

Para Android, rasterize nos tamanhos que a Play Store lista, geralmente 512 por 512 para o ícone da loja e tamanhos menores para o launcher. O mesmo SVG serve para todos.

Teste os ícones em fundos claros e escuros antes de enviar. Um ícone que depende de fundo branco some num tema escuro, e a correção é uma versão transparente.

Guarde os SVGs originais no repositório do projeto. São os recursos de origem, e cada versão para cada plataforma vem deles, então merecem controle de versão.

SVG para materiais impressos

Materiais impressos, como cartões de visita, panfletos e pôsteres, precisam de imagens em alta resolução, e o SVG é a fonte ideal. Rasterize a 300 DPI para uma impressão nítida.

Para um logotipo de cartão de visita, rasterize em 4x o tamanho do SVG. Um logotipo pequeno ampliado na impressão continua nítido quando o PNG tem pixels suficientes por trás.

Para um pôster, rasterize na maior escala que a ferramenta permite, até o limite de 8000 pixels. Uma impressão grande precisa de muitos pixels, e o limite raramente restringe trabalhos reais de pôster.

Confira as cores depois de converter, já que cores de impressão diferem das cores de tela. Uma impressão de teste rápida confirma que as cores da marca parecem certas no papel.

Envie o PNG para a gráfica com o SVG como backup. A gráfica pode rasterizar o próprio SVG se o PNG tiver um problema, então fornecer os dois cobre todos os casos.

SVG para assinaturas de e-mail

Assinaturas de e-mail precisam de um logotipo pequeno, e o SVG não é suportado na maioria dos clientes de e-mail. Rasterize o logotipo para PNG num tamanho pequeno, geralmente de 100 a 200 pixels de largura.

Mantenha o arquivo PNG pequeno, abaixo de 50 KB se possível. Um logotipo grande em cada e-mail desperdiça banda e irrita os destinatários, enquanto um pequeno carrega na hora.

Hospede o logotipo no seu site e crie um link na assinatura, em vez de anexar. Uma imagem com link carrega do seu servidor, mantendo o e-mail pequeno.

Teste a assinatura em vários clientes de e-mail antes de lançar. Um teste rápido no Gmail, Outlook e Apple Mail pega as imagens quebradas antes dos seus contatos.

Para um logotipo com transparência, o PNG mantém ela. O logotipo da assinatura fica limpo em qualquer fundo de e-mail, enquanto uma versão JPG mostraria uma caixa branca.

SVG para favicons

Um favicon é o ícone minúsculo na aba do navegador e geralmente começa como um logotipo SVG. Rasterize ele em 16, 32 e 48 pixels para os tamanhos padrão de favicon.

Navegadores modernos também aceitam favicons SVG direto, então talvez você nem precise converter. Confira o suporte dos navegadores para o seu público antes de decidir.

Para navegadores mais antigos, o favicon PNG é a escolha segura. Um PNG de 32 pixels funciona em todos os navegadores, enquanto um favicon SVG pode falhar num antigo.

Crie o favicon de forma simples, já que tamanhos minúsculos escondem detalhes. Um logotipo complexo com 16 pixels vira um borrão, enquanto uma forma simples continua reconhecível.

Teste o favicon em vários navegadores depois de adicionar. Uma checagem rápida confirma que ele exibe certo, então o site parece caprichado em todas as abas.

Perguntas frequentes

Qual escala devo escolher para transformar um ícone de 24 px num PNG nítido?

Use 4x para um PNG de 96 px, que fica nítido em telas retina e em apresentações. Para um ícone de site, 2x ou 3x geralmente basta. Para impressão, escolha uma escala que alcance pelo menos 300 DPI no tamanho impresso. A exportação é limitada a 8000 px no lado maior, o que raramente importa.

A conversão de SVG para PNG mantém o fundo transparente?

Sim. Arquivos SVG com fundos transparentes produzem PNGs transparentes, então um logotipo fica limpo em qualquer cor de fundo. Se o SVG tiver um retângulo de fundo, esse retângulo vira parte do PNG, então remova ele na sua ferramenta de design primeiro, se quiser transparência.

Por que uma foto vinculada está faltando no meu PNG convertido?

O conversor não consegue buscar arquivos externos durante a conversão, então qualquer imagem vinculada por URL fica de fora. Embuta a imagem como URI de dados dentro do SVG antes de converter, para o arquivo ficar totalmente autocontido. A maioria das ferramentas de design tem uma opção para embutir imagens ao exportar SVG.

Dá para usar uma fonte da web dentro de um SVG para exportar PNG?

Não com confiança. Fontes da web referenciadas dentro de um SVG não são carregadas durante a conversão, então o texto cai para uma fonte padrão. Converta o texto em curvas na sua ferramenta de design antes de converter, para as letras virarem formas e renderizarem com exatidão, seja qual for a fonte.

Qual é o maior PNG que um SVG pode produzir?

A escala de exportação é limitada a 8000 px no lado maior, então um SVG bem grande em 4x para nesse teto. Para a maioria dos ícones e logotipos, o limite nunca importa, já que um logotipo de 100 px em 4x tem só 400 px. Para trabalho de impressão, confira se o tamanho limitado ainda atende às suas necessidades de DPI.

O PNG de saída é sem perda?

Sim. O PNG é um formato sem perda, então os pixels rasterizados são guardados com exatidão como foram desenhados. O PNG não pode ser mais nítido que a rasterização, porém, já que as formas vetoriais são fixadas em pixels na escala escolhida. Para um resultado mais nítido, rasterize de novo numa escala maior a partir do SVG original.
