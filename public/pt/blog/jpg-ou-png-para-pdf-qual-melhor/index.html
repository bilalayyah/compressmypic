JPG ou PNG para PDF: qual é melhor?

Para o seu PDF, é melhor usar JPG ou PNG? Compare tamanho, nitidez do texto e transparência e veja os melhores ajustes para cada tipo de documento.

Quando você cria um PDF a partir de imagens, o formato dessas imagens importa mais do que a maioria espera. Uma página JPG e uma página PNG podem parecer idênticas na tela e se comportar de forma bem diferente.

A escolha afeta o tamanho do arquivo, a nitidez do texto e a forma como o PDF imprime. Para um álbum de fotos, um formato ganha; para um contrato digitalizado, o outro ganha.

Este artigo compara JPG e PNG dentro de PDFs, para você escolher o formato certo antes de gerar, não depois. Depois de decidir, o Imagem para PDF junta as suas imagens num só documento, na ordem que você quiser, direto no navegador.

Imagens JPG dentro de um PDF

O JPG é um formato com perda, o que significa que ele descarta detalhe para encolher o arquivo. Dentro de um PDF, uma página JPG guarda a foto com essa mesma compressão, mantendo o documento pequeno.

As fotos comprimem muito bem como JPG. Uma fotografia de página inteira com 85 por cento de qualidade parece limpa e mantém o PDF leve o bastante para enviar por e-mail.

O ponto fraco é o texto. As letras pequenas e as linhas nítidas ficam com bordas suaves no JPG, porque a compressão borra os limites de alto contraste. Uma página digitalizada de letras miúdas sofre primeiro.

Use JPG dentro de PDFs para fotografias, álbuns de fotos e qualquer página em que a imagem importe mais que o texto nela.

Imagens PNG dentro de um PDF

O PNG é um formato sem perda, então cada pixel é guardado exatamente. Dentro de um PDF, uma página PNG é uma cópia perfeita da imagem original, sem nenhum dano de compressão.

Texto e arte em linha ficam perfeitamente nítidos em PNG. Um contrato digitalizado, um formulário ou um diagrama parece exatamente tão limpo no PDF quanto na digitalização original.

O preço é o tamanho do arquivo. Uma fotografia detalhada guardada como PNG pode ser várias vezes maior que a mesma foto em JPG, e um PDF longo de fotos PNG fica pesado rápido.

Use PNG dentro de PDFs para documentos digitalizados, formulários, recibos e qualquer página em que o texto legível seja a prioridade.

Tamanho de arquivo: a grande diferença

Um álbum de fotos de dez páginas feito com JPGs pode pesar 3 MB, enquanto o mesmo álbum feito com PNGs pode pesar 15 MB ou mais. Essa diferença importa para anexos de e-mail e conexões lentas.

A diferença encolhe para imagens simples. Um formulário digitalizado quase todo branco comprime bem como PNG, porque áreas chapadas grandes custam pouco para guardar sem perda.

Ela cresce para fotos detalhadas. Uma paisagem cheia de detalhes ou um retrato em grupo tem textura sem fim, e o PNG precisa descrever cada pixel dela exatamente.

Se o PDF precisar ficar abaixo de um limite de e-mail, o JPG é a escolha prática. Se o tamanho não importar, o PNG dá o resultado mais nítido.

Nitidez do texto: onde o PNG ganha

O texto digitalizado é o caso mais claro para o PNG. As letras são formas de alto contraste, e a compressão JPG borra as bordas delas, deixando as letras miúdas mais difíceis de ler.

Com qualidade JPG alta, o borrão é leve, mas continua lá. Com qualidade média, as letras miúdas podem ficar realmente difíceis de ler, principalmente depois de imprimir.

O PNG mantém cada borda nítida. Uma assinatura, um carimbo ou um bilhete manuscrito continua exatamente tão nítido quanto a digitalização, o que importa para documentos oficiais.

Para qualquer documento que será lido em vez de admirado, o PNG é o formato mais seguro. O arquivo é maior, mas as palavras são o objetivo.

Documentos de foto: retratos e fotos de identidade

Fotos de identidade e retratos são fotografias, então o JPG é a escolha natural. Os tons de pele e os degradês suaves comprimem bem, e o arquivo fica pequeno.

Uma foto de passaporte dentro de um PDF não precisa de armazenamento sem perda. O rosto continua reconhecível com 85 por cento de qualidade JPG, e o PDF continua fácil de enviar.

O PNG só ajuda para fotos de identidade quando a foto tem texto nítido sobreposto, como um nome impresso sobre a imagem. Nesse caso raro, o PNG mantém o texto nítido.

Para um conjunto de fotos de identidade, o JPG mantém o PDF leve e os rostos claros. Essa é a combinação que a maioria dos sistemas de envio espera.

Documentos digitalizados: contratos e formulários

Um contrato digitalizado é quase todo texto sobre papel branco. O PNG guarda isso com eficiência, já que áreas brancas grandes custam quase nada em um formato sem perda.

O texto fica nítido, a assinatura fica legível e o carimbo fica claro. Uma digitalização JPG da mesma página suavizaria os três.

As digitalizações de documentos antigos ou desbotados ganham ainda mais. Marcas fracas de lápis e carimbos claros são exatamente os detalhes que a compressão JPG destrói primeiro.

Para qualquer digitalização que precise ser lida, arquivada ou enviada oficialmente, crie o PDF a partir de arquivos PNG. O tamanho extra é um preço justo pela legibilidade.

Transparência: o que acontece com ela

Nenhum dos dois formatos mantém a transparência dentro de um PDF do jeito que você pode esperar. As áreas transparentes de um PNG viram branco quando o PDF é gerado, porque a página do PDF precisa de um fundo.

Para a maioria dos documentos, o branco está certo. Um logotipo transparente sobre uma página branca parece exatamente como deve, e imprime limpo.

Se você precisar de um logotipo sobre um fundo colorido, converta o PNG para JPG primeiro com uma cor de preenchimento correspondente. O conversor de PNG para JPG deixa você escolher a cor exata de preenchimento.

As fotografias nunca têm transparência, então isso só importa para logotipos e gráficos. Para documentos comuns, você pode ignorar.

Ajustes de qualidade para cada formato

Para páginas JPG, defina o controle de qualidade do PDF como alto para documentos com texto, e como médio para álbuns de fotos. O alto mantém as letras miúdas legíveis; o médio mantém os PDFs de fotos pequenos.

Para páginas PNG, o controle de qualidade tem menos efeito, já que o PNG não tem perda. O PDF ainda comprime os dados da imagem, mas os pixels em si são guardados exatamente.

Uma regra prática: JPG com 85 por cento para fotos, PNG em qualquer ajuste para texto. Essa combinação cobre quase todos os documentos que você vai criar.

Gere sempre uma vez e confira o resultado. Abra o PDF, dê zoom no menor texto e confirme que ele lê limpo antes de enviar.

Lotes misturados: fotos e digitalizações juntas

Os documentos reais costumam ser misturados. Um pedido de visto pode conter uma foto JPG, uma digitalização PNG de um passaporte e uma digitalização JPG de um extrato bancário.

O criador de PDF aceita formatos misturados em um documento só. Cada página mantém o formato original dela, então você não precisa converter tudo para um formato só antes.

Converta só as páginas que precisam. Transforme uma foto PNG em JPG para economizar espaço, mas deixe uma digitalização PNG quieta para o texto dela continuar nítido.

Confira o tamanho final do arquivo depois de gerar. Se estiver grande demais, as páginas de foto são o melhor lugar para economizar espaço, não as páginas de texto.

Qual formato você deve escolher?

Escolha JPG quando as páginas forem fotografias. Álbuns, portfólios e fotos de identidade combinam com JPG, e o PDF fica pequeno e fácil de compartilhar.

Escolha PNG quando as páginas forem documentos. Contratos, formulários, recibos e digitalizações combinam com PNG, e o texto fica nítido em qualquer nível de zoom.

Escolha uma mistura quando o documento tiver os dois. Fotos em JPG e digitalizações em PNG dão o melhor dos dois mundos em um único PDF.

Na dúvida, pergunte o que o leitor vai fazer. Se ele vai ler, use PNG. Se ele vai olhar, use JPG.

Três exemplos reais

Um estudante enviando uma digitalização de tese usa páginas PNG em A4 com posicionamento Ajustar. Cada página é legível, e o PDF imprime limpo para o professor.

Um fotógrafo enviando um portfólio usa páginas JPG com Ajustar ao tamanho da imagem. As fotos parecem ricas, o arquivo é pequeno o bastante para enviar por e-mail, e nenhum cliente reclama do tempo de download.

Um freelancer faturando um cliente usa PNG para os recibos digitalizados e JPG para a foto do trabalho entregue. O PDF misturado é nítido onde importa e pequeno onde conta.

Cada exemplo segue a mesma regra: texto ganha PNG, fotos ganham JPG, e o documento serve o leitor primeiro.

Dicas de fluxo de trabalho para PDFs melhores

Prepare as suas imagens antes de criar o PDF. Converta fotos PNG para JPG quando o tamanho importar, e converta digitalizações JPG para PNG só quando precisar editar elas várias vezes.

Dê aos seus arquivos originais nomes na ordem das páginas, como 01-passaporte.png e 02-foto.jpg. O criador acrescenta os arquivos na ordem em que você escolhe eles, e nomes numerados evitam erros.

Gere uma vez, confira e gere de novo se precisar. O controle de qualidade e os ajustes de posicionamento são rápidos de mudar, e uma segunda geração custa só segundos.

Guarde as imagens originais depois de gerar. Se o destinatário pedir outro tamanho de página ou um arquivo menor, você pode reconstruir a partir dos originais sem digitalizar nada de novo.

Resolução e DPI dentro de PDFs

A resolução decide o quanto uma imagem parece nítida quando impressa a partir de um PDF. Uma página feita com uma imagem de 150 DPI parece boa na tela, mas suave no papel, enquanto uma imagem de 300 DPI imprime nítida.

A maioria das fotos de celular e das digitalizações tem resolução alta o bastante para ver na tela. Elas só viram problema quando impressas em tamanhos grandes, em que os pixels esticam demais.

JPG e PNG lidam com a resolução do mesmo jeito dentro de um PDF. O formato não define o DPI, a contagem de pixels define, então um JPG de alta resolução imprime tão nítido quanto um PNG de alta resolução.

Confira as dimensões em pixels das suas imagens originais antes de criar. Uma imagem de 1000 pixels de largura impressa em uma página A4 tem cerca de 120 DPI, o que é aceitável, mas não excelente.

Para documentos que serão impressos, use as fontes de maior resolução que você tem. Uma fonte nítida faz um PDF nítido, seja o formato JPG ou PNG.

Cor: páginas RGB vs. tons de cinza

A maioria das imagens é RGB, com cor total, enquanto algumas digitalizações são em tons de cinza, com só tons de cinza. A escolha afeta o tamanho do arquivo e a legibilidade.

As digitalizações em tons de cinza são menores que as digitalizações em cores, já que guardam um valor por pixel em vez de três. Um contrato em tons de cinza costuma ter metade do tamanho da versão em cores.

A cor importa para carimbos, assinaturas e texto destacado. Um carimbo vermelho em tons de cinza parece cinza, o que pode reduzir o valor dele como prova, então mantenha a cor para documentos oficiais.

O JPG lida bem com tons de cinza, comprimindo o canal único bem. O PNG também lida, embora o arquivo seja maior, já que o armazenamento sem perda não consegue descartar a textura do papel.

Para um documento que precisa ser lido em vez de admirado, o JPG em tons de cinza com alta qualidade é a escolha prática. Ele é pequeno, nítido e honesto sobre o que o documento contém.

Quando converter fotos antes de criar

Às vezes as imagens originais precisam ser convertidas antes de entrar no PDF. Uma foto PNG de 12 MB vai inchar o PDF, enquanto a mesma foto em JPG tem 1 MB.

Converta fotos PNG para JPG antes de criar quando o PDF precisar ficar pequeno. O conversor de PNG para JPG encolhe elas drasticamente com pouca mudança visível.

Converta fotos HEIC para JPG primeiro se o criador de PDF tiver dificuldade com elas. O conversor de HEIC para JPG produz arquivos padrão que qualquer ferramenta consegue lidar.

Não converta digitalizações PNG para JPG antes de criar. O texto da digitalização é o conteúdo, e a compressão JPG suaviza ele, enquanto o PNG mantém ele nítido no PDF.

A regra é simples: converta fotos por tamanho, mantenha as digitalizações em PNG por nitidez. Essa divisão dá o menor PDF que ainda lê limpo.

Limites de tamanho de arquivo em portais de envio

A maioria dos portais de envio limita o tamanho do PDF a 5 MB, 10 MB ou 25 MB. Um PDF longo de digitalizações de alta qualidade pode passar fácil do menor desses limites.

As páginas JPG ajudam aqui, já que comprimem bem melhor que as páginas PNG. Um documento de fotos de dez páginas em JPG pode ter 3 MB, enquanto o mesmo documento em PNG pode ter 15 MB.

Se o PDF estiver grande demais, baixe o controle de qualidade um passo e gere de novo. As fotos comprimem bem com qualidade média, enquanto as digitalizações precisam de um toque mais suave.

Divida um documento muito longo em dois PDFs se o tamanho continuar acima do limite. Dois arquivos de 8 MB cada passam por um limite de 10 MB, enquanto um arquivo de 16 MB não passa.

Confira sempre as regras do portal antes de gerar. O limite de tamanho, o tamanho da página e os formatos aceitos geralmente estão na página de envio, e ler eles economiza uma reconstrução.

Como digitalizar com o DPI certo

O DPI decide o quanto uma digitalização parece nítida quando impressa a partir de um PDF. Uma digitalização com 150 DPI parece boa na tela, mas suave no papel, enquanto uma digitalização com 300 DPI imprime nítida.

A maioria dos documentos precisa de 200 a 300 DPI. As digitalizações de texto com 200 DPI são legíveis, enquanto 300 DPI é melhor para documentos com letras miúdas ou assinaturas finas.

As fotos precisam de DPI maior quando impressas grandes. Uma foto digitalizada com 300 DPI imprime bem no tamanho original dela, mas uma impressão maior precisa de uma digitalização de maior resolução.

DPI maior significa arquivos maiores, tanto em JPG quanto em PNG. Uma digitalização com 600 DPI é quatro vezes maior que uma com 300 DPI, então escolha o menor DPI que atenda a necessidade.

Para documentos que só serão vistos na tela, 150 DPI basta. A tela não consegue mostrar mais detalhe que a própria resolução dela, então DPI extra só desperdiça bytes.

A escolha de formato é uma decisão pequena com um resultado visível. Fotos querem JPG, documentos querem PNG, e documentos misturados querem os dois.

Perguntas frequentes

Dá para misturar imagens JPG e PNG no mesmo PDF?

Sim. O criador de PDF aceita formatos misturados, e cada página mantém o formato original dela. Na verdade, essa é a melhor abordagem para documentos misturados: fotos em JPG para economizar espaço e digitalizações em PNG para manter o texto nítido. Não precisa converter tudo para um formato só antes.

Por que o meu PDF com fotos PNG é bem maior que com JPG?

O PNG guarda cada pixel exatamente, então uma fotografia detalhada precisa de bem mais dados que a mesma foto em JPG. A diferença é maior para fotos cheias de detalhes e menor para digitalizações simples. Se o tamanho importar, converta as páginas de foto para JPG antes de criar o PDF e deixe o PNG só para as páginas de texto.

JPG ou PNG imprime melhor a partir de um PDF?

O PNG imprime texto e arte em linha com mais nitidez, enquanto o JPG imprime fotos tão bem quanto, com alta qualidade. Para um documento que vai ser impresso e lido, o PNG é melhor. Para um álbum de fotos que vai ser impresso e admirado, o JPG com alta qualidade serve.

Devo converter as minhas digitalizações JPG para PNG antes de fazer um PDF?

Só se você precisar editar elas de novo. Converter uma digitalização JPG para PNG não restaura o detalhe que o JPG já perdeu, e deixa o arquivo bem maior. Para um trabalho direto de digitalização para PDF, use o JPG como está e deixe o controle de qualidade alto.

Qual é o melhor formato para uma assinatura digitalizada em um PDF?

O PNG é o melhor para assinaturas, porque as linhas finas da caligrafia continuam nítidas. Uma assinatura em JPG pode parecer difusa nas bordas, principalmente depois de imprimir. Digitalize a assinatura em PNG, mantenha uma boa resolução e coloque com Ajustar para não cortar nada.

Dá para reduzir o tamanho de um PDF feito com imagens PNG?

Sim. Baixe o controle de qualidade ao gerar, ou converta as páginas de foto para JPG antes de criar. As páginas de texto devem continuar em PNG, mas as páginas de foto podem passar para JPG com 85 por cento de qualidade com pouca mudança visível. Essa combinação muitas vezes reduz o tamanho do arquivo pela metade.
