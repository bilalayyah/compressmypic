Base64 سے امیج کیسے استعمال کریں

اپنا کام براہِ راست اپنے براؤزر میں مکمل کرنے کے لیے ان آسان مراحل پر عمل کریں۔

1

اپنی Base64 اسٹرنگ یا ڈیٹا URL پیسٹ کریں

مکمل data:image/...;base64,... اسٹرنگ یا خام Base64 حروف Paste Base64 String or Data URL باکس میں پیسٹ کریں۔

2

خودکار ڈی کوڈنگ کا انتظار کریں (یا Decode Image پر کلک کریں)

ڈی کوڈر پیسٹ کرتے ہی (یا Decode Image پر کلک کرنے پر) وائٹ اسپیس، URL-safe حروف اور میجک ہیڈر بائٹس کو فوراً پڑھ کر تصویر کی توثیق کرتا ہے۔

3

پیش نظارہ، فارمیٹ، سائز اور جسامت دیکھیں

ڈی کوڈ شدہ گرافک شفافیت چیکر بورڈ پر Valid Image Decoded بیج، Detected Format، Binary Size اور پکسل Width × Height کے ساتھ دیکھیں۔

4

ڈاؤن لوڈ فارمیٹ منتخب کریں

ڈی کوڈ شدہ بائنری فائل کو بالکل ویسے ہی محفوظ کرنے کے لیے Original منتخب کریں، یا ایکسپورٹ پر تصویر تبدیل کرنے کے لیے PNG، JPG یا WEBP چنیں۔

5

ڈی کوڈ شدہ تصویر فائل ڈاؤن لوڈ کریں

Download Image File پر کلک کر کے decoded_image.<ext> براہ راست اپنے آلے پر محفوظ کریں، یا دوسرا پے لوڈ آزمانے کے لیے ان پٹ باکس کے اوپر Clear پر کلک کریں۔
