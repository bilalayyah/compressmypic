تصاویر: ایمبیڈ نہ کریں

آرائشی گریڈینٹ اور شکلیں خالص CSS کے طور پر اور بھی بہتر ہیں، بغیر کسی تصویر کے۔ CSS میں لکھا گریڈینٹ چند درجن حروف لیتا ہے اور مکمل اسکیل ہوتا ہے۔

جب پس منظر تصویر CSS میں ایمبیڈ ہو تو اسے اسٹائل شیٹ سے الگ کیش نہیں کیا جا سکتا۔ CSS کی ایک لائن بدلیں اور براؤزر کو ہر ایمبیڈ شدہ تصویر دوبارہ ڈاؤن لوڈ کرنی پڑتی ہے۔

HTML ای میل: چھوٹی ایمبیڈ کریں، بڑی لنک کریں

لوگو اور چھوٹی آرائشی تصاویر ایمبیڈ کریں جو پیغام کو پہچاننے کے قابل بناتی ہیں۔ یہ وہ تصاویر ہیں جو ای میل کے درست لگنے کے لیے ظاہر ہونی چاہیے۔

بڑی تصاویر کو اس کے بجائے لنک کریں، یا انہیں مکمل چھوڑ دیں۔ بھاری ایمبیڈ شدہ تصویر فون پر پیغام کو آہستہ کھولتی ہے، اور کچھ کلائنٹ ایسے پیغامات مسترد کر دیتے ہیں۔

یہاں فیصلہ ایمبیڈ بمقابلہ لنک نہیں، بلکہ یہ ہے کہ تصویر پے لوڈ میں ہے یا نہیں۔ چھوٹا اوتار یا دستخط تصویر ٹھیک بیٹھتی ہے، جبکہ کئی میگا بائٹ والی تصویر نہیں بیٹھتی۔

پے لوڈ سائز کی حد پر نظر رکھیں۔ بہت سی API درخواستیں چند میگا بائٹ تک محدود کرتی ہیں، اور 2 MB تصویر 2.7 MB اسٹرنگ بن جاتی ہے جو اکیلی حد سے تجاوز کر سکتی ہے۔

Base64 ایمبیڈنگ کے متبادل
