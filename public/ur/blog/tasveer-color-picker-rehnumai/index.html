اس کا مطلب یہ بھی ہے کہ صفحہ لوڈ ہونے کے بعد ٹول آف لائن کام کرتا ہے۔ آپ ہوائی جہاز پر، میٹنگ روم میں، یا کنکشن کے بغیر کہیں بھی رنگ نمونہ لے سکتے ہیں۔

گریڈینٹ اور نمونوں سے رنگ نمونہ لینا

گریڈینٹ خاص صورت ہیں، کیونکہ رنگ ایک سرے سے دوسرے تک ہموار بدلتا ہے۔ گریڈینٹ میں کوئی ایک درست رنگ نہیں، صرف وہ رنگ جو آپ کے نمونہ لینے والے بالکل نقطے پر ہے۔

گریڈینٹ پکڑنے کے لیے اس کی لمبائی کے ساتھ کئی نقطے نمونہ لیں۔ شروع رنگ، درمیان رنگ، اور آخر رنگ چنیں، اور آپ ان تین سٹاپ سے CSS میں گریڈینٹ دوبارہ بنا سکتے ہیں۔

نمونوں کو اسی احتیاط کی ضرورت ہے۔ دھاری دار یا چیکر سطح میں کم از کم دو رنگ ہوتے ہیں، اور پکر صرف آپ کے کرسر کے نیچے پکسل پڑھتا ہے، نمونہ کو مجموعی طور پر نہیں۔

تصویر رنگ پکر کیسے استعمال کریں

اپنے براؤزر میں تصویر رنگ پکر کھولیں۔ اپنی تصویر اپ لوڈ والے حصے میں گھسیٹ دیں، یا کلپ بورڈ سے اسکرین شاٹ سیدھا چسپاں کریں۔

جیسے ہی تصویر لوڈ ہوتی ہے، پہلے سے طے شدہ رنگ دکھائی دیتا ہے، تصویر کے مرکز سے نمونہ لیا گیا۔ اپنا کرسر منتقل کر کے دریافت کریں، اور لوپ کو اپنے پوائنٹر کے نیچے پکسل میں زوم کرتے دیکھیں۔

اپنے Picked Swatches میں شامل کرنے کے لیے کسی بھی پکسل پر کلک کریں۔ اپنے ڈیزائن کے لیے چاہیے رنگوں کا مکمل سیٹ جمع کرنے کے لیے کلک کرتے رہیں۔

جب آپ کا مجموعہ مکمل ہو تو رنگوں کو اسٹائل شیٹ متغیر کے طور پر ڈاؤن لوڈ کرنے کے لیے Export CSS پر کلک کریں۔ پھر قدم بہ قدم ورژن How to Pick a Color from an Image میں پڑھیں، یا کوڈ فارمیٹ HEX vs RGB vs HSL: Colour Codes Explained میں سیکھیں۔

عمومی سوالات

رنگ چننے اور پیلیٹ نکالنے میں کیا فرق ہے؟

چننا ایک بالکل پکسل پڑھتا ہے جسے آپ چنتے ہیں، اس لیے آپ بالکل کنٹرول کرتے ہیں کہ آپ کو کون سا رنگ ملتا ہے۔ نکالنا پوری تصویر اسکین کرتا ہے اور اس کے سب سے عام رنگ خود بخود درجہ دیتا ہے۔ برانڈ کے بالکل رنگوں کے لیے پکر استعمال کریں اور تصویر سے تیار پیلیٹ چاہنے پر ایکسٹریکٹر استعمال کریں۔

ایک ہی حصے پر دو کلک تھوڑے مختلف HEX کوڈ کیوں دیتے ہیں؟

تصویروں میں پڑوسی پکسل شاذ ہی ایک جیسے ہوتے ہیں کیونکہ کیمرہ شور اور JPEG کمپریشن ہے۔ ہر پکسل اپنا رنگ رکھتا ہے، اس لیے ایک پکسل طرف منتقل کرنے سے آخری ہندسہ بدل سکتا ہے۔ چپٹے حصے کے درمیان کو نمونہ لیں اور وہ قیمت چنیں جو سب سے زیادہ بار دکھائی دے۔

کیا چنے ہوئے رنگ سیدھے ویب سائٹ اسٹائل شیٹ میں استعمال کر سکتا ہوں؟

جی ہاں۔ Export CSS بٹن آپ کے سویچ کو HEX قیمتوں والی CSS کسٹم پراپرٹی کے طور پر ڈاؤن لوڈ کرتا ہے۔ انہیں اپنی اسٹائل شیٹ میں چسپاں کریں اور متغیر کو کہیں بھی استعمال کریں جہاں آپ کو وہ رنگ چاہیے۔ HEX کوڈ کسی بھی ڈیزائن ٹول میں بھی کام کرتے ہیں جو چسپاں شدہ رنگ قیمتیں قبول کرے۔

کیا رنگ پکر میری تصویر بدلتا یا کمپریس کرتا ہے؟

نہیں۔ ٹول صرف پکسل قیمتیں پڑھتا ہے اور آپ کی فائل کو کبھی ترمیم، دوبارہ محفوظ، یا کمپریس نہیں کرتا۔ آپ کی اصل تصویر اچھوتی رہتی ہے، اور آپ صفحہ بند کر سکتے ہیں یہ جانتے ہوئے کہ آپ کے آلے پر فائل بالکل ویسی ہی ہے جیسی تھی۔

جس ویب سائٹ سے تصویر ڈاؤن لوڈ نہیں کر سکتا، اس سے رنگ کیسے چنوں؟

صفحے کا اسکرین شاٹ لیں، پھر اسے Ctrl+V سے ٹول میں چسپاں کریں یا اسکرین شاٹ فائل اپ لوڈ کریں۔ پکر اسکرین شاٹ پکسل کو کسی بھی دوسری تصویر کی طرح پڑھتا ہے، اس لیے آپ کسی بھی سائٹ سے بٹن، پس منظر اور متن رنگ نمونہ لے سکتے ہیں۔

اگر میرا چنا ہوا رنگ میرے ڈیزائن ٹول میں مختلف لگے تو کیا کروں؟

پہلے جانچیں کہ آپ نے مکمل HEX کوڈ کاپی کیا، کوئی ہندسہ گم کیے بغیر۔ پھر یاد رکھیں کہ مانیٹر اور رنگ پروفائل مختلف ہیں، اس لیے ایک ہی کوڈ دو اسکرین پر تھوڑا مختلف لگ سکتا ہے۔ خود کوڈ پر بھروسہ کریں، اور اسے اسی اسکرین پر اصل تصویر سے موازنہ کریں۔
