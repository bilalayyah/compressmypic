从照片提取配色：设计工作流程技巧

一张照片里已经包含一套好用的配色。光线、表面和主体共同作用，产生了彼此属于对方的颜色，好的设计师可以整套借用这种和谐。

难的不是找到颜色，而是选择用哪些、用多少、舍弃哪些，让配色服务设计而不是和设计作对。

本文会讲这个工作流程：从提取出来的配色到一套能用的设计系统，包括规则、比例，以及让照片配色出问题的错误。

为什么照片能做出好配色

照片捕捉的是真实世界里的颜色，在真实的光线下、在真实的表面上。这些颜色本身就很和谐，因为照亮场景的光对所有颜色都是一样的。

从零发明的配色没有这种保证。分开选的两种颜色可能以难以预测的方式冲突，而来自同一张照片的两种颜色已经证明了它们可以共存。

照片还带有情绪。一张暖色日落照片给出暖色配色，一张冷色海洋照片给出冷色配色，情绪不用任何额外努力就转移进了设计。

提取器让这一切变得实际。它按占比排出照片的颜色，所以你得到的配色不仅和谐，还诚实地反映了哪些颜色真正定义了这张图片。

主色与强调色

每套配色都有层次。主色覆盖的面积最大、定下基调，次色起辅助作用，强调色以少量出现，吸引目光。

提取器的百分比徽章直接展示了这个层次。占 40% 的颜色是主色，占 15% 的是次色，占 3% 的是强调色。

在设计里尊重这个层次。按和照片相同的比例使用配色，感觉会很自然，因为它重复了眼睛在图片里已经接受过的平衡。

最常见的错误是把强调色提升为主色。照片里只占 2% 的鲜艳红色用作按钮很抢眼，但填满半页时就会压垮设计。

60-30-10 规则

60-30-10 规则是应用照片配色最简单的方法。主色占 60% 的空间，次色占 30%，强调色占剩下的 10%。

从提取器的百分比出发，向这个规则取整。一张照片的颜色占比是 55%、30%、8%，已经接近理想状态，规则只是把照片本来在做的事形式化了。

这条规则有效，是因为它创造了清晰的层次。眼睛不用从上下文里推断，就知道什么是背景、什么是内容、什么是重点。

当设计有要求时，要有意识地打破规则，而不是无意中打破。一张 90% 都是强调色的海报是一个大胆的选择，它应该是一个选择，而不是一个错误。

暖色与冷色的和谐

照片偏暖或偏冷，配色也会继承这种倾向。沙漠照片给出暖橙色和棕色，冬季照片给出冷蓝色和灰色。

混合暖色和冷色的配色也可以成立，但需要一个明确的主导。暖色配色加一个冷色强调色感觉是有意的，暖冷各占一半的配色感觉是拿不定主意的。

检查提取器输出里的色相值。色相在 0 到 60 度附近的颜色是暖色，180 到 260 度附近的是冷色，两者之间的平衡告诉你配色的温度。

当照片是混合的，选择符合信息的温度。想要活力的品牌保留暖色、去掉冷色，想要平静的品牌反过来做。

对比度与无障碍

一套漂亮的配色仍然可能无法阅读。文字和背景之间需要足够的对比度，照片配色本身并不能保证这一点。

检查配色里每对文字和背景的对比度。最浅和最深的颜色通常能通过，来自同一张照片的两个中间色调常常失败。

HSL 在这里有帮助。亮度值相差大的两种颜色通常能通过对比度检查，亮度相近的会失败，和色相无关。

当一对颜色失败时，调整亮度，而不是色相。把文字颜色调暗或背景调亮十个百分点，配色保持性格，同时变得可读。

从配色到设计系统

当每种颜色都有一个角色时，配色就变成了设计系统。按工作给色板命名，比如背景、表面、主色、次色、强调色、文字，而不是按颜色命名。

角色让配色能被团队使用。开发者看到一个叫 accent 的变量就知道在哪里用它，而一个叫 orange-3 的变量只会引人猜测。

在 HSL 里只改亮度，从基础色生成深浅变化。亮度 50% 的主色可以生成亮度 42% 的悬停状态和亮度 70% 的禁用状态，彼此明显相关。

把系统存为设计令牌，从提取器的 JSON 导出它们。JSON 给你基础颜色，令牌记录角色和由它们生成的变体。

用照片做情绪板

情绪板是一组共享一种感觉的照片，它们的配色应该彼此一致。从每张照片提取配色，并排比较。

当配色共享一个主导色相或相似的温度时，情绪板感觉连贯。当它们朝不同方向拉时，情绪板感觉散乱，很可能有一张照片不属于这里。

把提取器的配色卡直接用作情绪板。每张卡片展示照片和它的色板，所以情绪板同时传达图片和它们的颜色。

这样搭建的情绪板也是一份决策记录。当客户问为什么是这些颜色时，情绪板展示了它们来源的照片，这比一串 HEX 代码更有说服力。

从照片做品牌配色

品牌常常从一张照片开始：创始人肖像、产品照，或者对公司有意义的地方。从这张照片提取的配色把品牌故事带进了颜色里。

做品牌工作时，从源照片最好的版本提取，再把配色修剪到四五种颜色。品牌配色需要让人记住，十二种颜色的集合对任何人来说都太多了。

提取之后，用图片取色器验证关键颜色。取色器读取精确的像素，当提取器的数值是渐变平均值时，它能确认品牌色。

用源照片、HEX、RGB、CMYK 值和角色记录配色。一份在颜色旁边展示照片的品牌指南，能讲出单纯的列表讲不出的故事。

季节与文化信号

颜色承载的联想会随季节和文化变化。秋天照片的橙色和棕色在十月感觉正好，在五月感觉沉重；春天照片清新的绿色在冬天感觉不对。

选择一张照片作为配色来源时，考虑设计会在什么时候、什么地方被看到。活动配色应该匹配它的季节，全球品牌配色应该避开和信息冲突的强烈本地含义的颜色。

提取器无法判断这些联想，它只报告颜色。判断属于设计师，设计师了解受众和时机。

不确定的时候，找受众里的人测试配色。五分钟的对话能揭示一个联想，而几个小时的设计工作可能都发现不了。

避免浑浊的配色

当太多中间色调互相竞争时，照片配色会变浑浊。一张有五种相似棕色和灰色的照片生成的配色里，什么都不突出，一切看起来都很暗淡。

解决办法是减法。去掉彼此接近的中间色调，保留最浅和最深的，再保留一个清晰的强调色。有对比的配色才有生命力。

浑浊的另一个原因是混合了光线不同的照片。暖色照片和冷色照片各自生成一套好配色，合并之后得到的配色却完全没有温度。

当配色感觉浑浊时，检查 HSL 值。如果饱和度都很低、亮度都在中间，配色需要一个鲜艳的强调色和一个深色锚点来塑形。

正式采用之前测试配色

正式采用之前，先在真实版式里测试配色。作为色板看起来好的配色，做成页面可能失败，因为色板看不出对比度、层次或可读性。

用配色快速搭建一个 mock：标题、段落、按钮和卡片。如果 mock 读起来好，配色就好用；如果感觉不对，mock 会精确显示哪一对颜色出了问题。

也要用灰度测试。把 mock 转成黑白，检查层次是否还在。只依赖色相的配色会崩塌，有亮度对比的配色能撑住。

也要在手机屏幕上测试。颜色在小而亮的显示屏上看起来不同，在大显示器上好用的配色，在手机上可能感觉刺眼或发灰。

配色与排版一起考虑

颜色和字体是一对搭档，配色的选择会限制排版。忙碌多彩的配色需要安静简单的字体，克制的配色可以承载更有表现力的字体。

文字颜色值得和配色本身一样的重视。配色里最深的颜色通常是文字颜色，它在小字号下应该足够深、读起来舒服。

链接和互动元素需要一种和文字明显不同的颜色。强调色通常担任这个角色，它应该足够独特，让读者不用思考就能认出链接。

当配色来自照片时，照片本身也能提供字体颜色。用取色器取图片最深阴影的色调，这个色调和配色天生和谐。

迭代配色

配色很少在第一次提取时就是对的。把第一次的配色当作草稿，用在 mock 里，留意什么失败了，再用另一张照片或不同的色板数量重新提取。

保留各个版本。一个对网站不对的配色可能对海报正好，被你丢弃的版本可能成为之后某个 brief 的答案。

小步迭代。一次只改一种颜色，或者一次只改一个数量，这样你能分辨哪次改动改进了结果、哪次让它变糟了。

配色能用的时候就停下来。一套够好、已经在用的配色，胜过一套完美、还在争论的配色，而且提取器让以后重新审视这个决定变得很便宜。

数据可视化的配色

图表和图形需要的配色逻辑和版式不同。每个数据系列都需要一种一眼就能和别的区分开的颜色，系列重叠时配色也必须保持可读。

从照片提取配色、用在图表上之前，先把颜色互相检查一遍。作为色板看起来不同的两种颜色，做成细图表线时可能看起来完全一样，尤其对色觉有差异的读者来说。

对分类数据，选择色相相隔很远的颜色。色相相隔 0 度、120 度、240 度的配色，即使在小图例里，系列也很容易区分。

对连续数据，改用单一色相加亮度变化。浅蓝到深蓝的渐变读起来是一个递进关系，而彩虹般的色相读起来是分类，会混淆信息。

用灰度和色盲模拟器测试图表配色。两种测试都通过的配色几乎对每个读者都有效，这是一张公开图表应该达到的标准。

常见问题

配色的 60-30-10 规则是什么？

这是一条比例规则：主色占大约 60% 的空间，次色占 30%，强调色占 10%。这条规则创造了清晰的视觉层次，让眼睛知道什么是背景、什么是内容、什么是重点。从提取器的百分比出发，向这些数字取整。

品牌配色应该有多少种颜色？

四到六种是常见的范围。这足够容纳背景、主色、次色、强调色和文字色，同时还让人记得住。超过六种，团队用起来就很难保持一致。先提取更大的一组，再修剪到最强的四到六种。

应该直接用提取出来的精确颜色，还是调整它们？

调整它们。提取给你的是起点，不是最终答案。为品牌契合微调一下色相，提高暗淡强调色的饱和度，或者为对比度加深文字颜色。照片证明这些颜色和谐，但最终数值由你的设计目标决定。

照片配色能用在深色模式主题里吗？

可以，用反转的办法。把照片里最深的颜色作为深色模式的背景，最浅的颜色作为文字。强调色通常可以直接转移。测试反转后的配色对比度，因为在浅色背景上成立的颜色组合，在深色背景上可能失败。

提取出来的配色里没有好的强调色，该怎么办？

借一个。用吸管工具取一个提取器漏掉的小鲜艳细节，或者从色轮上主色相对的位置引入一个互补色。强调色不一定要来自照片，它必须和照片的颜色搭配。

怎么让照片配色在整个网站上保持一致？

把配色存为 CSS 自定义属性或设计令牌，在每个地方引用变量，而不是粘贴 HEX 代码。这样一次改动就能更新整个网站。记录每种颜色的角色，让每个页面在相同的工作上用相同的颜色。
