EXIF 数据详解：你的照片泄露了什么

一张照片展示的是一个瞬间。它的 EXIF 数据讲述的却是这个瞬间背后的故事：哪台相机拍的、什么时候拍的、在哪里拍的、用了什么参数。

大多数人从来没有见过这一层信息。它悄悄地待在文件里，经历复制、转发和下载，直到被什么东西清理掉才消失。

本文将深入讲解 EXIF：它是如何构成的、每个字段泄露了什么、它如何外泄，以及如何读取和删除它。没有多余内容，只讲这些数据真实包含的东西。

EXIF 到底是什么

EXIF 是可交换图像文件格式的缩写。它是一种把元数据存放在图片文件里的标准，由相机和手机在拍摄瞬间写入。

从技术上讲，EXIF 数据位于嵌入文件中的 TIFF 结构里。在 JPEG 中，它存放在 APP1 段；在 PNG 中，它可能存放在 eXIf 块；在 WebP 文件中，它存放在 EXIF 块。

这个结构由一组名为 IFD 的目录组成，全称是图像文件目录。每个 IFD 包含带编号的标签，每个标签存放一个值：数字、字符串，或一组有理分数。

查看器会读取 JPEG 文件中的三个 IFD：IFD0 存放基本设备信息，ExifIFD 存放曝光数据，GPSIFD 存放位置信息。几乎所有有趣的内容都在这里。

EXIF 不是照片里唯一的元数据。XMP 数据包、IPTC 字段、JPEG 注释和 PNG 文本块可能与它并存，但 EXIF 是其中最丰富、最标准化的一个。

IFD0：你的设备身份

IFD0 是第一个目录，它标识了设备。相机品牌和型号是最醒目的字段，但里面还有更多内容。

软件字段记录的是最后一次写入该文件的程序。可能是相机固件版本、手机操作系统，也可能是 Lightroom 这样的编辑应用。

有些相机还会在这里记录序列号或机主姓名。这些字段会让一张匿名照片，变成与某一台具体设备、甚至某一个具体的人绑定的照片。

作者字段可能存放摄影师姓名，版权字段可能存放权利声明。对专业人士来说，这两者都是正当的，同时也都具有识别性。

图片尺寸和方向标记也存放在附近。方向标签负责告诉查看器把照片旋转到正确方向，它也是导致照片横过来的那个字段，一旦被粗暴清理就会出问题。

ExifIFD：曝光数据

ExifIFD 是 EXIF 的技术核心。它记录了相机在拍摄瞬间做出的曝光决定，或者你本人做出的决定。

ISO、光圈、快门速度和焦距，是摄影师最关心的四个字段。它们合在一起，描述了光线、景深和画面中的动态。

曝光时间以有理分数的形式存储，例如 1/250 秒。光圈以 F 值存储。焦距以毫米存储，有时还会附带一个 35mm 等效焦距。

闪光灯状态记录闪光灯是否闪过、用了什么模式。测光模式记录相机如何测量场景光线：平均测光、中央重点测光、点测光，还是多重测光。

白平衡、曝光程序和曝光补偿又补充了更多细节。只凭这些字段，受过训练的读者就能还原拍摄条件。这就是摄影师看重它们的原因，同时它们单独来看又是无害的。

GPSIFD：位置目录

GPSIFD 是最小的目录，也是最危险的一个。它以度、分、秒的有理数形式存放纬度、经度和海拔。

查看器会自动把这些分数换算成十进制坐标。像 25.2048、55.2708 这样的一对数字，就是地图上一个精确的点，精确到可以识别一栋建筑。

GPS 标签还带有时间戳，以及表示南纬或北纬、东经或西经的参考值。日期戳记录的是定位完成的时间，通常与拍摄时间一致。

海拔常常也会记录在内，虽然没有水平坐标精确。在手机上，它仍然能判断照片是在地面拍的，还是在高层拍的。

大多数手机相机应用默认会记录 GPS。坐标被悄悄写入，照片上没有任何可见标记，大多数机主根本不知道它们的存在。

你的照片泄露了你什么

一张照片泄露得不多，一组照片泄露得就多了。EXIF 会把照片合集变成一份关于地点、生活规律和设备的时间线。

多张照片的拍摄时间戳放在一起，能看出你什么时候在家、什么时候出门旅行、通常什么时候不在家。这就是生活规律，而生活规律对别有用心的人很有价值。

多张照片的 GPS 坐标放在一起，能标出你的家、工作地点、健身房和孩子的学校。即使没有名字，地图上的规律也一目了然。

相机序列号把照片与某一台设备绑定。如果同一个序列号出现在不同名字下的照片里，这两个身份之间的联系就暴露了。

软件字段会暴露你的编辑工具和操作系统。单独看微不足道，但与时间戳和位置结合起来，就会拼出一份相当详细的个人画像。

关键不在于某一个字段本身是秘密，而在于这些字段合在一起，拼出了一幅你从未选择公开的生活图景。

EXIF 如何存活，又如何消失

EXIF 能经受复制、发邮件和文件夹之间的移动。它是文件的一部分，所以会跟着文件走到任何地方，除非有什么东西主动把它删除。

社交网络和聊天应用是最大的清理者。微信、Instagram 和 Facebook 会在你通过它们的服务器上传时，自动去掉 EXIF、相机和 GPS 文件头。

这就是为什么从 Instagram 下载的照片，在图片元数据查看器里显示零 EXIF 标签。是平台把它清理了，不是你。

编辑应用各不相同。有的在导出时保留 EXIF，有的丢弃，有的提供选择。一张编辑并重新导出的照片，可能像素还在，相机数据却没了。

截图从一开始就没有 EXIF。剪贴板传递的是原始像素，所以截图只有尺寸和格式，没有相机或 GPS 数据块。

二手交易平台、论坛和邮件附件则不同。它们很多会原样保留上传的文件，所以 EXIF 和 GPS 会一路跟到陌生人的下载文件夹里。

如何读取 EXIF 数据

读取 EXIF 需要查看器，因为没有任何操作系统默认展示完整内容。图片元数据查看器会在本地解析原始字节，并把字段分组展示给你。

先看摘要横幅。它会告诉你格式、尺寸，以及是否发现了敏感标签类型。然后检查 GPS 提醒，有坐标时它会显示解码后的坐标。

接着阅读分组表格。相机字段标识设备，EXIF 字段描述曝光，GPS 字段给出位置。琥珀色的「隐私标记」标出敏感条目。

需要留存记录时导出 JSON。「复制 JSON」会把完整结构化报告放到剪贴板，「导出 JSON」则下载一份可以保存或附加到问题反馈里的文件。

分步骤的操作流程，请阅读如何查看图片元数据。工具的完整介绍，请阅读图片元数据查看器：完整指南。

EXIF 与 XMP、IPTC 的区别

EXIF 不是孤身一人。另外两种标准常常与它共存于同一文件，每一种泄露的东西都不一样。

XMP 是 Adobe 的 XML 数据包，嵌入在文件里。它可以包含编辑历史、评分、标签和描述。用 Lightroom 或 Photoshop 编辑过的照片，常常带有一长串 XMP 记录，记录每一次调整。

IPTC 是新闻出版行业的标准。它包含说明、标题、关键词、版权和版权信息。新闻照片和图库照片的 IPTC 字段非常丰富。

EXIF 由相机写入，XMP 由编辑软件写入，IPTC 由人和出版方写入。一张照片可以同时带有这三种数据，各自讲述故事的不同部分。

只清理 EXIF 有时还不够。彻底的清理还要去掉 XMP 数据包、IPTC 字段、JPEG 注释和 PNG 文本块，删除图片元数据工具做的正是这些。

EXIF 方向：照片横过来的问题

方向标签是个很小的 EXIF 字段，影响却很大。它告诉查看器如何把照片旋转到正确方向，因为相机常常把像素存成一个方向，再用元数据记录正确的方向。

如果标签被去掉而像素没有旋转，竖拍的照片就可能横过来。图片数据本身没有变，但让它变正的指令已经没了。

这就是为什么删除图片元数据工具提供两种方法。「无损二进制清理」会删除 APP1 块，包括方向标记，但不触碰像素。

「完整画布重新编码」走的是另一条路。它把像素画到一张全新的画布上，直接把竖直方向写进导出的图片里，这样照片不需要标签也能保持竖直。

如果竖拍的 JPEG 在无损清理后看起来横了，请切换到「完整画布重新编码」，点击「重新清理全部」。像素本身会被修正，不再需要方向标签。

EXIF 对摄影师和开发者的价值

EXIF 不只是隐私风险。对摄影师来说，它是学习工具；对开发者来说，它是调试帮手。

摄影师可以读出一张好照片的曝光参数，然后重复它们。ISO、光圈、快门速度和焦距合在一起，就是在类似光线下拍出同样效果的配方。

开发者可以用 EXIF 来解释奇怪的表现。错误的方向标记、PNG pHYs 块给出的意外 DPI 值，或者隐藏的色彩配置文件，常常就是渲染问题的原因。

对比两个文件是常见的调试方法。分别导出它们的 JSON，差异会显示哪一步处理丢了或改了某个字段。

当问题与尺寸有关时，图片尺寸检查器与 EXIF 阅读是很好的搭配。尺寸和 DPI 合在一起，才能判断一张照片适合打印还是只适合屏幕。

安全地删除 EXIF

读取 EXIF 只是工作的一半。另一半是在照片公开之前把它删除。

删除图片元数据工具会在你的浏览器本地清理 EXIF、GPS、XMP、IPTC、注释和 PNG 文本块，全程不上传。

「无损二进制清理」适用于 JPG 和 PNG 文件，它删除元数据段，不解码、不重新压缩任何一个像素。图片质量完全不受影响。

「完整画布重新编码」会从像素开始重建图片，确保每一个继承下来的二进制段都被丢弃。WebP 和 HEIC 输入会自动使用它，更改输出格式时也是如此。

清理之后请验证结果。把清理后的文件重新拖进图片元数据查看器，确认出现绿色横幅：未检测到 EXIF、GPS 或隐藏相机标签。

完整的删除指南，请阅读删除图片元数据：完整指南；关于这些数据背后的隐私风险，请阅读照片隐私：GPS、EXIF 与元数据风险。

关于 EXIF 的常见误区

关于 EXIF 有几个流传已久的误区，每一个都会带来虚假的安全感。值得逐一纠正。

误区一：调整图片尺寸会去掉元数据。通常不会。除非工具明确清理元数据，否则缩小后的照片可能带有与原片相同的 GPS 坐标。

误区二：转换格式会去掉元数据。把 JPG 转成 PNG 可能会丢弃 EXIF，也可能通过 eXIf 块把它带过去。永远不要以为转换就等于清理。

误区三：裁剪会去掉位置数据。裁剪改变的是像素，不是文件头。除非工具清理了元数据，否则 GPS 标签在裁剪后依然存在。

误区四：照片里看不到位置就是安全的。位置在文件头里，不在画面里。一张白墙的照片，仍然可能带有精确坐标。

误区五：只有专业人士才需要担心。手机相机写入的 EXIF 与专业相机一样，包括 GPS。每一个分享照片的人都会受到影响。

简要总结

EXIF 是相机写入每张照片的隐藏数据：设备身份、曝光参数、时间戳和 GPS 坐标。它按 IFD 目录组织，跟着文件一起走，直到被什么东西清理掉。

社交应用会自动清理它，但二手交易平台、论坛和邮件常常不会。一组照片就能暴露你的生活规律、常去的地方和使用的设备。

用图片元数据查看器读取 EXIF，用删除图片元数据工具删除它，清理后再检查一遍确认。你的照片，应该只展示你选择分享的内容，别无其他。

常见问题

元数据被清理后，还能恢复吗？

不能。元数据段一旦从文件里删除，这些信息就从这份副本里彻底消失了，无从恢复。所以如果你想为自己保留相机参数或位置记录，请在清理之前先留存一份原片。清理后的副本无法恢复到原始状态。

EXIF 数据会影响图片质量或文件大小吗？

EXIF 不会改变像素的样子，但会增加文件大小。相机照片常常带有嵌入的预览缩略图、XMP 数据块和注释段，这些加起来可能有几十 KB。清理它们可以在画质零变化的前提下缩小文件，这是隐私收益之外的额外好处。

所有相机和手机都会写入 EXIF 数据吗？

几乎所有数码相机和智能手机默认都会写入 EXIF 数据，包括品牌、型号、曝光参数和时间戳。GPS 坐标则取决于定位服务是否开启。有些相机应用允许关闭位置记录，这样可以从源头上去掉 GPS 标签，同时保留其他字段。

EXIF 数据能证明照片的拍摄时间和地点吗？

EXIF 时间戳和 GPS 坐标是证据，但不是铁证。时间戳可以被修改，GPS 数据可以伪造，而清理过的文件什么都不带。在法律或新闻用途上，EXIF 可以支持一种说法，但应当与其他证据对照核实。在隐私方面，请假定它是准确的，因为陌生人也会这么认为。

为什么同一张照片的不同副本，EXIF 数据不一样？

每个副本经历的处理不同。一个可能经过社交应用被全部清理，另一个则保持原样。编辑、转换和重新导出，每一步都可能添加、改变或删除字段。文件里的 EXIF 描述的是这份文件，而不是原始场景，所以副本一旦被不同方式处理，就会开始分化。

EXIF 数据和照片水印是一回事吗？

不是。水印是叠加在像素上的可见内容，例如标志或文字。EXIF 是描述照片的不可见文件头数据。水印在截图和重新保存后依然存在，EXIF 在清理后就消失了。它们的用途不同：水印是公开声明所有权，EXIF 是无形地记录事实。
