GIF 帧率与文件大小：流畅还是小巧，怎么取舍

每个GIF的核心取舍：帧率、帧数、尺寸和色彩调色板如何决定你的动画是流畅、是小巧，还是两者兼顾。看懂四个因素的互相影响，动图既流畅又轻巧，不用在两者之间二选一。还讲了帧率、帧数、尺寸和调色板各自的影响、哪个对体积最大，以及四者之间怎样取舍才划算。

每个 GIF 都是流畅和体积之间的一次妥协。帧率越高，动作越流畅，文件也越大。文件越小，分享越快，但看起来可能一顿一顿。做 GIF 的本事，就是为每段动画找到这个平衡点。

这篇指南会讲决定 GIF 文件大小的四个因素：帧率、帧数、尺寸和色彩调色板。说明每个因素如何与流畅度交换，以及怎么缩小 GIF 又不把它毁掉。

这里说的所有控制项都在 GIF 制作器里。生成之前设置帧率、帧数和输出尺寸，预计文件超过 5 MB 或 15 MB 时，工具会发出警告。

帧率与文件大小

帧率是每秒播放多少帧，是 GIF 制作里最直接的交换。帧率越高，动作越流畅，因为眼睛看到的位置变化步子更小。帧率越高，文件里的帧也越多，文件也就越大。

每秒一帧的 GIF 是幻灯片：每张图停留整整一秒，动作是一连串跳跃。每秒十帧的 GIF 足够做简单的平滑动作，但每秒动画要装下十张图。

这个关系大致是线性的。帧率翻倍，每秒的帧数翻倍，文件大小也按类似的倍数增长。三秒的 GIF 在每秒五帧时有十五帧，同样 GIF 在每秒十帧时有三十帧。

眼睛很快就注意不到提升了。从每秒一帧到每秒五帧，变化非常明显；从每秒五帧到每秒十帧，大多数题材的变化很细微。超过每秒十帧，GIF 几乎得不到流畅度的提升，只会增加体积。

GIF 压缩是怎么工作的？

GIF 压缩的原理是只保存帧与帧之间变化的像素。如果两帧除了一个小物体在移动之外完全相同，编码器会保存完整的第一帧，之后的帧只保存变化的像素。这就是为什么静止场景加一个小移动物体，GIF 依然很小。

整个场景都在动的 GIF 压缩得很差，因为几乎每个像素在每帧里都在变化。横跨风景的镜头移动，或者全屏的颜色变化，会打败压缩机制，文件迅速变大。

256 色调色板是另一个限制。每帧最多只能用 256 种颜色，编码器会挑选最重要的颜色，把其余颜色映射到最接近的那个。成千上万种颜色的照片会失去细腻感，颜色很少的图形则什么都不会失去。

理解这一点能帮你设计出更小的 GIF。背景保持静止，只移动主体，尽量用纯色。按这个格式的脾气来设计的 GIF 压缩得很好，和格式对着干的 GIF 压缩得很差。

每秒帧数怎么选？

每秒一帧适合幻灯片，每张图都值得完整看一眼。一组照片每秒展示一张，读起来像一个有意的序列，帧很少，文件也非常小。

每秒两帧适合慢速演示，比如一步步的操作，每个步骤需要半秒钟来确认。动作明显是一格一格的，但步骤本身就是重点，所以顿挫感读起来像是清晰。

每秒五帧是大多数 GIF 的最佳平衡点。它快到能感觉到动感，又慢到每帧都能被注意到。产品演示、教程和简单动画通常都用这个速率，文件大小也可控。

每秒十帧是工具提供的最平滑选项，适合必须看起来流畅的动作，比如旋转或行走循环。它的帧数是每秒五帧 GIF 的两倍，只有在动作确实需要这种平滑度时才用它。

帧数

帧数是 GIF 里图片的总数，它和帧率相乘决定动画的长度。十五帧、每秒五帧的 GIF 是三秒长。同样十五帧、每秒十帧的 GIF 只有一秒半。

短 GIF 是更好的 GIF。三秒的动画把意思讲清楚了，比十秒重复自己的动画有效得多。把帧列表砍到关键时刻，GIF 会同时变得更清晰、更小、更容易分享。

删掉的每一帧都是直接的节省。和帧率不同，帧率是拿流畅度来交换，删掉多余的帧在画质上没有任何代价。上一帧的近似复制品、模糊的照片，或者没有提供信息的帧，都可以删掉。

生成之前数一数帧。如果列表超过二十帧，问问自己每帧是不是都有存在的价值。帧列表太长，是 GIF 大到分享不出去最常见的原因。

输出尺寸

尺寸是对文件大小影响最大的杠杆。输出宽度减半，像素数量变成四分之一，因为宽度和高度同时缩小。没有任何一个改动能像缩小输出尺寸这样省得多。

480 像素宽的 GIF 是聊天和社交分享的标准。它大到手机上看得清楚，小到发送起来够快。960 像素宽的 GIF 是四倍的像素、好几倍的文件大小，大多数观众根本看不出差别。

目的地决定尺寸。聊天消息需要 480 像素，网站横幅需要更大，演示幻灯片需要的最大。宽度跟着地方走，导出不要超过显示尺寸。

记住很多平台反正会把大 GIF 缩小。上传到聊天应用的 1000 像素宽 GIF，显示出来可能是 480 像素，多出来的像素只是浪费了流量。按显示尺寸导出，文件就是它能达到的最小值。

色彩调色板与大小

色彩调色板同时影响画质和大小。GIF 每帧最多能装 256 种颜色，编码器负责挑选保留哪些颜色。色彩调色板画质滑块控制这个选择的仔细程度。

调色板画质高，分析帧更彻底，保留最重要的颜色。渐变更平滑，肤色更准确，但编码时间更长，文件也可能稍大一点。

调色板画质低，编码更快，文件更小，但渐变可能出现色带，细微的颜色可能偏移。插画和截图颜色很少，低设置就够了，因为调色板反正能装下所有颜色。

照片用更高的调色板画质。照片有成千上万种颜色，仔细的调色板能让图片保持可辨认。低调色板设置会把照片变成海报化的色块，天空出现色带，皮肤出现色斑。

透明度的代价

GIF 的透明度是单一透明色，不是平滑的透明通道。一个像素要么完全透明，要么完全不透明，柔和的边缘会变成硬边，阴影在透明背景前会变成实心的形状。

透明 GIF 可能比不透明的 GIF 更大，因为透明区域仍然需要编码，硬边比平滑渐变的压缩效率更低。简单贴纸的代价很小，细节丰富的图形代价会变大。

柔和的边缘是主要问题。带羽化边缘或投影的 Logo，半透明像素被迫变成实色或完全透明时，会出现光晕。硬边的图形能避开光晕，压缩效果也更好。

只有当 GIF 必须放在不同背景上的时候才用透明度，比如聊天贴纸。如果 GIF 永远只出现在一种背景色上，就把它压平到那个颜色上。文件会更小，边缘也会更干净。

循环次数与大小

循环次数不会改变文件大小。无限循环的 GIF 和只播放一次的 GIF 包含的帧完全相同，文件大小也完全一样。循环设置只改变播放器的行为，不改变存储的内容。

这让循环成了一个免费的选择。无限循环在文件大小上没有任何代价，单次播放也省不下任何空间。循环跟着场景和观众选，别跟着大小选。

循环确实会影响对大小的感受。大 GIF 无限循环，观众要等它下载完再反复播放，感觉很沉重。大 GIF 只播放一次就停下来，感觉像一次下载。

文件太大的时候，循环不是解决办法。砍帧数、缩小尺寸，或者降低帧率。循环设置是找节省空间最不该去的地方。

GIF 什么时候胜过视频？

动画短、没有声音、需要不用播放器就能播放的时候，GIF 胜过视频。反应、两秒的产品旋转，或者教程步骤，做成 GIF 能立刻播放；视频需要播放器、需要点一下，有时还需要声音权限。

GIF 在聊天和评论里也胜过视频，因为这个格式是原生的。粘贴到聊天的 GIF 会内联播放，视频可能只显示一个链接或缩略图，需要点一下才能看。无摩擦播放就是 GIF 的优势。

短循环是 GIF 的主场。五秒以内的动画，动作简单，帧数很少，就是 GIF。该格式就是为这个而生的，而且没有任何依赖。

观众未知、场景随意的时候用 GIF。任何人、任何设备、任何应用都能看 GIF，不用安装任何东西。短动画的通用性，值得付出更大的文件体积。

视频什么时候胜过 GIF？

动画长、细节多，或者色彩丰富的时候，视频胜过 GIF。十秒的全彩动态片段做成 MP4，体积只是做成 GIF 的一小部分，因为视频压缩就是为这项工作设计的。

视频在平滑动作上也胜过 GIF。GIF 在这个工具里最高每秒十帧，视频是每秒三十或六十帧。平滑的镜头移动或快速动作，做成视频很流畅，做成 GIF 会一顿一顿。

声音是视频显而易见的优势。GIF 按定义就是静音的，任何需要解说、音乐或音效的动画都必须是视频。带配音的教程不可能是 GIF。

如果你的 GIF 超过 15 MB，或者警告出现、怎么砍都小不下来，就换成视频。GIF 压缩器能缩小做好的 GIF，但文件大小是主要问题时，视频是更好的格式。

缩小做好的 GIF

做好的 GIF 太大，事后还能缩小。GIF 压缩器通过优化帧和调色板来减小文件，不改变动画本身，体积能显著下降。

压缩对帧重复多、颜色简单的 GIF 效果最好。很多近似相同的帧，编码器可以去掉重复的部分。动作复杂、颜色多的 GIF，压缩空间比较小。

从帧重新生成，通常比压缩成品文件更好。帧让你可以砍数量、缩小尺寸、降低帧率，这些节省都比任何事后压缩大得多。这也是要保留帧的原因。

必须缩小一个不是你做的 GIF 时，压缩是唯一的选择。把成品 GIF 上传到压缩器，选择设置，下载更小的文件。检查结果，重度压缩会让动画变顿挫。

流畅还是小巧，怎么决定？

决定要问观众和场景。聊天消息用的 GIF 必须小，因为它通过手机流量分享，在手机上播放。观众在移动中，速度比流畅度更重要。

网站或演示文稿用的 GIF 可以大一点，因为观众用的是稳定的网络和更大的屏幕。流畅度在那里更重要，动画是设计的一部分，观众会有意地观看它。

从每秒五帧、480 像素宽开始，再调整。动作看着顿挫，就把帧率提高到十帧。文件太大，先降低宽度，再减少帧数，最后降低帧率。这个顺序能用每兆字节换到最多的流畅度。

没有完美的 GIF，只有适合它工作的 GIF。小而略带顿挫的反应 GIF，胜过一个永远下载不完的平滑 GIF。评判 GIF 的标准是它能不能快速播放、把意思讲清楚，而不是技术上有多完美。

每秒五帧、480 像素宽是平衡的默认值。每秒十帧用双倍的帧换流畅度，宽度减半能让像素变成四分之一。删掉多余的帧在画质上没有任何代价。

常见问题

GIF 应该用什么帧率？

每秒五帧是大多数 GIF 最好的默认值：快到能感觉到动感，又慢到文件保持小巧。幻灯片用每秒一到两帧，只有在动作确实需要流畅度时才用每秒十帧。

帧率越高看起来一定越好吗？

不是。从每秒一帧到每秒五帧，变化非常明显；从每秒五帧到每秒十帧，大多数题材的变化很细微，文件大小却翻倍了。超过每秒十帧，GIF 几乎得不到流畅度的提升，只会增加体积。

帧率翻倍，文件大小会增加多少？

大致翻倍，因为帧率翻倍意味着每秒的帧数翻倍。三秒的 GIF 在每秒五帧时有十五帧，同样 GIF 在每秒十帧时有三十帧，文件会按类似的倍数增长。

GIF 最小能做到多大？

没有固定的最小值，因为大小取决于帧、尺寸和颜色。帧少、480 像素宽、纯色多的短 GIF，可以远小于一兆字节。长而写实的照片 GIF 无论如何都可能超过 15 MB。

循环次数会影响 GIF 文件大小吗？

不会。无限循环的 GIF 和只播放一次的 GIF 包含的帧完全相同，文件大小也完全一样。循环设置只改变播放器的行为。缩小 GIF 要砍帧数、缩小宽度，或者降低帧率。

缩小 GIF 时，先减帧数还是先减尺寸？

先减尺寸，因为宽度减半能让像素变成四分之一，这是单次能省最多的办法。然后删掉多余的帧，这在画质上没有任何代价。最后才降低帧率，因为它直接拿流畅度来交换。
