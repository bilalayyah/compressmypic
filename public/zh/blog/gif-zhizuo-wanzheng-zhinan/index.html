GIF 制作器完全指南：帧、时序与文件大小

GIF 是由一系列静态图片组成的短循环动画。它没有声音，会一直重复或按设定的次数循环，几乎所有聊天应用、社交信息流和网站都支持。做得好的 GIF，两秒钟就能表达一段文字讲不清的东西。

GIF 制作器可以在浏览器里把你的照片变成动态 GIF。上传两张或更多帧图片，设置每帧的时长，选择循环次数，下载一张没有水印的 GIF89a 文件。什么都不用上传到服务器。

这篇指南会讲 GIF 是怎么工作的、如何选择和安排帧，以及如何让文件小到方便分享。不管你是做反应 GIF、产品演示，还是教程片段，原理都是一样的。

什么是 GIF？

GIF 是 Graphics Interchange Format（图形交换格式）的缩写，从 20 世纪 80 年代末就有了。它是至今仍在日常使用的最古老的图片格式之一，能一直活下来靠的是一个特点：不用视频就能做动画。

GIF 保存的是一系列帧，每帧显示很短的时间，一张接一张。播放器循环播放这些帧，看起来就像一段短视频片段。没有声音，没有播放器控制，也不需要视频编解码器。

GIF 每帧最多只能用 256 种颜色，所以它更适合插画、截图和简单动画，而不是全彩照片。照片 GIF 也能做，但有限的调色板会让渐变出现色带，肤色看起来发平。

这个格式是通用的。聊天应用、社交信息流、论坛、邮件和网站都能直接显示 GIF，不需要任何专用播放器。正是这种通用性，让 GIF 至今仍是和任何人分享短动画最简单的方式。

GIF 制作器是怎么工作的？

GIF 制作器完全在浏览器里把你的照片编码成动态 GIF。帧图片不会离开你的设备，未发布的产品图或私人照片用起来也没有顾虑。不用上传，不用排队，也不用等服务器。

上传两张或更多帧图片，工具会按顺序排列它们。你可以拖动调整帧的顺序，复制某一帧让它停留更久，或者删掉不属于这里的帧。帧列表就是你动画的时间线。

每帧都有自己的延迟时间，按零点几秒计算。延迟短，动画就快；延迟长，动画就慢。你也可以给所有帧设一个统一的延迟，再单独调整需要停留更久的帧。

实时预览会按当前设置播放动画，下载之前先看一眼。你在预览里看到的样子，就是成品 GIF 的样子。生成的文件是标准的 GIF89a，任何支持 GIF 的地方都能播放。

如何选择帧？

帧是组成动画的静态图片，选帧决定了 GIF 能不能成立。好的 GIF 会讲一个小故事：前后对比、产品旋转、一步步的操作，或者一个层层递进再释放的反应。

帧的尺寸和形状尽量接近。工具能处理长宽比不同的图片，但尺寸匹配的帧组动画更平滑，不会出现跳动或黑边。帧的差别太大，先裁剪或缩放统一一下。

帧的数量别太多。五到十五帧通常足够做一个反应、演示或简短的教程步骤。帧越多，动画越长，文件也越大；很长的 GIF 会失去这个格式应有的冲击力。

顺序比数量更重要。产品旋转按顺时针或逆时针读，教程按步骤顺序读，反应按铺垫和释放读。按自然的动感排列帧，再检查预览。

帧延迟与时序

帧延迟是每帧在屏幕上停留的时间，它是决定动画感觉的主要控制项。每帧 0.1 秒，动作会很快、很有能量；每帧 0.5 秒，动作会很慢、很从容。

动画主体用统一的延迟，需要强调的帧用更长的延迟。开头的标题页值得多停留一会儿，让观众读完；最后一帧也值得多停留一会儿，让信息在循环重新开始之前落下来。

1、2、5 和 10 帧每秒这几个快捷预设是很好的起点。每秒一帧是慢速幻灯片，每秒五帧是节奏明快的演示，每秒十帧足够做简单的平滑动作。先从预设开始，再微调个别帧。

在实时预览里测试时序。看着数字觉得合适的延迟，动起来可能感觉不对，预览能显示真实的感觉。如果动画匆匆掠过重要的帧，拉长那一帧就好，不用把整个 GIF 都放慢。

帧率预设

预设把每秒帧数换算成延迟时间。每秒一帧意味着每张图显示一秒，适合每张图都值得完整看一眼的幻灯片。每秒两帧意味着每帧半秒，适合慢速演示。

每秒五帧意味着每帧五分之一秒，是大多数 GIF 的最佳平衡点。它快到能感觉到动感，又慢到每帧都能被注意到。产品演示、教程和简单动画通常都用这个速率。

每秒十帧意味着每帧十分之一秒，是工具提供的最平滑选项。它适合需要看起来流畅的动作，比如旋转或行走循环，但每秒动画的帧数更多，文件也更大。

越高不一定越好。每秒十帧、三十帧的 GIF 是三秒长、很重的文件；每秒五帧、十五帧的 GIF 同样是三秒长，文件只有一半大小。速率要跟着动作走，而不是跟着最大值走。

循环选项

循环决定 GIF 播放多少次。无限循环会永远播放，这是经典的 GIF 行为，适合反应、装饰，以及任何想反复吸引眼球的内容。

有限循环按设定的次数播放，停在最后一帧。适合教程或演示，观众最后应该停在完成的状态，而不是动画中间的某一帧。循环两三次，能让观众再看一遍，又不至于永远循环下去。

单次播放，也就是循环次数为一，只播放一次动画就停下来。适合一次性的揭示，比如前后对比，结束时应该停在对比之后的样子。观众看到变化，然后结果留在屏幕上。

循环要跟着场景选。聊天反应想要无限循环，产品演示想要几次循环，教程步骤想要停在结果上。循环选错了，再好的 GIF 也会感觉不对劲。

画面适配：完整显示与填满裁剪

画面适配决定帧的长宽比不一样时会发生什么。完整显示（Contain）会把每帧完整放进输出尺寸，不做裁剪，整张图都能看见，多出来的空隙变成边框。它保留了完整画面，代价是出现空白带。

填满裁剪（Cover）会裁剪帧图片，完全填满输出尺寸，没有空白带，但帧的边缘可能被裁掉。它做出来的动画干净、满幅，代价是损失部分帧的边缘。

每帧的每个部分都很重要的时候，比如教程里裁掉一个按钮就会藏住步骤，选完整显示。动画必须干净填满画框的时候，比如社交帖子里空白带会显得没做完，选填满裁剪。

调整输出宽度时，长宽比保持固定，所以改宽度是整体缩放 GIF，而不是拉伸。输出尺寸定一次，选好适配方式，帧就会一致地跟着走。

输出尺寸

输出宽度设置成品 GIF 的像素宽度，高度由帧的长宽比决定。480 像素宽是聊天和社交分享的常见选择，更大的宽度适合网站或演示文稿。

GIF 通常越小越好。480 像素宽的 GIF 分享起来够快，手机上看也够清楚。1000 像素宽的 GIF 是四倍的像素、好几倍的文件大小，大多数观众根本看不出差别。

工具对输出尺寸设了最小值和最大值，极端的尺寸做不出来。输出太小会丢失细节，输出太大会产生分享不出去的文件。留在中间范围，平衡最好。

尺寸要对照目的地检查。聊天应用反正会把大 GIF 缩小，发送一个巨大的文件只是在浪费流量，没有任何可见的好处。网站横幅需要的宽度比聊天贴纸大，尺寸要跟着地方走。

色彩调色板画质

GIF 每帧最多存 256 种颜色，编码器必须决定保留哪些颜色。色彩调色板画质滑块控制这个选择的仔细程度。设置得高，分析帧更彻底，保留最重要的颜色。

画质高，渐变更平滑，肤色更准确，但编码时间更长，文件也可能稍大一点。画质低，编码更快，文件更小，但渐变可能出现色带，细微的颜色可能偏移。

照片用更高的调色板画质。照片有成千上万种颜色，仔细的调色板能让图片保持可辨认。插画和截图颜色很少，低设置就够了，因为调色板反正能装下所有颜色。

在带渐变或人脸的帧上测试调色板。调色板不好的地方最先出现在这里：天空出现色带，皮肤出现色斑。测试帧看着干净，整个 GIF 也会干净。

大 GIF 警告

预计文件超过 5 MB 或 15 MB 时，工具会显示大 GIF 警告。设置这两个阈值是有原因的：大 GIF 很难分享，聊天里加载慢，可能超过上传限制，还会消耗手机流量。

GIF 变大的原因有三个：帧太多、尺寸太大，或者帧率太高。三个里砍掉任何一个，文件都会变小。砍帧数通常是最好的选择，因为更短的 GIF 本身也是更好的 GIF。

警告出现时，先减小输出宽度。宽度减半，像素数量变成四分之一，这是单次能省最多的办法。然后减少帧数或帧率，直到警告消失。

GIF 必须保持很大的时候，先想想 GIF 是不是正确的格式。同样动画的 MP4 视频比 GIF 小得多，大多数平台都接受视频。GIF 压缩器能缩小做好的 GIF，但文件大小是主要问题时，视频是更好的选择。

GIF 里的透明度

GIF 支持透明度，但只支持单一透明色，不支持平滑的透明通道。一个像素要么完全透明，要么完全不透明，柔和的边缘和阴影在透明背景前会变成硬边。

GIF 制作器在输出设置正确的情况下，会保留 PNG 帧的透明背景。带透明度的 Logo 或贴纸能保持镂空区域，适合需要放在任何背景上的叠加图和聊天贴纸。

柔和的边缘需要小心处理。带投影或羽化边缘的 Logo，透明度被压成单一颜色时会看到光晕，因为半透明的像素必须变成实色或完全透明。硬边的图形比柔和的图形效果更好。

透明 GIF 要在浅色和深色两种背景上都测试。白色上看不见的光晕，在黑色上可能很明显，反过来也一样。光晕出现了，就把图形压平到纯色上，别用透明度。

常见错误

最常见的错误是帧太多。五十帧的 GIF 其实是一段伪装成 GIF 的视频，又重又慢又无聊。把帧列表砍到关键时刻，GIF 会同时变得更清晰、更小。

另一个错误是每帧用统一的延迟。标题页只显示十分之一秒，根本读不完；最后一帧只显示十分之一秒，信息落不下来。重要的帧给更长的延迟，动作帧给更短的延迟，GIF 才会感觉是经过思考的，而不是机械的。

第三个错误是输出尺寸太大。聊天消息用的 GIF 导出成 1000 像素宽，是 500 像素版本的四倍像素，聊天应用反正会把它缩小。尺寸要跟着目的地走。

最后，很多人会在照片 GIF 上忽略调色板画质。低调色板设置会把照片变成海报化的色块，天空出现色带，皮肤出现色斑。照片提高调色板画质，低设置只留给简单的图形。

选五到十五帧尺寸匹配的图片，按故事顺序排列，基础延迟设在每秒五帧左右。标题帧和最后一帧多停留一会儿，循环次数跟着场景选。

输出宽度跟着目的地定，每个细节都很重要时用完整显示，画框必须填满时用填满裁剪，照片提高调色板画质。看到大 GIF 警告，先缩小宽度。

常见问题

什么是 GIF？它和视频有什么区别？

GIF 是一系列静态图片循环播放，没有声音，也没有播放器控制。视频用编解码器把动作和声音压缩成小得多的文件。GIF 文件更大，但到处都能直接播放，不需要播放器，所以在聊天和社交信息流里占主导。

GIF 应该有多少帧？

大多数 GIF 五到十五帧就够了：一个反应、一个产品演示，或者一个简短的教程步骤。帧越多，动画越长，文件也越大。如果你的 GIF 需要五十帧，那它其实是一段视频，用视频格式会更合适。

为什么 GIF 文件这么大？

GIF 把每一帧都存成一张完整的图片，用 256 色调色板，压缩效率比视频差得多。帧多、尺寸大、帧率高，都会增加体积。先减小宽度，再减少帧数，文件很快就能变小。

可以用视频做 GIF 吗？

GIF 制作器是用静态图片做 GIF，不是直接用视频文件。想把视频变成 GIF，先从视频里提取一系列静态帧，再把这些帧作为 GIF 的帧上传。选那些能表现动作的帧。

GIF 在所有社交平台上都能用吗？

几乎都可以。聊天应用、社交信息流、论坛和邮件都能直接显示 GIF，不需要专用播放器。少数平台会把上传的 GIF 自动转成视频，但动画照样播放，观众看到的结果是一样的。

GIF 最好的尺寸是多少？

480 像素宽左右是聊天和社交分享的好默认值：发送起来够快，手机上看也够清楚。只有网站或演示文稿这种显示更大的地方，才需要用更大的宽度。
