HEX、RGB、HSL 颜色代码详解与对比

HEX、RGB、HSL 与 CMYK 用不同方式描述同一种颜色。本文讲清每种格式的含义、适用场景、互相转换的方法，以及取色工具怎么用，帮你快速选对颜色代码，还附常见配色示例和取色技巧，无论是做网页、修图还是设计海报，都能快速找到想要的颜色。

屏幕上的每一种颜色都有好几个名字。同一个蓝色可以是 #2563EB，也可以是 rgb(37, 99, 235)，还可以是 hsl(221, 83%, 53%)，三者描述的是完全相同的像素。

这种重叠让新手很困惑。既然代码可以互换，为什么会有四种格式？实际工作中到底该用哪一种？

本文会把 HEX、RGB、HSL 与 CMYK 放在一起讲清楚：每种格式是什么意思、在哪里用、以及如何为自己的工作选择合适的格式。

为什么会有多种颜色格式？

不同的工作需要用不同的方式描述颜色。网页开发者想要一段能粘贴进 CSS 的短代码，设计师则想把颜色说成一个色相加一个亮度。

HEX 源于计算机存储颜色的方式：三个字节，分别对应红、绿、蓝，写成六位十六进制数字。它紧凑、方便复制。

RGB 源于屏幕产生颜色的方式：红、绿、蓝三盏灯，每盏灯的亮度从 0 到 255。它直接、易读。

HSL 源于人思考颜色的方式：先是色相，再是浓淡，最后是明暗。它和大多数设计工具里的滑块是一致的。

HEX 详解

HEX 代码以井号开头，后面跟着六位十六进制数字，比如 #2563EB。前两位是红色，中间两位是绿色，最后两位是蓝色。

每一对数字的范围是十六进制的 00 到 FF，换算成十进制就是 0 到 255。所以 #FF0000 是纯红色，#00FF00 是纯绿色，#000000 是黑色。

HEX 是 CSS 和大多数设计工具的默认格式。它短、能干净地粘贴进样式表，也很容易从取色器里复制出来。

有些代码可以缩写：#336699 可以写成 #369，因为每一对数字的两个字符相同。缩写和完整写法表示同一种颜色，不过大多数工具显示的是完整的六位。

RGB 详解

RGB 用十进制数字写出同样的三个值，比如 rgb(37, 99, 235)。每个数字从 0（完全没有这种光）到 255（满强度）。

RGB 是对屏幕行为最直白的描述。它直接说明要混合多少红光、绿光和蓝光，所以图片编辑器和相机内部用的都是它。

RGB 还通过 RGBA 支持透明度，再加一个表示不透明度的数字。rgba(37, 99, 235, 0.5) 就是同一个蓝色，半透明。

大多数办公软件和文档工具要求输入 RGB 值。当品牌指南把一种颜色列成三个数字时，通常给的就是 RGB 形式。

HSL 详解

HSL 用三个不同的概念描述颜色：色相、饱和度、亮度。典型写法是 hsl(221, 83%, 53%)。

色相是色轮上的一个角度，从 0 到 360 度。红色在 0 度附近，绿色在 120 度附近，蓝色在 240 度附近，转到 360 度又回到红色。

饱和度是百分比：0% 是灰色，100% 是这个色相最鲜艳的版本。亮度也是百分比：0 是黑色，50 是纯色相，100 是白色。

当你需要一种颜色的多种变化时，HSL 最能发挥作用。想让按钮悬停状态变亮一点，只需保持色相和饱和度不变，提高亮度。这只是一处小改动，不用重新发明一个新颜色。

CMYK 详解

CMYK 用纸上的油墨来描述颜色：青、品红、黄、黑，各占一个百分比。典型写法是 cmyk(84%, 58%, 0%, 8%)。

印刷机混合油墨的方式和屏幕相反。屏幕靠加光达到白色，印刷机从白纸开始，靠加墨变暗。

这种差异意味着有些屏幕颜色无法精确印刷。非常明亮的蓝色和绿色常常超出油墨的色域，印出来的结果会暗淡一些。

图片取色器显示的 CMYK 值是根据屏幕颜色算出的近似值。把它当作印刷沟通的起点，而不是保证能匹配的承诺。

HEX 与 RGB：该用哪一个？

HEX 和 RGB 描述的是同一种颜色，只是写法不同。#2563EB 和 rgb(37, 99, 235) 是同一个蓝色的两种写法。

写 CSS 和分享颜色时选 HEX。它更短，是样式表里的惯例，复制进设计工具和聊天消息里也很干净。

当工具要求输入三个数字，或者需要透明度时选 RGB。RGBA 是在 CSS 里写半透明颜色的标准方式。

两者之间的转换只是简单的算术。每一对十六进制数字对应一个十进制数，所以 #25 是 37，#63 是 99，#EB 是 235。

HSL 与 HEX、RGB：HSL 什么时候更胜一筹

当你要设计一套颜色体系，而不是命名一种颜色时，HSL 更胜一筹。用 HSL 搭建的配色能保持协调，因为色相固定不变，只有亮度在变化。

想想一个按钮的三种状态：正常、悬停、禁用。在 HSL 里，色相保持 221，饱和度保持 83%，亮度分别设为 53%、45% 和 70% 就可以了。

用 HEX 做同样的事，意味着要发明三个互不相关的代码。它们看起来可能没问题，但代码本身看不出它们属于同一个系列。

现在很多设计工具可以直接输入 HSL，CSS 也原生支持它。如果你的工作涉及深浅变化，HSL 是能让它们保持条理的格式。

不同格式之间如何转换

你很少需要手动转换，因为取色器会同时显示所有格式。不过，理解转换原理能帮你信任这些数字。

HEX 转 RGB 是进制转换：每一对十六进制数字变成一个 0 到 255 的十进制数。FF 是 255，80 是 128，00 是 0。

RGB 转 HSL 是一套公式，不是查表。它找出三个值里最大和最小的那个，用它们的平均值得出亮度，再根据哪个通道最大算出色相。

RGB 转 CMYK 也是一套公式。它把 RGB 值取反，找出最小的那个作为黑色（K），再按比例缩放其余数值。这就是 CMYK 结果只是近似值、而不是实测值的原因。

网页上该用哪种格式？

对大多数网站来说，HEX 是安全的默认选择。它短、到处都支持，每个开发者一眼就能认出来。

需要透明度时用 RGBA。半透明的遮罩或柔和的阴影，用不透明度小于 1 的 rgba 写起来最简单。

搭建有系统深浅变化的主题时用 HSL。从一个色相生成浅色和深色变体的设计系统，用 HSL 维护起来要容易得多。

现代 CSS 还支持 OKLCH 等更新的格式，它们描述颜色的方式更均匀，很有前景。不过，HEX、RGB 和 HSL 仍然是今天每个工具和浏览器都支持的格式。

印刷时该用哪种格式？

印刷时，CMYK 是工作语言。印刷机按油墨百分比思考，提前准备好 CMYK 文件能避免在印刷机前出现意外。

先从屏幕颜色出发，记下取色器给出的 CMYK 近似值，再用印刷打样确认。打样才是唯一的真正检验。

千万不要只给一个 HEX 代码就送去印刷，不做任何 CMYK 沟通。印刷方会自行转换，但转换结果选用的油墨值可能不是你想要的。

做品牌工作时，向印刷方索要他们的色彩配置文件。配置文件能把屏幕颜色映射到特定印刷机和纸张的油墨上，比任何通用公式都准确。

设计工具里该用哪种格式？

Figma、Photoshop、Canva 都接受粘贴进颜色字段的 HEX，所以 HEX 是把取到的颜色移进设计的最快方式。

在工具内部调整颜色时，通常拖动的是 HSL 风格的滑块：色相、饱和度、亮度。工具显示的是 HEX，但你编辑时用的是 HSL 的思路。

品牌指南常常三种都列：HEX 给开发者，RGB 给文档，CMYK 给印刷。这是很好的做法，因为每类受众用的格式不同。

如果你用图片配色提取器提取配色，导出文件里每个色板都包含 HEX、RGB 和 HSL，不用你自己转换任何东西。

颜色格式的常见错误

最常见的错误是以为 HEX 和 RGB 是不同的颜色。它们只是同一个值的两种写法，#2563EB 和 rgb(37, 99, 235) 永远匹配。

另一个错误是把 CMYK 近似值当成精确值。屏幕到印刷的转换只是一套公式，真实的印刷颜色取决于印刷机、油墨和纸张。

很多人还忘了，亮度不是明亮度。在 HSL 里，把亮度调向 100% 会让颜色向白色褪去，调向 0 则会推向黑色。

最后，不要只凭肉眼在不同屏幕之间比较颜色。两台显示器可以把同一个 HEX 代码显示得不一样，所以要求精确时要相信数字。

如何读懂取色器的输出

取样一个像素后，取色器会同时显示所有格式。HEX 代码是网页工作要复制的那一个，RGB 数字是文档工作要复制的那一组。

HSL 值告诉你这个颜色在色轮上的位置，以及它有多鲜艳。色相接近 0 或 360 是红色，接近 120 是绿色，接近 240 是蓝色。

CMYK 百分比告诉你这个颜色需要多少油墨。青和品红高、黄色为零的是蓝色，黄色高、带一点品红的是橙色。

学会一眼读懂这四种格式需要练习，但很值得。你会还没粘贴，就能看着代码想象出颜色的样子。

跨格式搭建配色

一套好的配色会选一种格式作为可信来源，其他格式都由它推导出来。大多数团队把 HEX 作为来源，因为它是开发者粘贴进代码的格式。

从 HEX 基础出发，在 HSL 里只改亮度，就能生成更亮和更暗的变体。这样色相家族保持完整，配色也很协调。

把 RGB 值记下来给文档用，把 CMYK 近似值记下来给印刷用。一份包含四种格式的品牌指南能服务每个团队，不用任何人临时转换。

从取色器导出取到的颜色为 CSS 变量，再把变体记录在旁边。样式表就成了每个人都信任的唯一参考。

HSL 与无障碍：用亮度判断对比度

无障碍规范关心对比度，而 HSL 让对比度很容易推断。亮度值相差大的两种颜色通常能通过对比度检查，亮度相近的两种颜色则会失败。

想想深色文字配浅色背景。如果文字亮度在 15% 附近，背景在 95% 附近，差距很大，几乎所有人读起来都轻松。

深色模式的逻辑反过来也一样。亮度 90% 的浅色文字配亮度 10% 的深色背景，差距同样大，阅读体验同样舒适。

HSL 还能帮你在不改变颜色性格的前提下修复失败的组合。如果某个彩色按钮没有通过对比度检查，把亮度降低十个百分点再测一次，色相和饱和度保持不动。

这比猜一个新的 HEX 代码容易得多。在 HEX 里，同一个颜色的深色版本是一组全新的数字，和原色看不出任何关系，所以每次尝试都是一次新的猜测。

审计设计时，把关键颜色转成 HSL，按亮度排序。排好序的列表一眼就能看出文字、背景和强调色的亮度差距够不够，读起来是否清晰。

记住，色相和饱和度本身对对比度几乎没有影响。鲜艳的红色和鲜艳的绿色亮度可能几乎相同，这就是色盲用户难以区分红绿组合的原因，即使它们的色相差得很远。

快速参考：格式速查表

HEX 是井号后跟六位数字，比如 #2563EB。在 CSS、设计工具里用它，书面分享颜色时也用它。

RGB 是 0 到 255 的三个数字，比如 rgb(37, 99, 235)。在文档、办公软件里用它，需要透明度时用 RGBA。

HSL 是色相角度加饱和度和亮度百分比，比如 hsl(221, 83%, 53%)。搭建深浅变化和主题变体时用它。

CMYK 是印刷用的四个油墨百分比。做印刷工作时把它当作起点的近似值，一定要用打样确认。想动手实践，可以看图片取色器完整指南和分步操作如何从图片中取色。

常见问题

网站颜色用 HEX 还是 RGB 更好？

就颜色本身而言，两者没有好坏之分，因为它们描述的是同一个值。HEX 更短，是样式表里的惯例，所以大多数开发者更喜欢它。需要透明度时 RGB 更好，因为 RGBA 可以加一个 HEX 不容易表达的不透明度值。

为什么我的品牌色印出来和屏幕上不一样？

屏幕用光产生颜色，印刷用油墨产生颜色，两种系统的色域不同。屏幕上明亮的蓝色和绿色常常超出油墨能表现的范围。取色器给出的 CMYK 值只是近似值，大批量印刷之前一定要看打样。

不用工具，能把 HEX 代码转成 HSL 吗？

可以，但要分两步：先把 HEX 转成 RGB，再用 RGB 转 HSL 的公式计算。取色器会瞬间完成这两步，同时显示所有格式。偶尔转换一次的话，用任何在线转换器或取色器本身都比手算快。

HSL 里的色相数字到底是什么意思？

色相是色轮上 0 到 360 度的一个角度。红色在 0 度附近，黄色在 60 度附近，绿色在 120 度附近，青色在 180 度附近，蓝色在 240 度附近，品红在 300 度附近。色相相差 30 度的两种颜色看起来有关联，相差 180 度的看起来互补。

网站或社交媒体图片需要 CMYK 值吗？

不需要。网站、App 和社交媒体图片都是屏幕媒介，HEX、RGB 或 HSL 就够了。只有油墨接触纸张时才需要 CMYK。可以把 CMYK 近似值存档，万一同一个品牌色将来要印刷，还能用得上。

为什么有些 HEX 代码只有三位数字？

三位 HEX 代码是六位代码的缩写，只适用于每一对数字两个字符都相同的情况。#369 就是 #336699，因为 3 变成 33，6 变成 66，9 变成 99。不是每个六位代码都能缩写，只有成对数字相同的时候才可以。
