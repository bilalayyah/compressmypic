一张图片在你的屏幕上看起来完美无缺，上传的那一刻却可能失败。电商平台因为太小而拒绝它，印刷厂把它裁得面目全非，或者网站把它拉伸成一片模糊。

原因几乎总是尺寸：以像素为单位的宽度和高度。大多数人直到出问题才去查尺寸，而那时截止日期已经很紧了。

本指南会介绍 CompressMyPic 图片尺寸检查器的工作方式、报告里每个数字的含义，以及如何用它在尺寸问题到达客户手里之前就发现它们。

图片尺寸检查器是什么？

图片尺寸检查器会读取图片的像素宽度和高度，显示在一张清晰的表格里。单个文件可以查，整批文件一次拖进来也可以查。

工具支持 JPG、PNG、WebP、GIF、BMP、HEIC、SVG 文件，单个最大 20 MB。它读取的是文件里实际存储的尺寸，而不是操作系统根据文件名猜出来的大小。

除了宽度和高度，报告还包括宽高比、像素数、文件大小，以及图片是否有透明度。还会为每张图片计算 300 DPI 下的打印尺寸。

一切都在浏览器本地运行。图片不会上传到任何服务器，所以未发布的产品照和保密的广告素材在检查时依然是私密的。

像素、宽度与高度详解

一张图片就是一个像素网格，它的尺寸就是这个网格的列数和行数。一张写着 1920×1080 的图片，横向有 1920 个像素，纵向有 1080 个像素。

宽度永远写在前面。1200×800 的图片是横图，800×1200 的图片是竖图，尽管两者的像素总数相同。

在屏幕上，只有像素才是真正有意义的尺寸。屏幕在全尺寸显示时，一个图片像素对应一个屏幕像素，所以一张 400 像素宽的图片永远填不满 1200 像素宽的空间，不拉伸是不可能的。

拉伸就是人们说的图片模糊。浏览器凭空编造出缺失的像素，而编造出来的东西总比真实的要柔和。

宽高比详解

宽高比是宽度与高度的关系，写成两个数字中间加冒号，比如 16:9 或 4:3。它描述的是图片的形状，而不是大小。

1920×1080 的图片和 1280×720 的图片都是 16:9，因为两者约分后比例相同。它们大小不同，形状相同。

检查器会把每张图片和常见比例做匹配，比如 16:9、4:3、1:1、3:2、4:5。当图片落在标准形状之间时，也会显示精确比例。

比例很重要，因为平台会按比例裁剪。Instagram 的竖图位置要求 4:5，上传一张 16:9 的照片，两边会被裁掉。先检查比例，就知道裁剪后还能留下什么。

像素数详解

像素数是图片像素总数的百万计数。宽度乘以高度，再除以一百万，就得到了像素数。

一张 4000×3000 的照片是 1200 万像素，因为 4000 乘以 3000 等于 1200 万像素。一张 1920×1080 的图片大约是 210 万像素。

相机厂商把像素数当作主打数字来宣传，但它掩盖了形状。1200 万像素的全景图和 1200 万像素的正方形图，像素数相同，尺寸却大不相同。

对印刷来说，像素数是能印多大的粗略参考。1200 万像素的文件印 A4 尺寸效果很好，而 200 万像素的文件印到超过明信片大小就开始发软。

批量检查：一次检查多张图片

当你要验证一个产品目录或一次拍摄的全部照片时，一张一张地查太慢了。尺寸检查器支持一次拖入整批文件。

把一个文件夹或一组文件拖进工具，它会生成一张包含所有图片的表格。每一行显示文件名、尺寸、比例、像素数、文件大小和透明度状态。

之后还可以继续追加批次。如果第二个文件夹晚到了，拖进来就行，新行会加入现有报告，而不是替换它。

如果大批量里有一个文件无法读取，工具会把这个文件标为错误，然后继续处理。其余批次照常检查，一个坏文件永远不会卡住整个任务。

最小宽度与最小高度验证器

很多平台都公布了最小像素尺寸。亚马逊、Etsy、Shopify 都会拒绝宽度低于某个值的产品图片，而且每个平台的具体数字都不一样。

检查器里有「最小宽度检查」和「最小高度检查」。输入平台要求的数字，工具会标出所有不达标的图片。

被标出的图片不一定完全不能用，但需要处理。你可以把它放大，不过会变软；也可以回头找原文件，导出一个更大的版本。

验证器在团队里也很有用。大家约定一次最小值，输入工具，之后每个批次都按同一个标准评判，而不是凭眼睛估。

300 DPI 下的打印尺寸

报告里有一列「300 DPI 打印尺寸」，它把像素尺寸换算成印刷质量下的物理英寸数。它回答的问题是：这张图片不损失清晰度能印多大。

计算很简单：像素宽度除以 300，就是可打印的英寸宽度。一张 3000 像素宽的图片，在 300 DPI 下可以印 10 英寸宽。

在 150 DPI 下，同一张图片可以印两倍大，但细节明显更柔和。300 DPI 这个数字是宣传册、书籍和产品包装的安全值。

这一列能防止一个常见错误：把网页尺寸的图片拿去印刷。一张 1200 像素的图片在屏幕上看起来没问题，但在 300 DPI 下只能印 4 英寸宽，做海报远远不够。

透明度检测：Alpha 通道

有些图片带有一个透明通道，叫作 Alpha 通道，可以让图片的一部分透出它后面的东西。Logo 和图标通常需要它，照片几乎从来不需要。

检查器能检测 PNG 或 WebP 是否真的带有 Alpha 通道。这很重要，因为一个文件即使保存为 PNG，也可能完全不透明，一点透明度都没有。

知道这一点能避免尴尬。一个在编辑器里看起来透明的 Logo，如果实际上是不透明的，放在彩色背景上会出现一个白框。

如果需要改变透明度，要正确地转换文件。把 JPG 另存为 PNG 并不会增加透明度，检查器会在你上线之后才发现问题之前就告诉你。

导出报告：CSV 与 JSON

检查只是工作的一半，另一半是分享结果。工具可以一键把完整表格导出为 CSV 或 JSON。

CSV 导出包含文件名、尺寸、宽高比、像素数、文件大小、透明度和打印尺寸等列。在电子表格里打开后可以直接排序和筛选。

JSON 导出用结构化格式承载同样的数据，适合开发者。当报告要进入脚本、内容流程或质量看板时，JSON 是正确的选择。

关掉标签页之前先导出。表格只存在你的浏览器里，刷新就会清空。保存下来的 CSV 是团队可以随时查阅的记录。

SVG 文件与固有尺寸

SVG 图形是矢量图，不是像素，所以尺寸的计算方式不同。SVG 的固有尺寸由 width、height 和 viewBox 属性定义，检查器读取的就是这些。

这很有用，因为 SVG 可以缩放到任意大小而不损失清晰度。它的固有尺寸告诉你设计师预期的大小，而不是它能放大的上限。

要小心只有 viewBox、没有 width 或 height 的 SVG。它们有比例，但没有固定尺寸，检查器会显示比例，同时注明不存在绝对尺寸。

对 Logo 和图标来说，SVG 读数能确认预期的比例。如果 viewBox 的比例和你布局要求的比例不符，图标会变形或留下空隙。

常见平台的尺寸要求

每个平台都有自己的尺寸规则，而且经常变化。下面的表格只是一个起点，大批量上传之前，一定要去平台本身确认最新的数字。

亚马逊和 Etsy 这样的电商平台想要大尺寸的方形或近方形产品图，最长边常常至少 1000 像素。更小的图片通不过它们的最小值检查，买家放大查看时效果也很差。

社交平台各有自己想要的形状。方形适合动态帖子，4:5 竖图能更好地填满手机屏幕，16:9 横图适合视频缩略图或封面图。

印刷服务想要你能给出的最多像素。300 DPI 的目标意味着整页印刷大约需要 2500×3300 像素，远远超过任何网页图片。

修复检查失败的图片

失败的图片通常有三个问题之一：太小、比例不对，或者格式不适合这项工作。每种问题的修复方法都不同。

太小是最难修复的。放大只会增加原本不存在的像素，结果比真正的原始高清图要柔和。能回到源文件就尽量回源文件。

比例不对就裁剪。用图片裁剪工具把图片裁成平台要求的比例，保持主体居中，重要细节留在画面里。

格式不对就转换。保存为 PNG 的照片可以转成 JPG 用在网页上，保存为 JPG 的 Logo 应该转成 PNG，这样边缘保持锐利，背景也保持透明。

尺寸检查器与图片缩放工具

检查器和缩放工具是搭档，不是竞争对手。检查器告诉你图片现在是多大，缩放工具在答案不对时改变它。

先用检查器做诊断。它会告诉你批次里哪些图片不合格、差多少，这样你只需要缩放那些需要处理的文件。

然后只对被标出的文件使用图片缩放工具。把整个批次都缩放一遍是浪费时间，还可能损坏本来正确的图片。

缩放之后，再用检查器复查一次。第二次检查能确认修复生效，并留下一份可以归档的最终报告。

隐私：浏览器本地批量处理

一批产品照片里可能包含未发布的商品，广告素材里可能包含尚未公开的价格。把这类文件上传到服务器是有风险的。

检查器在本地读取每个文件。浏览器打开每张图片、测量尺寸、生成表格，全程没有一个字节被发送出去。

这也意味着没有每日限额、没有费用。一次会话可以检查上千张图片，唯一的成本就是你自己的电脑读取它们所花的时间。

对处理保密素材的团队来说，本地处理是让这个工具真正可用的功能。没有上传，就意味着这些文件在你自己的电脑之外不存在任何副本。

如何使用图片尺寸检查器

打开图片尺寸检查器，把图片拖进上传区域。也可以直接粘贴剪贴板里的图片，几秒钟就能验证它的像素分辨率。

表格会随着每个文件的读取逐行填充。先看尺寸、比例和像素数这几列，再看打印尺寸和透明度这些和你的工作相关的细节。

如果平台有要求，设置最小宽度和最小高度。不合格的行会清楚地标出来，你能一眼看到哪些文件需要处理。

完成后把报告导出为 CSV 或 JSON，再阅读分步操作如何查看图片尺寸或对比文章图片尺寸、分辨率与文件大小的区别。如果文件需要修改，图片 DPI 修改器接下来可以修复它的打印元数据。

常见问题

图片尺寸和图片分辨率有什么区别？

尺寸是像素宽度和高度，比如 1920×1080。分辨率是密度，通常用 DPI 或 PPI 表示，意思是每英寸里放多少个像素。一张图片可以尺寸大、分辨率低，也可以尺寸小、分辨率高。完整对比可以看我们关于尺寸、分辨率与文件大小的文章。

一次可以批量检查多少张图片？

工具没有固定上限。你可以把整个文件夹的图片拖进来，表格会逐行生成。非常大的批次会花更长时间，因为浏览器要逐个读取文件，但没有每日上限，也没有任何费用。

为什么同一张图片在不同应用里显示的尺寸不一样？

有些应用显示像素尺寸，有些应用显示的是应用 DPI 值或显示缩放之后的尺寸。检查器读取的是文件里存储的真实像素尺寸，这个数字才是上传和印刷真正要看的。

检查器能告诉我图片印出来效果好不好吗？

可以，通过「300 DPI 打印尺寸」这一列。它把像素尺寸换算成印刷质量下的物理英寸数。如果打印尺寸比你需要的小，图片印大之后看起来就会发软。

批量检查尺寸需要安装软件吗？

不需要。检查器在桌面端和手机端的浏览器里都能运行，不用安装、不用注册账号。把文件拖进来，读表格，再把报告导出为 CSV 或 JSON 就可以了。

检查完之后，我的图片会怎么样？

什么都不会发生。文件只在你的浏览器本地读取，从不上传到任何地方。关掉标签页，表格就会从内存里清除，所以需要保留结果的话，先导出 CSV 或 JSON 报告。
