PNG vs WebP：透明度与文件大小对比

PNG与WebP对比：透明度、文件大小、文字锐利度、浏览器支持，以及标志、截图和照片分别该用哪个格式。看懂两种格式的取舍，透明图和网页图都能选对格式。还按标志、截图和照片分了场景，讲清哪种格式更轻、哪种文字更锐利、哪种透明效果更可靠。操作起来很顺手。

PNG 和 WebP 都能存透明度，都能保持边缘锐利，在现代网页上都能用。差别在文件大小上，而 WebP 通常能赢下一大截。

但 PNG 并没有过时。它更简单、更兼容，默认就是无损的，好几个场景里反而是更安全的选择。

这篇对比会诚实地看两种格式，帮你为每张图片选对格式。

PNG 一览

PNG 是 1996 年推出的无损格式，专为图形设计。每个像素都原样保存，锐利边缘、纯色区域和文字都完美清晰。

PNG 通过透明通道支持完整透明度。每个像素可以全透明、全不透明或半透明，柔和边缘和阴影都能实现。

这个格式是通用的。过去二十五年里造出来的浏览器、编辑器、办公软件和操作系统，不用装任何额外东西就能打开 PNG。

代价是文件大小。存成 PNG 的细节照片，比同样照片的 WebP 或 JPG 大好几倍，因为无损存储没法丢掉纹理。

WebP 一览

WebP 是 Google 在 2010 年推出的现代格式。有损压缩、无损压缩、透明度和动画，一个格式全都支持。

有损 WebP 的照片通常比 PNG 小 50% 到 80%，标志和图标能小 25% 到 50%。

无损 WebP 在每个像素都原样的情况下，仍比 PNG 小 20% 到 30%。图形必须保持完美时，无损 WebP 是最小的精确副本。

现在所有主流浏览器都支持 WebP。Chrome、Edge、Firefox、Safari 和 Opera 都能原生显示，覆盖了几乎所有网页流量。

透明度：几乎打平

两种格式都有透明通道，透明标志在 PNG 和 WebP 里效果一样。透明背景的标志放在任何颜色上都很干净。

半透明在两种格式里也都行。柔和阴影和抗锯齿边缘在 PNG 和 WebP 里都是渐渐淡出，高画质下看不出差别。

WebP 画质低了，透明边缘可能出现毛边。70% 画质转换的标志可能出现淡淡的光晕，PNG 版却依然干净。

边缘完美很重要的标志，就用 PNG 或 90% 高画质 WebP。低画质 WebP 省下的那点体积，不值得换来一个带毛边的标志。

文件大小：WebP 明显胜出

存成 PNG 的照片，转 WebP 通常能小 60% 到 80%。一张 5MB 的 PNG 照片，用 85% 画质转完只剩 1MB 到 2MB。

标志和图标能省 25% 到 50%。简单图形用 PNG 本来就压得不错，省得少一些，但依然实实在在。

带文字的截图能省 50% 到 70%，文字还保持可读。这个组合让它成为博客图片和文档配图的理想选择。

整个网站累积起来，节省非常可观。二十张 PNG 图片的页面可能从 15MB 降到 5MB，加载时间的改善肉眼可见。

文字锐利度：PNG 小胜

PNG 是无损格式，文字保持绝对锐利。每个字母的边缘都原样保存，没有任何变软。

有损 WebP 用 85% 画质时文字依然很清晰，不过逐像素对比会发现字母边缘轻微变软。正常阅读的字号下，这个差别看不见。

无损 WebP 在文字上和 PNG 完全一样，因为两者都保存每个像素。而且文件还比 PNG 小，所以无损 WebP 是文字密集图片的两全之选。

每个字都必须完美的截图，比如法律证据，就用 PNG 或无损 WebP。博客截图用 85% 的有损 WebP 就够了。

照片：WebP 完胜

照片存成 PNG 是在浪费字节。无损格式把每一点细微的颜色变化都原样保存，而人眼根本分辨不出其中大多数。

WebP 用 80% 到 85% 画质看起来和 PNG 照片一模一样，体积却只有四分之一。省得这么多，网上提供 PNG 照片几乎没有理由。

编辑时 PNG 仍有用处。打算反复编辑的照片应该留着 PNG，因为 WebP 反复保存会叠加损伤，PNG 保存却不会。

不过用来交付时，WebP 是照片的明确赢家。文件更小，页面更快，肉眼看不出差别。

浏览器支持：PNG 胜出，WebP 在追赶

PNG 在有史以来所有浏览器里都能用，包括 Internet Explorer。不管访客的软件多旧，都能看到 PNG。

WebP 在所有现代浏览器里都能用。Chrome、Edge、Firefox、Safari 14 及更新版和 Opera 都支持，覆盖了绝大多数流量。

差距现在已经很小了。Safari 在 2020 年加上了支持，剩下不支持的都是用量微乎其微的老版本浏览器。

少数还在用古老浏览器的访客，用 PNG 备用版就行。HTML 的 picture 元素可以先提供 WebP，再提供 PNG，每个人都能看到图片。

浏览器之外的支持

桌面编辑器原生处理 PNG，WebP 的支持还在追赶。Photoshop 现在支持 WebP 了，但很多老编辑器还不支持。

办公软件到处都接受 PNG。PNG 粘贴进 Word 或 PowerPoint 马上就能用，WebP 在办公软件里的支持却不一致。

打印机和打印店只认 PNG 或 JPG。发给打印店的 WebP 文件可能被拒，打印时还是转成 PNG 更稳妥。

邮箱客户端显示 PNG 很可靠，WebP 在邮件里的支持还参差不齐。邮件里发送的图片，PNG 是更安全的选择。

什么时候用 PNG

图片要反复编辑时用 PNG。无损格式反复保存也不会累积损伤。

目的地不明或比较老时用 PNG。表单、打印机或办公软件一定接受 PNG，WebP 却可能被拒。

截图必须像素级完美时用 PNG。法律证据、技术文档和归档图片，都值得 PNG 的精确性。

文件本来就很小时用 PNG。一张 10KB 的图标转了也省不下什么，PNG 版本来就够高效了。

什么时候用 WebP

网站图片用 WebP。文件更小，页面加载更快，访客体验和搜索排名都会变好。

网上的标志和图标用 WebP。透明度能用，文件比 PNG 小，所有现代浏览器都能显示。

博客截图和头图用 WebP。文字保持可读，文件大幅缩小，页面明显变快。

网店的产品照片用 WebP。几百张图的商品目录，每张小 60%，整个店铺加载起来快得多。

PNG 与 WebP 互转

PNG 转 WebP 很容易，用 85% 画质也很安全。图片保留透明度，看起来一样，文件却大幅缩小。

WebP 转 PNG 同样容易，用 WebP 转 PNG 工具就行。PNG 更大，但到处能打开，反复编辑也不会有损。

转换一定要从手头最好的原件开始。PNG 转成 WebP 再转回 PNG，会在 WebP 那一步损失一点画质，所以要避免来回转换。

转成 WebP 后留着 PNG 原件。万一哪个目的地拒绝 WebP，PNG 马上就能上传，不用重新转换。

结论：哪个格式赢了？

效率上 WebP 赢了。它更小、更快、能力更强，单从技术上说，它是现代网页更好的格式。

兼容性和简洁性上 PNG 赢了。它到处能打开，默认无损，从来不会用一次拒绝或一道毛边给你惊喜。

上网用 WebP，再配一个 PNG 备用。编辑、归档和去向不明的图片用 PNG。这个组合能同时拿到两个格式的好处。

未来属于 WebP，但现在仍然需要 PNG。各用在各自擅长的地方，两者之间自由转换就好。

邮件里的 PNG 与 WebP

邮件是 PNG 依然明显胜出的地方。邮箱客户端显示 PNG 很可靠，WebP 的支持却不一致，邮件里出现破损图片显得很不专业。

带 WebP 图片的新闻邮件，有些订阅者看到的可能是破损图标。同样一封邮件用 PNG 图片，所有人都能正常看到，这才是邮件的目的。

邮件附件里，图形用 PNG 更安全，照片用 JPG 更好。文件小到能直接发送，所有设备上的所有客户端都能打开。

WebP 在邮件里目前还没有位置。在客户端普遍支持它之前，邮件里的标志和图形还是 PNG 的天下。

每封新闻邮件发送前，都在几个邮箱客户端里测试一下。在 Gmail、Outlook 和 Apple Mail 里快速看一遍，就能在订阅者之前发现破损图片。

社交媒体上的 PNG 与 WebP

社交平台会把上传的图片转成自己的格式，所以原格式不如画质重要。高质量的输入不管什么格式，结果都比低质量的输入好。

发照片帖子时，上传高质量的 JPG 或 WebP。平台反正要压缩一次，好的输入比差的输入结果更干净。

带文字的配图，上传 PNG 或高质量 WebP。文字在平台压缩后依然更锐利，公告图尤其需要这一点。

上传前先查平台推荐的尺寸。Instagram、Facebook 和 X 各有理想尺寸，尺寸合适比格式更重要。

上传后下载平台上的版本检查一下。快速看一眼发布后的帖子，就能确认图片在平台处理后是否完好。

打印时的 PNG 与 WebP

打印店只认 PNG 或 JPG，WebP 在打印工作里没有位置。发给打印机的 WebP 文件可能直接被拒，也可能印出来颜色全错。

带文字的打印文档，PNG 是最好的格式。无损画质让每个字母的边缘在纸上都锐利清晰，合同和表单尤其需要这一点。

打印照片用高画质 JPG 通常就够了，文件还小得多。照片印出来一模一样，文件小了发给打印店也更方便。

发文件之前先问打印店想要什么。大多数会说图形用 PNG、照片用 JPG，顺着他们的要求来，就不会白跑一趟。

重要的活儿先印一张小样试试。一张小样就能确认颜色和清晰度，再决定要不要下大单。

归档用的 PNG 与 WebP

归档需要五十年后还能打开的格式，PNG 是更安全的选择。它快三十岁了，有史以来所有系统都支持，而 WebP 还很年轻。

WebP 有一天可能成为归档标准，但那一天还没到。WebP 存档要靠未来的软件继续支持这个格式，很可能，但不是确定的。

母版用无损 WebP 是个合理的折中。它每个像素都原样保存，占用空间还比 PNG 少，不过 PNG 依然是更保守的选择。

母版存 PNG，交付副本存 WebP。这样分开存放，归档完美，交付又快，两头都不耽误。

每隔几年检查一次存档。格式一直在变，母版用的格式过时了，可能要在旧格式读不出来之前先迁移。

新网站怎么选格式

新建网站是认真选格式的最好时机。第一天就定好明确的规则，以后媒体库里就不会出现格式混杂的情况。

照片选 WebP，用 80% 画质。文件小，页面加载快，所有现代浏览器显示都没问题。

标志和图标选 WebP，用 90% 画质加透明度。图形保持锐利，文件比 PNG 小，透明度到处都能用。

备用版留着标志的 PNG 和照片的 JPG。picture 元素给现代浏览器提供 WebP，给其他浏览器提供备用格式。

把格式规则写下来分享给团队。项目笔记里的一行规则，能防止网站慢慢滑向格式混杂的老问题。

应用商店列表里的 PNG 与 WebP

应用商店列表需要锐利的截图，因为截图就是在卖应用。PNG 让界面文字保持清晰，WebP 则用更小的文件提供同样的清晰度。

截图用设备能提供的最高分辨率来拍。高清截图的像素翻倍，商店缩放后文字依然锐利。

商店列表的截图用 90% 画质转成 WebP。文字保持可读，文件上传快，列表看起来也很专业。

上传前先查商店的尺寸和大小规则。苹果和谷歌各有精确的尺寸要求，形状不对的截图会被拒绝。

上传后把 PNG 母版留在项目文件夹里。应用更新了，截图可以从同一批母版重新处理，不用从头再来。

常见问题

网站上的标志用 WebP 比 PNG 好吗？

通常是的。WebP 和 PNG 一样保留透明度，文件却小 25% 到 50%，页面加载更快。标志用 85% 到 90% 画质，边缘才能保持锐利。PNG 原件也要留着，万一哪个目的地有要求还能用。

PNG 转 WebP 会损失画质吗？

设置正确时损失很小。85% 画质的 WebP 在大多数图片上看起来和原 PNG 一模一样，文件却小得多。只有放大细看，或者画质设得特别低时才能发现差别。每个像素都必须完美的工作，就用无损 WebP。

WebP 图片能在 Word 和 PowerPoint 里用吗？

不太可靠。办公软件原生处理 PNG，WebP 在不同版本里的支持却不一致。文档和演示文稿用 PNG，WebP 留给网页，那里浏览器支持一致，文件小的好处也更明显。

WebP 会完全取代 PNG 吗？

短期内大概不会。PNG 快三十岁了，有史以来所有系统都支持它，而 WebP 在编辑器、办公软件和打印机里仍未实现全面支持。WebP 正在赢下网页，但编辑、归档和去向不明的场景里，PNG 依然是安全选择。

带文字的截图用哪个格式更好？

PNG 的文字绝对锐利，而 85% 的有损 WebP 文字依然很清晰，文件却小得多。博客截图选 WebP 更好。每个字都必须完美的截图，比如法律证据，就用 PNG 或无损 WebP。

应该把所有 PNG 文件都转成 WebP 吗？

不用。放到网站上的 PNG 才转，因为文件小了页面才快。经常编辑、归档、发邮件或打印的 PNG 就留着，PNG 无损又通用。按需转换，别为了转而转，除非某项具体工作有要求。
