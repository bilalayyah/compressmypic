如何查看图片尺寸：批量检查 5 步

查看任意图片的宽度、高度、宽高比与打印尺寸——单个文件或整批都可以。5 个步骤，最后导出 CSV 或 JSON 报告。

上传、印刷或交给客户之前，你需要知道一张图片真实的像素大小。文件名不会告诉你，缩略图也会骗人。

本指南会用 5 个步骤教你检查图片尺寸，单个图片或整批图片都适用。大约一分钟就能完成，最后还能得到一份可以分享的报告。

不用安装软件，不用注册账号，什么都不用上传。图片从头到尾都在你的浏览器本地读取。

开始之前需要准备什么

你需要图片文件本身，存在电脑或手机上。JPG、PNG、WebP、GIF、BMP、HEIC、SVG 都支持，单个最大 20 MB。

如果平台有要求，先把它记下来。最小宽度、要求的比例或目标打印尺寸，能让检查有一个明确的通过或不通过标准，而不是一种模糊的感觉。

一个浏览器就是你需要的全部软件。Chrome、Safari、Firefox、Edge 都能运行这个工具，桌面端和手机端都可以，不用装扩展。

批量检查时，开始之前先把文件收进一个文件夹。直接拖入整个文件夹，比表格建到一半时再一个一个找文件快得多。

第 1 步：上传一张图片或整批图片

打开图片尺寸检查器，把文件拖进上传区域。一次可以拖一张图片，也可以拖整个文件夹。

也可以点击上传区域浏览文件，或者用 Ctrl+V 粘贴剪贴板里的图片，检查刚截的图。

表格会随着每个文件的读取开始填充。每一行显示文件名、像素尺寸、宽高比、像素数、文件大小和透明度状态。

之后如果还有文件要加，拖进来就行，它们会加入现有表格。工具会追加新行，而不是清空已有的行。

第 2 步：读懂尺寸表格

先看尺寸这一列。它以像素为单位显示宽×高，比如 1920×1080，这一组数字是整份报告里最重要的。

把宽度和高度和你的要求对比。如果平台要求宽度至少 1000 像素，而图片只有 800，不管它看起来多好，都是不合格的。

接下来扫一眼像素数这一列。它一眼就能告诉你像素总数，方便你比较两张形状不同、大小相近的图片。

最后看文件大小这一列。尺寸很大、文件却很小的图片可能被重度压缩过，这对印刷工作是一个警示信号，哪怕像素数本身合格。

第 3 步：检查宽高比

比例这一列显示每张图片的形状，比如 16:9、4:3 或 1:1。当图片不符合标准形状时，也会显示精确比例。

把比例和目标位置匹配起来。4:5 竖图比方形更能填满手机动态，16:9 横图适合视频缩略图或网站主视觉。

留意那些接近但不等于标准比例的情况。一张 1.48:1 的图片看起来接近方形，但它不是 3:2，平台按 3:2 裁剪时会以你没想到的方式裁掉边缘。

如果比例不对，先裁剪图片再做其他处理。图片裁剪工具能精确裁成你需要的比例，之后用检查器确认结果。

第 4 步：按最小宽度和高度验证

在「最小宽度检查」和「最小高度检查」字段里输入平台的最小值。工具会标出所有低于任一数值的图片。

被标出的行就是你的待办清单。每一张都需要更大的源文件、一次缩放，或者一个接受较低质量的决定。

不要把被标出的图片放大了就以为问题解决了。放大是凭空编造像素，文件通过了数字检查，看起来却比真正的原始高清图要柔和。

当源文件无法再变大时，去找提供文件的人。摄影师或设计师手里有原始文件，通常几秒钟就能导出一个更大的版本。

第 5 步：把报告导出为 CSV 或 JSON

表格完成后，点击「导出 CSV」得到电子表格，或点击「导出 JSON」得到结构化数据文件。两者包含的列和屏幕上的表格一样。

CSV 可以在 Excel 或 Google Sheets 里打开，按宽度排序、按比例筛选，或者把被标出的行高亮出来交给同事修复。

JSON 是给开发者和自动化流程用的。它用脚本能读取的格式承载同样的数据，适合内容系统和质量看板。

关掉标签页之前先导出，因为表格只存在你的浏览器里。刷新就会清空，重新检查一个大批量纯粹是浪费时间。

快速检查一张图片

只查一张图片时，流程一样，但更快。把文件拖进来，读一下尺寸那一行，不到十秒就完成了。

粘贴是截图最快的办法。复制截图，在工具里按 Ctrl+V，不用保存任何文件就能看到尺寸。

在手机上，从相册上传图片。表格在小屏幕上也能用，关键数字不用横向滚动就能看到。

单张检查也是最快解决争论的办法。当两个人对一张图片够不够大意见不一致时，检查器给出的数字是谁都无法反驳的。

读懂打印尺寸这一列

「300 DPI 打印尺寸」这一列把像素换算成印刷质量下的英寸数。一张 3000 像素宽的图片显示为 10 英寸，这就是它安全的打印宽度。

把这个数字和你实际需要的尺寸比较。如果你需要印 8 英寸，而这一列显示 4 英寸，图片拉大到目标尺寸后看起来就会发软。

记住，300 DPI 是一个质量标准，不是法律。隔着房间看的海报用 150 DPI 印也可以，拿在手里的宣传册才需要完整的 300 DPI。

关于印刷的一般问题，确认像素足够之后，可以用图片 DPI 修改器设置文件的 DPI 元数据。

识别误导性的文件扩展名

一个叫 .jpg 的文件不一定真的是 JPEG。有人会改文件名，有些系统也会不小心把 WebP 存成 .jpg 扩展名。

检查器读取的是实际的图片数据，而不是扩展名。如果一个所谓的 JPG 实际上是 WebP，工具会报告文件真实的格式。

这很重要，因为有些平台会拒绝内容与扩展名不符的文件。在检查器里发现不匹配，能避免之后上传失败。

如果发现文件改错了名字，要正确地转换它，而不是再改一次名。图片转换器能写出格式和扩展名都正确的真正文件。

检查 SVG 文件

SVG 文件是矢量图，所以检查器从 width、height 和 viewBox 属性读取它们的固有尺寸，而不是数像素。

固有尺寸是设计师预期的尺寸。SVG 可以放大到远超这个尺寸而不损失清晰度，但预期尺寸告诉你要保持的比例。

如果 SVG 只有 viewBox、没有 width 或 height，检查器会显示比例，不显示绝对尺寸。这对为缩放而设计的响应式图标来说是正常的。

对图标来说，要把 SVG 的比例和你的布局对比。viewBox 为 0 0 24 24 的是正方形，放在宽槽里要么被拉伸，要么留下空白。

疑难解答：无法读取的文件

有时候一个文件完全读不出来，工具会把它标为错误。常见原因是下载损坏，或者这个文件根本不是图片。

先试着在图片查看器里打开这个文件。如果查看器也打不开，文件就是损坏的，需要重新下载或从源头重新导出。

超过 20 MB 的文件也会被拒绝。先压缩或缩放，再检查缩小后的版本，因为你要实际使用的就是缩放后文件的尺寸。

一个坏文件永远不会卡住批次里的其他文件。检查器会报告错误行，继续读取其余文件，坏的那个可以之后再修。

修复检查失败的图片

先从源头入手。先向对方要原始文件的大尺寸版本，再考虑任何软件修复，因为真正的原始高清文件永远胜过任何放大后的副本。

如果比例不对，裁剪它。图片裁剪工具能精确裁成平台要求的比例，重新检查一次就能确认新的尺寸。

如果文件太小，又没有更大的源文件，就用图片缩放工具放大，并接受变软的结果。这比上传失败要好，但要如实告诉客户质量上的取舍。

每次修复之后都要重新检查。第二次通过检查器，能确认新的尺寸，并留下一份干净的报告归档。

和团队分享报告

CSV 报告是最容易分享的东西。发给设计师、开发者或客户，每个人看到的都是同样的数字，而不是凭记忆争论。

发送之前，把被标出的行高亮出来。一份清楚标出失败项的报告，比一份让读者自己去找问题的原始表格修复得更快。

对经常重复的工作，一次约定好最小尺寸并写下来。之后每个批次都按同一个标准检查，报告之间也能互相比较。

把旧报告保存在项目文件夹里。当平台改变要求时，旧报告能显示哪些图片以前是合规的、哪些现在需要重新检查。

下印刷单之前先检查尺寸

印刷单是发现尺寸问题最贵的地方，因为错误只有在印好、付完钱之后才看得见。提前花两分钟检查，是整个流程里最便宜的保险。

先问印刷方要成品尺寸（英寸）和他们想要的 DPI，通常是 300。英寸数乘以 DPI，就得到需要的像素尺寸，把这个数字记下来。

把图片放进检查器，逐张和目标对比。任何一张不达标的图片印出来都会发软，而差距大小正好告诉你打印尺寸必须缩小多少才能保持清晰。

比例也要留意。按固定比例裁切的印刷厂会裁掉你的图片，所以要确认重要细节都安全地留在裁切区域之内。

同时检查文件格式。印刷厂做照片喜欢 JPG 或 TIFF，做图形喜欢 PDF 或 PNG，格式不对即使尺寸正确也可能造成延误。

最后，导出报告，和文件一起发给印刷方。能看到尺寸表的印刷方会在开印之前发现问题，这比在成品上发现问题要好得多。

把尺寸检查变成习惯

一次性检查只能解决一次性问题，但大多数尺寸故障会重复出现。同一个供应商每个月都发小图，或者同一个模板每次都以错误的比例导出。

把检查做到工作流程里，而不是当作应急步骤。每批新图片一到手，马上放进检查器跑一遍，在任何人开始用它设计之前。

简单记录一下什么失败了、为什么失败。几周之后，规律就很明显了，你可以修复源头——错误的导出预设、粗心的供应商，或者需要更新的模板——而不是一张一张地修图。

把这个习惯分享给团队。当每个人交接文件之前都先检查尺寸，故障就不会在最后一刻才出现，检查器也会从救火工具变成安静的后台步骤。

快速参考清单

把文件拖进来，先读尺寸列，再读比例，然后看像素数和文件大小作为参考。

输入最小宽度和高度，标出失败项，尽量从源文件修复，而不是放大。

任何东西送去印刷之前先看打印尺寸列，关掉标签页之前先导出 CSV 或 JSON 报告。

常见问题

怎么在手机上查看图片尺寸？

在手机浏览器里打开尺寸检查器，从相册上传图片。表格会显示宽度、高度、比例和像素数。也可以直接粘贴截图，不用保存文件就能检查它的像素尺寸。

不下载任何软件，能检查尺寸吗？

可以。检查器完全在浏览器里运行，桌面端和手机端都可以。不用安装、不用注册账号，文件也不会上传到服务器。

为什么 Windows 显示的尺寸和检查器显示的不一样？

Windows 资源管理器有时会显示四舍五入或为显示而缩放过的尺寸，有些应用还会显示应用 DPI 设置之后的尺寸。检查器读取的是文件里存储的真实像素宽高，这个数字才是平台实际检查的。

产品照片的最小宽度多少才合适？

这取决于平台，但大多数电商平台要求最长边至少 1000 像素，方便买家放大查看。一定要先查具体平台的最新规则，再把这个数字填进「最小宽度检查」字段。

检查器能读取粘贴的截图的尺寸吗？

可以。复制截图，在工具里按 Ctrl+V，它会立即读取像素尺寸。这是发送截图之前验证屏幕截图大小的最快办法。

如果我的图片比要求的尺寸小，该怎么办？

先向对方要更大尺寸的原始文件，因为放大是凭空编造像素，会让图片变软。如果确实没有更大的源文件，就用图片缩放工具放大，接受质量上的取舍，再重新检查确认新的尺寸。
