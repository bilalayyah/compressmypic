如何从图片中提取配色：5 步完成

你有一张颜色很喜欢的照片，需要把这些颜色变成一套配色，用在网站、海报或品牌上。凭眼睛复制又慢又不准。

本指南会用 5 个步骤带你从图片中提取配色：上传、选择色板数量、读懂百分比，再复制或下载结果。

熟悉之后，整个过程不到一分钟。不用安装软件，不用注册账号，文件也不会上传到任何服务器。

开始之前需要准备什么

你需要一张包含这些颜色的图片，格式为 JPG、PNG 或 WebP，单个最大 20 MB。照片、产品照、截图或艺术作品都可以。

知道这套配色是做什么用的。网站主题需要四到六种颜色，品牌视觉需要再多一点，情绪板可以用满十二种。

一个浏览器就是你需要的全部软件。工具在 Chrome、Safari、Firefox、Edge 上都能运行，桌面端和手机端都可以，不用装扩展。

最后，用你手头最干净的原始文件。重新压缩的副本或照片的截图可能让像素值轻微偏移，改变生成的配色。

第 1 步：上传图片或粘贴截图

打开图片配色提取器，把图片拖进上传区域。也可以点击上传区域，从设备里选择文件。

如果颜色就在你现在的屏幕上，截屏后用 Ctrl+V 粘贴。工具直接支持剪贴板图片，所以你可以从正在看的任何网站或应用里提取配色。

图片加载后，配色会立即出现，默认是 6 个色板。每个色板显示它的颜色、代码，以及它在图片里占的百分比。

如果传错了文件，可以在工具里换一张照片。旧配色会被替换，不用重新加载页面就能继续工作。

第 2 步：选择想要多少个色板

移动滑块，把色板数量设在 3 到 12 之间。每次移动，配色都会立即重建，所以几秒钟就能比较不同的数量。

从 6 个开始，看一下结果。如果两个色板看起来几乎一样，把数量降到 4 或 5，看着重复项合并成一种更干净的颜色。

如果在意的强调色不见了，把数量提高到接近 12。色板越多，小细节越有自己的盒子，一块小霓虹招牌或一朵小花就可能出现。

没有唯一正确的数量。极简网站想要 3 或 4 个，丰富的品牌板想要 8 或 10 个，滑块的存在就是让你找到适合自己项目的数字。

第 3 步：读懂百分比与颜色条

每个色板都带一个百分比徽章，显示这个颜色占图片的多少。百分比最大的颜色是主色，最小的那些是强调色。

把百分比读成设计的层次。主色应该占最大空间，次色起辅助作用，最小的颜色只用于高光。

看看色板下方按比例排列的颜色条。它用条带的形式展示同样的层次，色段宽度和百分比一致，平衡很容易判断。

如果颜色条大部分是一种颜色，说明照片有一个强势的主色调，你的设计会感觉平静。如果颜色条均匀分割，说明照片很忙，设计其他地方需要克制。

第 4 步：把配色复制为 CSS 或 JSON

点击「复制 CSS」，把所有色板复制为 CSS 自定义属性。变量按顺序命名，每个变量对应一个 HEX 值，可以直接粘贴进样式表。

配色要进入代码而不是样式表时，点击「复制 JSON」。JSON 包含每种颜色的 HEX、RGB、HSL 值和占比，以脚本能解析的形式呈现。

改一下色板数量，导出也会更新。你可以从 6 种颜色切换到 4 种，不用重新上传，复制的 CSS 或 JSON 会立即反映新的集合。

把导出结果和项目保存在一起。只存在浏览器标签页里的配色，关掉标签页就消失了，而保存下来的文件在项目继续时还在那里。

第 5 步：下载配色卡

点击「下载配色 PNG」，生成一张配色卡：原始照片，下面排列着色板条和颜色。它是这次提取的视觉总结。

把卡片分享给客户或团队。一张配色的图片比一串 HEX 代码沟通得更快，尤其对不读代码的人来说。

在情绪板、品牌文档和演示里使用这张卡片。它展示了颜色的来源，能建立信任，因为客户能看到源照片。

把卡片和项目文件保存在一起。几个月后配色被质疑时，卡片能在一张图片里展示来源和理由。

从照片里提取配色

照片是配色的最佳来源，因为它们的颜色在真实世界里本身就很协调。日落、街景或产品照都能提供一整套方案。

先从照片里最大、最平坦的区域入手。晴朗的天空、粉刷过的墙面或一件衣服，提取器能可靠地把它们排在高位。

留意混合光线。一张照片一边是暖阳光、一边是冷阴影时，可能产生同一个颜色的两个版本，在配色里看起来像重复项。

这时选择符合你想要氛围的那个版本。暖色适合温馨的设计，冷色适合利落的设计，两个都保留通常会让配色变浑浊。

从 Logo 里提取配色

Logo 是要求精确的场景，因为品牌配色必须完全一致。先找你手头质量最高的 Logo 文件，最好是纯色背景上的 PNG。

提取器会处理透明背景，忽略完全透明的像素。但透明背景上的 Logo 如果边缘半透明，仍然可能产生奇怪的结果。

想得到最干净的结果，先把 Logo 放在白色或品牌色背景上，再从那个版本提取。这样配色反映的是 Logo 的颜色，而不是透明度处理方式。

之后用图片取色器验证关键颜色。取色器读取精确的像素，当提取器的数值看起来略有偏差时，它能确认品牌色。

从截图里提取配色

截图是捕捉你喜欢的网站或应用配色最快的方式。截屏后用 Ctrl+V 粘贴，配色就会出现。

提取器按占比排出界面颜色，所以背景和主要表面占主导，按钮和链接颜色以小强调色的形式出现。

小心文字。满是文字的截图会从字母产生灰色和黑色色板，这些不是设计配色的一部分，应该忽略。

记住原创性问题。受另一个网站启发的配色没问题，但为客户工作整套照搬竞争对手的品牌配色是个糟糕的选择。

小强调色不见了怎么办

一个小强调色可能从配色里消失，因为提取器按占比排序颜色。只占照片 1% 的霓虹招牌可能被折叠进相邻的颜色。

先把色板数量提高到接近 12。色板越多，小细节越有自己的盒子，强调色出现的概率就越大。

如果还是没有出现，用吸管工具取它。图片取色器读取精确的像素，你可以手动把这个颜色加进提取出来的配色。

手动添加时，记下强调色的百分比。占 1% 的强调色是高光色，不是主色，用在大面积上会压垮设计。

修复配色里的重复色调

两个看起来几乎一样的色板通常来自渐变，比如天空从浅蓝慢慢变成深蓝。算法把渐变切成两个盒子。

保留更符合你设计的那个色调，去掉另一个。一套只有一个蓝色的配色，比一套有两个谁都分不出的蓝色更干净。

也可以降低色板数量。在 6 种颜色时，渐变通常落进一个盒子，重复项不用手动编辑就自己消失了。

去掉重复项时，检查百分比。保留的颜色应该在你的设计里承担合并后的占比，因为这两个色调合起来占了照片的那么多。

在 Figma、Canva 与 CSS 里使用配色

在 Figma 里，把每个 HEX 代码粘贴进一个颜色样式。每个色板创建一个样式，按它的角色命名，比如背景、主色、强调色，这样团队能一致地使用它们。

在 Canva 里，把 HEX 代码粘贴进品牌套件，或者粘贴进每个元素的取色器。配色之后在账号里的每个设计里都能用。

在 CSS 里，把复制的自定义属性粘贴进样式表，在每个地方引用变量。基于变量的配色很容易更新，因为改一个值就能更新整个网站。

对设计系统来说，把 JSON 导出作为事实来源保存。令牌流程可以读取它，从同一个文件生成 CSS、Figma 变量和文档。

不重新上传就切换数量

你可以随时改变色板数量，不用再次上传图片。移动滑块，配色会立即从同一张图片数据重建。

这对比较数量很有用。试试 4 个，再试 6 个，再试 8 个，看着配色获得细节、然后开始出现重复色调。正确的数量通常就在重复项出现之前。

每次改动之后，如果想保留几个版本，就复制 CSS 或 JSON。导出永远反映当前的数量，喜欢的版本可能在再次移动滑块时丢失。

上传新图片会自动清除旧配色。这让工具保持整洁，但也意味着切换图片之前，要先保存任何想保留的配色。

从产品照片里提取配色

产品照片是一种特殊情况，因为配色必须服务产品，而不只是照片。白底上的产品照给出的配色以白色为主，这对产品本身几乎没有说明。

做产品工作时，从生活场景照而不是影棚照提取。产品在使用中、在房间里或户外拍摄时，带有它所处环境的颜色，这些颜色能构成更好的配色。

只有影棚照时，提取之前先把产品裁紧。去掉白色背景，迫使提取器排出产品颜色，而不是它周围的空白。

拿配色和你知道的产品颜色对照。如果产品的品牌色缺失或偏移了，用吸管工具验证，手动加进配色。

产品配色会进入 listing、包装和广告，所以一致性比平时更重要。把 CSS 或 JSON 导出和产品文件保存在一起，在产品出现的每个渠道都用同一套配色。

对一个产品系列来说，从每个产品提取配色，再比较它们。共享一个配色家族的产品看起来像一个系列，配色互不相关的产品看起来像随机的拼凑。

季节性产品值得拥有季节性配色。夏季产品照给出明亮、温暖的颜色，同一产品的冬季版本给出更深的色调，配色应该随季节变化。

最后，在电商 listing 本身上测试配色。在设计工具里好看的配色，放在 listing 的白底和界面颜色面前可能失败，所以上线之前先在原地检查。

常见问题

提取出来的颜色，实际用的时候该怎么选？

从百分比最大的颜色开始作为主色，第二大的作为次色，最小的作为强调色。四到六种颜色对大多数设计已经够了。去掉近重复项和任何不符合氛围的颜色，哪怕它排名很高。

能从视频画面或电影帧里提取配色吗？

可以。截取那一帧的图，粘贴进提取器，配色就会出现。电影剧照是非常好的来源，因为摄影师会精心设计色彩方案。把它当作灵感，而不是为客户工作整套照搬电影的配色。

为什么百分比加起来不是 100%？

通常在四舍五入范围内是 100%。每个色板的百分比都四舍五入到整数，所以显示的数值加起来可能是 99% 或 101%。底层的占比是精确的，四舍五入只体现在显示上。

配色卡和 CSS 导出有什么区别？

配色卡是一张 PNG 图片，展示照片和它的色板，是给人看的。CSS 导出是带颜色变量的文本，是给代码用的。给客户和做演示时用卡片，给开发者时用 CSS。

能从黑白图片里提取配色吗？

可以，但结果会是灰色。百分比仍然展示照片的影调结构，设计单色方案时很有用。一张有力量的照片的灰色配色，可以成为极简设计的优雅基础。

怎么把提取出来的配色分享给不懂设计工具的客户？

下载配色卡 PNG 发过去。卡片展示源照片和下面的色板，任何人都能看到颜色和它们的来源。消息里也附上 HEX 代码，方便客户之后引用。
