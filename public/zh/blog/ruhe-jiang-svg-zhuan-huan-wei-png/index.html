如何把SVG转换成PNG

把 SVG 标志和图标转成需要尺寸的 PNG：上传、选缩放比例、检查结果、下载，一个文件或一整套都可以。

SVG 标志可以无限缩放，但很多地方还是只要 PNG。转换只要几秒钟，唯一真正重要的决定是输出尺寸。

比例选对了，PNG 看起来完美。选错了，要么模糊，要么大得没必要。

这篇指南一步一步带你走完流程，从上传 SVG 到下载一张锐利的 PNG。

开始之前：先准备好 SVG

先在浏览器里打开 SVG，确认它渲染正常。浏览器里看着不对，转成 PNG 也一样不对。

SVG 里有文字的话，先在设计工具里把文字转曲。转曲后的文字变成形状，不管什么字体都能精确渲染。

把外链图片以 data URI 的形式嵌进 SVG。转换器取不到外部文件，外链的照片会从 PNG 里消失。

想要透明 PNG，就删掉背景矩形。背景形状会变成图片的一部分，而透明的 SVG 依然保持透明。

第 1 步：打开 SVG 转 PNG 工具

在浏览器里打开 SVG 转 PNG 工具。Windows、Mac、Linux、ChromeOS、安卓和 iOS 都能用。

页面上有上传区和缩放比例选择器这两个控件，整个操作就是它们了。

不用注册账号，文件也不会上传。转换就在你的设备上完成，客户的标志和品牌素材也不用担心外泄。

用手机的话，直接在手机浏览器里打开这个页面就行。点一下上传区，就能从设备里选 SVG 文件。

第 2 步：上传 SVG 文件

把 SVG 文件拖到上传区，或者点一下打开文件选择器。一次选多个文件，就能批量转换。

每个文件都会显示为一张带缩略图的卡片，确认传对了文件。传错的文件很容易发现，也很容易删掉。

单个文件最大支持 25MB，哪怕是带几千条路径的超大插画文件都能覆盖。特别复杂的 SVG 只是多花一两秒。

电脑上还能用 Ctrl+V 直接粘贴复制好的 SVG。SVG 代码在别的软件里复制好之后，这个办法很方便。

第 3 步：选输出缩放比例

缩放比例选择器提供 1 倍、2 倍、3 倍和 4 倍。比例按 SVG 的自然尺寸放大，24 像素的图标用 4 倍就变成 96 像素的 PNG。

网站图标用 2 倍或 3 倍通常就够了。PNG 在高清屏幕上看起来锐利，又不浪费字节。

幻灯片上的标志用 4 倍比较保险。PowerPoint 里放大的小标志，只要背后的 PNG 像素够多，就能保持锐利。

打印按 300 DPI 需要的尺寸来选比例。2 英寸宽的标志打印出来至少需要 600 像素，从打印尺寸倒推就行。

第 4 步：转换文件

点“转换”按钮。工具会按选好的比例把每个 SVG 画到画布上，再编码成 PNG。

转换很快，每张通常只要一两秒。带几千条路径的特别复杂的 SVG，画起来要多花一点时间。

每张卡片都会更新，显示新的 PNG 大小和尺寸。看一下尺寸，确认缩放比例做出了你预期的大小。

某个文件转换失败并报错，SVG 里可能有不支持的功能或损坏的代码。先在浏览器里打开它，确认能在浏览器里正常渲染。

第 5 步：检查结果

点卡片上的“对比”，就能并排看到 SVG 和 PNG。放大看标志边缘，确认锐利干净。

SVG 里有文字就先检查文字。文字看着不对就是字体缺失，解决办法是把文字转曲再转换一次。

检查有没有缺失的图片。本该有照片的地方出现空白，说明图片是外链的，需要以 data URI 的形式嵌进去。

检查透明度。应该透明的标志周围不能出现白框，出现白框说明 SVG 里有个需要删掉的背景矩形。

第 6 步：下载 PNG 文件

点单张卡片上的“下载”，就能保存这一张 PNG。文件名保持原名，只把后缀换成 .png。

批量转换时，点“全部下载”可以拿到一个 ZIP，里面装着所有转好的 PNG。这比一张一张下载快得多。

用之前先检查一遍下载好的文件。在看图软件里打开一张 PNG，确认在你需要的尺寸下看起来锐利。

原 SVG 文件也留着。它们是母版，需要不同尺寸的 PNG 时，随时可以再栅格化一次。

  1. 打开 SVG 转 PNG 工具，上传 SVG 文件。
  2. 选缩放比例：网页用 2 倍，演示文稿和打印用 4 倍。
  3. 转换后检查边缘、文字和透明度。
  4. 单张下载 PNG，或整批打包成 ZIP 下载。

整套图标一起转换

在文件选择器里一次选中所有 SVG 图标。它们会全部进入队列，点一下就能用同一个比例全部转换。

整套用同一个缩放比例。图标常常一起出现，尺寸不一致看起来会参差不齐。

转换后抽查两三张图标就行，不用五十张全看。设置相同，抽查的几张没问题，其余的也不会有问题。

把 PNG 图标上传到需要的地方。网站图标、应用图标或幻灯片都直接接受 PNG，不用再转换。

按用途选尺寸

网站图标按网站需要的精确尺寸栅格化，通常是 16、32 和 48 像素。网站图标生成器也能从 PNG 做出这些尺寸。

社交媒体头像用 400×400 像素比较合适。电脑和手机上看起来都锐利，文件也保持很小。

演示文稿里的标志用 SVG 尺寸的 4 倍通常像素就够了。100 像素的标志用 4 倍变成 400 像素，幻灯片上看起来很锐利。

打印按 DPI 来算。2 英寸的标志按 300 DPI 需要 600 像素，选能达到这个数字的比例就行。

常见问题怎么修

PNG 看着模糊，是缩放比例太低了。用更高的比例从 SVG 原件重新栅格化一次，低分辨率的 PNG 之后再怎么处理也变不锐利。

文字看着不对，是字体缺失。在设计工具里把文字转曲，再转换一次。

外链照片不见了，就把它以 data URI 的形式嵌进 SVG。转换器取不到外部文件，图片必须跟着 SVG 本身一起走。

文件转换失败并报错，先在浏览器里打开 SVG。浏览器里能渲染的话，试试单独转换它，而不是放在批量里。

手机和平板上的小技巧

手机上点一下上传区，从设备里选 SVG 文件。转换就在手机上完成，PNG 会下载到你的设备里。

手机上批量别贪多，复杂的 SVG 在手机处理器上栅格化比较慢。一次转十张左右比较舒服。

下载的文件在手机的“下载”文件夹里。iPhone 在“文件”应用里找，安卓在文件管理器里找。

要转一大套图标，还是用电脑。更快的处理器和更大的屏幕，处理五十个文件要轻松得多。

为名片转换标志

名片上的标志要在很小的尺寸下印得锐利，所以用 4 倍栅格化 SVG。小标志背后的像素够多，印在卡片上才清晰。

转换后检查一下颜色，因为打印颜色和屏幕颜色不一样。先印一张小样，就能确认品牌颜色印在纸上是否正确。

把 PNG 发给打印店，同时附上 SVG 做备用。PNG 出了问题，打印店可以自己栅格化 SVG，两种都提供就万无一失。

PNG 文件别太大，名片印刷不需要很大的图片。1000 像素的标志对名片来说绰绰有余，文件更大只会拖慢上传。

整批印刷前先印一张测试卡。一张卡就能确认标志大小、颜色和锐利程度，再决定要不要印几百张。

为网站转换图标

网站图标从 SVG 文件开始，到老浏览器手里就变成 PNG。按显示尺寸的 2 倍或 3 倍栅格化，图标在高清屏幕上看起来才锐利。

整套图标用同一个缩放比例。图标常常一起出现，尺寸不一致看起来会参差不齐。

发布前在网站实际页面上测试一下图标。设计工具里看着完美的图标，放在网站背景色上可能看起来不一样。

现代网站可以考虑直接用 SVG 文件。浏览器原生显示 SVG，图标缩放完美，根本不用栅格化。

转换后把 SVG 母版留在项目文件夹里。网站改版后，图标可以按新尺寸重新栅格化，不用重新画。

为 T 恤印花转换 SVG

T 恤印花需要高分辨率图片，SVG 是理想的来源。用工具允许的最大缩放比例栅格化，上限是 8000 像素，印出来才清晰。

转换后检查一下设计，因为 T 恤印花会放大每个瑕疵。屏幕上看着没问题的标志，印大在布料上可能露出粗糙的边缘。

把 PNG 发给打印店，同时附上 SVG 做备用。打印店的软件可能更喜欢其中一种格式，两种都提供就万无一失。

深色 T 恤要检查透明度。透明背景的标志印在深色布料上很干净，带白框的标志看起来就不对了。

批量印刷前先印一件测试衫。测试印花能确认尺寸、颜色和位置，再决定要不要印几十件。

为演示文稿转换 SVG

演示幻灯片需要锐利的标志，SVG 是理想的来源。用 SVG 尺寸的 4 倍栅格化，投影到大屏幕上标志依然清晰。

转换后在幻灯片实际背景上检查标志。在白色上看着完美的标志，画质低了在彩色幻灯片上可能出现淡淡的毛边。

幻灯片多的文稿，把所有标志一次转好。批量转换几分钟就能完成，转好的 PNG 直接拖进幻灯片就行。

演讲前先在投影仪上测试一下文稿。笔记本上锐利的幻灯片，投影出来可能变软，提前测试就能早点发现问题。

转换后把 SVG 母版留在项目文件夹里。演示文稿换了新模板，标志可以按新尺寸重新栅格化。

为网站图标转换 SVG

网站图标是浏览器标签页里的小图标，通常从 SVG 标志开始。按 16、32 和 48 像素栅格化，覆盖标准网站图标尺寸。

网站图标设计得简单一点，太小的尺寸藏不住细节。16 像素下复杂的标志会糊成一团，简单的形状却依然能认出来。

加上之后在几个浏览器里测试一下网站图标。快速检查确认显示正常，网站在每个标签页里看起来都很精致。

现代浏览器可以考虑直接用 SVG 网站图标。浏览器原生显示 SVG 网站图标，图标缩放完美，根本不用栅格化。

转换后留着 SVG 母版。网站改版后，网站图标可以按新尺寸重新栅格化，不用重新画标志。

为网站横幅转换 SVG

网站横幅是一张宽图，横幅是图形而不是照片时，SVG 是理想的来源。按横幅的显示宽度栅格化，结果才锐利。

转换前先看横幅尺寸。显示宽度 1200 像素的横幅，PNG 至少要这么宽，不然看起来会发软。

带文字的横幅用显示尺寸的 2 倍栅格化。文字在高清屏幕上保持锐利，文件也小到能快速加载。

转换后在电脑和手机上都测试一下横幅。宽屏幕上看着完美的横幅，在窄屏幕上可能裁切得很糟，快速测试就能发现。

把 SVG 母版留在项目文件夹里。网站改版用了新的横幅尺寸，图形可以重新栅格化，不用重新画。

整个流程就是：准备、上传、选缩放比例、下载。想了解背后的原理，可以看SVG 转 PNG 完全指南；矢量与位图的问题可以看SVG vs PNG：矢量图与位图全面对比。SVG 混在批量文件里时，图片转换器也能处理。

常见问题

1 倍比例下 PNG 是多大？

1 倍时 PNG 和 SVG 的自然尺寸一样，24 像素的图标就变成 24 像素的 PNG。现代屏幕上想要锐利的效果，用 2 倍或 3 倍；演示文稿或打印用 4 倍。导出上限是长边 8000 像素，图标和标志很少会碰到。

手机上能转换 SVG 文件吗？

可以。在手机浏览器里打开工具，点一下上传区，从设备里选 SVG 文件。转换就在手机上完成，PNG 会下载到你的设备里。手机上批量别贪多，复杂的 SVG 在手机上栅格化比较慢。

导出的 PNG 会保留什么文件名？

PNG 会保留原来 SVG 的文件名，只把后缀换成 .png，logo.svg 就变成 logo.png。这样很好找，文件也保持整齐。批量转换时，ZIP 里每张 PNG 用的都是对应的原名。

转换器支持 SVG 动画吗？

不太支持。用 SMIL 或 CSS 做的 SVG 动画不会保留下来，因为转换器只把一帧静态画面画到画布上。结果是 SVG 开头那一帧的静态 PNG。动态标志就留着 SVG 本身。

SVG 里以 data URI 嵌的图片能栅格化吗？

可以。以 data URI 嵌进 SVG 的图片是文件的一部分，会在 PNG 里正确渲染。这是在 SVG 里放照片的正确办法。外链的外部图片正好相反，会被漏掉，因为转换器取不到它们。

为什么转出来的 PNG 看着模糊？

缩放比例对你要的尺寸来说太低了。24 像素的图标用 1 倍栅格化只有 24 像素，拉到 200 像素就会变糊。用更高的比例从 SVG 原件重新栅格化一次，低分辨率的 PNG 之后再怎么处理也变不锐利。
