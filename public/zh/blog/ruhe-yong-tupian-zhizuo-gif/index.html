如何用图片制作 GIF：从选帧到分享全步骤

几分钟就能把你的照片变成动态GIF：收集帧图片、上传、排序和设置时序、选择循环、预览，再下载一张可以直接分享的GIF。照片动起来，表情包和教程演示都生动很多。还讲了帧图片怎么排序、时序设多少才自然，以及预览之后怎样微调、确认动图流畅又不太大。操作起来很顺手。

用图片做 GIF 是个很快的活：收集几张照片，上传作为帧，设置时序，下载动画就行。这篇指南会按顺序带你走完每一步，从选帧到分享成品 GIF。

开始之前只需要准备一样东西：两张或更多要做成动画的图片。可以是照片、截图、产品图或插画。尺寸和形状接近的图片做出来的效果最平滑，工具也能处理尺寸混合的图片。

GIF 制作器会在浏览器里完成这项工作。什么都不用上传到服务器，不用注册，成品 GIF 免费下载。跟着下面的步骤走，几分钟就能做出一段动画。

第一步：收集帧图片

收集要成为 GIF 帧的图片。反应 GIF 需要几张能表现表情变化的照片，产品演示需要不同角度的照片，教程需要每个步骤一张图。

五到十五帧是大多数 GIF 的合适范围。帧少，动画短而有力；帧多，动画长而平滑。超过二十帧的 GIF，通常意味着它其实是想当一段视频。

尽量用尺寸相近的图片。尺寸和形状相同的帧动画起来很平滑，差别很大的帧会造成跳动和黑边。差别太大的话，先裁剪或缩放统一一下。

上传之前，先在脑子里排好帧的顺序。产品旋转按顺时针读，教程按步骤顺序读，反应按铺垫和释放读。开始之前顺序清楚了，之后就不用反复调整了。

第二步：上传帧图片

打开 GIF 制作器，把帧图片拖到上传区，或者点击选择设备里的文件。可以一次性全部上传，中途找到更多图片，也可以用添加帧功能之后再加。

工具支持 JPG、PNG、WebP、HEIC、GIF、BMP 和 SVG 文件，每张最大 20 MB。手机照片、截图和图形都能用。iPhone 的 HEIC 照片上传后会自动转换，不用额外操作。

帧会按你上传的顺序出现，排成一个可以重新排列的列表。继续之前，确认需要的图片都在里面。缺失的帧现在补，比设置好时序之后再补容易得多。

如果你上传了一张已有的 GIF 作为帧，工具可以从中提取一帧。当你想把一段旧动画里的某个瞬间用到新动画里时，这个功能很有用。

第三步：调整帧的顺序

拖动帧，按讲故事的顺序排列。第一帧是观众在动画开始之前看到的画面，最后一帧是循环重新开始之前看到的画面，所以两端都值得认真对待。

最强的一帧放最前面。在聊天或信息流里，第一帧就是缩略图，它决定有没有人看这段动画。第一帧平淡无奇，GIF 就会被直接跳过。

检查顺序里有没有跳动。本该在动作靠后的帧，放在列表靠前的位置，动画里会出现明显的跳动。把帧列表当作故事板来读，任何破坏流畅感的帧都移走。

删掉任何没有存在价值的帧。模糊的照片、重复的角度，或者对故事没有任何贡献的帧，只会让 GIF 更长、更重。少而精的帧，胜过很多平庸的帧。

第四步：复制或删除帧

想让某一帧停留更久，又不想改时序设置，就复制这一帧。复制过的标题页会显示两倍的时间，复制过的最后一帧能让信息在循环重新开始之前落下来。复制是强调某个瞬间最简单的办法。

复制也是在动画里重复某个瞬间的方法。产品角度出现两次，读起来像一次停顿；反应帧出现两次，读起来像一次强调。省着用，否则动画会感觉像卡住了。

删掉那些让 GIF 变慢又没有意义的帧。上一帧的近似复制品、模糊的照片，或者只是重复上一张的帧，都可以删掉。每删掉一帧，文件就小一点，动画也紧凑一点。

重复一帧不需要把同一个文件上传两次。复制功能在工具内部完成帧的复制，重复的瞬间不用额外上传，也不用额外管理文件。

第五步：设置帧延迟

帧延迟是每帧在屏幕上停留的时间，决定动画的感觉。先从快捷预设里选一个：每秒 1、2、5 或 10 帧。演示或反应通常从每秒五帧开始。

先给所有帧设一个统一的延迟，再单独调整需要更多时间的帧。标题页需要更长的停留，让观众读完；最后一帧需要更长的停留，让信息在循环重新开始之前落下来。

每帧用统一延迟，是 GIF 时序里最常见的错误。重要的帧匆匆掠过，来不及读；动作帧却拖得很慢。重要的帧多给时间，动作帧少给时间，GIF 才会感觉是经过思考的，而不是机械的。

调整的时候看着实时预览。看着数字觉得合适的延迟，动起来可能感觉不对，预览能显示真实的感觉。如果动画匆匆掠过关键帧，拉长那一帧就好，不用把整个 GIF 都放慢。

第六步：设置循环次数

选择 GIF 播放多少次。无限循环会永远播放，适合反应、装饰，以及任何想反复吸引眼球的内容。这是经典的 GIF 行为，也是默认选择。

有限循环按设定的次数播放，停在最后一帧。适合教程或演示，观众最后应该停在完成的状态。循环两三次，能让观众再看一遍，又不至于永远循环下去。

单次播放只播放一次动画就停下来。适合一次性的揭示，比如前后对比，结束时应该停在对比之后的样子。观众看到变化，然后结果留在屏幕上。

循环要跟着目的地选。聊天反应想要无限循环，产品演示想要几次循环，教程步骤想要停在结果上。循环选错了，再好的 GIF 也会感觉不对劲。

第七步：选择画面适配

画面适配决定帧的长宽比不一样时会发生什么。完整显示会把每帧完整放进输出尺寸，不做裁剪，整张图都能看见，多出来的空隙变成边框。

填满裁剪会裁剪帧图片，完全填满输出尺寸，没有空白带，但部分帧的边缘可能被裁掉。它做出来的动画干净、满幅，代价是损失边缘细节。

每帧的每个部分都很重要的时候，比如教程里裁掉一个按钮就会藏住步骤，选完整显示。动画必须干净填满画框的时候，比如社交帖子里空白带会显得没做完，选填满裁剪。

如果所有帧的尺寸都一样，适配设置没有意义，因为既没有东西要裁剪，也没有东西要填充。这个设置只对尺寸混合的帧组有影响，帧来自不同来源的时候检查一下它。

第八步：设置输出尺寸

根据 GIF 要分享的地方设置输出宽度。480 像素左右的宽度适合聊天和社交信息流，手机上看就是这个尺寸。更大的宽度适合网站或演示文稿，GIF 在那里显示得更大。

调整输出宽度时，长宽比保持固定，所以改宽度是整体缩放 GIF，而不是拉伸。宽度定一次，高度就跟着帧走。

GIF 通常越小越好。480 像素宽的 GIF 分享起来够快，看着也够清楚。1000 像素宽的 GIF 是好几倍的文件大小，大多数观众根本看不出差别。

生成之前，先检查目的地的限制。有些聊天应用和平台会缩小大 GIF，或者拒绝超过大小限制的文件，巨大的 GIF 只是在浪费流量，没有任何可见的好处。尺寸要跟着地方走。

第九步：检查实时预览

打开实时预览，按当前设置观看动画播放。这是最诚实的测试：预览显示的时序、循环和帧顺序，和下载的文件播放出来完全一样。

留意三个问题：一闪而过的帧、顺序断掉造成的跳动，以及循环重新开始时感觉突兀的衔接。第一帧和最后一帧决定循环的平滑程度，所以重新开始的那个点要仔细看。

问题在预览里修，别等下载之后再修。调整延迟、重排帧，或者改循环次数，再看一遍预览。在这里每次修正只要几秒钟，下载之后再修就要重新生成一遍。

GIF 是发给聊天或信息流的，在手机上也检查一下预览。桌面显示器上看着平滑的 GIF，在手机上可能感觉很快，观众会在手机上看到它。

第十步：生成并下载

预览没问题了，就生成 GIF。工具在浏览器里把帧编码成标准的 GIF89a 文件，短 GIF 几秒钟就能完成，帧多或调色板画质高的 GIF 需要更长时间。

留意大 GIF 警告。预计文件超过 5 MB 或 15 MB，工具会告诉你。先减小输出宽度，宽度减半能让像素变成四分之一，然后减少帧数或帧率。

下载成品文件，默认保存为 animated_compressmypic.gif。分享之前改成一个有意义的名字，比如 product-demo.gif 或 birthday-reaction.gif，之后找起来也方便。

打开下载的 GIF 播放一次，确认它能正常工作。检查时序、循环和大小。哪里不对就在工具里改设置重新生成，别想着去修成品文件。

GIF 太大怎么办？

GIF 太大通常有三个原因：帧太多、尺寸太大，或者帧率太高。按影响大小的顺序修，先从尺寸开始，它能省得最多。

输出宽度减半，文件会大幅缩小，因为像素数量变成四分之一。480 像素宽的 GIF 是同样 GIF 在 960 像素宽时的四分之一大小，手机上看着差别很小。

接下来砍帧数。删掉重复上一帧的帧，或者对故事没什么贡献的帧。每删掉一帧，文件大小就直接省下一份，更短的 GIF 通常也是更好的 GIF。

最后降低帧率。从每秒十帧降到每秒五帧，每秒动画的帧数减半。三招都用了还不够小，GIF 压缩器还能进一步压缩成品文件。

分享你的 GIF

在 WhatsApp、Telegram、Slack 和 Discord 这类聊天应用里直接分享 GIF 文件，这些应用都会内联播放 GIF。把文件作为附件上传，或者粘贴到消息里，对方不用任何额外操作就能看到动画。

社交平台上，把 GIF 作为媒体文件上传。大多数信息流都接受 GIF 上传并自动播放，有些会在后台把 GIF 转成视频。动画照样播放，观众看到的结果是一样的。

网站上用普通的 img 标签嵌入 GIF。页面加载时它会自动播放，放在动作能增加价值、而不是分散注意力的地方。教程里的 GIF 能把目光引到它演示的步骤上。

帧图片和成品 GIF 都要留一份。以后需要不同的尺寸、不同的循环，或者修正某一帧的时候，帧图片能让你几分钟内重新生成。光有一个 GIF，很难再把它编辑回原来的帧。

常见问题

做 GIF 需要多少张图片？

至少需要两张，因为 GIF 是一系列帧按顺序播放的动画。大多数 GIF 五到十五帧是合适的范围。帧少，动画短而有力；帧多，动画更长也更重。

开始之后还能再加帧吗？

可以。添加帧功能让你随时追加更多图片，哪怕时序已经设置好了。新帧会加到列表末尾，你可以拖动它们到正确的位置。

怎么让某一帧在屏幕上停留更久？

给那一帧设置更长的延迟，或者复制它，让它连续出现两次。两种方法都行，标题页用更长的延迟更干净，短暂强调复制起来更快。在实时预览里检查结果。

GIF 的帧可以用哪些图片格式？

工具支持 JPG、PNG、WebP、HEIC、GIF、BMP 和 SVG 文件，每张最大 20 MB。照片、截图和图形都能当作帧。如果你上传了一张已有的 GIF，工具可以从中提取一帧。

为什么我的 GIF 文件这么大？

GIF 把每一帧都存成一张完整的图片，帧多、尺寸大、帧率高，都会增加体积。先减小输出宽度，宽度减半能让像素变成四分之一，再减少帧数或帧率。

我做的 GIF 能在 WhatsApp 和 Instagram 上用吗？

可以。WhatsApp、Telegram、Slack、Discord 和 Instagram 都会播放 GIF。把文件作为媒体附件上传，它就会内联播放。有些平台会在后台把 GIF 转成视频，但动画照样播放，观众看到的是一样的。
