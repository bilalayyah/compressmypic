如何制作 Favicon：一步步教你生成网站图标

几分钟就能用 Logo 做出 Favicon：准备源图片、设置留白和背景、在浅色与深色标签下预览，再把图标包安装到你的网站上。

制作 Favicon 听起来很技术，其实只要用对工具，几分钟就能搞定。上传 Logo，调几个设置，下载一包文件，再把一小段代码加到网站上就行。这篇指南会按顺序带你走完每一步。

开始之前只需要准备两样东西：一个 Logo 文件，以及对你网站文件的访问权限。方形 PNG 或 SVG 格式的 Logo 效果最好，尺寸越大结果越清晰。如果只有 JPG，也能用。

Favicon 生成器会在你的浏览器里完成全部工作。Logo 不会离开你的设备，不用注册，生成的图标包以 ZIP 形式免费下载。跟着下面的步骤走，你的网站很快就能拥有一整套图标。

第一步：准备 Logo

打开 Logo 文件，确认它是方形，或者接近方形。方形的画布最能利用 Favicon 这个小小的空间，而宽长的 Logo 上下会留出空白带。如果你的 Logo 很宽，可以裁一个方形局部，或者用单字母版本。

检查分辨率。512×512 像素或更大的源图可以干净地缩到每个 Favicon 尺寸。64 像素的源图拉伸到 512 像素做安卓图标会发软，所以一定要用你手头最大的文件。SVG 文件最理想，因为它根本没有固定分辨率。

如果 Logo 里有小字或精细的细节，先简化它。文字商标下面的标语在 16 像素下完全看不清，做 Favicon 时可以去掉。保留最醒目的元素：图形符号、首字母，或者最有力的形状。

如果 Logo 是透明背景，先保持透明。透明背景在生成器里选择最多，因为之后随时可以加背景填充。JPG 没有透明通道，所以 PNG 或 SVG 是更好的起点。

第二步：上传到生成器

打开 Favicon 生成器，把 Logo 拖到上传区，或者点击选择设备里的文件。你也可以直接按 Ctrl+V，把剪贴板里复制的图片粘贴进来，Logo 正在别的软件里打开时特别方便。

工具支持 PNG、SVG、JPG、WebP 和 HEIC 文件，最大 20 MB。大多数 Logo 远小于这个上限，尺寸很少成为问题。如果是 iPhone 拍的 HEIC 格式照片，上传后会自动转换，不用额外操作。

文件一加载，生成器就会生成图标包的预览。你能立刻看到图形在几种尺寸下的效果，判断它在小尺寸和大尺寸下是否都清晰。如果 16 像素下看着不对，现在就回去改源图，别等到后面。

如果上传的是长方形 Logo，工具会把它放进方形画布，不做拉伸。检查一下结果会不会显得太小。如果太小，先回去准备一个更接近方形的版本，再继续下一步。

第三步：设置留白和形状

留白是 Logo 和图标边缘之间的空隙。先给一点点，只要图形不贴着画布边缘就行。Logo 贴着边框时看起来很挤，尤其在标签尺寸下，每个像素都很宝贵。

如果 Logo 边缘很细、线条很薄，可以把留白调大一些。细线在小尺寸下容易和边缘糊在一起，需要呼吸的空间。如果图形粗壮简单，留白可以小一点，大胆的形状可以更放心地填满画布。

圆角可以把图标背景的角磨圆。轻微的圆角能柔化外观，又不改变图形本身的性格。完全磨圆会把图标变成圆形，适合头像和应用风格的图标，但方形 Logo 可能会被裁得不自然。

调整这些设置时留意预览的变化。改动会同时应用到图标包里的所有尺寸，标签图标、苹果图标和安卓图标会一起更新。看到最小的预览依然清晰，就可以停下来了。

第四步：选择背景填充

背景填充是透明 Logo 后面的颜色。保持透明可以让图标保持轻盈，浏览器标签的颜色会从后面透出来。深色、粗壮的 Logo 配浅色标签时，这样做效果很好。

Logo 颜色浅、线条细的时候，就加一个纯色填充。白色或品牌色的方块能让图形在任何标签上都有对比。填充颜色会成为图标身份的一部分，所以尽量选和品牌一致的颜色。

Apple Touch Icon 会忽略透明度，用黑色填充空白区域，所以主屏幕图标用纯色填充最稳妥。即使标签页图标保持透明，生成器也能根据同一套设置，给苹果图标配好填充。

选好填充之后，在浅色和深色两种标签预览下都检查一遍。在浅色标签上好看的填充，在深色标签上可能显得沉重，反过来也一样。合适的填充能让图形在两种主题下都清晰，又不喧宾夺主。

第五步：检查预览

生成器会在浅色和深色浏览器标签上展示你的图标。如果 Logo 是深色的，先看深色预览；如果 Logo 是浅色的，先看浅色预览。Logo 颜色和标签颜色接近的那个预览，最容易暴露问题。

重点看最小的预览，也就是 16 像素的标签图标。这是访客最常看到的尺寸，也是细节最容易消失的地方。如果这个尺寸下还能认出图形，Favicon 就算成功了。如果变成一团模糊，就简化源图或调大留白。

再看一眼最大的预览，也就是 512 像素的安卓图标。小尺寸下清晰的图形，放大后可能显得空洞，尤其只有一个细字母的时候。大尺寸预览能告诉你这个设计放在主屏幕上是否站得住。

这一步千万别跳过。预览能发现两个最常见的失败：图标在深色模式下消失，以及图形在标签尺寸下糊成一团。现在修好只要几秒钟，上传之后再修，就要多花一整轮清缓存的时间。

第六步：下载图标包

预览没问题了，就下载 ZIP。里面有 favicon.ico、Apple Touch Icon、192 和 512 像素的安卓图标、site.webmanifest 文件，以及 HTML 代码片段。所有文件都已经命名好，可以直接上传。

如果只需要其中某一个文件，也可以单独下载。只拿 favicon.ico 就够给老网站做快速修复，而新网站最好用完整的 ZIP，一次拿到全套文件。

先在电脑上解压，上传之前看一眼里面的文件。确认图标尺寸齐全，清单文件也在里面。现在花几秒钟检查，能避免改完网站才发现少了文件。

把 ZIP 另外存一份备用。以后换品牌或丢了网站文件，ZIP 能最快恢复整套图标。想微调之后重新生成，也可以从它出发，不用从头开始。

第七步：上传文件

把图标文件上传到网站的根目录，也就是放首页的那个文件夹。浏览器默认会到根目录找 favicon.ico，放在那里，没加代码的页面也能被覆盖到。

用主机文件管理器、FTP 客户端或部署工具复制文件就行。文件都很小，上传只要几秒钟。确认每个文件都落在了根目录，而不是不小心进了子文件夹。

如果你的建站工具不开放根目录，就在后台找 Favicon 或网站图标的设置项。很多建站工具接受上传图标，自己处理文件存放。这时候上传 512 像素的 PNG 就好，建站工具通常会从大图开始缩放。

除非同时更新 HTML 代码，否则不要改文件名。文件名改了、代码路径还是旧的，效果和文件丢失一样，浏览器只会显示默认图标。

第八步：添加 HTML 代码片段

打开图标包里附带的 HTML 代码片段，里面有 Favicon、Apple Touch Icon 和网页清单的链接标签。整段代码原样复制，不要改里面的路径。

把代码粘贴到页面的 head 部分，放在其他 meta 和 link 标签附近。纯 HTML 网站可以加到每个页面，或者加到共享的头部模板里。React 或 Next.js 项目里，加到所有页面共用的布局或文档文件里一次就够了。

保存文件，在浏览器里重新加载网站。标签图标应该已经变成你的新 Favicon。如果没有变，旧图标可能是缓存的，这很正常，下一步会讲怎么处理。

如果清完缓存图标还是不出现，检查代码里的路径。路径指向一个不存在的子文件夹是最常见的原因。代码默认文件在网站根目录，放别处就要更新路径。

第九步：清除缓存并测试

浏览器会把 Favicon 缓存很长时间，所以上传之后，你自己的浏览器可能还会显示旧图标。按 Ctrl+Shift+R 硬刷新，或者直接打开 Favicon 的链接地址再刷新那个页面，强制重新下载。

再用第二个浏览器或隐私窗口测试，隐私窗口的缓存是空的，能看到新访客看到的样子。如果那里显示了新图标，说明上传成功了，只是主浏览器的缓存还没过期。

把网站添加到手机主屏幕，检查苹果或安卓图标。主屏幕图标是最大的版本，桌面预览藏住的瑕疵在这里会现形。在手机上看着没问题，整套图标才算完整。

收藏这个页面，看看收藏夹列表。Favicon 应该显示在保存的标题旁边。如果收藏夹里没有图标，通常是代码路径错了，或者文件根本没上传成功。

第十步：什么时候重新生成？

Logo 只要有改动，哪怕只是改了一点点，就重新生成图标包。新的文字商标、新的品牌色、微调过的图形，都值得做一套新图标，因为旧 Favicon 会在它出现的每个地方悄悄和新品牌对不上。

重新生成整套图标包，不要只换一个文件。只换 favicon.ico 的话，主屏幕和清单里还是旧图标，不同设备上新旧混杂，看起来很混乱。

如果改了网站名称或主题颜色，清单文件也要更新。生成器每次都会写一份新的清单，所以重新生成能让名称、颜色和图标一次同步，不用手改 JSON。

新图标包确认上线之前，先留着旧的 ZIP。如果新上传出了问题，旧文件几秒钟就能恢复。等标签页、手机和收藏夹里都确认是新图标了，再删旧包也不迟。

常见问题

做 Favicon 应该用什么 Logo 文件？

至少 512 像素的方形 PNG 或 SVG 效果最好。SVG 最理想，因为它可以无损缩放到任意尺寸。JPG 也能用，但它没有透明通道，所以 PNG 或 SVG 能让你对背景有更多控制。

为什么新 Favicon 上传后没有立刻显示？

浏览器对 Favicon 的缓存非常顽固，有时能缓存好几个星期。硬刷新一次，或者直接打开 Favicon 的链接地址刷新，也可以用隐私窗口测试。新图标会在其他访客的缓存过期后出现，或者在图标链接后面加版本号，让浏览器立刻重新下载。

Favicon 文件要放在网站的哪个位置？

放在网站的根目录，和首页同一个文件夹。浏览器默认会到根目录找 favicon.ico。然后把 HTML 代码片段粘贴到页面的 head 部分，这样浏览器才能找到苹果图标和清单文件。

HTML 代码片段要加到每个页面吗？

不用。加到所有页面共用的 head 模板或布局文件里一次就够了。纯 HTML 网站加到头部引用文件里，React 或 Next.js 项目加到布局或文档文件里。不用每个页面手工粘贴一遍。

可以用手机上的照片做 Favicon 吗？

可以，生成器也支持 iPhone 的 HEIC 照片，以及 JPG 和 PNG 文件。不过照片在 16 像素下很少能做出好效果，最好先裁出一个醒目的局部或一个强烈的形状，再上传。

Logo 不是方形的怎么办？

生成器会把长方形 Logo 放进方形画布，不做拉伸，但两侧可能留出空白，看起来偏小。想要最好的效果，先准备一个方形版本的图形，或者裁出最容易辨认的局部再上传。
