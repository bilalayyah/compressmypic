删除图片元数据：完整指南

教你如何安全地删除图片元数据：会清理哪些内容，无损清理与画布重新编码的区别，批量清理、ZIP 导出，以及如何验证文件真的干净了。

你分享的每一张照片都可能带有隐藏数据：你的位置、你的相机、你拍摄的确切时间。删除图片元数据，就是在别人读到这些数据之前，把它们从文件里拿掉。

本指南会讲清楚元数据删除做了什么、该选哪种方法、如何清理一整批照片，以及如何验证结果。全文围绕免费的删除图片元数据工具展开，它完全在你的浏览器里运行。

无需账号、无需上传、没有水印。你的照片不会离开你的设备，隐私工具本来就该如此。

什么是元数据删除？

元数据删除会删掉图片文件里存放的隐藏数据，同时保持像素原样不动。照片看起来完全一样，只是携带的信息变少了。

清理的目标包括 EXIF 相机详情、GPS 纬度和经度、拍摄时间戳、Adobe XMP 数据包、IPTC 字段、JPEG 注释，以及 PNG 文本块和时间块。

它还会删除嵌入的 EXIF 预览缩略图。相机照片常常在元数据里带有一张小预览图，这张预览图本身也可能泄露拍摄细节。

对清理后的副本来说，删除是永久性的。数据段一旦消失，就无法从这个文件里恢复，所以如果你想自己留存这些数据，请先保留一份原片。

你硬盘上的原始文件永远不会被改动。浏览器无法覆盖本地文件夹里的文件，所以清理总会生成一份单独的下载文件，原片保持原样。

分享之前为什么要删除元数据？

原因很简单：你不知道谁会下载这张照片，也不知道他们会用里面的数据做什么。二手交易平台的买家、论坛读者或陌生人，都可以在元数据查看器里打开任何图片。

GPS 坐标是最直接的风险。一张在家里拍的照片，就能让任何下载它的人知道你的地址。一组照片更能暴露你的日常规律。

相机序列号是更隐蔽的风险。它把照片与某一台设备绑定，如果同一个序列号出现在不同名字下，这两个身份之间的联系就暴露了。

时间戳同样会暴露规律。一组拍摄时间的模式，能看出你什么时候在家、什么时候出门、家里什么时候可能没人。

对卖家、记者、家长和任何公开发布的人来说，清理元数据是基本卫生习惯。只需几秒钟，就能消除一整类风险。

两种清理方法

工具提供两种清理照片的方法，选对方法很重要。两种方法都能删除元数据，但工作原理不同。

「无损二进制清理」是 JPG 和 PNG 文件的默认方法。它直接解析容器结构，删除元数据段，例如 JPEG 的 APP1 至 APP15 段和 COM 段，以及 PNG 的 eXIf、tEXt、iTXt 和 tIME 块，全程不解码、不重新压缩任何一个像素。

因为没有任何像素被重新编码，图片质量完全不受影响。文件会变小，常常能小几十 KB，清晰度却零变化。透明 PNG 的背景也能逐字节保留，因为被删除的只是辅助块。

「完整画布重新编码」走的是另一条路。它把像素画到一张全新的 HTML5 画布上，生成一张全新的压缩位图，不带任何继承下来的二进制段。

WebP 和 HEIC 输入会自动使用重新编码，更改输出格式时也是如此。当你想要绝对确定没有任何残留，或者无损清理后照片变横了，它也是正确的选择。

无损清理与画布重新编码的对比

想要清理得最彻底、同时质量零变化时，选择「无损二进制清理」。它最适合保持原始格式的 JPG 和 PNG 照片，是最好的默认选项。

更改输出格式、输入是 WebP 或 HEIC，或者想要一张没有任何继承片段的全新位图时，选择「完整画布重新编码」。

重新编码有一个代价：它会重新压缩像素，所以画质取决于「重新编码质量」滑块，范围从 50% 到 100%。无损清理没有这个代价，因为它从不触碰像素。

质量滑块只对 WebP 和 HEIC 输入，或者「完整画布重新编码」导出有效。无论你把滑块设成多少，它对「无损二进制清理」的文件都没有任何影响。

方向是另一个区别。无损清理会删除 EXIF 方向标记，可能让竖拍的 JPEG 看起来横了。画布重新编码会把竖直方向直接写进像素里。

如果竖拍照片在无损清理后看起来横了，请切换到「完整画布重新编码」，点击「重新清理全部」。导出的图片无需方向标签也能保持竖直。

删除元数据，分步操作

清理一张照片只需五步，而且最初几步在你上传的那一刻就自动完成了。

  1. 把照片拖进上传框。支持 JPG、PNG、WebP 和 HEIC，单个文件最大 20 MB，也可以按 Ctrl+V 粘贴。
  2. 查看自动清理和验证徽章。文件在上传时立即被清理并自动重新扫描，显示清理了多少标签，例如「已清理 X 个标签，剩余 0 个」。
  3. 如需调整设置，选择清理方法。JPG 和 PNG 保持「无损二进制清理」，想要全新位图时选择「完整画布重新编码」。
  4. 可选：设置输出格式和质量。选择原始、JPG、PNG 或 WebP 输出，把「重新编码质量」从 50% 调到 100%，然后点击「重新清理全部」。
  5. 下载清理后的文件或批量 ZIP。点击单张卡片上的「下载干净文件」，或者点击「下载全部干净文件（ZIP）」保存 clean_images_no_metadata.zip。

每个输出文件都会由内置的元数据解析器自动重新扫描。验证徽章确认剩余的敏感 EXIF 或 GPS 标签为零，所以这里没有任何猜测。

想看带图的分步详解，可以阅读如何删除图片元数据。

一次清理一整批照片

清理一张照片很快，但卖家和摄影师常常需要一次清理几十张。工具无需任何额外设置就能处理批量任务。

把多张照片一起拖进去，稍等片刻，所有卡片上的验证徽章都会变绿。每个文件都会被独立清理并重新扫描。

点击「下载全部干净文件（ZIP）」，即可把整批照片保存为 clean_images_no_metadata.zip。这一个文件装着所有清理后的照片，可以直接上传到二手交易平台或商品页面。

批量清理最适合在发布到二手交易平台、论坛或商品页面之前使用。在家里拍商品的卖家，可以一次清理整个拍摄批次，任何 GPS 数据都不会到达买家手里。

除了每个文件 20 MB 的上限之外，文件数量没有限制。清理不限张数，没有水印、无需注册、完全免费。

输出格式与质量

默认情况下，工具会保持原始格式，JPG 还是 JPG，PNG 还是 PNG。如果你只想去掉元数据、别的什么都不改，这是最安全的选择。

也可以在清理的同时转换格式。在「输出格式」下选择 JPG、PNG 或 WebP，设置「重新编码质量」，点击「重新清理全部」。每个文件都会通过画布干净地重新编码，元数据全部清理，并应用你选择的格式。

当商品页面需要更小的文件时，把干净的 PNG 直接转成 WebP 或 JPG 很有用。转换和清理一步完成，无需再跑第二遍。

请记住，PNG 透明度在无损清理后能保留，但并非每次转换都能保留。如果你需要透明背景，请保持 PNG 格式并使用「无损二进制清理」。

WebP 和 JPG 导出的质量设在 85% 左右是不错的默认值。数值越高，细节保留得越多；数值越低，文件越小。滑块只影响重新编码的导出。

验证清理后的文件

要信任，但要验证。清理之后，把下载的文件拖进图片元数据查看器，确认标签真的消失了。

查看器会独立解析原始二进制文件头。如果清理成功，绿色横幅会确认未检测到 EXIF、GPS 或隐藏相机标签，也不会出现 GPS 提醒。

工具本身也会验证自己的输出。清理完每张图片后，它会对输出文件再运行一次元数据解析，并显示一个绿色徽章，例如「已清理 X 个元数据标签，剩余 0 个」或「已验证干净」。

如果某个文件上传后立即显示「已验证干净」，说明源文件本身就不含 EXIF、GPS 或文本块。截图和聊天软件下载的照片常常就是这样。

对敏感照片，请养成验证的习惯。先查看原片，清理它，再查看清理后的副本。完整流程不到一分钟。

在手机上删除元数据

大多数照片都是从手机分享的，所以工具支持手机浏览器。在 iOS Safari 或安卓 Chrome 里打开页面，直接从相册里选照片即可。

绿色验证徽章出现后，把干净的副本直接下载到设备上。然后分享清理后的文件，不要分享原片。

请在发布之前检查，不要等到发布之后。照片一旦上传到二手交易平台或社交平台，可能已经有人下载了带有元数据的原片。

在支持的手机上，粘贴同样可用。在电脑上，按 Ctrl+V 或 Cmd+V 可以把复制的图片或截图直接放进上传队列。

删除元数据做不到的事

删除元数据不会改变照片拍到的内容。门牌号、校服、车牌或可辨认的背景，在像素里依然清晰可见。

它不会去掉可见水印，也不会模糊人脸或文字。处理这些问题，请用图片裁剪器把敏感区域裁掉，或者用模糊工具遮住它们。

如果图片本身就能认出你，它不会让照片变得匿名。删除元数据只是隐私保护的一层，不是完整的伪装。

它也不会缩小像素尺寸。一张 4000 像素宽的照片，清理后仍然是 4000 像素宽。如果需要更小的图片，请在清理之后或之前用图片尺寸调整器调整大小。

最后，它无法保护你已经分享过的照片。一张未清理的照片一旦公开，副本可能已经存在于别处。清理能帮到的是下一张照片，而不是上一张。

按来源清理照片

并不是每张照片的来路都一样，来源会影响需要清理的内容。直接从相册里拿的照片携带的元数据最多，包括 GPS 和完整 EXIF。

通过邮件收到的照片通常原样到达，原始元数据完整。转发或发布之前请先清理，因为发件人可能没意识到里面带了什么。

从聊天软件下载的照片常常已经是干净的。微信等应用在上传时会去掉 EXIF 和 GPS，所以你收到的文件没什么可清理的。

截图在大多数情况下根本不需要清理。剪贴板传递的是原始像素，截图不带相机文件头。工具只会确认文件已经干净。

编辑过的照片则难以预测。有的编辑器保留 EXIF，有的丢弃，有的还会加上自己的软件标签。即使原片是干净的，编辑后的导出文件在分享前也一定要检查。

拿不准的时候，把每个文件都过一遍清理工具。成本只有几秒钟，而本来就干净的文件只会显示一个「已验证干净」徽章，不会有任何损失。

清理后文件变小了多少

清理元数据通常会让文件变小，而且省下的空间比大多数人预想的要多。隐藏数据不只是几个数字。

相机照片常常在 EXIF 块里带有一个嵌入的预览缩略图。这张缩略图本身就是一张小 JPEG，去掉它能释放实实在在的空间。

Adobe XMP 数据包又增加了更多重量。编辑过的照片可能带有一长串 XML，记录每一次调整，这些文字可能达到几十 KB。

PNG 文件的文本块和时间块加起来也不少。作者姓名、注释和创建时间，单个来看都很小，但一个带有多个块的文件在清理后会明显变轻。

在「无损二进制清理」模式下，省下的空间完全不损失画质，因为没有任何像素被重新编码。更小的文件上传也更快，这对有大量照片的商品页面来说是个实用的好处。

如果你的主要目标是减小文件而不是隐私保护，可以先清理、再压缩。先清理照片，再用图片压缩器压缩，得到的文件既小又安全。

简要总结

删除图片元数据，就是去掉照片里隐藏的 EXIF、GPS、XMP、IPTC 和文本数据，同时保持像素不变。这是公开分享任何照片之前最简单的隐私步骤。

希望画质零变化时，对 JPG 和 PNG 文件使用「无损二进制清理」。处理 WebP、HEIC、更改格式，或者想要一张保证全新的位图时，使用「完整画布重新编码」。

批量清理、下载 ZIP，再用图片元数据查看器验证每个清理后的文件。然后放心分享，你的照片只会展示你选择分享的内容。

常见问题

删除元数据会改变我的照片外观吗？

不会。「无损二进制清理」只删除元数据段，绝不触碰像素，所以图片看起来逐字节相同。「完整画布重新编码」会重建像素，画质取决于「重新编码质量」滑块：设在 90% 到 100% 时差异肉眼不可见，设得更低时可能看到轻微的压缩柔化。

清理元数据之前，该保留一份原片吗？

如果元数据对你有意义，那就应该保留。清理对清理后的副本来说是永久性的，相机参数、GPS 坐标和时间戳都无法从中恢复。请把原片放在私人文件夹里自己留存，只分享清理后的副本。

删除元数据也会去掉照片方向吗？

无损清理会删除 EXIF 方向标记，可能让竖拍的 JPEG 在某些查看器里看起来横了。「完整画布重新编码」会把竖直方向直接写进像素，所以照片保持竖直。如果照片在清理后变横了，请切换到「完整画布重新编码」，点击「重新清理全部」。

已经发布到网上的照片，能清理元数据吗？

你可以清理自己手里的副本，但无法清理别人已经下载的副本。一张未清理的照片一旦公开，就可能存在于其他设备上。请删除或替换已发布的照片，改用清理后的版本，并保证今后每次上传前都先清理元数据。

删除自己照片的元数据合法吗？

合法。删除自己拥有的照片的元数据完全合法，这是你的数据，你有权选择不公开它。唯一需要注意的是不属于你的照片：去掉别人作品里的版权声明或署名字段可能违反许可条款，所以不是你拍的照片，请保留其中的署名信息。

如果照片本身拍到了我家或街道，清理元数据能保护我吗？

不能。删除元数据只会删掉隐藏的文件头数据。像素里看得见的任何东西，门牌号、路牌、校服、车牌，都会保留。遇到可见的识别信息，请在分享前裁掉或模糊处理，同时清理元数据。
