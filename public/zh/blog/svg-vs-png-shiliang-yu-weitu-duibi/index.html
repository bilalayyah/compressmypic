SVG vs PNG：矢量图与位图全面对比

SVG与PNG对比：矢量与位图、缩放、文件大小、透明度、浏览器支持，以及两种格式分别该用在什么时候。看懂矢量图和位图的根本差别，标志和照片就不会选错格式。还按标志、插画和照片分了场景，讲清矢量图什么时候无可替代、位图什么时候更实用，选格式有据可依。

SVG 和 PNG 是标志与图形最重要的两种格式，工作方式却完全相反。SVG 用代码描述形状，PNG 存的是像素网格。

这个差别决定了一切：图片怎么缩放、文件有多大、在哪里能用，以及什么时候该从一种格式转成另一种。

这篇文章会用通俗的话讲清楚矢量与位图，帮你为手头的每张图形选对格式。

矢量是什么意思？

矢量图存的是指令，不是像素。SVG 文件说在这里画个圆、填蓝色、在那里放文字，查看器就照着这些指令画出来。

图片是指令，所以能放大到任意尺寸。同一张 SVG 做成的 24 像素图标和广告牌看起来都一样完美，因为形状在每个尺寸下都会重新画一遍。

简单图形的矢量文件非常小。几处形状的标志存成 SVG 可能只有 3KB，同样标志存成 PNG 却可能有 50KB。

编辑矢量也很容易。改一下代码里的颜色值，所有用这个颜色的形状马上更新，不用重新画任何东西。

位图是什么意思？

位图存的是像素网格。PNG 文件说这个像素是蓝色、那个像素是白色，图片里的每个像素都这样一一说明。

网格尺寸是固定的。100×100 的 PNG 有一万个像素，拉到 500×500 就要凭空编造本来不存在的像素，看起来就会变糊。

位图最适合照片，照片本来就是像素网格。相机拍下来的是像素，存成像素就是最老实的做法。

位图也是通用的。每个软件、浏览器、打印机和设备都能显示 PNG，SVG 在某些场景下的支持还参差不齐。

缩放：SVG 完胜

SVG 可以无限放大，锐利度没有任何损失。形状在每个尺寸下都会重新画一遍，边缘从网站图标到广告牌都保持清晰。

PNG 只有缩小才干净。缩小大 PNG 看起来没问题，放大一张小 PNG 却会变糊，因为缺失的像素必须凭空编造。

标志要在很多尺寸下出现时，SVG 是唯一合理的母版格式。一个文件就能服务网站、演示文稿和打印店，而且画质都完美。

尺寸固定不变的图片，比如社交媒体头像，用 PNG 就行。尺寸永远不变，SVG 的缩放优势也就用不上了。

文件大小：看图片而定

简单图形用 SVG 要小得多。几处形状的标志存成 SVG 可能只有 3KB，存成 PNG 却有 50KB，相差十六倍。

复杂插画用 SVG 可能更大。带几千条路径和渐变的 SVG 可能达到几百 KB，同样图片的 PNG 反而更小。

照片根本没法用 SVG。照片转成矢量指令会变得巨大无比，所以照片永远是位图。

规则很简单：简单形状适合 SVG，复杂细节适合 PNG。标志属于 SVG，细节丰富的插画可能属于 PNG。

透明度：打平

两种格式都支持透明度。SVG 可以有透明背景，PNG 也可以，透明通道和柔和边缘都一样。

透明的 SVG 标志在任何背景色上都能用，透明的 PNG 标志也一样。差别不在透明度，而在缩放和兼容性。

半透明在两种格式里也都行。渐渐淡出的投影在 SVG 和 PNG 里看起来一样，因为两种格式都存了透明度值。

要在很多种背景上使用的标志，两种格式都行。看重缩放选 SVG，看重兼容选 PNG。

编辑：图形用 SVG 更胜一筹

编辑 SVG 就是改指令。给形状换个颜色、移动一条线、调整一组大小，改动精确又可以撤销。

编辑 PNG 就是改像素。给形状换颜色要先选中像素，既不精确，改动还会永久写进网格里。

标志要随季节或活动换颜色时，SVG 容易得多。改一行代码就能更新所有实例，PNG 却要手动重画。

照片的编辑本来就是改像素。SVG 在那里没有优势，因为照片天生就是位图。

浏览器与软件支持

现代浏览器原生显示 SVG。Chrome、Edge、Firefox 和 Safari 都能直接渲染 SVG 标志和图标，不用任何插件。

老软件就没那么可靠了。有些邮件客户端、办公软件版本和设计工具处理 SVG 很差，甚至完全不支持，而 PNG 到处都能用。

社交平台通常会把上传的 SVG 转成位图格式。上传的 SVG 标志到了平台上会变成 PNG 或 JPG，直接提供 PNG 更能控制结果。

打印店两种都接受，不过很多更喜欢 PNG，因为它可预测。SVG 在不同软件里渲染可能不一样，PNG 在任何地方看起来都一样。

什么时候用 SVG

网站上的标志用 SVG。标志在每块屏幕上都完美缩放，从手机到 4K 显示器都一样，文件还很小。

应用或界面里的图标用 SVG。图标出现在很多尺寸下，一张 SVG 就能服务所有尺寸，不用每个尺寸各存一个文件。

必须缩放的插画用 SVG。图表、示意图或地图用 SVG，在任何缩放级别下都保持锐利，细节丰富的图形尤其需要这一点。

任何图形都把 SVG 当母版格式。留着 SVG，需要时再栅格化出 PNG 副本，哪个目的地要求就给哪个。

什么时候用 PNG

目的地不接受 SVG 时用 PNG。表单、邮件、老软件和很多社交平台要的是位图，不是矢量文件。

图片必须在任何地方看起来都一样时用 PNG。SVG 在不同浏览器里渲染可能有差别，PNG 在每个软件里看起来都一样。

社交媒体头像和个人资料图片用 PNG。大多数平台反正会把上传的图片转成位图格式，直接提供 PNG 更能控制结果。

带几千条路径的复杂插画用 PNG。细节丰富的 SVG 可能比同样图片的 PNG 更大，渲染也更慢。

SVG 与 PNG 互转

SVG 转 PNG 叫作栅格化。选一个缩放比例，矢量形状就变成那个尺寸的固定像素网格。

PNG 转 SVG 叫作描摹，难度要大得多。描摹工具必须从像素里猜形状，结果很少能像原生的 SVG 那样干净。

一定要留着 SVG 原件。它是母版，需要不同尺寸的 PNG 时，随时可以再栅格化一次。

PNG 永远变不成真正的 SVG。位图标志需要矢量版时，在设计工具里重画，别用自动描摹。

标志的实用工作流程

标志用 SVG 设计，存成母版。这个文件是品牌的唯一真实来源，其他所有版本都从它来。

按每个目的地需要的尺寸栅格化出 PNG 副本。48 像素的网站图标、400 像素的头像、1200 像素的幻灯片标志，全都来自同一张 SVG。

网站上用 SVG，缩放完美又加载快。邮件、文档和社交媒体用 PNG，那里兼容性更重要。

标志改了，只更新一次 SVG，再重新栅格化 PNG。一次更新就能让所有版本保持同步，不用手动重画。

结论：哪个格式赢了？

缩放、编辑和简单图形的文件大小上，SVG 赢了。它是现代网页上标志、图标和插画更好的格式。

兼容性和可预测性上，PNG 赢了。它到处能打开，在每个软件里看起来都一样，复杂细节也比臃肿的 SVG 处理得更好。

大多数图形工作，答案是两者都要：SVG 做母版，PNG 做交付格式。留着矢量，栅格化出副本，各用在各自擅长的地方。

这两种格式是搭档，不是对手。SVG 保存设计，PNG 负责交付，两者之间的转换是图形工作的正常环节。

动画里的矢量图形

动画很喜欢矢量图形，因为形状可以移动、缩放和变形，锐利度一点不丢。放大十倍的矢量角色，每一帧都保持清晰。

SVG 动画用 SMIL 或 CSS 来移动形状。动画是代码，不是像素，所以在任何尺寸、任何屏幕分辨率下都保持流畅。

位图动画正好相反，每一帧都要存成像素。十秒的动画按每秒 30 帧算，需要 300 张像素网格，比矢量代码重得多。

网页动画就用 SVG。文件小，动作流畅，图形在每台设备上都完美缩放。

视频则以位图为标准。视频编码器能高效地存储像素，动画一旦变成视频文件，矢量的优势就消失了。

摄影里的位图

摄影天生就是位图。相机拍下来的是像素网格，把这些像素存成位图就是最老实的做法。

照片转矢量叫作描摹，效果很少好。描摹工具必须从像素里猜形状，结果是简化的卡通，而不是忠实的照片。

照片的母版就是位图格式。JPG、PNG 或 WebP 文件原样保存相机拍下的像素，没有凭空编造，也没有猜测。

编辑照片就是编辑像素。裁剪、校色和修图都在像素网格上进行，位图格式支持所有这些操作。

照片母版留着位图文件，每个目的地再转换一份副本。这个策略既保留了原始像素，又满足了每种需要。

游戏里的位图

游戏用位图做纹理、精灵图和背景。游戏世界由像素网格搭建，位图是存储它们的自然方式。

精灵图是带透明度的小位图，通常是 PNG 文件。角色精灵图需要精确的像素和透明背景，PNG 正好能提供。

纹理是贴在 3D 模型上的大位图。砖墙纹理就是一张照片，只有位图格式能装下照片的细节。

矢量图形出现在游戏界面里，图标和菜单需要缩放。矢量图标在任何分辨率下都保持锐利，游戏要在很多屏幕尺寸上运行，这一点很重要。

现代游戏两种格式都用。世界用位图，界面用矢量，每种格式做自己最擅长的工作。

两者结合的工作流程

大多数真实项目两种格式都用。网站有 SVG 标志和 JPG 照片，游戏有矢量图标和位图纹理，演示文稿有 PNG 截图和 SVG 图表。

流程从每个素材的正确母版开始。标志是 SVG 母版，照片是位图母版，每个素材在交付前都留在自己的自然格式里。

交付阶段再转换，不要提前转。目的地要求时标志才变成 PNG，网站需要时照片才变成 WebP。

母版按格式分文件夹存放。SVG 一个文件夹，位图一个文件夹，项目再忙也不会把两者搞混。

把项目的格式规则写下来。每种素材类型一句话，就能防止团队慢慢滑向格式混杂的老问题。

怎么教矢量与位图

教这个差别，从一个简单的演示开始。同一张标志，一个 SVG 版、一个 PNG 版，放大十倍，SVG 依然锐利，PNG 却变糊了。

放大测试是最清楚的一课。几秒钟就能展示出一段话讲不清的东西，学生对这个视觉差别记得很牢。

用学生自己的作品举真实例子。他们设计的标志、拍的照片，再问每张适合什么格式，课程一下就具体了。

文件大小的差别也要讲。简单标志存成 SVG 可能只有 3KB，同样标志存成 PNG 却有 50KB，数字一摆，效率差别就很明显了。

最后给一条实用规则：标志和图标用 SVG，照片用位图。这条简单的规则几乎覆盖了学生会处理的所有图片，例外情况以后再说。

常见问题

PNG 能转回真正的 SVG 吗？

不能真正转回去。PNG 转 SVG 叫作描摹，描摹工具必须从像素里猜形状，结果很少能像原生的 SVG 那样干净。位图标志需要矢量版时，在设计工具里重画，别用自动描摹。

为什么我的 SVG 在不同浏览器里看起来不一样？

SVG 渲染依赖浏览器引擎，不同引擎处理字体、滤镜和冷门功能的方式略有不同。PNG 在任何地方看起来都一样，因为它是固定的像素网格。想要像素级一致，就把 SVG 栅格化成需要尺寸的 PNG。

网站标志用 SVG 比 PNG 好吗？

通常是的。SVG 标志在每块屏幕上都完美缩放，从手机到 4K 显示器都一样，文件还很小。只有目的地不接受 SVG 时才用 PNG，比如邮件或老软件。网站本身用 SVG 是正确的选择。

Word 和 PowerPoint 里能用 SVG 文件吗？

新版 Word 和 PowerPoint 支持 SVG，老版本不支持，渲染效果也可能不一样。文档和演示文稿必须在任何地方都正常时，用 PNG。它在所有版本里都能打开，在每台机器上看起来都一样。

SVG 动画转成 PNG 后会怎么样？

动画会丢失。转换器只画一帧静态画面，因为 PNG 存不了动画。结果是 SVG 开头那一帧的静态图。动态标志就留着 SVG 本身，别转换它。

转成 PNG 后还应该留着 SVG 吗？

是的，一定要留着。SVG 是母版，需要不同尺寸的 PNG 时，随时可以再栅格化一次。PNG 永远变不成真正的 SVG，删掉原件就等于失去了以后干净缩放标志的能力。
