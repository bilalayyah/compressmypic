SVG转PNG完全指南

SVG 标志可以放大到任意尺寸都不会糊，可一半需要用到它的地方都不接受 SVG。表单、邮件或老软件要的是 PNG，SVG 必须变成像素。

把 SVG 转成 PNG 叫作栅格化，就是把矢量形状变成按你选的尺寸排列的固定像素网格。转出来的是一张普通的、到处能打开的图片。

这篇指南会讲清楚栅格化是怎么进行的、该选什么缩放比例，以及字体、外链图片和透明度这些容易踩的坑。

什么是 SVG 文件？

SVG 是可缩放矢量图形（Scalable Vector Graphics）的缩写。照片存的是像素，SVG 存的却是指令：在这里画个圆，在那里画条线，这个形状填蓝色。

文件描述的是形状而不是像素，所以能放大到任意尺寸都不失真。同一张 SVG 做成的 24 像素图标和广告牌，看起来都一样完美。

SVG 文件本身就是文本，可以用文本编辑器打开直接读代码。简单图形的文件也因此很小，常常只有几 KB。

这个格式最适合标志、图标和插画。照片不太适合用它，照片还是存成像素更好。

栅格化是什么意思？

栅格化就是把矢量形状变成像素网格。转换器读取 SVG 的指令，把形状画到画布上，再保存为 PNG。

关键选择是输出尺寸。24 像素的图标用 1 倍栅格化，得到 24 像素的 PNG；用 4 倍就得到 96 像素的 PNG，在高清屏幕上足够锐利。

一旦栅格化，图片就定型了。96 像素的 PNG 放大到 500 像素会变糊，不像原来的 SVG 那样可以随意缩放。

一定要留着 SVG 原件。它是母版，需要不同尺寸的 PNG 时，随时可以再栅格化一次。

选合适的缩放比例

网站图标用显示尺寸的 2 倍或 3 倍通常就够了。视网膜屏幕上显示的 24 像素图标，想要看起来锐利，就需要 48 像素或 72 像素的 PNG。

幻灯片上的标志用 4 倍比较保险。PowerPoint 里放大的小标志，只要背后的 PNG 像素够多，就能保持锐利。

打印要更大。2 英寸宽的标志按 300 DPI 打印，至少需要 600 像素，选能达到这个尺寸的缩放比例。

导出尺寸上限是长边 8000 像素。大多数图标和标志根本碰不到这个上限，100 像素的标志用 4 倍也只有 400 像素。

透明度得以保留

SVG 文件常常带有透明背景，PNG 会保留这种透明度。栅格化后的标志放在任何背景色上都很干净。

下载前用对比查看器检查一下结果。放大看标志边缘，确认透明度干净，没有白色毛边。

如果 SVG 里有个背景矩形，这个矩形会变成 PNG 的一部分。想要透明的效果，先在设计工具里删掉背景形状。

要在很多种背景上使用的标志，透明度必不可少。留着 SVG 母版，需要透明 PNG 时随时栅格化一张。

SVG 里的字体与文字

SVG 里的文字依赖字体，转换器可能没有你的 SVG 用的那种字体。字体缺失时，文字会回退到默认字体，样子就变了。

SVG 里引用的网络字体在转换时不会被加载。浏览器在栅格化环境里取不到它们，文字只能用备用字体渲染。

解决办法是转换前在设计工具里把文字转曲。转曲后的文字变成形状而不是字母，不管什么字体都能精确渲染。

标志用转曲文字本来就是专业标准。这样能保证字形在每台机器上看起来都一模一样。

外链照片与外部文件

SVG 可以引用外部图片文件，比如用链接指向一张照片。这张外链图片不会出现在 PNG 里，因为转换器取不到它。

外部 CSS 文件也一样。写在单独文件里的样式在转换时不会被加载，形状可能失去颜色。

解决办法是转换前把所有东西都嵌进 SVG 里。图片用 data URI，样式写成内联样式，文件就完全自包含了。

大多数设计工具在导出 SVG 时都有嵌入图片的选项。用上它，转出来的 PNG 就会和原图完全一致。

渐变、不透明度与特效

SVG 里的渐变在转换时能正确渲染。从一种颜色平滑过渡到另一种颜色，PNG 里也一样平滑。

不透明度也没问题。设为 50% 不透明度的形状，在 PNG 里是半透明的，会和后面的内容混合。

复杂的滤镜，比如 SVG 里定义的模糊和投影，通常也能渲染。浏览器的 SVG 引擎能正确处理大多数标准滤镜。

特别冷门的效果可能保留不下来。某个滤镜在 PNG 里看着不对，就在设计工具里简化它，或者接受这点小差别。

整套图标一起转换

整套 SVG 图标可以一次转换。每个文件独立转换，最后打包进一个 ZIP，直接就能用。

整套用同一个缩放比例。图标常常一起出现，尺寸不一致看起来会参差不齐。

单个文件最大支持 25MB，哪怕是带几千条路径的超大插画文件都能覆盖。特别复杂的 SVG 栅格化时只会多花一两秒。

转换后抽查两三张图标就行，不用五十张全看。设置相同，抽查的几张没问题，其余的也不会有问题。

什么时候用 PNG 而不用 SVG

目的地不接受 SVG 时用 PNG。表单、邮件、老软件和很多社交平台要的是位图，不是矢量文件。

图片必须在任何地方看起来都一样时用 PNG。SVG 在不同浏览器里渲染可能有差别，PNG 在每个软件里看起来都一样。

社交媒体头像和个人资料图片用 PNG。大多数平台反正会把上传的图片转成位图格式，直接提供 PNG 更能控制结果。

上网和以后编辑还是留着 SVG。矢量母版是你要回去找的文件，需要不同尺寸或不同格式时随时能用。

转换会改变颜色吗？

SVG 转 PNG 不会改变颜色。形状用的颜色值一样，PNG 原样保存这些颜色。

色彩配置是唯一微妙的地方。嵌了色彩配置的 SVG 在 PNG 里渲染可能略有不同，不过差别通常看不见。

品牌颜色要拿 PNG 和原件对照一下。两张并排打开，确认颜色一致，饱和度高的品牌色尤其要看。

某个颜色看着不对，问题通常是字体缺失或外链图片，而不是颜色本身。先检查这两处，再怪转换。

转换后的文件大小

一张 5KB 的小 SVG 图标，转成 PNG 后可能变成 20KB 甚至更大，具体看缩放比例。像素比矢量指令更占字节，尺寸越大越明显。

PNG 大小随缩放比例的平方增长。比例翻倍，像素数变成四倍，所以 4 倍的 PNG 是 1 倍 PNG 的十六倍大。

选够用的最小缩放比例。网站图标用 2 倍 PNG 就够了，同样图标用 4 倍只会白白浪费字节，看不出任何好处。

大幅打印的 PNG 体积大是免不了的。300 DPI 的打印文件本来就需要很多像素，PNG 大才是对的。

常见问题与解决办法

SVG 栅格化失败并报错，文件里可能有不支持的功能或损坏的代码。先在浏览器里打开它，确认能在浏览器里正常渲染。

文字看着不对，是字体缺失。在设计工具里把文字转曲，再转换一次。

外链照片不见了，就把它以 data URI 的形式嵌进 SVG。转换器取不到外部文件，图片必须跟着 SVG 本身一起走。

PNG 看着模糊，是缩放比例太低了。用更高的比例从 SVG 原件重新栅格化一次，低分辨率的 PNG 之后再怎么处理也变不锐利。

社交媒体上的 SVG 标志

社交平台不接受 SVG 上传，标志要做头像或封面图，必须先变成 PNG。按合适的尺寸栅格化，结果才锐利。

头像用 400×400 像素栅格化。电脑和手机上看起来都锐利，文件也小到能快速上传。

封面图按平台推荐的尺寸栅格化。Facebook、X 和领英的封面尺寸各不相同，尺寸合适比格式更重要。

转换后检查一下标志，因为社交平台会把头像裁成圆形。重要细节靠近边缘的标志，可能会被圆形裁切掉。

留着 SVG 原件给下一个平台用。出现要求尺寸不同的新社交平台，只需重新栅格化一次，不用重新设计。

应用里的 SVG 图标

应用图标在设计工具里是 SVG 文件，到应用商店就变成 PNG。每个商店的尺寸要求都不一样，一张 SVG 能做出很多张 PNG。

App Store 的图标用 1024×1024 像素栅格化，再按比例缩小做更小的尺寸。大尺寸母版在每个更小的尺寸上都能出锐利的结果。

安卓按 Play 商店列出的尺寸栅格化，商店图标通常是 512×512，启动器图标更小。同一张 SVG 能满足所有尺寸。

提交前在浅色和深色背景上都测试一下图标。依赖白色背景的图标在深色主题下会直接消失，解决办法是用透明版本。

把 SVG 母版留在项目仓库里。它们是源素材，每个平台的构建都从它们开始，值得放进版本控制。

印刷品里的 SVG

名片、传单、海报这类印刷品需要高分辨率图片，SVG 是理想的来源。按 300 DPI 栅格化，印出来才清晰。

名片上的标志用 4 倍 SVG 尺寸栅格化。印在卡片上的小标志，只要背后的 PNG 像素够多，就能保持锐利。

海报用工具允许的最大缩放比例栅格化，上限是 8000 像素。大尺寸印刷需要很多像素，这个上限很少会真的限制海报工作。

转换后检查一下颜色，因为打印颜色和屏幕颜色不一样。先印一张小样，就能确认品牌颜色印在纸上是否正确。

把 PNG 发给打印店，同时附上 SVG 做备用。PNG 出了问题，打印店可以自己栅格化 SVG，两种都提供就万无一失。

邮件签名里的 SVG

邮件签名需要一个小标志，大多数邮件客户端不支持 SVG。把标志栅格化成 PNG，宽度通常是 100 到 200 像素。

PNG 文件尽量小，最好在 50KB 以内。每封邮件都带一个大标志既浪费流量又惹人烦，小标志能瞬间加载。

把标志放在你的网站上，在签名里链接它，而不是作为附件发送。链接的图片从你的服务器加载，邮件本身保持很小。

全面推广前，在几个邮箱客户端里测试一下签名。在 Gmail、Outlook 和 Apple Mail 里快速看一遍，就能在联系人之前发现破损图片。

带透明度的标志，PNG 能保留透明。签名标志放在任何邮件背景上都很干净，JPG 版却会显示一个白框。

网站图标里的 SVG

网站图标是浏览器标签页里的小图标，通常从 SVG 标志开始。按 16、32 和 48 像素栅格化，覆盖标准网站图标尺寸。

现代浏览器也直接接受 SVG 网站图标，所以可能根本不用转换。决定前先看你的受众用的浏览器是否支持。

老浏览器用 PNG 网站图标更安全。32 像素的 PNG 在所有浏览器里都能用，SVG 网站图标在老浏览器上可能失败。

网站图标设计得简单一点，太小的尺寸藏不住细节。16 像素下复杂的标志会糊成一团，简单的形状却依然能认出来。

加上之后在几个浏览器里测试一下网站图标。快速检查确认显示正常，网站在每个标签页里看起来都很精致。

准备好栅格化了吗？打开 SVG 转 PNG 工具，把文件拖进去就行。具体步骤可以看如何把 SVG 转换成 PNG，矢量与位图的问题可以看SVG vs PNG：矢量图与位图全面对比。SVG 混在批量文件里时，图片转换器也能处理。

常见问题

24 像素的图标，要选什么比例才能转出锐利的 PNG？

用 4 倍，得到 96 像素的 PNG，在高清屏幕和演示文稿里都锐利。网站图标用 2 倍或 3 倍通常就够了。打印要选能达到 300 DPI 的比例。导出上限是长边 8000 像素，图标和标志很少会碰到。

SVG 转 PNG 能保留透明背景吗？

可以。透明背景的 SVG 转出来就是透明 PNG，标志放在任何背景色上都很干净。如果 SVG 里有个背景矩形，这个矩形会变成 PNG 的一部分，想要透明效果就先在设计工具里删掉它。

为什么转换后的 PNG 里少了外链照片？

转换器在转换时取不到外部文件，任何用链接引用的图片都会被漏掉。转换前把图片以 data URI 的形式嵌进 SVG 里，文件就完全自包含了。大多数设计工具在导出 SVG 时都有嵌入图片的选项。

SVG 里能用网络字体导出 PNG 吗？

不太可靠。SVG 里引用的网络字体在转换时不会被加载，文字会回退到默认字体。转换前在设计工具里把文字转曲，字形变成形状后，不管什么字体都能精确渲染。

SVG 能转出的最大 PNG 是多大？

导出上限是长边 8000 像素，特别大的 SVG 用 4 倍时会在这个上限处停下。大多数图标和标志根本碰不到上限，100 像素的标志用 4 倍也只有 400 像素。打印用的话，要确认上限后的尺寸还能满足 DPI 要求。

转出来的 PNG 是无损的吗？

是的。PNG 是无损格式，栅格化画出来的像素会原样保存。不过 PNG 的锐利程度不会超过这次栅格化，因为矢量形状已经按选好的比例定型成像素了。想要更锐利，就用更高的比例从 SVG 原件重新栅格化一次。
