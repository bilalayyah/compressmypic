每个设计师都遇到过这样的时刻：屏幕上看到一个颜色，想要它的准确色值。截图、照片、Logo 或者网站设计稿里可能藏着最完美的那个色调，但靠猜永远猜不准。

图片取色器几秒钟就能解决这个问题。打开一张图片，对准任意一个像素，就能读到它的 HEX、RGB、HSL 与 CMYK 代码。

本指南会介绍 CompressMyPic 图片取色器的工作方式、每种颜色代码的含义，以及如何在实际设计与开发工作中使用取到的颜色。

图片取色器是什么？

图片取色器是一款浏览器工具，可以读取你上传的图片中任意像素的颜色。它就像设计软件里的吸管工具，只是不用安装任何东西。

把照片或截图拖进工具，移动鼠标，工具就会实时显示光标正下方那个点的颜色。数值会随着你的移动不断更新。

工具支持 JPG、PNG、WebP、GIF 等常见图片格式，单个文件最大 20 MB，几乎所有照片、Logo 和截图都能取色。

一切都在你的浏览器本地完成。图片不会上传到任何服务器，所以客户的设计稿和未发布的品牌素材在取色时依然是私密的。

吸管工具如何读取像素

每一张数字图片都是由一个个叫像素的小方格组成的网格。每个像素只存一种颜色，用红、绿、蓝三组数值来表示。

当你点击图片上的某一点，工具会读取这个像素的红、绿、蓝数值，然后把这三个数字转换成你可能需要的各种颜色格式。

这个读数是精确值，不是估算。像素本身就是这个颜色，复制下来的代码能在设计文件、样式表或印刷文档里原样还原它。

不过，单个像素有时也会让人意外。在照片里，相邻像素的颜色常常略有不同，横向移动一步，HEX 代码的最后一位就可能变了。

颜色代码详解：HEX、RGB、HSL、CMYK

每个取到的像素都会同时给出好几种颜色代码。HEX 是网页开发者在 CSS 里用的六位代码，比如 #2563EB 就是一个明亮的蓝色。

RGB 用 0 到 255 的三个数字表示同一种颜色，分别对应红、绿、蓝。大多数设计工具和图片编辑器都原生支持这种格式。

HSL 用色相、饱和度和亮度来描述颜色。设计师喜欢它，因为它更符合人对颜色的直觉：先选一个色相，再让它更浓或更淡。

CMYK 用油墨百分比来表示印刷颜色。它在屏幕上只是一个近似值，因为屏幕用光、印刷用墨，但作为印刷工作的起点很有用。

11×11 放大镜：为什么放大很重要

在正常缩放比例下，想点中正确的像素并不容易。一条细线、一个小图标或一像素宽的边框，稍微偏一点就点错了，取到的颜色也就不对。

工具用一个 11×11 的放大镜解决了这个问题。它会放大显示光标周围的像素，让你看清自己即将取样的到底是哪一个像素。

放大镜在处理界面截图时尤其有用。按钮、分隔线和文字常常处在抗锯齿边缘，颜色会在两三个像素之间混合过渡。

有了放大功能，你可以瞄准图形实心的中心，而不是混合的边缘。这一个选择，往往就是取到真实品牌色还是取到一个浑浊中间色的区别。

收藏色板：建立你的颜色集合

一种颜色很少够用。品牌配色、网站主题或幻灯片需要好几种能搭配的颜色，工具可以让你一个一个地收集它们。

每次点击，取样的颜色就会加入「已取色板」。你可以从同一张图片里收集主色、强调色、背景色和文字色。

色板在工作时会一直可见，方便你并排比较。如果两次取到的颜色几乎一样，可以删掉一个，保留更干净的那个。

重复点击同一个 HEX 值不会产生重复项。工具会让你的收藏保持整洁，这在取样一张有大量相近色调的照片时很重要。

导出 CSS：从图片到样式表

收集好的色板只有能带进项目才有用。「导出 CSS」按钮会把你取到的颜色下载为可以直接使用的 CSS 自定义属性。

下载的文件里包含 --color-1、--color-2 这样的变量，每个变量对应一个 HEX 值。你可以把它们粘贴进样式表，在设计的任何地方引用。

这比一个一个地把色值抄进文本文件方便多了。导出文件把所有颜色集中放在一处，顺序正确，也不会出现抄错的情况。

如果想要更完整的配色流程，图片配色提取器可以自动生成按占比排序的配色。想取某个精确像素时用取色器，想得到整张照片的主色时用提取器。

从照片中取色

照片是最常见的取色来源。日落、产品照或旅行照片都能提供一整套本身就很协调的配色。

先从照片里最大、最平坦的区域入手。晴朗的天空、粉刷过的墙面或一件纯色衣服，取到的颜色最稳定，比杂乱的纹理可靠得多。

避开最亮的高光和最深的阴影。这些区域常常已经过曝或死黑，真实的颜色信息已经丢失，取到的代码只是白色或黑色。

同一个区域多取几次，再比较结果。如果代码集中在某一个值附近，那个值就是这个表面的真实颜色；如果结果很分散，就取中间的那个值。

从 Logo 和截图中取色

Logo 和界面截图是最讲究精确度的场景。品牌颜色必须完全一致，差一点点，放在真实 Logo 旁边就会显得不对。

取 Logo 的颜色时，要取大块纯色区域的中心。字母或色块的中心是实心的，边缘会和背景混合，给出混合后的数值。

取截图的颜色时，能用 Ctrl+V 直接粘贴就直接粘贴。工具支持粘贴剪贴板里的图片，截屏后不用先保存文件就能取色。

取截图颜色时，留意像素检查器里显示的像素坐标。坐标能帮你在之后需要验证某个数值时，回到完全相同的那个点。

颜色准确度：JPEG 噪点与透明度

JPEG 压缩会轻微改变像素颜色。这种格式把颜色按小块存储，所以平滑天空里相邻的两个像素，色值可能差上一两位。

这种变化很正常，对大多数工作也没有影响。取那个区域里出现次数最多的值，肉眼看上去的结果就是对的。

PNG 文件则不同。PNG 存储的是精确颜色，所以读到的代码就是文件里实际存的代码，完全没有压缩噪点。

透明区域需要小心。取 PNG Logo 透明部分的色值，读到的是透明层之下的颜色，可能是白色或黑色，而不是你以为的那个颜色。

手机与触屏上取色

取色器在手机和平板上也能用，和桌面端一样。点一下图片代替点击鼠标，放大镜和色板功能都是一样的。

触摸没有鼠标精确，因为一根手指会盖住很多像素。放大镜在这里更加重要，它能显示手指底下到底是什么。

如果目标很小，先在浏览器里放大图片再点。图片越大，手指的目标就越大，取到相邻像素的概率就越低。

对于关键的品牌色，之后最好在桌面端再验证一次。手机点一下能接近目标，但鼠标精确点中一个像素才是可靠的最终检查。

取色时常见的错误

最常见的错误是取到了边缘而不是平坦区域。抗锯齿边缘会混合两种颜色，混合出来的值既不属于这个，也不属于那个。

另一个错误是在有噪点的照片上只点一次就相信结果。颗粒感图片里的单个像素可能是个异常值，所以同一个位置至少取两三次。

很多人还忘了屏幕之间有差异。同一个 HEX 代码在两台显示器上看起来可能略有不同，所以判断颜色要看代码本身，不只看它在你屏幕上的样子。

最后，不要从「截图的截图」里取色。每一次截取和重新保存都可能让颜色轻微偏移，一定要用你手头最干净的原始文件。

取色器与配色提取器的区别

取色器和配色提取器回答的是不同的问题。取色器告诉你自己选中的某一个像素的确切颜色，提取器则找出整张图片的主导颜色。

当你明确知道自己想要什么时用取色器：Logo 的确切蓝色、按钮的确切色调，或者照片里某面墙的确切颜色。

当你想要灵感时用提取器：它会按占比排出照片里最重要的五六种颜色。这是快速得到一整套配色的办法。

很多设计师两个都用。先用提取器得到整体配色方案，再用取色器抓一个提取器排名太低、没有收录的精确强调色。

谁会用到图片取色器？

网页开发者用它来精确还原设计稿。当客户发来的是截图而不是设计文件时，取色器能找回真实的 HEX 代码。

平面设计师用它从参考照片里搭建配色。一张情绪板照片就能提供海报或品牌视觉的整套配色方案。

印刷设计师把 CMYK 读数当作起点。它不是完美的印刷匹配，但能告诉他们屏幕上鲜艳的颜色印到纸上之后还能保留多少。

内容创作者用它做缩略图和社交媒体图片。缩略图的强调色和品牌色保持一致，整个频道几十个视频看起来才会统一。

隐私：图片只留在你的浏览器里

当图片是客户的设计稿、未发布的产品照或私人照片时，隐私就很重要了。把这类文件上传到不知名的服务器，风险完全没必要冒。

这款工具全部在本地处理。浏览器读取图片，在你的设备上取样像素，什么都不会离开你的电脑。

这也意味着页面加载好之后，工具可以离线使用。在飞机上、会议室里，或者任何没有网络的地方，你都能取色。

如果你经常处理敏感的品牌素材，本地处理就是决定性的功能。没有上传，就不会有任何一份文件副本留在你控制之外的服务器上。

从渐变与图案中取色

渐变是一种特殊情况，因为颜色会从一端平滑地过渡到另一端。渐变里没有唯一的「正确颜色」，只有你取样那个点的颜色。

要还原一个渐变，可以沿着它的长度多取几个点。取起点色、中间色和终点色，就能在 CSS 里用这三个色标重建这个渐变。

图案也需要同样的耐心。条纹或格子表面至少包含两种颜色，而取色器一次只能读到光标下的那一个像素，读不到整个图案。

遇到图案时，把每一条不同的色带分别取样，全部保存为色板。这样一组色板就能描述这个图案，尽管一次点击做不到。

木纹、布料或石头这类有纹理的表面是最难的情况。它们的颜色逐像素变化，一次读数几乎没有意义。

处理纹理时，在附近取五六个像素，看看它们的平均值。出现次数最多的那个值，就是这个表面最好的单一代表色，用在设计里看上去也是对的。

如何使用图片取色器

在浏览器里打开图片取色器。把图片拖进上传区域，或者直接从剪贴板粘贴截图。

图片加载后会立即显示一个默认颜色，取自图片中心。移动鼠标探索，观察放大镜如何放大指针下的像素。

点击任意像素，把它加入「已取色板」。不断点击，收集设计所需的全部颜色。

收集完成后，点击「导出 CSS」，把颜色下载为样式表变量。想看分步操作，可以阅读如何从图片中取色，想了解代码格式，可以阅读HEX、RGB、HSL 颜色代码详解与对比。

常见问题

取色和提取配色有什么区别？

取色是读取你自己选中的某一个像素的确切颜色，你完全掌控取到的是哪个颜色。提取配色是扫描整张图片，自动排出最常见的颜色。想要精确的品牌色时用取色器，想要一张照片现成的配色方案时用提取器。

为什么在同一区域点两次，HEX 代码会略有不同？

在照片里，相邻像素很少完全相同，因为相机噪点和 JPEG 压缩会让每个像素的颜色略有差异。横向移动一个像素，最后一位就可能变了。取平坦区域中间的像素，并选择出现次数最多的那个值。

取到的颜色能直接用在网站样式表里吗？

可以。「导出 CSS」按钮会把你的色板下载为带 HEX 值的 CSS 自定义属性。粘贴进样式表后，就能在任何需要的地方使用这些变量。HEX 代码也可以直接粘贴进任何接受颜色值的设计工具。

取色器会修改或压缩我的图片吗？

不会。工具只读取像素值，从不修改、重新保存或压缩你的文件。原始图片完全不受影响，关掉页面后，你设备上的文件和原来一模一样。

如果图片无法下载，我怎么从网页上取色？

把网页截屏，然后用 Ctrl+V 粘贴进工具，或者上传截图文件。取色器读取截图像素的方式和读取任何图片一样，所以任何网站的按钮、背景和文字颜色都能取到。

取到的颜色在设计工具里看起来不一样，怎么办？

先检查复制的 HEX 代码是否完整，有没有漏掉一位。再记住，不同显示器和色彩配置会让同一个代码看起来略有不同。相信代码本身，并在同一块屏幕上把它和原始图片放在一起对比。
