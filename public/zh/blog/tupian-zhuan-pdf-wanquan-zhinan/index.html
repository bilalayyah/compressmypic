把图片做成 PDF，过去要装软件，或者把文件上传到某个网站。现在在浏览器里就能完成，图片还不用离开你的设备。

这篇指南会讲完整流程。你会了解页面尺寸、方向、边距、画质，以及让 PDF 看起来专业的小决定。

图片转 PDF 是什么意思？

图片转 PDF，就是把一张或多张图片做成一个 PDF 文档。每张图片变成一页，页面的顺序由你来定。

结果是一个人人能打开的文件。手机、电脑、打印机都认 PDF，版式也永远是你设定的样子。

大家用它来处理扫描件、证件照、收据、作业、作品集和相册。几张图片本就属于同一件事时，做成 PDF 是最整齐的发送方式。

CompressMyPic 的工具在浏览器本地生成 PDF。扫描件和证件照永远不会上传到服务器，敏感文件也能放心用。

为什么不直接发图片，要做成 PDF？

二十张图片的文件夹发起来别扭，还容易丢三落四。一个 PDF 把所有内容装在一起、按顺序排好，只用一个文件名。

PDF 还能保护你的版式。图片贴进聊天软件可能被压缩、被打乱顺序，PDF 却能原样保留页序和尺寸。

打印也是个原因。PDF 一页印一张图，尺寸可预测；直接打印散图，常常出意外。

最后，很多官方系统只接受 PDF 上传。签证表格、大学申请、税务网站要的是文档，不是照片文件，这个工具正好能搭上这座桥。

页面尺寸：A4、Letter 与按图适配

A4 是世界上大多数地方的标准页面尺寸，210×297 毫米，是文档、表格和打印投稿的默认选择。

Letter 比 A4 略宽略短，是美国和加拿大的标准。收件人在美国，或者表格写明 Letter 时，用它。

“按图片尺寸”会让每一页精确匹配图片本身。没有白边、不裁剪，图片铺满整页。

PDF 要打印或提交给官方系统时，选 A4 或 Letter。做成照片集或扫描存档时，选“按图片尺寸”。

方向与自动方向

方向决定页面是竖版还是横版。竖构图照片配竖版页面，横构图照片配横版页面。

自动方向会读取每张图，为它挑选匹配的方向。竖图横图混在一起时，每页都会自动排对。

选了“按图片尺寸”后，方向控件会被禁用。这很合理，页面尺寸跟着图片走，就没有单独的方向可言了。

扫描件几乎总是竖版。截图和宽幅照片，让自动方向决定，别强行给所有页面套同一个版式。

完整显示与铺满页面

“完整显示”会把整张图放进页面，哪怕边缘留出白边。什么都不裁，文档的任何部分都不会被切掉。

“铺满页面”会填满整页，多余部分裁掉。页面看起来满满当当、直达边缘，但图片边缘可能被修剪。

证件、身份证、收据一律用“完整显示”。被裁掉的签名或身份证一角，可能导致提交被退回。

相册和演示文稿用“铺满页面”更好看。满版布局显得有意为之，照片裁掉一点通常无伤大雅。

边距：无、小、中

无边距让图片直达页面边缘。适合“按图片尺寸”和整页照片，白边在那里会像个失误。

小边距在图片周围加一圈细白边。屏幕上看整洁，打印时图片也不会顶到纸边。

中等边距加更宽的白边，适合正式文档和要打印归档的东西。多出来的空间能保护图片不被打印机边缘吃掉。

打印机印不到纸的最边缘，无边距的 PDF 在纸上可能丢掉一丝图像。打算打印的东西，至少留个小边距。

PDF 画质滑块

画质滑块控制 PDF 里的图片压缩程度。画质越高，细节保留越多，PDF 也越大；画质越低，文件越小。

扫描件和证件照，画质保持高位。文字和细小印刷内容在低画质下很快变模糊，模糊的证件就是会被退回的证件。

屏幕上看的照片集，中等画质就够了。图片在手机或电脑上依然干净，PDF 也小到能发邮件。

生成后留意最终文件大小。PDF 太大发不出去时，把画质降一档再生成一次。

生成前调整页面顺序

页面顺序就是文档顺序，生成前就要排对。工具里有“页面顺序”列表，可以拖动页面调整次序。

看过列表后还能继续加照片。新图片会加到队列末尾，再拖到合适的位置就行。

正式提交的文件，顺序要检查两遍。签证申请页序错了，哪怕每页本身都完美，看起来也很马虎。

顺手删掉重复或倒置的页面。现在修好，远比生成后重做容易。

HEIC 照片直接做成 PDF

iPhone 照片可以直接放进 PDF 生成器，不用先单独转换。工具在浏览器里解码 HEIC，像 JPG 一样排到页面上。

这给 iPhone 用户省了一整步。不用先把 HEIC 转 JPG 再做 PDF，拖进 HEIC 文件，生成一次就行。

解码后的图片保持完整分辨率和方向。竖版照片还是竖版，宽幅照片还是宽幅，全靠自动方向处理。

某个 HEIC 文件加载失败时，先用HEIC 转 JPG 工具转成 JPG，再把 JPG 加进 PDF。两步走，什么文件都行。

PDF 里的透明背景

透明的 PNG 或 WebP 图片放进 PDF 后，透明部分会变成白色。PDF 承载透明的方式和图片文件不一样，所以工具会把透明区域填白。

大多数文档用白色正合适。透明标志落在白底上，看着干净，打印也没问题。

标志需要放在彩色页面上时，先转成 JPG 并配好底色。PNG 转 JPG 工具可以让你挑选填充色。

扫描件永远没有透明背景，所以这只关系到标志、贴纸和图形。普通照片完全不用管。

文件名与下载 PDF

保存前可以自定义输出文件名。passport-application.pdf 这样的名字，以后找起来比通用下载名容易得多。

生成时会显示进度，比如“正在编码第 X 页，共 Y 页”，长文档的生成过程也能看得到。二十页的 PDF 只要几秒，不用几分钟。

浏览器下载框消失了，就去“下载”文件夹里找。文件会自动保存在那里，哪怕你不小心关掉了弹窗。

发送之前打开成品 PDF 看一次。确认页数、顺序，以及最小的文字是否清晰，再放心分享。

隐私：证件与收据也能放心用

PDF 完全在浏览器里生成，护照、身份证、税务收据都不会上传到任何地方。这让这个工具对你最敏感的文件也很安全。

生成的 PDF 不加水印、不加页脚标志、不加页面戳记。文档里只有你自己的图片，按你排好的样子呈现。

有一点隐私提醒：生成 PDF 不会清除图片里的 EXIF 元数据。照片如果带 GPS 标签，建议先用元数据工具清除。

下载后，PDF 只存在你的设备上。关掉标签页，服务器上不会留下任何副本，因为从头到尾就没有服务器参与。

学生作业与大学申请的 PDF

学生一直在做 PDF，从作业扫描件到论文投稿。单个 PDF 让每一页保持顺序，老师一次读几十份投稿时，这一点很重要。

交作业用 A4 页面、“完整显示”、小边距。这套组合在屏幕上专业，打印出来批改也干净。

手写作业的扫描件，画质滑块保持高位。手写字在低画质下很快变模糊，老师看不清答案就没法打分。

文件名写上名字和作业，比如 ahmed-essay-3.pdf。清楚的名字方便老师归档，也不会和其他学生的文件搞混。

提交前检查文件大小。大学系统常常把上传上限设在 5MB 或 10MB，高画质扫描件做成的长 PDF 可能超限。

工作与商务的 PDF

发票、合同、收据在商务往来中都以 PDF 流转。单个文档比一堆散图更容易归档、转发和保存。

发票用 A4、“完整显示”、中等边距。正式的版式看起来专业，边距也能保护内容不被打印机边缘吃掉。

收据用“按图片尺寸”效果很好，因为收据形状各异。每一页精确匹配自己的收据，没有浪费的白边。

每份发出的 PDF 都留一份副本。按客户和月份整理好已发送文件夹，有问题时找文档就容易了。

敏感的商务文件别忘了，PDF 是本地生成的。合同和财务记录在转换过程中从不离开你的设备。

扫描小技巧，做出干净的 PDF

扫描干净，PDF 才干净，再好的设置也救不了一张糟糕的扫描。页面平铺在扫描仪上，对齐边缘，别让纸张折叠或带阴影。

带文字的文档，扫描分辨率用 200 DPI 或更高。分辨率低了，小字会模糊，PDF 没法把扫描仪没拍到的东西变清晰。

带印章、签名或彩色标记的文档，用彩色扫描。灰度扫描文件更小，但会丢掉证明真实性的颜色信息。

重要任务开始前，先擦干净扫描仪玻璃。一粒灰尘会在每一页上变成黑点，正式文件上看起来很不专业。

每张扫描件加进 PDF 前先预览。横着或倒着的页面，在扫描阶段修起来很容易，事后修就麻烦了。

分享与保存做好的 PDF

做好的 PDF 发邮件、发聊天、存云端都很方便。单个文件一次发走，不像文件夹那样可能发不全。

发邮件前检查文件大小。大多数邮件服务把附件上限设在 20MB 到 25MB，高画质扫描件的长 PDF 可能超限。

PDF 太大时，用云链接代替附件。把文件传到网盘，分享链接，对方下载不受大小限制，链接以后还能撤销。

做好的 PDF 按用途和日期分文件夹存放。2026-11-visa-documents 这样的文件夹几年后还好找，叫 stuff 的文件夹就不行。

生成 PDF 后，源图片也要留着。对方要求换页面尺寸或更小的文件时，有原图就能重做，不用重新扫描。

旅行证件的 PDF

旅行证件值得在手机里存成一个 PDF。护照复印件、签证、酒店订单、机票装在一个文件里，在边检或值机柜台都好找。

用 A4 页面加“完整显示”，每份证件完整地待在自己的页面上。被裁掉的护照号码或签证印章，是旅行 PDF 最常见的问题。

旅行证件的画质滑块保持高位。模糊的护照复印件可能在边检被拒，清晰的则一次通过。

PDF 一份存手机，一份存云端。手机可能丢、可能被盗，云端有副本，任何设备上都能取到证件。

原图也要留着。官方要求换格式时，有原图就能重做 PDF，不用重新扫描。

常见问题

一个 PDF 里能放多少张图片？

工具没有固定的页数上限，几十张图片的批量都没问题。文档太长会生成得更慢、文件更大，发邮件时要考虑篇幅。五十张图片的相册，可以考虑拆成两个 PDF。

做好的 PDF 在每台设备上看起来都一样吗？

是的，这正是 PDF 最大的优点。你设定的页面尺寸、顺序和版式，在手机、电脑和打印机上都会保留下来。不管对方用什么应用打开，看到的都是你看到的样子。

能把已有的 PDF 和图片合并成一个文档吗？

这个工具不行，它只从图片生成 PDF。如果你已经有一个 PDF，请用专门的 PDF 合并工具，把它和新生成的图片 PDF 合并。先生成图片 PDF，再合并两个文件。

为什么生成的 PDF 文件这么大？

PDF 大小取决于图片数量和画质滑块。高画质扫描件页数一多，体积很快就上去了。把画质降一档，或者减少图片数量，再生成一次。照片在中等画质下的压缩效果比扫描件好得多。

没有网络能把图片转成 PDF 吗？

页面加载好之后，PDF 生成在本地运行，不需要联网。只有第一次打开页面时需要网络。之后在关掉标签页之前，都可以离线做 PDF。

扫描件做 PDF，用什么页面尺寸最好？

大多数国家默认选 A4，因为打印机和官方系统都认它。只有收件人在美国或加拿大时才用 Letter。“按图片尺寸”适合照片，不适合文档，因为每页尺寸都不一样。
